## 仕組み

文字列セット属性を使用すると、ユーザーがサイトを利用する際に、情報のコレクションをリアルタイムで追跡、絞り込み、調整できます。この情報を使用して、パーソナライズされた体験を構築し、ターゲティングを改善できます。ユーザーが閲覧した上位の商品カテゴリー、頻繁に検索した旅行先、利用した特定のサービスなどを追跡する場合に、文字列セットを使用すれば、これらのデータを動的に保存および処理できます。

## 文字列セットを使用する理由

この属性がさまざまな業界のビジネスにどのように役立つか、実際のユースケースをいくつか紹介します。

* 小売・Eコマース：ユーザーがセッション中に閲覧した上位の商品カテゴリーを追跡し、パーソナライズされたおすすめ情報をメールで送信します。
* 旅行・ホスピタリティ：頻繁に検索された場所を抽出し、ユーザーが最も関心を持っている旅行先を特定します。
* ヘルスケア：ユーザーが最も多く調査した疾患を保存し、関連コンテンツを個別に提供します。
* 自動車：訪問が閲覧した車種を追跡し、それに応じてターゲティング広告を調整します。
* サブスクリプションサービス：訪問が最も積極的に利用したサブスクリプションプランやサービスを取得し、関連するおすすめ情報を送信します。

文字列セット属性は、エンリッチメントを使用して動的に更新され、多くの場合、集計、文字列、ルールベースのロジックなどの他の属性と組み合わせて使用されます。これにより、関連性の高いユーザーインタラクションのみが取得および保存され、分析に利用できるようになります。

## 主なメリット

* 顧客固有の関心を追跡し、最も重要なインタラクションを動的に取得できます。
* 閲覧された上位の商品カテゴリーなど、重要なエンゲージメントデータのみを保持できます。
* 実際のエンゲージメントデータを使用して、パーソナライズされたマーケティングキャンペーンを開始できます。
* 予約済みの旅行先や返品された商品を削除するなど、保存された値を更新および調整し、リターゲティングやパーソナライゼーションに使用するデータを最新かつ関連性の高い状態に維持できます。

## このガイドの内容

このガイドでは、文字列セットを使用して訪問のインタラクションを追跡、絞り込み、管理し、パーソナライゼーションとリターゲティングを改善する方法を説明します。

次のユースケースについて説明します。

* **Set to Top Tally Items**エンリッチメントを使用して、セッション中に検索された上位3件の旅行先を取得し、パーソナライズされたおすすめ情報に活用します。
* **Set to Tally Items Above Target**値エンリッチメントを使用して、5回を超えて閲覧された旅行先のみを保存し、関心度の高い項目に絞ってターゲティングマーケティングを行います。
* コネクターを使用して文字列セット属性をメールプラットフォームに渡し、訪問が最も多く検索した旅行先に基づいて、動的にパーソナライズされたコンテンツを配信します。

## Set to Top Tally Itemsの例

文字列セット属性を使用して、訪問がセッション中に検索した上位3件の旅行先を取得します。この情報は、パーソナライズされたフォローアップメールの送信、旅行に関するおすすめ情報の最適化、広告ターゲティングの改善に使用できます。

たとえば、訪問が5件の旅行先を検索した場合、**Set to Top Tally Items**エンリッチメントは、フォローアップマーケティングに関連する、検索頻度が最も高い上位3件の旅行先のみを取得して保存します。

### ステップ1：Increment Tally属性を作成する

検索回数の多い上位3件の旅行先を特定するには、まず、訪問がセッション中に各旅行先を検索した回数を追跡する必要があります。これを追跡するには、**Countries of Resorts Browsed in Visit**という名前の訪問スコープの集計属性を、次のエンリッチメントで作成します。

```
For Tally Countries of Resorts Browsed in Visit increment the value based on "country" by 1
WHEN: Any event
Rule "page_type" equals (ignore case) "resort_details"
```

![](https://docs.tealium.com/images/guides/set-of-strings-increment-tally-attribute.png)

### ステップ2：文字列セット属性を作成する

各旅行先が検索された回数を追跡できるようになったため、次に、最も多く検索された3件の旅行先のみを抽出します。

次のエンリッチメントを使用して、訪問中に閲覧されたリゾートの国の上位3件を保存する文字列セット属性を作成します。

1. **Transform > Visitor / Visit Attributes**に移動します。
1. **+ Add Attribute**をクリックします。
1. **Visit scope**を選択し、**Continue**をクリックします。
1. **Set of Strings**データ型を選択します。
1. **Title**に、**Top 3 Countries for Resorts Browsed in Visit**と入力します。
1. **+ Add Enrichment**をクリックします。
1. **Set to Top Tally Items**を選択します。
1. 次の文字列セットを構成します。
    ```
    Set Top 3 Countries for Resorts Browsed in Visit to top 3 items in "Countries of Resorts Browsed in Visit"
    WHEN: Any event
    ```
1. **Finish**をクリックします。

![](https://docs.tealium.com/images/guides/set-of-strings-set-to-top-tally-items.png)

訪問が次の旅行先を検索したとします。

* ベトナム（1回）
* パリ（4回）
* ロンドン（3回）
* ローマ（2回）
* ニューヨーク（5回）

最終的な文字列セットには、上位3件の旅行先のみが保存されます。

```
[ "New York", "Paris", "London" ]
```

## Set to Tally Items Above Targetの例

次の例では、**Set to Tally Items Above Target**エンリッチメントを使用して、訪問がセッション中に5回を超えて検索した旅行先を保存します。これにより、最も多く検索された旅行先のお得な情報を掲載したパーソナライズ広告、旅行に関するおすすめ情報、フォローアップメールを使用して、意向の強い訪問をリターゲティングできます。

[上記のステップ1](#step-1-create-an-increment-tally-attribute)で、訪問がセッション中に各旅行先を検索した回数を追跡するために、訪問集計属性**Countries of Resorts Browsed in Visit**を作成しました。この集計を使用して、**5回を超えて**検索された関心度の高い旅行先のみを抽出します。

**Set of Strings**属性を作成するには、次の手順を実行します。

1. **Transform > Visitor / Visit Attributes**に移動します。
1. **+ Add Attribute**をクリックします。
1. **Visit scope**を選択し、**Continue**をクリックします。
1. **Set of Strings**データ型を選択します。
1. **Title**に、**Countries Seen More Than 5 Times**と入力します。
1. **+ Add Enrichment**をクリックします。
1. **Set to Tally Items Above Target Value**を選択します。
1. 次の文字列セットを構成します。
    ```
    Set Countries Seen More Than 5 Times to items in "Countries of Resorts Browsed in Visit" where the value is greater than 5
    WHEN: Any event
    ```
1. **Finish**をクリックします。

![](https://docs.tealium.com/images/guides/set-of-strings-set-to-tally-items-above-target.png)

訪問が次の旅行先を検索したとします。

* パリ（6回）
* ロンドン（3回）
* ローマ（7回）
* マドリード（2回）
* ベルリン（1回）

最終的な文字列セットには、5回を超えて検索された旅行先のみが保存されます。

```
[ "Paris", "Rome" ]
```

これにより、関心度の高い旅行先のみにリターゲティング施策を集中させ、広告の効率、おすすめ情報、パーソナライズされたメールキャンペーンを改善できます。
## コネクタアクションで文字列セットを使用する

**Countries Seen More Than 5 Times** 属性のような**文字列セット**属性を、コネクタを使用して **Iterable** などのメールサービスプロバイダーに渡すことができます。この属性には、訪問が1回のセッションで5回を超えて検索した目的地が記録されるため、関心の強さを示す有力なシグナルとなります。Braze、Adobe Campaign、Salesforce Marketing Cloud など、サポートされている他のプラットフォームでも同じ方法を適用できます。

コネクタをトリガーするには、**Countries Seen More Than 5 Times** 属性に値が割り当てられている訪問を含むオーディエンスを作成します。コネクタアクションで、この属性を `countries_seen_more_than_5_times` などのテンプレート変数にマッピングします。その後、メールコンテンツ内でこの変数を参照し、パーソナライズされた目的地のリストを表示できます。訪問がこのオーディエンスに加わると、コネクタアクションが実行され、**Countries Seen More Than 5 Times** 属性がメールプラットフォームに送信されます。

たとえば、訪問の文字列セットに `["Paris", "Rome"]` が含まれているとします。

コネクタはこのリストをメールプラットフォームに渡します。メールプラットフォームでは、このリストを使用して、*「パリやローマへの旅行をまだ夢見ていますか？あなたにぴったりのお得なプランをご紹介します。」*のようなコンテンツを動的に構成できます。

これにより、関心の高い訪問に行動に基づいたオファーを配信でき、エンゲージメントとコンバージョンの可能性が高まります。

## 次のステップ

訪問のインタラクションを追跡、フィルタリング、アクティブ化するための文字列セット属性を実装したら、構成をさらに拡張するために次のステップを検討してください。

* **使用状況を監査およびモニタリングする**  
[Trace](https://docs.tealium.com/manage-traces/) と [Live visitors](https://docs.tealium.com/visitor-profile-sampler/) を使用して、セッション全体で属性がどのように構成され、使用されているかを確認します。
* **新しいチャネルに展開する**  
SMS、ディスプレイ広告、プッシュ通知など、他のコネクタで文字列セット属性を使用し、一貫性のあるクロスチャネルエクスペリエンスを実現します。

* **除外およびクリーンアップロジックを追加する**  
**Remove From Set of Strings** などのエンリッチメントを使用して、予約済みの目的地や期限切れの商品など、不要な値を削除し、データを整理します。

* **他の属性タイプと組み合わせる**  
文字列セットをバッジ、数値、ブール値と組み合わせて、高度なオーディエンスロジックや時間制約のあるキャンペーンを作成します。

* **リアルタイムパーソナライゼーションで使用する**  
Functions で文字列セットを使用するか、EventStream を介して渡すことでイベントデータを拡充し、Web サイト、モバイルアプリ、その他のチャネルでリアルタイムパーソナライゼーションをトリガーします。
