## 要件

この機能には以下が必要です：

* サーバーサイドのリーダー、エディター、またはパブリッシャーのレガシー権限、または
* 最低限の**閲覧**ビジタールックアッププラットフォーム権限

## 動作原理

このAPIを使用すると、特定のビジターに関する既知のデータを取得し、ウェブサイトへの初回訪問のパーソナライゼーションを向上させることができます。ビジタールックアップは、アカウントからの[ビジターID](https://docs.tealium.com/visitor-id-attribute/)属性に基づいています。

## レート制限

ビジタープロファイルAPIのデフォルトのレート制限は、秒間50リクエストです。より高いレート制限が必要な場合は、予想される使用量を持ってTealiumアカウントマネージャーに連絡してください。

## 認証


<blockquote>
すべてのAPI呼び出しを認証するために使用されるのはベアラートークンであり、APIキーではありません。APIキーは認証呼び出しでのみ使用されます。ベアラートークンに加えて、認証応答には、後続のサーバーサイドAPI呼び出しで使用する必要がある地域固有のホスト名が含まれています。
</blockquote>


APIキーからベアラートークンを生成する方法については、[認証](https://docs.tealium.com/api/v3/getting-started/authentication/)を参照してください。
