Seznamリターゲティングは、サイトを訪問したユーザーにリーチするために設計されています。

## タグに関するヒント

* マッピングを使用して、以下を行います。
    * 標準構成値を動的に上書きする。
    * Eコマース拡張機能の値を動的に上書きする。

## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加するときに、以下の構成を構成します。

* **Rtg Id**：Seznamから提供されたマーチャントID。
* **Auto Tracking**：タグが読み込まれるたびに`retargetingHit()`関数を呼び出すには、このオプションを有効にします。

## 読み込みルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。詳細については、[読み込みルールについて](https://docs.tealium.com/about-load-rules/)を参照してください。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

利用可能なカテゴリーは次のとおりです。

### 構成

| 変数 | 型 | 説明 |
|:---------|:-----|:------------|
| `rtgId` | 文字列 | Seznamから提供されたマーチャントID。 |
| `auto_tracking` | ブール値 | 自動トラッキング。タグが読み込まれるたびに`retargetingHit()`関数を呼び出すには、このオプションを有効にします。 |

### 標準

| 変数 | 型 | 説明 |
|:---------|:-----|:------------|
| `eid` | 文字列 | ユーザーのメールアドレス。 |
| `a1` | 文字列 | ユーザーの国。 |
| `a2` | 文字列 | ユーザーの市区町村。 |
| `a3` | 文字列 | ユーザーの通り名。 |
| `a4` | 文字列 | ユーザーの番地。 |
| `a5` | 文字列 | ユーザーの郵便番号。 |
| `tid` | 文字列 | ユーザーの電話番号。 |

### リターゲティング

| 変数 | 型 | 説明 |
|:---------|:-----|:------------|
| `consent` | 数値 | ユーザーの同意。<ul><li>`0`：同意なし。</li><li>`1`：同意済み。</li></ul> |
| `itemId` | 文字列 | オファー識別子。 |
| `category` | 文字列 | カテゴリー。 |
| `pageType` | 文字列 | ページタイプ。 |
| `rtgUrl` | 文字列 | クエリ文字列。 |

### コンバージョン

| 変数 | 型 | 説明 |
|:---------|:-----|:------------|
| `id` | 文字列 | コンバージョン識別子。 |
| `value` | 文字列 | 注文金額（`_ctotal`を上書き）。 |
| `orderId` | 文字列 | 注文識別子（`_corder`を上書き）。 |
| `zboziType` | 文字列 | 測定タイプ（`_ctype`を上書き）。 |
| `zboziId` | 文字列 | 施設ID。 |
