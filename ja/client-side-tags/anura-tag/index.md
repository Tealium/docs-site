---Anura は、トラフィックを分析し、実在するユーザーとボット、マルウェア、不正な人間のユーザーを識別する広告詐欺検出ソリューションです。この記事では、タグ管理用の Anura マーケットプレイタグを構成する方法について説明します。

Anura タグは、「good」や「suspect」などの基本的な Anura レスポンスを、指定したレスポンス保存先のレスポンス変数名に格納します。スクリプトレスポンスを使用している場合、レスポンスオブジェクト変数名はデフォルトの Anura ウィンドウオブジェクトで使用できます。

## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際は、次の構成を行います。

* **タイトル**
  * デフォルトは Anura です。
  * 任意のカスタム名に変更できます。
  * 同じベンダーのタグを複数使用する場合は、一意の名前を割り当ててください。
* **インスタンス ID**
  * アカウント担当者から割り当てられたインスタンス ID。
* **ソーストラッキング ID**
  * Anura インターフェイス内でトラフィックを識別するために宣言する変数。
* **キャンペーントラッキング ID**
  * Anura インターフェイス内でトラフィックを識別しやすくするために宣言する、ソーストラッキング ID のサブセット変数。
* **レスポンスオブジェクト変数名**
  * 初期レスポンスデータが割り当てられる JavaScript オブジェクトの変数名。
* **結果取得方法**
  * 結果の照会に使用する方法。
  * オプションは、スクリプトレスポンスまたはダイレクトレスポンスです。
* **レスポンス保存先**  
  * 結果を格納する場所。
  * オプションは、ウィンドウ変数、セッション保存、またはローカル保存です。
* **レスポンス変数名**
  * 最終的な Anura レスポンスを格納するレスポンス保存先変数の名前。

## 読み込みルール

[読み込みルール](https://docs.tealium.com/about-load-rules/)は、サイト上のどの場所で、いつこのタグのインスタンスを読み込むかを決定します。

推奨される読み込みルール：**すべてのページで読み込む**

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

Anura タグの宛先変数は、その［データマッピング］タブに組み込まれています。利用可能なカテゴリーは次のとおりです。

### 標準

|タグの宛先|説明|変数|
|---|---|---|
|インスタンス|<ul><li>（必須）インスタンス ID。</li></ul>|`instance`|
|ソーストラッキング ID|<ul><li>（任意）Anura ダッシュボード内でソーストラフィックを識別するために宣言する変数。</li><li>最大 128 文字。</li><li>「all sources」、「all campaigns」、「&」、「\*」、「?」、「%」と同じ値は使用できません。</li><li>先頭には「$」、「\_」、または「a-z」の文字を使用でき、その後には「a-z」および「0-9」の文字を使用できます。</li></ul>|`source`|
|キャンペーントラッキング ID|<ul><li>（任意）Anura ダッシュボード内でキャンペーントラフィックを識別するために宣言する、ソース変数のサブセット。</li><li>最大 128 文字。</li><li>「all sources」、「all campaigns」、「&」、「\*」、「?」、「%」と同じ値は使用できません。</li></ul>|`campaign`|
|一意の外部 ID|<ul><li>（任意）Anura サーバーから結果を照会するために使用される、宣言済みの一意の外部トラッキング ID。</li><li>最大 128 文字。</li></ul>|`exid`|
|レスポンスオブジェクト変数名|<ul><li>（任意）レスポンスデータが割り当てられる JavaScript オブジェクトの変数名。</li><li>この変数にはレスポンス ID とその他のデータが含まれており、リアルタイムでの意思決定に使用できます。</li><li>最大 128 文字。</li></ul>|`variable`|
|結果取得方法|<ul><li>（任意）結果の取得方法。</li></ul>|`result_method`|
|結果の保存先|<ul><li>（任意）結果の保存先。</li></ul>|`result_location`|
|レスポンス変数名|<ul><li>（任意）レスポンス変数名。</li></ul>|`response_variable`|
|訪問の IP アドレス|<ul><li>（必須）訪問の IP アドレス。</li><li>IPv6 アドレスもサポートされています。</li></ul>|`ip`|
|訪問のユーザーエージェント|<ul><li>（任意）訪問のユーザーエージェント文字列。</li></ul>|`ua`|

### E コマース

Anura タグは E コマースに対応しているため、デフォルトの [E コマース拡張機能](https://docs.tealium.com/e-commerce-extension/)のマッピングを自動的に使用します。拡張機能のマッピングを上書きする場合や、E コマース変数が拡張機能に用意されていない場合を除き、通常、このカテゴリーで手動マッピングを行う必要はありません。

|宛先|説明|E コマース拡張機能の変数|
|---|---|---|
|注文 ID|確定した注文に割り当てられる一意の識別子。|`_corder`|
|小計|確定した注文の小計金額。|`_csubtotal`|
|通貨|支払いに使用された通貨。|`_ccurrency`|
|商品 ID のリスト|商品配列内の各商品の一意の識別子。|`_cprod`|
|商品名のリスト|商品配列内の各商品の名前。|`_cprodname`|
|ブランドのリスト|商品配列内の各商品のブランド。|`_cbrand`|
|カテゴリーのリスト|商品配列内の各商品の名前。|`_ccat`|
|数量のリスト|商品配列内の各商品の数量。|`_cquan`|
|価格のリスト|商品配列内の各商品の単価。|`_cprice`|
|E コマースの宛先名|説明を挿入します。|該当なし|
