この記事では、タグ管理アカウントで Neustar PlatformOne コンバージョンタグを構成する方法について説明します。

Neustar® PlatformOne は、広告主があらゆるマーケティング活動で精度の高いマーケティングを実施できる統合マーケティングプラットフォームです。Neustar の Authoritative Identity Engine を搭載した PlatformOne は、顧客と見込み客に関する単一かつ公平で正確なビューを提供し、コンバージョン率の向上、支出の最適化、そして最終的な売上の増加を実現します。

## タグに関するヒント

*   マッピングを使用すると、標準の構成値を動的に上書きできます。
*   次の E コマース変数を使用します。
    *   `_corder`
    *   `_ctotal`
    *   `_ccustid`
    *   `_cquan`
*   `product_quantity`
    *   配列としてマッピングできます（通常どおり E コマースの値を上書きします）。配列の値は合計され、総数として使用されます。
    *   または、数値としてマッピングすると、その値が直接割り当てられます。

## タグの構成

タグマーケットプレイスに移動し、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際に、次の項目を構成します。

*   **タグ ID**：整数値。例：`123456`
*   **タイプ ID**：整数値。例：`123456`

## ロードルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。ロードルールの詳細については、[ロードルール](https://docs.tealium.com/about-load-rules/)のドキュメントを参照してください。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

利用可能なカテゴリーは次のとおりです。

### 標準

| 変数 | 説明 |
|:---------|:------------|
| タグ ID   | (`tag_id`)  |
| タイプ ID  | (`type`)    |

### E コマース

| 変数                                                     | 説明                            |
|:-------------------------------------------------------------|:---------------------------------------|
| 注文 ID                                                     | (`order_id`)（`_corder` を上書き）     |
| 注文合計                                                  | (`order_total`)（`_ctotal` を上書き）  |
| 顧客 ID                                                  | (`customer_id`)（`_ccustid` を上書き） |
| 数量のリスト（`product_quantity`）（`_cquan` を上書き） | \[配列／数値\]                       |
| カスタム属性 1（`cust1`）                                 | \[配列／文字列\]                       |
| カスタム属性 2（`cust2`）                                 | \[配列／文字列\]                       |
