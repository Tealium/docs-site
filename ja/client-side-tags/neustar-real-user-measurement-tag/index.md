Neustar (RUM), Inc. は、インターネット、通信、情報サービス、金融サービス、小売、メディア、広告の各分野にリアルタイムの情報と分析を提供する、信頼性の高い中立的なプロバイダーです。

## タグに関するヒント

* より正確な指標を取得するには、PreLoader拡張機能に次のコードを追加します。
```
window.t_pagestart = new Date().getTime();
```
* このタグを最初に実行することを推奨します（タグリストの先頭に移動してください）。
* このタグは `Wait=Yes`（デフォルト）に構成してください。
* タグの構成は必要ありません。

## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳しくは、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際に、次の項目を構成します。

* **アカウントID**：アカウントID。
* **タイムアウト値**：タグがタイムアウトするまでの時間を構成します。
* **タグ読み込み時にInitを実行**：タグの読み込み時にinitプロセスを実行します。マッピングはできません。

## 読み込みルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。詳しくは、[読み込みルールについて](https://docs.tealium.com/about-load-rules/)を参照してください。

## データマッピング

データマッピングを使用すると、データレイヤー変数の値がベンダータグ内の対応する変数に送信されます。詳しくは、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

使用可能なカテゴリは次のとおりです。

### 標準

| 説明 | 変数 |
|:---------|:------------|
| `account` | アカウントID |
| `time_out` | 体感読み込みタイムアウト |
