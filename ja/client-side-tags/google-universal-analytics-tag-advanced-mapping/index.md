## 要件

開始する前に、[Eコマース拡張機能](https://docs.tealium.com/e-commerce-extension/)を追加してください。この拡張機能により、Eコマースデータが Google ユニバーサル アナリティクスに自動的にマッピングされます。Eコマース変数のマッピング先については、以下の「Eコマース」セクションを参照してください。
## 標準マッピング

Tealium では、デフォルト構成を上書きしたり、標準構成値を動的に構成したりできる標準マッピングを提供しています。マッピングを使用してデフォルト値を変更すべきか判断できるよう、可能な場合は Google が使用するデフォルト値を示します。標準マッピングには以下が含まれます。

* **トラッキング ID**
トラッキング ID は、Google がアカウントに割り当てる識別子です。通常は「UA-」で始まる文字列です。このマッピングを使用すると、Marketplace タグのインターフェイスで構成したトラッキング ID を上書きしたり、動的に構成したりできます。
Google Universal Analytics タグでは、1 つのタグに複数のトラッキング ID を構成できるため、マッピングを行う場合は、「トラッキング ID」と「トラッカー名」の数を一致させる必要があります。たとえば、5 つの異なるトラッキング ID が指定されている場合は、同じ数のトラッカー名を指定する必要があります。5 つのトラッカー名のうち 4 つしか指定されていない場合、意図しない動作が発生します。
* **トラッカー名**
このマッピングを使用すると、Marketplace タグのインターフェイスで構成したトラッカー名を上書きしたり、動的に構成したりできます。これは、複数アカウントのトラッキングを行う場合にのみ必要です。
Google Universal Analytics タグでは、1 つのタグに複数のトラッキング ID を構成できるため、マッピングを行う場合は、「トラッキング ID」と「トラッカー名」の数を一致させる必要があります。たとえば、5 つの異なるトラッキング ID が指定されている場合は、同じ数のトラッカー名を指定する必要があります。5 つのトラッカー名のうち 4 つしか指定されていない場合、意図しない動作が発生します。
* **ページ**
デフォルトでは、ページはページ URL のパス名部分であり、主にモーダルウィンドウなどの仮想ページパスを指定するために使用されます。このパラメータは各 Web ページに固有であるため、Google はこれをページ識別子として使用します。
* **タイトル**
ページまたはドキュメントのタイトルを識別します。デフォルトでは、Google は JavaScript の title プロパティを返します。
```js
document.title
```
* **ロケーション**
訪問が閲覧している URL を識別します。デフォルトでは、Google はページの完全な URL（アンカーを除く）を返します。
* **UID**
訪問または顧客を識別します。ユーザー ID を手動で指定するには、この宛先にマッピングします。この値は一意かつ永続的であり、認証システムと併用すると、セッションやデバイスをまたいで同一ユーザーをトラッキングできます。
* **Cookie ドメイン**
Cookie ドメインパラメータは、Analytics Cookie の保存に使用するドメインを指定します。これを「none」に構成すると、ドメインを指定せずに Cookie が構成されます。詳細については、[Google Universal Analytics：基本構成](https://docs.tealium.com/google-universal-analytics-analyticsjs-tag/)の記事にある「タグ構成」セクションの「ドメイン」を参照してください。
* **Cookie の有効期限**
デフォルトでは、Google Universal Analytics タグによって作成される Cookie の有効期限は 2 年後に構成されます。この有効期限は、ヒットが送信されるたびに更新されます。このパラメータに値 0 を渡すとセッションベースの Cookie になり、それ以外の場合、値は秒単位で指定されます。
* **従来の Cookie ドメイン**
従来の Cookie ドメインパラメータは、Analytics Cookie の保存に使用するドメインを上書きします。空欄のままにすると、Google がこの値を自動検出します。これを「none」に構成すると、ドメインを指定せずに Cookie が作成されます。詳細については、[Google Universal Analytics：基本構成](https://docs.tealium.com/google-universal-analytics-analyticsjs-tag/)の記事にある「タグ構成」セクションの「ドメイン」を参照してください。
* **従来の履歴のインポート**
`ga.js` Cookie から履歴データをインポートするかどうかを指定します。この宛先にマッピングする変数に、ブール値「true」または「false」が含まれていることを確認してください。
* **非インタラクション**
イベントを直帰率に反映するかどうかを指定できます。デフォルトでは、Google はイベントをインタラクションとして識別します。Google の[イベントについて](https://support.google.com/analytics/answer/1033068#NonInteractionEvents)の記事にある「非インタラクション イベント」の説明を参照してください。
* **拡張リンクのアトリビューション**
拡張リンクのアトリビューションのオン／オフを切り替え、構成を上書きできます。デフォルトは**オフ**です。拡張リンクのアトリビューションでは、リンク要素 ID を使用して、1 つのページ内にある同じ URL への複数のリンクを自動的に区別するため、ページ解析レポートの精度が向上します。詳細については、Google の[拡張リンクのアトリビューション](https://support.google.com/analytics/answer/2558867?hl=en)の記事を参照してください。
* **setAllowLinker（allowLinker）**
クロスドメイントラッキングのオン／オフを切り替えられます。デフォルトは**オフ**です。詳細については、Google の[リンカー](https://developers.google.com/analytics/devguides/collection/analyticsjs/linker)の記事を参照してください。
* **自動リンクドメイン（crossDomainTrack）**
アクティビティを横断的にトラッキングするドメインのリストを指定するために使用します。複数のドメインがある場合は、リスト内で各ドメインをカンマで区切る必要があります。
* **サイト速度のサンプルレート（siteSpeedSampleRate）**
Google がページのタイミング指標を算出するために使用するユーザーサンプルのサイズを指定します。Google のデフォルト構成は 1% です。
* **サンプルレート（sampleRate）**
トラッキング対象とする訪問の割合を示します。デフォルト値は 100 で、ユーザーの 100% がサンプリング対象になることを意味します。詳細については、Google デベロッパー向けドキュメントの[サンプルレート](https://developers.google.com/analytics/devguides/collection/analyticsjs/field-reference#sampleRate)を参照してください。
* **E コマースパラメータの自動入力（autofill\_params）**
「E コマース値の自動入力」のオン／オフを切り替え、タグ構成の切り替えを上書きできます。
* **Optimizely 連携（optimizely）**
「Optimizely 連携」のオン／オフを切り替え、タグ構成の切り替えを上書きできます。
* **拡張機能の前にトラッカーを初期化（init\_before\_extensions）**
「拡張機能の前に create を有効化」のオン／オフを切り替え、タグ構成の切り替えを上書きできます。
* **セッション制御（sessionControl）**
セッション期間を「start」または「end」に構成できます。詳細については、Google デベロッパー向けリファレンスの[セッション制御](https://developers.google.com/analytics/devguides/collection/protocol/v1/parameters?hl=en#sc)を参照してください。
* **IP の匿名化（anonymizeip）**
「IP の匿名化」のオン／オフを切り替え、タグ構成の切り替えを上書きできます。詳細については、Google デベロッパー向けリファレンスの[IP の匿名化](https://developers.google.com/analytics/devguides/collection/protocol/v1/parameters?hl=en#aip)を参照してください。
* **データソース（dataSource）**
これはヒットの変数値です。例として、Web、モバイル、CRM などがあります。詳細については、Google デベロッパー向けリファレンスの[データソース](https://developers.google.com/analytics/devguides/collection/protocol/v1/parameters?hl=en#ds)を参照してください。
* **変数をクリア**  
シングルページアプリケーションにのみ推奨されます。この宛先へのマッピングは、[変数をクリアのタグ構成](https://docs.tealium.com/google-universal-analytics-analyticsjs-tag/)を上書きします。
* **クライアント ID**  
ブラウザインスタンス用にランダムに生成される ID です。[詳細はこちら](https://developers.google.com/analytics/devguides/collection/analyticsjs/field-reference#clientId)。
* **カスタム Set コマンド（set.###）**
「set」コマンドにカスタムパラメータを渡すことができます。たとえば、`ga(‘set’, ‘dataSource’, ‘web’)` です。
## イベントマッピング


<blockquote>
イベントは、イベントカテゴリとイベントアクションの両方が定義されている場合にのみ送信されます。
</blockquote>


ほかの2つのパラメータであるイベントラベルとイベント値は任意です。これらは、Webページ上で動画が再生された場合や、ショッピングカートに商品が追加された場合など、特定のコンバージョンを記録するためによく使用されます。

* **eventCategory**（必須）  
「クリック」など、インタラクションの種類を識別する変数をマッピングできます。
* **eventAction**（必須）  
「ボタン」など、操作されたオブジェクトを識別する変数をマッピングできます。
* **eventLabel**  
「ナビゲーションボタン」など、イベントを分類する変数をマッピングできます。
* **eventValue**  
イベントの回数を識別する変数をマッピングできます。例：4回。このパラメータの値は、0以上の数値である必要があります。
* **ga\_events**  
イベントヒットの配列を含む変数をマッピングできます。
* **グローバルビューコールバックと標準イベントコールバック**  
これらの宛先は、[GoogleのhitCallback関数](https://developers.google.com/analytics/devguides/collection/analyticsjs/field-reference#hitCallback)に対応します。ページビューを含むすべてのヒットタイプで関数を呼び出すには、グローバルビューコールバックの宛先にマッピングします。イベントカテゴリとイベントアクションの宛先に値が構成されている場合にのみ関数を呼び出すには、標準イベントコールバックの宛先にマッピングします。最初に、マッピングするデータレイヤー変数の値をコールバック関数に構成する必要があります。  
次の手順で、変数をコールバックの宛先にマッピングします。
  1. [新しいSet Data Value拡張機能を追加](https://docs.tealium.com/set-data-values-extension/)し、そのスコープをGoogle Universal Analyticsタグに構成します。
  1. 「Configuration」で、「Set」ドロップダウンリストから変数を選択します。
  1. 「**To**」ドロップダウンで「**JS Code**」を選択し、テキストフィールドにコールバック関数を記述します。
  1. タグの「Data Mappings」タブに戻り、同じ変数を使用するコールバックの宛先にマッピングします。
  1. 保存してパブリッシュします。
  
詳細については、[Google Universal Analyticsのイベントトラッキングガイド](https://docs.tealium.com/google-universal-analytics-event-tracking/)を参照してください。


## キャンペーンマッピング

キャンペーンの値は、クエリ文字列パラメータを介してページのURLから自動的に取得されます。GUAでは、これらの値を手動で構成できます。以下に示す値はすべて任意です。

* **キャンペーンID**
Googleによって割り当てられたキャンペーンの一意の識別子。
* **キャンペーン名**
キャンペーンの名前。
* **キャンペーンソース**
Webサイト名や会社名など、キャンペーンの参照元。
* **キャンペーンメディア**
バナー広告、メールキャンペーン、クリック広告など、キャンペーンの種類。
* **キャンペーンコンテンツ**
キャンペーン広告の説明。
* **キャンペーンキーワード**
キャンペーン広告のキーワード。

## ソーシャルマッピング

この機能セットを使用すると、Facebookの「いいね！」やXへの投稿など、ソーシャルボタンのクリックを測定できます。これはイベントトラッキングに似ていますが、一貫した変数を使用して個別にレポートできます。ソーシャルインタラクションイベントを送信するには、3つの変数をすべて構成する必要があります。

* **ソーシャルネットワーク**
アクションが発生するネットワーク（Facebook、Xなど）。
* **ソーシャルアクション**
発生するアクションの種類（「いいね！」、送信、投稿など）。ソーシャルネットワーク、ソーシャルアクション、ソーシャルターゲットのすべてが必要です。
* **ソーシャルターゲット**
ソーシャルインタラクションの対象を指定します。この値は通常URLですが、任意のテキストを使用できます。

## Eコマースマッピング

これらの変数はEコマースに関連しており、対応するEコマース拡張機能の変数から値を自動的に取得します。これらの値は「transaction」ページでのみ送信されることに注意してください。「product」や「cart」など、その他の種類のEコマースページでは使用されません。Eコマース拡張機能を追加して構成している場合、ここで構成するマッピングがEコマース拡張機能のマッピングを上書きします。

* **注文ID（トランザクションID）**
マッピングすると、この変数は、完了した購入の注文IDを表す`_corder`の値を上書きします。
* **アフィリエーション（店舗名／ID）**
マッピングすると、この変数は、このトランザクションが発生した店舗またはアフィリエーションを表す`_cstore`の値を上書きします。
* **収益（総合計）**
マッピングすると、この変数は、トランザクションに関連付けられた総収益／総合計を表す`_ctotal`の値を上書きします。この値には、送料や税金を含める必要があります。
* **送料**
マッピングすると、この変数は注文の送料を表す`_cship`の値を上書きします。
* **税金**
マッピングすると、この変数は注文の税額を表す`_ctax`の値を上書きします。

## アプリ／画面トラッキング

これらのタグの宛先では、訪問が主にコンテンツを閲覧するために使用するアプリ（「アプリケーション」の略）のさまざまな構成を追跡できます。

* **画面ビューの追跡（screenView）**
ヒットの種類をscreenViewとして識別します。
* **アプリケーション名（appName）**
画面をレンダリングするアプリの名前を識別します。
* **アプリケーションID（appId）**
アプリの一意の識別子を指定します。
* **アプリケーションバージョン（appVersion）**
アプリのバージョンを識別します。
* **アプリケーションインストーラーID（appInstallerId）**
アプリのインストーラー識別子を指定します。
* **画面名（screenName）**
訪問が閲覧した画面の名前を識別します。
* **例外の説明（exception\_reason）**
このパラメータは例外について説明します。詳細については、[例外の説明](https://developers.google.com/analytics/devguides/collection/protocol/v1/parameters?hl=en#exd)のセクションを参照してください。

## コンテンツグループ

コンテンツグループを使用すると、サイトまたはアプリのコンテンツを、コンテンツの捉え方に応じたコレクションに整理できます。類似するコンテンツを同じグループにまとめ、グループ名別にコンテンツを表示できます。

「**イベントタイプ**」では、イベントタイプに基づいてカスタム指標をマッピングできます。

![](https://docs.tealium.com/images/client-side-tags/dimeventtypes-1.png)

コンテンツグループの分類に使用するイベントタイプを選択します。


<blockquote>
Googleでは現在、**contentGroup1**から**contentGroup10**まで、最大10個のコンテンツグループを定義できます。詳細については、Googleの[コンテンツグループ](https://developers.google.com/analytics/devguides/collection/analyticsjs/field-reference#contentGroup)に関する記事を参照してください。
</blockquote>


## ディメンション

ディメンションはレポートの行に対応し、画面名別の画面ビュー数など、特定の値に基づいて指標を詳細に分析できます。

![](https://docs.tealium.com/images/client-side-tags/dimensions-1.png)

このパラメータでは、イベントタイプに基づいてカスタムディメンションをマッピングできます。「All Page Hits (set)」以外のオプションを選択すると、選択したイベントタイプにのみマッピングが適用されます。

マッピングが特定のイベントタイプに適用される場合、そのタイプはマッピング名に`{{event_type}}-dimension#`という形式で表示されます。

たとえば、トランザクションイベントのディメンション9のマッピングは、`transaction-dimension9`のようになります。

![](https://docs.tealium.com/images/client-side-tags/dimeventtypes-1.png)


<blockquote>
標準アカウントでは、**dimension1**から**dimension20**まで、最大20個のカスタムディメンションを使用できます。Premiumアカウントでは、**dimension21**から**dimension200**まで使用できます。<br>
この範囲のディメンションを構成するには、「Dimension」ドロップダウンリストで「**dimension21** **-****dimension200**」を選択し、ウィンドウ上部に表示されるフィールドをクリックして、目的のディメンション番号に編集します。
</blockquote>

## 指標

カスタム指標は、ページビューなど、特定のデータタイプの件数です。標準の指標値は整数です。GUA 構成で通貨に構成されている場合、この値には固定小数点数を使用できます。

![](https://docs.tealium.com/images/client-side-tags/metrics-1.png)

このパラメータを使用すると、イベントタイプに基づいてカスタム指標をマッピングできます。「All Page Hits (set)」以外のオプションを選択すると、選択したイベントタイプにのみマッピングが適用されます。

特定のイベントタイプにマッピングが適用される場合、そのタイプはマッピング名に `{{event_type}}-metric#` 形式で表示されます。

たとえば、ページビューイベントのみに指標 12 をマッピングする場合は、`pageview-metric12` のようになります。

標準アカウントでは、**metric1** から **metric20** まで、最大 20 個のカスタム指標を使用できます。Premium アカウントでは、**metric21** から **metric200** まで使用できます。この範囲の指標を構成するには、［Metric］ドロップダウンリストから **metric21 - metric200** を選択し、ウィンドウ上部に表示されるフィールドをクリックして、使用する指標の番号に変更します。

## 拡張 E コマース

このタブの送信先は、GUA の拡張 E コマース機能でサポートされる E コマースアクションに対応しています。GUA タグ構成でこの機能を有効にしている場合は、これらの送信先にマッピングする必要があります。Tealium の [E-Commerce Extension](https://docs.tealium.com/e-commerce-extension/) を構成すると、送信先へのマッピングが自動的に行われます。

拡張機能のマッピングを上書きする場合や、拡張機能でサポートされていないマッピングを追加する場合は、手動でマッピングする必要があります。

拡張 E コマースアクションのマッピングについて詳しくは、[GUA：拡張 E コマース](https://docs.tealium.com/google-universal-analytics-tag-enhanced-e-commerce/)の記事を参照してください。以下の E コマースアクションについて確認する場合は、この資料を使用してください。

* 拡張 E コマース：インプレッション／プロモーション
* 拡張 E コマース：イベント
