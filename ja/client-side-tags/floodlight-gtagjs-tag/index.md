## タグに関するヒント

* 開始する前にコンバージョン API を有効にしてください。詳細については、[Google：新しい Floodlight コンバージョン アクション用の Google タグを作成する](https://support.google.com/ds/answer/7562806)を参照してください。
* 次の項目について E コマース拡張機能をサポートします。
  * 注文 ID（`_corder`）  
  * 注文合計（`_ctotal`）  
  * 商品 ID のリスト（`_cprod`）  
  * 数量のリスト（`_cquan`）  
  * 価格のリスト（`_cprice`）
* マッピングは、次の目的で使用します。
  * イベントトリガーを構成する
  * 標準構成値を動的に上書きする
  * E コマース拡張機能の値を動的に上書きする
* カスタムイベントパラメータを渡すには、「DoubleClick Custom Parameters」にマッピングし、`myvar` をカスタム変数名に置き換えます。
* リストを使用するときにセッション ID が不要な場合は、SessionID を空白または空文字列に構成します。
* 詳細については、[Google：Floodlight のドキュメント](https://support.google.com/dcm/partner/answer/7568534)を参照してください。

## タグの構成

新しいタグを追加するには、タグマーケットプレイスに移動します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加するときに、次の構成を行います。

* **広告主 ID**
  * Floodlight アクティビティのソースとなる広告主 ID を、1 つまたはカンマ区切りのリストで指定します。例：`DC-123456789`
* **グループタグ文字列**
  * グループタグ文字列を、1 つまたはカンマ区切りのリストで指定します。
  * 広告主 ID の数と一致させる必要があります。
* **アクティビティタグ文字列**
  * アクティビティタグ文字列を、1 つまたはカンマ区切りのリストで指定します。
  * 広告主 ID の数と一致させる必要があります。
* **カウント方法**
  * カウント方法を、1 つまたはカンマ区切りのリストで指定します。
  * 広告主 ID の数と一致させる必要があります。
* **購入イベントの自動発火**
  * 注文 ID が存在する場合に購入イベントを発火します。
  * カウント方法が構成されていない場合は、トランザクションに構成されます。
* **カスタムスクリプトを許可**
  * Dynamic タグが、Web サイトのアクティビティをトラッキングするサードパーティツールと連携できるようにします。
* **グローバルオブジェクト**
  * イベントキューに使用されるグローバルオブジェクトの名前です。
  * 指定しない場合は、`gtag` が使用されます。
  * ほとんどの実装では必要ありません。
* **データレイヤー名**
  * デフォルトでは、グローバルサイトタグによって初期化および参照されるデータレイヤーの名前は `dataLayer` です。
  * プロジェクトで別の名前が必要な場合にのみ、データレイヤーの名前を変更してください。
* **クロストラッキングドメイン**
  * クロスドメイントラッキング（`setAllowLinker`）で使用するドメインのカンマ区切りリストです。
  * この値にはトップレベルドメインを指定します。例：`tealiumiq.com`

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

使用可能なカテゴリは次のとおりです。

### 標準

|構成| 説明|
|---| ---|
| 広告主 ID `advertiser_id` |  <ul><li>（必須）文字列／配列</li><li>1 つ以上の広告主 ID をカンマで区切ります。</li><li>例：`DC-12345678`</li><li>データはすべての ID に送信されます。</li><li>大文字と小文字が区別されます。</li></ul> |
| グループタグ文字列 `activity_group` |  <ul><li>（必須）文字列／配列</li><li>1 つ以上のグループタグ文字列をカンマで区切ります。</li><li>広告主 ID の数と一致させる必要があります。</li><li>大文字と小文字が区別されます。</li></ul> |
| アクティビティタグ文字列 `activity` |  <ul><li>（必須）文字列／配列</li><li>1 つ以上のアクティビティタグ文字列をカンマで区切ります。</li><li>広告主 ID の数と一致させる必要があります。</li><li>大文字と小文字が区別されます。</li></ul> |
| カウント方法 `counting_method` |  <ul><li>（必須）文字列／配列</li><li>1 つ以上のカウント方法の名前をカンマで区切ります。</li><li>広告主 ID の数と一致させる必要があります。</li><li>小文字に変換されます。</li></ul> |

| クロストラッキングドメイン `cross_track_domains` | <ul><li>クロスドメイントラッキングで使用するドメインのカンマ区切りリストです。</li></ul> |
| マッチ ID `dc_custom_params.match_id` | <ul><li>オフラインコンバージョンのアトリビューションのために Google と同期できる、広告主が作成した一意の ID（Floodlight 経由で渡されます）です。</li><li>この値では大文字と小文字が区別され、100 文字以内で、英字（`a-z` または `A-Z`）、数字（`0-9`）、アンダースコア（`_`）、ハイフン（`-`）、ピリオド（`.`）のみを使用できます。</li></ul> |
| 序数 `dc_custom_params.ord` | <ul><li>ブラウザーが広告画像やクリックスルー URL をキャッシュから読み込むのを防ぐ、キャッシュバスターとして機能する一意の乱数です。</li><li>[SA360 拡張コンバージョンコネクタ](https://docs.tealium.com/google-sa360-enhanced-conversions-connector/)を Floodlight タグと併用する場合、購入以外のコンバージョンには `tealium_random` をマッピングすることを推奨します。</li></ul>  |

### イベント

ページ上で特定のイベントをトリガーするには、これらの宛先にマッピングします。

イベントをトリガーするには、次の手順を実行します。

1. `tealium_event` 変数を選択します。
1. **+ マッピングを追加**をクリックします。
1. 左側のサイドバーで、**イベント**をクリックします。
1. **トリガー**フィールドに、マッピングする変数の値を入力します。
1. ドロップダウンリストから**コンバージョン**または**購入**を選択します。
1. **+ 追加**をクリックします。
    * さらに変数をマッピングするには、手順 4、5、6 を繰り返します。
1. **完了**をクリックします。  

指定された値がデータレイヤーで検出されると、イベントがトリガーされます。

|**宛先名**| **説明**|
|---| ---|
| コンバージョン `conversion` |  <ul><li>コンバージョンタイプのイベント送信をトリガーするためにマッピングします。</li><li>コンバージョンイベントはデフォルトでは送信されません。</li><li>このイベントには、`standard`、`unique`、または `per_session` カウント方法を使用します。</li></ul> |
| 購入 `purchase` |  <ul><li>購入タイプのイベント送信をトリガーするためにマッピングします。</li><li>注文 ID が存在する場合、購入イベントは自動的に送信されます。</li><li>このイベントには、`transactions` または `items_sold` カウント方法を使用します。</li></ul> |

### E コマース

Floodlight（`gtag.js`）タグでは E コマースが有効になっているため、デフォルトの E コマース拡張機能のマッピングが自動的に使用されます。拡張機能のマッピングを上書きする場合や、E コマース変数が拡張機能で提供されていない場合を除き、通常、このカテゴリで手動マッピングを行う必要はありません。

|**宛先名**| **説明**|
|---| ---|
| 注文 ID `order_id` |  <ul><li>`_corder` を上書きします。</li></ul> |
| 注文合計 `order_total` |  <ul><li>`_ctotal` を上書きします。</li></ul> |
| ID のリスト `product_id` |  <ul><li>配列</li><li>`_cprod` を上書きします。</li></ul> |
| 数量のリスト `product_quantity` |  <ul><li>配列</li><li>`_cquan` を上書きします。</li><li>単一の数値または値の配列による上書きを受け付けます。</li></ul> |
| 価格のリスト `product_unit_price` |  <ul><li>配列</li><li>`_cprice` を上書きします。</li></ul> |
