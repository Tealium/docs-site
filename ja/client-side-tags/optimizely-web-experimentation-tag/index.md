## タグに関するヒント

*   マッピングを使用すると、プロジェクトIDの標準構成値を上書きできます。

## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[about-tags](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際は、次の構成を構成します。

* **プロジェクトID**：プロジェクトIDは、`.js`ファイルへのパスに含まれる数値部分です（たとえば、`//cdn.optimizely.com/js/1234567.js`の`1234567`）。

## 読み込みルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。詳細については、[読み込みルールについて](https://docs.tealium.com/about-load-rules/)を参照してください。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

使用可能なカテゴリは次のとおりです。

### 標準

| 変数 | 型／値 | 説明 |
|:---------|:-----|:------------|
| `pid` | 文字列 | プロジェクトID。 |

### イベント固有のタグ

イベントをマッピングする方法については、[イベントマッピングの作成](https://docs.tealium.com/ja/tag-management/data-mappings/manage/#add-an-event-mapping)を参照してください。

| イベント | 説明 |
|:---------|:---------------------|
| `revenue`| セント単位の収益。 |
| `value`  | 値。 |
| `custom` | カスタム値。 |

### イベント固有のプロパティ

特定のイベントのプロパティをマッピングするには、まずプロパティを選択し、次にこのマッピングが行われるイベント名を入力します。カスタムプロパティを使用する場合は、**カスタム**オプションを選択し、表示されるフィールドに名前を入力します。

| プロパティ | 説明 |
|:------------|:-----------------------|
| カテゴリ | カテゴリ。 |
| サブカテゴリ | サブカテゴリ。 |
| テキスト | テキスト。 |
| URL | URL。 |
| SKU | SKU。 |
| カスタム | カスタムプロパティ。 |
