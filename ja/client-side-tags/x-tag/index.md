Xは、関心のある最新の話題、アイデア、意見、ニュースとユーザーをつなぐリアルタイム情報ネットワークです。

## タグに関するヒント
*   必要に応じて、コンテンツ変更拡張機能を使用して新しいdivを追加します
*   指定したDiv IDの内容はXボタンで上書きされます（ボタンは単なるリンクです）

## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際は、次の構成を行います。

* **ボタンタイプ**：`Share`（投稿）、`Follow`、`mention`、または`hashtag`。
* **言語**：ドロップダウンリストから言語を選択します。
* **Div ID**：Xリンク（ボタン）を追加するDiv IDです。divの内容が上書きされます。ページにリンクがすでに定義されている場合は、空白のままにします。
* **サイズ**：`Standard`または`Large`。
* **カウントの表示**：`None`、`Horizontal`、または`Vertical`。
* **フォロー**：Xアカウント（`@`は含めないでください）
* **リンクテキスト**：デフォルトのテキストを使用する場合は、空白のままにします。
* **投稿するメッセージ**：共有ボタンで送信するメッセージ
* **共有URL**：現在のURLを使用する場合は、空白のままにします。例：http://www.tealium.com
* **クエリ文字列の追加**：（任意）`/share?`の後にクエリ文字列として追加されます。例：http://x.com/share?utm_source=website の utm_source=website

## 読み込みルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。詳細については、[読み込みルールについて](https://docs.tealium.com/about-load-rules/)を参照してください。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

使用可能なカテゴリーは次のとおりです。

### 標準

| 変数 | 説明 |
|:---------|:------------|
| `type` |  | ボタンのタイプ |
| `divid` | Div ID |
| `lang` | 言語 |
| `size` | サイズ |
| `count` | カウントボックスの位置 |
| `follow` | フォロー |
| `text` | テキスト |
| `url` | URL |
| `post` | 投稿テキスト |
| `dnt` | パーソナライズのオプトアウト |

### 投稿

| 変数 | 説明 |
|:---------|:-----|:------------|
| `via` | スクリーンネーム |
| `related` | 関連アカウント |
| `counturl` | 長いURL |
| `hashtags` | ハッシュタグの文字列または配列 |

### フォロー

| 変数 | 説明 |
|:---------|:------------|
| `width` | 幅 |
| `align` | 配置 |
| `screen_name` | スクリーンネーム |
| `show-screen-name` | スクリーンネームを表示 |
| `show-count` | カウントボックスを表示 |
