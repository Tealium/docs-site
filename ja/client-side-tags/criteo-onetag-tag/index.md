## タグに関するヒント

* マッピングを使用して、次のことができます。
  * アカウントIDの値を上書きする
  * 必須パラメータとオプションパラメータの値を構成する
  * イベントをトリガーし、イベントパラメータの値を構成する

* サポートされているEコマース拡張パラメータ：
  * 注文ID（`_corder`）
  * 商品IDのリスト（`_cprod`）
  * 数量のリスト（`_cquan`）
  * 価格のリスト（`_cprice`）

## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際に、次の構成を構成します。

* **アカウントID**：（必須）複数のアカウントを指定する場合は、カンマ区切りのリストを使用します。
* **ページビューIDを生成**：コネクタでの重複排除のために、Criteoの各トラッキングイベントに対してページビューIDを自動生成します。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

使用可能なカテゴリーは次のとおりです。

### 標準

| タグの送信先          | 説明 |
|:----------------------|:-----|
| アカウントID          | <ul><li>Criteoのアカウント番号。</li><li>`account`を上書きします。</li></ul> |
| `email`               | <ul><li>文字列</li><li>顧客のメールアドレス。</li></ul> |
| `retailer_visitor_id` | <ul><li>文字列</li><li>小売業者の訪問ID</li><li>同じデバイス上の複数のセッションで一貫して使用される、一意の未認証ID。</li></ul> |
| `customer_id`         | <ul><li>文字列</li><li>顧客ID</li><li>ログインしているすべてのセッションで一貫して使用される、認証済みユーザーの識別子。</li><li>Criteoでは、このIDに氏名、メールアドレス、暗号化されていない電話番号などの個人を特定できる情報を含めないよう求めています。</li><li>顧客が不明な場合、またはサイトに一意のIDがない場合は空のままにします。</li><li>この変数は、Eコマース拡張の`_ccustid`変数とは関係ありません。</li></ul> |
| `site_type`           | <ul><li>サイトの種類。</li><li>サイトのバージョン。</li><li>次のいずれかの値を指定できます。<ul><li>`m` - サイトのモバイル版</li><li>`t` - サイトのタブレット版</li><li>`d`（デフォルト）- サイトのクラシック版。通常、ブラウザーがアクセスするサイトです。</li></ul></li></ul> |
| `hashed_email`        | <ul><li>ハッシュ化されたメールアドレス。</li><li>文字列</li><li>ハッシュ化された顧客のメールアドレス。</li></ul> |
| `zip_code`            | <ul><li>文字列</li><li>顧客の郵便番号。</li></ul> |

### Eコマース

| タグの送信先       | 説明 |
|:-------------------|:-----|
| `order_id`         | <ul><li>注文ID</li><li>一意のトランザクション識別子。</li><li>`_corder`を上書きします。</li></ul> |
| 商品ID             | <ul><li>配列</li><li>商品ID</li><li>商品配列内の各商品を識別する一意の識別子。</li><li>`_cprod`を上書きします。</li></ul> |
| 商品価格           | <ul><li>配列</li><li>商品配列内の各商品の単価。</li><li>`_cprice`を上書きします。</li></ul> |
| 商品数量           | <ul><li>配列</li><li>商品配列内の各商品の数量。</li><li>`_cquan`を上書きします。</li></ul> |

### イベント

ページ上でCriteoイベントをトリガーするには、変数をこれらの送信先にマッピングします。指定された値がデータレイヤーで見つかると、イベントがトリガーされます。

1. **イベント**ドロップダウンリストからイベントを選択します。
1. **トリガー**フィールドに、マッピングする変数の値を入力します。
1. **+ 追加**をクリックします。
1. さらにイベントをマッピングするには、手順1、2、3を繰り返します。

| イベント名         | 説明 |
|:-------------------|:-----|
| `viewHome`         | ホームページが表示された。 |
| `viewCategory`     | 商品カテゴリーが表示された。 |
| `viewSearchResult` | 検索結果が表示された。 |
| `viewItem`         | 商品が表示された。 |
| `viewBasket`       | カートが表示された。 |
| `viewList`         | 商品リストが表示された。 |
| `addToCart`        | 商品がカートに追加された。 |
| `trackTransaction` | トランザクションページでのアクティビティ。 |

### ロードルール

[ロードルール](https://docs.tealium.com/about-load-rules/)は、サイト上でCriteo OneTagのインスタンスを読み込むタイミングと場所を決定します。

Criteoイベントをトリガーする任意のページでタグを読み込むには、カスタムロードルールを作成します。たとえば、コンバージョンイベントをトラッキングする場合は、チェックアウトページまたは確認ページでこのタグを読み込みます。
### データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

Criteo OneTag の送信先変数は、**データマッピング**タブに組み込まれています。利用可能な送信先変数について、以下のセクションで説明します。

#### イベントでパラメーターを渡す

先ほどマッピングしたイベント送信先で追加データを渡すには、変数を対応するパラメーターにマッピングします。ユーザーが商品リストを絞り込んだ場合は、そのフィルターをパラメーターとして含めることができます。

マッピングされた Criteo イベントでパラメーターを渡すには、次の手順を実行します。

1. **イベント**ドロップダウンリストからイベントを選択します。
1. **パラメーター**ドロップダウンリストからパラメーターを選択します。
1. **+ 追加**をクリックします。

利用可能なパラメーターとフィルターは、次の表に示すように、選択したイベントによって異なります。

| イベント                              | パラメーター                                                                                                       | フィルター                                              |
|:--------------------------------------|:-------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------|
| `viewHome`                            | <ul><li>ページ ID</li><li>カスタム</li></ul>                                                                       | <ul><li>なし</li></ul>                                  |
| `viewCategory`<br> `viewSearchResult` | <ul><li>商品</li><li>キーワード</li><li>カテゴリー</li><li>ページ番号</li><li>ページ ID</li><li>カスタム</li></ul> | <ul><li>名前</li><li>演算子</li><li>値</li></ul>        |
| `viewItem`                            | <ul><li>商品</li><li>価格</li><li>在庫状況</li><li>カスタム</li></ul>                                             | <ul><li>なし</li></ul>                                  |
| `viewBasket`<br> `addToCart`          | <ul><li>ページ ID</li><li>カスタム</li></ul>                                                                       | <ul><li>ID</li><li>価格</li><li>数量</li></ul>          |
| `viewList`                            | <ul><li>商品</li><li>カスタム</li></ul>                                                                            | <ul><li>なし</li></ul>                                  |
| `trackTransaction`                    | <ul><li>トランザクション ID</li><li>カスタム</li></ul>                                                            | <ul><li>ID</li><li>価格</li><li>数量</li></ul>          |
