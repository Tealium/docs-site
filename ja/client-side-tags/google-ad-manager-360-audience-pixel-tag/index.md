サイトまたはモバイルアプリにオーディエンスピクセルタグを追加することで、広告を配信せずに Google Ad Manager 360 でファーストパーティのオーディエンスセグメントを構築できます。このピクセルタグは追加費用なしで使用でき、Ad Manager のインプレッション配信に対する料金も発生しません。また、このタグを使用すると、Google Marketing Platform の Cookie やモバイル広告 ID の代わりに、パブリッシャー提供 ID（PPID）をオーディエンスのセグメンテーションに使用できます。

## タグに関するヒント

* マッピングを使用して、タグ構成を上書きするか動的に構成します。
* パブリッシャー提供 ID（PPID）は、マッピングされた値が入力されている場合にのみ URL に追加してください。
* PPID 値の要件は次のとおりです。
    * 英数字（`[0-9 a-z A-Z]`）または UUID の 16 進数表記（`8-4-4-4-12`）。（ハイフンを使用できます）
    * 値を制限するには、次の正規表現を使用できます：`^([0-9a-zA-Z]{32,150})$|^([0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12})$`

## タグ構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際は、次の項目を構成します。

* **ネットワークコード**：パブリッシャーの Google Ad Manager ネットワーク識別子です。**管理者 > 全般構成**または Ad Manager の URL で確認できます。
* **セグメント ID**：セグメント識別子（`dc_seg`）です。

## 読み込みルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。読み込みルールの詳細については、[読み込みルール](https://docs.tealium.com/about-load-rules/)のドキュメントを参照してください。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

使用可能なカテゴリーは次のとおりです。

### 標準

| 変数 | 説明 |
| --- | --- |
| ネットワークコード（`network_code`） | 文字列 |
| セグメント ID（`segment_id`） | 文字列 |
| パブリッシャー提供 ID（`publisher_provided_id`） | 文字列 |
