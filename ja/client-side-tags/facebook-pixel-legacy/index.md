<blockquote>

</blockquote>


## 前提条件

* Facebook広告アカウント
* アップグレード済みのFacebookピクセル（または旧カスタムオーディエンスピクセル）
* コンバージョンピクセル（旧バージョン）

## タグの構成

最初にTealiumタグマーケットプレイスへ移動し、Facebookピクセルタグをプロファイルに追加します。詳細については、[タグの管理](https://docs.tealium.com/manage-tags/#add-a-tag)を参照してください。


<blockquote>
標準のPageViewおよびイベントトラッキングでは、ピクセルIDごとに1つのタグインスタンスを構成することを推奨します。
</blockquote>


タグを追加する際は、次の構成を行います。

| 構成 | 説明 |
|:------|:-----------------|
| タイトル | <ul><li>タグを識別するための一意の名前を入力します</li><li>このタグのインスタンスを複数追加する場合に重要です</li></ul> |
| FacebookピクセルID | <ul><li>FacebookピクセルID</li><li>コードスニペット内では長い数値列として表示されます</li><li>複数のピクセルIDをカンマ区切りのリストとして追加できます</li><li>例：`fbq('init', '12345678901234')`</li></ul> |
| コンバージョンピクセルID | <ul><li>旧コンバージョンピクセル（非推奨）をトラッキングする場合にのみ必要です</li><li>IDはコードスニペット内に次のように表示されます：<br> `fb_param.pixel_id = '12345';`<br> または <br>`fbq('track', '12345') OR fbq.push(['track', '12345', { }]);`</li></ul> |
| デフォルトのページビューを許可 | <ul><li>すべてのページでPageViewイベントをトリガーします<ul><li>`True`<ul><li>デフォルト値</li><li>コンバージョン以外のイベントに対するPageViewの自動トラッキングを有効にします</li></ul></li><li>`False`<ul><li>コンバージョンイベントをトラッキングする際のPageViewのトリガーを無効にします</li></ul></li></ul></li></ul> ヒント：このデフォルト動作を使用しない場合は、フラグ`disablePushState`を使用して無効にできます。このフラグを`true`に構成すると、履歴の状態が変更された際に`PageView`イベントが送信されなくなります。 |
| 送信するデフォルトイベント | <ul><li>デフォルトでトリガーするイベントを選択します</li><li>主にコンバージョンピクセルで使用します</li></ul> |
| 高度なマッチング | <ul><li>Facebookの高度なマッチングサービスを有効にします（[詳細](https://developers.facebook.com/docs/facebook-pixel/pixel-with-ads/conversion-tracking#advanced_match)）</li><li>これはデフォルトで有効ですが、高度なマッチングの利点を活用するにはデータマッピングを追加する必要があります。</li></ul> |
| アイテム数を自動計算 | <ul><li>チェックアウト時にアイテム数を自動的にカウントするかどうかを選択します</li><li>デフォルト値は`True`です</li></ul> |
| trackSingleを有効化 | <ul><li>Facebookイベントトラッキング呼び出しでtrackSingleおよびtrackSingleCustomを使用できるようにします。</li><li>複数のFacebookピクセルが読み込まれている場合、このタグで構成されたピクセルIDに対してのみトラッキング呼び出しをトリガーします。</li><li>デフォルト値は`True`です</li><li>例：`fbq('trackSingle', 'FB_PIXEL_ID', 'Purchase', customData )` <br> - または - <br> `fbq('trackSingleCustom', 'FB_PIXEL')`</li></ul> |
| trackCustomを有効化 | <ul><li>Facebookイベントトラッキング呼び出しで`trackCustom`を使用できるようにします。</li><li>カスタムイベント名と、必要に応じてJSONオブジェクトをパラメータとして指定し、`fbq('trackCustom')`ピクセル関数を呼び出すことでカスタムイベントをトラッキングできます。</li><li>例：割引を受けるためにプロモーションを共有した訪問をトラッキングする場合、次の例に示すカスタムイベントを使用できます：`fbq('trackCustom','ShareDiscount',{promotion:'share_discount_10%'});`</li></ul> |

## ロードルール

[ロードルール](https://docs.tealium.com/about-load-rules/)は、サイト上でこのタグのインスタンスをいつ、どこで読み込むかを決定します。

推奨されるロードルール：

* 標準のPageViewおよびイベントをトラッキングする場合は、デフォルトの**すべてのページ**ルールを使用します
* 旧コンバージョンピクセルをトラッキングする場合は、特定のコンバージョンページでタグを読み込むようにカスタムルール条件を適用します。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数へ送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

### **標準**

タグの構成構成を上書きするには、これらのマッピングを使用します。データレイヤーに基づいて値を動的に構成する場合に便利です。

| 宛先名 | 宛先変数 | 説明 |
|:----|:--|:-----------|
| FacebookピクセルID | `cust_pixel` | Facebookピクセルの数値識別子 |
| コンバージョンピクセルID | `conv_pixel` | 旧コンバージョンピクセルの数値識別子 |
| Initページビューを許可 [`true`/`false`] | `page_view` | 'init'トラッキング呼び出し |
| 発火するイベントのリスト | `evt_list` | 変数内でカンマ区切りの値または配列として指定されたイベント |
| trackSingleを有効化 [`true`/false] | `track_single` | <ul><li>イベントトラッキングで`trackSingle`および`trackSingleCustom`を使用できるようにします。</li><li>複数のFacebookピクセルが読み込まれている場合、イベントトラッキングをタグ管理のFacebookピクセル構成に追加されたピクセルIDのみに制限します。</li></ul> |
| trackCustomを有効化<br> [`true`/`false`] | `track_custom` | <ul><li>Facebookイベントトラッキング呼び出しで`trackCustom`を使用できるようにします。</li></ul> <ul><li>カスタムイベント名は文字列である必要があり、50文字を超えることはできません。</li></ul> |

この追加データを使用すると、より多くのコンバージョンを獲得できるように広告をレポートおよび最適化し、より大規模なリマーケティングオーディエンスを構築できます。チェックアウト、アカウントへのサインイン、または登録プロセス中にWebサイトから収集した顧客識別子を、ピクセルのパラメータとして渡すことができます。


<blockquote>
高度なマッチングでは、照合対象の項目がすでに認識されている場合を除き、入力された用語の大文字と小文字が正規化されます。
</blockquote>

|:------|:--|:------|

| 名 | `fn` | 名 |
| 姓 | `ln` | 姓 |
| 電話番号 | `ph` | 電話番号の数値 |
| 性別 | `ge` | `f`または`m` |
| 生年月日 | `db` | [`yyyymmdd`] |
| 市区町村 | `ct` | 市区町村 |

| 宛先名 | 宛先変数 | 説明 | Eコマース拡張機能の変数 |
|:---|:--|:---|:------|
| 注文ID | `order_id` | 最終注文に割り当てられた一意の識別子 | `_corder` |
| 小計 | `sub_total` | 最終注文の小計金額 | `_csubtotal` |
| 通貨 | `order_currency` | 支払いに使用された通貨 | `_ccurrency` |
| 製品IDのリスト | `product_id` | 製品配列内の各製品の一意の識別子 | `_cprod` |
| 製品名のリスト | `product_name` | 製品配列内の各製品の名前 | `_cprodname` |
| カテゴリのリスト | `product_category` | 製品配列内の各製品のカテゴリ | `_ccat` |
| 価格のリスト | `product_unit_price` | 製品配列内の各製品の単価 | `_cprice` |

| 変数  | 説明  |
|:---|:---------|

## **イベント**

ページ上で特定のイベントをトリガーするには、これらの宛先にマッピングします。イベントは、コンバージョンの追跡と、Facebook広告のターゲットに構成できるオーディエンスの構築に使用されます。


<blockquote>
購入イベントは、Eコマース拡張機能またはデータの直接マッピングを通じて注文IDの値を利用できる場合、自動的にトリガーされます。
</blockquote>


イベントをマッピングするには、次の手順を実行します。

1. **トリガー**フィールドに、選択したイベントに対応する宛先へマッピングする変数の値を入力します。  
たとえば、UDOに `event_name="order"` が存在するときに**購入**イベントをトリガーする場合は、`order` と入力します（現在、変数 `event_name` をマッピングしていることを前提とします）。
1. **イベント**リストで、使用するイベント（たとえば**購入**）を選択します。
1. **+ 追加**をクリックします。

### **カスタムイベント**

カスタムイベントの場合は、**カスタム**を選択し、カスタムイベントの名前を入力します。

次の例では、変数 `event_name` が `inbound_lead_event` と等しい場合に、カスタムイベント「InboundLead」がトリガーされます。

![](https://docs.tealium.com/images/client-side-tags/custom-event.png)

カスタムイベントを編集するには、宛先の入力フィールドをシングルクリックし、イベント名を直接編集します。値は `{VARIABLE_VALUE}:{DESTINATION_EVENT}` の形式で入力します。

* コロンの左側は、`inbound_lead_event` など、イベントをトリガーする変数値です。
* コロンの右側は、`InboundLead` などのカスタムイベント名です。

### **カスタムイベントデータ**

[イベントタブ](#events_tab)でマッピングしたカスタムイベントとともにカスタムパラメータを渡す場合は、これらの宛先にマッピングします。

カスタムイベントデータ変数をマッピングするには、次の手順を実行します。

1. **イベント名**フィールドに、**イベント**タブで指定したものと完全に同じカスタムイベント名を入力します。
1. **パラメータ**フィールドに、送信するパラメータの名前を入力します。
1. **+ 追加**をクリックします。

### 標準イベントの全一覧

| 宛先イベント    | イベントの説明    |
|:--|:------|

## パラメータ

以前にマッピングしたイベントとともに追加データを渡す場合は、これらの宛先にマッピングします。


<blockquote>
パラメータは、事前定義されたイベントでのみ使用されます。カスタムイベントとともにパラメータを渡す方法については、[カスタムイベントデータ](#custom-event-data)セクションを参照してください。
</blockquote>


事前定義されたイベントとともにパラメータを渡すには、次の手順を実行します。

1. **イベント**フィールドで、ドロップダウンリストからFacebookイベントを選択します。
1. **パラメータ**フィールドで、ドロップダウンリストからFacebookパラメータを選択します。
**カスタム**パラメータの場合は、パラメータを識別する名前を入力します。
1. **+ 追加**をクリックします。

### 事前定義されたパラメータの全一覧

|:---|:---|
| Value | イベントに関連付けられた値 |
| Currency  | Valueパラメータに関連付けられた通貨 |
| Content Name  | 製品またはページの名前 |
| Content Type  | イベントに関連付けられた製品またはページの種類 |
| Content IDs   | イベントに関連付けられた任意の識別子 |
| Content Category  | 製品またはページのカテゴリー |
| Number of Items   | チェックアウト時の商品数 |
| Search String | 検索操作で使用されたキーワードまたは語句 |
| Order ID  | 最終注文の一意の識別子 |
| Status    | CompleteRegistrationイベントのステータス |
| Custom    | 事前定義されたイベントとともに渡すカスタムパラメータ |

## ユースケース

このセクションでは、実際のシナリオを表すユースケースについて説明します。

### ユースケース：PageViewおよび標準／カスタムイベントのトラッキング

すべてのページでPageViewイベントが自動的に発火するように構成し、マッピングによってすべての非コンバージョンイベントをトリガーします。

お使いの環境でこのユースケースを構成するには、次の手順を実行します。

1. 次の構成を構成します。
    * **ピクセルID**：`FB_PIXEL_ID`
    * **デフォルトのページビューを許可：** `True`
    * **送信するデフォルトイベント**：`None`

1. すべてのページでタグを読み込みます（デフォルトルール）。
1. 変数 `event_name` を任意の非コンバージョンイベントにマッピングします。

### ユースケース：PageViewおよびコンバージョンイベントのトラッキング（非推奨）

コンバージョンイベントをトリガーするには、コンバージョンピクセルIDが必要です。PageViewおよび非コンバージョンイベントのトラッキングに使用しているものと同じタグインスタンスで実行できます。

お使いの環境でこのユースケースを構成するには、次の手順を実行します。

1. 次の構成を構成します。
    * **ピクセルID**：`FB_PIXEL_ID`
    * **コンバージョンピクセルID**：`CONVERSION_PIXEL_ID`
    * **デフォルトのページビューを許可**：`True`
    * **送信するデフォルトイベント**：`None`
1. すべてのページでタグを読み込みます（デフォルトルール）。
1. 変数 `event_name` を任意のコンバージョンイベントにマッピングします。

### ユースケース：従来のコンバージョンピクセルのみのトラッキング（非推奨）

コンバージョンピクセルは、別のタグインスタンスでトラッキングする必要があります。このタグインスタンスでは、ピクセルIDを空欄のままにし、ページビューの自動トラッキングを無効にします。特定のイベントをトラッキングしないため、データマッピングは必要ありません。

お使いの環境でこのユースケースを構成するには、次の手順を実行します。

1. 次の構成を構成します。
    * **コンバージョンピクセルID**：`CONVERSION_PIXEL_ID`
    * **デフォルトのページビューを許可**：`False`
    * **送信するデフォルトイベント**：`Conversion`

1. 特定のコンバージョンページでこのタグを読み込むように、カスタム読み込みルールを適用します。
### ユースケース：単一ページ上の複数ピクセル

以下のユースケースは、単一ページ上で複数のピクセルを使用できるシナリオを示しています。

* **イベントトラッキングの共有**
  * 複数のFacebookピクセルでページビューとイベントのトラッキングを共有する場合は、タグ構成のFacebook Pixel IDフィールドに、それらのピクセルIDをカンマ区切りのリストとして追加できます。
  * それぞれ固有のピクセルIDを持つ複数のFacebookピクセルでは、Enable trackSingle構成が`false`の場合、ページ上の他のFacebookピクセルとイベントトラッキングを共有することがあります。ただし、トラッキング動作に不整合が生じる可能性があるため、推奨されません。

* **個別のイベントトラッキング**
  * 単一ページに複数のFacebookピクセルを読み込み、そのページ上のすべてのピクセルにトラッキングイベントが記録されないようにする場合は、**Enable trackSingle**構成が`true`になっていることを確認してください。
  * この構成では、そのタグに追加されたピクセルIDに対してのみイベントトラッキングが実行されます。
  * Tag ManagementのFacebookピクセルを2018年3月より前に追加した場合、trackSingle機能を利用できないことがあります。
    * この場合は、[Facebookタグテンプレートを最新バージョンに更新してください](https://docs.tealium.com/about-templates/)。trackSingle構成のデフォルト値は`true`であることに注意してください。
    * この機能を上書きして無効にするには、`track_single`にマッピングし、値を`false`に構成する必要があります。

* **2018年3月より前のバージョン**
  * 2018年3月より後にタグを追加した場合、複数のFacebookピクセルを構成する際は、上記のユースケースを参照してください。
  * 旧バージョンのFacebookピクセルは、[単一ページに複数回読み込まれる](https://www.facebook.com/business/help/community/question/?id=10100525729830570)ことを想定して設計されていません。
  * Facebook JavaScriptライブラリは、ページ上で実行されるすべてのトラッキングに使用される`fbq`オブジェクトの単一インスタンスを初期化します（そのため、同じピクセルIDが再利用されます）。
  * それぞれ異なるピクセルIDを持つ複数のFacebookピクセルを単一ページで実行する必要があり、タグテンプレートを更新できない場合は、[Tealium Genericタグ](https://docs.tealium.com/tealium-generic-tag/)を使用してピクセルの`<noscript>`バージョンを実装することを推奨します。

#### シナリオ例

Facebookピクセルの`<noscript>`コード例：

```
`<noscript><br>
<img height="1" width="1" style="display:none"<br>
 src="https://www.facebook.com/tr?id={{FACEBOOK_PIXEL_ID}}&ev=PageView&noscript=1"<br>
/><br>
</noscript>`
```

このシナリオでは、非表示画像ピクセルのURLを次のように構成できます。

1. Tealium Genericタグを追加します。
1. **Title**を`Facebook Pixel (custom)`に構成します。
1. **Base URL**を`https://www.facebook.com/tr`に構成します。
1. **Query String**を`id={{FACEBOOK_PIXEL_ID}}&ev=PageView&noscript=1"`に構成します。  
![](https://docs.tealium.com/images/client-side-tags/facebook-tag-generic-tag-pixel.png)

1. 必要なロードルールとデータマッピングを構成します。
1. **Apply**をクリックします。
