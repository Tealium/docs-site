Crimtanは、世界12か国で事業を展開する、完全にプログラマティックかつデータドリブンなデジタルマーケティング企業です。Crimtanは消費者データを有益なインサイトやクリエイティブなディスプレイ広告キャンペーンへと変換し、企業のブランド認知度向上、新規顧客の獲得、顧客関係の維持・向上を支援します。

## タグに関するヒント

*   マッピングを使用すると、標準の構成値を動的に上書きできます。

## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳しくは、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際は、次の項目を構成します。

*   **コンテナID**
*   **サイレントモード**

## 読み込みルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。読み込みルールについて詳しくは、[読み込みルール](https://docs.tealium.com/about-load-rules/)のドキュメントを参照してください。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳しくは、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

利用可能なカテゴリーは次のとおりです。

### 標準

| 変数 | 説明 |
| --- | --- |
| コンテナID | (`containerId`) |
| サイレントモード | (`silentMode`) |
| 同意ステータス | (`consentStatus`) |
