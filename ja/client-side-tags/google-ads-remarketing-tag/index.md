## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際に、次の構成を構成します。

* **コンバージョン ID**
  * `google_conversion_id` の値を入力します。
  * この値はコードスニペットに記載されているほか、広告管理パネルでも確認できます。
* **ページタイプ**
  * このタグインスタンスを使用してコンバージョンをトラッキングするサイトのページタイプを選択します。
  * これは、コードスニペット内のカスタム `ecomm_pagetype` パラメータの値でもあります。
* **コンバージョン値**
  * コンバージョンアクションに割り当てる値を入力します。
  * 注文小計の値を使用する場合や、データマッピングツールボックスを使用して動的に構成する場合は、このフィールドを空白のままにできます。


<blockquote>
必要に応じて、上記のすべての構成をデータマッピングツールボックスで構成できます。
</blockquote>


## 読み込みルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。読み込みルールの詳細については、[読み込みルール](https://docs.tealium.com/about-load-rules/)のドキュメントを参照してください。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

### 標準

タグ構成の値を動的に送信（または上書き）するには、以下の宛先にマッピングします。

次の表に、標準変数の宛先名と説明を示します。

|宛先名|説明|
|---|---|
| コンバージョン ID `google_conversion_id` | <ul><li>`google_conversion_id` パラメータの値。</li></ul> |
|コンバージョンラベル| <ul><li>ここでデフォルトラベルを構成し、マッピングを使用してこの値を動的に上書きします。</li><li>複数のラベルのデータを送信するには、カンマ区切りのリストを使用します。</li><li>このリストでは、コンバージョン ID と同じ数のコンバージョンラベルを使用するか、すべてのコンバージョン ID に対して単一のラベルを使用できます。</li></ul> |
|コンバージョン値（value）| <ul><li>ここでデフォルト値を構成します。または、このフィールドを空白のままにして、E-Commerce 拡張機能の小計値を使用します。</li><li>マッピングを使用して、この値および E-Commerce 拡張機能の値を動的に上書きします。</li><li>コンバージョントラッキングを使用する場合、特定のタイプのすべてのコンバージョンアクションに同じ値（静的な値）を割り当てることも、コンバージョンアクションごとに異なる値（トランザクション固有の値を表す動的な値）を割り当てることもできます。</li><li>コンバージョンに値を割り当てると、広告によってもたらされた合計値をコンバージョンごとに区別し、価値の高いコンバージョンを特定して重点的に取り組むことができます。</li><li>このフィールドを空にすると、タグは E-Commerce の小計値（`_csubtotal`）を使用して自動入力します。</li></ul> |
|グローバルオブジェクト| <ul><li>イベントキューに使用するグローバルオブジェクトの名前。</li><li>指定しない場合は、"gtag" が使用されます。</li><li>ほとんどの実装では必要ありません。</li></ul> |
|データレイヤー名| <ul><li>デフォルトでは、グローバルサイトタグによって初期化および参照されるデータレイヤーの名前は **dataLayer** です。</li><li>プロジェクトで別の名前が必要な場合にのみ、データレイヤーの名前を変更してください。</li></ul> |
|リマーケティングを有効化| <ul><li>値は **オン** または **オフ** です。</li><li>デフォルト値は **オフ** です。</li><li>リマーケティングを有効にすると、このタグは E-Commerce 拡張機能からデータを自動的に取得し、Google 広告の「Retail」パラメータ（接頭辞 `ecomm_`）に構成します。</li><li>ツールボックスの「Retail」タブに直接マッピングすると、E-Commerce 拡張機能を通じて取得されたデータが上書きされます。</li></ul> |
| ページタイプ `pagetype` | <ul><li>コンバージョンをトラッキングするページのタイプ。</li><li>ここでデフォルトのページタイプを選択し、マッピングを使用してこの値を動的に上書きします。</li></ul> |
|クロストラッキングドメイン| <ul><li>クロスドメイントラッキング（setAllowLinker）で使用するドメインのカンマ区切りリスト。</li><li>"tealiumiq.com" などのトップレベルドメインを指定する必要があります。</li></ul> |
|カスタム| <ul><li>Google 広告で事前定義されていないカスタムパラメータを定義できます。</li><li>詳細については、以下の「詳細構成」を参照してください。</li></ul> |

### 小売

このタグには、[E-Commerce 拡張機能](https://docs.tealium.com/e-commerce-extension/)を構成することをお勧めします。これにより、必要な商品および注文の詳細が適切な広告パラメータに自動的に送信されます。また、マッピングを使用して拡張機能の変数を上書きすることもできます。

次の表に、小売変数の宛先名と説明を示します。

|宛先名|説明|
|---|---|
|`ecomm.prodid`| <ul><li>（必須）現在のページに表示されている商品の商品 ID です。ここで使用する ID は、フィード内の ID と一致する必要があります。</li><li>E-Commerce 拡張機能を使用している場合、このパラメータをマッピングすると `_cprod` が上書きされます。</li></ul> |
|`ecomm.totalvalue`| <ul><li>このパラメータは、商品、カート、購入の各ページタイプで使用します。商品ページでは単一商品の値を、カートページと購入ページでは1つ以上の商品の値の合計を含める必要があります。</li></ul> |
|`ecomm.category`| <ul><li>このパラメータには、現在表示されている商品ページまたはカテゴリページのカテゴリが含まれます。</li><li>E-Commerce 拡張機能を使用している場合、このパラメータは `_ccat` を上書きします。</li></ul> |
|`ecomm.pagetype`| <ul><li>推奨。</li><li>タグが配置されているページのタイプを示します。</li><li>次のいずれかの値を使用します。</li> <ul><li>`home`</li><li>`searchresults`</li><li>`category`</li><li>`product`</li><li>`cart`</li><li>`purchase`</li></ul> <ul><li>`other` 上記のページタイプに該当しない場合（「お問い合わせ」ページや「会社概要」ページなど）に使用します。</li></ul> <li>このパラメータを含める場合は、データソースを `ecomm.pagetype` にマッピングします。</li></ul> |
|`ecomm.value`| <ul><li>非推奨。</li><li>このパラメータは、このリマーケティングタグでは Google 広告によって使用されなくなりました。</li></ul> |
|`ecomm.quantity`| <ul><li>非推奨。</li><li>このパラメータは、このリマーケティングタグでは Google 広告によって使用されなくなりました。</li></ul> |
|`Custom`| <ul><li>Google 広告で事前定義されていないカスタムパラメータを定義できます。</li><li>詳細については、以下の「詳細構成」を参照してください。</li></ul> |

### 電話コンバージョンのオプション

電話コンバージョン トラッキングを使用すると、広告がウェブサイトからの電話問い合わせにどの程度効果的につながっているかを確認できます。ユーザーが広告をクリックしてウェブサイトにアクセスした場合、ウェブサイト通話コンバージョン トラッキングを使用すると、サイトからの通話を特定して測定できます。この種類のコンバージョン トラッキングでは、構成した最小通話時間を超えた通話がコンバージョンとして記録されます。

次の表では、電話コンバージョン オプション変数の宛先名と説明を示します。

|宛先名|説明|
|---|---|
|`phone_conversion_number`| <ul><li>（必須）次の例では、「REPLACE WITH VALUE」を会社の電話番号に置き換えます。</li><li>番号がページ上の番号と完全に一致し、必要な国コードが含まれていることを確認してください。</li></ul> |
|`phone_conversion_css_class`| <ul><li>（必須）CSS クラス名を入力します。</li><li>そのクラスのすべての要素の内容が、書式構成された電話番号に置き換えられます。</li></ul> |

|`dynx.itemid2`| <ul><li>（任意）このパラメータは、検索結果、オファー詳細、コンバージョン意向、およびコンバージョンの各ページタイプで表示されている商品のセカンダリ ID です。</li><li>この ID は、フィード内の値と一致する必要があります。</li></ul> |
|`dynx.totalvalue`| <ul><li>このパラメータは、コンバージョン意向のページタイプで使用し、訪問が購入した商品の合計金額を含める必要があります。</li><li>通貨記号は含めないでください。</li></ul> |
|`dynx.pagetype`| <ul><li>推奨。</li><li>タグが配置されているページのタイプを示します。次のいずれかの値を使用します。</li> <ul><li>`home`</li><li>`searchresults`</li><li>`offerdetail`</li><li>`conversionintent`</li><li>`conversion`</li><li>`cancel`</li></ul> <ul><li>`other` ページが上記のページタイプに該当しない場合に使用します。たとえば、「お問い合わせ」ページや「会社概要」ページなどです。</li></ul> <li>このパラメータを含める場合は、データソースを `dynx.pagetype` にマッピングしてください。</li></ul> |

### E コマース

このタグは、E コマース拡張機能からデータを自動的に取得し、次の小売パラメータに値を構成します。

* `_cprod` から `ecomm.prodid`
* `_ccat` から `ecomm.category`
* `_corder` が存在する場合、またはページタイプのいずれかに `purchase`、`conversion`、`cart`、`conversionintent` が含まれる場合、`_csubtotal` から `ecomm.totalvalue`

次の表では、E コマース変数の宛先名と説明を示します。

|宛先名|説明|
|---|---|
|注文 ID `_corder`| <ul><li>確定した注文に割り当てられた一意の識別子を表します。</li><li>E コマース パラメータを使用する利点の 1 つは、構成したどのビジネスタイプでも、タグが合計金額として `_csubtotal` を自動的に使用することです。</li><li>たとえば、小売ビジネスタイプでは、`ecomm.totalvalue` の値に `_csubtotal` が使用されます。</li></ul> |
|小計（`_csubtotal`）| <ul><li>確定した注文の小計金額を表します。</li><li>レポートされるどのビジネスタイプでも、`_csubtotal` 内の値が合計金額として自動的に使用されます。</li><li>たとえば、小売ビジネスタイプでは、`ecomm.totalvalue` の値に `_csubtotal` が使用されます。</li></ul> |
|商品 ID のリスト `_cprod`| <ul><li>商品配列内の各商品の一意の識別子を表します。</li><li>存在する場合、カスタム パラメータ ecomm.prodid に `_cprod` の内容が格納されます。</li></ul> |
|カテゴリのリスト `_ccat`| <ul><li>商品配列内の各商品のカテゴリを表します。</li><li>存在する場合、カスタム パラメータ ecomm.category に `_ccat` の内容が格納されます。</li></ul> |
|数量のリスト `_cquan`| <ul><li>商品配列内の各商品の数量を表します。</li><li>存在する場合、カスタム パラメータ ecomm.quantity に `_cquan` の内容が格納されます。</li></ul> |
|価格のリスト `_cprice`| <ul><li>商品配列内の各商品の単価を表します。</li><li>存在する場合、カスタム パラメータ ecomm.pvalue に `_cprice` の内容が格納されます。</li></ul> |
|通貨 `_ccurrency`| <ul><li>商品配列内の価格の通貨を表します。</li><li>存在する場合、カスタム パラメータ ecomm.currency に `_ccurrency` の内容が格納されます。</li></ul> |
|割引のリスト `product_discount`| <ul><li>商品配列内の各商品の単位あたりの割引額を表します。</li><li>存在する場合、カスタム パラメータ ecomm.discount に `_cdisc` の内容が格納されます。</li></ul> |
## タグの検証

[Google Tag Assistant](https://support.google.com/tagassistant/answer/2947093?hl=en&ref_topic=6000196)を使用するには、Chromeウェブブラウザが必要です。ブラウザがすでにコンピューターにインストールされている場合は、[Google Chromeストア](https://chrome.google.com/webstore/detail/tag-assistant-by-google/kejbdjndbnbjgmefkgdddjlbokphdefk)からGoogle Tag Assistantをインストールします。正常にインストールされたら、次の手順に従います。

1. サイトにアクセスし、対象ページを開きます。
1. ブラウザの右上にあるアシスタントアイコンをクリックします。
1. **Check this page now**をクリックします。  
![](https://docs.tealium.com/images/client-side-tags/test-page.png)

</blockquote>

 Tag Assistantを実行すると、構成された値を確認できます。次のユースケース例では、ホームページをテストしています。この例では、リクエストが「working」となっており、データソースが取得されていることを確認できます。また、`ecomm_pagetype`には`home`という値が構成されていますが、ホームページには該当する値がないため、`ecomm_value`と`ecomm_prodid`には値が構成されていません。
