Xピクセルを使用すると、X上の広告を表示したユーザーや広告に反応したユーザーが、その後に実行したアクションを追跡し、投資収益率を測定できます。Xのコンバージョントラッキングでは、最後にクリックされたリンクだけでなく、リンクのクリック、投稿、いいね、インプレッションなど、あらゆる種類の広告エンゲージメントによって促されたアクションをコンバージョンに関連付けることができます。

## タグに関するヒント

* マッピングを使用して、以下を行います。
  * イベントトリガーを構成する。
  * イベント固有のパラメータをイベントコードIDにマッピングする。
  * 標準構成値を動的に上書きする。
  * Eコマース拡張機能の値を動的に上書きする。
* 以下のEコマース拡張機能パラメータをサポートしています。
  * 注文ID
  * 注文合計
  * 通貨
  * 商品IDのリスト
  * 名前のリスト
  * カテゴリのリスト
  * 数量のリスト

## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加するときに、以下の構成を構成します。

* **ピクセルID**：XピクセルIDとも呼ばれます。Xピクセルのコードスニペットで確認できます。たとえば、次のスニペット内の`pid`です：`twq('config','pid');`。
* **イベントIDを生成**：Xの各トラッキングイベントのイベントIDを自動的に生成します。

## 読み込みルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。詳細については、[読み込みルールについて](https://docs.tealium.com/about-load-rules/)を参照してください。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

**イベント**カテゴリは、ピクセルをトリガーするイベントの構成に使用します。**イベント固有のパラメータ**カテゴリでは、トリガーイベントの発生時に他の変数をマッピングできます。

### ピクセルをトリガーするイベントの構成

以下の手順に従って、ピクセルをトリガーするイベントを構成します。

1. **データマッピング**をクリックします。
1. ピクセルをトリガーする変数を選択し、**+ 宛先を選択**をクリックします。
1. **カテゴリ**で、**イベント**を選択します。
1. **マッピングされた変数の値**フィールドに、ピクセルをトリガーする変数の値を入力します。
1. X広告アカウントからイベントのイベントIDをコピーし、**イベントコードID**フィールドに貼り付けます。  
たとえば、`tw-o6ou1-o9l96`です。
1. **+ 追加**をクリックします。
1. イベントの発生時に追加の変数をマッピングするには、以下の手順に従います。  
    1. 変数を選択し、**+ 宛先を選択**をクリックします。  
    1. **カテゴリ**で、**イベント固有のパラメータ**を選択します。  
    1. 変数のマッピング先となるパラメータを選択します。  
    1. X広告アカウントのイベントIDを**イベントコードID**フィールドに入力します。  
    1. **+ 追加**をクリックします。
1. **完了**をクリックします。
1. 保存してパブリッシュします。

### 標準パラメータ

| 変数 | データ型 | 説明 |
|---|---|---|
| `pixel_code` | 文字列 | XピクセルID |
| `email_address` | 文字列 | メールアドレス |
| `phone_number` | 文字列 | 電話番号 |
| `external_id` | 文字列 | 外部ID |
| `search_string` | 文字列 | Webサイトで検索されたテキスト |
| `description` | 文字列 | 追加情報の文字列による説明 |
| `twclid` | 文字列 | 任意のリクエストに含めることができるXクリックID |
| `status` | 文字列 | 登録またはサブスクリプションのステータス |

### Eコマース

| 変数 | データ型 | 説明 |
|---|---|---|
| `value` | 数値 | コンバージョンイベントの合計値。たとえば、購入の場合はトランザクションの金額です。`_ctotal`にマッピングされます。 |
| `currency` | 文字列 | ISO 4217コードで表される通貨。たとえば、USD、JPY、EURです。`_ccurrency`にマッピングされます。 |
| `conversion_id` | 文字列 | 特定の購入または注文に対する一意の識別子。`_corder`にマッピングされます。 |
| `content_type` | 配列 | 購入された商品のカテゴリ。`_ccat`にマッピングされます。 |
| `content_id` | 配列 | 商品カタログのユーザーは、商品のSKUを渡します。それ以外のユースケースでは、利用可能な場合は国際取引商品番号（GTIN）を渡し、利用できない場合は商品のSKUを渡します。`_csku`にマッピングされます。 |
| `content_name` | 配列 | 商品またはサービスの名前。`_cprodname`にマッピングされます。 |
| `content_price` | 配列 | 商品またはサービスの価格。`_cprice`にマッピングされます。 |
| `num_items` | 配列 | 購入された商品の数量。`_cquan`にマッピングされます。 |
| `content_group_id` | 文字列 | 商品バリエーションのグループに関連付けられたID。 |

### イベント固有のパラメータ

変数のマッピングについて詳しくは、[データマッピングの管理](https://docs.tealium.com/manage-data-mappings/)を参照してください。


| 変数 | 説明 |
|----------------------|---------------------------------------------|
| `pixel_code` | XピクセルID |
| `email_address` | メールアドレス |
| `phone_number` | 電話番号 |
| `external_id` | 外部ID |
| `search_string` | Webサイトで検索されたテキスト |
| `description` | 追加情報の文字列による説明 |
| `twclid` | 任意のリクエストに含めることができるXクリックID |
| `order_total` | 注文合計（`_ctotal`を上書き） |
| `order_currency` | 通貨（`_ccurrency`を上書き） |
| `order_id` | 注文ID（`_corder`を上書き） |
| `product_category` | カテゴリのリスト（`_ccat`を上書き） |
| `product_skus` | SKUのリスト（`_csku`を上書き） |
| `product_names` | 名前のリスト（`_cprodname`を上書き） |
| `product_unit_price` | 価格のリスト（`_cprice`を上書き） |
| `product_quantity` | 数量のリスト（`_cquan`を上書き） |
| `content_group_id` | 商品バリエーションのグループに関連付けられたID |
| `custom_parameter` | カスタムパラメータ |
