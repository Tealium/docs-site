## タグの構成

最初に、タグマーケットプレイスに移動し、CUBEDタグをプロファイルに追加します（[タグの追加](https://docs.tealium.com/manage-tags/#add-a-tag)を参照）。

タグを追加するときに、以下の構成を構成します。

* **アカウントトークン**：CUBEDから提供された一意のトークン
* **イベント詳細を送信**：イベントとともに商品の詳細を送信するかどうかを選択します。デフォルトは**false**です

## ロードルール

[ロードルール](https://docs.tealium.com/about-load-rules/)では、サイト上のどの場所で、どのタイミングにこのタグのインスタンスを読み込むかを指定します。

推奨されるロードルール：**すべてのページ**

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

CUBEDタグの宛先変数は、そのデータマッピングタブに組み込まれています。使用可能なカテゴリーは次のとおりです。

### 標準

| **宛先名**                                   | **説明**                                                                                                                                                    |
|:---------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| アカウントトークン（`account_token`）        | アカウントトークンを動的に上書きする場合は、これにマッピングします                                                                                          |
| 転送パラメーター（`forward_param`）          | マーケティングチャネルの分類に使用される、ランディングページURLパラメーターの配列                                                                           |
| 整数ラベル（`addIntLabel.custom`）           | CUBEDデータとともに送信する整数ラベル値。マッピング内のcustomをラベルのキー名に置き換えます                                                                  |
| 浮動小数点数ラベル（`addFloatLabel.custom`） | CUBEDデータとともに送信する浮動小数点数ラベル値。マッピング内のcustomをラベルのキー名に置き換えます                                                          |
| 文字列ラベル（`addStringLabel.custom`）      | CUBEDデータとともに送信する文字列ラベル値。マッピング内のcustomをラベルのキー名に置き換えます                                                                |
| 日時ラベル（`addDataTimeLabel.custom`）      | CUBEDデータとともに送信する日時ラベル値。マッピング内のcustomをラベルのキー名に置き換えます。日付はISO 8601形式である必要があります                           |
| ブール値ラベル（`addBoolLabel.custom`）      | CUBEDデータとともに送信するブール値ラベル。マッピング内のcustomをラベルのキー名に置き換えます                                                                |
| 同期ID（`sync_ids`）                         | デバイスやプラットフォームをまたいで顧客レコードを結合するための一意の識別子の配列                                                                           |

### Eコマース

CUBEDタグではEコマースが有効になっているため、デフォルトのEコマース拡張機能のマッピングが自動的に使用されます。通常、以下の場合を除き、このカテゴリーで手動マッピングを行う必要はありません。

* 拡張機能のマッピングを上書きする場合
* 必要なEコマース変数が拡張機能で提供されていない場合

| **宛先名**                                | **説明**                                                                                                                                                                     |
|:------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 注文ID／トランザクションID（`order_id`） | イベントに関連付けられた一意のID。マッピングされていない場合、この値はデフォルトでEコマース値の`_corder`になります                                                            |
| 注文合計／売上（`order_total`）           | イベントに関連付けられた売上。マッピングされていない場合、この値はデフォルトでEコマース値の`_ctotal`になります                                                               |
| 名前のリスト（`product_name`）            | イベントに関連付けられた商品名のリスト。イベント詳細を送信する場合は必須です。マッピングされていない場合、この値はデフォルトでEコマース値の`_cprodname`になります             |
| SKUのリスト（`product_sku`）              | イベントに関連付けられた商品のSKUのリスト。マッピングされていない場合、この値はデフォルトでEコマース値の`_csku`になります                                                     |
| 数量のリスト（`product_quantity`）        | イベントに関連付けられた商品の数量のリスト。マッピングされていない場合、この値はデフォルトでEコマース値の`_cquan`になります                                                   |
| 価格のリスト（`product_unit_price`）      | イベントに関連付けられた商品の価格のリスト。マッピングされていない場合、この値はデフォルトでEコマース値の`_cprice`になります                                                  |

### イベントデータ：カスタムイベント

| **宛先名**                              | **説明**                                                                                                       |
|:----------------------------------------|:---------------------------------------------------------------------------------------------------------------|
| イベント名（`event_name`）             | 送信するイベントの名前。CUBEDインターフェイスで事前構成したイベントのいずれかと一致する必要があります         |
| イベント詳細を送信（`send_details`）   | 商品固有のEコマース詳細をイベントとともに送信するかどうかを決定するブール値                                   |
