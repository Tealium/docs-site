## タグの仕様と要件

### 仕様

**名前**: Marin Software

**ベンダー**: Marin Software

**タイプ**: 検索

### 必須要件

**サービス**: Marin Softwareアカウント

**構成**:

* クライアントID

## タグの構成

### 1. タグの追加

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

### 2. タグの構成

1. **タイトル**:（必須）タグインスタンスを識別するための分かりやすいタイトルを入力します。
1. **クライアントID**:（必須）Marin Softwareから割り当てられたクライアントIDを入力します。

### 3. 読み込みルールの適用

[読み込みルール](https://docs.tealium.com/about-load-rules/)では、このタグのインスタンスをいつ、どこで読み込むかを指定します。デフォルトの読み込みルールは、**すべてのページで読み込む**ルールです。特定のページでこのタグを読み込むには、該当する条件を指定した新しい読み込みルールを作成します。

**ベストプラクティス**: 注文確認ページでのみこのタグを読み込む読み込みルールを作成します。また、注文確認ページでは、このタグのインスタンスを1つだけ読み込むようにしてください。同じページで複数のインスタンスを読み込むと、Marin Softwareタグが機能しなくなります。

### 4. マッピングの構成

[マッピング](https://docs.tealium.com/ja/tag-management/data-mappings/manage/)とは、データレイヤー内のデータソースから、ベンダータグの対応する宛先変数にデータを送信する簡単なプロセスです。

このタグを使用するには、[E-Commerce拡張機能](https://docs.tealium.com/e-commerce-extension/)を追加して構成する必要があります。以下のデータポイントは、E-Commerce拡張機能によってMarinへ自動的に送信されます。該当する場合、マッピングツールボックスでこれらの宛先へのマッピングを構成すると、E-Commerceのマッピングが上書きされます。

* **convType**
E-Commerce拡張機能の`_ctype`変数がこの宛先にマッピングされます。このデータポイントは、カートまたは注文のタイプを識別します。

* **orderid**
E-Commerce拡張機能の`_corder`変数がこの宛先にマッピングされます。このデータポイントは、注文IDを識別します。

* **category**
E-Commerce拡張機能の`_ccat`変数がこの宛先にマッピングされます。このデータポイントは、商品のカテゴリーを識別します。

* **currency**
E-Commerce拡張機能の`_ccurrency`変数がこの宛先にマッピングされます。このデータポイントは、注文の通貨タイプを識別します。

* **product**
E-Commerce拡張機能の`_cprod`変数がこの宛先にマッピングされます。この変数は、マッピングツールボックスに宛先として表示されません。ここにマッピングするには、マッピングフィールドに`product`を手動で入力する必要があります。これは、注文された商品のリストです。

* **quantity**
E-Commerce拡張機能の`_cquan`変数がこの宛先にマッピングされます。この変数は、マッピングツールボックスに宛先として表示されません。ここにマッピングするには、マッピングフィールドに`quantity`を手動で入力する必要があります。これは、注文された商品の数量です。

* **price**
E-Commerce拡張機能の`_cprice`変数がこの宛先にマッピングされます。この変数は、マッピングツールボックスに宛先として表示されません。ここにマッピングするには、マッピングフィールドに`price`を手動で入力する必要があります。これは、商品の価格リストです。

#### 非推奨のマッピング

* **Affiliation**
この宛先は、最新のMarin Softwareタグテンプレートでは非推奨です。この宛先にマッピングしても何も実行されません。
