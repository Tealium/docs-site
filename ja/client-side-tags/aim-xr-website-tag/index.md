IQVIAの事業部門であるDMDは、マーケターと主要な医療関係者を結び付け、効果的なエンゲージメントを実現することに注力するヘルスケアID企業です。同社のAudience Identity Manager Extended Reach（AIM XR）は、医療従事者（HCP）のID解決機能を提供します。このタグはDMDのAIM XRライブラリを読み込み、DMDタグが構成されたデバイスをスキャンします。識別されると、`AIM.ondetect()`によって関数内の処理が実行されます。

## タグに関するヒント

* マッピングを使用して、標準の構成値を上書きします。

## タグの構成

タグを追加する際に、以下の構成を構成します。

* **バージョン**：使用するタグのバージョンを選択します。
* **データレイヤー名**：デフォルトでは、グローバルサイトタグによって初期化および参照されるデータレイヤーの名前は`aimDataLayer`です。プロジェクトで別の名前が必要な場合にのみ、データレイヤーの名前を変更してください。
* **APIキー**：`AIM.init`関数で使用するAIM XR APIキーです。
* **AIMシグナルのトリガーイベント**：シグナルデータがサーバーサイドでTealium Collectに送信されます。
* **セッション情報イベント**：セッション情報（`id`、`timestamp`）をリクエストします。
* **POI IDタイプを含める**：POI IDタイプを含めるには、このオプションを有効にします。デフォルト値は`No`です。
* **TST IDタイプを含める**：TST IDタイプを含めるには、このオプションを有効にします。デフォルト値は`No`です。
* **UNK IDタイプを含める**：UNK IDタイプを含めるには、このオプションを有効にします。デフォルト値は`No`です。
* **HCPデータの送信先**：`utag.link`を介して高価値顧客（HCP）データを送信する対象として選択するタグの一意識別子（UID）を、カンマ区切りで指定します。デフォルトでは、すべてのタグが使用されます。
* **タグを最初のページビューでのみ発火させる**：パラメータを`Yes`に構成すると、`utag.link`はWebサイトの最初のページビューでのみ有効になります。パラメータを`No`に構成すると、`utag.link`はすべてのページで発火します。

## ロードルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。詳細については、[ロードルールについて](https://docs.tealium.com/about-load-rules/)を参照してください。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

使用可能なカテゴリは次のとおりです。

### 構成

| 変数 | タイプ／値 | 説明 |
|:---------|:-----|:------------|
| `apiKey` | 文字列 | APIキー。 |
| `triggerEvent` | ブール値 | AIMシグナルのトリガーイベント。 |
| `sessionInformation` | ブール値 | セッション情報。 |
| `poiSelected` | ブール値 | POI IDタイプを含める。 |
| `tstSelected` | ブール値 | TST IDタイプを含める。 |
| `unkSelected` | ブール値 | UNK IDタイプを含める。 |
| `selectedTagsToSend` | 文字列 | HCPデータの送信先。 |
| `firstPageOnly` | ブール値 | タグを最初のページビューでのみ発火させる。 |
