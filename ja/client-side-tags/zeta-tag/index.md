Zeta Marketing Platform（ZMP）は、24億件の固有データIDと業界をリードするAIを組み合わせ、期待を上回るパーソナライズされたオムニチャネル体験を生み出し、優れたマーケティング成果を実現します。Zetaはあらゆるチャネルで意図とエンゲージメントを予測できるため、消費者が求めるパーソナライズされた体験を提供し、ブランドのパフォーマンスを向上させることができます。


## タグに関するヒント

* データマッピングを使用すると、次のことができます。
    * 標準構成値を動的に上書きする
    * Eコマース拡張機能の値を動的に上書きする
* Eコマース拡張機能では、以下をサポートしています。
  * 注文ID
  * 注文合計
  * 注文店舗
  * 注文通貨
  * 注文プロモーションコード<
  * 商品IDのリスト
  * カテゴリーのリスト
  * 数量のリスト

## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際は、次の構成を行います。

* **クライアントハッシュキー**：クライアントハッシュキー
* **パートナーハッシュキー**：パートナーハッシュキー
* **タグ短縮名**：Zeta Marketing Platform内でタグの種類を定義するタグの短縮名
* **クライアントサイトID**：Zeta Marketing Platform内のアカウントを定義します

## 読み込みルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。読み込みルールの詳細については、[読み込みルール](https://docs.tealium.com/about-load-rules/)のドキュメントを参照してください。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。
利用可能なカテゴリーは次のとおりです。

### 標準パラメーター

| 変数 | 説明 |
| --- | --- |
| ベースURL (base\_url) | \[文字列\] |
| クライアントサイトID (zmpID) | \[文字列\] |
| クライアントハッシュキー (c) | \[文字列\] |
| パートナーハッシュキー (p) | \[文字列\] |
| タグ短縮名 (k) | \[文字列\] |
| 顧客ID (CustID) | \[文字列\] |
| キャッシュバスター (Cache\_buster) | \[文字列\] |
| MD5ハッシュ化メールアドレス (e\_md5) | \[文字列\] |
| SHAハッシュ化メールアドレス (e\_sha) | \[文字列\] |
| GDPR (gdpr) | \[数値\] |
| GDPR同意 (gdpr\_consent) | \[文字列\] |
