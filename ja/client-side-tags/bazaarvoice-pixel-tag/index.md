## タグの構成

最初にタグマーケットプレイスへ移動し、Bazaarvoice Pixelタグをプロファイルに追加します（[タグの追加](https://docs.tealium.com/manage-tags/#add-a-tag)を参照）。

タグを追加する際に、以下の構成を行います。

* クライアント名：Bazaarvoiceから提供されたクライアント名
* サイトID：サイトIDは、Bazaarvoice WorkbenchのConversations構成ハブ内にあるデプロイメントゾーンで確認できます。デフォルトは`main_site`
* 環境：BV Pixelを実装するデプロイ環境。ProductionまたはStagingから選択します
* ロケール：BV Pixelの実装で使用するロケール。デフォルトは`en_US`

## 読み込みルール

[読み込みルール](https://docs.tealium.com/about-load-rules/)では、サイト上でこのタグのインスタンスをいつ、どこに読み込むかを指定します。

推奨される読み込みルール：すべてのページ

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

Bazaarvoice Pixelタグの宛先変数は、タグの**データマッピング**タブに組み込まれています。使用可能なカテゴリは以下のとおりです。

### 標準

| **宛先名** | **説明** |
|:---|:---|
| クライアント名 | 構成値を動的に構成または上書きするために使用します |
| サイトID | 構成値を動的に構成または上書きするために使用します |
| 環境 | 構成値を動的に構成または上書きするために使用します |
| ロケール | 構成値を動的に構成または上書きするために使用します |
| RatingsAndReviewsの有無 | `bvProduct`の値を`RatingsAndReviews`に構成し、現在のデータを送信するには`true`に構成します |
| AskAndAnswerの有無 | `bvProduct`の値を`AskAndAnswer Present`に構成し、現在のデータを送信するには`true`に構成します |
| Curationsの有無 | `bvProduct`の値を`Curations Present`に構成し、現在のデータを送信するには`true`に構成します |

### Eコマース

Bazaarvoice PixelタグではEコマースが有効になっているため、デフォルトのEコマース拡張機能のマッピングが自動的に使用されます。通常、以下の場合を除き、このカテゴリで手動マッピングを行う必要はありません。

* 拡張機能のマッピングを上書きする場合
* 使用するEコマース変数が拡張機能で提供されていない場合

| **宛先名** | **説明** |
|:---|:---|
| 注文配達日（`order_delivery_date`） | この注文の配達予定日 |
| 注文ラベル（`label`） | このコンバージョンに関連付けられたラベル |
| 注文デプロイメントゾーン（`order_deployment_zone`） | この注文のデプロイメントゾーン |
| 注文ID（`order_id`） | この注文の一意の識別子。デフォルトのEコマース値`_corder`を上書きする場合に使用します |
| 注文合計（`order_total`） | この注文の総収益。デフォルトのEコマース値`_ctotal`を上書きする場合に使用します |
| 注文の配送料（`order_shipping`） | 注文に適用される配送料。デフォルトのEコマース値`_cship`を上書きする場合に使用します |
| 注文の税額（`order_tax`） | 注文に適用される税額。デフォルトのEコマース値`_ctax`を上書きする場合に使用します |
| 注文通貨（`order_currency`） | デフォルトのEコマース値`_ccurrency`を上書きする場合に使用します |
| 顧客の市区町村（`customer_city`） | デフォルトのEコマース値`_ccity`を上書きする場合に使用します |
| 顧客の州（`customer_state`） | デフォルトのEコマース値`_cstate`を上書きする場合に使用します |
| 顧客の国（`customer_country`） | デフォルトのEコマース値`_ccountry`を上書きする場合に使用します |
| 商品名のリスト（`product_name`） | デフォルトのEコマース値`_cprodname`を上書きする場合に使用します |
| SKUのリスト（`product_sku`） | 各明細項目の商品SKU。デフォルトのEコマース値`_csku`を上書きする場合に使用します |
| カテゴリのリスト（`product_category`） | 各明細項目の商品カテゴリ。デフォルトのEコマース値`_ccat`を上書きする場合に使用します |
| 数量のリスト（`product_quantity`） | 各明細項目の商品の数量。デフォルトのEコマース値`_cquan`を上書きする場合に使用します |
| 価格のリスト（`product_unit_price`） | 販売時点における各商品の価格。デフォルトのEコマース値`_cprice`を上書きする場合に使用します |
| 画像URLのリスト（`product_img_url`） | 各明細項目の画像URL。 |

### コンバージョン

| **宛先名** | **説明** |
|:---|:---|
| タイプ | このコンバージョンのタイプ（例：`Download`、`Compare`、`Coupon`） |
| ラベル | このコンバージョンに関連付けられたラベル |
| 値 | このコンバージョンに関連付けられた値。PIIデータは送信しないでください。 |

### EコマースおよびコンバージョンのPII

| **宛先名** | **説明** |
|:---|:---|
| メールアドレス | トランザクションまたはコンバージョンに関連付けられたユーザーのメールアドレス |
| ロケール | トランザクションまたはコンバージョンに関連付けられたユーザーのロケール。例：`en_US` |
| ニックネーム | トランザクションまたはコンバージョンに関連付けられたユーザーのニックネーム |
| 顧客／ユーザーID | デフォルトのEコマース値`_ccustid`を上書きする場合に使用します |
| 注文発送日 | この注文について、インタラクション後のメールを送信する特定の日付を定義します |
| 注文発送遅延 | この注文について、購入からインタラクション後のメールを送信するまでの日数を定義します |
| 発送日のリスト | 各明細項目の発送日 |
| 発送遅延のリスト | 各明細項目の発送遅延 |
### イベント

ページ上で特定のイベントをトリガーするには、以下の送信先にマッピングします。イベントをトリガーするには、次の手順を実行します。

1. ドロップダウンリストからイベントを選択します。事前定義されたリストから選択するか、カスタムイベントを作成できます。カスタムイベントの場合は、イベントを識別する名前を入力します。
1. **Trigger**フィールドに、マッピングする変数の値を入力します。
1. さらにイベントをマッピングするには、**+**ボタンをクリックし、手順1と2を繰り返します。
1. **Apply**をクリックします。

指定された値がデータレイヤーで見つかると、イベントがトリガーされます。

| **送信先名**                                | **説明**                                                                 |
|:--------------------------------------------|:-------------------------------------------------------------------------|
| ページビュー（`trackPageView`）             | ページの表示を追跡します                                                 |
| インプレッション（`trackImpression`）       | ページ上にユーザー生成コンテンツが存在することを追跡します               |
| CGC表示中（`trackInView`）                  | ページ上でユーザー生成コンテンツが表示されていることを追跡します         |
| CGC閲覧（`trackViewedCGC`）                 | ページ上でユーザー生成コンテンツが一定時間表示されていることを追跡します |
| 非コマースコンバージョン（`trackConversion`） | 非コマースのユーザーイベントが発生したことを追跡します                   |
| eコマーストランザクション（`trackTransaction`） | eコマースのユーザーイベントが発生したことを追跡します                    |
| 有用性への投票（`helpfulness\`）            | 有用性への投票を示すユーザーイベントが発生したことを追跡します           |
| プロフィール（`profile`）                   | プロフィールの表示を示すユーザーイベントが発生したことを追跡します       |
| 報告（`report`）                            | 報告ボタンのクリックに関するユーザーイベントを追跡します                 |
| もっと読む（`read_more`）                   | 「もっと読む」ボタンのクリックに関するユーザーイベントを追跡します       |
| フィルター（`filter`）                      | コンテンツの絞り込みに関するユーザーイベントが発生したことを追跡します   |
| リンク（`link`）                            | ユーザーがリンクをクリックしたことを追跡します                           |
| ページネーション（`paginate`）              | 別のページからのコンテンツのリクエストに関するユーザーイベントを追跡します |
| 質問（`ask`）                               | 質問に関するユーザーイベントが発生したことを追跡します                   |
| 統計（`statistics`）                        | ヒストグラムの表示に関するユーザーイベントが発生したことを追跡します     |
| 投稿内容の入力（`write`）                   | 投稿コントロールの操作を示すユーザーイベントが発生したことを追跡します   |
| 並べ替え（`sort`）                          | コンテンツの順序変更に関するユーザーイベントが発生したことを追跡します   |
| 検索（`search`）                            | ユーザー生成コンテンツの検索に関するユーザーイベントが発生したことを追跡します |
| 送信（`submit`）                            | ユーザー生成コンテンツの送信に関するユーザーイベントが発生したことを追跡します |
| カスタム                                    | カスタムイベントタイプを送信します                                       |

### イベントパラメーター

先にマッピングしたイベントとともに追加データを渡す場合は、以下の送信先にマッピングします。

注：パラメーターは事前定義されたイベントでのみ使用されます。カスタムイベントでパラメーターを渡す方法については、「カスタムイベントデータ」を参照してください。

事前定義されたイベントでパラメーターを渡すには、次の手順を実行します。

1. **Event** - ドロップダウンリストからBazaarVoiceイベントを選択します。
1. **Parameter** - ドロップダウンリストからBazaarVoiceパラメーターを選択します。
1. カスタムパラメーターの場合は、パラメーターを識別する名前を入力します。
1. **+Add**をクリックします。

| **送信先名**                               | **説明**                                                                                                               |
|:-------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------|
| コンテンツコンテナーID（`containerId`）    | ユーザー生成コンテンツを含むHTML要素のID                                                                               |
| ページタイプ（`type`）                     | 表示イベントの場合は、現在表示されているページのタイプ。機能イベントの場合、値がなければデフォルトで`Used`になります |
| 製品ID（`productId`）                      | 現在表示されている製品のID                                                                                             |
| カテゴリーID（`categoryId`）               | 現在表示されている製品またはページのカテゴリーID                                                                       |
| ルートカテゴリーID（`rootCategoryId`）     | 現在表示されている製品またはページのカテゴリーにおける最上位カテゴリーのID                                             |
| ブランド名（`brand`）                      | 現在表示されている製品またはページのブランド名                                                                         |
| HTMLコントロール名（`name`）               | HTMLコントロールの目的を説明するために使用されます                                                                      |
| レビュー数（`numReviews`）                 | 現在のページにあるレビューの総数                                                                                       |
| 質問数（`numQuestions`）                   | 現在のページにある質問の総数                                                                                           |
| 回答数（`numAnswers`）                     | 現在のページにある回答の総数                                                                                           |
| 平均評価（`avgRating`）                    | 現在のページにある製品の総合評価の平均                                                                                 |
| 推奨率（`percentRecommended`）             | 推奨数をレビュー総数で割った値                                                                                         |
| メタデータ詳細1（`detail1`）               | この値は、アクティブな「使用された機能」イベントに関する二次メタデータを取得することを目的とします                     |
| メタデータ詳細2（`detail2`）               | 該当する場合、この属性でHTMLコントロールに関する追加メタデータを取得します                                              |
| 最小ピクセル数（`minPixels`）              | 分析イベントを実行するために表示されている必要がある、ユーザー生成コンテンツのコンテナーの最小ピクセル数               |
| 最小時間（`minTime`）                      | 要素の一部（minPixels）が画面上に連続して表示される必要がある最小時間（ミリ秒単位）                                     |
| カスタム                                   | カスタム変数                                                                                                           |

### カスタムイベントデータ

「イベント」タブでマッピングしたカスタムイベントとともにカスタムパラメーターを渡す場合は、以下の送信先にマッピングします。

カスタムイベントデータ変数をマッピングするには、次の手順を実行します。

1. **Event Action** - 「イベント」タブで指定したとおりに、カスタムイベントの名前を正確に入力します。
1. **Parameter** - 送信するパラメーターの名前を入力します。
1. **+Add**をクリックします。
