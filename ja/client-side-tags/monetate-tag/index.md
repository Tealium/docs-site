## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際は、次の構成を行います。

* **ページ上でライブラリを読み込む**：Tealium経由ではなくページ上でMonetateを読み込む場合は、Trueに構成します
* **Monetate HTTPS URL**：Monetateのトラッキングコードスニペットに記載されているURL
* **すべてのページでaddCartRowsを使用する**：すべてのページタイプでカートデータを自動的に送信できるようにします

## ロードルール

[ロードルール](https://docs.tealium.com/about-load-rules/)では、サイト上でこのタグのインスタンスを読み込むタイミングと場所を決定します。

推奨されるロードルール：**すべてのページ**

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

Monetateタグの宛先変数は、そのタグの**データマッピング**タブに組み込まれています。利用可能なカテゴリは次のとおりです。

### 標準

| **宛先名** | **説明** |
|:---|:---|
| Monetate HTTPS URL（`base_url`） | Monetateのトラッキングコードスニペットに記載されているURL |
| ページタイプ（`page_type`） | ユーザーが表示しているページを識別するために使用します。値が構成されている場合は常に`setPageType`メソッドで使用されます。デフォルトのページタイプを上書きするために使用します |
| パンくずリスト（`breadcrumbs`） | ユーザーのナビゲーションにおけるパンくずリストを表す順序付き配列です。値が構成されている場合は常に`addBreadcrumbs`メソッドで使用されます。すべてのページタイプで送信されます |
| カスタム変数（`variable.custom`） | `setCustomVariables`とともに使用して、カスタム変数を構成します。目的の値を含む変数にマッピングし、マッピング名の`custom`を変数名に置き換えます。すべてのページタイプで送信されます |

### Eコマース

MonetateタグはEコマースに対応しているため、デフォルトのEコマース拡張機能のマッピングを自動的に使用します。通常、次の場合を除き、このカテゴリで手動マッピングを行う必要はありません。

* 拡張機能のマッピングを上書きする場合
* 使用するEコマース変数が拡張機能で提供されていない場合

| **宛先名** | **説明** |
|:---|:---|
| カスタム注文データ（`orderData.custom`） | 現在のページまたはトランザクションに関する注文データのカスタム項目です。目的の値を含む変数にマッピングし、マッピング名の`custom`を`_CUSTOM`形式の変数名に置き換えます。すべてのイベントで送信されます。特定のイベントのプロパティを構成するには、イベントパラメータを使用します。 |
| 注文割引（`order_discount`） | 現在のページまたはトランザクションの注文割引です。 |
| 注文ID（`order_id`） | 現在のトランザクションに固有の注文IDです。デフォルトのEコマース値`_corder`を上書きするために使用します |
| 小計（`order_subtotal`） | 現在のページまたはトランザクションの注文小計です。デフォルトのEコマース値`_csubtotal`を上書きするために使用します |
| 配送料（`order_shipping`） | 現在のページまたはトランザクションの注文配送料です。デフォルトのEコマース値`_cship`を上書きするために使用します |
| 税額（`order_tax`） | 現在のページまたはトランザクションの注文税額です。デフォルトのEコマース値`_ctax`を上書きするために使用します |
| 通貨（`order_currency`） | 現在のページまたはトランザクションの注文通貨です。デフォルトのEコマース値`_ccurrency`を上書きするために使用します |
| 商品IDのリスト（`product_id`） | 現在のページまたはトランザクションの商品IDのリストです。デフォルトのEコマース値`_cprod`を上書きするために使用します |
| SKUのリスト（`product_sku`） | 現在のページまたはトランザクションの商品SKUのリストです。デフォルトのEコマース値`_csku`を上書きするために使用します |
| カテゴリのリスト（`product_category`） | 商品カテゴリのリストです。値が構成されている場合は常に`addCategories`メソッドで使用されます。デフォルトのEコマース値`_ccat`を上書きするために使用します |
| 数量のリスト（`product_quantity`） | 現在のページまたはトランザクションの商品数量のリストです。デフォルトのEコマース値`_cquan`を上書きするために使用します |
| 価格のリスト（`product_unit_price`） | 現在のページまたはトランザクションの商品価格のリストです。デフォルトのEコマース値`_cprice`を上書きするために使用します |

### ページタイプ

ページ上で特定のページタイプイベントをトリガーするには、これらの送信先にマッピングします。イベントをトリガーするには、次の手順を実行します。

1. ドロップダウンリストからページタイプを選択します。ドロップダウンリストからカスタムページイベントを送信することもできます。カスタムページイベントの場合は、イベントを識別するための名前を入力します。
1. **トリガー**フィールドに、マッピングする変数の値を入力します。
1. さらにイベントをマッピングするには、**+** ボタンをクリックし、手順 1 と 2 を繰り返します。
1. **適用**をクリックします。

指定された値がデータレイヤーで検出されると、ページタイプイベントがトリガーされます。

| **送信先名**                        | **説明**                                                                                                                                                                                |
|:--------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ホームページ表示 (`home`)                     | 通常、サイト訪問が Web サイトにアクセスしたときに最初に到達するページです。                                                                                                    |
| ログインページ表示 (`login`)                   | ログインページは、チェックアウト処理中以外に、サイト訪問がサイト上の**ログイン**、**マイアカウント**、または**新規登録**をクリックしたときに表示されます。                                        |
| カテゴリページ表示 (`category`)             | 通常、このページには、サイト訪問を特定のインデックスページへ誘導するサムネイル画像やリンクが表示されます。                                                                                    |
| チェックアウトページ表示 (`checkout`)             | チェックアウトは、サイト訪問が注文を確定する直前に表示されるページです。                                                                                                     |
| 商品インデックスページ表示 (`product_index`)   | 通常、これらのページには商品のサムネイル、説明、価格が表示されます。                                                                                                |
| 検索 (`search`)                           | 通常、このページには、サイト訪問の特定のリクエストに関連するサムネイル画像やリンクが表示されます。                                                                                       |
| 商品詳細ページ表示 (`product_detail`) | インデックスページで商品画像またはリンクをクリックしたときに移動するページです。商品の詳細情報が表示され、商品をカートに追加できます。 |
| カート (`cart`)                               | サイト訪問が購入しようとしているすべての商品を表示するページです。                                                                                                          |
| 購入 (`purchase`)                       | 購入ページは、顧客が注文を完了した後に表示されるページです。                                                                                                                     |
| カスタムページイベント                           | サイト上で重要な事象が発生したことを示すための手段を提供します。イベント名はイベントキーとして Monetate に送信されます。                                                            |

### 旅行イベント

ページ上で特定のイベントをトリガーするには、これらの送信先にマッピングします。イベントをトリガーするには、次の手順を実行します。

1. ドロップダウンリストからイベントを選択します。定義済みのリストから選択するか、「カスタム」イベントを作成できます。「カスタム」イベントの場合は、イベントを識別するための名前を入力します。カスタムパラメーターまたはイベントを構成する前に、BloomReach の担当者にお問い合わせください。
1. **トリガー**フィールドに、マッピングする変数の値を入力します。
1. さらにイベントをマッピングするには、**+** ボタンをクリックし、手順 1 と 2 を繰り返します。
1. **適用**をクリックします。

指定された値がデータレイヤーで検出されると、イベントがトリガーされます。

| **送信先名**              | **説明**                                                                              |
|:----------------------------------|:---------------------------------------------------------------------------------------------|
| クルーズ検索 (`cruise_search`)   | ユーザーがクルーズを検索したときに、サイトから Monetate に情報を渡します。              |

| クルーズ予約 (`cruise_booking`) | ユーザーがクルーズの購入を完了したときに、サイトから Monetate に情報を渡します。 |
| ホテル検索 (`hotel_search`)     | ユーザーがホテルを検索したときに、サイトから Monetate に情報を渡します。               |
| ホテル確認 (`hotel_review`)     | ユーザーがホテルをカートに追加したときに、サイトから Monetate に情報を渡します。           |
| ホテル予約 (`hotel_booking`)   | ユーザーがホテルの購入を完了したときに、サイトから Monetate に情報を渡します。  |
| フライト検索 (`flight_search`)   | ユーザーがフライトを検索したときに、サイトから Monetate に情報を渡します。              |
| フライト確認 (`flight_review`)   | ユーザーがフライトをカートに追加したときに、サイトから Monetate に情報を渡します。          |
| フライト予約 (`flight_booking`) | ユーザーがフライトの購入を完了したときに、サイトから Monetate に情報を渡します。 |
