LINEで適切な顧客を見つけ、ビジネスの成長を促進しましょう。LINE広告では、キャンペーンの目的、ターゲティング、予算、測定をいつでも管理でき、より多くのオーディエンスにリーチして、より良い成果を達成できます。

## タグに関するヒント

* データマッピングを使用して、構成パラメータと標準パラメータを上書きできます。
* 次のEコマース拡張機能の値をサポートしています。
  * タイプ（`type`）
  * 商品ID（`itemIds`）
  * 価格（`price`）
  * 通貨（`currency`）
  * 注文ID（`orderId`）

## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際は、次の項目を構成します。

* **タグID**：（必須）LINEアカウントID。複数のLINEアカウントIDを構成する場合は、カンマで連結します。
* **顧客タイプ**：顧客のタイプ。構成すると、タグのカスタムパラメータに顧客タイプが追加されます。空の場合、デフォルト値は`lap`です。

## 読み込みルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。読み込みルールの詳細については、[読み込みルール](https://docs.tealium.com/about-load-rules/)のドキュメントを参照してください。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

使用可能なカテゴリーは次のとおりです。

### 構成パラメータ

| 変数                           | 説明       |
|:-------------------------------|:-----------|
| タグID（`tagId`）              | ［文字列］ |
| 顧客タイプ（`customerType`）   | ［文字列］ |

### 標準パラメータ

| 変数                                                   | 説明       |
|:-------------------------------------------------------|:-----------|
| タイプ（`type`）（`_ctype`を上書き）                   | ［文字列］ |
| 商品ID（`itemIds`）（`_cprod`を上書き）                | ［配列］   |
| カテゴリー（`category`）                               | ［文字列］ |
| キーワード（`keywords`）                               | ［文字列］ |
| 価格（`price`）（`_csubtotal`を上書き）                | ［文字列］ |
| 通貨（`currency`）（`order_currency`を上書き）         | ［文字列］ |
| 注文ID（`orderId`）（`_corder`を上書き）               | ［文字列］ |
| 開始日（`startDate`）                                  | ［文字列］ |
| 終了日（`endDate`）                                    | ［文字列］ |

### イベント

選択したイベントをトリガーするために必要な、マッピング済み変数の値を入力します。**CustomEvent**を選択した場合は、**カスタムイベント名**フィールドにイベント名を入力します。**CustomEvent**のマッピングを構成し、イベントがLINEに送信されるようになると、LINE広告プラットフォームアカウントでカスタムオーディエンスを作成する際に、指定した**CustomEvent**名を選択できます。

イベントをマッピングする方法については、[イベントマッピングの作成](https://docs.tealium.com/ja/tag-management/data-mappings/manage/)を参照してください。

| 変数               | 説明           |
|:-------------------|:---------------|
| ページビュー       | `PageView`     |
| カテゴリービュー   | `CategoryView` |
| 商品表示           | `ViewProduct`  |
| 検索               | `Search`       |
| カートに追加       | `AddToCart`    |
| 購入               | `Purchase`     |
| カスタムイベント   | `Custom`       |
