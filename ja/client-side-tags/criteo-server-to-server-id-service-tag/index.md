Criteoサーバー間識別サービスタグを使用すると、広告主はファーストパーティ識別子をCriteoに渡し、その識別子とCriteoユーザー識別子とのマッピングを構成できます。このファーストパーティ識別子は、その後Criteoコネクタの「イベントを送信（ファーストパーティID）」アクションで使用されます。

## タグに関するヒント

* マッピングを使用して、標準の構成値を上書きします。

## タグの構成

タグマーケットプレイスに移動し、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際は、次の構成を行います。

* **パートナーID**：CriteoのパートナーID。この値が不明な場合は、Criteoの担当者にお問い合わせください。
* **ファーストパーティ名**：広告主名。

## 読み込みルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。詳細については、[読み込みルールについて](https://docs.tealium.com/about-load-rules/)を参照してください。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

使用可能なカテゴリーは次のとおりです。

### 標準

| 変数 | 型 | 説明 |
|:---------|:-----|:------------|
| `p` | 文字列 | パートナーID。 |
| `first_party_id` | 文字列 | ファーストパーティ識別子。 |
| `first_party_domain` | 文字列 | ファーストパーティドメイン。 |
| `first_party_name` | 文字列 | ファーストパーティ名。 |
