RoktのSDKおよびAPIスイートの詳細については、[Roktインテグレーションガイド](https://docs.rokt.com/docs/developers/integration-guides/overview%20)を参照してください。

## タグに関するヒント

* マッピングを使用して、標準の構成値を上書きし、イベントをトリガーします。

## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際は、次の構成を構成します。

* **RoktアカウントID**：RoktアカウントID。
* **2段階メール**：肯定的なエンゲージメントがあった場合にのみメールアドレスを送信します。
* **サンドボックスを使用**：テスト用のサンドボックスアカウントにイベントを送信します。

## 読み込みルール

[読み込みルール](https://docs.tealium.com/about-load-rules/)は、サイト上でRoktタグのインスタンスをいつ、どこに読み込むかを決定します。

コンバージョンページでRoktタグを読み込むための読み込みルールを作成します。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳細については、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

利用可能なカテゴリーは次のとおりです。

### 標準

| 変数           | 型 | 説明   |
|:-------------------|:--------------|:--------------|
| `email`| 文字列 |メールアドレス                   |
| `firstname`| 文字列 |名          |
| `lastname`| 文字列 |姓            |
| `mobile`| 文字列 |携帯電話番号         |
| `zipcode`| 文字列 |ZIPコードまたは郵便番号    |
| `country`| 文字列 | ISO Alpha-2国コード    |
| `language`| 文字列 |言語             |
| `sandbox`   |ブール値 |テスト用のサンドボックスアカウントにイベントを送信する場合は、`True`を選択します。        |

### Eコマース

| 変数                        | 属性           | 型 | 説明                                             |
|:--------------------------------|:--------------------|:--------------------|:--------------------------------------------------------|
| 確認番号             | `confirmationref` | 数値 | この変数は`_corder`変数を上書きします。確認参照番号。      |
| 金額                          | `amount`          | 数値 |この変数は`_ctotal`変数を上書きします。取引金額。       |
| 通貨                        | `currency`        | 文字列 |この変数は`_ccurrency`変数を上書きします。3文字の通貨コード（例：`USD`）。     |
| 支払いタイプ                    | `paymenttype`    | 文字列| 支払いタイプ（例：`Credit Card`）。 |                                                         |
| ccbin                           | `ccbin`           | 文字列 | クレジットカードのBIN。                                                         |
| 商品価格のリスト             | `price`          | 数値の配列 | この配列は`_cprice`変数を上書きします。各商品の価格のリスト。   |
| 商品数量のリスト          | `quantity`        | 数値の配列 |この配列は`_cquan`変数を上書きします。各商品の価格のリスト。      |
| 商品の大カテゴリーのリスト   | `majorcat`        | 文字列の配列 |この配列は`_ccat`変数を上書きします。各商品のカテゴリーのリスト。       |
| 商品の大カテゴリーIDのリスト | `majorcatid`      | 文字列の配列 | 各商品の大カテゴリーIDのリスト。 |
| 商品の小カテゴリーのリスト   | `minorcat`        | 文字列の配列 | この配列は`_ccat2`変数を上書きします。各商品の小カテゴリーのリスト。      |
| 商品の小カテゴリーIDのリスト | `minorcatid`      | 文字列の配列 | 各商品の小カテゴリーIDのリスト。                                                |
| 商品名のリスト           | `productname`     | 文字列の配列 | この配列は`_cprodname`変数を上書きします。各商品の名前のリスト。|
| 商品SKUのリスト               | `sku`             | 文字列の配列 | この配列は`_csku`変数を上書きします。各商品のSKUのリスト。     |
