## タグに関するヒント

* 注文通貨のデフォルト値は、Eコマース拡張機能の値です。
* このタグでは、以下のEコマース拡張機能パラメータを使用します。
    * 注文ID
    * 注文通貨
    * 注文プロモーションコード
    * SKUのリスト
    * カテゴリのリスト
    * 数量のリスト
    * 価格のリスト
* カスタム商品パラメータのマッピングは配列にする必要があります。
* カスタムコンバージョンパラメータのマッピングは文字列にする必要があります。

## タグの構成

タグマーケットプレイスに移動して、新しいタグを追加します。詳しくは、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

タグを追加する際に、以下の構成を構成します。

* **キャンペーン**：デフォルトのキャンペーン。
* **Adref**：Partnerizeから提供される値。
* **顧客タイプ**：デフォルトの顧客タイプ。
* **国**：訪問または販売場所の国を表す2文字のISOコード。
* **デフォルト通貨**：コンバージョンが発生する通貨を表す3文字のISOコード。

## 読み込みルール

すべてのページでタグを読み込むか、タグを読み込む条件を構成します。読み込みルールについて詳しくは、[読み込みルール](https://docs.tealium.com/about-load-rules/)のドキュメントを参照してください。

## データマッピング

データマッピングは、データレイヤー変数の値をベンダータグ内の対応する変数に送信します。詳しくは、[データマッピングについて](https://docs.tealium.com/about-data-mappings/)を参照してください。

使用可能なカテゴリは以下のとおりです。

### 標準

| 変数 | 説明 |
| --- | --- |
| キャンペーン | (campaign) |
| 顧客タイプ | (customertype) |
| 顧客参照／顧客ID | (customer_id) |
| 国 | (country) |
| Adref | (adref) |
| カスタムコンバージョンパラメータ | (conversion.###) |
| カスタム商品パラメータ | (product.###) |

### Eコマース

| 変数 | 説明 |
| --- | --- |
| コンバージョン参照／注文ID | (order_id)（_corderを上書き） |
| 通貨 | (currency)（_ccurrencyを上書き） |
| バウチャー／プロモーションコード | (voucher)（_cpromoを上書き） |
| SKUのリスト (product_sku)（_cskuを上書き） | [配列] |
| カテゴリのリスト (product_category)（_ccatを上書き） | [配列] |
| 数量のリスト (product_quantity)（_cquanを上書き） | [配列] |
| 価格のリスト (product_unit_price)（_cpriceを上書き） | [配列] |
