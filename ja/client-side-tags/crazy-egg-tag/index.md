## タグの仕様と要件

### 仕様

**名前**: Crazy Egg

**ベンダー**: Crazy Egg

**タイプ**: その他：ヒートマッピング

##### 必須

**サービス**: Crazy Eggアカウント

**構成**:

* アカウント

## タグの構成

### タグの追加

タグマーケットプレイスに移動して、新しいタグを追加します。詳細については、[タグについて](https://docs.tealium.com/about-tags/)を参照してください。

### タグの構成

Crazy Eggタグの読み込みに必要なタグ構成は次のとおりです。

1. **タイトル**: （必須）タグを識別するための分かりやすいタイトルを入力します。
1. **アカウント**: （必須）Crazy Eggのアカウント番号を入力します。

**ヒント**: タグが可能な限り早く読み込まれるように、**タグ**タブのリスト上部付近にこのタグを配置してください。タグが早く読み込まれるほど、訪問のアクティビティを早く取得できます。

### 読み込みルールの適用

[読み込みルール](https://docs.tealium.com/about-load-rules/)では、このタグのインスタンスをいつ、どこで読み込むかを決定します。デフォルトの読み込みルールは、**すべてのページに表示**ルールです。特定のページでこのタグを読み込むには、該当する条件を指定した新しい読み込みルールを作成します。

**注**: ヒートマップを生成するページでのみこのタグが読み込まれるように、読み込みルールを作成することをお勧めします。

### マッピングの構成

[マッピング](https://docs.tealium.com/about-data-mappings/)とは、データレイヤー内のデータソースから、ベンダータグの対応する宛先変数へデータを送信するプロセスです。

Crazy Eggの場合、タグ管理ではマッピングがサポートされていません。デフォルトでは、Crazy Eggのライブラリがデータを取得し、Crazy Eggレポートに送信します。カスタムのUser Vars 1～5を使用するには、次のメソッド定義をコールバック関数に渡す必要があります。

```
window.CE_READY = function CE_READY() {
CE2.set(1, 'some string');
CE2.set(2, 'another value');
CE2.set(3, 'yet another value');
CE2.set(4, 'more');
CE2.set(5, 'and more');
}
```
