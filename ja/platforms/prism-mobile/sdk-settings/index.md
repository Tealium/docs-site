SDK構成を使用すると、アプリコードを変更することなく、TealiumからリモートでPrism SDKのランタイム動作を構成できます。構成はリモート構成ファイルを通じてSDKに配信され、次のリモート構成のリフレッシュまたはアプリの起動時に有効になります。

## SDK構成の追加

リモートでSDK構成を追加および構成するには：

1. モバイルプロファイルにログインし、**SDK構成**に移動します。
1. **構成の追加**を選択し、構成を調整します。
1. 変更を保存して公開します。

SDKは、次のリモート構成のリフレッシュまたは、`TealiumConfig`に構成URLが構成されている場合は次のアプリ起動時に新しい構成を取得します。

## 利用可能な構成

| 構成 | 説明 |
| :--- | :--- |
| `max_queue_size` | キューが保持できるディスパッチの最大数です。キューはFIFO順序を使用します：限界に達すると、最も古いディスパッチが新しいもののために削除されます。 |
| `queue_expiration` | キュー内のディスパッチの有効期限です。この時間内に送信されなかったディスパッチはキューから削除されます。 |
| `log_level` | SDKによって発行されるメッセージの最小ログレベルです。 |
| `remote_settings_refresh_interval` | リモート構成のリフレッシュ間の最小時間です。構成URLが`TealiumConfig`に提供されている場合、アプリの起動時にもリフレッシュが行われます。 |
| `visitor_identity_key` | SDKが自動的な訪問切り替えを実行するためにチェックするデータレイヤーキーです。 |
