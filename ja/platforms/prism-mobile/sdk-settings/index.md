SDK構成を使用すると、アプリのコードを変更することなく、TealiumからPrism SDKのランタイム動作をリモートで構成できます。構成はリモート構成ファイルを通じてSDKに配信され、次回のリモート構成の更新時またはアプリの起動時に有効になります。

## SDK構成の追加

SDK構成をリモートで追加および構成するには、次の手順を実行します。

1. モバイルプロファイルにログインし、**SDK構成**に移動します。
1. **構成を追加**を選択し、構成を調整します。
1. 変更を保存してパブリッシュします。

`TealiumConfig`に構成URLが構成されている場合、SDKは次回のリモート構成の更新時、または次回のアプリ起動時に新しい構成を取得します。

## 使用可能な構成

| 構成 | 説明 |
| :--- | :--- |
| `max_queue_size` | キューに保持できるディスパッチの最大数です。キューではFIFO順序が使用されます。上限に達すると、新しいディスパッチ用の領域を確保するため、最も古いディスパッチが削除されます。 |
| `expiration` | キュー内のディスパッチの有効期限です。この時間内に送信されなかったディスパッチは、キューから削除されます。 |
| `log_level` | SDKが出力するメッセージの最小ログレベルです。 |
| `refresh_interval` | リモート構成を更新する最小間隔です。`TealiumConfig`に構成URLが指定されている場合は、アプリを起動するたびにも更新されます。 |
| `session_timeout` | アクティビティがない状態が続いた後、現在のセッションが終了するまでの時間です。デフォルトは5分です。 |

訪問の自動切り替えに使用するデータレイヤーキー（`visitor_identity_key`）を構成するには、訪問IDモジュールを構成します。
