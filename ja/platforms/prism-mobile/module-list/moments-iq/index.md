Moments iQモジュールは、Tealium Prismで構築されたアプリのアプリ内調査と体験ウィジェットを構成するためのものです。このモジュールはTealium iQモバイルプロファイルで構成され、構成はホストされた構成ファイルまたはローカルにロードされたファイルを通じてPrism SDKに配信されます。単一のプロファイルに複数のMoments iQモジュールを追加でき、それぞれが異なる体験を構成します。

![](https://docs.tealium.com/images/platforms/prism-moments-iq-popup.png)

Moments iQモジュールは、Moments iQのモバイルプロファイル実装です。詳細については、[Moments iQについて](https://docs.tealium.com/about-moments-iq/)を参照してください。

## 要件

Moments iQモジュールには以下が必要です：

* Tealium Prismモバイルプロファイル

## 構成

Moments iQ体験を作成するには、モジュールマーケットプレイスにアクセスして**Moments iQ**モジュールを追加します。詳細については、[モジュール](https://docs.tealium.com/platforms/prism-mobile/modules/)を参照してください。

### 一般

| フィールド | 説明 |
| :--- | :--- |
| **モジュールID** | このモジュールの一意の識別子。プロファイル内のすべてのモジュールで一意でなければなりません。Moments iQモジュールが1つだけ構成されている場合、IDはモジュールタイプと一致することができます。 |
| **タイトル** | 体験の表示名。 |
| **ノート** | 内部ノート。ユーザーには表示されません。 |

### 体験コンテンツ

以下のテキストフィールドは[動的変数](#dynamic-variables)をサポートします。

| フィールド | 説明 |
| :--- | :--- |
| **ヘッダーテキスト** | 体験の上部に表示されるテキスト。 |
| **メインテキスト** | ヘッダーの下に表示されるテキスト。 |
| **質問テキスト** | ユーザーに尋ねる質問。 |
| **プライマリボタンテキスト** | プライマリボタンのラベル。デフォルト値は`Submit`です。 |

### 回答モデル

| フィールド | 説明 |
| :--- | :--- |
| **回答タイプ** | 回答の入力タイプ：**ラジオ**、**テキスト**、**チェックボックス**、または**ボタン**。 |
| **回答** | **ラジオ**、**チェックボックス**、および**ボタン**タイプの場合、回答ラベル。[動的変数](#dynamic-variables)をサポートします。 |
| **回答必須** | ユーザーが回答を選択または入力する前に必須とする場合は`true`に構成します。 |
| **回答ごとのリダイレクトURL** | 各個別の回答のためのオプションのリダイレクトURL。任意の回答に構成されている場合、デフォルトのリダイレクトURLは無視されます。 |
| **デフォルトリダイレクトURL** | プライマリボタンをクリックした後にユーザーをリダイレクトするURL。回答ごとのリダイレクトURLが構成されていない場合に使用されます。 |

### 体験の振る舞い

| フィールド | 説明 |
| :--- | :--- |
| **体験の抑制** | 体験が再び表示されるのを防ぎます。オプション：**Never**（デフォルト）、**After close**、**After submit**、**After close or submit**。 |
| **抑制有効期限ポリシー** | 抑制が持続する期間：**Forever**、**Session**、**Until app restart**、またはカスタム期間（秒）。 |
| **ロード追跡** | 体験がロードされたときに追跡コールを送信するように構成します。デフォルト：`false`。 |
| **追跡タイプ** | モーダルクローズと送信アクションの`tealium.track`コールで使用されるイベントタイプ：**Link**（デフォルト）または**View**。 |

### 画像構成

| フィールド | 説明 |
| :--- | :--- |
| **画像URL** | 外部ホストされた画像のURL。HTTPSを使用し、`.png`または`.jpg`ファイル拡張子を持つ必要があります。 |
| **画像配置** | 体験コンテンツに対する画像の配置：**Top**（デフォルト）、**Left**、または**Right**。 |

### スタイル構成

スタイル構成はCSSではなく、ネイティブモバイルレイアウトプロパティを使用します。すべての測定値はポイント（iOS）または密度非依存ピクセル（Android）で表されます。色値は16進コードです（例：`#0A1B36`）。透明度を含めるには、`#RRGGBBAA`形式を使用します（例：`#0A1B36AA`）。

すべてのフィールドはデフォルトで空です。UIはデフォルト値をキャプションとして表示します。

#### テキスト

これらの構成は体験内のすべてのテキストに全体的に適用されます。

| フィールド | 説明 | デフォルト |
| :--- | :--- | :--- |
| **フォントファミリー** | すべてのテキストのフォントファミリー。 | None |
| **フォントサイズ** | フォントサイズ。 | None |
| **フォントスタイル** | フォントスタイル（例：`normal`または`italic`）。 | None |
| **フォントウェイト** | フォントの太さ（例：`normal`または`bold`）。 | None |
| **テキストカラー** | テキストの色、16進コードとして。 | None |

#### 外部コンテナ

| フィールド | 説明 | デフォルト |
| :--- | :--- | :--- |
| **背景色** | 体験の背景色、16進コードとして。 | `#FCFCFC` |
| **マージン** | 最外部コンテナのマージン、1から4のスペースで区切られた数字（例：`1`、`4 6`、または`0 1 0 2`）。 | `0` |
| **ボーダーラディウス** | 最外部コンテナの角の半径。 | `0` |
| **ボーダーカラー** | ボーダーの色、16進コードとして。ボーダーラディウスが`0`より大きい場合にのみ表示されます。 | None |
| **幅** | 最外部コンテナの幅、数字または`auto`として。 | `300` |
| **高さ** | 最外部コンテナの高さ、数字または`auto`として。 | `auto` |

#### 質問コンテナ

| フィールド | 説明 | デフォルト |
| :--- | :--- | :--- |
| **マージン** | 質問コンテナのマージン、1から4のスペースで区切られた数字。 | `0` |
| **テキストアライン** | 質問テキストのアラインメント：`start`、`center`、または`end`。 | `start` |

#### 回答コンテナ

| フィールド | 説明 | デフォルト |
| :--- | :--- | :--- |
| **マージン** | 回答コンテナのマージン、1から4のスペースで区切られた数字。 | `0` |
| **テキストアライン** | 回答テキストのアラインメント：`start`、`center`、または`end`。 | `start` |
| **方向** | 回答のレイアウト方向：`column`（垂直）または`row`（水平）。 | `column` |
| **アイテムのアラインメント** | コンテナ内の回答のアラインメント：`start`、`center`、または`end`。 | `start` |

#### ボタンスタイル

| フィールド | 説明 | デフォルト |
| :--- | :--- | :--- |
| **プライマリボタンの背景色** | プライマリボタンの背景色、16進コードとして。 | `#1B1B1B` |
| **セカンダリボタンの背景色** | セカンダリボタンの背景色、16進コードとして。**回答タイプ**が**ボタン**に構成されている場合に適用されます。 | `#FFFFFF` |

## 動的変数

**ヘッダーテキスト**、**メインテキスト**、**質問テキスト**、および**回答**フィールドで動的なテキストを作成するために変数を使用できます。変数名を二重中括弧で囲みます。

たとえば、モバイルデータレイヤーイベントに`customer_name`が含まれている場合、Prism SDKは実行時に`{{customer_name}}`を値に置き換えます。

データが利用できない場合に表示されるフォールバック値を構成するには、パイプ文字を2つ続けてフォールバック値を追加します。たとえば：`{{customer_name || Guest}}`。

## トラッキングデータ

ユーザーがMoments iQ体験と対話すると、Prism SDKはデータレイヤーに次の変数を追加します：

| 変数 | 説明 |
| :--- | :--- |
| `tealium_event` | 相互作用のタイプ：`momentsiq_submit`または`momentsiq_close`。 |
| `momentsiq_id` | このモジュールの一意のID。 |
| `momentsiq_question1` | ユーザーがプライマリボタンをクリックした場合の質問テキスト。 |
| `momentsiq_question1_type` | ユーザーがプライマリボタンをクリックした場合の質問タイプ。 |
| `momentsiq_answer1` | ユーザーがプライマリボタンをクリックした場合の選択または入力された回答。 |
| `momentsiq_questions_answered` | ユーザーがプライマリボタンをクリックしなかった場合の回答された質問。 |

イベントの例については、[Moments iQ：イベント](https://docs.tealium.com/about-moments-iq/#events)を参照してください。

## ルールとイベント

ルールとイベントを使用して、体験が表示されるタイミングを制御します。データの衝突を避けるために、一度に1つのMoments iQ体験のみがロードされるようにルールを構成します。

詳細については、[ルール](https://docs.tealium.com/rules/)を参照してください。

## サーバーサイド統合

サーバーサイドアクティベーションでMoments iQを統合するには、Tealium Collectモジュールを通じてデータを収集し、モバイルプロファイルをサーバーサイドプロファイルにリンクします。

詳細については、[Moments iQの管理：サーバーサイド統合](https://docs.tealium.com/manage-moments-iq/#server-side-integration)を参照してください。
## モバイルプロファイルで利用できないWeb機能

以下のMoments iQ機能はWebプロファイルで利用可能ですが、モバイルプロファイルでは利用できません：

* CSSスタイルシートエディター
* CSSセレクターベースの配置
* DOM挿入位置の制御（before, after, begin, end, replace）
* ブラウザモーダル配置制御
* カスタムスクリプトソース
* 新しいタブでのオープンリダイレクト
