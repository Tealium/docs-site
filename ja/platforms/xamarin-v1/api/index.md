## Android/iOS向けAPI

以下のリソースには、AndroidおよびiOS向けTealium APIリファレンスへのリンクがあります。Xamarinでモバイルアプリケーションを構築する場合は、TealiumのiOSおよびAndroidライブラリへのバインディングを使用してください。

*   [Tealium for iOS](https://docs.tealium.com/ja/platforms/ios-objective-c/api/)
*   [Tealium for Android](https://docs.tealium.com/ja/platforms/android-java/api)

## C\#向けAPI

また、Tealium Customer Data Hubサービス（Customer Data Platform（CDP）、Event Streaming、DataAccess）のみを使用する場合は、[Tealium for C#](https://docs.tealium.com/ja/platforms/csharp/api)ライブラリをXamarinプロジェクトのネイティブコードとして使用できます。
