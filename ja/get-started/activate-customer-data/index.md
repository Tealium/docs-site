アクティベーションは、イベントデータとプロファイルデータをアクションにつなげます。カートが放棄されるとリマインダーメールを送信し、訪問が購入すると広告キャンペーンによるターゲティングを停止し、再訪問には前回閲覧した商品をホームページに表示できます。

## コネクタと関数を使用してデータをプッシュする

コネクタは、メール、広告、分析、CRMプラットフォームなど、すでに使用しているベンダーにデータをリアルタイムで送信します。ベンダーごとに個別のデータパイプラインを構築して保守する代わりに、Tealiumで各統合を構成します。

各コネクタはアクションを実行します。アクションでは、ベンダーに送信するデータとそのタイミングを決定します。

* **オーディエンスアクション**：訪問がオーディエンスに参加または離脱したとき、あるいは訪問の開始時または終了時にデータを送信します。オーディエンスアクションを使用すると、カートを放棄した訪問を一連のメール配信に追加したり、購入者がコンバージョンに至った直後に広告キャンペーンから除外したりできます。
* **イベントアクション**：プロファイル履歴を待たずに、イベントフィード内のすべてのイベントについてデータを送信します。イベントアクションを使用すると、ページビューを分析ベンダーに送信したり、注文情報をCRMに送信したりできます。

コネクタがユースケースに適合しない場合は、関数で独自のJavaScriptコードを実行できます。これにより、外部APIの呼び出しなど、JavaScriptでサポートされる任意のロジックを適用できます。データ変換関数は、Tealiumが処理する前に受信イベントを整形します。イベント関数と訪問関数は処理後に実行されるため、処理済みのイベントまたはプロファイルに対してアクションを実行できます。

## リクエストに応じてデータを取得する

訪問が到着した時点でデータを必要とするエクスペリエンスもあります。再訪問がホームページを開いた場合、ページの読み込みが完了する前にその訪問の関心情報が必要です。Tealiumはリクエストに応じて訪問の現在のオーディエンス、バッジ、属性を返すため、Webサイト、アプリ、サービスのワークフローでエクスペリエンスをリアルタイムにパーソナライズできます。

Context APIは訪問プロファイル全体ではなく、各エクスペリエンスに必要なデータだけを返します。AIエージェントも、Context API MCPサーバーを通じて同じように使用します。詳細については、[TealiumでAIを使用する](https://docs.tealium.com/use-ai-with-tealium/)を参照してください。


![](https://docs.tealium.com/images/icons/icon-moments-api.svg)
