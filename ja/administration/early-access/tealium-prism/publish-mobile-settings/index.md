## モバイル構成パブリッシャーについて

モバイル構成パブリッシャーは、Tealium Tools ブラウザー拡張機能に含まれるツールで、Prism モバイルプロファイルの構成を Tealium CDN に公開します。

このツールは、早期アクセス期間中の一時的なソリューションです。モバイル構成の公開機能が一般提供（GA）されると、このツールは廃止されます。アプリを変更する必要はありません。

## 要件

この機能を使用するには、以下が必要です。

* Chrome または Edge の [Tealium Tools ブラウザー拡張機能](https://docs.tealium.com/tealium-tools-browser-extension/)。アカウントでモバイル構成パブリッシャーが有効になっている必要があります。
* 公開する Tealium アカウントおよびプロファイルへのアクセス権。
* 1 つ以上のモジュールが構成された Tealium モバイルプロファイル（早期アクセス）。
* このアカウントおよびプロファイルの [Hosted Data Layer API](https://docs.tealium.com/about-hosted-data-layer-api/) へのアクセス権を持つ [Tealium API キー](https://docs.tealium.com/api-keys/)。

## 仕組み

このツールは、現在開いているモバイルプロファイルの構成を読み取り、Prism 構成ファイルとして公開します。

公開されたファイルは、SDK 構成のリモート階層になります。アプリ内のプログラムによる（強制）構成は、この構成を上書きします。詳細については、[高度な構成](https://docs.tealium.com/about-prism-mobile/#advanced-configuration)を参照してください。

### 環境

このツールは、環境ごとに個別のファイルを公開します。カスタム環境はサポートされていません。公開先は Dev、QA、Prod のみです。

| 環境 | デフォルトの構成ファイル名 | URL |
| :--- | :--- | :--- |
| Dev | `mobile_settings_dev` | `https://tags.tiqcdn.com/dle/<account>/<profile>/mobile_settings_dev.json` |
| QA | `mobile_settings_qa` | `https://tags.tiqcdn.com/dle/<account>/<profile>/mobile_settings_qa.json` |
| Prod | `mobile_settings_prod` | `https://tags.tiqcdn.com/dle/<account>/<profile>/mobile_settings_prod.json` |

各環境のファイル URL を、アプリの構成 URL として指定します。iOS および Android では `TealiumConfig` を使用し、React Native では `Tealium.create()` の `settingsUrl` 引数を使用します。SDK は、アカウント、プロファイル、または環境から URL を導出しません。アプリ内の URL は、公開されたファイルと完全に一致する必要があります。詳細については、[クイックスタートガイド](https://docs.tealium.com/quick-start-prism/)を参照してください。

### カスタム構成ファイル名

別のファイル名で公開するには、環境の **Settings file name** を変更します。たとえば、アプリがすでに `settings.json` を取得している場合は、`settings` と入力します。この名前は、その環境の CDN URL、**Last published** の確認、公開、およびダウンロードされるファイルに適用されます。

ツールは、末尾の `.json` と、英字、数字、`_`、`.`、`-` 以外の文字を削除します。名前を空にするとデフォルトに戻ります。デフォルトに戻すには、**Reset** をクリックします。カスタム名は、現在のアカウントおよびプロファイル用としてブラウザーに保存されます。

### 初期構成ファイルをアプリにバンドルする

**Download JSON** をクリックして構成ファイルを生成し、ローカル構成ファイルとしてアプリにバンドルします。ファイルをバンドルすると、接続が制限されている場合でも、初回起動時に SDK が完全に構成されます。SDK がリモート構成を取得した後は、リモート構成がバンドルされたファイルを上書きします。

ローカル構成ファイルの指定方法については、[クイックスタートガイド](https://docs.tealium.com/quick-start-prism/)を参照してください。

### API キー

このツールは、API キーを短期間有効なベアラートークンと交換し、そのトークンを使用して公開します。API キー自体が Hosted Data Layer API に送信されることはありません。

デフォルトでは、現在のブラウザーセッション中のみキーが保持されます。**Remember API key across sessions** を選択すると、キーがブラウザーのローカル保存に保存されます。保存されたキーは暗号化されません。このオプションは、信頼できるデバイスでのみ選択してください。保存されたキーはマスクされ、**Change** および **Clear** アクションが表示されます。**Clear** を実行すると、保存されたキーとキャッシュされたトークンが削除されます。

### 監査警告

公開前に、SDK が受け入れるものの、エラーをログに記録せず無視する構成が生成ファイルに含まれていないか、ツールが確認します。検出結果はツールの上部に表示されます。検出結果が公開を妨げることはありませんが、Tealium で修正するまで、該当する構成はアプリで機能しません。

| 検出結果 | SDK への影響 | 対処方法 |
| :--- | :--- | :--- |
| リスト構成に、単純な値ではなく選択オブジェクトが含まれている | SDK はすべての値を破棄します。何も選択されていない場合と同様に動作します。 | Tealium で構成を再保存します。検出結果が引き続き表示される場合は、[サポートにお問い合わせください](https://docs.tealium.com/support/)。 |
| バリア構成値の型が正しくない | SDK はその値を無視し、デフォルト値を使用します。 | Tealium でバリアを再保存します。 |
| バリアまたは変換のスコープが不明なモジュールを参照している | バリアは何も制御しないか、変換が実行されません。 | スコープを更新します。通常、この参照先は削除されたタグか、Web 専用タグです。 |
| バリアまたは変換のスコープが空である | スコープがどのディスパッチャーにも一致せず、適用されません。 | 対象となるディスパッチャーを選択するか、その項目を削除します。 |
| SDK に存在しないトランスフォーマーが変換で使用されている | 変換は実行されません。 | 拡張機能を Prism がサポートするタイプに置き換えます。 |
| モジュールがファイル内に存在しないロードルールを参照している | すべてのディスパッチでモジュールがブロックされます。 | ロードルールが存在し、有効であることを確認します。 |
| 同意構成が、モジュールではないディスパッチャーを参照している | 影響はありません。同意管理は現在 Prism では利用できないため、SDK は同意セクションを無視します。 | 対応は不要です。同意を適用するには、[同意オーケストレーション](https://docs.tealium.com/about-consent-orchestration/)を使用します。 |
| モジュールタイプを SDK が認識できない | SDK は起動時にモジュールを破棄します。 | モバイルプロファイルから Web 専用タグを削除します。 |

## モバイル構成を公開する

モバイル構成を公開するには、次の手順を実行します。

1. Tealium で、公開するモバイルプロファイルを開きます。
1. Tealium Tools アイコンをクリックし、**Mobile Settings Publisher** を選択します。**Account** と **Profile** が、公開対象のプロファイルと一致していることを確認します。ツールは、開いているセッションからこれらを読み取ります。
1. **Tealium API Key** ボックスに API キーを貼り付けます。
1. （任意）公開前にファイルを確認するには、**Download JSON** をクリックします。公開のたびにコピーを保存するには、**Also download the file when publishing** を選択したままにします。
1. （任意）環境の **Settings file name** を変更します。
1. **Publish to Dev**、**Publish to QA**、または **Publish to Prod** をクリックします。同じファイルを 3 つすべての環境に公開するには、**Publish to All Environments** をクリックします。
1. Prod が含まれている場合は、「You are about to publish to PROD. This will overwrite live CDN data. Continue?」というメッセージを含む確認ダイアログが表示されます。確認ダイアログで **OK** をクリックします。

公開するたびに、CDN 上のファイルが直ちに置き換えられます。モバイル構成セクションには、ワンクリックでロールバックする機能はありません。ロールバックするには、**Tag Management > Client-Side Versions** に移動し、以前のバージョンを選択して、モバイル構成を再度公開します。

このツールは、公開前に Prism 構成スキーマに対してファイルを検証しません。Prod に公開する前に、Dev または QA に公開するか、ファイルをダウンロードして確認してください。

このツールは空のファイルを公開しません。プロファイルにモバイル構成がない場合、ツールに **No Mobile Configuration Found** または **Nothing to Publish** と表示され、CDN ファイルは変更されません。
### パブリッシュステータス

パブリッシュ後、ツールには次のいずれかのメッセージが表示されます。

| メッセージ | 意味 |
| :--- | :--- |
| **パブリッシュ成功** | 対象となるすべての環境がパブリッシュされました。 |
| **パブリッシュが一部失敗** | 一部の環境はパブリッシュされましたが、ほかの環境では失敗しました。メッセージには、各環境の結果が表示されます。 |
| **パブリッシュ失敗** | 対象となるすべての環境で失敗しました。メッセージには、各環境で失敗した理由が表示されます。 |

環境ボタンは有効なままなので、失敗した環境に対して直接再試行できます。

## パブリッシュを確認する

各環境には、**最終パブリッシュ日時**とCDNファイルへのリンクが表示されます。この日時は、CDN上のファイルから取得されます。**未パブリッシュ**は、その構成ファイル名に対応するファイルが存在しないことを意味します。

パブリッシュされたファイルを表示するには、対象環境のリンクをクリックします。CDNでは、ファイルが最長1時間キャッシュされます。キャッシュを回避するには、`?cb=1`のように、それまで使用していないクエリ文字列を追加します。

## エラーのトラブルシューティング

| エラー | 原因と解決方法 |
| :--- | :--- |
| **UTUIが見つかりません** | ツールがTealiumモバイルプロファイルから開かれていません。モバイルプロファイルを開いてから、ツールを開きます。 |
| **モバイル構成が見つかりません**または**パブリッシュする内容がありません** | プロファイルにパブリッシュ対象のモバイル構成がありません。モバイルプロファイルで少なくとも1つのモジュールを構成し、保存します。 |
| **APIキーが必要です** | APIキーが入力されていません。**Tealium APIキー**ボックスにキーを貼り付けます。 |
| **ユーザーのメールアドレスがありません**または**セッションエラー** | 現在のTealiumセッションから、メールアドレス、アカウント、またはプロファイルを読み取れませんでした。Tealiumを再読み込みして、ツールをもう一度開きます。 |
| **トークン交換に失敗しました** | APIキーが無効または期限切れであるか、ユーザーにAPIキーを生成する権限がありません。**管理 > APIキー**で新しいキーを生成し、もう一度試します。 |
| **HTTP 400** | ホステッドデータレイヤーAPIがリクエストを拒否しました。APIメッセージの指示に従ってください。エラーが解消しない場合は、ファイルをダウンロードして[サポートにお問い合わせください](https://docs.tealium.com/support/)。 |
| **HTTP 403** | ユーザーには、このアカウントおよびプロファイルのホステッドデータレイヤーにパブリッシュする権限がありません。アカウント管理者にお問い合わせください。 |
| **HTTP 404** | このアカウントでは、ホステッドデータレイヤーが有効になっていません。Tealiumアカウントマネージャーにお問い合わせください。 |
| **最終パブリッシュ日時：不明** | ファイルが存在しないこと以外の理由（たとえば、一時的なネットワークエラー）でCDNの確認に失敗しました。パブリッシュには影響しません。 |

### アプリで新しい構成が反映されない

* CDNでは、各ファイルが最長1時間キャッシュされます。SDKもキャッシュされたコピーを保持し、CDNからファイルが変更されていないことが通知された場合は、そのコピーを引き続き使用します。
* SDKは起動時にキャッシュされた構成を適用し、リモート構成の更新間隔に従って、バックグラウンドでCDNから構成を更新します。
* アプリ内の構成URLが、パブリッシュしたアカウント、プロファイル、環境、および構成ファイル名と一致していることを確認します。DevまたはQAのファイルは、その環境にパブリッシュした後にのみ作成されます。
