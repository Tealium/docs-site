## モバイル構成パブリッシャーについて

モバイル構成パブリッシャーは、Tealium Toolsブラウザ拡張機能のツールで、Prismモバイルプロファイルの構成をTealium CDNに公開します。

このツールはEarly Accessフェーズ中の一時的な解決策です。モバイル構成の公開がGAにリリースされると、このツールは廃止されます。アプリは変更する必要はありません。

## 要件

この機能には以下が必要です：

* ChromeまたはEdgeの[Tealium Toolsブラウザ拡張機能](https://docs.tealium.com/tealium-tools-browser-extension/)で、アカウントにモバイル構成パブリッシャーが有効になっていること。
* 公開したいTealiumアカウントとプロファイルへのアクセス。
* 少なくとも1つのモジュールが構成されているTealiumモバイルプロファイル（Early Access）。
* このアカウントとプロファイルにアクセスするための[Tealium APIキー](https://docs.tealium.com/api-keys/)と[ホストされたデータレイヤーAPI](https://docs.tealium.com/about-hosted-data-layer-api/)。

## 動作方法

このツールは、現在開いているモバイルプロファイルの構成を読み取り、Prism構成ファイルとして公開します。

公開されたファイルはSDK構成のリモート層です。アプリのプログラム構成がそれを上書きします。詳細については、[構成ガバナンス](https://docs.tealium.com/about-tealium-prism/#configuration-governance)を参照してください。

### 環境

ツールは各環境に対して別々のファイルを公開します。ツールはカスタム環境をサポートしていません。Dev、QA、Prodのみに公開します。

| 環境 | デフォルト構成ファイル名 | URL |
| :--- | :--- | :--- |
| Dev | `mobile_settings_dev` | `https://tags.tiqcdn.com/dle/<account>/<profile>/mobile_settings_dev.json` |
| QA | `mobile_settings_qa` | `https://tags.tiqcdn.com/dle/<account>/<profile>/mobile_settings_qa.json` |
| Prod | `mobile_settings_prod` | `https://tags.tiqcdn.com/dle/<account>/<profile>/mobile_settings_prod.json` |

各環境のファイルのURLをアプリの`TealiumConfig`の構成URLとして構成します。詳細については、[クイックスタートガイド](https://docs.tealium.com/quick-start/)を参照してください。SDKはアカウント、プロファイル、または環境からURLを導出しません。アプリのURLは公開されたファイルと正確に一致する必要があります。

### カスタム構成ファイル名

異なるファイル名で公開するには、環境の**構成ファイル名**を変更します。たとえば、アプリがすでに`settings.json`をフェッチしている場合は、`settings`と入力します。名前はCDN URL、**最終公開**チェック、公開、およびその環境のダウンロードされたファイルに適用されます。

ツールは末尾の`.json`と、文字、数字、`_`、`.`、`-`以外の文字を削除します。名前が空の場合はデフォルトにリセットされます。デフォルトに戻すには、**リセット**をクリックします。カスタム名は現在のアカウントとプロファイルのブラウザに保存されます。

### アプリに初期構成ファイルをバンドルする

**JSONをダウンロード**をクリックして構成ファイルを生成し、それをアプリにローカル構成ファイルとしてバンドルします。バンドルされたファイルは、接続性が限られている場合でも最初の起動時にSDKを完全に構成します。リモート構成は、SDKがそれらをフェッチした後、バンドルされたファイルを上書きします。

ローカル構成ファイルを指定する方法の詳細については、[クイックスタートガイド](https://docs.tealium.com/quick-start/)を参照してください。

### APIキー

ツールはAPIキーを短期間のベアラートークンと交換し、そのトークンを使用して公開します。ツールはAPIキー自体をホストされたデータレイヤーAPIに送信しません。

デフォルトでは、ツールはキーを現在のブラウザセッションのみで保持します。**セッション間でAPIキーを記憶する**を選択すると、ツールはキーをブラウザのローカル保存に保存します。保存されたキーは暗号化されていません。信頼できるデバイスでのみこのオプションを選択してください。保存されたキーはマスクされ、**変更**および**クリア**アクションが表示されます。**クリア**は保存されたキーとキャッシュされたトークンを削除します。

### 監査警告

公開前に、ツールはSDKが受け入れるがエラーを記録せずに無視する構成をチェックします。調査結果はツールの上部に表示されます。調査結果は公開をブロックしませんが、影響を受ける構成はTealiumで修正するまでアプリでは効果がありません。

| 調査結果 | SDKでの効果 | 対処方法 |
| :--- | :--- | :--- |
| リスト構成にプレーン値ではなく選択オブジェクトが含まれている | SDKはすべての値をドロップします。構成は何も選択されていないかのように動作します。 | Tealiumで構成を再保存します。調査結果が続く場合は、[サポートに連絡してください](https://docs.tealium.com/support/)。 |
| バリア構成値のタイプが間違っている | SDKは値を無視し、デフォルトを使用します。 | Tealiumでバリアを再保存します。 |
| バリアまたは変換スコープが不明なモジュールを参照している | バリアは何もゲートせず、変換は実行されません。 | スコープを更新します。通常、参照は削除されたかウェブ専用のタグを指します。 |
| バリアまたは変換スコープが空 | スコープはディスパッチャーに一致せず、効果がありません。 | 意図したディスパッチャーを選択するか、アイテムを削除します。 |
| 変換がSDKにないトランスフォーマーを使用している | 変換は実行されません。 | Prismがサポートするタイプの拡張機能に置き換えます。 |
| モジュールがファイルにないロードルールを参照している | モジュールはすべてのディスパッチでブロックされます。 | ロードルールが存在し、アクティブであることを確認します。 |
| 同意がモジュールでないディスパッチャーを参照している | 同意構成は何もゲートしません。 | 同意構成をアクティブなモジュールを参照するように更新します。 |
| モジュールタイプがSDKに不明 | SDKは起動時にモジュールをドロップします。 | モバイルプロファイルからウェブ専用のタグを削除します。 |

## モバイル構成の公開

モバイル構成を公開するには：

1. Tealiumで公開したいモバイルプロファイルを開きます。
1. Tealium Toolsアイコンをクリックし、**モバイル構成パブリッシャー**を選択します。**アカウント**と**プロファイル**が公開するプロファイルと一致していることを確認します。ツールは開いているセッションからそれらを読み取ります。
1. **Tealium APIキー**ボックスにAPIキーを貼り付けます。
1. (オプション)公開する前にファイルを確認するには、**JSONをダウンロード**をクリックします。公開するたびにコピーを保持するには、**公開時にもファイルをダウンロードする**を選択したままにします。
1. (オプション)環境の**構成ファイル名**を変更します。
1. **Devに公開**、**QAに公開**、または**Prodに公開**をクリックします。同じファイルをすべての環境に公開するには、**すべての環境に公開**をクリックします。
1. Prodが含まれる場合、確認ダイアログが表示され、「PRODに公開しようとしています。これにより、ライブCDNデータが上書きされます。続行しますか？」というメッセージが表示されます。確認ダイアログで**OK**をクリックします。

各公開はCDN上のファイルを直ちに置き換えます。モバイル構成セクションにはワンクリックでロールバックする機能はありません。ロールバックするには、**タグ管理 > クライアントサイドバージョン**に移動し、以前のバージョンを選択してモバイル構成を再度公開します。

ツールは公開前にファイルをPrism構成スキーマに対して検証しません。Prodに公開する前に、DevまたはQAに公開するか、ファイルをダウンロードして確認してください。

ツールは空のファイルを公開しません。プロファイルにモバイル構成がない場合、ツールは**モバイル構成が見つかりません**または**公開するものがありません**と表示し、CDNファイルは変更されません。

### 公開ステータス

公開後、ツールは次のいずれかのメッセージを表示します：

| メッセージ | 意味 |
| :--- | :--- |
| **公開成功** | 対象のすべての環境が公開されました。 |
| **公開部分的に失敗** | いくつかの環境が公開され、いくつかが失敗しました。メッセージは各環境の結果をリストします。 |
| **公開失敗** | 対象のすべての環境が失敗しました。メッセージは各環境の理由をリストします。 |

環境ボタンはアクティブのままなので、失敗した環境を直接再試行できます。
## 公開を確認する

各環境では、**最終公開時刻**とCDNファイルへのリンクが表示されます。時刻はCDN上のファイルから取得されます。**未公開**はその構成ファイル名のファイルが存在しないことを意味します。

公開されたファイルを表示するには、環境のリンクをクリックします。CDNはファイルを最大1時間キャッシュします。キャッシュをバイパスするには、以前に使用していないクエリ文字列を追加します。例えば `?cb=1` です。

## エラーのトラブルシューティング

| エラー | 原因と解決策 |
| :--- | :--- |
| **UTUIが見つかりません** | ツールはTealiumモバイルプロファイルから開かれていません。モバイルプロファイルを開き、その後でツールを開いてください。 |
| **モバイル構成が見つからない**または**公開するものがない** | プロファイルにはモバイル構成が公開されていません。モバイルプロファイルで少なくとも1つのモジュールを構成して保存してください。 |
| **APIキーが必要です** | APIキーが入力されていません。**Tealium APIキー**ボックスにキーを貼り付けてください。 |
| **ユーザーのメールが見つからない**または**セッションエラー** | ツールが現在のTealiumセッションからメールアドレス、アカウント、またはプロファイルを読み取れませんでした。Tealiumを再読み込みして、ツールを再度開いてください。 |
| **トークン交換に失敗しました** | APIキーが無効または期限切れであるか、ユーザーがAPIキーを生成する権限がありません。**管理 > APIキー**で新しいキーを生成して再試行してください。 |
| **HTTP 400** | ホストされたデータレイヤーAPIがリクエストを拒否しました。APIメッセージに従ってください。エラーが続く場合は、ファイルをダウンロードして[サポートに連絡してください](https://docs.tealium.com/support/)。 |
| **HTTP 403** | このアカウントとプロファイルに対してホストされたデータレイヤーに公開する権限がユーザーにありません。アカウント管理者に連絡してください。 |
| **HTTP 404** | このアカウントではホストされたデータレイヤーが有効になっていません。Tealiumアカウントマネージャーに連絡してください。 |
| **最終公開: 不明** | CDNのチェックがファイルの欠落以外の理由で失敗しました。例えば一時的なネットワークエラーです。公開には影響しません。 |

### アプリが新しい構成を認識しない

* CDNは各ファイルを最大1時間キャッシュします。SDKもキャッシュされたコピーを保持し、CDNがファイルに変更がないと報告した場合にそれを使用し続けます。
* SDKは起動時にキャッシュされた構成を適用し、リモート構成の更新間隔でCDNから背景でそれらを更新します。
* アプリの構成URLが公開したアカウント、プロファイル、環境、および構成ファイル名と一致していることを確認してください。DevまたはQAファイルは、その環境に公開した後にのみ存在します。
