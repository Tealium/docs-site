APIカタログは、[Tealium 開発者ポータル](https://app.tealiumapis.com/)の中心的な発見ハブです。カタログから、公開されているすべてのAPIを閲覧し、リファレンスドキュメントを読むことができ、利用可能なプランとセキュリティタイプを確認し、サブスクリプションの手続きを開始することができます。

## カタログを閲覧する

カタログは、公開されているすべてのAPIをカードとして表示します。各カードには以下が表示されます：

* APIの名前とバージョン
* APIの目的の短い説明
* サポート終了日（例：「2028年7月までサポート」）
* APIがモデルコンテキストプロトコルをサポートしている場合、MCPバッジ

## 検索とフィルター

検索バーを使用して、名前または説明によってAPIを見つけます。また、カタログを以下でフィルタリングすることもできます：

* **MCP**: モデルコンテキストプロトコルをサポートするAPIのみを表示。
* **バージョン**: 複数のバージョンのAPIが存在する場合、バージョンピッカーを使用して切り替えます。
* **カテゴリ**: 論理的なカテゴリに整理されたAPIを閲覧します。

## APIライフサイクル

APIのバージョニングはライフサイクルの状態に基づいています。ライフサイクルの段階とバージョニングの仕組みの詳細については、[APIバージョニング](https://docs.tealium.com/dev-portal-api-versioning/)および[APIライフサイクル](https://docs.tealium.com/dev-portal-api-lifecycle/)を参照してください。

## APIの詳細

任意のAPIカードをクリックして、その詳細ページを開きます。詳細ページはタブで整理されています：

* **説明:** APIの説明と概要。
* **概要:** バージョン、ステータス、および所有者情報。
* **プラン:** すべての利用可能なサブスクリプションプランとそのセキュリティタイプ、検証モード（自動または手動）。Tealium APIはOAuth 2.0クライアント認証情報を使用します。他のセキュリティタイプ（JWT、APIキー、キーレス）が一部のプランに表示されることがあります。APIのサブスクリプションに関する情報については、[アプリケーション](https://docs.tealium.com/dev-portal-applications/)を参照してください。
* **RESTエンドポイント:** リソースごとにグループ化されたすべての利用可能なエンドポイント。グループを展開して個々の操作を表示します。
* **MCP:** MCPツールが利用可能で、各ツールの目的、必要なパラメータ、および期待される動作が文書化されています。
* **ドキュメント:** Tealium 開発者ポータルのAPIドキュメントへのリンク。リファレンスドキュメントからは、以下を行うことができます：
  * すべてのエンドポイントとそのHTTPメソッド、パス、および説明を表示します。
  * リクエストとレスポンスのスキーマを例のペイロードとともに検査します。
  * 必須およびオプションのパラメータを特定します。
  * 各エンドポイントの認証要件を確認します。
  * テスト用のベアラートークンを生成します。

  詳細については、[APIリファレンス](https://docs.tealium.com/dev-portal-api-reference/)を参照してください。
