Tealium開発者ポータルの分析を使用して、アプリケーションのAPI使用状況、パフォーマンス、エラー率を監視します。時間枠（24時間、7日、30日、または90日）、アプリケーション、およびAPIでフィルタリングします。

## 概要メトリクス

分析画面の上部には、選択した時間範囲に対する以下のメトリクスが表示されます：

| メトリック | 説明 |
|---|---|
| 総リクエスト数 | アプリケーションによって行われたAPIコールの総数。 |
| 成功率 | 2xxステータスコードを返したリクエストの割合。 |
| 平均応答時間（ms） | APIリクエスト全体の平均応答時間（ミリ秒）。 |
| エラー数 | 4xxまたは5xxステータスコードを返したリクエストの数。 |

## チャート

分析画面には、時間経過に伴うAPI活動をレビューするためのチャートが含まれています。

### リクエストボリューム

リクエストボリュームチャートは、選択した時間範囲における2xx、4xx、および5xxの応答を示します。このチャートを使用して、トラフィックパターン、ピーク使用期間、およびクライアントまたはサーバーエラーの増加を特定します。

### 応答時間

応答時間チャートは、選択した時間範囲における平均API応答時間を示します。このチャートを使用して、パフォーマンスの変化や最適化が必要かもしれないリクエストパターンを特定します。

### ステータス分布

ステータス分布チャートは、ステータスコードカテゴリー別にグループ化された応答を示します：

| ステータスコードカテゴリー | 説明 |
| --- | --- |
| 2xx | 成功したリクエスト。 |
| 4xx | クライアントエラー、認証失敗、無効なパラメーター、またはスコープの欠如など。 |
| 5xx | サーバーエラー。5xxエラーが続く場合は、Tealiumサポートに連絡してください。 |

### トップAPI

トップAPIチャートは、リクエスト数でランク付けされたAPIを示します。このチャートを使用して、最もトラフィックの多いAPIを特定します。

## 分析データのフィルタリング

分析ページの上部にあるフィルターを使用して、分析データを絞り込みます：

| フィルター | 説明 |
| --- | --- |
| 時間範囲 | **24h**、**7d**、**30d**、または**90d**を選択します。 |
| アプリケーション | 特定のアプリケーションを選択するか、または**すべてのアプリケーション**を選択して、すべてのアプリケーションのデータを表示します。 |
| API | 特定のAPIを選択するか、または**すべてのAPI**を選択して、すべてのAPIのデータを表示します。 |

## 一般的なパターンのトラブルシューティング

### 高い403エラー率

403（禁止）の応答が多い場合、通常は認証の問題を示しています。次の点を確認してください：

* 実行している操作を許可するサブスクリプションスコープがあるか。
* アカウントとプロファイルの割り当てが、アクセスしようとしているリソースを含んでいるか。
* トークンリクエストに必要なすべてのスコープが含まれているか。

### 高い401エラー率

401（未認証）の応答が多い場合、通常は認証の問題を示しています。次の点を確認してください：

* リクエストを送信する前にアクセストークンが期限切れになっていないか。
* 期限切れのトークンを使用するのを避けるために、積極的なトークン更新を実装しているか。
* 保存されているクライアント認証情報、クライアントシークレットを含め、現在のものであるか。

### 応答時間の増加

応答時間が増加している場合、次の点を確認してください：

* 429（リクエスト数が多すぎます）の応答を探し、レート制限を示しているかどうかを確認します。
* 大きな結果セットを返すリクエストにはページネーションを使用します。
* リクエストパターンを見直し、可能な場所で不要なリクエスト量を減らします。
