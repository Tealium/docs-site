## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。

* **Splunk トークン**：HTTP Event Collector のトークンです。**Settings > Data Inputs > HTTP Event Collector** でトークンを作成します。
* **ホスト**：HTTP Event Collector を実行する Splunk インスタンスです。例：`https://hec.example.com`
* **ポート**：（任意）HTTP Event Collector のポート番号です。

コネクタを構成した後、**Done** をクリックします。

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| イベントデータ全体を送信 | ✗ | ✓ |
| イベントデータ全体を送信（バッチ） | ✗ | ✓ |
| カスタムイベントデータを送信 | ✗ | ✓ |
| カスタムイベントデータを送信（バッチ） | ✗ | ✓ |
| ログイベントを送信 | ✗ | ✓ |
| イベント全体を送信 | ✗ | ✓ |
| 訪問データ全体を送信 | ✓ | ✗ |
| 訪問データ全体を送信（バッチ） | ✓ | ✗ |
| カスタム訪問データを送信 | ✓ | ✗ |
| カスタム訪問データを送信（バッチ） | ✓ | ✗ |

アクションの名前を入力し、**Action Type** を選択します。

以下のセクションでは、各アクションのパラメーターとオプションの構成方法について説明します。

### イベントデータ全体を送信

#### メタデータ

| **パラメーター** | **説明** |
| --- | --- |
| Splunk リクエストチャネル | インデクサー確認応答が有効な場合のチャネル識別子です。 |
| 時刻 | イベントの時刻です。 |
| ホスト | イベントデータに割り当てるホスト値です。 |
| ソース | イベントデータに割り当てるソース値です。たとえば、開発中のアプリからデータを送信する場合は、このキーをアプリ名に構成します。 |
| ソースタイプ | イベントデータに割り当てるソースタイプの値です。 |
| インデックス | イベントデータのインデックス作成に使用するインデックスの名前です。トークンに indexes パラメーターが構成されている場合、ここで指定するインデックスは、許可されているインデックスのリストに含まれている必要があります。 |
| カスタムフィールド | fields キーは生データには適用されません。このキーでは、インデックス作成時に定義する明示的なカスタムフィールドのフラットな（ネストされていない）リストを含む JSON オブジェクトを指定します。`fields` プロパティを含むリクエストは、`/collector/event` エンドポイントに送信する必要があります。それ以外の場合、インデックスは作成されません。詳細については、[Splunk Enterprise：HTTP Event Collector を使用したインデックス付きフィールド抽出の自動化](https://help.splunk.com/en/splunk-enterprise/get-started/get-data-in/9.4/get-data-with-http-event-collector/automate-indexed-field-extractions-with-http-event-collector)を参照してください。 |
| 属性名を出力 | 属性名が更新された場合、ペイロード内の名前にも更新が反映されます。 |

### イベントデータ全体を送信（バッチ）

#### バッチの制限

このアクションでは、ベンダーへの大量データ転送に対応するため、バッチリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：60 分
* リクエストの最大サイズ：10 MB

#### メタデータ

| **パラメーター** | **説明** |
| --- | --- |
| Splunk リクエストチャネル | インデクサー確認応答が有効な場合のチャネル識別子です。 |
| 時刻 | イベントの時刻です。 |
| ホスト | イベントデータに割り当てるホスト値です。 |
| ソース | イベントデータに割り当てるソース値です。たとえば、開発中のアプリからデータを送信する場合は、このキーをアプリ名に構成します。 |
| ソースタイプ | イベントデータに割り当てるソースタイプの値です。 |
| インデックス | イベントデータのインデックス作成に使用するインデックスの名前です。トークンに indexes パラメーターが構成されている場合、ここで指定するインデックスは、許可されているインデックスのリストに含まれている必要があります。 |
| カスタムフィールド | fields キーは生データには適用されません。このキーでは、インデックス作成時に定義する明示的なカスタムフィールドのフラットな（ネストされていない）リストを含む JSON オブジェクトを指定します。`fields` プロパティを含むリクエストは、`/collector/event` エンドポイントに送信する必要があります。それ以外の場合、インデックスは作成されません。詳細については、[Splunk Enterprise：HTTP Event Collector を使用したインデックス付きフィールド抽出の自動化](https://help.splunk.com/en/splunk-enterprise/get-started/get-data-in/9.4/get-data-with-http-event-collector/automate-indexed-field-extractions-with-http-event-collector)を参照してください。 |
| 属性名を出力 | 属性名が更新された場合、ペイロード内の名前にも更新が反映されます。 |
| バッチの有効期間 | バッチアクションを送信する頻度を指定するため、有効期間（TTL）を構成します。`1`～`60` 分の値を入力します。デフォルトは `15` 分です。 |

### カスタム訪問データを送信（バッチ）

#### バッチの制限

このアクションでは、ベンダーへの大量データ転送をサポートするためにバッチリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳しくは、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：60 分
* リクエストの最大サイズ：10 MB

#### メタデータ

| **パラメーター** | **説明** |
| --- | --- |
| Splunk リクエストチャネル | インデクサー確認応答が有効な場合のチャネル識別子。 |
| 時刻 | イベント時刻。 |
| ホスト | イベントデータに割り当てるホスト値。 |
| ソース | イベントデータに割り当てるソース値。たとえば、開発中のアプリからデータを送信する場合は、このキーをアプリ名に構成します。 |
| ソースタイプ | イベントデータに割り当てるソースタイプ値。 |
| インデックス | イベントデータのインデックス作成に使用するインデックスの名前。トークンに indexes パラメーターが構成されている場合、ここで指定するインデックスは許可されたインデックスのリストに含まれている必要があります。 |
| カスタムフィールド | fields キーは生データには適用されません。このキーでは、インデックス作成時に定義する明示的なカスタムフィールドのフラットな（ネストされていない）リストを含む JSON オブジェクトを指定します。`fields`プロパティを含むリクエストは、`/collector/event`エンドポイントに送信する必要があります。それ以外の場合、リクエストはインデックス化されません。詳しくは、[Splunk Enterprise：HTTP Event Collector を使用したインデックスフィールド抽出の自動化](https://help.splunk.com/en/splunk-enterprise/get-started/get-data-in/9.4/get-data-with-http-event-collector/automate-indexed-field-extractions-with-http-event-collector)を参照してください。 |

| **パラメーター** | **説明** |
| --- | --- |
| カスタムメッセージ定義 | メッセージデータを構築するための値を指定します。テンプレートをサポートするには、テンプレートからメッセージデータを生成するためにテンプレート名を参照します。テンプレートを使用する場合は、カスタムメッセージ定義にマッピングします。テンプレートを使用すると、その他のキーと値のペアは無視されます。|

|テンプレート|<ul><li>（任意）URL、URL パラメーター、ヘッダー、または本文データで参照するテンプレートを指定します。詳しくは、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。</li><li>テンプレートは、二重中括弧で囲んだ名前によって、サポートされているフィールドに挿入されます。例：`{{SomeTemplateName}}`。</li></ul> |
| バッチの有効期間 | バッチアクションを送信する頻度を指定するため、有効期間（TTL）を構成します。`1`～`60`分の値を入力します。デフォルトは`15`分です。 |
