## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を構成します。

* **アカウントドメイン**：アカウントのドメイン名を指定します。たとえば、FreshdeskアカウントのAPIエンドポイントが`https://exampledomain.freshdesk.com/api/v2/`の場合は、`exampledomain`と入力します。   
（[Freshdesk API](https://developers.freshdesk.com/api/#getting-started)）
* **ユーザー名**：認証には、Freshdeskへのログイン時に使用するものと同じユーザー名とパスワードを使用します。
* **パスワード**：認証には、Freshdeskへのログイン時に使用するものと同じユーザー名とパスワードを使用します。

## アクション構成 - パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### アクション - 連絡先を作成

#### パラメータ

| **パラメータ**      | **説明**                                                                                                                                                                                |
|:-------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 名前               | 連絡先の名前。このエンドポイントの詳細については、[Freshdeskのドキュメント](https://developers.freshdesk.com/api/#create_contact)を参照してください。                                          |
| メールアドレス              | 連絡先のプライマリメールアドレス。この連絡先に追加のメールアドレスを関連付けるには、`other_emails`属性を使用します。                                                                      |
| 電話番号              | 連絡先の電話番号。                                                                                                                                                               |
| 携帯電話番号             | 連絡先の携帯電話番号。                                                                                                                                                                  |
| Twitter ID         | 連絡先のXハンドル。                                                                                                                                                                 |
| 一意の外部ID | 連絡先の外部ID。                                                                                                                                                                    |
| その他のメールアドレス       | 連絡先に関連付けられた追加のメールアドレス。文字列または文字列セット属性。                                                                                                             |
| 会社ID         | この連絡先が所属する主要会社のID。                                                                                                                                       |
| すべてのチケットを表示   | `True`または`false`。連絡先が、所属する会社に関連付けられたすべてのチケットを表示できる場合は、`true`に構成します。                                                             |
| 住所            | 連絡先の住所。                                                                                                                                                                        |
| カスタムフィールド      | カスタムフィールドの名前と値を含むキーと値のペア。カスタム日付フィールドの入力には、`YYYY-MM-DD`形式の日付のみを使用できます。                                         |
| 説明        | 連絡先の簡単な説明。                                                                                                                                                            |
| 役職          | 連絡先の役職。                                                                                                                                                                      |
| 言語           | 連絡先の言語。デフォルト言語は`en`です。これは、多言語機能が有効な場合（Gardenプラン以上）にのみ構成できます。                                                   |
| タグ               | この連絡先に関連付けられたタグ。属性タイプは`set of strings`または`array of strings`である必要があります。項目が1つだけの場合でも、最初にこれらのいずれかの属性タイプに形式を整える必要があります。 |
| タイムゾーン          | 連絡先のタイムゾーン。デフォルト値はドメインのタイムゾーンです。これは、複数タイムゾーン機能が有効な場合（Gardenプラン以上）にのみ構成できます。                             |

### アクション - 連絡先を更新
#### パラメーター

| **パラメーター**   | **説明**                                                                                                                                                                              |
|:-------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 連絡先 ID          | 更新する連絡先の ID。このエンドポイントの詳細については、[Freshdesk のドキュメント](https://developers.freshdesk.com/api/#update_contact)を参照してください。                       |
| 名前               | 連絡先の名前。                                                                                                                                                                       |
| メール             | 連絡先のメインメールアドレス。この連絡先に追加のメールアドレスを関連付けるには、`other_emails` 属性を使用します。                                                                    |
| 電話番号           | 連絡先の電話番号。                                                                                                                                                                   |
| 携帯電話番号       | 連絡先の携帯電話番号。                                                                                                                                                               |
| Twitter ID         | 連絡先の X ハンドル。                                                                                                                                                                |
| 一意の外部 ID      | 連絡先の外部 ID。                                                                                                                                                                    |
| その他のメール     | 連絡先に関連付けられた追加のメールアドレス。文字列または文字列セットの属性。                                                                                                         |
| 会社 ID            | この連絡先が所属する主要会社の ID。                                                                                                                                                  |
| すべてのチケットを表示 | `True` または `false`。連絡先が、自身の所属会社に関連付けられたすべてのチケットを閲覧できる場合は、`true` に構成します。                                                          |
| 住所               | 連絡先の住所。                                                                                                                                                                       |
| カスタムフィールド | カスタムフィールドの名前と値を含むキーと値のペア。カスタム日付フィールドへの入力には、`YYYY-MM-DD` 形式の日付のみ使用できます。                                                       |
| 説明               | 連絡先の簡単な説明。                                                                                                                                                                 |
| 役職               | 連絡先の役職。                                                                                                                                                                       |
| 言語               | 連絡先の言語。デフォルト言語は `en` です。これは、多言語機能が有効な場合（Garden プラン以上）にのみ構成できます。                                                                    |
| タグ               | この連絡先に関連付けられたタグ。属性タイプは `set of strings` または `array of strings` である必要があります。項目が 1 つだけの場合も、最初にいずれかの属性タイプの形式に整える必要があります。 |
| タイムゾーン       | 連絡先のタイムゾーン。デフォルト値はドメインのタイムゾーンです。これは、複数タイムゾーン機能が有効な場合（Garden プラン以上）にのみ構成できます。                                     |

### アクション - 連絡先の論理削除

#### パラメーター

| **パラメーター** | **説明**                                                                                                                                                           |
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 連絡先 ID        | 論理削除する連絡先の ID。このエンドポイントの詳細については、[Freshdesk のドキュメント](https://developers.freshdesk.com/api/#delete_contact)を参照してください。 |

### アクション - 連絡先の完全削除

#### パラメーター

| **パラメーター** | **説明**                                                                                                                                                     |
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 連絡先 ID        | 完全に削除する連絡先の ID。このアクションを実行するには、連絡先がすでに論理削除されているか、`force` パラメーターが `true` に構成されている必要があります。 |
| 強制             | `True` または `false`。まだ論理削除されていない連絡先を強制的に完全削除するには、`true` に構成します。                                                      |
