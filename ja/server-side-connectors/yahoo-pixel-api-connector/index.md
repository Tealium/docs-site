## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Yahoo API
* APIバージョン：v1
* ドキュメント：[Yahoo：Ad Tech DataX API仕様](https://help.yahooinc.com/datax/docs/yahoo-ad-tech-datax-api-specifications)
* APIエンドポイント：`https://dataxonline.yahoo.com`

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の項目を構成します。

* **クライアントID**  
  * （必須）クライアントIDは、Yahooから提供される暗号化された認証情報ファイルに含まれています。
* **クライアントシークレット**  
  * （必須）クライアントシークレットは、Yahooから提供される暗号化された認証情報ファイルに含まれています。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| ピクセルおよびイベントデータを送信 | ✓ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。

### ピクセルおよびイベントデータを送信

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| アクションソース | （必須）イベントの発生元。例：`Website`、`App`、`Offline`。 |
| ピクセルID | （必須）Yahoo DSPで作成されたインテグレーションのピクセルID。 |
| アクションソースURL | WebサイトのURL。 |
| イベント時刻 | イベントが発生した時刻（UTCのエポックミリ秒）。**イベント時刻**がマッピングされていない場合は、現在のタイムスタンプが送信されます。 |

#### ユーザーデータ

| **パラメーター** | **説明** |
| --- | --- |
| メールアドレス（SHA256ハッシュ化済み） | 前後の空白を削除し、小文字に変換してSHA256でハッシュ化済みのメールアドレスを指定します。 |
| メールアドレス（SHA256ハッシュを適用） | （SHA256ハッシュを適用）プレーンテキストのメールアドレスを指定すると、コネクタによって前後の空白が削除され、小文字に変換されたうえで、SHA256を使用してハッシュ化されます。 |
| GPSAID | Google Playストアの広告ID。 |
| IDFA | Apple広告ID。 |
| Yahoo ID | Cookie Sync識別子。 |
| VMCID | クリックまたはサードパーティーの広告サーバーから収集されたURLマクロ内のクリックIDの値。これは仕様のバージョン2でサポートされる予定です。 |

#### カスタムデータ

| **パラメーター** | **説明** |
| --- | --- |
| gv | 特定のコンバージョンの金銭的価値。値のデフォルト通貨は米ドル（USD）です。DSPでは動的コンバージョン値としてレポートされます。 |
| ec | イベントに関連付けられたコンテンツカテゴリー。 |
| el | イベントカテゴリー配下の下位レベルのラベル。 |
| ea | `AddToCart`など、広告主が定義したアクション。 |
| 商品ID | 商品ID、またはカンマ区切りの複数のID。 |
| ユーザー定義 | クライアントが、上記の標準イベントの代わりにカスタム名を構成できる、最大10個のカスタムイベントラベル。名前の最大長は32文字、値の最大長は255文字です。 |
