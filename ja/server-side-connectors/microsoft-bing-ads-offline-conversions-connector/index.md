## API 情報

このコネクタは、次のベンダー API を使用します。

* API 名: Microsoft API
* API バージョン: v13
* API エンドポイント: `https://campaign.api.bingads.microsoft.com/Api/Advertiser/CampaignManagement/v13/CampaignManagementService.svc`
* ドキュメント: [Campaign Management API](https://learn.microsoft.com/en-us/advertising/campaign-management-service/campaign-management-service-reference?view=bingads-13)

## コネクタのアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| コンバージョンイベントを送信 | ✗ | ✓ |

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。

* **顧客 ID**  
（必須）Microsoft Ads UI にログインすると、URL の `CID=` の後に顧客 ID が表示されます。
* **アカウント ID**  
（必須）Microsoft Ads UI にログインすると、URL の `AID=` の後にアカウント ID が表示されます。

Microsoft に接続するには、**接続を確立**をクリックします。画面の指示に従って接続プロセスを完了してください。

### オフラインコンバージョン目標の作成

コンバージョン目標を構成するには、**オフラインコンバージョン目標を作成**をクリックします。次の情報を入力します。

1. コンバージョン目標の一意の**名前**を入力します。名前は最大 100 文字です。
1. コンバージョン目標を分類するための**目標カテゴリ**を選択します。
1. 目標をすべてのアカウントに適用するか、指定したアカウントのみに適用するかを決定するための**スコープ**を選択します。スコープを構成した後に変更するには、新しいコンバージョン目標を作成して古い目標を一時停止する必要があります。
1. **ID** に、コンバージョン目標の Microsoft Advertising 識別子を入力します。
1. **コンバージョン期間（分）**に、クリック後のコンバージョンを追跡する期間を分単位で入力します。デフォルト値は `43200` です。サポートされる最小値は `1` 分です。サポートされる最大値は `129600` 分（90 日）です。コンバージョン期間を短くすると、アカウントに記録されるコンバージョン数が減少します。
1. コンバージョン期間内でコンバージョンを記録する方法を決定するための**カウントタイプ**を選択します。デフォルトは `All` です。
    * **すべて**: 広告のクリック後に発生した、オフラインコンバージョン時刻が異なるすべてのコンバージョンをカウントします。通常、販売に使用します。
    * **ユニーク**: 広告のクリック後に発生した最初のコンバージョンのみをカウントします。通常、リードに使用します。
1. **入札から除外**で、この目標を入札に含めるか除外するかを選択します。この構成により、このコンバージョン目標に関連するデータがパフォーマンスレポート列のサブセットに表示されるかどうかが決まります。
1. **収益額**に、各コンバージョンがビジネスにとってどれだけの価値を持つかを決定する値を入力します。
1. **収益コード**に、レポートで使用する通貨タイプを入力します。
1. （任意）**ステータス**で、コンバージョン目標に構成できるユーザー指定のステータス値として、`Active`、`Paused`、または `Deleted` を選択します。
1. **作成して閉じる**をクリックします。

## アクション

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### コンバージョンイベントを送信

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| コンバージョン名 | （必須）コンバージョン目標の名前。この名前は既存のコンバージョン目標名と一致している必要があります。一致しない場合、オフラインコンバージョン目標のデータは適用されません。|
| Microsoft クリック ID | （必須）Microsoft Advertising によって構成されるランディングページ URL の一意の ID。 |
| 外部アトリビューションモデル | アトリビューションモデル名を指定します。このフィールドは、外部アトリビューションを使用するコンバージョンアクションにのみ構成できます。 |
| 外部アトリビューションクレジット | 各クリックに関連付けられるコンバージョンの割合を表します。値は 0 より大きく、1 以下である必要があります。このフィールドは、外部アトリビューションを使用するコンバージョンアクションにのみ構成できます。 |
| コンバージョン値 | オフラインコンバージョンの値。 |
| コンバージョン時刻 | （必須）ユーザーがアクションを完了してから、Bing Ads がコンバージョンデータを記録するまでの期間。 |
| 通貨コード | オフラインコンバージョンの通貨コード。オフラインコンバージョンの通貨コードを指定しない場合は、目標の<a href="https://learn.microsoft.com/en-us/advertising/campaign-management-service/conversiongoalrevenue?view=bingads-13" target="_blank">コンバージョン目標の収益</a>にある通貨コード要素が使用されます。 |
| メールアドレス（SHA256 でハッシュ化済み） | 空白の除去、小文字への変換、および SHA256 によるハッシュ化がすでに行われたメールアドレスを指定します。 |
| メールアドレス（SHA256 ハッシュを適用） | プレーンテキストのメールアドレスを指定します。コネクタは空白を除去し、小文字に変換してから、この値を SHA256 でハッシュ化します。 |
| 電話番号（SHA256 でハッシュ化済み） | E.164 標準に準拠し、空白の除去、小文字への変換、および SHA256 によるハッシュ化がすでに行われた電話番号を指定します。 |
| 電話番号（SHA256 ハッシュを適用） | プレーンテキストの電話番号を指定します。コネクタは数字以外の記号をすべて削除し、番号の先頭にプラス記号（`+`）をエンリッチメントして、空白を除去し、小文字に変換してから、この値を SHA256 でハッシュ化します。 |
