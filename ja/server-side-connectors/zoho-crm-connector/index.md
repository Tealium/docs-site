## API 情報

このコネクタは、以下のベンダー API を使用します。

* API 名: Zoho CRM API
* API バージョン: v2
* API エンドポイント: `https://www.zohoapis.com/crm/v2/`

## コネクタアクション

| **アクション名** | **訪問プロファイル** | **イベントデータ** |
|:------------------------|:-------------------|:----------------|
| レコードの作成または更新 | ✓                  | ✓               |

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタの追加方法に関する一般的な手順については、[コネクタの概要](https://docs.tealium.com/ja/server-side/connectors/manage/)の記事を参照してください。

コネクタを追加した後、以下の構成を行います。

### アクション構成 - パラメーターとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### アクション - レコードの作成または更新

#### パラメーター

| **パラメーター**          | **説明**                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:-----------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| モジュール                 | <ul><li>モジュール名。</li><li>例: `Leads`、`Accounts`</li><li>使用可能なすべてのモジュール名については、[レコードの挿入または更新（Upsert）](https://www.zoho.com/crm/developer/docs/api/v2/upsert-records.html)を参照してください。</li></ul>                                                                                                                                                                                                             |
| テンプレート変数     | <ul><li>データ入力としてテンプレート変数を指定します。</li><li>詳細については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。</li><li>ネストされたテンプレート変数には、ドット表記で名前を付けます。</li><li>例: `items.name`</li><li>ネストされたテンプレート変数は通常、データレイヤーのリスト属性から作成されます。</li></ul> |
| テンプレート              | <ul><li>本文データ内で参照するテンプレートを指定します。</li><li>詳細については、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。</li><li>テンプレートは、サポートされているフィールドに二重波括弧を使用して名前で挿入されます。</li><li>例: `{{SomeTemplateName}}`。</li></ul>                                                |
| 重複チェックフィールド | <ul><li>重複チェックフィールドによって、新しいレコードを追加するか、既存のレコードを更新するかが決まります。</li><li>デフォルトでは、システム定義の重複チェックフィールドが使用されます。</li><li>重複チェックフィールドの詳細については、[レコードの挿入または更新（Upsert）](https://www.zoho.com/crm/developer/docs/api/v2/upsert-records.html)を参照してください。</li></ul>                                                                                           |
| トリガー                | <ul><li>トリガーには、`workflow`、`approval`、または `blueprint`を指定できます。</li><li>トリガーが指定されていない場合、API に関連するワークフロー、承認、およびブループリントが実行されます。</li></ul>                                                                                                                                                                                                                                              |
