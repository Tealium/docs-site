この記事では、Google BigQueryコネクタを構成する方法について説明します。

## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Google API
* APIバージョン：v2
* APIエンドポイント：`https://bigquery.googleapis.com/bigquery/v2`
* ドキュメント：[Google API](https://cloud.google.com/bigquery/docs/loading-data)

## バッチ制限

このコネクタは、ベンダーへの大量のデータ転送に対応するため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに追加されます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：90 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の手順に従ってGoogleに対する認証を行います。

1. **認証タイプ**を選択します。
    * **Googleでログイン**
        1. Googleアカウントを選択し、TealiumによるGoogleアカウントへのアクセスを許可します。
        1. **プロジェクトID**フィールドの下にある**再読み込み**をクリックします。
    * **秘密鍵JSONファイル**：（このオプションは従来のコネクタインターフェイスでは使用できません。）
        1. **IAMと管理 > サービスアカウント > サービスアカウントを作成（任意）**に移動します。
        1. サービスアカウントのアクションメニュー（3つのドット）で、**鍵を管理 > 鍵を追加 > 新しい鍵を作成 > JSON > 作成**の順にクリックします。
        1. サービスアカウント用に生成されたJSON鍵の内容を貼り付けます。詳細については、[Google：サーバー間アプリケーションでのOAuth 2.0の使用](https://developers.google.com/identity/protocols/oauth2/service-account#creatinganaccount)を参照してください。
1. 接続する**プロジェクトID**を選択します。
1. **完了**をクリックします。

### カスタムステートメントを実行

このアクションを使用して、BigQueryテーブルに対してカスタムSQLステートメントを実行します。

この機能を使用するには、属性を名前付きプレースホルダーにマッピングします。SQLでは、`@MY_PLACEHOLDER`形式でこれらのプレースホルダーを参照します。次に、マッピングした各プレースホルダーにデータ型をマッピングします。たとえば、整数属性を`MY_NUM_PARAM`という名前のプレースホルダーにマッピングした場合は、`INT64` → `MY_NUM_PARAM`とマッピングします。

最後に、実行時にマッピング済みの値を動的に置換できるように、プレースホルダーを使用してSQLステートメントを記述します。

次の例は、`INSERT`ステートメントを実行して、文字列値とブール値を含む行を追加する方法を示しています。

まず、属性をプレースホルダーにマッピングします。

![](https://docs.tealium.com/images/server-side-connectors/bigquery-custom-sql-map-values.png)

次に、データ型をプレースホルダーにマッピングします。

![](https://docs.tealium.com/images/server-side-connectors/bigquery-custom-sql-map-types.png)

続いて、これらのプレースホルダーを参照するSQLステートメントを記述します。

```none
INSERT INTO bigquery_table (my_string_col, my_bool_col)
VALUES ('@MY_STRING_PARAM', @MY_BOOLEAN_PARAM);
```

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| データセット | （必須）接続するテーブルコレクションのIDを選択します。 |
| クエリパラメータ | （必須）属性をSQLクエリで使用するプレースホルダー名にマッピングします。少なくとも1つのパラメータをマッピングする必要があります。 |
| クエリパラメータの型 | （必須）マッピングした各パラメータの型を指定します。有効な値は、`STRING`、`INT64`、`FLOAT64`、`BOOL`、`TIMESTAMP`、`DATE`、`TIME`、`DATETIME`、`ARRAY`、`STRUCT`です。たとえば、整数属性を`MY_PARAM`という名前のプレースホルダーにマッピングした場合は、`INT64`を`MY_PARAM`にマッピングします。 |
| クエリ | （必須）実行するSQLステートメントを入力します。使用できるのは、単一の`INSERT`、`UPDATE`、または`MERGE`ステートメントのみです。マッピング済みのパラメータは`@`記号を使用して参照します。たとえば、ブール属性を`MY_BOOLEAN_PARAM`にマッピングした場合、その値を挿入するSQL内の位置で`@MY_BOOLEAN_PARAM`を使用します。 |
| バッチの有効期間 | 有効期間（TTL）を1～60分の値で構成します。デフォルト値は10分です。 |
