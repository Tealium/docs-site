## API 情報

このコネクタでは、次のベンダー API を使用します。

* API 名: Google Ads API
* API バージョン: v24
* API エンドポイント: `https://googleads.googleapis.com/`
* ドキュメント: [Google Ads API](https://developers.google.com/google-ads/api/docs/start)

## コネクタアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| トランザクションをアップロード | ✓ | ✓ |
| トランザクションをアップロード（複数の識別子） | ✓ | ✓ |

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。


<blockquote>
このコネクタを追加すると、ベンダーのデータプラットフォームポリシーへの同意を求められます。
</blockquote>


コネクタを追加した後、次の項目を構成します。

* **顧客 ID**  
（必須）Google Ads アカウントの顧客 ID。
* **マネージャー顧客 ID**  
（任意）クライアントに代わってアカウントにアクセスする場合は、マネージャー顧客 ID を構成する必要があります。顧客 ID を確認するには、Google Ads にログインし、**構成 > アクセスとセキュリティ > 管理者**に移動します。

## アクション構成 - パラメータとオプション

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションの構成方法について説明します。

### アクション - トランザクションをアップロード

#### バッチ制限

このアクションでは、ベンダーへの大容量データ転送に対応するため、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数: 100000
* 最も古いリクエストからの最大経過時間: 60 分
* リクエストの最大サイズ: 40 MB

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| コンバージョンアクション | `customers/{customer_id}/conversionActions/{conversion_action_id}` 形式で指定する、有効な Google Ads コンバージョンアクションのリソース名。コンバージョンアクション ID は、Google Ads URL の `ctId` クエリパラメータです。コンバージョンアクションのタイプは `STORE_SALES` である必要があります。詳細については、[Google Ads API: 店舗販売コンバージョンをインポートする](https://developers.google.com/google-ads/api/docs/conversions/upload-store-sales-transactions)を参照してください。 |

##### ユーザー識別子

| **パラメータ** | **説明** |
| --- | --- |
| 住所情報: 国コード | 2 文字の ISO 3166-1 alpha-2 形式で指定する、ユーザーの住所の国コード。 |
| 住所情報: 名（SHA256 でハッシュ化済み） | 前後の空白を削除し、小文字に変換して、SHA256 でハッシュ化済みのユーザーの名を指定します。 |
| 住所情報: 名（SHA256 ハッシュを適用） | ユーザーの名をプレーンテキストで指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、SHA256 ハッシュを使用してハッシュ化します。 |
| 住所情報: 姓（SHA256 でハッシュ化済み） | 前後の空白を削除し、小文字に変換して、SHA256 でハッシュ化済みのユーザーの姓を指定します。 |
| 住所情報: 姓（SHA256 ハッシュを適用） | ユーザーの姓をプレーンテキストで指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、SHA256 ハッシュを使用してハッシュ化します。 |
| 住所情報: 郵便番号 | ユーザーの住所の郵便番号。 |
| メールアドレス（SHA256 でハッシュ化済み） | 前後の空白を削除し、小文字に変換して、SHA256 でハッシュ化済みのユーザーのメールアドレスを指定します。 |
| メールアドレス（SHA256 ハッシュを適用） | ユーザーのメールアドレスをプレーンテキストで指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、SHA256 ハッシュを使用してハッシュ化します。 |
| 電話番号（SHA256 でハッシュ化済み） | 前後の空白を削除し、SHA256 でハッシュ化済みのユーザーの電話番号を指定します。 |
| 電話番号（SHA256 ハッシュを適用） | ユーザーの電話番号をプレーンテキストで指定します。コネクタは、この値の前後の空白を削除し、SHA256 ハッシュを使用してハッシュ化します。 |
| サードパーティーユーザー ID | サードパーティーによって割り当てられたユーザー ID。 |

##### トランザクションデータ

| **パラメータ** | **説明** |
| --- | --- |
| トランザクション日時 | （必須）トランザクションが発生した時刻のタイムスタンプ。形式は `YYYY-MM-DD HH:MM:SS[+/-HH:MM]` です。`[+/-HH:MM]` は、UTC からのオプションのタイムゾーンオフセットです。コネクタは、マッピングされた日付属性をこの形式（タイムゾーンオフセットなし）に変換します。 |
| トランザクション金額 | （必須）マイクロ単位のトランザクション金額。100 万マイクロが通貨単位の 1 に相当します。 |
| 通貨コード | （必須）ISO 4217 の 3 文字形式で指定するトランザクションの通貨コード。 |
| トランザクションアップロード比率 | （必須）顧客に関連付けられた売上全体に対する、アップロードされた売上の比率。この値は 0 より大きく、1 以下である必要があります。たとえば、顧客に関連付けることができる売上の半分をアップロードする場合、この値は 0.5 になります。 |
| トランザクション注文 ID | トランザクションの注文 ID。 |
| カスタムキー | 店舗販売のカスタム変数キーの名前。トランザクションに適用し、後からレポートのカスタムセグメンテーションに使用できる、事前定義されたキーです。 |
| カスタム値 | 各トランザクションのカスタム変数の値。 |
| 店舗コード | Google に以前アップロードした一意の店舗 ID。 |
| 商品 ID | 商品の一意の識別子。Merchant Center の商品 ID または GTIN（国際取引商品番号）のいずれかを指定できます。 |
| 数量 | 販売された商品の数量。構成しない場合、デフォルトは 1 です。 |
| 国コード | 商品をアップロードしたフィードに関連付けられている国の Common Locale Data Repository（CLDR）地域コード。 |
| 言語コード | 商品をアップロードしたフィードに関連付けられている言語の ISO 639-1 コード。 |
| 販売者 ID | Merchant Center アカウントの ID。 |

##### 同意

コネクタは、デフォルトで `adUserData` および `adPersonalization` の同意に対して `GRANTED` の値を送信します。デフォルトを上書きするには、関連する Event Streaming 属性を `Ad User Data Consent` または `Ad Personalization Consent`、あるいはその両方に、値 `DENIED` でマッピングします。

| **パラメータ** | **説明** |
| --- | --- |
| 広告ユーザーデータの同意 | 広告ユーザーデータに対する同意。デフォルト値は `GRANTED` です。有効な値は `GRANTED` と `DENIED` です。 |
| 広告のパーソナライズに対する同意 | 広告のパーソナライズに対する同意。デフォルト値は `GRANTED` です。有効な値は `GRANTED` と `DENIED` です。 |
