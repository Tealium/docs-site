## API 情報

このコネクタは、次のベンダー API を使用します。

* API 名：Google Ads API
* API バージョン：v24
* API エンドポイント：`https://googleads.googleapis.com/`
* ドキュメント：[Google Ads API](https://developers.google.com/google-ads/api/docs/start)

## コネクタアクション

| アクション名 | AudienceStream | EventStream |
| --- | :---: | :---: |
| トランザクションをアップロード | ✓ | ✓ |
| トランザクションをアップロード（複数の識別子） | ✓ | ✓ |

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/about-connectors/)を参照してください。


<blockquote>
このコネクタを追加すると、ベンダーのデータプラットフォームポリシーへの同意を求められます。
</blockquote>


コネクタを追加したら、次の構成を構成します。

* **顧客 ID**  
（必須）Google Ads アカウントの顧客 ID。
* **マネージャー顧客 ID**  
（任意）クライアントに代わってアカウントにアクセスする場合は、マネージャー顧客 ID を構成する必要があります。顧客 ID は、Google Ads にログインし、**構成 > アクセスとセキュリティ > マネージャー**に移動すると確認できます。

## アクション構成 — パラメーターとオプション

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

以下のセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。

### アクション — トランザクションをアップロード

#### バッチ制限

このアクションは、ベンダーへの大量データ転送に対応するため、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数：100000
* 最も古いリクエストからの最大経過時間：60 分
* リクエストの最大サイズ：40 MB

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| コンバージョンアクション | 有効な Google Ads コンバージョンアクションのリソース名。形式は `customers/{customer_id}/conversionActions/{conversion_action_id}` です。コンバージョンアクション ID は、Google Ads URL の `ctId` クエリパラメーターです。コンバージョンアクションのタイプは `STORE_SALES` である必要があります。詳細については、[Google Ads API：店舗販売コンバージョンのインポート](https://developers.google.com/google-ads/api/docs/conversions/upload-store-sales-transactions)を参照してください。 |

##### ユーザー識別子

| **パラメーター** | **説明** |
| --- | --- |
| 住所情報：国コード | ユーザーの住所に含まれる国コード（2 文字の ISO 3166-1 alpha-2 形式）。 |
| 住所情報：名（SHA256 ハッシュ化済み） | 前後の空白を削除し、小文字に変換して SHA256 でハッシュ化済みのユーザーの名を指定します。 |
| 住所情報：名（SHA256 ハッシュを適用） | ユーザーの名をプレーンテキストで指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、SHA256 でハッシュ化します。 |
| 住所情報：姓（SHA256 ハッシュ化済み） | 前後の空白を削除し、小文字に変換して SHA256 でハッシュ化済みのユーザーの姓を指定します。 |
| 住所情報：姓（SHA256 ハッシュを適用） | ユーザーの姓をプレーンテキストで指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、SHA256 でハッシュ化します。 |
| 住所情報：郵便番号 | ユーザーの住所の郵便番号。 |
| メールアドレス（SHA256 ハッシュ化済み） | 前後の空白を削除し、小文字に変換して SHA256 でハッシュ化済みのユーザーのメールアドレスを指定します。 |
| メールアドレス（SHA256 ハッシュを適用） | ユーザーのメールアドレスをプレーンテキストで指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、SHA256 でハッシュ化します。 |
| 電話番号（SHA256 ハッシュ化済み） | 前後の空白を削除し、SHA256 でハッシュ化済みのユーザーの電話番号を指定します。 |
| 電話番号（SHA256 ハッシュを適用） | ユーザーの電話番号をプレーンテキストで指定します。コネクタは、この値の前後の空白を削除し、SHA256 でハッシュ化します。 |
| サードパーティユーザー ID | サードパーティによって割り当てられたユーザー ID。 |

##### トランザクションデータ

| **パラメーター** | **説明** |
| --- | --- |
| トランザクション日時 | （必須）トランザクションが発生した日時。形式は `YYYY-MM-DD HH:MM:SS[+/-HH:MM]` です。`[+/-HH:MM]` は、UTC からの任意のタイムゾーンオフセットです。コネクタは、マッピングされた日付属性をこの形式（タイムゾーンオフセットなし）に変換します。 |
| トランザクション金額 | （必須）マイクロ単位のトランザクション金額。100 万マイクロが通貨の 1 単位に相当します。 |
| 通貨コード | （必須）ISO 4217 の 3 文字形式によるトランザクションの通貨コード。 |
| トランザクションアップロード比率 | （必須）顧客に関連付けられた売上全体に対する、アップロードした売上の比率。この値は、0 より大きく 1 以下である必要があります。たとえば、顧客に関連付けることができる売上の半分をアップロードする場合、この値は 0.5 になります。 |
| トランザクション注文 ID | トランザクションの注文 ID。 |
| カスタムキー | 店舗販売のカスタム変数キーの名前。トランザクションに適用でき、後でレポートのカスタムセグメンテーションに使用できる事前定義済みのキーです。 |
| カスタム値 | 各トランザクションのカスタム変数の値。 |
| 店舗コード | Google に以前アップロードした一意の店舗 ID。 |
| 商品 ID | 商品の一意の識別子。Merchant Center の商品 ID または GTIN（国際取引商品番号）のいずれかを使用できます。 |
| 数量 | 販売された商品の数量。構成されていない場合、デフォルトは 1 です。 |
| 国コード | 商品がアップロードされるフィードに関連付けられた国の Common Locale Data Repository（CLDR）地域コード。 |
| 言語コード | 商品がアップロードされるフィードに関連付けられた言語の ISO 639-1 コード。 |
| マーチャント ID | Merchant Center アカウントの ID。 |

##### 同意

デフォルトでは、コネクタは `adUserData` および `adPersonalization` の同意に対して `GRANTED` の値を送信します。デフォルト値を上書きするには、関連する EventStream 属性を `Ad User Data Consent` および／または `Ad Personalization Consent` にマッピングし、値を `DENIED` に構成します。

| **パラメーター** | **説明** |
| --- | --- |
| 広告ユーザーデータへの同意 | 広告ユーザーデータに対する同意。デフォルト値は `GRANTED` です。有効な値は `GRANTED` と `DENIED` です。 |
| 広告パーソナライズへの同意 | 広告パーソナライズに対する同意。デフォルト値は `GRANTED` です。有効な値は `GRANTED` と `DENIED` です。 |
