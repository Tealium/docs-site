## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：ActiveCampaign API
* APIバージョン：v3
* ドキュメント：[ActiveCampaign API](https://developers.activecampaign.com/reference/overview)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。

* **アカウント名**  
  * アカウント固有のベースURLを使用してAPIにアクセスします。
  * ActiveCampaignに移動し、**Settings &gt; Developer**をクリックしてAPI URLを取得します。
* **APIトークン**  
  * ActiveCampaignに移動し、**Settings &gt; Developer**をクリックしてAPIトークンを取得します。
  * ActiveCampaignアカウントの各ユーザーには、それぞれ一意のAPIトークンがあります。

コネクタを構成した後、**Done**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| 連絡先のアップサート | ✓ | ✓ |
| 連絡先へのタグの追加 | ✓ | ✓ |
| オートメーションへの連絡先の追加 | ✓ | ✓ |
| 連絡先のリストステータスの更新 | ✓ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### アクション — 連絡先のアップサート

#### 連絡先パラメータ

| パラメータ | 説明 |
| --- | --- |
| メールアドレス | （必須）同期する連絡先のメールアドレス。 |
| 名 | （必須）連絡先の名。 |
| 姓 | （必須）連絡先の姓。 |
| 電話番号 | （必須）連絡先の電話番号。 |

#### フィールド値

連絡先のフィールド値の配列。カスタムフィールド値は、フィールド名ではなく`id`で参照されます。これは整数値であり、ActiveCampaignのフィールド管理から確認する必要があります。

| パラメータ | 説明 |
| --- | --- |
| フィールド | フィールド名。 |
| 値 | フィールドの値。 |

### アクション — 連絡先へのタグの追加

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| 連絡先ID | 連絡先のID。 |
| タグID | 訪問に割り当てるタグの正確な名前を入力します。ドロップダウンからタグを選択します。 |

### アクション — オートメーションへの連絡先の追加

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| 連絡先ID | 連絡先のID。 |
| オートメーションID | オートメーションのID。 |

### アクション — 連絡先のリストステータスの更新

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| リストID | （必須）連絡先を登録するリストのID。 |
| 連絡先ID | <ul><li>**連絡先ID**または**メールアドレス**のいずれかが必須です。リストに登録する連絡先のID。</li></ul> |
| メールアドレス | <ul><li>**連絡先ID**または**メールアドレス**のいずれかが必須です。</li><li>連絡先のメールアドレス。</li><li>ユーザーがTealiumに**連絡先ID**を保存していない場合、このフィールドが必要です。**連絡先ID**を使用しない場合は、API呼び出しでユーザーのメールアドレスを検索し、レスポンスの**ID**フィールドを**連絡先ID**として使用します。</li></ul> |
| ステータス | <ul><li>（必須）連絡先をリストに登録するには`1`に構成します。</li><li>連絡先をリストから登録解除するには`2`に構成します。</li><li>警告：ステータスを登録解除済みからアクティブに変更すると、連絡先が手動で登録解除したリストに、その連絡先を再登録できます。</li></ul> |
| ソースID | <ul><li>（任意）連絡先の流入元に関連付けられた一意の識別子。</li><li>連絡先をリストに再登録する場合は`4`に構成します。</li></ul> |
