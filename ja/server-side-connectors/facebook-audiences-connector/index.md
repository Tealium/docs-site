## API情報

このコネクタでは、次のベンダーAPIを使用します。

* API名：Facebook Graph API - Marketing API
* APIバージョン：v25.0
* APIエンドポイント：`https://graph.facebook.com`
* ドキュメント：[Facebook Marketing API](https://developers.facebook.com/docs/marketing-api/)

## バッチ処理の制限

このコネクタでは、ベンダーへの大量のデータ転送に対応するため、リクエストをバッチ処理します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルが公開されるまでキューに入れられます。

* リクエストの最大数：10000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：1 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を行います。

* **認証タイプ**：Facebookへの接続に使用する認証タイプを選択します。このオプションは、従来のコネクタインターフェイスでは使用できません。
    * **SUAT（システムユーザー認証トークン）**：（推奨）より安定した永続的な認証方法を使用するには、このオプションを選択します。詳細については、[Facebook：システムユーザーアクセストークンを取得する](https://developers.facebook.com/docs/news-indexing/guides/access-tokens/)を参照してください。
    * **OAuth2**：通常、この接続は60日以内に期限切れとなり、すべてのFacebook広告アクションで予期しない結果が生じる可能性があります。問題を回避するには、接続の有効期限が切れる前に再認証する必要があります。このオプションを選択した場合は、**接続を確立**をクリックしてFacebookで認証します。  
    
<blockquote>
**接続を確立**ボタンをクリックする前に、使用する広告アカウントIDにリンクされたアカウントでFacebookにサインインしていることを確認してください。そうでない場合、生成されるトークンに問題が発生する可能性があります。
</blockquote>

* **広告アカウントID**：（必須）管理するFacebook AudiencesアカウントIDです。詳細については、[Facebook：Facebook広告アカウントID番号を確認する](https://www.facebook.com/business/help/1492627900875762)を参照してください。

このコネクタを使用してFacebookでカスタムオーディエンスを作成するには、事前に[Facebookカスタムオーディエンス規約](https://www.facebook.com/ads/manage/customaudiences/tos.php)に同意する必要があります。

### カスタムオーディエンスの作成

コネクタを使用してカスタムオーディエンスを作成するには、事前にFacebookサイトで最初のカスタムオーディエンスを作成し、利用規約に同意する必要があります。


<blockquote>
カスタムオーディエンスを使用するには、20件以上のエントリが含まれている必要があります。オーディエンスが正常に作成されると、ボタンの横に小さなチェックアイコンが表示されます。
</blockquote>


**カスタムオーディエンスを作成**をクリックし、次の構成を行います。

* **オーディエンス名**：（必須）カスタムオーディエンスの名前です。CRMのオーディエンス名またはセグメント名を使用します（例：`Qualified Leads - US - Q3 2026`または`High Value Customers - EMEA`）。Metaはこの名前を使用してオーディエンスセグメントを識別します。
* **オーディエンスメタデータ（JSON）**：（任意）オーディエンスの条件を記述するJSONオブジェクトで、Meta APIの`description`パラメータにマッピングされます。集計属性またはカテゴリ属性を含むキーと値のペアを使用してください。個人識別情報（PII）を含めないでください。例：`{"lifecycle_stage":"churned","region":"EMEA","tier":"high_value"}`。Metaはこのメタデータをオーディエンスラベルおよび最適化機能で使用します。ラベルの割り当てはMeta広告マネージャで行います。Metaがメタデータを解析できるように、値は有効なJSONである必要があります。
* **顧客ファイルのソース**：
  * `USER_PROVIDED_ONLY`：広告主が顧客から直接収集した情報を使用します。
  * `PARTNER_PROVIDED_ONLY`：広告代理店やデータプロバイダーなどのパートナーから広告主が直接入手した情報を使用します。
  * `BOTH_USER_AND_PARTNER_PROVIDED`：広告主が顧客から直接収集した情報と、広告代理店などのパートナーから入手した情報の両方を使用します。
* **オーディエンスタイプ**：
  * `VALUE_BASED_AUDIENCE`：最も価値の高い顧客と類似した行動を示す顧客を識別します。
  * `CUSTOMER_FILE_AUDIENCE`：（デフォルト）メールアドレス、電話番号、その他の識別子など、顧客ファイルの情報に基づいて顧客を識別します。

コネクタを構成した後、**完了**をクリックします。

Facebook Audiencesサイトでは、顧客リスト、Webサイトのトラフィック、またはアプリのアクティビティに基づいてオーディエンスを作成できます。この例では、顧客リストに基づいてオーディエンスを作成します。

詳細については、[Metaビジネスヘルプセンター：顧客リストのカスタムオーディエンスを作成する](https://www.facebook.com/business/help/170456843145568?id=2469097953376494)を参照してください。

## Facebook Audiencesコネクタの使用

### 訪問IDの作成

Facebook Audiencesコネクタでは、Facebook Audiencesに渡すことができる訪問ID属性が少なくとも1つ必要です。

訪問ID属性を構成するには、次のリソースを使用してください。

* [訪問ID属性の構成](https://docs.tealium.com/visitor-id-attribute/)
* [Facebook Marketing API](https://developers.facebook.com/docs/marketing-api/audiences-api)

### オーディエンスの定義

アカウントには複数の訪問ID属性が定義されている場合があります。この場合、いずれかの訪問IDが存在するかどうかを確認するために、[`Known Visitor`という名前の訪問バッジ](https://docs.tealium.com/known-visitor-badge-guide/)を作成することが重要です。この属性を使用すると、Facebookに渡すことができる訪問IDが割り当てられた訪問のみがオーディエンスに含まれるようになります。不明な訪問をターゲティングすることはできません。

`Known Visitor`バッジを他の条件と組み合わせて、コネクタ用のオーディエンスを作成します。


<blockquote>
このコネクタには、メールアドレス、電話番号、アプリID、ユーザーIDなどの必須IDパラメータもあります。これらのIDのうち、少なくとも1つが必要です。これらのIDをオーディエンスフィルターに含めると、コネクタエラーの回避に役立ちます。
</blockquote>


### テスト

最も効果的なテスト方法は、[Trace](https://docs.tealium.com/about-trace/)を実行してイベントが適切に処理されていることを確認し、Facebookダッシュボードでカスタムオーディエンスが作成され、データが追加されていることを確認することです。

## よくある質問
### CDPのドロップダウンリストにオーディエンスが表示されないのはなぜですか？

Facebookに2,000件を超えるオーディエンスがある場合、CDPコネクターのドロップダウンリストですべてを選択できるわけではありません。

Facebookですべてのオーディエンスを表示し、特定のオーディエンスの識別子を選択するには、次の手順を実行します。

1. Facebook Audiencesアカウントへのアクセス権を持つユーザーとしてFacebookにログインします。
1. <https://www.facebook.com/adsmanager/audiences> に移動します。
1. 目的のオーディエンスを見つけ、Audience IDをコピーします。  
    
<blockquote>
Audience IDが表示されない場合は、テーブルの列表示を変更して追加できます。
</blockquote>
  

    ![](https://docs.tealium.com/images/server-side-connectors/facebook-ads-find-audience-id.png)
1. CDPに戻り、CDPコネクターのカスタム値としてAudience IDを入力します。
