## バッチ制限

このコネクタは、ベンダーへの大量のデータ転送をサポートするため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに保存されます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：200 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を構成します。
* **接続タイプ**：（必須）接続タイプを指定します。
  * SFTP
  * FTPS
* **ホスト**：（必須）リモートホストを指定します。
* **ユーザー名**：（必須）ユーザー名を指定します。
* **パスワード**：（必須）ユーザーのパスワードを指定します。
* **ポート**：（任意）ポートを指定します。ポートを指定しない場合は、次のデフォルトポートが使用されます。
    * SFTP：22
    * FTPS：990

コネクタを構成したら、**完了**をクリックします。

アクションの名前を入力し、アクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### イベントデータ全体を送信

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| ファイルタイプ | ファイルタイプを指定します。指定可能な値：`CSV`または`JSON`。 |
| ファイルパス | データを追加するファイルへのパスを指定します。 |
| 配信時にファイル名を生成 | 有効にすると、処理タイムスタンプとパーティション識別子を使用して配信（フラッシュ）時にファイル名が生成されます。これにより、バッチ処理を中断することなく一意のファイル名が確保されます。バッチバッファキーを安定させるため、日付タイプのファイルパスサフィックスのエントリはファイル名から除外されます。バッチ出力を多数の小さなファイルではなく、少数の大きなファイルとして配信する必要がある場合に、このオプションを使用します。 |
| ファイルパスサフィックス | 値をマッピングして、ファイルパスにサフィックスを動的に追加します。複数のサフィックス値を指定した場合は、アンダースコア文字で区切られます。 |
| 既存ファイルを上書き | ファイルがすでに存在する場合は、現在のデータで上書きします。選択しない場合は、代わりにデータが追加されます。データを追加する場合、各ブロックは、Tealiumから送信されたデータを含むペイロードが格納された単一のJSONオブジェクトの配列またはCSV行で構成されます。 |
| レコードサフィックス | 区切り文字として使用するために各レコードの末尾に追加されるサフィックスです。デフォルト：改行（`\n`）。JSON形式のファイルにのみ適用されます。 |
| ファイルを圧縮 | gzipを使用してファイルを圧縮するように構成します。**既存ファイルを上書き**が`false`に構成されている場合、このオプションは無視されます。 |

#### バッチ構成

| **パラメータ** | **説明** |
| --- | --- |
| バッチの有効期間 | バッチアクションを送信する頻度を指定するため、有効期間（TTL）を構成します。`1`から`60`までの値を入力します。デフォルト：`15`。 |
| 最大ファイルサイズ | 圧縮前の最大ファイルサイズ（MB）です。`1`から`200`までの値を構成します。デフォルト値は`90`です。 |
| 属性名を出力 | デフォルトでは、オブジェクトデータのキーとして属性IDが使用されます。代わりに属性名をキーとして使用するには、このオプションを選択します。属性名を変更すると、保存されるデータのキーがファイル間で異なり、不整合が発生する可能性があることに注意してください。 |
