## API情報

このコネクタは以下のベンダーAPIを使用します：

* API名：Skai API
* APIバージョン：v1
* APIエンドポイント：`https://{subdomain}.xg4ken.com`

## 構成

コネクタマーケットプレイスに移動して新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の構成を構成します：

* **サブドメイン**：オンボーディング中に提供されたSkaiのサブドメインで、リクエストホスト `https://{subdomain}.xg4ken.com/...`（例：`1234`）を構築するために使用されます。
* **トークン**：オンボーディングからのSkaiセキュアトークン。この値は`token`クエリパラメータとしてコネクタによって送信されます。イベントごとにこの値を上書きするには、イベントレベルのマッピングを追加します。

## アクション

| アクション名 | AudienceStream | EventStream |
| --- | :---: | :---: |
| コンバージョンを送信 | ✓ | ✓ |
| クリックを送信 | ✓ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションの構成方法について説明します。

### コンバージョンを送信

#### イベントデータ

| パラメータ | 説明 |
| --- | --- |
| コンバージョンタイプ | 100文字までの文字列（例：`sale`, `purchase`, `signup`）。 |
| 収益 | 通貨記号なしの数値（整数または小数）。 |
| 通貨 | 通貨コード（例：`USD`）。 |
| 注文ID | 64文字までの文字列。Skaiでは、24時間以内に重複する`orderId + conversionType`の組み合わせの重複を排除するために使用されます。 |
| プロモーションコード | オプション。1024文字までのフリーテキスト。 |
| Skai UUID | UUID文字列（`k_user_id`）。ユーザーIDが利用できない場合は空にすることがあります。**ユーザーID**と**Skai UUID**の両方がマッピングされている場合、**Skai UUID**が優先されます。 |
| ユーザーID | コネクタがSkai互換のUUID（MD5ハッシュとしてフォーマットされた`8-4-4-4-12`）に変換する生のユーザー識別子。UUIDを既に生成していない場合にこの値を使用します。 |
| トークン | Skaiセキュアトークン。コネクタ構成値がデフォルトです。イベントレベルのマッピングでこの値をイベントごとに上書きします。 |

#### 追加パラメータ

| パラメータ | 説明 |
| --- | --- |
| ken_gclid | Google Click ID（`gclid`）。Google広告がユーザーが広告をクリックしたときにURLに追加する一意のトラッキングパラメータ。利用可能な場合、`gclid`クエリパラメータまたはクッキーパラメータから自動マッピングされます。 |
| ken_msclkid | Microsoft Click ID（`msclkid`）。Microsoft AdvertisingがランディングページのURLに追加する一意の32文字のトラッキングパラメータ。利用可能な場合、`msclkid`クエリパラメータまたはクッキーパラメータから自動マッピングされます。 |

#### SKU詳細

注文内の各SKUについて、製品ごとの数量と収益データを送信するために製品SKU配列をマッピングします。たとえば、`quantity_56549611915=3&revenue_56549611915=149.97`として、コネクタは各SKUに対して`quantity_[sku]`と`revenue_[sku]`を別々のクエリパラメータとして送信します。

#### カテゴリ集計

オプション。カテゴリ名をアイテム数にマッピングします（例：`cameras=3`, `accessories=3`）。これにより、コンバージョンリクエストにカテゴリレベルのデータが送信されます。コネクタはこれらの値をクエリ文字列にフラット化します。

#### 自動マッピング

| パラメータ | 説明 |
| --- | --- |
| Eコマース自動マッピングを無効にする | 有効にすると、標準のeコマース属性`tealium_event`, `_csubtotal`, `_ccurrency`, `_corder`, `_cpromo`がSkaiのコンバージョンパラメータ`conversionType`, `revenue`, `currency`, `orderId`, `promoCode`に自動マッピングされません。 |
| 識別子自動マッピングを無効にする | 有効にすると、識別子属性`skai_k_user_id`, `gclid`, `msclkid`がSkaiパラメータ`k_user_id`, `ken_gclid`, `ken_msclkid`に自動マッピングされません。 |

### クリックを送信

#### イベントデータ

| パラメータ | 説明 |
| --- | --- |
| Skai UUID | UUID文字列（`k_user_id`）、コンバージョンと一致します。**ユーザーID**と**Skai UUID**の両方がマッピングされている場合、**Skai UUID**が優先されます。 |
| ユーザーID | コネクタがSkai互換のUUID（MD5ハッシュとしてフォーマットされた`8-4-4-4-12`）に変換する生のユーザー識別子。UUIDを既に生成していない場合にこの値を使用します。 |
| リダイレクトURL | 最後のクエリパラメータとして追加されるリダイレクトURL。デフォルトは`http://dummyfortracking.skai.com`です。 |
| prof | SkaiプロファイルID。 |
| camp | SkaiキャンペーンID。 |
| kct | Skaiチャンネルタイプ。 |
| kchid | SkaiチャンネルID。 |
| criteriaid | キーワードID、オーディエンスID、または製品グループID。 |
| campaignid | パブリッシャーキャンペーンID。 |
| locphy | パブリッシャーからのユーザーの物理的な位置。 |
| adgroupid | 広告グループID。 |
| adpos | 広告位置。 |
| cid | 広告ID。 |
| networkType | ネットワークタイプ：`Search`または`Content`。 |
| kdv | デバイスタイプ：`mobile`, `desktop`, `tablet`。 |
| kext | 広告拡張ID。 |
| kpg | 製品グループID。Microsoftのみ。 |
| kadtype | 広告タイプ。 |
| kmc | ショッピングキャンペーンのためのマーチャントID。 |
| kpid | ショッピングキャンペーンのための製品ID。 |
| queryStr | 検索用語。Microsoftのみ。 |
| npclid | オプションのパブリッシャークリックID（例：`gclid`または`msclkid`）。パブリッシャー側の最適化（例：スマートビディング）のためにパブリッシャーにコンバージョンデータを返すために使用します。 |
| 追加パラメータ | オプション。クリックイベントのために追加のクエリパラメータを通過させます。 |

#### 自動マッピング

| パラメータ | 説明 |
| --- | --- |
| 識別子自動マッピングを無効にする | 有効にすると、派生した`skai_k_user_id`属性がSkaiの`k_user_id`パラメータに自動マッピングされません。 |
