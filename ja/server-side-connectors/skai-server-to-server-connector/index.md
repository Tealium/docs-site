## API 情報

このコネクタは、次のベンダー API を使用します。

* API 名: Skai API
* API バージョン: v1
* API エンドポイント: `https://{subdomain}.xg4ken.com`

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **サブドメイン**: オンボーディング時に提供される Skai サブドメインです。リクエストホスト `https://{subdomain}.xg4ken.com/...` の構築に使用されます（例: `1234`）。
* **トークン**: オンボーディング時に提供される Skai セキュアトークンです。コネクタは、この値を `token` クエリパラメータとして送信します。イベントごとにこの値を上書きするには、イベントレベルのマッピングを追加します。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| コンバージョンを送信 | ✓ | ✓ |
| クリックを送信 | ✓ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### コンバージョンを送信

#### イベントデータ

| パラメータ | 説明 |
| --- | --- |
| コンバージョンタイプ | 最大 100 文字の文字列（例: `sale`、`purchase`、`signup`）。 |
| 収益 | 数値（整数または小数）。通貨記号は含めません。 |
| 通貨 | `USD` などの通貨コード。 |
| 注文 ID | 最大 64 文字の文字列。Skai は、24 時間以内に発生した重複する `orderId + conversionType` の組み合わせを重複排除するために使用します。 |
| プロモーションコード | 任意。最大 1024 文字の自由形式テキスト。 |
| Skai UUID | UUID 文字列（`k_user_id`）。ユーザー ID を使用できない場合は空にできます。両方がマッピングされている場合、**ユーザー ID** より優先されます。 |
| ユーザー ID | コネクタによって `k_user_id` 用の Skai 互換 UUID（`8-4-4-4-12` 形式の MD5 ハッシュ）に変換される未加工のユーザー識別子。UUID をまだ生成していない場合は、この値を使用します。 |
| トークン | Skai セキュアトークン。デフォルトではコネクタ構成の値が使用されます。イベントレベルのマッピングを使用して、イベントごとにこの値を上書きできます。 |

#### 追加パラメータ

| パラメータ | 説明 |
| --- | --- |
| ken_gclid | Google クリック ID（`gclid`）。ユーザーが広告をクリックしたときに、Google 広告によって URL に追加される一意のトラッキングパラメータ。使用可能な場合は、`gclid` クエリパラメータまたは Cookie パラメータから自動的にマッピングされます。 |
| ken_msclkid | Microsoft クリック ID（`msclkid`）。Microsoft Advertising によってランディングページ URL に追加される、一意の 32 文字のトラッキングパラメータ。使用可能な場合は、`msclkid` クエリパラメータまたは Cookie パラメータから自動的にマッピングされます。 |

#### SKU の詳細

商品 SKU の配列をマッピングし、商品ごとの数量および収益データを送信します。注文内の各 SKU について、コネクタは `quantity_[sku]` と `revenue_[sku]` を個別のクエリパラメータとして送信します。例: `quantity_56549611915=3&revenue_56549611915=149.97`。

#### カテゴリ集計

任意。カテゴリ名を商品数にマッピングし（例: `cameras=3`、`accessories=3`）、コンバージョンリクエストでカテゴリレベルのデータを送信します。コネクタは、これらの値をフラット化してクエリ文字列に追加します。

#### 自動マッピング

| パラメータ | 説明 |
| --- | --- |
| E コマース自動マッピングを無効化 | 有効にすると、標準の E コマース属性 `tealium_event`、`_csubtotal`、`_ccurrency`、`_corder`、`_cpromo` は、Skai のコンバージョンパラメータ `conversionType`、`revenue`、`currency`、`orderId`、`promoCode` に自動マッピングされません。 |
| 識別子の自動マッピングを無効化 | 有効にすると、識別子属性 `skai_k_user_id`、`gclid`、`msclkid` は、Skai のパラメータ `k_user_id`、`ken_gclid`、`ken_msclkid` に自動マッピングされません。 |

### クリックを送信

#### イベントデータ

| パラメータ | 説明 |
| --- | --- |
| Skai UUID | コンバージョンと一貫性のある UUID 文字列（`k_user_id`）。両方がマッピングされている場合、**ユーザー ID** より優先されます。 |
| ユーザー ID | コネクタによって `k_user_id` 用の Skai 互換 UUID（`8-4-4-4-12` 形式の MD5 ハッシュ）に変換される未加工のユーザー識別子。UUID をまだ生成していない場合は、この値を使用します。 |
| リダイレクト URL | 最後のクエリパラメータとして追加されるリダイレクト URL。デフォルトは `http://dummyfortracking.skai.com` です。 |
| prof | Skai プロファイル ID。 |
| camp | Skai キャンペーン ID。 |
| kct | Skai チャネルタイプ。 |
| kchid | Skai チャネル ID。 |
| criteriaid | キーワード ID、オーディエンス ID、または商品グループ ID。 |
| campaignid | パブリッシャーのキャンペーン ID。 |
| locphy | パブリッシャーから提供されるユーザーの物理的な位置情報。 |
| adgroupid | 広告グループ ID。 |
| adpos | 広告の掲載位置。 |
| cid | 広告 ID。 |
| networkType | ネットワークタイプ: `Search` または `Content`。 |
| kdv | デバイスタイプ: `mobile`、`desktop`、または `tablet`。 |
| kext | 広告表示オプション ID。 |
| kpg | 商品グループ ID。Microsoft のみ。 |
| kadtype | 広告タイプ。 |
| kmc | ショッピングキャンペーンのマーチャント ID。 |
| kpid | ショッピングキャンペーンの商品 ID。 |
| queryStr | 検索語句。Microsoft のみ。 |
| npclid | 任意のパブリッシャークリック ID（例: `gclid` または `msclkid`）。スマート自動入札など、パブリッシャー側の最適化に使用するコンバージョンデータをパブリッシャーへ返す場合に使用します。 |
| 追加パラメータ | 任意。クリックイベントに追加する任意のクエリパラメータをそのまま渡します。 |

#### 自動マッピング

| パラメータ | 説明 |
| --- | --- |
| 識別子の自動マッピングを無効化 | 有効にすると、派生した `skai_k_user_id` 属性は Skai の `k_user_id` パラメータに自動マッピングされません。 |
