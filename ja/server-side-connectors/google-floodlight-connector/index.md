Google Floodlightコネクタは、Google Campaign Manager 360 APIを通じて、オフラインコンバージョンをFloodlightのコンバージョントラッキングおよびアトリビューションシステムに挿入します。


<blockquote>
Floodlightは、Google Marketing Platform全体で使用されるコンバージョントラッキングシステムです。すべてのGMP製品（Campaign Manager 360*、Search Ads 360、Display & Video 360）で、コンバージョンの測定にFloodlightを使用できます。
</blockquote>


## 要件

* Campaign Manager 360（CM360）アカウントが必要です。
* CM360アカウントでAPIアクセスが有効になっている必要があります。
* Floodlightトラッキングに使用する広告主アカウントへのアクセス権を持つCM360ユーザープロファイルが必要です。
* コンバージョンデータへのアクセスを許可するには、CM360アカウントで次のOAuthスコープを有効にします：`https://www.googleapis.com/auth/ddmconversions`。
* **api@tealium.com**ユーザーをアカウントに追加し、**Insert offline conversions**権限を付与してCM360アカウントへのアクセスを許可します。
* **api@tealium.com**ユーザーをCM360アカウントに追加した後、生成されたプロファイルIDをコネクタの構成ページまたはアクションページで使用します。両方で定義されている場合は、アクションページで定義されたプロファイルIDが優先されます。

## API情報

このコネクタでは、次のベンダーAPIを使用します。

* API名：Google Campaign Manager 360 API
* APIバージョン：v5
* APIエンドポイント：`https://www.googleapis.com/dfareporting/`
* ドキュメント：[Campaign Manager 360 API](https://developers.google.com/doubleclick-advertisers/rest/v5)

### バッチ制限

このコネクタでは、ベンダーへの大量のデータ転送をサポートするため、リクエストをバッチ処理します。並列処理により、イベントが順不同でベンダーに到達する可能性があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに保持されます。

* リクエストの最大数：1000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：1 MB

## 遅延アクション

Googleのベストプラクティスに従い、オフラインコンバージョンのアップロードに対応するため、アクションは30分間遅延されます。Google Campaign Manager 360 Floodlightコネクタでの遅延アクションの詳細については、[Google：オフラインコンバージョンをアップロードする際のベストプラクティス](https://support.google.com/campaignmanager/answer/2823388?hl=en)を参照してください。


<blockquote>
EventStreamまたはCustomer Data Platform（CDP）で[トレース](https://docs.tealium.com/about-trace/)を使用する場合、アクションは遅延されません。
</blockquote>


## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を行います。

* **FloodlightプロファイルID**  
  * `api@tealium.com`ユーザーをCampaign Manager 360アカウントに追加した後、Campaign Manager 360から提供されるFloodlightプロファイルIDです。

コネクタを構成したら、**完了**をクリックします。


<blockquote>
このコネクタを追加すると、ベンダーのデータプラットフォームポリシーへの同意を求められます。
</blockquote>


## アクション

| アクション名 | ビジタープロファイル | イベントデータ |
| --- | :---: | :---: |
|Floodlightコンバージョンをトラッキング| ✓| ✓|

**続行**をクリックして、コネクタのアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### Floodlightコンバージョンをトラッキング

#### 構成IDパラメータ

|パラメータ| 説明|
|---| ---|
|プロファイルID| **api@tealium.com**ユーザーをCM360アカウントに追加した後、CM360から提供されるFloodlightプロファイルIDです。ここで構成した場合、この値は「構成」で定義された値によって上書きされます。 |
|Floodlight構成ID| （必須）このコンバージョンのFloodlight構成IDです。 |
|FloodlightアクティビティID| （必須）このコンバージョンのFloodlightアクティビティIDです。 |

#### ユーザー／デバイスID

* 複数の属性がマッピングされている場合、空でない最初の値が送信されます。
* すべてのコンバージョンは30分の遅延後に送信されます。

|パラメータ| 説明|
|---| ---|
|暗号化されたユーザーID| 1つ以上の暗号化されたユーザーIDを指定する場合は、暗号化エンティティタイプ、ID、およびソースの各セクションが必須です。 |
|モバイルデバイスID| 単一のデバイスID、単一のクリックID、単一のユーザーID、マッチID、または複数のユーザー候補IDを指定します。単一のユーザー候補IDパラメータに、候補IDのリストを使用することもできます。 |
|GoogleクリックID| 単一のデバイスID、単一のクリックID、単一のユーザーID、マッチID、または複数のユーザー候補IDを指定します。単一のユーザー候補IDパラメータに、候補IDのリストを使用することもできます。 |
|ディスプレイクリックID| 単一のデバイスID、単一のクリックID、単一のユーザーID、マッチID、または複数のユーザー候補IDを指定します。単一のユーザー候補IDパラメータに、候補IDのリストを使用することもできます。 |
|マッチID| 単一のデバイスID、単一のクリックID、単一のユーザーID、マッチID、または複数のユーザー候補IDを指定します。単一のユーザー候補IDパラメータに、候補IDのリストを使用することもできます。 |
|インプレッションID| 単一のデバイスID、単一のクリックID、単一のユーザーID、マッチID、または複数のユーザー候補IDを指定します。単一のユーザー候補IDパラメータに、候補IDのリストを使用することもできます。 |

#### 追加パラメータ

|パラメータ| 説明|
|---| ---|
|序数| （必須）コンバージョンの序数です。同じユーザーかつ同じ日のコンバージョンを重複排除するために使用されます。 |
|マイクロ秒単位のタイムスタンプ| Unixエポックからのマイクロ秒単位のコンバージョンタイムスタンプです。指定しない場合は自動生成されます。 |
|広告トラッキングを制限| コンバージョンをターゲティングには使用せず、レポートのみに使用するには、`true`に構成します。 |
|子ども向けの取り扱い| 子どもを対象としたコンバージョンの場合は、`true`に構成します。 |
|非パーソナライズド広告| 非パーソナライズド広告のコンバージョンである場合は、`true`に構成します。 |
|未成年者向けの取り扱い| リクエストが未成年ユーザーから送信された可能性がある場合は、`true`に構成します（GDPRを参照）。 |
#### ユーザー識別子

| **パラメーター** | **説明** |
| --- | --- |
| メールアドレス（SHA256 でハッシュ化済み） | 前後の空白を削除し、小文字に変換して、SHA256 でハッシュ化済みのメールアドレスを指定します。`gmail.com` および `googlemail.com` のメールアドレスについては、ハッシュ化する前にドメイン名より前にあるすべてのピリオド（`.`）を削除してください。 |
| メールアドレス（SHA256 ハッシュを適用） | プレーンテキストのメールアドレスを指定します。コネクターは、`gmail.com` および `googlemail.com` のメールアドレスについてドメイン名より前にあるすべてのピリオド（`.`）を削除し、前後の空白を削除して小文字に変換した後、この値を SHA256 でハッシュ化します。 |
| 電話番号（SHA256 でハッシュ化済み） | 前後の空白を削除し、SHA256 でハッシュ化済みの電話番号を指定します。 |
| 電話番号（SHA256 ハッシュを適用） | プレーンテキストの電話番号を指定します。コネクターは数字以外のすべての記号を削除し、番号の先頭にプラス記号（`+`）をエンリッチメントして前後の空白を削除した後、この値を SHA256 でハッシュ化します。 |
| 住所情報：名（SHA256 でハッシュ化済み） | 前後の空白を削除し、小文字に変換して、SHA256 でハッシュ化済みの名を指定します。 |
| 住所情報：名（SHA256 ハッシュを適用） | プレーンテキストの名を指定します。コネクターは前後の空白を削除し、小文字に変換した後、この値を SHA256 でハッシュ化します。 |
| 住所情報：姓（SHA256 でハッシュ化済み） | 前後の空白を削除し、小文字に変換して、SHA256 でハッシュ化済みの姓を指定します。 |
| 住所情報：姓（SHA256 ハッシュを適用） | プレーンテキストの姓を指定します。コネクターは前後の空白を削除し、小文字に変換した後、この値を SHA256 でハッシュ化します。 |
| 住所情報：番地（SHA256 でハッシュ化済み） | 特殊文字を含まず、前後の空白を削除し、小文字に変換して、SHA256 でハッシュ化済みの住所を指定します。 |
| 住所情報：番地（SHA256 ハッシュを適用） | プレーンテキストの住所を指定します。コネクターはすべての特殊文字を削除し、前後の空白を削除して小文字に変換した後、この値を SHA256 でハッシュ化します。 |
| 住所情報：市区町村 | ユーザーの住所の市区町村。 |
| 住所情報：州 | ユーザーの住所の州コード。 |
| 住所情報：郵便番号 | ユーザーの住所の郵便番号。 |
| 住所情報：国コード | ISO 3166-1 alpha-2 形式による、ユーザーの住所の2文字の国コード。 |

#### 暗号化

|パラメーター| 説明|
|---| ---|
|暗号化エンティティタイプ| 暗号化されたユーザー ID を指定する場合は必須です。広告配信またはデータ転送の暗号化構成と一致している必要があります。 |
|暗号化エンティティ ID| 暗号化されたユーザー ID を指定する場合は必須です。広告配信またはデータ転送の暗号化構成と一致している必要があります。 |
|暗号化ソース| 暗号化されたユーザー ID を指定する場合は必須です。暗号化された Cookie を広告配信とデータ転送のどちらから受信したかを示します。 |

|パラメーター| 説明|
|---| ---|

#### カスタムデータ

必要に応じて属性を `U` カスタム変数にマッピングします。値が構成されているものだけが送信されます。
このセクションのマッピング先を使用すると、**カスタムデータ配列 - レガシー**セクションのマッピングよりも優先されます。

|パラメーター| 説明|
|---| ---|
|カスタム変数値| カスタム値のコレクション。各値は50文字以内である必要があります。 |
|カスタム変数タイプ| 文字列のコレクション。各文字列は `Uxxx` の形式で、`xxx` には `1` から `100` までの数値を指定します。 |

#### カートデータ

| **パラメーター** | **説明** |
| --- | --- |
| 販売者 ID | 商品がアップロードされている Merchant Center の ID。Merchant Center ID を指定すると、正確なオファーの詳細を特定する際の曖昧さが軽減されます。 |
| 販売者フィードラベル | 商品がアップロードされているフィードに関連付けられたフィードラベル。 |
| 販売者フィード言語 | 商品がアップロードされているフィードに関連付けられた言語。ISO 639-1 言語コードを使用します。 |
| 商品 ID | （必須）商品のショッピング ID。Merchant Center の商品識別子と同じである必要があります。 |
| 数量 | （必須）販売された商品の数量。 |
| 単価 | （必須）税金、送料、および取引単位の割引を除いた単価。CM360 Floodlight 構成の親広告主の通貨コードで解釈されます。 |
