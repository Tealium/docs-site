MNTN Audienceコネクタを使用すると、TealiumからMNTNオーディエンスセグメントを作成および管理できます。このコネクタを使用して、ファーストパーティIDをバッチで同期し、手動でのファイルアップロードやカスタムAPIコードを使用することなく、コネクテッドTV（CTV）のターゲティング、リターゲティング、配信除外を目的としてオーディエンスメンバーを追加、更新、または削除できます。



## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：MNTN Audience API
* APIバージョン：v2026.0.1
* APIエンドポイント：`https://integrations.ex.mountain.com`

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **MNTN Audience APIキー**：（必須）MNTN Audience APIキー。

コネクタを構成した後、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| ----------- | :------------: | :---------: |
| オーディエンスメンバーの一括アップサート | ✓ | ✓ |
| オーディエンスメンバーの一括削除 | ✓ | ✓ |

### オーディエンスメンバーの一括アップサート

#### バッチ制限

このアクションでは、ベンダーへの大量のデータ転送に対応するため、バッチリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに格納されます。

* リクエストの最大数：10,000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：2 MB

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| セグメントID | IDを挿入または更新する既存のMNTNオーディエンスセグメントのID。 |
| ID識別子 | （必須）セグメント内のオーディエンスメンバーを一意に識別するID（Tealium訪問IDやCRM IDなど）。 |

#### 識別子

| パラメータ | 説明 |
| --- | --- |
| メール（SHA256を適用） | プレーンテキストのメールアドレス。コネクタが正規化（小文字への変換、前後の空白の除去）し、SHA256ハッシュを適用します。 |
| メール（SHA256適用済み） | ハッシュ化済みのメールアドレス。ハッシュ化する前に、値が小文字に変換され、前後の空白が除去されていることを確認してください。 |
| 電話番号（SHA256を適用） | プレーンテキストの電話番号。コネクタが数字以外の文字を除去し、国番号を先頭にエンリッチメントして、SHA256ハッシュを適用します。 |
| 電話番号（SHA256適用済み） | ハッシュ化済みの電話番号。ハッシュ化する前に数字以外の文字を除去し、米国の10桁の電話番号の場合は先頭に`1`をエンリッチメントしてください。 |
| IPv4 | 未加工のIPv4アドレス。 |
| IPv4（SHA256適用済み） | ハッシュ化済みのIPv4アドレス。 |
| IPv6 | 未加工のIPv6アドレス。 |
| IPv6（SHA256適用済み） | ハッシュ化済みのIPv6アドレス。 |
| MAID | UUID形式の未加工のモバイル広告ID。CTVまたはモバイルのターゲティングに使用します（例：`3f097372-f01e-4b64-984c-395ae5828ee6`）。 |


<blockquote>
IPv4（SHA256適用済み）、IPv6、IPv6（SHA256適用済み）、およびMAIDは、MNTNキャンペーンのターゲティングでのサポートが限定されています。これらの識別子をターゲティングに使用する前に、MNTNアカウントチームにお問い合わせください。
</blockquote>


### オーディエンスメンバーの一括削除

#### バッチ制限

このアクションでは、ベンダーへの大量のデータ転送に対応するため、バッチリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに格納されます。

* リクエストの最大数：1,000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：2 MB

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| オーディエンスセグメント | メンバーを削除するMNTNオーディエンスセグメントを選択するか、セグメントIDを手動で入力します。 |
| ID識別子 | （必須）セグメントから削除するオーディエンスメンバーのID（Tealium訪問IDやCRM IDなど）。 |

## ベストプラクティス

* 本番環境のデータ量にスケールアップする前に、小規模なテストセグメントから開始してください。
* リクエストペイロードを効率的に保ってください。MNTNでは、バッチサイズを約2 MBにし、リクエストの最大サイズである8 MB未満に抑えることを推奨しています。
* 重複または競合するレコードを避けるため、一貫したID戦略を使用してください。
* MNTNに識別子を送信する前に、同意およびプライバシーに関する要件を確認してください。

詳細については、[MNTNヘルプセンター：Tealiumへの接続](https://help.mountain.com/en/articles/14696352-connect-tealium)を参照してください。
