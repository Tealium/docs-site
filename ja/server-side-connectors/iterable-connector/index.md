## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を行います。

* **ホスト**  
    * EUベースのAPIエンドポイントの場合は、**https://app.eu.iterable.com**を選択します。
    * 米国ベースのAPIエンドポイントの場合は、**https://app.iterable.com**を選択します。
* **APIキー**：Iterable APIキーを入力します。

コネクタを構成した後、**完了**をクリックします。

APIキーを確認するには、Iterableサイトの**Iterableコネクタ**メニューで、**Integrations > API Keys**に移動します。

### イベントの追跡（バッチ）

#### バッチ制限

このアクションでは、ベンダーへの大量のデータ転送をサポートするために、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数：1000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：4 MB

#### パラメーター

|パラメーター|説明|
|---|---|
|イベント名|（必須）イベントの名前。|
|作成日時|イベントが発生した時刻（Unixタイムスタンプ）。省略した場合は、現在の処理時刻が使用されます。|
|メールアドレス|ユーザーのメールアドレス。ユーザーを識別するには、**メールアドレス**または**ユーザーID**のいずれかを入力する必要があります。両方を入力した場合は、**メールアドレス**が優先されます。|
|イベントID|入力したIDを持つイベントが存在する場合、そのイベントが更新されます。指定しない場合、新しいIDが自動的に生成され、返されます。このIDは512バイトを超えることはできません。|
|ユーザーID|`updateUser`呼び出しに渡されたユーザーID。|
|キャンペーン|<ul><li>コンバージョンに関連付けられたキャンペーン。</li><li>詳細については、[Iterable：キャンペーンの概要](https://support.iterable.com/hc/en-us/articles/360050203812-Introduction-to-Campaigns-)を参照してください。</li></ul>|
|プロジェクトテンプレート|テンプレートID。詳細については、[Iterable：テンプレートの概要](https://support.iterable.com/hc/en-us/articles/205480315-Introduction-to-Templates-)を参照してください。|
|データフィールド|イベントに関連付けられた追加データ。例：アイテムの金額や数量。同じ名前のイベントでは、同じ名前のデータフィールドは同じ型である必要があります。|
|テンプレート変数|<ul><li>テンプレート変数をデータ入力として指定します。詳細については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。</li><li>ネストされたテンプレート変数には、ドット表記を使用して名前を付けます。例：`items.name`。</li><li>ネストされたテンプレート変数は通常、データレイヤーのリスト属性から作成されます。</li></ul>|
|テンプレート|<ul><li>本文データで参照するテンプレートを指定します。詳細については、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。</li><li>テンプレートは、サポートされているフィールドに二重波括弧を使用して名前で挿入されます。例：`{{SomeTemplateName}}`。</li></ul>|
|APIキーの上書き|コネクタ構成で指定されたAPIキーを上書きするには、APIキーを入力するか、APIキーの属性をマッピングします。|

### ユーザーのアップサート（バッチ）

* リクエストの最大数：1000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：4 MB

#### パラメーター

|パラメーター|説明|
|---|---|
|メールアドレス|ユーザーのメールアドレス。ユーザーIDが構成されたプロファイルがすでに存在する場合を除き、メールアドレスを構成する必要があります。プロファイルがすでに存在する場合は、**ユーザーID**から**メールアドレス**へのルックアップが実行されます。|
|ネストされたオブジェクトをマージ|最上位レベルのオブジェクトを上書きせずにマージします。デフォルト値は`False`です。たとえば、ユーザープロファイルに`{mySettings:{mobile:true}}`が含まれ、連絡先変更フィールドに`{mySettings:{email:true}}`が含まれる場合、結果のプロファイルには`{mySettings:{mobile:true,email:true}}`が含まれます。|
|ユーザーIDを優先|ユーザーがまだ存在しない場合、指定されたユーザーIDで新しいユーザーを作成します。|
|ユーザーID|ユーザーID。**メールアドレス**または**ユーザーID**のいずれかを指定する必要があります。|
|データフィールド|ユーザープロファイルに保存するデータフィールド。|
|テンプレート変数|<ul><li>テンプレート変数をデータ入力として指定します。詳細については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。</li><li>ネストされたテンプレート変数には、ドット表記を使用して名前を付けます。例：`items.name`。</li><li>ネストされたテンプレート変数は通常、データレイヤーのリスト属性から作成されます。</li></ul>|
|テンプレート|<ul><li>本文データで参照するテンプレートを指定します。詳細については、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。</li><li>テンプレートは、サポートされているフィールドに二重波括弧を使用して名前で挿入されます。例：`{{SomeTemplateName}}`。</li></ul>|
|APIキーの上書き|コネクタ構成で指定されたAPIキーを上書きするには、APIキーを入力するか、APIキーの属性をマッピングします。|
