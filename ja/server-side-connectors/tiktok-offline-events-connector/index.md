## API 情報

このコネクタは、次のベンダー API を使用します。

* API 名: TikTok HTTP API
* API バージョン: v1.3
* API エンドポイント: `https://business-api.tiktok.com/open_api/v1.3`
* ドキュメント: [TikTok オフラインイベント API](https://ads.tiktok.com/marketing_api/docs?id=1758427539356673)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **アクセストークン**: （必須）TikTok で構成されたアクセストークン。
* **広告主 ID**: （必須）TikTok 広告マネージャーの広告アカウント ID。詳細については、[TikTok：広告アカウント ID を確認する方法](https://ads.tiktok.com/help/article/find-your-ad-account-id?lang=en)を参照してください。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| オフラインイベントを送信（リアルタイム） | ✗ | ✓ |
| オフラインイベントを送信（バッチ） | ✗ | ✓ |

**続行**をクリックして、コネクタのアクションを構成します。アクションの名前を入力し、**アクションタイプ**を選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### オフラインイベントを送信（リアルタイム）

メールアドレスまたは電話番号のいずれかのパラメータを指定することをお勧めします。

複数の項目を追加するには、**コンテンツ名**、**コンテンツタイプ**、**コンテンツカテゴリ**、**コンテンツ ID**、**数量**、および**価格**にデータ型属性を指定します。配列データ型の属性は、長さを同じにする必要があります。

単一値の属性も使用でき、各項目に適用されます。

**Tealium iQ タグ ID**を構成すると、コネクタはタグ管理から送信された**イベント ID**の値を使用します。

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| イベント名 | （必須）コンバージョンイベント名。 |
| カスタムイベント名 | コンバージョンイベント名。 |
| イベントセット ID | イベントセット ID。 |
| イベント ID | 各イベントに固有の値。この ID を使用して、TikTok とデータを照合できます。 |
| タイムスタンプ | ISO 8601 形式のイベントのタイムスタンプ。例：`2019-06-12T19:11:01:152Z`。タイムスタンプを指定しない場合は、現在のタイムスタンプが使用されます。 |
| メールアドレス（SHA256 でハッシュ化済み） | SHA256 でハッシュ化済みのクリアテキストのメールアドレス（`@`記号を含める必要があります）を指定します。 |
| メールアドレス（SHA256 ハッシュを適用） | プレーンテキストのメールアドレスを指定します。コネクタはこの値の前後の空白を削除し、小文字に変換して、SHA256 でハッシュ化します。 |
| 電話番号（SHA256 でハッシュ化済み） | SHA256 でハッシュ化済みの電話番号を指定します。 |
| 電話番号（SHA256 ハッシュを適用） | プレーンテキストの電話番号を指定します。コネクタはこの値の前後の空白を削除し、SHA256 でハッシュ化します。 |
| 注文 ID | トランザクションの注文 ID。 |
| ショップ ID | トランザクションのショップ ID。 |
| 通貨 | ISO 4217 形式の通貨コード。 |
| 値 | 推奨。すべてのコンテンツの合計収益。 |
| イベントチャネル | 推奨。イベントチャネル。`email`、`website`、`phone_call`、`in_store`、`crm`、`other`をサポートします。 |
| コンテンツ名 | 商品またはコンテンツの名前。複数のコンテンツを追加するには、配列データ型の属性を使用します。 |
| コンテンツタイプ | 商品またはコンテンツのタイプ。 |
| コンテンツカテゴリ | 商品またはコンテンツのカテゴリ。 |
| コンテンツ ID | 商品またはコンテンツの識別子。 |
| 数量 | 項目数。 |
| 価格 | 商品またはコンテンツの価格。 |
| Tealium iQ タグ ID | タグ管理のイベント ID を使用します。 |

### オフラインイベントを送信（バッチ）

メールアドレスまたは電話番号のいずれかのパラメータを指定することをお勧めします。

複数の項目を追加するには、**コンテンツ名**、**コンテンツタイプ**、**コンテンツカテゴリ**、**コンテンツ ID**、**数量**、および**価格**にデータ型属性を指定します。配列データ型の属性は、長さを同じにする必要があります。

単一値の属性も使用でき、各項目に適用されます。

**Tealium iQ タグ ID**を構成すると、コネクタはタグ管理から送信された**イベント ID**の値を使用します。

#### バッチ処理の制限

このアクションは、ベンダーへの大量データ転送をサポートするために、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに入れられます。

* リクエストの最大数：100
* 最も古いリクエストからの最大経過時間：10 分
* リクエストの最大サイズ：10 MB
