## 仕組み

LinkedIn は、LinkedIn 広告主のデータを集約する一元化されたデータ管理プラットフォーム（DMP）を提供しています。DMP セグメントはステージングエンティティとして機能し、サードパーティプロバイダーからユーザー情報を取り込み、その情報を LinkedIn メンバープロファイルにマッピングして、広告セグメントを出力します。出力された広告セグメントは、他の LinkedIn Ads API で使用できます。この連携により、LinkedIn 広告主が保有するユーザー情報と LinkedIn メンバープロファイルをマッピングできます。LinkedIn Matched Audiences コネクタを使用すると、DMP セグメントに追加するユーザーと企業を管理できます。

ハッシュ化されたメールアドレスを使用してユーザーを LinkedIn アカウントと照合し、ターゲティングに使用できます。メールアドレスパラメータでは、コネクタアクションの実行時にハッシュ化できる未ハッシュのメールアドレスのほか、SHA-256 または SHA-512 ですでにハッシュ化されたアドレスもサポートされます。

Android 広告 ID（GAID）や名と姓などの追加識別子を使用して、DMP セグメント内のユーザーを照合できます。有効なユーザー ID が指定されていない場合は、名と姓のパラメータを指定する必要が**あります**。

企業は、企業名、企業ドメイン、企業 Web サイト、または LinkedIn 組織 URN に基づいて照合できます。

### 考慮事項

* セグメントの取得時に、Customer Data Platform（CDP）はドロップダウンの選択肢に DMP セグメントのステータスを表示します。オーディエンスセグメントのステータスメッセージの意味について詳しくは、[DMP セグメントの状態遷移フロー](https://docs.microsoft.com/en-us/linkedin/marketing/integrations/matched-audiences/matched-audiences?view=li-lms-2022-08)を参照してください。
* CDP には、Tealium で作成されたオーディエンスセグメントのみが表示されます。
* キャンペーンで使用できるオーディエンスの最小サイズは 300 メンバーです。
* DMP セグメントの作成後、そのセグメントにユーザーまたは企業を追加できるようになるまで 5 秒待つ必要があります。
* `READY` ステータスではない DMP オーディエンスにユーザーまたは企業を登録できる場合もありますが、`EXPIRED`、`FAILED`、または `ERROR` ステータスのセグメントをキャンペーンのターゲティングに含めたり、ターゲティングから除外したりすることはできません。
* 認証アクセスは 365 日間有効です。認証アクセスの有効期限が切れると、ユーザーは再認証する必要があります。

### マッチ率とオーディエンスサイズ

* `audienceSize` と `matchedCount` の値の微妙な違いを理解することが重要です。セグメントに何らかの変更が発生した場合、マッチ数と入力数は、過去 7 日間のデータを対象とするローリング方式の 7 日間ウィンドウに基づいて計算されます。
* オーディエンスサイズは、すべての入力データに基づきます。コネクタアクションによって送信されたオーディエンス数は、オーディエンスインサイトに返されるマッチ数と一致しない場合があります。
* マッチ率が高いにもかかわらずオーディエンスサイズが 0 の場合、ターゲットとなるメンバーが LinkedIn でサードパーティによるターゲティングをオプトアウトしている可能性があります。その結果、リストが 300 メンバーのしきい値を下回る場合があります。
* また、オーディエンス数ではオプトアウトが考慮されますが、マッチ数では考慮されません。`audienceSize` と `matchedCount` の値の違いについて詳しくは、[オーディエンスサイズとマッチ数フィールドの違い](https://docs.microsoft.com/en-us/linkedin/marketing/integrations/matched-audiences/create-and-manage-segment-destinations?view=li-lms-2022-08&amp;tabs=http#differences-between-audience-size-and-matched-count-fields)を参照してください。
* 類似セグメントを作成するには、シードセグメントとして使用する DMP セグメントが `READY` ステータスで、オーディエンス数が 200 以上である必要があります。

## API 情報

このコネクタでは、次のベンダー API を使用します。

* API 名：LinkedIn API
* API バージョン：202601
* API エンドポイント：`https://api.linkedin.com/rest`
* ドキュメント：[LinkedIn Marketing API](https://docs.microsoft.com/en-us/linkedin/marketing/)

## バッチ制限

このコネクタでは、ベンダーへの大量データ転送をサポートするために、リクエストをバッチ処理します。詳しくは、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに保持されます。

* リクエストの最大数：5000。
* レート制限：ユーザーアクションの場合はユーザーごとに 500 リクエスト、企業アクションの場合はユーザーごとに 200 リクエスト。
* 最も古いリクエストからの最大経過時間：60 分。
* リクエストの最大サイズ：100 MB。

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

## DMP セグメントの作成

DMP セグメントはステージングエンティティとして機能し、Tealium からユーザー情報を取り込み、その情報を LinkedIn メンバープロファイルにマッピングして、広告セグメントを出力します。出力された広告セグメントは、他の LinkedIn Ads API で使用できます。DMP セグメントは、スポンサーアカウントに関連付けられます。

DMP セグメントユーザーは DMP セグメントのサブリソースであり、DMP セグメントにユーザーを追加できます。

### パラメータ

|パラメータ|説明|
|---|---|
|セグメント名|（必須）LinkedIn Ads アカウントに表示する DMP セグメントの名前。|
|セグメントタイプ|（必須）ユーザープロファイルのインポート元となるソースプラットフォームを選択します。次のタイプをサポートします。<ul><li>**標準** - Ads アカウントに Tealium 提供のリストとして登録します。</li><li>**類似** - 既存のオーディエンスセグメントに基づいて、広告主がオーディエンスグループを拡張できます。</li></ul>|
|セグメントの説明|（任意）DMP セグメントの説明。|
|ソースセグメント ID|（任意）<ul><li>このフィールドは、類似セグメントタイプにのみ適用されます。</li><li>ソースプラットフォーム上の外部キーです。このフィールドは任意であり、インデックスが作成されるため、ソースプラットフォームがセグメントを検索する際に使用できます。</li></ul>|
|セグメントコンテンツタイプ|DMP セグメントにインポートされるプロファイルのコンテンツタイプ。<ul><li>デフォルトのコンテンツタイプ：`USER`。</li><li>ユーザーリストと企業リストをサポートします。</li></ul>|

## 類似シードセグメントの作成

DMP セグメントの類似機能は、通常、リーチを拡大したい広告主に役立ちます。広告主は既存のオーディエンスセグメントに基づき、DMP セグメントの類似機能を利用してオーディエンスグループを拡張できます。DMP セグメントの類似機能では、既存の広告セグメントをシードとして取り込み、シードオーディエンスに類似するオーディエンスを構築します。この処理には最大 48 時間かかる場合があります。

シードとして使用するには、オーディエンス数が 300 以上で `READY` ステータスの DMP セグメント（Web サイトのリターゲティングの場合は adSegment）が必要です。

### パラメータ

|パラメータ|説明|
|---|---|
|類似セグメント|（必須）作成する類似セグメントの名前。|
|シード DMP セグメント|（必須）シードオーディエンスに類似するオーディエンスを作成するため、シードとして使用する DMP セグメントを選択します。<ul><li>シードとして使用するには、DMP セグメントが `READY` ステータスで、オーディエンス数が 200 以上である必要があります。</li></ul>|

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳しくは、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **広告アカウント**  
（必須）スポンサーアカウントに対応する広告アカウント ID を選択します。

コネクタの構成が完了したら、**完了**をクリックします。
