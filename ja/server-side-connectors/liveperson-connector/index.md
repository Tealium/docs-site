この記事では、LivePersonコネクタの構成方法について説明します。

## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：LivePerson Proactive Messaging API
* APIバージョン：v1.0
* APIエンドポイント：`https://proactive-messaging.z1.fs.liveperson.com`
* ドキュメント：[LivePerson API](https://developers.liveperson.com/proactive-messaging-api.html)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の項目を構成します。
* **アカウントID**：LivePersonのサイトID
* **クライアントID**：クライアントIDを指定します
* **クライアントシークレット**：クライアントシークレットを指定します
* **APIドメイン**：認証用のAPIドメイン（ホスト）

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| アウトバウンドメッセージを送信 | ✓ | ✓ |
| アウトバウンドメッセージをバッチ送信 | ✓ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### アウトバウンドメッセージを送信

#### メッセージパラメータ

必須パラメータ：

| **パラメータ** | **説明** |
| --- | --- |
| キャンペーン名 | キャンペーンの名前。 |
| スキル | キャンペーンのスキル`ID`。 |
| テンプレートID | キャンペーンのテンプレート`ID`またはハンドオフ`ID`。 |
| 同意 | このキャンペーンを有効にすることにより、企業は、消費者へのメッセージ送信に関して適用されるすべての法律および規制を遵守する責任を負うことを認識し、同意します。 |
| 送信元番号 | 消費者へのメッセージ送信に使用する番号。 |

#### 消費者コンテンツ

| **パラメータ** | **説明** |
| --- | --- |
| 消費者コンテンツ（WA） | 消費者のWhatsApp電話番号。 |
| 消費者コンテンツ（SMS） | 消費者の`SMS`電話番号。 |
| 消費者コンテンツ（Apple） | 消費者のApple `ID`。 |
| 消費者コンテンツ（アプリ内） | 消費者のアプリ内識別子。 |

#### 消費者変数

| **パラメータ** | **説明** |
| --- | --- |
| 変数1～20 | テンプレート内の`consumers.variables.1`～`consumers.variables.20`で使用する変数番号。 |

#### 消費者ヘッダー変数

| ドキュメント | ヘッダーに使用するドキュメントの`URL`。 |

| **パラメータ** | **説明** |
| --- | --- |
| ctype | 顧客タイプ。 |
| 顧客ID | 顧客の`ID`。 |
| 残高 | 顧客の残高。 |
| 通貨 | 顧客の通貨。 |
| ソーシャルID | 顧客のソーシャル`ID`。 |
| IMEI | 顧客の`IMEI`。 |
| ユーザー名 | 顧客のユーザー名。 |
| 会社規模 | 顧客の会社規模。 |
| 会社支店 | 顧客の会社支店。 |
| アカウント名 | 顧客のアカウント名。 |
| 役割 | 顧客の役割。 |
| 最終支払日 | 顧客の最終支払日。日付を文字列形式で送信するには、`yyyy-MM-dd`のパターンを使用します。 |
| 登録日 | 顧客の登録日。日付を文字列形式で送信するには、`yyyy-MM-dd`のパターンを使用します。 |

### アウトバウンドメッセージをバッチ送信

#### バッチ制限

このアクションでは、ベンダーへの大量データ転送をサポートするためにバッチリクエストを使用します。次のいずれかのしきい値に達するまで、リクエストはキューに追加されます。

* リクエストの最大数：100
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：1 MB
