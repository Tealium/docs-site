## 構成

コネクターマーケットプレイスに移動し、新しいコネクターを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクターを追加した後、次の項目を構成します。
* **APIキー**  
  * CampaignerのAPIキー。購読者を追加、更新、または削除するために必要です。
* **インテグレーションキー**  
  * Campaignerのインテグレーションキー。連絡先のアップサートアクションに必要です。

コネクターを構成した後、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| 連絡先をアップサート | ✓ | ✗ |
| 購読者を追加 | ✓ | ✗ |
| 購読者を更新 | ✓ | ✗ |
| 購読者を削除 | ✓ | ✗ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

以降のセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。

### 連絡先をアップサート

#### 連絡先

| **パラメーター** | **説明** |
| --- | --- |
| 再購読 | 連絡先をメールチャネル、SMSチャネル、またはその両方に再購読させるには、`true`に構成します。 |
| 連絡先ID | Campaignerによって割り当てられた連絡先ID。指定すると、この連絡先の情報が更新されます。省略すると、主キーフィールドによって更新または挿入のどちらを行うかが決まります。 |

#### カスタムフィールド

次のフィールドには文字列の配列をマッピングします。文字列をマッピングした場合、その文字列は要素数1の配列として扱われます。

| **パラメーター** | **説明** |
| --- | --- |
| フィールドID | カスタムフィールドの一意の識別子。 |
| 値 | 連絡先のカスタムフィールドの値。 |
| リストID | この購読者に関連付けるリストID。リストを割り当てるには、チェックボックスを選択します。 |

#### 静的フィールド

| **パラメーター** | **説明** |
| --- | --- |
| メール | 連絡先のメールアドレス。 |
| 名 | 連絡先の名。 |
| 姓 | 連絡先の姓。 |
| 電話番号 | 連絡先の電話番号。 |
| 携帯電話番号 | 連絡先の携帯電話番号。 |
| FAX | 連絡先のFAX番号。 |
| メールメッセージ形式 | 連絡先が希望するメールメッセージ形式。 |
| メールステータス | 連絡先のメールステータス。 |
| SMSステータス | 連絡先のSMSステータス。 |
| テスト連絡先 | この連絡先がテスト用の連絡先としてマークされているかどうか。 |
| 所有者のメール | 連絡先の所有者のメールアドレス。 |
| 所有者の名 | 連絡先の所有者の名。 |
| 所有者の姓 | 連絡先の所有者の姓。 |

#### ワークフローのトリガー

| **パラメーター** | **説明** |
| --- | --- |
| すべてのワークフローをトリガー | この連絡先の作成または更新後に、Campaignerですべての該当するワークフローをトリガーする場合は、`true`に構成します。デフォルトは`false`です。 |
| 特定のワークフローをトリガー | この連絡先の作成または更新時にトリガーするワークフローIDの配列。`triggerAllWorkflows`が`true`に構成され、`triggerSpecificWorkflows`にも値が指定されている場合はエラーが発生します。 |

### 購読者を追加

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| メールアドレス | 購読者のメールアドレス。 |

#### カスタムフィールド

次のフィールドには文字列の配列をマッピングします。文字列をマッピングした場合、その文字列は要素数1の配列として扱われます。

| **パラメーター** | **説明** |
| --- | --- |
| フィールド名 | データベースの列名。 |
| 値 | データベースの列値。 |
| ソースID | この購読者に関連付けるソースのID。指定しない場合は、最初のソースが使用されます。 |
| パブリケーション | 購読者に関連付けるパブリケーションID。パブリケーションを指定しない場合、購読者は非アクティブになり、キャンペーンを受信しません。購読者が以前にパブリケーションから削除されている場合、「パブリケーションを強制」が`true`に構成されていない限り、再追加されません。 |
| リストID | この購読者に関連付けるリストID。 |

#### 注文データ

| **パラメーター** | **説明** |
| --- | --- |
| SKU | 商品のSKU。 |
| 数量 | 購入された商品の数量。デフォルトは`1`です。 |
| 重量 | 注文明細の合計重量。デフォルトは`0`です。 |
| ステータス | 注文明細のステータス。 |
| 注文番号 | 注文番号。 |
| 購入日 | 注文が行われた日付。`YYYY-MM-DD`形式（UTC）で指定します。指定しない場合は、現在の日付がデフォルトになります。 |
| 商品名 | 商品の名前。 |
| 単価 | 1単位当たりの価格。デフォルトは`0`です。 |

#### 強制

| **パラメーター** | **説明** |
| --- | --- |
| 強制 | 以前に削除された、またはバウンスした購読者を追加するには、`true`に構成します。`false`に構成するか指定しない場合、購読者は追加されず、`HTTP 400 Bad Request `エラーが返されます。オプトアウトした購読者を追加しないよう、このオプションは慎重に使用してください。 |
| パブリケーションを強制 | 以前に削除を要求したパブリケーションにこの購読者を強制的に戻すには、`true`に構成します。 |
