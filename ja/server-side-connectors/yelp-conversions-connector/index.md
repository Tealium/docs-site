## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Yelp API
* APIバージョン：v3
* APIエンドポイント：`https://api.yelp.com/v3/conversion`
* ドキュメント：[Yelp API](https://docs.developer.yelp.com/docs/conversions-api)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。

* **APIキー** &ndash;（必須）アプリケーションのAPIキー。APIキーはリクエストにエンリッチメントされます。Yelp Adsのアプリケーション構成で確認できます。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| コンバージョンを送信（リアルタイム） | ✗ | ✓ |
| コンバージョンを送信（バッチ） | ✗ | ✓ |

アクションの名前を入力し、ドロップダウンリストからアクションタイプを選択します。

以下のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### コンバージョンを送信（リアルタイム）

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| イベント名 | コンバージョントラッキングイベントのタイプ。ドロップダウンリストから値を選択するか、カスタム文字列値を入力します。アトリビューション処理中の集計に使用されます。また、重複排除処理では`event_id`と組み合わせて使用されます。 |

#### コンバージョンイベントのパラメータ

| **パラメータ** | **説明** |
| --- | --- |
| イベントID | 重複排除処理で使用される、コンバージョンの一意の識別子。 |
| イベント日時 | コンバージョンイベントが発生した過去の日時。 |
| アクションソース | コンバージョンが発生した場所を示します。現在は`app`、`physical_store`、`website`に限定されています。 |

| 名 |（SHA256でハッシュ化済み）SHA256でハッシュ化された名を指定します。 |

| 姓 |（SHA256でハッシュ化済み）SHA256でハッシュ化された姓を指定します。 |
| 電話番号 |（SHA256ハッシュを適用）プレーンテキストの電話番号を指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、SHA256でハッシュ化します。 |
| 電話番号 |（SHA256でハッシュ化済み）SHA256でハッシュ化された電話番号を指定します。 |
| 生年月日 |（SHA256ハッシュを適用）顧客の生年月日を`YYYYMMDD`形式で指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、SHA256でハッシュ化します。 |
| 生年月日 |（SHA256でハッシュ化済み）`YYYYMMDD`形式の、SHA256でハッシュ化された顧客の生年月日を指定します。 |
| 性別 |（SHA256ハッシュを適用）顧客の性別を1文字（女性、男性、ノンバイナリーを表す`f`、`m`、`n`のいずれか）で指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、SHA256でハッシュ化します。 |

| 国 |（SHA256でハッシュ化済み）SHA256でハッシュ化された国コードを指定します。 |
| 州 |（SHA256ハッシュを適用）プレーンテキストの州を指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、SHA256でハッシュ化します。 |

| 郵便番号 |（SHA256でハッシュ化済み）SHA256でハッシュ化された郵便番号を指定します。 |
| 市区町村 |（SHA256ハッシュを適用）プレーンテキストの市区町村を指定します。コネクタは、スペースと句読点、および前後の空白を削除して小文字に変換し、この値をSHA256でハッシュ化します。 |
| 市区町村 |（SHA256でハッシュ化済み）SHA256でハッシュ化された市区町村を指定します。 |
| 外部ID |（SHA256ハッシュを適用）コンバージョンユーザーに関連付けられた任意の一意のID（会員ID、ロイヤルティIDなど）を指定します。コネクタは、スペースと句読点、および前後の空白を削除して小文字に変換し、この値をSHA256でハッシュ化します。 |
| 外部ID |（SHA256でハッシュ化済み）コンバージョンユーザーに関連付けられた一意のID（会員ID、ロイヤルティIDなど）をSHA256でハッシュ化して指定します。 |

| MADID | 顧客のモバイル広告ID（IDFA／AAID）。モバイルイベントにのみ使用します。 |

#### カスタムコンバージョンデータ

| **パラメータ** | **説明** |
| --- | --- |
| 値 | コンバージョンの合計金額。このパラメータはROASを算出するための必須フィールドであるため、`event_name`の値が`purchase`の場合は必ず含める必要があります。 |
| 通貨 | 通貨には、有効なISO 4217の3桁通貨コードを指定する必要があります。現在は`USD`に限定されています。 |
| 注文ID | コンバージョンイベントのトランザクションIDまたは注文ID。 |
| コンテンツカテゴリー | コンバージョンが属するカスタムカテゴリー。 |
| コンテンツID | このコンバージョンに関連付けられたサブアイテムID。同じ購入に含まれるすべての商品のSKU IDなどを指定できます。 |
| カスタムコンバージョンコンテンツ | このコンバージョンの内容に関する追加情報をJSONオブジェクト形式で指定します。 |

### コンバージョンを送信（バッチ）

#### バッチ制限

このアクションでは、ベンダーへの大量データ転送に対応するため、バッチリクエストを使用します。次のいずれかのしきい値に達するまで、リクエストはキューに保持されます。

* リクエストの最大数：1,000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：2 MB
