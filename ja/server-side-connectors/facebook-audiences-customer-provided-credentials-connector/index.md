この記事では、Facebook Audiences 顧客提供認証情報コネクタを構成する方法について説明します。

## 前提条件

Facebook アプリの作成について詳しくは、[Facebook：アプリ開発](https://developers.facebook.com/docs/apps/)を参照してください。

コネクタを構成する前に、以下の手順を実行します。

1. [Facebook カスタムオーディエンス利用規約](https://www.facebook.com/ads/manage/customaudiences/tos.php)に同意します。
1. Facebook アカウントに次のリダイレクト URI を追加します：`https://my.tealiumiq.com/oauth/facebook/callback.html`。Facebook アプリダッシュボードで、**Facebookログイン > 構成**に移動し、**Facebookアプリの有効なOAuthリダイレクトURI**に URI を入力します。
1. Facebook アプリで `ads_management` 権限をリクエストします。`ads_management` 権限により、アプリは自身が所有する広告アカウント、または広告アカウントの所有者からアクセス権を付与された広告アカウントの読み取りと管理の両方を行うことができます。詳しくは、[Facebook：アクセス許可のリファレンス](https://developers.facebook.com/docs/facebook-login/permissions/#reference-ads_management)を参照してください。

より高いレート制限など、より多くのアプリリソースを利用するには、広告管理の**標準アクセス**をリクエストします。詳しくは、[Facebook：アクセスと認証](https://developers.facebook.com/docs/marketing-api/access/)を参照してください。

## API 情報

このコネクタは、次のベンダー API を使用します。

* API 名：Facebook Graph API - Marketing API
* API バージョン：v25.0
* API エンドポイント：`https://graph.facebook.com`

## バッチ制限
  
このコネクタは、ベンダーへの大量のデータ転送に対応するため、バッチ処理されたリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳しくは、[バッチ処理されたアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに格納されます。

* リクエストの最大数：10000
* 最も古いリクエストからの最大経過時間：10 分
* リクエストの最大サイズ：1 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳しくは、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を行います。

* **アプリ ID**：（必須）接続する Facebook アプリの ID。
* **アプリシークレット**：（必須）接続する Facebook アプリのアプリシークレット。
* **広告アカウント ID**：（必須）管理する Facebook 広告アカウントの ID。Facebook 広告アカウント ID について詳しくは、[Facebook：Facebook広告アカウントID番号を確認する](https://www.facebook.com/help/1492627900875762)を参照してください。

コネクタを構成したら、**完了**をクリックします。

通常、この接続は 60 日以内に期限切れとなり、すべての Facebook 広告アクションで予期しない結果が生じる可能性があります。

接続は、**接続を確立／接続済み**をクリックすることで、いつでも再確立できます。


<blockquote>
**接続を確立**ボタンをクリックする前に、使用する広告アカウント ID にリンクされているアカウントで Facebook にログインしていることを確認してください。そうでない場合、生成されるトークンに問題が生じる可能性があります。
</blockquote>

### ユーザーをカスタムオーディエンスに追加

メールアドレス、電話番号、ユーザー ID またはアプリ ID、およびセカンダリ ID の 4 種類の識別子がサポートされています。複数のセカンダリ識別子がサポートされています。**Facebook ユーザー ID**を指定する場合は、**Facebook アプリ ID**も指定する必要があります。サポートされるメールアドレスまたは電話番号は 1 つだけです。複数の識別子を指定した場合は、上記の順序で選択されます。たとえば、メールアドレスと電話番号の両方を指定した場合、メールアドレスに値がなければ電話番号が選択され、それ以外の場合はメールアドレスが選択されます。

## Facebook Audiences Customer-Provided Credentialsコネクタの使用

### 訪問ID属性の作成

Facebook Audiences Customer-Provided Credentialsコネクタには、Facebook Audiencesに渡すことができる訪問ID属性が少なくとも1つ必要です。

訪問ID属性を構成するには、次のリソースを使用してください。

* [訪問ID属性の構成](https://docs.tealium.com/visitor-id-attribute/)
* [Facebook Marketing API](https://developers.facebook.com/docs/marketing-api/audiences-api)

### オーディエンスの定義

アカウントに複数の訪問ID属性が定義されている場合があります。この場合、いずれかの訪問IDが存在するかどうかを確認するため、訪問スコープのブール型属性を作成し、`Known Visitor`という名前を付けることが重要です。この属性を使用すると、Facebookに渡すことができる訪問IDが割り当てられた訪問のみがオーディエンスに含まれるようになります。不明な訪問をターゲティングすることはできません。


<blockquote>
このコネクタには、メールアドレス、電話番号、アプリID、ユーザーIDなど、必須のIDパラメータもあります。これらのIDのうち少なくとも1つが必要です。これらのIDをオーディエンスフィルターに含めることで、コネクタエラーを回避できます。
</blockquote>


次の例を使用して、「Known Visitor」ブールデータ型が`true`に構成されている訪問の[オーディエンスフィルターを作成](https://docs.tealium.com/manage-audiences/)します。バッジ属性とブール属性は、事前に追加することも、フィルターの作成時に追加することもできます。

![](https://docs.tealium.com/images/server-side-connectors/edit-audience-shoe-fan.png)
### TealiumをFacebookオーディエンスアカウントに接続する

Facebookオーディエンスアカウントでコネクタを構成するには、アカウントIDが必要です。

以下の手順でFacebookオーディエンスのアカウントIDを取得します。

1. Facebookオーディエンスアカウントにログインします。
1. [広告マネージャ](https://www.facebook.com/ads/manage)で、広告アカウント、キャンペーン、広告セット、または広告をクリックします。
1. ブラウザのURLから`account_id`パラメータの値をコピーし、CDPのコネクタに戻ります。  
![](https://docs.tealium.com/images/server-side-connectors/facebook-account-id.png)

1. **構成**ウィンドウで、タイトル、関連するメモ、および上記でコピーした広告アカウントIDを追加します。
1. **接続を確立**をクリックして接続を確認します。

### カスタムオーディエンスを作成する

Facebookオーディエンスアカウントへの接続が完了したら、カスタムオーディエンスを作成します。コネクタでカスタムオーディエンスを作成できるようにするには、まずFacebookサイトで最初のカスタムオーディエンスを作成し、利用規約に同意する必要があります。

以下の手順でカスタムオーディエンスを作成します。

1. コネクタ構成で、**作成**タブをクリックします。
1. 以下のフィールドを構成します。
   * **オーディエンス名**（必須）：カスタムオーディエンスの名前です。CRMのオーディエンス名またはセグメント名を使用します（例：`Qualified Leads - US - Q3 2026`または`High Value Customers - EMEA`）。Metaはこの名前を使用してオーディエンスセグメントを識別します。
   * **オーディエンスメタデータ（JSON）**（任意）：オーディエンスの条件を記述するJSONオブジェクトで、Meta APIの`description`パラメータにマッピングされます。集計属性またはカテゴリ属性を含むキーと値のペアを使用します。PII（個人を特定できる情報）は含めないでください。例：`{"lifecycle_stage":"churned","region":"EMEA","tier":"high_value"}`。Metaはこのメタデータをオーディエンスラベルおよび最適化機能で使用します。ラベルの割り当てはMeta広告マネージャで行います。Metaがメタデータを解析できるように、値は有効なJSONである必要があります。
1. **作成**をクリックします。  
`customer_file_source`パラメータでは、以下の値がサポートされています。
    * `USER_PROVIDED_ONLY`
    * `PARTNER_PROVIDED_ONLY`
    * `BOTH_USER_AND_PARTNER_PROVIDED`

Facebookオーディエンスサイトでは、顧客リスト、ウェブサイトトラフィック、またはアプリアクティビティに基づいてオーディエンスを作成できます。この例では、顧客リストに基づいてオーディエンスを作成します。


<blockquote>
カスタムオーディエンスを使用するには、少なくとも20件のエントリが含まれている必要があります。オーディエンスが正常に作成されると、ボタンの横に小さなチェックアイコンが表示されます。
</blockquote>


### コネクタアクションを指定する

次に、コネクタに実行させるアクションを指定する必要があります。

以下の手順でコネクタのアクションを指定します。

1. **アクション**タブをクリックします。
1. **カスタムオーディエンスにユーザーを追加**を選択します。  
![](https://docs.tealium.com/images/server-side-connectors/facebook-ads-connector-action-add-user-to-custom-audience.jpg)
1. **+ アクションを作成**をクリックします。

### コネクタアクションを構成する

以下の手順でコネクタのアクションを構成します。

1. **オーディエンス**メニューから、先ほど作成した**Shoe-Fans**オーディエンスを選択します。  
**ユーザーの追加先となるカスタムオーディエンス**メニューには、Facebookオーディエンスアカウントに存在するオーディエンスが表示されます。
1. **ユーザーの追加先となるカスタムオーディエンス**ドロップダウンリストから、訪問を追加するオーディエンスを選択します。
1. **対象ユーザー識別子**ドロップダウンリストで、訪問のメール属性をFacebookオーディエンスアカウント内の対応する訪問識別子にマッピングします。
1. **WHEN**は**オーディエンスへの参加**に構成したままにします。
1. **保存**をクリックします。

### テスト

最も効果的なテスト方法は、[Trace](https://docs.tealium.com/about-trace/)を実行してイベントが適切に処理されていることを確認し、Facebookダッシュボードでカスタムオーディエンスが作成され、データが追加されていることを確認することです。

## よくある質問

### CDPのドロップダウンリストにオーディエンスが表示されないのはなぜですか？

Facebookに2,000件を超えるオーディエンスがある場合、CDPコネクタのドロップダウンリストですべてを選択することはできません。

Facebookですべてのオーディエンスを表示し、特定のオーディエンスの識別子を選択するには、以下の手順を実行します。

1. Facebookオーディエンスアカウントへのアクセス権を持つユーザーとしてFacebookにログインします。
1. <https://www.facebook.com/adsmanager/audiences>に移動します。
1. 目的のオーディエンスを見つけ、オーディエンスIDをコピーします。  
    
<blockquote>
オーディエンスIDが表示されない場合は、テーブルの列表示を変更して追加できます。
</blockquote>
  

    ![](https://docs.tealium.com/images/server-side-connectors/facebook-ads-find-audience-id.png)
1. CDPに戻り、CDPコネクタのカスタム値としてオーディエンスIDを入力します。
