## コネクタアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
|イベントデータをキューまたはトピックに送信| ✗| ✓|
|訪問データをキューまたはトピックに送信| ✓| ✗|
|カスタマイズしたデータをキューまたはトピックに送信| ✓| ✓|

## 要件

* Microsoft Azure アカウント
* Service Bus 共有アクセスポリシーの資格情報
* データの送信先となるキューまたはトピック

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

ベンダーを構成するには、次の手順に従います。

1. Configure タブで、コネクタインスタンスのタイトルを入力します。

1. Service Bus の名前空間、共有アクセスポリシー名、およびキーを入力します。詳細については、[名前空間と共有アクセスポリシー](https://docs.microsoft.com/en-us/azure/service-bus-messaging/service-bus-create-namespace-portal)を参照してください。

1. **Test Connection** をクリックし、指定した資格情報で API に接続できることを確認します。


<blockquote>
共有アクセスポリシーでは、`Send`、`Listen`、`Manage`の3種類のアクセス許可を付与できます。指定するポリシーには、少なくとも`Send`アクセス許可が必要です。
</blockquote>


## アクション構成 - パラメーターとオプション

**Continue** をクリックして、コネクタアクションを構成します。アクション名を入力し、リストからアクションタイプを選択します。

このセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。

### アクション - イベントデータをキューまたはトピックに送信

#### パラメーター

| パラメーター | 説明 |
|---|---|
| キューまたはトピック | （必須）このリストからキューまたはトピックのオプションを選択します。これらのオプションは、構成したポリシーに **Manage** アクセス許可が付与されている場合にのみ使用できます。アクセス許可が付与されていない場合は、カスタム値としてキューまたはトピックを手動で入力する必要があります。 |
| ユーザープロパティ | **To** ドロップダウンで、属性をメッセージのユーザープロパティ（カスタム値として入力）にマッピングします。 |
| ブローカープロパティ | **To** ドロップダウンで、属性を目的のメッセージブローカープロパティにマッピングします。使用可能なオプションについては、以下を参照してください。 |
| 属性名を出力 | このチェックボックスをオンにすると、メッセージペイロード内の各イベントデータ属性の名前が表示されます。 |


<blockquote>
すべてのアクションで、メッセージのユーザープロパティとブローカープロパティがサポートされています。これらは、キーと値のペアを使用して、メッセージに関する有用で便利な情報を提供します。ただし、HTTP ヘッダーとして構成され、メッセージ本文には含まれません。詳細については、[メッセージのユーザープロパティとブローカープロパティ](https://docs.microsoft.com/en-us/rest/api/servicebus/message-headers-and-properties)を参照してください。
</blockquote>


#### オプション - ブローカープロパティ

|**オプション**| **説明**|
|---| ---|
|コンテンツタイプ|メッセージコンシューマー向けに HTTP ヘッダー`Content-Type`を構成します|
|相関 ID|相関を識別する一意の ID|
|セッション ID|メッセージを分割し、特定のコンシューマーにルーティングするために使用できます|
|メッセージ ID|デフォルトで自動生成されるメッセージ ID を上書きします|
|ラベル|アプリケーションラベル|
|返信先|メッセージコンシューマーからの応答の送信先を指定するために使用できます|
|有効期間（秒）|X 秒後にメッセージを期限切れにします（キューまたはトピックレベルの構成を上書きします）|
|送信先|送信先アドレス|
|スケジュールされたエンキュー時刻|メッセージをエンキューする予定日時|
|返信先セッション ID|返信先と同様ですが、応答先としてセッションを指定します|
|パーティションキー|パーティション分割されたキューまたはトピックの一意の ID|

### アクション - 訪問データをキューまたはトピックに送信

#### パラメーター

| パラメーター | 説明 |
|---|---|
| キューまたはトピック | （必須）このリストからキューまたはトピックのオプションを選択します。これらのオプションは、構成したポリシーに **Manage** アクセス許可が付与されている場合にのみ使用できます。アクセス許可が付与されていない場合は、カスタム値としてキューまたはトピックを手動で入力する必要があります。 |
| ユーザープロパティ | **To** ドロップダウンで、属性をメッセージのユーザープロパティ（カスタム値として入力）にマッピングします。 |
| ブローカープロパティ | **To** ドロップダウンで、属性を目的のメッセージブローカープロパティにマッピングします。使用可能な[ブローカープロパティ](#options---broker-properties)のオプションを参照してください。 |
| 現在の訪問データを訪問データに含める | 現在の訪問データをペイロードに追加します。「現在の訪問のイベントデータを除外」が選択されていない場合は、訪問のイベントデータも含まれます。 |
| 現在の訪問のイベントデータを除外 | 現在の訪問データからイベントデータを除外します。 |
| 属性名を出力 | このチェックボックスをオンにすると、メッセージペイロード内の各訪問データ属性の名前が表示されます。 |

### アクション - カスタマイズしたデータをキューまたはトピックに送信（詳細構成）

#### パラメーター

| パラメーター | 説明 |
|---|---|
| キューまたはトピック | （必須）このリストからキューまたはトピックのオプションを選択します。これらのオプションは、構成したポリシーに **Manage** アクセス許可が付与されている場合にのみ使用できます。アクセス許可が付与されていない場合は、カスタム値としてキューまたはトピックを手動で入力する必要があります。 |
| ユーザープロパティ | **To** ドロップダウンで、属性をメッセージのユーザープロパティ（カスタム値として入力）にマッピングします。 |
| ブローカープロパティ | **To** ドロップダウンで、属性を目的のメッセージブローカープロパティにマッピングします。使用可能な[ブローカープロパティ](#options---broker-properties)のオプションを参照してください。 |
| メッセージデータ | （必須）カスタムメッセージ本文を構築します。単純な1階層の JSON 形式で属性を名前にマッピングするか、テンプレート名（二重波括弧で囲む）を参照して、**Custom Message Definition** オプションを選択します。 |
| テンプレート変数 | 属性をテンプレート変数名にマッピングします。テンプレート変数は、すべてのテンプレートでの置換とレンダリングに使用できます。詳細については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。 |
| テンプレート | レンダリングするテンプレートを1つ以上指定します。通常、メッセージデータの構築には単一のテンプレートを使用します。一般的な構文と拡張機能については、[テンプレートガイド](https://docs.tealium.com/about-connector-templates/)を参照してください。一般的な構文と拡張機能の詳細については、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。 |


<blockquote>
必要に応じて、ユーザープロパティとブローカープロパティ内でテンプレートを参照して挿入することもできます。
</blockquote>
