## 仕組み

このコネクタは、カスタムプロンプトとマッピングされた Tealium データを使用して AI モデルを呼び出し、その応答を JSON イベントとして Tealium Collect に送り返し、リアルタイムのエンリッチメントに使用します。


<blockquote>
このコネクタは、大量のイベントではなく、対象を絞った価値の高いインタラクションに使用してください。過度に使用すると、ベンダーアカウントでレート制限が適用されたり、API コストが増加したりするほか、Tealium の受信イベント量が増加する可能性があります。
</blockquote>


## 使用量とコストに関する考慮事項

Google Vertex AI コネクタを有効化する前に、Google Cloud の割り当てと制限を確認してください。このコネクタは、イベントトリガーやオーディエンストリガーに応じて大量のリクエストを生成する可能性があり、予期しない使用量や超過料金が発生することがあります。

詳細については、[Google：Vertex AI の割り当てと制限](https://docs.cloud.google.com/vertex-ai/docs/quotas)を参照してください。

**主な考慮事項**

* **使用階層とレート制限**  
  Google Vertex AI では、アカウント階層に基づいてレート制限（1 分あたりのリクエスト数およびトークン数）が適用されます。高頻度のイベントや大規模なオーディエンスでは、これらの上限にすぐに達し、スロットリングやリクエストの失敗が発生する可能性があります。
* **料金とトークン消費量**  
  Google Vertex AI の料金は、モデルによって処理された入力トークンと出力トークンの数に基づいて決まります。プロンプトが長いほど、ペイロードが大きいほど、また高性能なモデルを使用するほど、リクエストあたりのコストが増加します。使用予定のモデルごとに料金を確認してください。
* **月間支出と予算管理**  
  予定外の支出を防ぐため、Google Cloud アカウントで使用量の上限またはアラートを構成してください。上限を構成していない場合、自動化されたワークフローによって多額のコストが累積する可能性があります。
* **トリガー量**
  このコネクタを、ページビューなどの大量かつ価値の低いイベントに関連付けないでください。意味のある顧客行動を表し、管理可能な頻度で発生するイベントまたはオーディエンスを使用してください。

## ベストプラクティス

このコネクタの価値を最大限に引き出すには、次のガイドラインに従って効果的なソリューションを構築してください。

* **価値の高いトリガー**：豊富なコンテキストや意味のある顧客入力を含むイベントフィードまたはオーディエンストリガーを選択します。大量の処理が発生するユースケースでこのコネクタをトリガーすると、Google Cloud アカウントで追加コストが発生したり、リクエストが失敗したりする可能性があります。
* **具体的に記述する**：モデルが評価すべき内容と期待する値の詳細を含めます。期待する値を正確に列挙してください。
* **JSON 形式**：Tealium イベントとして送信できる有効な JSON 応答テンプレートを含めます。
* **応答値**：取得する応答値を参照します。たとえば、購入意向を評価するようプロンプトで要求する場合は、その値をイベント JSON に表示する位置で `<customer purchase intent>` を参照します。
* **Tealium データ**：二重波括弧を使用して、Tealium データとマッピングされたパラメータを参照します。たとえば、`tealium_account` にマッピングされた値を参照するには、プロンプトに `{{tealium_account}}` と記述します。

## API 情報

このコネクタは、次のベンダー API を使用します。

* API 名：Vertex API
* API バージョン：v1
* API エンドポイント：`https://aiplatform.googleapis.com/v1`
* ドキュメント：[Google API](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/reference/rest/v1/projects.locations.endpoints/generateContent)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を構成します。

* **Google Cloud Platform プロジェクト ID**：（必須）Vertex AI が有効になっている Google Cloud プロジェクト ID。
* **秘密鍵 JSON ファイル**：（必須）サービスアカウント用に生成された JSON キーの内容を貼り付けます。プロジェクト内で、サービスアカウントに Vertex AI ユーザーロール（`roles/aiplatform.user`）を付与します。このロールにより、コネクタは利用可能なモデルの一覧取得と、Vertex AI Generative API を介した選択済みモデルの呼び出しの両方を実行できます。
* **ロケーション**：モデルを実行する Vertex AI のロケーションを選択します。Google パブリッシャーの Gemini モデルには **global** を使用します。データレジデンシー要件がある場合、または Vertex リソースがリージョン単位の場合は、リージョンのロケーションを選択します。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| Vertex AI にプロンプトを送信 | ✓ | ✓ |

アクションの名前を入力し、アクションタイプを選択します。

以下のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### Vertex AI にプロンプトを送信

このアクションは、カスタムプロンプトとマッピングされた Tealium データを使用して Vertex AI モデルを呼び出します。モデルが有効な JSON イベントオブジェクトで応答すると、このイベントがアカウントに送り返され、生成された値をリアルタイムエンリッチメントで取得できます。

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| モデル | <ul><li>このプロンプトで使用する Vertex モデルを選択します。</li><li>このリストには、テキスト形式または JSON 形式の応答に適した Google の Gemini 生成モデルが表示されます。</li><li>チームでプライベートモデルまたはファインチューニング済みの Vertex AI モデルを使用している場合は、そのモデルリソース名を手動で入力できます（例：`projects/{{PROJECT}}/locations/{{REGION}}/models/{{MODEL_ID}}`）。</li><li>構造化出力（JSON）に最適化され、パフォーマンスとコストの要件を満たすモデルを使用することを推奨します。</li></ul> |

#### プロンプトパラメータ

| パラメータ | 説明 |
| --- | --- |
| イベントペイロードを追加 | （イベントアクションで使用可能）プロンプトテンプレートで変数 `{{event_payload}}` として使用するイベントペイロードを含めるには、このチェックボックスをオンにします。 |
| 訪問プロファイルを追加 | （オーディエンスアクションで使用可能）プロンプトテンプレートで変数 `{{visitor_profile}}` として使用する訪問プロファイルを含めるには、このチェックボックスをオンにします。 |
| 現在の訪問を追加 | （オーディエンスアクションで使用可能）変数 `{{visitor_profile}}` に現在の訪問を含めるには、このチェックボックスをオンにします。 |
| プロンプト | <ul><li>選択した Vertex AI モデルに送信するプロンプトを入力します。一貫性のある機械可読な出力を得るため、次のガイドラインに従ってください。</li><li>マッピングされたパラメータを参照するには、二重波括弧を使用します。例：`{{tealium_account}}`、`{{visitor_id}}`、`{{event_value}}`。</li><li>訪問アクションを使用する場合は、最初に **訪問プロファイルを追加** チェックボックスを有効にしてから、`{{visitor_profile}}` を使用して訪問プロファイルをプロンプトに含めます。</li><li>曖昧な表現を避けてください。出力を確実に解析できるよう、プロンプトは決定論的にする必要があります。</li><li>応答に期待する JSON フィールドと構造を定義します。</li><li>コネクタが応答を正しく解析して Collect エンドポイントに転送できるように、応答で `tealium_account`、`tealium_profile`、`tealium_visitor_id` を返すようモデルに明示的に指示します。</li><li>モデルが JSON を返すよう強制するため、コネクタはリクエストに `response_mime_type`: `application/json` を含めます。</li><li>詳細と例については、このコネクタに関する Tealium のドキュメントを参照してください。</li></ul> |
| デバッグモード | デバッグモードを有効にすると、コネクタは未加工の Vertex AI 応答を Tealium Collect に送信せずに受け入れます。完全な処理を有効にする前に、トレースを使用して応答形式を検証してください。 |
#### 高度なモデル構成

| パラメーター | 説明 |
| --- | --- |
| `temperature` | ランダム性と創造性を制御します。値を低くすると、確率分布曲線が鋭くなり、より焦点を絞った予測可能な回答になります。一方、値を高くすると、確率分布曲線が平坦になり、より多様で創造的な回答になります。指定できる値は `0` から `2` までです。 |
| `maxOutputTokens` | 回答で生成するトークンの最大数です。 |
| `topP` | 核サンプリングのしきい値を指定します。`topP` の値を低くすると、より安全で焦点を絞った出力になり、値を高くすると、より多様で創造的な出力になります。指定できる値は `0` から `1` までです。たとえば、`topP` を `0.9` に構成した場合、累積確率が 90% に達するまでのトークンのみが考慮され、確率の低い裾部分のトークンは除外されます。 |
| `topK` | top-k サンプリングのしきい値を指定します。`topK` の値を低くすると、より決定論的で多様性の低い出力になり、値を高くすると、より多様になりますが、一貫性が低下する可能性があります。たとえば、`topK` を `40` に構成した場合、確率が最も高い 40 個のトークンのみを対象として、温度パラメーターを使用した確率的な方法で次のトークンが選択され、それ以外はすべて無視されます。 |
