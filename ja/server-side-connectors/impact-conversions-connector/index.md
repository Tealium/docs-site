## コネクタアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| コンバージョンを送信 | ✓ | ✓ |

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **アカウントSID**  
（必須）Impactによって定義されます。例：`MhyXaouO5Ijnw658m6kXoqwlo1IasLKJBX`
* **認証トークン**  
（必須）Impactによって定義されます。例：`t0k5Lr3GciUAqR0JNj1CzxKE2XTEmK5i`

## アクション

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### アクション - コンバージョンを送信

#### コンバージョンパラメータ

次の2つのパラメータを含める必要があります。

| **パラメータ** | **説明** |
| --- | --- |
| キャンペーンID | （必須）Impactから提供される一意の整数キャンペーン識別子。 |
| 注文ID | （必須）アプリ内コンバージョンを追跡するための一意の英数字ID。 |

次の2つのパラメータのいずれかを含める必要があります。

| **パラメータ** | **説明** |
| --- | --- |
| アクショントラッカーID | Impactから提供される一意の整数トラッカー識別子。 |
| イベントタイプコード | コンバージョンイベントのタイプ。すべてのコードを表示するには、Impactプラットフォームで**イベントタイプ > アクション > 表示／編集 > コード**に移動します。 |

次のアトリビューションキーパラメータを少なくとも1つ含める必要があります。

| **パラメータ** | **説明** |
| --- | --- |
| カスタムプロファイルID | 広告主独自の文字列型ユーザー識別子。ユーザーが最初の訪問イベントを記録したときにカスタムプロファイルIDが渡された場合、ここでも同じカスタムプロファイルIDの値を渡す必要があります。 |
| クリックID | ランディングページのURLまたはPage Load APIのレスポンスで取得されたクリックIDの文字列値。 |
| 顧客ID | プラットフォームが顧客アカウントに割り当てる一意の英数字顧客識別子。 |
| 一意のコンバージョンURL | コンバージョンを参照したパートナーまたは参照元に固有のURL。このパラメータは、パートナーに一意のドメインを構成して割り当てる場合にのみ使用します。 |
| Google広告ID | 顧客がコンバージョンを行ったモバイルデバイスに関連付けられているGoogle広告ID。 |
| IDFA | 顧客がコンバージョンを行ったモバイルデバイスに関連付けられている広告用Apple ID（IDFA）。 |
| IDFV | 顧客がコンバージョンを行ったモバイルデバイスに関連付けられているベンダー用Apple ID（IDFV）。 |
| メディアID | アトリビューションを強制的に割り当てるパートナーまたは参照元の一意の識別子。 |

次の追加パラメータを使用できます。

| **パラメータ** | **説明** |
| --- | --- |
| デバイスメーカー | 顧客がコンバージョンに使用したモバイルデバイスのメーカー。<ul><li>Android：`manufacturer = android.os.Build.MANUFACTURER;`</li><li>Apple：`NSString *manufacturer = @"Apple";`</li></ul> |
| アプリパッケージ | ユーザーがインストールしたモバイルアプリのパッケージ名。モバイルコンバージョンでのみ使用します。 |
| アプリインストールリファラー | アプリのインストール時にGoogle Playストアから渡されるインストールリファラー。Androidコンバージョンでのみ使用します。 |
| アプリバージョン | モバイルアプリのバージョン。モバイルコンバージョンでのみ使用します。 |
| 発信者ID | コールトラッキングコンバージョンにおける顧客の一意の識別子。この値は、コンバージョンと発信元の通話記録を照合するために使用されます。 |
| ロケーションID | 宿泊イベントで使用される、このコンバージョンで指定されたロケーションの一意の識別子。 |
| ロケーション名 | 宿泊イベントで使用される、このコンバージョンで指定されたロケーションの名前。 |
| ロケーションタイプ | 宿泊イベントで使用される、このコンバージョンで指定されたロケーションのカテゴリ。 |
| プロパティID | モバイルアプリのコンバージョンの場合、この値は`impact.com`上のアプリの**システムアプリID**です。この値を確認するには、Impactプラットフォームで**構成 > モバイルアプリ**に移動します。 |
| トラッキングへの同意 | リクエスト時点で、ユーザーがトラッキングへの同意を提供しているかどうかを示します。この値は、同意管理プラットフォーム、またはiOSで利用可能なAppleのATT（App Tracking Transparency）などのフレームワークから取得されます。 |
| 顧客の市区町村 | 顧客の市区町村。 |
| 処理コード | Impactのイベントタイプ構成でカスタム処理コードを構成している場合、このコンバージョンから生成されるアクションのデフォルト処理として、その値を送信できます。 |
| 顧客のメールアドレス | 顧客のメールアドレスのSHA1ハッシュ文字列。 |
| 顧客ステータス | `New`または`Returning`の文字列値を使用します。 |
| 顧客の郵便番号 | 顧客の郵便番号。 |
| 支払いタイプ | 注文の支払いタイプを表す文字列。 |
| 注文リベート | 注文リベートの金額を表す小数。レポート作成にのみ使用されます。 |
| イベント日時 | `NOW`の文字列値、または<a href="https://en.wikipedia.org/wiki/ISO_8601">ISO 8601</a>か「dd-MMM-yyyy HH:mm:ss z」形式の日付を使用します。デフォルト値は`NOW`です。 |
| 注文プロモーションコード | クーポンまたはプロモーションコードの文字列。注文にプロモーションコードがない場合は、空の文字列を使用します。デフォルト値は空の文字列です。このパラメータは単一のコードのみをサポートし、複数のコードはサポートしません。 |
| 通貨コード | セールアクションでは必須です。デフォルト値は`USD`です。<a href="https://en.wikipedia.org/wiki/ISO_4217">ISO 4217</a>通貨コードを使用できます。 |
| ユーザーエージェント | ブラウザとオペレーティングシステムを識別する文字列。 |
| IPアドレス | 顧客のIPアドレスを表す文字列。 |
#### コンバージョン販売アイテム

アイテムレベルの詳細を渡す場合、以下のアイテムパラメーターが必須です。


<blockquote>
すべての配列とリストは同じ長さである必要があります。単一値の属性は、値を繰り返すことで、ほかのすべての配列と同じ長さの配列に展開されます。
</blockquote>


| **パラメーター** | **説明** |
| --- | --- |
| Item Category | 文字列型のアイテムカテゴリー識別子。Impact に渡すには、配列およびリストの値をキーにマッピングします。 |
| Item SKU | アイテム固有の英数字識別子。Impact に渡すには、配列およびリストの値をキーにマッピングします。 |
| Item Subtotal | Impact に渡すには、配列およびリストの値をキーにマッピングします。 |
| Item Quantity | 明細アイテムの数量を表す整数値。Impact に渡すには、配列およびリストの値をキーにマッピングします。 |
| Item Price | このアイテムに含まれる各商品の単価。**Item Subtotal** を使用する場合は、このパラメーターに値を構成しないでください。 |

以下のアイテムパラメーターは任意です。

| **パラメーター** | **説明** |
| --- | --- |
| Item Promo Code | 注文のアイテムに適用されるプロモーションコード。このパラメーターは、特定のパートナー向けに構成された固有のトラッキングコードでは機能しません。 |
| Item Total Discount | この明細アイテム全体に適用される割引（この種類の各商品に対する割引ではありません）。支払いおよびレポート用の最終販売額を算出するため、この金額は ItemSubTotal から自動的に差し引かれます。 |
| Item Sub Category | 該当する場合、アイテムレベルで参照される商品のサブカテゴリー。 |
| Item Name | 参照される商品の名前。 |
| Item MPN | 参照される商品の製造元部品番号（MPN）。 |
| Item Brand | 参照される商品のブランド名。 |
| Item Discount | 購入されたこの種類の各アイテムに適用される割引。 |
| Item Delivery Type | このアイテムに指定された配送方法の種類（例：`STORE`）。 |
| Payment Type | 注文の支払いタイプを表す文字列。 |
| Order Sub Total Post Discount | 注文レベルでコンバージョンをレポートする場合（アイテムレポートなし）に使用します。割引、税金、送料、その他の費用を反映した後の注文小計です。アイテムレベルのデータを送信する場合は、この値を構成しないでください。 |
| Order Discount | 販売の場合、注文全体に適用される割引です。処理時に、割引は注文合計から自動的に差し引かれます。アイテム金額を使用する場合、送信された各アイテム金額から割引が比例配分で差し引かれます。送料は含めないでください。 |
| Order Shipping | このパラメーターは主に小売販売で使用されます。このコンバージョンの送料です。支払いの算出に使用する合計販売額に送料を含めないでください。 |
| Order Tax | このパラメーターは主に小売販売で使用されます。このコンバージョンの税額です。支払いの算出に使用する合計販売額に送料を含めないでください。 |
| Order Margin | このパラメーターは主に小売販売で使用されます。コンバージョンで得られた合計利益（収益から費用を差し引いた額）です。通常、アイテムレベルの `ItemMargin` パラメーターまたは商品カタログを通じて指定します。 |
| Gift Purchase | ギフト購入をトラッキングする場合は、コンバージョン内の注文をギフト購入としてマークするために `true` に構成します。注文がギフト購入でない場合は `false` に構成します。 |
