## バッチ制限

このコネクタでは、ベンダーへの大量のデータ転送に対応するため、リクエストをバッチ処理します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに格納されます。

* リクエストの最大数：10000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：2 MB

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **APIキー**：（必須）Quantcast UIのプロファイル構成から取得したAPIキー。
* **APIシークレット**：（必須）キーのAPIシークレット。
* **所有者pCode**：（必須）セグメント所有者のpCode。`p-`で始まります。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| ユーザーをセグメントに追加 | ✓ | ✓ |
| ユーザーをセグメントから削除 | ✓ | ✓ |

アクションの名前を入力し、アクションタイプを選択します。

以下のセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。

### ユーザーをセグメントに追加

#### ユーザー

次のパラメーターのうち、少なくとも1つが必要です：**パートナーユーザーID**、**Quantcast CookieユーザーID**、または**メールアドレス**（ハッシュ化済みまたはプレーンテキスト）。

| パラメーター | 説明 |
| --- | --- |
| パートナーユーザーID | ユーザーに対して生成するID。QuantcastがIDマップをホストする場合は、この値を使用します。 |
| Quantcast CookieユーザーID | Quantcastがユーザーに対して生成した暗号化済みCookie ID。 |
| メールアドレス（SHA256でハッシュ化済み） | 前後の空白を削除し、小文字に変換してSHA256でハッシュ化済みのメールアドレスを指定します。 |
| メールアドレス（SHA256ハッシュを適用） | プレーンテキストのメールアドレスを指定します。コネクタは、この値の前後の空白を削除し、小文字に変換したうえで、SHA256を使用してハッシュ化します。 |


<blockquote>
ハッシュ化されたメール識別子は、米国内のQuantcastオーディエンスでのみサポートされています。米国外のオーディエンスではサポートされていません。
</blockquote>


#### セグメント

単一値属性、または長さが等しい配列属性をマッピングします。

| パラメーター | 説明 |
| --- | --- |
| セグメント名 | （必須）このユーザーに割り当てるセグメントの名前。パイプ文字（`|`）を除く、文字、数字、特殊文字を任意に組み合わせて使用できます。 |
| 所有者pCode | セグメント所有者の**pCode**。`p-`で始まります。セグメントの所有者が自分とは異なる場合に、このフィールドを使用します。 |

### ユーザーをセグメントから削除

#### ユーザー

次のパラメーターのうち、少なくとも1つが必要です：**パートナーユーザーID**、**Quantcast CookieユーザーID**、または**メールアドレス**（ハッシュ化済みまたはプレーンテキスト）。

| パラメーター | 説明|
| --- | --- |
| パートナーユーザーID | ユーザーに対して生成するID。QuantcastがIDマップをホストする場合は、この値を使用します。 |
| Quantcast CookieユーザーID | Quantcastがユーザーに対して生成した暗号化済みCookie ID。IDマップを自分でホストする場合は、この値を使用します。 |
| メールアドレス（SHA256でハッシュ化済み） | 前後の空白を削除し、小文字に変換してSHA256でハッシュ化済みのメールアドレスを指定します。 |
| メールアドレス（SHA256ハッシュを適用） | プレーンテキストのメールアドレスを指定します。コネクタは、この値の前後の空白を削除し、小文字に変換したうえで、SHA256を使用してハッシュ化します。 |

#### セグメント

単一値属性、または長さが等しい配列属性をマッピングします。

| パラメーター | 説明 |
| --- | --- |
| セグメントID | （必須）このユーザーを削除するセグメントのID。 |
| セグメント名 | （必須）このユーザーに割り当てられたセグメントの名前。パイプ文字（`|`）を除く、文字、数字、特殊文字を任意に組み合わせて使用できます。 |
| 所有者pCode | セグメント所有者の**pCode**。`p-`で始まります。セグメントの所有者が自分とは異なる場合に、このフィールドを使用します。 |
