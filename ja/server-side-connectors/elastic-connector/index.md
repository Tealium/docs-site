## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の項目を構成します。
* **認証タイプ**：認証タイプを選択します。
* **ホスト**：（必須）ElasticホストのURL。
* **APIキー**：（必須）Elastic APIキー。

コネクタを構成したら、**完了**をクリックします。

### データストリームの作成

データストリームを作成するには、次の手順を実行します。

1. **リモート構成**で、**データストリームを作成**をクリックします。
1. **データストリーム名**を入力します。
1. **データストリームを作成して閉じる**をクリックします。

### イベントデータ全体を送信

#### パラメーター

| パラメーター | 説明 |
| --- | --- |
| ターゲットタイプ | （必須）ターゲットタイプとして、**インデックス**または**データストリーム**を指定します。 |
| ターゲット | （必須）ターゲットを指定します。ターゲットタイプが**インデックス**の場合は、カスタム値を指定できます（必要に応じてインデックスがその場で作成されます）。ターゲットタイプが**データストリーム**の場合は、既存のデータストリームを選択するか、**データストリームを作成**をクリックして作成します。**データストリーム名**を入力し、**データストリームを作成して閉じる**をクリックします。 |

#### ドキュメントの詳細

省略可能なドキュメントメタデータ。使用可能なキーはターゲットタイプによって異なります。

| パラメーター | 説明 |
| --- | --- |
| `document_id` | ドキュメントの一意の識別子。ターゲットタイプが**インデックス**の場合に使用できます。 |
| `timestamp` | ISO 8601形式（例：`2025-05-16T11:48:00Z`）またはエポックナノ秒（例：`1715856480000000000`）のイベントタイムスタンプ。ターゲットタイプが**データストリーム**の場合に使用できます。空欄または形式が不正な場合は、現在時刻がデフォルトとして使用されます。 |

#### 同時実行制御

| パラメーター | 説明 |
| --- | --- |
| `primary_term` | ドキュメントがこのプライマリタームを持つ場合にのみ、操作を実行します。 |
| `seq_no` | ドキュメントがこのシーケンス番号を持つ場合にのみ、操作を実行します。 |
| `version` | 同時実行制御に使用する明示的なバージョン番号。負でないlong値である必要があります。 |
| エラー処理 | Elasticが解析エラーを報告する方法を構成します。 |


<blockquote>
データストリームでは、同時実行制御パラメーターはサポートされていません。データストリームは追加専用であり、最初の書き込みを優先するセマンティクスが適用されるため、`primary_term`、`seq_no`、`version`は効果がありません。楽観的同時実行制御またはドキュメントの更新が必要な場合は、データストリームではなく通常のインデックスまたはその書き込みエイリアスをターゲットにしてください。
</blockquote>


#### インデックス作成動作

ドキュメントのインデックス作成方法を制御する省略可能なパラメーター。

| パラメーター | 説明 |
| --- | --- |
| `operation_type` | ドキュメントのインデックス作成方法を定義します。`index`は、同じIDを持つ既存のドキュメントを上書きします。`create`は挿入のみを行い、同じIDを持つドキュメントがすでに存在する場合は失敗します。ターゲットタイプが**インデックス**の場合にのみ使用できます。 |
| `pipeline` | ドキュメントの前処理に使用する取り込みパイプラインのID。デフォルトの取り込みパイプラインを無効にするには、`_none`を使用します。 |
| `routing` | 操作を特定のシャードに送るためのカスタムルーティング値。 |
| `wait_for_active_shards` | 処理を続行する前に必要となるシャードコピーの最小数。デフォルト：`1`。指定可能な値：`all`、またはシャード総数（`number_of_replicas + 1`）以下の任意の正の整数。 |
| 更新 | インデックス作成操作が検索結果に反映されるタイミングを決定します。指定可能な値：`true`、`false`、`wait_for`。 |
| イベントデータ | イベントペイロードのキーを出力する方法を構成します。 |
| カスタム属性 | JSONオブジェクトのルートレベルに追加する任意の属性を含めます。 |

### イベントデータ全体を送信（バッチ）

#### バッチ制限

このアクションでは、ベンダーへの大量データ転送をサポートするためにバッチリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルが公開されるまでキューに格納されます。

* リクエストの最大数：300,000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：100 MB

### 訪問データ全体の送信（バッチ）

#### バッチ制限

このアクションでは、ベンダーへの大量データ転送をサポートするためにバッチリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルが公開されるまで、リクエストはキューに保持されます。
