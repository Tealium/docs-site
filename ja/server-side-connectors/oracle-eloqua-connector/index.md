## 要件

* Oracle Eloquaアカウント
* Oracle Eloquaアカウントの会社名
* Oracle Eloquaアカウントのユーザー名
* Oracle Eloquaアカウントのパスワード
* Oracle Eloquaで許可リストが有効になっている場合は、[Customer Data Platform（CDP）サーバーのIPアドレス](https://docs.tealium.com/ip-allow-list/)をOracle Eloquaの許可リストに追加します。

<blockquote>
Oracle Eloquaの許可リストにIPアドレスが追加されておらず、かつOracle Eloquaの許可リストが無効になっていない場合、Import Definitionアクションは`DD: ELOQUA UNABLE TO RETRIEVE VENDOR ENDPOINT`エラーで失敗します。
</blockquote>

## バッチ制限
  
このコネクタは、ベンダーへの大量データ転送に対応するため、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに保持されます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：32 MB

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の必須構成を構成します。

* 会社
* ユーザー名
* パスワード

### 新しいインポート定義の構成

インポート定義は、アップロードするデータの構造を作成します。この定義では、Tealiumにアップロードするフィールドを構成します。連絡先リストまたはメールリストへのデータ同期も構成できます。

インポート定義を作成すると、データのインポート時にTealiumが自動的にデータを同期します。

|**パラメータ**| **説明** |
| --- | --- |
| インポート定義名 | （必須）連絡先インポート定義の名前。 |
| 連絡先フィールド | （必須）アップロード時に使用する連絡先フィールドを選択します。 |
| 識別子フィールド名 | （必須）インポートしたデータをOracle Eloqua内の既存レコードと照合するためのフィールドを選択します。このフィールドは、いずれかの**連絡先フィールド**と一致し、各レコードに固有のデータを含んでいる必要があります。 |
| オプション - 更新ルール | このインポート定義でインポートした値を使用して、Oracle Eloquaデータベース内の値を更新するアクションを選択します。<ul><li>`always`：常に値を更新します。</li><li>`ifNewIsNotNull`：新しい値が空白でない場合に値を更新します。</li><li>`ifExistingIsNull`：既存の値が空白の場合に値を更新します。</li><li>`useFieldRule`：フィールドレベルで定義されたルールを使用します。</li></ul> |
| オプション - 連絡先リストに同期 | この連絡先の同期先となる連絡先リストを選択します。 |
| オプション - 連絡先リストへの同期アクション | このインポート定義に対する連絡先リストの同期アクション（`add`または`remove`）を選択します。 |
| オプション - メールグループに同期 | この連絡先の同期先となるメールグループを選択します。 |
| オプション - メールグループへの同期アクション | このインポート定義に対するメールグループの同期アクション（`subscribed`または`unsubscribed`）を選択します。 |

## アクション構成 - パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### アクション - Bulk APIによる連絡先の更新

Bulk APIでは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストがキューに保持されます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：32 MB

詳細については、[Oracle Eloqua Bulk API](https://docs.oracle.com/en/cloud/saas/marketing/eloqua-develop/Developers/BulkAPI/bulk-API.htm)を参照してください。

#### パラメータ

|**パラメータ**| **説明**|
| --- | --- |
|連絡先インポート定義| （必須）このバッチアップロードに使用するインポート定義を選択します。 |
|連絡先データ | 属性をインポート定義のフィールドにマッピングします。 |

### アクション - 共有リストへの連絡先の追加


<blockquote>
アカウントから取得される共有リストは、最初の1,000件のみです。特定の共有リストが見つからない場合は、「カスタムテキスト」オプションを使用し、共有リストの数値IDのみを指定してください。テキスト名を入力すると、エラーが発生する可能性があります。
</blockquote>
 


<blockquote>
「API連絡先ID」が指定されていない場合、**連絡先検索**パラメータで指定した**連絡先フィールド**に基づいて対象の連絡先を検索するため、追加のAPI呼び出しが行われます。
</blockquote>


#### パラメータ

|**パラメータ**| **説明**|
| --- | --- |
|対象の共有リスト| （必須）対象の連絡先を追加する共有リスト。 |
|連絡先検索| <ul><li>API連絡先ID – 対象の連絡先ID</li><li>連絡先フィールド – 「API連絡先ID」が指定されていない場合、**連絡先フィールド**を使用して対象の連絡先を検索します。</li><li>日付属性は次の形式に変換されます：`yyyy-MM-dd HH:mm:ss`</li></ul>|

### アクション - 共有リストからの連絡先の削除


<blockquote>
「API連絡先ID」が指定されていない場合、**連絡先検索**パラメータで指定した**連絡先フィールド**に基づいて対象の連絡先を検索するため、追加のAPI呼び出しが行われます。
</blockquote>


#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|対象の共有リスト| （必須）対象の連絡先を削除する共有リスト。 |
|連絡先検索| <ul><li>API連絡先ID – 対象の連絡先ID</li><li>連絡先フィールド – 「API連絡先ID」が指定されていない場合、**連絡先フィールド**を使用して対象の連絡先を検索します。</li><li>日付属性は次の形式に変換されます：`yyyy-MM-dd HH:mm:ss`</li></ul> |

### アクション - 連絡先の挿入または更新


<blockquote>
「API連絡先ID」が指定されていない場合、**連絡先検索**パラメータで指定した**連絡先フィールド**に基づいて対象の連絡先を検索するため、追加のAPI呼び出しが行われます。
</blockquote>


#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|更新方法| <ul><li>（必須）該当する更新方法を選択します。<ul><li>作成のみ – 検索せずに新しい連絡先を作成します。</li><li>更新のみ – 既存の連絡先を検索して更新します。</li><li>作成または更新 – 既存の連絡先を検索し、見つかった場合は更新し、見つからない場合は新しい連絡先を作成します。</li></ul></li></ul> |
|連絡先検索| <ul><li>更新方法が**更新のみ**、**作成**、または**更新**の場合は必須です。</li><li>連絡先フィールド – 「API連絡先ID」が指定されていない場合、これらのフィールドを使用して対象の連絡先を検索します。</li></ul> <ul><li>日付属性は次の形式に変換されます：`yyyy-MM-dd HH:mm:ss`</li></ul> |
|連絡先作成データ| <ul><li>更新方法が**作成のみ**、**作成**、または**更新**の場合は必須です。</li><li>新しい連絡先を作成するための値をマッピングします。</li><li>日付属性は秒単位のUnixタイムスタンプに変換されます。</li></ul> |
|連絡先更新データ| <ul><li>更新方法が**更新のみ**、**作成**、または**更新**の場合は必須です。</li><li>既存の連絡先を更新するための値をマッピングします。</li><li>日付属性は秒単位のUnixタイムスタンプに変換されます。</li></ul> |
