## 要件

* アカウントでAudienceStoreが有効になっている必要があります。詳細については、Tealiumアカウントマネージャーにお問い合わせください。
* アカウントにアクティブなオーディエンスが必要です。詳細については、[オーディエンスの構築](https://docs.tealium.com/manage-audiences/)を参照してください。
* オーディエンス名は128文字未満にする必要があります。それ以上の場合、DataAccessによってオーディエンス名が切り詰められ、エラーが発生する可能性があります。

## コネクタのアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| 訪問データをバケットに送信（すべての属性） | ✓ | ✗ |
| 訪問データをバケットに送信（選択した属性） | ✓ | ✗ |

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

## アクション構成 — パラメータとオプション

AudienceStoreコネクタには、エクスポートするデータとエクスポートをトリガーするタイミングを指定できる2つのアクションがあります。データはログファイルに圧縮され、S3バケット内の`audiences`フォルダーにアップロードされます。デフォルトでは、データはJSONのキーと値のペアとして保存されます。S3では、データをダウンロードし、任意のビジネスインテリジェンスツールを使用して分析できます。

コネクタは、バッチのサイズが100 MBに達した時点、または1時間が経過した時点のうち、いずれか早い方でデータを送信します。デフォルトの動作は、**最大レコード数**、**有効期間**、および**最大ペイロードサイズ**の各パラメータで変更できます。

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### アクション — 訪問データをバケットに送信（すべての属性）

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| 現在の訪問データを含める | 訪問による直近の訪問に関するすべてのイベントデータが含まれます。 |
| 属性IDで送信 | デフォルトでは、訪問データのJSONプロパティキーにはCustomer Data Platform（CDP）の属性名が使用されます。CDP属性IDをキーとしてデータを送信するには、このオプションを選択します。 |
| 最大レコード数 | コネクタがバッチを`audiences`フォルダーに送信するまでに収集するレコード数です。1,000～100,000レコードの値を入力します。 |
| 有効期間 | コネクタがバッチを`audiences`フォルダーに送信するまでの待機時間です。20～180分の値を入力します。 |
| 最大ペイロードサイズ | コネクタがバッチを`audiences`フォルダーに送信するまでに収集するペイロードのサイズです。1MB～100MBの値を入力します。 |

### アクション — 訪問データをバケットに送信（選択した属性）

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| 保存する訪問属性 | 訪問属性を列ヘッダー名にマッピングします。 |
| データをCSV形式にする（選択しない場合はJSON） | データをJSONではなくCSV形式で保存します。 |
| 最大レコード数 | コネクタがバッチを`audiences`フォルダーに送信するまでに収集するレコード数です。1,000～100,000レコードの値を入力します。 |
| 有効期間 | コネクタがバッチを`audiences`フォルダーに送信するまでの待機時間です。20～180分の値を入力します。 |
| 最大ペイロードサイズ | コネクタがバッチを`audiences`フォルダーに送信するまでに収集するペイロードのサイズです。1MB～100MBの値を入力します。 |
