## API情報

このコネクタでは、次のベンダーAPIを使用します。

* API名：Sklik API
* APIバージョン：5
* APIエンドポイント：`https://api.sklik.cz`
* ドキュメント：[Sklik API](https://api.sklik.cz/drak/changelog.html)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **APIキー**  
  * （必須）アクセスキーを指定します。キーはhttps://www.sklik.cz/settingsで生成できます。
* **ユーザーID**  
  * （任意）管理対象ユーザーのID。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | ビジタープロファイル | イベントデータ |
| --- | :---: | :---: |
| メールアドレスをリストに追加 | ✓ | ✓ |
| メールアドレスをリストに追加（バッチ） | ✓ | ✓ |
| メールアドレスをリストから削除 | ✓ | ✓ |
| メールアドレスをリストから削除（バッチ） | ✓ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### メールアドレスをリストに追加

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| リターゲティングリストID | メールアドレスの追加先となるメールリターゲティングリストのID。 |
| メールアドレス | 選択したメールリターゲティングリストに追加するメールアドレス。 |

#### 任意のパラメータ

| **パラメータ** | **説明** |
| --- | --- |
| ユーザーのメールアドレス（ハッシュ化済み） | メールアドレスがすでにハッシュ化されている場合は、このチェックボックスをオンにします。 |
| ユーザーのメールアドレス（SHA256ハッシュを適用） | 送信前にTealiumでメールアドレスをSHA256ハッシュ化する場合は、このチェックボックスをオンにします。 |

### メールアドレスをリストに追加（バッチ）

#### バッチ制限

このアクションでは、ベンダーへの大容量データ転送に対応するため、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに入れられます。

* リクエストの最大数：10,000
* 最も古いリクエストからの最大経過時間：15分

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| リターゲティングリストID | メールアドレスの追加先となるメールリターゲティングリストのID。 |
| メールアドレス | 選択したメールリターゲティングリストに追加するメールアドレス。 |

#### 任意のパラメータ

| **パラメータ** | **説明** |
| --- | --- |
| ユーザーのメールアドレス（ハッシュ化済み） | メールアドレスがすでにハッシュ化されている場合は、このチェックボックスをオンにします。 |
| ユーザーのメールアドレス（SHA256ハッシュを適用） | 送信前にTealiumでメールアドレスをSHA256ハッシュ化する場合は、このチェックボックスをオンにします。 |
