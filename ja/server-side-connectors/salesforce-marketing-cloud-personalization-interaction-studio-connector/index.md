## API 情報

このコネクタは、次のベンダー API を使用します。

* API 名：Personalization Event API
* API バージョン：v2
* ドキュメント：[Personalization Event API](https://developer.salesforce.com/docs/marketing/personalization/guide/event-api.html)

## コネクタアクション

| **アクション名** | **訪問プロファイル** | **イベントデータ** |

| 信頼済みチャネル経由でイベントデータを送信（Evergage 名前空間） | ✓  | ✓ |

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を構成します。

* **アカウント名**  
（必須）Marketing Cloud Personalization のアカウント名。  
アカウント名を確認するには、Salesforce の **Interaction Studio UI** から **Gears** にアクセスし、URL を確認します。たとえば、Gears の URL が `https://demo.us-1.evergage.com/` の場合、アカウント名は `demo` です。
* **インスタンス識別子**  
（必須）Marketing Cloud Personalization のインスタンス識別子。  
インスタンス識別子を確認するには、Salesforce の **Interaction Studio UI** から **Gears** にアクセスし、URL を確認します。たとえば、Gears の URL が `https://demo.us-1.evergage.com/` の場合、インスタンス識別子は `us-1` です。
* **データセット識別子**  
（必須）データの送信先となる Marketing Cloud Personalization データセットの名前または識別子。
* **API キー ID**  
（必須）API トークンの生成に使用する API キー ID。  
API トークンの詳細については、[Salesforce：Personalization API Tokens](https://help.salesforce.com/s/articleView?id=mktg.mc_pers.htm&type=5)を参照してください。
* **API キーシークレット**  
（必須）API トークンの生成に使用する API キーシークレット。  
API トークンの詳細については、[Salesforce：Personalization API Tokens](https://help.salesforce.com/s/articleView?id=mktg.mc_pers.htm&type=5)を参照してください。

コネクタの構成が完了したら、**完了**をクリックします。

## アクション構成 — パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### アクション — 信頼済みチャネル経由でイベントデータを送信（SalesforceInteractions 名前空間）

#### イベントデータのパラメータ

| **パラメータ** | **説明**  |
|:------------------------|:-------------------|
| Explain | `true` の場合、キャンペーンがレンダリングされた、またはレンダリングされなかった理由に関する追加情報をレスポンスで返します。 |
| Page View | 値が `true` の場合、ページの読み込みによってイベントがトリガーされたことを示します。 |
| Time | （任意）UNIX エポックからイベント発生時までの経過時間を表す日時（ミリ秒単位）。このフィールドが null の場合は、現在時刻が自動的に入力されます。 |

#### インタラクションタイプのパラメータ

| **パラメータ** | **説明**  |
|:------------------------|:-------------------|
| Interaction Type | インタラクションタイプを選択します。<br> **Catalog Object Interaction**：カタログオブジェクトに関するエンゲージメントデータを取得します。<br> **Cart Interaction**：ユーザーのカート内容に関するエンゲージメントデータを取得します。<br> **Order Interaction**：ユーザーの注文内のアイテムに関するエンゲージメントデータを取得します。Personalization では、**PurchaseOrderInteraction** のみがユーザーの現在の注文に影響を与え、その注文を更新します。 |

#### インタラクション名のパラメータ

| **パラメータ** | **説明**  |
|:------------------------|:-------------------|
| Interaction Name | インタラクション名を選択します。選択した **Interaction Type** に応じた名前が表示されます。 |

#### カタログオブジェクトデータのパラメータ

| **パラメータ** | **説明**  |
|:------------------------|:-------------------|
| ID | カタログオブジェクトを表す一意の ID。 |
| Type | カタログオブジェクトを表すタイプ名。 |

#### カタログオブジェクト属性のパラメータ

| **パラメータ** | **説明**  |
|:------------------------|:-------------------|
| Catalog Object Attributes | **Interaction Type** セクションで選択したタイプが **Catalog Object Interaction** でない場合、このセクションは無視されます。<br>キーと値のペアは、カタログオブジェクトのメタデータとして保存されます。これらの属性は、プラットフォームで定義されている必要があります。<br>詳細および使用例については、[Salesforce：Marketing Cloud Personalization Event API](https://developer.salesforce.com/docs/marketing/personalization/guide/event-api.html)を参照してください。<br>ネストされたオブジェクトをサポートする必要がある場合は、**Templates** セクションを使用してテンプレートを定義できます。テンプレートは、その名前を対応する二重中括弧で囲んで参照し、マッピングする必要があります：`{{template_name}}`。 |

#### 関連カタログオブジェクトのパラメータ

| **パラメータ** | **説明**  |
|:------------------------|:-------------------|
| Related Catalog Objects | **Interaction Type** セクションで選択したタイプが **Catalog Object Interaction** でない場合、このセクションは無視されます。関連カタログオブジェクトは、キーと値のペアで構成されるオブジェクトの配列として指定します。これらの関連カタログオブジェクトは、プラットフォームで定義されている必要があります。詳細および使用例については、[Salesforce：Marketing Cloud Personalization Event API](https://developer.salesforce.com/docs/marketing/personalization/guide/event-api.html)を参照してください。 |

| **パラメータ** | **説明**  |
