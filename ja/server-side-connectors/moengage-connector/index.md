## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **ユーザー名**
（必須）MoEngageアカウントのユーザー名は、MoEngageダッシュボードで確認できます。詳細については、[MoEngageのドキュメント](https://developers.moengage.com/hc/en-us/articles/4404674776724-Overview#01H815VFPB3Y06MX539856QSK4)を参照してください。

* **パスワード**
（必須）MoEngageアカウントのパスワードは、MoEngageダッシュボードで確認できます。詳細については、[MoEngageのドキュメント](https://developers.moengage.com/hc/en-us/articles/4404674776724-Overview#01H815VFPB3Y06MX539856QSK4)を参照してください。

* **データセンター**
（必須）APIで使用するデータセンターです。詳細については、[MoEngageのデータセンターに関するドキュメント](https://help.moengage.com/hc/en-us/articles/360057030512-Data-Centers-in-MoEngage#01G5DQVXGT2KZMXTJPF77QPJ25)を参照してください。想定される値：0～4。

## アクション

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

### ユーザー情報の追加／変更（リアルタイム）

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| 顧客ID | （必須）MoEngage SDKで構成され、渡される一意の識別子です。 |
| 名前 | ユーザーの氏名です。 |
| 名 | ユーザーの名です。 |
| 姓 | ユーザーの姓です。 |
| メールアドレス | ユーザーのメールアドレスです。 |
| 年齢 | ユーザーの年齢です。 |
| 性別 | ユーザーの性別です。 |
| 携帯電話番号 | ユーザーの携帯電話番号です。例：**918888444411**。 |
| 緯度 | ユーザーの所在地の緯度です。 |
| 経度 | ユーザーの所在地の経度です。 |
| パブリッシャー名 | インストール元のパブリッシャー名です。例：**Google Ads**。 |
| 初回確認日時 | ISO 8601形式で示した、ユーザーが作成された日時です。例：**2019-05-21T03:47:35Z**。 |
| 最終確認日時 | ISO 8601形式で示した、ユーザーの最終確認日時です。例：**2020-05-01T03:52:35Z**。 |
| コンバージョン数 | ユーザーがこれまでに行ったコンバージョンの総数です。 |
| LTV | ユーザーの顧客生涯価値です。 |
| 配信停止 | メール配信停止属性です。構成値が**true**の場合、そのユーザーにはメールが送信されません。 |
| プラットフォーム | ユーザーのアクティブなプラットフォームに基づく値です。指定できる値は、**ANDROID**、**iOS**、または**web**です。 |
| アクティブ | プラットフォームのステータスです。 |

### ユーザー情報の追加／変更（バッチ）

#### バッチの制限

このアクションでは、ベンダーへの大量のデータ転送に対応するため、バッチリクエストを使用します。次のいずれかのしきい値に達するまで、リクエストはキューに格納されます。

* リクエストの最大数：50
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：1 MB

### イベントの追跡（リアルタイム）

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| 顧客ID | （必須）MoEngage SDKで構成され、渡される一意の識別子です。 |
| アクション | （必須） |
| デバイスID | デフォルト値は**顧客ID**の値です。この値は、イベントを特定のデバイスにマッピングするために使用されます。 |
| プラットフォーム | イベントが発生したプラットフォームを識別するために使用します。指定できる値は、**ANDROID**、**iOS**、**web**、または**unknown**です。 |
| アプリバージョン | イベントが発生したアプリのバージョンです。 |
| ローカル時刻 | イベントが発生したローカル時刻（秒単位）です。 |
| UTC時刻 | イベントが発生したUTC時刻（秒単位）です。 |
| ユーザータイムゾーンオフセット | -54000～54000の範囲の秒単位の値を指定する必要があります。たとえば、IST（UTC+0530）の場合、**ユーザータイムゾーンオフセット**は19800になります。 |

### オーディエンス／コホートへのユーザーの追加

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| ユーザーID | 登録済み／ログイン済みユーザーのユーザーIDです。**ユーザーID**または**匿名ID**のいずれかを指定する必要があります。両方が存在する場合、最初に**ユーザーID**を使用してユーザーの特定を試みます。ユーザーを特定できない場合は、**匿名ID**に基づいてユーザーの特定を試みます。 |
| 匿名ID | 未登録／未ログインユーザーの識別子です。 |
| タイムスタンプ | ISO 8601形式で示したリクエストのタイムスタンプです。例：**2019-05-21T03:47:35Z**。マッピングされていない場合、現在のタイムスタンプで初期化されます。 |
| コホート名 | コホートの名前です。この構成は、**Tealiumオーディエンス**セクションで選択したTealiumオーディエンス名より優先されます。 |
| コホートID | コホートのIDです。この構成は、**Tealiumオーディエンス**セクションで選択したTealiumオーディエンスIDより優先されます。 |
| コホートの説明 | コホートの説明です。 |
| Tealiumオーディエンス | TealiumオーディエンスIDとTealiumオーディエンス名をMoEngageコホートのIDおよび名前として使用するTealiumオーディエンスを選択します。<br> |
