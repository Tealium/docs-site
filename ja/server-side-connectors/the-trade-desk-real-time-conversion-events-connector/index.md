## 仕組み

The Trade Desk（TTD）リアルタイムコンバージョンイベントサーバーサイドコネクタは、コンバージョンイベントデータをTealiumからTTDインスタンスに送信し、アトリビューションの追跡とリターゲティングを支援します。

TealiumとThe Trade Deskのパートナーシップによる他の統合を使用して、このコネクタを拡張できます。イベントデータを送信する前に、Unified ID 2.0（UID2）またはEuropean Unified ID（EUID）関数を使用して、ユニバーサルユーザー識別子を生成して割り当てます。必要に応じて、タグ管理にTTD Universal Pixelを実装し、ユーザー行動をリアルタイムで包括的に把握できます。


<blockquote>
必要なすべてのパラメータが生成され、利用可能であることを、担当のTTD担当者と確認してください。
</blockquote>


## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：The Trade Desk API
* APIバージョン：v3
* APIエンドポイント：`https://insight.adsrvr.org`
* ドキュメント：[The Trade Desk API](https://partner.thetradedesk.com/v3/portal/data/doc/DataConversionEventsApi)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

The Trade Deskリアルタイムコンバージョンコネクタは、イベントマッピングとURLマッピングによるトラッキングをサポートしています。コネクタを構成するときは、使用する方式に応じて次のパラメータを構成します。

* **URLマッピング** - この方式では、ユーザーが訪問したページのURLが、リターゲティングおよびコンバージョン測定の基準としてTTDプラットフォーム内で割り当てられます。
    * ユーザーが閲覧したページの追跡を重視するWebサイトに推奨されます。
    * [TTD Universal Pixelタグ](https://docs.tealium.com/the-trade-desk-universal-pixel-tag/)と同じ方式を使用します。
    * 構成パラメータ：**広告主ID**および**Universal Pixel ID**。
* **イベントマッピング** - この方式では、イベント名（`Purchase`、`Addtocart`など）と、任意の関連コマース商品詳細を使用してコンバージョンを取得します。イベント名と商品は、リターゲティングおよびコンバージョン測定の基準としてTTDプラットフォーム内で評価されます。
    * 構成パラメータ：**マーチャントID**および**イベントトラッカーID**。

コネクタを追加した後、次の構成を構成します。

* **広告主ID**  
**マーチャントID**が指定されていない場合は必須です。トラッキング呼び出しの対象となる広告主の`advertiserId`です。
* **マーチャントID**  
**広告主ID**が指定されていない場合は必須です。`merchantId`は、オンボーディングプロセス中にTTDから提供されます。
* **ピクセルID**  
**イベントトラッカーID**が指定されていない場合は必須です。イベントのUniversal Pixel IDです。
* **イベントトラッカーID**  

コネクタを構成したら、**完了**をクリックします。
**ピクセルID**が指定されていない場合は必須です。イベントトラッカーのプラットフォームIDです。


<blockquote>
**広告主ID**を指定し、**Universal Pixel ID**を指定しない場合、コネクタリクエストはエラーを返します。
また、**構成ウィンドウ**のすべてのパラメータに値を入力することは避け、選択した方式に必要な値のみを指定することをお勧めします。たとえば、**広告主ID**と**マーチャントID**の両方を指定しないでください。代わりに、使用するトラッキング方式で必要な構成構成のみを入力してください。
</blockquote>


## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| コンバージョンイベントを送信 | ✗ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### コンバージョンイベントを送信

イベントがTTDインスタンス内で適切に定義されていることを確認してください。定義されていない場合、TTDから402エラーが返される可能性があります。

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| コンバージョンイベント名 | パートナープラットフォームによって定義されるイベントのタイプです。使用可能なイベントタイプ：<ul><li>`addtocart`：ユーザーがショッピングカートに商品を追加しました。</li><li>`purchase`：ユーザーが購入を完了し、**サンキューページ**が表示されました。</li><li>`viewitem`：ユーザーが商品またはSKU番号を閲覧しました。</li><li>`searchitem`：ユーザーが商品またはSKU番号を検索しました。</li><li>`searchcategory`：ユーザーがカテゴリを検索しました。</li><li>`login`：ユーザーがサイトにログインしました。</li><li>`messagebusiness`：ユーザーが事業者にメッセージを送信したか、フォームまたはメールで事業者に連絡しました。</li><li>`direction`：ユーザーが事業者までの経路をリクエストし、取得しました。</li><li>`startcheckout`：ユーザーがチェックアウトプロセスを開始しました。</li><li>`viewcart`：ユーザーがショッピングカートの内容を閲覧しました。</li><li>`sitevisit`：ユーザーがサイトを訪問しました。</li><li>`wishlistitem`：ユーザーが商品またはSKU番号をウィッシュリストに追加しました。</li></ul>|

#### ユーザー識別子パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| UID2 | 44文字のBase64エンコードされたSHA-256文字列として表される、ユーザーのUnified ID 2.0です。詳細については、[use-visitor-function-uid20](https://docs.tealium.com/use-visitor-function-uid20/)および[TTD：Unified ID](https://api.thetradedesk.com/v3/portal/data/doc/UnifiedIDs)を参照してください。 |
| UID2トークン（暗号化された広告トークン）| 暗号化されたUID2広告トークンです。このトークンでは大文字と小文字が区別されます。 |
| EUID | 44文字のBase64エンコードされたSHA-256文字列として表される、ユーザーのEuropean Unified IDです。詳細については、[use-visitor-function-euid](https://docs.tealium.com/use-visitor-function-euid/)および[Unified ID](https://api.thetradedesk.com/v3/portal/data/doc/UnifiedIDs)を参照してください。 |
| TDID | このユーザーに対するThe Trade Deskの36文字のGUID（ハイフンを含む）です。[The Trade Desk Cookie Matching Serviceタグ](https://docs.tealium.com/the-trade-desk-cookie-matching-service-tag/)を通じて取得できます。|
| IDFA | iOSデバイス用の広告識別子です。 |
| AAID | Androidデバイス用の広告識別子です。 |
| DAID | このユーザーの未加工のデバイスIDです。36文字のGUID形式（ハイフンを含む）で送信されます。 |
| NAID | Windowsデバイス用の広告識別子です。 |
| IDL | 49文字または70文字のRampID（旧称IdentityLink）です。<br>注：これは、The Trade Desk専用にマッピングされたLiveRampのRampIDである必要があります。RampIDのマッピングの詳細については、[LiveRampのドキュメント](https://sidecar.readme.io/docs/getting-started)を参照してください。 |

#### イベントパラメータ

次のパラメータはコンバージョンイベントに関連付けられており、説明に特定のイベントについて必須である旨が記載されている場合を除き、任意です。

| **パラメータ** | **説明** |
| --- | --- |
| 注文ID | イベントに関連付けられた注文識別子です。 |
| リファラーURL | イベントが発生したWebサイトのURL（存在する場合）です。URLマッピングを使用する場合は必須です。 |
| 購入金額 | 小数点としてカンマではなくピリオドを使用する、収益トラッキング値です。 |
| 購入通貨 | 収益値に対するISO 4217通貨コードです。購入イベントでは必須です。 |
| クライアントIPアドレス | マシン上のネットワークインターフェイスを一意に識別する、クライアントのIPv4またはIPv6アドレスです。 |
| インプレッションID | イベントインプレッションの一意のIDとして機能する36文字の文字列（ハイフンを含む）です。 |

#### 商品パラメータ

商品をマッピングする場合は、文字列データ属性の配列を使用して複数の商品を割り当てます。マッピングされた属性に、受信したコンバージョンイベントの適切なデータが入力されていることを確認してください。

| **パラメータ** | **説明** |
| --- | --- |
| 商品コード | （必須）SKU番号などの商品識別子です。 |
| 名前（`name`） | 商品コードに関連付けられた名前です。 |
| 数量（`qty`） | その商品コードについて注文された商品の数です。 |
| 価格（`price`） | 商品の単価です。 |
| カテゴリ（`cat`） | 商品カテゴリIDです。注：リアルタイムコンバージョンイベントAPIは、マーチャントの商品カタログに指定された商品コードが存在し、そのカテゴリIDが異なる場合を除き、すべての場合に指定された値を使用します。この場合は、商品カタログのカテゴリIDが使用されます。 |
#### プライバシー構成プロパティ

プライバシー構成は任意です。いずれかのプライバシー構成プロパティをマッピングする場合は、3つのプロパティすべてが必須です。

| **パラメーター** | **説明** |
| --- | --- |
| `privacy_type` | オブジェクトごとに、次の値のいずれか1つのみを指定します。<ul><li>GDPR（一般データ保護規則）：欧州経済領域（EEA）に適用されます。</li><li>GPP（グローバルプライバシープラットフォーム）：適用対象となるプライバシー規制が存在する米国の州のユーザーを対象としています。</li></ul> |
| `is_applicable` | `privacy_type`パラメーターで指定された値が適用されるかどうかを示します。有効な値は`true`または`1`です。 |
| `consent_string` | プライバシー規制が適用される場合のユーザーの同意情報です。詳細については、[IAB Tech Lab：GDPR透明性・同意フレームワーク](https://iabtechlab.com/standards/gdpr-transparency-and-consent-framework/)を参照してください。 |

#### カスタムプロパティ

新規ブランド顧客であることを示すフラグ、製品名、その他レポートに役立つ詳細情報など、追加のコンバージョンメタデータを指定するために使用できる、`td1`から`td10`までの連番が付いた10個のカスタム動的プロパティです。
