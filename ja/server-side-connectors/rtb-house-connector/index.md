## 構成

コネクターマーケットプレイスに移動し、新しいコネクターを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクターを追加した後、次の構成を構成します。
* **RTB House Partner Key**  
  * RTB Houseによって組織に割り当てられる一意の識別子です。このキーは、連携を認証するために必要です。取得するには、RTB Houseのアカウントマネージャーにお問い合わせください。
* **RTB House Tagging Hash**  
  * タグ付けイベントをアカウントに正しく関連付けるためにRTB Houseが使用する一意のハッシュです。Tagging Hashの値を取得するには、RTB Houseのアカウントマネージャーにお問い合わせください。
* **RTB House Region**  
  * RTB Houseアカウントに関連付けられている地域別サブドメインです。これにより、イベントとリクエストが適切にルーティングされます。地域が不明な場合は、RTB Houseのアカウントマネージャーにお問い合わせください。

コネクターを構成したら、**Done**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| Send Event | ✗ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。

### Send Event

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| Event Code | 使用可能なオプションは次のとおりです。<ul><li>**Home** - Webサイトのホームページへのアクセスに使用します。</li><li>**Category2** - カテゴリーページへのアクセスに使用します。</li><li>**Offer** - 商品ページへのアクセスに使用します。</li><li>**Listing** - 検索結果ページへのアクセスに使用します。</li><li>**Basket add** - 商品をカートに追加する場合に使用します。</li><li>**Basket status** - ショッピングカートページを表示する場合に使用します。</li><li>**Start order** - チェックアウトページなど、注文処理を開始するページへのアクセスに使用します。</li><li>**Conversion Order** - 注文確認ページに使用します。</li></ul> |

#### イベント属性

| **パラメーター** | **説明** |
| --- | --- |
| UID | 匿名ユーザーID（Web Pixelで使用されるものと同じ）。 |
| Time | UNIXエポック（1970年1月1日00:00:00 UTC）からの経過ミリ秒で表したイベント発生時刻。 |
