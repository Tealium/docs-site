## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：OpenAI Events API
* APIバージョン：v1
* APIエンドポイント：`https://bzr.openai.com`

## 構成

Connector Marketplaceに移動して、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の項目を構成します。

* **OpenAI Events APIキー**：必須。OpenAI Events APIへのリクエストの認証に使用するBearerトークンです。このキーは、BearerトークンとしてAuthorizationヘッダーで送信されます。この値のプロビジョニングについては、OpenAIのアカウントチームにお問い合わせください。
* **Pixel ID**：必須。OpenAI Pixel ID（`pid`）です。この値は、クエリパラメータとしてAPIエンドポイントに追加されます。Pixel IDは、**OpenAI Ads > Settings > Conversions**で確認できます。送信する各コンバージョンイベント（`page_viewed`、`items_added`、`order_created`など）は、ライブイベントがレポートに計上されるように、あらかじめそこでピクセルに登録しておく必要があります。
* **デフォルトのアクションソース**：コンバージョンイベントのデフォルトのソースを選択します。デフォルトは**Web**です。アクションごとに変更するには、アクションソースパラメータを使用します。
* **ベースURLの上書き**：デフォルトは`https://bzr.openai.com`です。サンドボックス環境またはステージング環境についてOpenAIから指示された場合にのみ上書きしてください。

## コネクタアクション

| アクション名 | AudienceStream | EventStream |
| ----------- | :------------: | :---------: |
| イベントを送信（リアルタイム） | ✓ | ✓ |
| イベントを送信（バッチ） | ✓ | ✓ |

### イベントを送信（リアルタイム）

#### パラメータ

**イベントタイプ**

必須。OpenAIに送信するイベントのタイプを選択します。各値は、OpenAI Events APIの`type`フィールドにマッピングされます。サポートされている値は次のとおりです。

* `appointment_scheduled`
* `attribution_appended`
* `checkout_started`
* `contents_viewed`
* `custom`
* `items_added`
* `lead_created`
* `order_created`
* `page_viewed`
* `registration_completed`
* `subscription_created`
* `trial_started`

各イベントタイプは、`contents`、`customer_action`、`plan_enrollment`、`custom`、`attribution`の5つのデータタイプオブジェクトのいずれかにマッピングされます。`attribution_appended`のフィールドについては、[元のイベントデータ](#original-event-data)および[アトリビューションデータ](#attribution-data)を参照してください。

`attribution_appended`は、以前のコンバージョンを参照する個別のアトリビューションレポートを送信します。**イベントデータ**では、**イベントID**がアトリビューションレポートのIDです。このIDは一意である必要があり、まったく同じリクエストを再試行する際には再利用する必要があります。**タイムスタンプ**はレポートの生成時刻で、デフォルトでは送信時刻になります。


<blockquote>
`attribution_appended`は、OpenAIがお客様の広告主ピクセルに対して有効にした後にのみ使用できます。本番環境で使用する前に、OpenAIのアカウントチームに連絡して利用可能かどうかを確認してください。
</blockquote>


**カスタムイベント名**

イベントタイプが**カスタム**の場合は必須です。イベントのカスタム名を指定します。この値は、その他すべてのイベントタイプでは無視されます。

#### イベントデータ

Tealium属性をOpenAIの最上位イベントフィールドにマッピングします。


<blockquote>
**アトリビューション追加**イベントでは、**イベントID**、**タイムスタンプ**、**アクションソース**、**ソースURL**、**OPPRef**のみが送信されます。**イベントID**はアトリビューションレポートのIDです。このIDは一意である必要があり、まったく同じリクエストを再試行する際には再利用する必要があります。**タイムスタンプ**はレポートの生成時刻で、マッピングされていない場合はデフォルトで送信時刻になります。
</blockquote>


| パラメータ | 説明 |
| --- | --- |
| イベントID | 必須。重複排除に使用されるイベントの一意の識別子です。 |
| タイムスタンプ | 必須。ミリ秒単位のイベントタイムスタンプです。過去7日以内、または未来10分以内である必要があります。 |
| OPPRef | OpenAIのプライバシー保護識別子です。 |
| ソースURL | アクションソースが`web`の場合は必須です。イベントが発生したページのURLです。 |
| アクションソース | コンバージョンイベントのソースです。サポートされている値：`web`、`mobile_app`、`offline`、`physical_store`、`phone_call`、`email`、`other`。 |
| オプトアウト | イベントをパーソナライズの対象外として指定するには、`true`に構成します。 |

#### ユーザーデータ


<blockquote>
ユーザーデータは、**アトリビューション追加**イベントでは送信されません。
</blockquote>


* アトリビューションの精度を向上させるため、該当するユーザー識別子をマッピングします。各PIIフィールドについて、値をあらかじめ自身でハッシュ化するか、コネクタでハッシュ化するかを選択できます。
* ハッシュ化可能なフィールドには2つの列があります。（SHA256ハッシュを適用）は、コネクタで正規化およびハッシュ化する未加工の値用です。（SHA256でハッシュ化済み）は、すでにハッシュ化した値用です。
* サポートされているPIIキー（ハッシュ化必須）：`email_address`、`phone_number`、`external_id`、`country`、`city`、`zip_code`。
* ハッシュ化せずに送信されるフィールド：`external_id_raw`、`ip_address`、`user_agent`。

| パラメータ | 説明 |
| --- | --- |
| メールアドレス（SHA256ハッシュを適用） | 小文字のプレーンテキストのメールアドレスを指定すると、コネクタがOpenAIで想定される形式にハッシュ化します。空またはnullの値は無視されます。 |
| メールアドレス（SHA256でハッシュ化済み） | SHA256でハッシュ化済みのメールアドレスを指定します。 |
| 電話番号（SHA256ハッシュを適用） | 小文字のプレーンテキストの電話番号を指定すると、コネクタがOpenAIで想定される形式にハッシュ化します。空またはnullの値は無視されます。 |
| 電話番号（SHA256でハッシュ化済み） | SHA256でハッシュ化済みの電話番号を指定します。 |
| 外部ID（SHA256ハッシュを適用） | ロイヤルティカードIDやその他の識別子など、プレーンテキストの外部IDを指定すると、コネクタがOpenAIで想定される形式にハッシュ化します。 |
| 外部ID（SHA256でハッシュ化済み） | SHA256でハッシュ化済みの外部IDを指定します。 |
| 国（SHA256ハッシュを適用） | イベントに関連付けられた国を指定すると、コネクタがOpenAIで想定される形式にハッシュ化します。 |
| 国（SHA256でハッシュ化済み） | SHA256でハッシュ化済みの国の値を指定します。 |
| 市区町村（SHA256ハッシュを適用） | コンバージョンに関連付けられた市区町村を小文字で指定すると、コネクタがOpenAIで想定される形式にハッシュ化します。 |
| 市区町村（SHA256でハッシュ化済み） | SHA256でハッシュ化済みの市区町村の値を指定します。 |
| 郵便番号（SHA256ハッシュを適用） | 郵便番号を小文字で指定すると、コネクタがOpenAIで想定される形式にハッシュ化します。 |
| 郵便番号（SHA256でハッシュ化済み） | SHA256でハッシュ化済みの郵便番号を指定します。 |
| 外部ID（未加工） | ロイヤルティカードIDやその他の識別子などの一意のIDです。ハッシュ化せずに送信されます。 |
| IPアドレス | デバイスのIPアドレスです。 |
| ユーザーエージェント | ユーザーのWebブラウザーのユーザーエージェント文字列です。 |

#### 元のイベントデータ

これらのフィールドは、**イベントタイプ**が`attribution_appended`に構成されている場合にのみ適用されます。このアトリビューションレポートが参照する元のコンバージョンイベントにマッピングしてください。

| パラメータ | 説明 |
| --- | --- |
| イベントID | 必須。元のコンバージョンイベントの`event_id`です。この値を正確にコピーしてください。再生成しないでください。 |
| イベントタイプ | 必須。元のコンバージョンイベントの`type`値です。サポートされている値：`app_installed`、`app_opened`、`appointment_scheduled`、`checkout_started`、`contents_viewed`、`custom`、`items_added`、`lead_created`、`order_created`、`page_viewed`、`registration_completed`、`subscription_created`、`trial_started`。 |
| タイムスタンプ（ms） | 必須。Unixミリ秒単位の元のコンバージョンイベントのタイムスタンプです。7日より前でもかまいません。 |
| カスタムイベント名 | 元のイベントタイプが`custom`の場合は必須です。その他すべてのイベントタイプでは省略してください。 |
| 注文ID | 任意。元の注文へのメタデータ参照です。**イベントID**の代わりにはなりません。 |
#### アトリビューションデータ

これらのフィールドは、**イベントタイプ**が `attribution_appended` に構成されている場合にのみ適用されます。元のコンバージョンへの貢献が認められたOpenAI広告のタッチポイントを表し、Tealiumによって自動マッピングまたは生成されることはありません。

必須のアトリビューションフィールドが1つでも欠けている場合、コネクタはイベントを送信しません。検証エラーがTraceとコネクタログに表示されます。

| パラメータ | 説明 |
| --- | --- |
| 広告ID | 必須。貢献が認められるOpenAI広告（`ad_id`）。 |
| タッチポイントのタイムスタンプ（ミリ秒） | 必須。広告タッチポイントのタイムスタンプ（Unixミリ秒）。7日より前の値も指定できます。 |
| タッチポイントタイプ | 必須。タッチポイントのタイプ（例：`ad_click`）。 |
| アトリビューション配分 | 必須。0以上1以下の数値。 |
| アトリビューション金額 | 必須。通貨の補助単位で表した整数（例：`6500` = $65.00）。 |
| アトリビューションモデル | 必須。サポートされる値：`customized_multi_touch`、`data_driven`、`first_click`、`first_touch`、`last_click`、`last_touch`、`linear`、`position_based`、`time_decay`。 |
| 合計クレジット | 任意。クレジットの合計値を表す数値。 |
| アトリビューション期間（日） | 任意。アトリビューション期間の日数を表す0以上の整数。 |

#### Eコマース

顧客アクションイベント（**予約のスケジュール構成**、**リードの作成**、**登録の完了**）では、注文概要フィールドのみが受け入れられます。OpenAIは、送信ペイロードからその他すべてのEコマースフィールドを除外します。

**アトリビューションの追加**イベントでは、**通貨**、**金額**、**金額 - 補助単位に変換**、**補助単位係数**、**データコンテンツタイプ**、**顧客セグメンテーション**のみが受け入れられます。Eコマースの自動マッピングは適用されません。

金額値には、次の2つの方法を使用できます。

* **変換済みの値**：補助単位ですでに表されている値（例：$29.90 USDの場合は`2990`）を、**金額**または**コンテンツ金額（単位あたり）**にマッピングします。
* **送信時に変換**：主要通貨単位の小数値（例：`29.90`）を、**金額 - 補助単位に変換**または**コンテンツ金額（単位あたり）- 補助単位に変換**にマッピングし、**補助単位係数**を通貨に適した乗数に構成します（例：USD/EUR/GBPの場合は`100`、JPY/KRWの場合は`1`、KWD/BHD/OMRの場合は`1000`）。

同じフィールドに両方の形式がマッピングされている場合、変換済みの値が優先されます。

| パラメータ | 説明 |
| --- | --- |
| 金額 | 補助単位ですでに表されている整数（例：$29.90 USDの場合は`2990`）。指定する場合は通貨が必須です。アトリビューションの追加イベントでは、これは元のコンバージョン値です。**金額**と**金額 - 補助単位に変換**の両方がマッピングされている場合、この値が優先されます。 |
| 金額 - 補助単位に変換 | 主要通貨単位の小数値（例：`29.90`）。コネクタは、この値に**補助単位係数**を乗算し、その結果を四捨五入して整数にしてから送信します。指定する場合は通貨が必須です。係数が構成されていない場合、コネクタは乗算を行わず、値を最も近い整数に丸めます。 |
| 補助単位係数 | 補助単位に変換する形式を使用する場合に適用する乗数。USD、EUR、GBPには`100`を使用します。JPYまたはKRWには`1`を使用します。KWD、BHD、OMRには`1000`を使用します。正の数である必要があります。この値はOpenAIには送信されません。 |
| 通貨 | **金額**または**金額 - 補助単位に変換**を指定する場合に必須です。アトリビューションの追加イベントでも必須です。ISO 4217形式の通貨コード（例：`USD`）。 |
| コンテンツ金額（単位あたり） | 補助単位ですでに表されている整数。明細項目コンテンツの項目単価です。**コンテンツ金額（単位あたり）**と**コンテンツ金額（単位あたり）- 補助単位に変換**の両方がマッピングされている場合、この値が優先されます。 |
| コンテンツ金額（単位あたり）- 補助単位に変換 | 項目単位の主要通貨単位による小数価格。コネクタは、この値に**補助単位係数**を乗算し、その結果を四捨五入して整数にしてから送信します。係数が構成されていない場合、コネクタは乗算を行わず、値を最も近い整数に丸めます。 |
| データコンテンツタイプ | アトリビューションの追加イベントのみ。任意。 |
| 顧客セグメンテーション | アトリビューションの追加イベントのみ。任意。 |

#### Eコマースの自動マッピングを無効化

* オンにすると、このアクションに対するTealiumからOpenAIへのデフォルトのEコマース自動マッピングが無効になります。対象は、`timestamp_ms`（Tealiumのイベント時刻から取得）、`source_url`（標準URL属性から取得）、および小売拡張属性の`_csubtotal`、`_ccurrency`、`_csku`、`_cprodname`、`_ccat`、`_cquan`、`_cprice`です。
* 明示的なフィールドマッピングが常に優先されます。オフにした場合は、未構成のフィールドのみが補完されます。
* **補助単位係数**がマッピングされている場合、コネクタは自動マッピングされた`_csubtotal`と`_cprice`の値にも係数を乗算してから送信します。
* ID情報の自動マッピング（IPアドレスとユーザーエージェント）は、**ID情報の自動マッピングを無効化**チェックボックスによって別途制御されます。


<blockquote>
従来の**自動マッピングを無効化**チェックボックスを有効にして、IPアドレスとユーザーエージェントの自動マッピングを抑止していた場合は、**ID情報の自動マッピングを無効化**も有効にする必要があります。従来のチェックボックスは、現在はEコマースフィールドの自動マッピングのみを制御します。
</blockquote>


#### ID情報の自動マッピングを無効化

* オンにすると、コネクタはIPアドレスとユーザーエージェントを自動的にマッピングしません。IDメタデータを完全に手動で制御する場合や、プライバシー上の理由からこれらのフィールドを除外する必要がある場合に使用します。
* オフ（デフォルト）の場合、コネクタは`ip_address`（Tealiumの標準IP属性から取得）と`user_agent`（Tealiumの標準ユーザーエージェント属性から取得）を自動的にマッピングします。

#### デバッグモード

有効にすると、コネクタは`validate_only: true`を指定してイベントを送信します。これにより、OpenAIはイベントを保存せずにペイロードを検証し、エラーがあれば返します。トラブルシューティングやドライランに使用してください。本番トラフィックでは無効のままにしてください。

#### ピクセルIDの上書き

任意。このアクションに対して、コネクタレベルのピクセルIDを上書きします。指定した場合、コネクタ構成で構成されたピクセルIDの代わりに、この値が使用されます。

#### APIキーの上書き

任意。このアクションに対して、コネクタレベルのAPIキーを上書きします。指定した場合、コネクタ構成で構成されたAPIキーの代わりに、この値が使用されます。

### イベントを送信（バッチ）

#### バッチ制限

このアクションでは、ベンダーへの大量データ転送をサポートするためにバッチリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに保持されます。

* リクエストの最大数：1,000
* 最も古いリクエストからの最大経過時間：5分
* リクエストの最大サイズ：1 MB

このアクションでは、**イベントを送信（リアルタイム）**アクションと同じパラメータおよびマッピングオプションを使用します。詳細については、[イベントを送信（リアルタイム）](#send-event-real-time)を参照してください。


<blockquote>
`attribution_appended`イベントタイプのバッチ配信は、まだサポートされていません。アトリビューションイベントには、**イベントを送信（リアルタイム）**アクションを使用してください。
</blockquote>
