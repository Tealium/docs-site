## API情報

このコネクタでは、次のベンダーAPIを使用します。

* API名：OpenAI Events API
* APIバージョン：v1
* APIエンドポイント：`https://bzr.openai.com`

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を構成します。

* **OpenAI Events APIキー**：必須。OpenAI Events APIへのリクエストの認証に使用するBearerトークンです。このキーは、BearerトークンとしてAuthorizationヘッダーで送信されます。この値は、OpenAIのアカウントチームから提供を受けることができます。
* **ピクセルID**：必須。OpenAIピクセルID（`pid`）です。この値は、クエリパラメータとしてAPIエンドポイントに追加されます。ピクセルIDは、**OpenAI Ads > Settings > Conversions**で確認できます。送信する各コンバージョンイベント（`page_viewed`、`items_added`、`order_created`など）は、ライブイベントをレポートに計上する前に、そのピクセルに対して登録する必要があります。
* **デフォルトのアクションソース**：コンバージョンイベントのデフォルトのソースを選択します。デフォルトは**Web**です。アクションソースパラメータを使用して、アクションごとに上書きできます。
* **ベースURLの上書き**：デフォルトは`https://bzr.openai.com`です。サンドボックス環境またはステージング環境についてOpenAIから指示された場合にのみ上書きしてください。

## コネクタのアクション

| アクション名 | AudienceStream | EventStream |
| ----------- | :------------: | :---------: |
| イベントを送信（リアルタイム） | ✓ | ✓ |
| イベントを送信（バッチ） | ✓ | ✓ |

### イベントを送信（リアルタイム）

#### パラメータ

**イベントタイプ**

必須。OpenAIに送信するイベントのタイプを選択します。各値は、OpenAI Events APIの`type`フィールドに対応します。サポートされる値は次のとおりです。

* `appointment_scheduled`
* `attribution_appended`
* `checkout_started`
* `contents_viewed`
* `custom`
* `items_added`
* `lead_created`
* `order_created`
* `page_viewed`
* `registration_completed`
* `subscription_created`
* `trial_started`

各イベントタイプは、`contents`、`customer_action`、`plan_enrollment`、`custom`、`attribution`の5つのデータタイプオブジェクトのいずれかに対応します。`attribution_appended`のフィールドについては、[元のイベントデータ](#original-event-data)および[アトリビューションデータ](#attribution-data)を参照してください。

`attribution_appended`は、以前のコンバージョンを参照する個別のアトリビューションレポートを送信します。**イベントデータ**の**イベントID**は、アトリビューションレポートのIDです。一意である必要があり、まったく同じ再試行では同じ値を再利用する必要があります。**タイムスタンプ**はレポートの生成時刻で、デフォルトでは送信時刻になります。


<blockquote>
`attribution_appended`は、OpenAIが広告主のピクセルに対して有効にした後にのみ使用できます。本番環境で使用する前に、OpenAIのアカウントチームに連絡して利用可否を確認してください。
</blockquote>


**カスタムイベント名**

イベントタイプが**カスタム**の場合は必須です。イベントのカスタム名を指定します。この値は、その他のすべてのイベントタイプでは無視されます。

#### イベントデータ

Tealium属性をOpenAIの最上位イベントフィールドにマッピングします。


<blockquote>
**アトリビューション追加**イベントでは、**イベントID**、**タイムスタンプ**、**アクションソース**、**ソースURL**、**OPPRef**のみが送信されます。**イベントID**はアトリビューションレポートのIDです。一意である必要があり、まったく同じ再試行では同じ値を再利用する必要があります。**タイムスタンプ**はレポートの生成時刻で、マッピングされていない場合はデフォルトで送信時刻になります。
</blockquote>


| パラメータ | 説明 |
| --- | --- |
| イベントID | 必須。重複排除に使用される、イベントの一意の識別子です。 |
| タイムスタンプ | 必須。ミリ秒単位のイベントタイムスタンプです。過去7日以内、または未来10分以内である必要があります。 |
| OPPRef | OpenAIのプライバシー保護識別子です。 |
| ソースURL | アクションソースが`web`の場合は必須です。イベントが発生したページのURLです。 |
| アクションソース | コンバージョンイベントのソースです。サポートされる値：`web`、`mobile_app`、`offline`、`physical_store`、`phone_call`、`email`、`other`。 |
| オプトアウト | イベントをパーソナライズの対象外として指定するには、`true`に構成します。 |

#### ユーザーデータ


<blockquote>
**アトリビューション追加**イベントでは、ユーザーデータは送信されません。
</blockquote>


* アトリビューションの精度を向上させるため、該当するユーザー識別子をマッピングします。各PIIフィールドについて、値を事前にハッシュ化するか、コネクタにハッシュ化させることができます。
* ハッシュ化可能なフィールドには2つの列があります。（SHA256ハッシュを適用）は、コネクタで正規化してハッシュ化する未加工の値に使用し、（SHA256でハッシュ化済み）は、すでにハッシュ化した値に使用します。
* サポートされるPIIキー（ハッシュ化必須）：`email_address`、`phone_number`、`external_id`、`country`、`city`、`zip_code`。
* ハッシュ化せずに送信されるフィールド：`external_id_raw`、`ip_address`、`user_agent`。

| パラメータ | 説明 |
| --- | --- |
| メールアドレス（SHA256ハッシュを適用） | 小文字のプレーンテキスト形式のメールアドレスを指定すると、コネクタがOpenAIで想定される形式にハッシュ化します。空またはnullの値は無視されます。 |
| メールアドレス（SHA256でハッシュ化済み） | SHA256でハッシュ化済みのメールアドレスを指定します。 |
| 電話番号（SHA256ハッシュを適用） | 小文字のプレーンテキスト形式の電話番号を指定すると、コネクタがOpenAIで想定される形式にハッシュ化します。空またはnullの値は無視されます。 |
| 電話番号（SHA256でハッシュ化済み） | SHA256でハッシュ化済みの電話番号を指定します。 |
| 外部ID（SHA256ハッシュを適用） | ロイヤルティカードIDやその他の識別子など、プレーンテキスト形式の外部IDを指定すると、コネクタがOpenAIで想定される形式にハッシュ化します。 |
| 外部ID（SHA256でハッシュ化済み） | SHA256でハッシュ化済みの外部IDを指定します。 |
| 国（SHA256ハッシュを適用） | イベントに関連付けられた国を指定すると、コネクタがOpenAIで想定される形式にハッシュ化します。 |
| 国（SHA256でハッシュ化済み） | SHA256でハッシュ化済みの国の値を指定します。 |
| 市区町村（SHA256ハッシュを適用） | コンバージョンに関連付けられた市区町村を小文字で指定すると、コネクタがOpenAIで想定される形式にハッシュ化します。 |
| 市区町村（SHA256でハッシュ化済み） | SHA256でハッシュ化済みの市区町村の値を指定します。 |
| 郵便番号（SHA256ハッシュを適用） | 小文字の郵便番号を指定すると、コネクタがOpenAIで想定される形式にハッシュ化します。 |
| 郵便番号（SHA256でハッシュ化済み） | SHA256でハッシュ化済みの郵便番号を指定します。 |
| 外部ID（未加工） | ロイヤルティカードIDやその他の識別子などの一意のIDです。ハッシュ化せずに送信されます。 |
| IPアドレス | デバイスのIPアドレスです。 |
| ユーザーエージェント | ユーザーのWebブラウザのユーザーエージェント文字列です。 |

#### 元のイベントデータ

これらのフィールドは、**イベントタイプ**が`attribution_appended`に構成されている場合にのみ適用されます。このアトリビューションレポートが参照する元のコンバージョンイベントにマッピングします。

| パラメータ | 説明 |
| --- | --- |
| イベントID | 必須。元のコンバージョンイベントの`event_id`です。この値を正確にコピーしてください。再生成しないでください。 |
| イベントタイプ | 必須。元のコンバージョンイベントの`type`値です。サポートされる値：`app_installed`、`app_opened`、`appointment_scheduled`、`checkout_started`、`contents_viewed`、`custom`、`items_added`、`lead_created`、`order_created`、`page_viewed`、`registration_completed`、`subscription_created`、`trial_started`。 |
| タイムスタンプ（ms） | 必須。Unixミリ秒単位の元のコンバージョンイベントのタイムスタンプです。7日以上前でもかまいません。 |
| カスタムイベント名 | 元のイベントタイプが`custom`の場合は必須です。その他のすべてのイベントタイプでは省略します。 |
| 注文ID | 任意。元の注文に対するメタデータ参照です。**イベントID**の代わりにはなりません。 |
#### アトリビューションデータ

これらのフィールドは、**イベントタイプ**が `attribution_appended` に構成されている場合にのみ適用されます。元のコンバージョンに貢献したとされる OpenAI 広告のタッチポイントを表し、Tealium によって自動マッピングまたは生成されることはありません。

必須のアトリビューションフィールドが不足している場合、コネクタはイベントを送信しません。Trace およびコネクタログに検証エラーが表示されます。

| パラメータ | 説明 |
| --- | --- |
| 広告 ID | 必須。貢献が割り当てられる OpenAI 広告（`ad_id`）。 |
| タッチポイントのタイムスタンプ（ミリ秒） | 必須。広告タッチポイントの Unix 時間（ミリ秒）。7 日より前の値も指定できます。 |
| タッチポイントタイプ | 必須。タッチポイントのタイプ（例：`ad_click`）。 |
| アトリビューション配分 | 必須。0 以上 1 以下の数値。 |
| アトリビューション金額 | 必須。通貨の最小単位による整数（例：`6500` = 65.00 米ドル）。 |
| アトリビューションモデル | 必須。サポートされる値：`customized_multi_touch`、`data_driven`、`first_click`、`first_touch`、`last_click`、`last_touch`、`linear`、`position_based`、`time_decay`。 |
| 合計クレジット | 任意。クレジットの合計値を表す数値。 |
| アトリビューション期間（日数） | 任意。アトリビューション期間を表す 0 以上の整数の日数。 |

#### E コマース

顧客アクションイベント（**予約日時の確定**、**リードの作成**、**登録の完了**）では、注文概要フィールドのみが受け付けられます。OpenAI は、送信ペイロードからその他すべての E コマースフィールドを除外します。

**アトリビューションの追加**イベントでは、**通貨**、**金額**、**データコンテンツタイプ**、**顧客セグメンテーション**のみが受け付けられます。E コマースの自動マッピングは適用されません。

| パラメータ | 説明 |
| --- | --- |
| 金額 | 最小単位（例：セント）による整数。指定する場合は、通貨が必須です。アトリビューションの追加イベントでは、元のコンバージョン値を表します。 |
| 通貨 | アトリビューションの追加イベントでは必須です。ISO 4217 形式の通貨コード（例：`USD`）。 |
| データコンテンツタイプ | アトリビューションの追加イベントのみ。任意。 |
| 顧客セグメンテーション | アトリビューションの追加イベントのみ。任意。 |

#### E コマース自動マッピングの無効化

* オンにすると、このアクションに対するデフォルトの Tealium から OpenAI への E コマース自動マッピングが無効になります。対象は、`timestamp_ms`（Tealium のイベント時刻から取得）、`source_url`（標準 URL 属性から取得）、および小売拡張属性 `_csubtotal`、`_ccurrency`、`_csku`、`_cprodname`、`_ccat`、`_cquan`、`_cprice` です。
* 明示的なフィールドマッピングが常に優先されます。このチェックを外した場合、未構成のフィールドのみが補完されます。
* ID の自動マッピング（IP アドレスとユーザーエージェント）は、**ID 自動マッピングの無効化**チェックボックスで個別に制御します。


<blockquote>
従来の **自動マッピングの無効化**チェックボックスをオンにして、IP アドレスとユーザーエージェントの自動マッピングを抑止していた場合は、**ID 自動マッピングの無効化**もオンにする必要があります。従来のチェックボックスでは、現在は E コマースフィールドの自動マッピングのみが制御されます。
</blockquote>


#### ID 自動マッピングの無効化

* オンにすると、コネクタは IP アドレスとユーザーエージェントを自動的にマッピングしません。ID メタデータを完全に手動で制御する場合や、プライバシー上の理由からこれらのフィールドを除外する必要がある場合に使用します。
* オフ（デフォルト）の場合、コネクタは `ip_address`（Tealium の標準 IP 属性から取得）と `user_agent`（Tealium の標準ユーザーエージェント属性から取得）を自動的にマッピングします。

#### デバッグモード

有効にすると、コネクタは `validate_only: true` を指定してイベントを送信します。これにより、OpenAI はイベントを保存せずにペイロードを検証し、エラーがあれば返します。トラブルシューティングやドライランに使用してください。本番トラフィックでは無効のままにしてください。

#### ピクセル ID の上書き

任意。このアクションについて、コネクタレベルのピクセル ID を上書きします。指定した場合、コネクタ構成で構成されたピクセル ID の代わりにこの値が使用されます。

#### API キーの上書き

任意。このアクションについて、コネクタレベルの API キーを上書きします。指定した場合、コネクタ構成で構成された API キーの代わりにこの値が使用されます。

### イベントの送信（バッチ）

#### バッチの上限

このアクションでは、ベンダーへの大容量データ転送に対応するため、バッチリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに保持されます。

* リクエストの最大数：1,000
* 最も古いリクエストからの最大経過時間：5 分
* リクエストの最大サイズ：1 MB

このアクションでは、**イベントの送信（リアルタイム）**アクションと同じパラメータおよびマッピングオプションを使用します。詳細については、[イベントの送信（リアルタイム）](#send-event-real-time)を参照してください。


<blockquote>
`attribution_appended` イベントタイプのバッチ配信は、まだサポートされていません。アトリビューションイベントには、**イベントの送信（リアルタイム）**アクションを使用してください。
</blockquote>
