## 仕組み

Google Ads コンバージョンは、ユーザーが広告をクリックした後、またはディスプレイ ネットワーク広告を表示した後に、指定されたアクションを実行した場合に発生します。Google Ads コンバージョンコネクタは Google Ads API を使用します。この API は、オフラインコンバージョンのアップロードと、以前に取得したコンバージョン値の調整をサポートしています。このコネクタを使用すると、電話や営業担当者を通じた販売など、オフラインでの売上につながった広告を追跡するために、オフラインクリックコンバージョンを Google Ads にアップロードできます。また、広告が電話につながったタイミングや、その電話が価値ある顧客アクションにつながったタイミングを追跡するために、オフライン通話コンバージョンをアップロードできます。

## 要件

* オフラインコンバージョンを送信するには、Google Ads のインポートコンバージョンアクションを構成し、ソースとして通話またはクリックのいずれかを指定します。詳細については、[オフラインコンバージョンに関する Google ヘルプドキュメント](https://support.google.com/google-ads/answer/2998031?sjid=13815989904284925133-NC)を参照してください。
* コンバージョンを調整するには、元のコンバージョンのトランザクション ID、または調整対象のコンバージョンを特定するための `gclid` とコンバージョンの日時が必要です。

## API 情報

このコネクタは、次のベンダー API を使用します。

* API 名: Google Ads API
* API バージョン: v24
* API エンドポイント: `https://googleads.googleapis.com/`
* ドキュメント: [Google Ads API](https://developers.google.com/google-ads/api/docs/start)

## バッチ処理の上限

このコネクタは、ベンダーへの大容量データ転送に対応するため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数: 2000
* 最も古いリクエストからの最大経過時間: 10 分
* リクエストの最大サイズ: 2 MB

## 遅延アクション

Google のベストプラクティスに従い、オフラインコンバージョンのアップロードに対応するため、アクションは 30 分間遅延されます。Google Campaign Manager 360 Floodlight コネクタでの遅延アクションについて詳しくは、Google の[オフラインコンバージョンをアップロードするためのベストプラクティス](https://support.google.com/searchads/answer/6074338?hl=en)ドキュメントを参照してください。


<blockquote>
Event Streaming または Customer Data Platform（CDP）で[トレース](https://docs.tealium.com/manage-traces/)を使用する場合、アクションは遅延されません。
</blockquote>


### 同意

このコネクタは、デフォルトで `adUserData` および `adPersonalization` の同意に `GRANTED` の値を送信します。デフォルト値を上書きするには、関連する Event Streaming 属性を、値が `DENIED` の `Ad User Data Consent` または `Ad Personalization Consent`、あるいはその両方にマッピングします。

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を行います。

* **顧客 ID**: 管理する Ads アカウントの顧客 ID を入力するか、アクション構成の動的オーバーライドフィールドを使用します。
* **管理者顧客 ID**: 管理対象アカウントにアクセスする場合は、**管理者顧客 ID**と**顧客 ID**を入力します。

コネクタを構成したら、**完了**をクリックします。

## アクション構成 - パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### アクション - 通話コンバージョンをアップロード - レガシー

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|顧客 ID|（必須）顧客アカウント ID を選択します。使用可能なオプションには、認証済みユーザーがアクセスできる顧客アカウントが表示されます。|
|コンバージョンアクション|（必須）既存のコンバージョンアクションを選択します。タイプが `UPLOAD_CALLS` の Google Ads コンバージョンアクションのみが表示されます。詳細については、[Google: Google Ads コンバージョントラッキング](https://support.google.com/google-ads/answer/1722022)を参照してください。|

#### コンバージョンデータのパラメータ

|**パラメータ**| **説明**|
|---| ---|
|発信者 ID|（必須）この通話の発信元となった発信者 ID。発信者 ID は E.164 形式で、先頭にプラス（`+`）記号を付ける必要があります。例: `+16502531234`。|
|通話開始日時|（必須）通話が発生した日時。タイムゾーンを指定する必要があります。形式は **yyyy-mm-dd hh:mm:ss±hh:mm** です。例: `2020-01-01 12:32:45-8:00`。|
|コンバージョン日時|（必須）コンバージョンが発生した日時。この日時は通話時刻より後である必要があります。タイムゾーンを指定する必要があります。形式は **yyyy-mm-dd hh:mm:ss±hh:mm** です。例: `2020-01-01 12:32:45-8:00`。|
|コンバージョン値|広告主にとってのコンバージョンの価値。|
|通貨コード|コンバージョン値に関連付けられた通貨。ISO 4217 の 3 文字の通貨コードです。例: `USD` または `EUR`。|

#### オプションのパラメータ

|**パラメータ**| **説明**|
|---| ---|
| コンバージョンアクションのオーバーライド | **コンバージョンアクション**パラメータを上書きするコンバージョンアクション ID を指定します。このフィールドでは、Event Streaming 変数を使用して**コンバージョンアクション ID**パラメータを構成できます。|
| カスタム変数 | このコンバージョンに関連付けられたカスタム変数。詳細については、[Google: カスタム変数](https://developers.google.com/google-ads/api/reference/rpc/v8/CustomVariable)を参照してください。|
|広告ユーザーデータの同意 | 広告ユーザーデータに対する同意。デフォルト値は `GRANTED` です。有効な値は `GRANTED` と `DENIED` です。|

|**パラメータ**| **説明**|
|---| ---|
|Google クリック ID|（必須）このコンバージョンに関連付けられた Google クリック ID（`gclid)`）。Google クリック ID、`gbraid`、または `wbraid` のいずれかが必要です。|
|コンバージョン日時|（必須）コンバージョンが発生した日時。この日時は通話時刻より後である必要があります。タイムゾーンを指定する必要があります。形式は **yyyy-mm-dd hh:mm:ss±hh:mm** です。例: `2020-01-01 12:32:45-8:00`。|
|コンバージョン値|広告主にとってのコンバージョンの価値。|
|通貨コード|コンバージョン値に関連付けられた通貨。ISO 4217 の 3 文字の通貨コードです。例: `USD` または `EUR`。|
|注文 ID|（必須）コンバージョンに関連付けられた注文 ID。1 つの注文 ID は、コンバージョンアクションごとに 1 つのコンバージョンにのみ使用できます。|
|外部アトリビューションクレジット|Google Ads のクリックに起因するコンバージョンの割合を表すパラメータです。|
|外部アトリビューションモデル|指定されたアトリビューションモデル名。詳細については、[Google: Google Ads API クリックコンバージョン](https://developers.google.com/google-ads/api/reference/rpc/v3/ClickConversion)を参照してください。|
| gbraid |（必須）iOS 14 以降の iOS デバイスから発生し、アプリコンバージョンに関連付けられたクリックの識別子。値には、Google クリック ID、`gbraid`、または `wbraid` を使用できます。|
| wbraid |（必須）iOS 14 以降の iOS デバイスから発生し、ウェブコンバージョンに関連付けられたクリックの識別子。値には、Google クリック ID、`gbraid`、または `wbraid` を使用できます。|
#### カートデータのパラメーター

|**パラメーター**| **説明**|
|---| ---|
|マーチャント ID|商品がアップロードされる Merchant Center の ID。|
|フィードの国コード|商品がアップロードされるフィードに関連付けられた国コード。|
|フィードの言語コード|商品がアップロードされるフィードに関連付けられた言語コード。|
|ローカルトランザクション|送料無料やカート全体に適用されるクーポン割引など、トランザクションレベルのすべての割引の合計。通貨コードは、`ClickConversion` メッセージ内のものと同じです。|
|商品 ID|商品のショッピング ID。この値は Merchant Center の商品 ID と同じである必要があります。複数の商品を追加するには、配列を使用します。配列型属性の長さは同じである必要があります。|
|数量|販売された商品の数量。複数の商品を追加するには、配列を使用します。配列型属性の長さは同じである必要があります。|
|単価|税金、送料、およびトランザクションレベルの割引を除いた単価。通貨コードは、`ClickConversion` メッセージ内のものと同じです。複数の商品を追加するには、配列を使用します。配列型属性の長さは同じである必要があります。|

### アクション — コンバージョンの修正

|コンバージョン日時|コンバージョンの日時。形式は **yyyy-mm-dd hh:mm:ss+&#124;-hh:mm** です。日付属性は、Google が想定する形式に変換されます。|
|通貨コード|修正後の値に使用する通貨。指定しない場合は、コンバージョンアクションのデフォルト通貨が使用されます。|

|顧客タイプ|コンバージョンに関連付けられた顧客のタイプ。許可リストに登録されている顧客のみが利用できます。指定できる値は `new` または `returning` です。|
|コンバージョン値|広告主にとってのコンバージョンの価値。|
|通貨コード|コンバージョン値に関連付けられた ISO 4217 の3文字通貨コード。例：`USD` または `EUR`。|
|注文 ID|（必須）コンバージョンに関連付けられた注文 ID。1つの注文 ID は、コンバージョンアクションごとに1つのコンバージョンにのみ使用できます。|
|外部アトリビューションクレジット|Google 広告のクリックに起因するコンバージョンの割合。|
|外部アトリビューションモデル|指定されたアトリビューションモデル名。詳細については、[Google：Google Ads API のクリックコンバージョン](https://developers.google.com/google-ads/api/reference/rpc/v3/ClickConversion)を参照してください。|
| gbraid |（必須）iOS 14以降の iOS デバイスから発生し、アプリコンバージョンに関連付けられたクリックの識別子。値には Google クリック ID、`gbraid`、または `wbraid` を指定できます。|
| wbraid |（必須）iOS 14以降の iOS デバイスから発生し、ウェブコンバージョンに関連付けられたクリックの識別子。値には Google クリック ID、`gbraid`、または `wbraid` を指定できます。|
