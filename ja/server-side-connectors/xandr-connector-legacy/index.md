## 要件

* Xandrアカウント

## サポートされているアクション

| **アクション名**                   | **オーディエンスでのトリガー** | **ストリームでのトリガー** |
|:-----------------------------------|:-------------------------------|:---------------------------|
| セグメントへのユーザーの追加または削除 | ✓                              | ✓                          |

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

ベンダーを構成するには、次の手順に従います。

1. **Configure**タブで、コネクタインスタンスのタイトルを入力します。
1. 実装に関する追加のメモを入力します。

## アクション構成 — パラメータとオプション

**Continue**をクリックして、コネクタのアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### アクション — セグメントへのユーザーの追加または削除

#### パラメータ

* **一般マッピング**
  * （必須）属性を必須イベントフィールドにマッピングします。
  * **To**ドロップダウンリストから目的のフィールドを選択するか、カスタム値を入力します。

#### オプション — 一般マッピング

| **オプション**       | **説明** |
|:---------------------|:---------|
| `uuid2`（必須） | <ul><li>タグ管理でXandr Cookie Matchタグを使用し、訪問のブラウザーからXandrの`uuid2`値を取得します</li></ul> |
| `sess` | <ul><li>自動的に`sess=1`を構成し、Cookieヘッダー内の`uuid2`値とともにXandrへ送信します。デフォルト値を上書きするには、`sess`を`0`にマッピングします。</li></ul> |
| `add` | <ul><li>ユーザーに追加するセグメントをカンマ区切りで指定します</li></ul> |
| `add_code` | <ul><li>ユーザーに追加するセグメントコードをカンマ区切りのリストで指定します。</li><li>コードを使用する場合は、`member`パラメータが必須です。</li></ul> |
| `remove` | <ul><li>ユーザーから削除するセグメントをカンマ区切りで指定します</li></ul> |
| `remove_code` | <ul><li>ユーザーから削除するセグメントコードをカンマ区切りのリストで指定します。</li><li>コードを使用する場合は、`member`パラメータが必須です。</li></ul> |
| `member` | <ul><li>セグメントを所有するメンバーのID。</li></ul> |
| `other` | <ul><li>レポート用に保存される整数値を持つユーザー定義フィールドです。</li><li>一部のメンバーは、これを使用データのソースとして使用します。</li></ul> |
| `redir` | <ul><li>別のピクセルをピギーバックするために使用されるリダイレクトURL</li></ul> |
| `external_uid` | <ul><li>このユーザーの外部ユーザーIDに対応する文字列</li></ul> |
