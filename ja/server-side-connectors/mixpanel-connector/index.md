## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の構成を構成します。

* **API プロジェクトトークン**：プロファイルおよびイベントデータを Mixpanel に送信するには、プロジェクトトークンが必要です。詳細については、[プロジェクトトークンはどこで確認できますか？](https://mixpanel.com/help/questions/articles/where-can-i-find-my-project-token)を参照してください。
* **Mixpanel API ベース URL**：（必須）Mixpanel API ベース URL を選択します。詳細については、[Mixpanel：プライバシープログラム](https://mixpanel.com/legal/eu-data-residency/)を参照してください。
  * 標準サーバー：`api.mixpanel.com`
  * EU データレジデンシーサーバー：`api-eu.mixpanel.com`
  * インドデータレジデンシーサーバー：`api-in.mixpanel.com`

## アクション構成 - パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### アクション - イベントのトラッキング

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|ユーザー ID| イベントに関連付けられたユーザーの一意の識別子。|
|IP アドレス| ユーザーの IP アドレス。 |
|イベント時刻の上書き| 非推奨。自動構成されるイベントのタイムスタンプをカスタム値（エポック時刻形式、UTC）で上書きします。 |
|イベント名| （必須）イベントの名前。 |
|イベントデータ|  <ul><li>イベントに追加するカスタムプロパティ。</li><li>日付型のプロパティは、Mixpanel の日付形式 `YYYY-MM-DDThh:mm:ss` に変換されます。</li><li>空の値を持つプロパティはスキップされ、含まれません。</li></ul> |

### アクション - プロファイルの更新 - 構成

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|最終確認日時の更新を無視| （任意）`true` に構成すると、Mixpanel はユーザープロファイルの「最終確認日時」プロパティを自動的に更新しません。 |
|ユーザー ID| （必須）イベントに関連付けられたユーザーの一意の識別子。 |
|IP アドレス| ユーザーの IP アドレス。 |
|更新時刻の上書き| 非推奨。自動構成されるイベントのタイムスタンプをカスタム値（エポック時刻形式、UTC）で上書きします。 |
|作成日時| プロファイルが更新された日時。日付型のプロパティは、Mixpanel の日付形式 `YYYY-MM-DDThh:mm:ss` に変換されます。 |
|電話番号| ユーザーの電話番号。|
|姓| ユーザーの姓。|
|メールアドレス| ユーザーのメールアドレス。 |
|名| ユーザーの名。|
|氏名| ユーザーの氏名。|
|既存のプロパティ値を上書きしない（初回のみ構成）| コネクタが既存の値を上書きしないようにするには、このチェックボックスを選択します。 |

|**パラメータ**| **説明**|
|---| ---|
|元のユーザー ID|  <ul><li>以前にユーザーに構成された識別子。</li><li>通常、より適切なユーザー ID が利用可能になる前に生成された一時 ID（例：サインアップ後のユーザーのメールアドレス）です。</li></ul> |
