## API 情報

このコネクタは、次のベンダー API を使用します。

* API 名: Viant API
* API バージョン: v1
* API エンドポイント: `https://vdp-connect-api.viantinc.com`
* ドキュメント: [Viant API](https://docs.api.viantinc.com/reference/create-new-audience-segment)

## バッチ制限

このコネクタは、ベンダーへの大量のデータ転送に対応するため、バッチリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに保持されます。

* リクエストの最大数: 1,000
* 最も古いリクエストからの最大経過時間: 10 分
* リクエストの最大サイズ: 10 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を行います。

* **クライアント ID**:（必須）Viant VDP API 認証用のクライアント ID。
* **クライアントシークレット**:（必須）Viant VDP API 認証用のクライアントシークレット。
* **アカウント ID**:（必須）Viant アカウント ID。
* **広告主 ID**:（必須）Viant 広告主 ID。
* **オーディエンスを選択**: リストからオーディエンスセグメントを選択するか、**新しいセグメントを作成**をクリックして新規作成します。カスタムの Viant セグメント ID を直接入力することもできます。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 顧客データプラットフォーム（CDP） | イベントストリーミング |
| ----------- | :------------: | :---------: |
| オーディエンスデータを追加 | ✓ | ✓ |
| 個別のオーディエンス ID を失効 | ✓ | ✓ |

### オーディエンスデータを追加

#### バッチ制限

このアクションは、ベンダーへの大量のデータ転送に対応するため、バッチリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに保持されます。

* リクエストの最大数: 1,000
* 最も古いリクエストからの最大経過時間: 10 分
* リクエストの最大サイズ: 10 MB

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| Viant セグメント ID | オーディエンスセグメントの ID。この値は、コネクタ構成で指定されたオーディエンスセグメントの値を上書きします。 |
| 国コード | 2 文字の国コード（例: `US`、`CA`）。 |

#### ユーザーデータ

| パラメータ | 説明 |
| --- | --- |
| メールアドレス（SHA256 ハッシュを適用） | プレーンテキストのメールアドレス。コネクタによって値が正規化され、ハッシュ化されます。 |
| 電話番号（SHA256 ハッシュを適用） | プレーンテキストの電話番号。コネクタによって値が正規化され、ハッシュ化されます。 |
| 住所（SHA256 でハッシュ化済み） | ハッシュ化済みの住所。ハッシュ化する前に USPS の書式標準に従ってください。 |
