## 要件

* Amazon Web Servicesアカウント
* Identity and Access Management（IAM）ユーザー認証情報
* Kinesis Streams

## コネクタアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| イベントデータをKinesis Streamに送信 | ✗ | ✓ |
| 訪問データをKinesis Streamに送信 | ✓ | ✗ |
| カスタマイズしたデータをKinesis Streamに送信（上級） | ✓ | ✓ |
| バッチ処理したイベントデータをKinesis Streamに送信 | ✗ | ✓ |
| バッチ処理した訪問データをKinesis Streamに送信 | ✓ | ✗ |
| バッチ処理したカスタマイズデータをKinesis Streamに送信（上級） | ✓ | ✓ |

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の構成を構成します。

* **アクセスキー**  
（必須）IAMユーザーのアクセスキーを指定します。関連付けられたIAMポリシー（IAMユーザーまたは引き受けるロールのいずれか）では、データの送信先となるストリームに対する`kinesis:PutRecord`権限を付与する必要があります。[Kinesis Streamsリソースへのアクセス](http://docs.aws.amazon.com/streams/latest/dev/controlling-access.html)を参照してください。
* **シークレットキー**  
（必須）IAMユーザーのシークレットキーを指定します。
* **リージョン**  
（必須）リージョンを選択します。
* **引き受けるロール：ARN**  
（任意）引き受けるロールのAmazonリソースネーム（ARN）を指定します。例：`arn:aws:iam::222222222222:role/myrole`。[IAMロールへの切り替え](http://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles_use_switch-role-api.html)を参照してください。
* **引き受けるロール：セッション名**  
（任意）引き受けるロールセッションの識別子を指定します。
* **引き受けるロール：外部ID**  
（任意）外部識別子を指定します。[外部IDの使用方法](http://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles_create_for-user_externalid.html)を参照してください。

## アクション

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

以下のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### アクション構成 - イベントデータをKinesis Streamに送信

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| ストリーム名 | データの送信先となるストリームを選択します。IAMポリシーで`kinesis:ListStreams`権限が付与されていない場合は、カスタム値を手動で入力する必要があります。 |
| パーティションキー | （必須）パーティションキーは、ストリーム内のデータをシャードにグループ化します。 |
| 順序付け用シーケンス番号 | Kinesisデータストリームのシャード内におけるデータレコードのシーケンス番号です。 |
| 明示的ハッシュキー | パーティションキーのハッシュ化に使用するキーです。 |
| 属性名を出力 | 属性名が更新された場合、ペイロード内の名前にも更新が反映されます。 |

### アクション構成 - 訪問データをKinesis Streamに送信

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| ストリーム名 | データの送信先となるストリームを選択します。IAMポリシーで`kinesis:ListStreams`権限が付与されていない場合は、カスタム値を手動で入力する必要があります。 |
| パーティションキー | （必須）パーティションキーは、ストリーム内のデータをシャードにグループ化します。 |
| 順序付け用シーケンス番号 | Kinesisデータストリームのシャード内におけるデータレコードのシーケンス番号です。 |
| 明示的ハッシュキー | パーティションキーのハッシュ化に使用するキーです。 |
| 現在の訪問データを訪問データに含める | 現在の訪問データをペイロードに追加します。「現在の訪問のイベントデータを除外」が選択されていない場合は、訪問時のイベントデータも含まれます。 |
| 現在の訪問のイベントデータを除外 | 現在の訪問データからイベントデータを除外します。 |
| 属性名を出力 | 属性名が更新された場合、ペイロード内の名前にも更新が反映されます。 |

### アクション構成 - バッチ処理したイベントデータをKinesis Streamに送信

#### バッチ制限

このアクションでは、ベンダーへの大容量データ転送をサポートするために、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。以下のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに保存されます。

* リクエストの最大数：500
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：5 MB

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| ストリーム名 | データの送信先となるストリームを選択します。IAMポリシーで`kinesis:ListStreams`権限が付与されていない場合は、カスタム値を手動で入力する必要があります。 |
| パーティションキー | （必須）パーティションキーは、ストリーム内のデータをシャードにグループ化します。 |
| 明示的ハッシュキー | パーティションキーのハッシュ化に使用するキーです。 |
| 属性名を出力 | 属性名が更新された場合、ペイロード内の名前にも更新が反映されます。 |
