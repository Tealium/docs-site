## API情報

このコネクタでは、次のベンダーAPIを使用します。

* API名：CDK Global API
* APIバージョン：v1
* APIエンドポイント：`https://api.fortellis.io`
* ドキュメント：[CDK CRM Direct Post Sales Leads](https://apidocs.fortellis.io/apis/1b0047b1-feec-42e9-be1b-d3285493ac9a)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。


<blockquote>
このコネクタを追加すると、ベンダーのデータプラットフォームポリシーへの同意を求められます。
</blockquote>


コネクタを追加したら、次の構成を構成します。

* **組織ID**  
  * Fortellis組織ID（エンティティID）を確認するには、Fortellisアカウントにログインし、自分の名前にカーソルを合わせて、**Organization Management**をクリックします。エンティティIDがページに表示されます。
* **サブスクリプションID**  
  * サブスクリプションIDを選択します。
* **エンドポイント**  
  * エンドポイントを選択します。デフォルトのエンドポイントは**Prod**です。

コネクタを構成したら、**Done**をクリックします。

### リードを送信

#### 見込み客

| **パラメータ** | **説明** |
| --- | --- |
| リクエスト日時 | API呼び出しが行われた日時。 |

#### ID

リードのソースを送信するために使用します。

| **パラメータ** | **説明** |
| --- | --- |
| IDソース | このIDを作成したソースの名前。 |
| IDシーケンス | このデータの履歴を追跡するために使用する番号。 |
| ID値 | IDの値。 |

#### 車両

| **パラメータ** | **説明** |
| --- | --- |
| 関心 | 車両に対する顧客の関心の種類。指定可能な値：`buy`、`lease`、`sell`、`trade-in`、`test-drive`。|
| ステータス | 車両が`new`または`used`のどちらであるかを指定します。 |
| 年式 | 車両のモデル年式。 |
| メーカー | 車両のメーカー。 |
| モデル | 車両のモデル。 |
| VIN | 車両の車両識別番号。 |
| 在庫番号 | 車両に対するベンダーの在庫番号。 |
| トリム | トリムの説明。 |
| 単位 | 走行距離計の測定単位。マイルの場合は`mi`、キロメートルの場合は`km`。 |
| 値 | 走行距離計の表示値。 |
| ボディスタイル | `SUV`、`Sedan`、`Coupe`などの一般的なボディスタイル。 |
| トランスミッション | `A`（オートマチック）または`M`（マニュアル）。 |
| ドア数 | 車両のドア数。 |
| 価格タイプ | 価格の種類。指定可能な値：`quote`、`offer`、`msrp`、`invoice`、`call`、`appraisal`、`asking`。 |
| 通貨 | ISO 4217通貨コード。 |
| デルタ | `Delta`値と`Relative To`プロパティを使用すると、請求書価格などの別の値に対する割合として価格を表現できます。指定可能な値：`absolute`、`relative`、`percentage`。|
| 相対基準 | `Delta`値と`Relative To`プロパティを使用すると、請求書価格などの別の値に対する割合として価格を表現できます。指定可能な値：`msrp`、`invoice`。 |
| 価格ソース | `Kelley Blue Book`など、この値の取得元。 |
| 価格金額 | 価格の金額。 |
| 価格コメント | `Anniversary Edition`など、価格に関する説明。 |
| コメント | 車両に関するコメント。 |
| ファイナンス方法 | ファイナンスオプションを指定します。指定可能な値：`cash`、`finance`、`lease`。 |
| ファイナンス金額タイプ | ファイナンスの支払額。指定可能な値：`downpayment`、`monthly`、`total`。|
| ファイナンス金額の制限 | ファイナンス金額の制限。指定可能な値：`maximum`、`minimum`、`exact`。|
| ファイナンス金額の通貨 | ISO 4217通貨コード。 |
| ファイナンス金額の値 | ファイナンス対象の金額。 |
| ファイナンス残高タイプ | 残高の種類。指定可能な値：`finance`、`residual`。|
| ファイナンス残高の通貨 | ISO 4217通貨コード。 |
| ファイナンス残高の値 | 残りの残高。 |
| 内装色 | 内装の色。 |
| 外装色 | 外装の色。 |
| 優先順位 | 優先順位を示す番号。`1`が最優先です。 |

| **パラメータ** | **説明** |
| --- | --- |

| メール値 | メールアドレス。 |
| 連絡先電話タイプ | 電話の種類。指定可能な値：`voice`、`phone`、`fax`、`cellphone`、`pager`。 |

| 電話番号 | 電話番号。 |
| 連絡先住所タイプ | 住所の種類。指定可能な値：`work`、`home`、`delivery`。 |
| 連絡先住所の値 | 番地と通りの名前。 |
| 連絡先の部屋番号 | 顧客の部屋番号。 |

| 連絡先の地域コード | 州または都道府県。 |
| 連絡先の郵便番号 | 郵便番号。 |
