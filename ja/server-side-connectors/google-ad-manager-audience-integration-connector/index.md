Google Ad Manager オーディエンス統合コネクタを使用すると、パブリッシャー提供 ID（PPID）を使用して、Google Ad Manager のユーザーリストに訪問を追加できます。その後、パブリッシャーは PPID に基づいて広告を配信し、最も価値の高い顧客と類似するオーディエンスを照合することで、新規ユーザーをターゲティングできます。詳細については、[Google Ad Manager ヘルプ：パブリッシャー提供の識別子について](https://support.google.com/admanager/answer/2880055?hl=en)を参照してください。

## 前提条件

* Google Ad Manager UI の **Linked Accounts** セクションを使用して、Tealium を Google Ad Manager にリンクします。
* ログインユーザー向けに、[Google Ad Manager 360 Audience Pixel タグ](https://docs.tealium.com/google-ad-manager-360-audience-pixel-tag/)または [Google Publisher タグ](https://docs.tealium.com/google-publisher-tag/)を使用して、クライアント側で PPID を生成して送信します。
* コネクタで使用するために、PPID を Tealium 属性として構成します。

## API 情報

このコネクタは、次のベンダー API を使用します。

* API 名：Google Data Manager API
* API バージョン：v1
* API エンドポイント：`https://datamanager.googleapis.com`

## コネクタアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| オーディエンスリストに追加 | ✓ | ✓ |
| オーディエンスリストから削除 | ✓ | ✓ |

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **顧客 ID**。

コネクタを構成した後、**完了**をクリックします。
（必須）Ad Manager UI で Tealium にリンクされているアカウントの顧客 ID。Ad Manager で **ツールと構成 > リンク済みアカウント**に移動し、Tealium へのリンクを作成します。

## アクション

次のセクションでは、各アクションでサポートされるパラメータについて説明します。

### オーディエンスリストに追加

#### バッチ制限

このアクションでは、ベンダーへの大量のデータ転送に対応するため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに追加されます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：1440 分
* リクエストの最大サイズ：50 MB

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| オーディエンスリスト | オーディエンスリストを選択します。<br>注：コネクタを使用して作成されたリストのみ選択できます。 |
| パブリッシャー提供 ID | （必須）単一の英数字値または UUID HEX 値、あるいは値の配列。各値は 32～150 文字である必要があります。 |

### オーディエンスリストから削除

#### バッチ制限

このアクションでは、ベンダーへの大量のデータ転送に対応するため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに追加されます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：1440 分
* リクエストの最大サイズ：50 MB

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| オーディエンスリスト | オーディエンスリストを選択します。<br>注：コネクタを使用して作成されたリストのみ選択できます。 |
| パブリッシャー提供 ID | （必須）単一の英数字値または UUID HEX 値、あるいは値の配列。各値は 32～150 文字である必要があります。 |

## 同意

**オーディエンスリストに追加**などのアクションでは、コネクタは `adUserData` と `adPersonalization` を `GRANTED` として自動的に送信します。同意した訪問のみがユーザーリストに追加されるように、オーディエンスロジックを実装してください。同意していない訪問については、**オーディエンスリストから削除**アクションを使用してユーザーリストから削除してください。

## ヒントとトラブルシューティング

* コネクタが PPID を確実に受信できるように、コネクタアクションで使用するイベントフィードまたはオーディエンス構成にロジックを含めてください。このロジックにより、`MISSING_USER_IDENTIFIER` エラーを回避できます。
