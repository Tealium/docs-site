## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、以下の構成を構成します。

* **REST API クライアント ID**：（必須）**Marketo > Admin > LaunchPoint** にあるクライアント ID を指定します。API ユーザーには、**Read-Write Lead**、**Read/Execute Campaigns**、および **Read Lists** の権限が必要です。詳細については、[Marketo：REST API で使用するカスタムサービスの作成](http://docs.marketo.com/display/public/DOCS/Create+a+Custom+Service+for+Use+with+ReST+API)を参照してください。
* **REST API クライアントシークレット**：（必須）**Marketo > Admin > LaunchPoint** にあるクライアントシークレットを指定します。
* **REST API エンドポイント URL**：（必須）**Marketo > Admin > Web Service** にある REST API エンドポイントを指定します。例：`https://123-ABC-123.mktorest.com/rest`
* **REST API ID URL**：（必須）**Marketo > Admin > Web Service** にある REST API Identity を指定します。例：`https://123-ABC-123.mktorest.com/identity`

コネクタを構成したら、**Done** をクリックします。

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

以下のセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。

### リードをリストに追加

#### パラメーター

| **パラメーター** | **説明** |
|---| ---|
| 対象の静的リスト | （必須）リストを選択します。プラットフォームが読み込むリストは最大 300 件です。リストが表示されない場合は、リスト ID を入力します。 |
| 対象リード ID | ユーザーの **Lead ID** が判明している場合に使用します。**Lead ID Lookup** は空白のままにします。 |
| リード ID の検索 | ユーザーの **Lead ID** が不明な場合に使用します。**Target Lead ID** は空白のままにし、このフィールドを使用してさまざまなフィルターから Lead ID を検索します。指定可能な値：`id`、`cookies`、`email`、`twitterId`、`facebookId`、`linkedInId`、`sfdcAccountId`、`sfdcContactId`、`sfdcLeadId`、`sfdcLeadOwnerId`、`sfdcOpptyId` |
| リードを追加 | リードが存在しない場合は追加します。 |

### リードをリストに追加（バッチ処理）

#### バッチ制限

このアクションでは、ベンダーへの大量データ転送に対応するため、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルが公開されるまで、リクエストはキューに追加されます。

* リクエストの最大数：300
* 最も古いリクエストからの最大経過時間：30 分
* リクエストの最大サイズ：1 MB

### トランザクションメールを送信

#### パラメーター

| **パラメーター** | **説明** |
|---| ---|
| 対象メールキャンペーン | トランザクションメール用に作成した対象のスマートキャンペーンを選択します。詳細については、[Marketo：トランザクションメール](https://experienceleague.adobe.com/en/docs/marketo-developer/marketo/rest/assets/transactional-email)を参照してください。 |
| 対象リード ID | （必須）対象リード ID を指定します。 |
| 構成するトークンデータ | （任意）トークン値をトークン名にマッピングします。Marketo UI に表示される完全なトークン形式を使用します。例：`{ { my.message } }` |

### リードを作成または更新

#### パラメーター

| **パラメーター** | **説明** |
|---| ---|
| 更新戦略 | （必須）更新戦略を選択します。 |
| リード検索フィルター | <ul><li>（任意）既存のリードを検索するためのフィルターフィールドを選択します。</li><li>選択した検索フィルターフィールドには、**Lead Data** セクションで値を構成する必要があります。</li></ul> |
| 構成するリードデータ | （必須）値をリードプロパティ名にマッピングします。日付属性は自動的に ISO 8601 形式に変換されます。 |

### リードを一括インポート（必要に応じてリストに追加）

#### バッチ制限

このアクションでは、ベンダーへの大量データ転送に対応するため、バッチリクエストを使用します。次のいずれかのしきい値に達するまで、リクエストはキューに追加されます。

* リクエストの最大数：25,000
* 最も古いリクエストからの最大経過時間：30 分
* リクエストの最大サイズ：10 MB
#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| 対象の静的リスト | （必須）リストを選択します。プラットフォームが読み込むリストは最大300件です。リストが表示されない場合は、リストIDを入力してください。 |
| リード検索フィールド | （必須）リードの検索に使用するフィールドです。<ul><li>選択した検索フィールドには、**リードデータ**セクションで値を構成する必要があります。</li><li>指定可能な値：`id`、`cookies`、`email`、`twitterId`、`facebookId`、`linkedInId`、`sfdcAccountId`、`sfdcContactId`、`sfdcLeadId`、`sfdcLeadOwnerId`、`sfdcOpptyId`。</li></ul> |
| リードデータ | （必須）値をリードのプロパティ名にマッピングします。検索フィールドもマッピングする必要があります。 |
