</blockquote>


## API 情報

このコネクタでは、次のベンダー API を使用します。

* API 名：Pinterest REST API
* API バージョン：v5
* API エンドポイント：`https://api.pinterest.com/v5/`
* ドキュメント：[Pinterest オーディエンス](https://developers.pinterest.com/docs/ads/targeting/#Audiences)

## バッチ処理の上限

このコネクタでは、ベンダーへの大量データ転送に対応するため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数：10000
* 最も古いリクエストからの最大経過時間：10 分
* リクエストの最大サイズ：1 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

<blockquote>
このコネクタを追加すると、ベンダーのデータプラットフォームポリシーへの同意を求められます。
</blockquote>


コネクタを追加した後、次の構成を行います。

* **広告アカウント ID**  
 （必須）広告アカウントの一意の識別子です。この識別子は、次の方法で確認できます。
    * 広告主アカウントを所有する Pinterest アカウントにログインし、[https://ads.pinterest.com/](https://ads.pinterest.com) に移動します。上部のナビゲーションセクションで、**表示中**をクリックします。広告アカウント ID は、ドロップダウンリスト内の広告アカウント名の下に表示される番号です。
    * **広告 > 概要**に移動し、URL パスで広告アカウント ID を確認します。URL は次の形式です：`ads.pinterest.com/advertiser/{ad_account_id}/?...`。

**接続を確立**をクリックして Pinterest に接続します。


<blockquote>
認証トークンは 60 日後に期限切れになります。オーディエンス同期の中断を防ぐため、少なくとも 60 日に 1 回は Tealium にログインし、**接続を確立**をクリックしてください。
</blockquote>


### 顧客リストの作成

Pinterest で顧客リストを作成するには、次の手順を実行します。

1. **顧客リストを作成**をクリックします。
1. 顧客リスト名を入力します。
1. オーディエンス名を入力します。顧客リストが正常に作成されると、タイプが `CUSTOMER_LIST` の Pinterest オーディエンスが自動的に作成されます。
1. 顧客リストのタイプを選択します。
    * **メール**：識別子として使用するメールアドレス。
    * **Apple 広告識別子（IDFA）**：Apple がユーザーのデバイスに割り当てるランダムなデバイス識別子。IDFA を使用して、ユーザーがモバイル広告キャンペーンを操作したタイミングを特定することもできます。これは、チャネルが IDFA トラッキングを提供し、広告主が広告を正常に操作したユーザーを追跡している場合に可能です。
    * **モバイル広告 ID（MAID）**：Android または Apple がモバイルデバイスに割り当てる、16 進数の文字列。
## アクション構成 - パラメータとオプション
1. メールアドレス、MAID、または IDFA のリストを、任意の組み合わせで 1 行につき 1 レコード入力します。
    * メールアドレスは小文字にする必要があり、プレーンテキストまたは SHA1、SHA256、MD5 のいずれかでハッシュ化した値を使用できます。
    * MAID と IDFA は、SHA1、SHA256、MD5 のいずれかでハッシュ化する必要があります。
1. オーディエンスの説明を入力します。
1. **完了**をクリックします。

アクションの名前を入力し、ドロップダウンリストからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |

| ユーザーをオーディエンスに追加 | ✓ | ✗ |
| ユーザーをオーディエンスから削除 | ✓ | ✗ |
