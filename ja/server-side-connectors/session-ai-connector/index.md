## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の構成を行います。

* **ホスト**  
 （必須）環境に関連付けられているホストを選択します。
Session AIのサンドボックス環境を指定するには、`https://csb.zineone.com`を使用します。本番環境を指定するには、`https://cloud.zineone.com`を使用します。
* **APIキー**  

コネクタを構成した後、**完了**をクリックします。
APIキーを生成するには、**Session AI > Integrations > Data Channel**でチャネルを作成します。

## アクション

以下のセクションでは、各アクションでサポートされるパラメータを示します。

### CCPA同意を更新

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| オプトインアクション | 指定可能な値：<ul><li>`true` - オプトインリクエストを行う場合に選択します。</li><li>`false` - オプトアウトリクエストを行う場合に選択します。</li></ul> |

#### ユーザー識別子

| **パラメータ** | **説明** |
| --- | --- |
| `id` | 顧客プロファイルの一意のID。 |
| `email` | 顧客の一意のメールアドレス。 |
| `deviceId` | 顧客の一意のデバイスID。 |

### イベントを送信

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| データチャネル | イベントの送信に使用するチャネル。 |
| イベント名 | イベント名を選択するか、カスタム名を入力します。 |

#### 共通属性

| **パラメータ** | **説明** |
| --- | --- |
| `session_id `| （必須）セッションまたは訪問を一意に識別するID。 |
| `visitor_id `| （必須）サインインしていないユーザーを識別するID。 |
| `customer_id` | サインインしているユーザーを識別するID。 |
| `user_agent` | 使用可能な場合は、ブラウザのユーザーエージェント文字列。 |
| `device_channel` | （必須）デバイスの種類（デスクトップ、タブレット、モバイル、アプリなど）。 |
| `referrer_url` | （必須）前のページのURLを参照元として示すURL。たとえば、ユーザーがサードパーティのWebサイトから初めてサイトを訪問した場合、そのサードパーティのURLが該当します。ユーザーがサイト上でセッションを継続している場合、前のページのURLが現在のページの参照元URLになります。 |
| `campaign_info` | キャンペーン名または構造。たとえば、`utm_campaign`の値。 |
| `os` | デバイスのオペレーティングシステム。 |
| `os_version` | オペレーティングシステムのバージョン。 |
| `platform_os` | オペレーティングシステムのプラットフォーム。 |
| `language` | デバイスの言語。 |
| `tz` | デバイスのタイムゾーン。 |
| `devicetype` | デバイスの種類。 |
| `browser` | デバイスで使用されているブラウザ。 |
| `browserversion` | デバイスで使用されているブラウザのバージョン。 |
| `resolution` | デバイスのディスプレイ解像度。 |
