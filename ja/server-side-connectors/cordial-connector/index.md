## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Cordial API
* APIバージョン：v1.0
* ドキュメント：[Cordial API](https://support.cordial.com/hc/en-us/categories/12092749097741-Developer-resources)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **APIキー**  
CordialではHTTP Basic Authentication（BA）を使用します。Cordialプラットフォーム内で、アカウント用のエンコードされたAPIキーを生成できます。このキーは、BA認証情報の`username`として使用されます。詳細については、[RESTful API Summary and Usage](https://support.cordial.com/hc/en-us/articles/203885498-RESTful-API-summary-and-usage)を参照してください。
<blockquote>
Cordialの`API_KEY`許可リストに[TealiumのIPアドレス]()を追加する必要があります。
</blockquote>

* **Path-URL**  
次のいずれかのパスURLを選択するか、手動で入力します。
  * `https://api.cordial.io/v2/` - 管理パネルのURLが`https://admin.cordial.io/`の場合は、このURLを使用します。
  * `https://api.usw2.cordial.io/v2/` - 管理パネルのURLが`https://usw2.admin.cordial.io/`の場合は、このURLを使用します。

コネクタの構成が完了したら、**完了**をクリックします。

### 連絡先をアップサート

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| 連絡先識別子キー | 連絡先の識別子キー。例：`email`、`cID`。 |
| 連絡先識別子の値 | 連絡先識別子の値。 |
| メールアドレス | 連絡先の識別および参照に使用する一意のチャネルアドレス。 |
| 購読ステータス | `subscribed`に構成されていない限り、プロモーションメッセージは送信されません。デフォルトは`none`です。指定可能な値：`none`、`subscribed`、`unsubscribed`。 |
| トリガーを抑制 | `true`の場合、連絡先属性値の更新に基づくメッセージトリガーを抑制します。デフォルトは`true`です。 |
| 購読を強制 | 購読解除済みの場合、購読ステータスを購読済みに更新するには、このキーを使用する必要があります。指定可能な値：`true`、`false`。 |
| 無効 | `false`に構成されていない限り、メールメッセージは送信されません。デフォルトは`false`です。指定可能な値：`true`、`false`。 |

#### オプションパラメータ

| **パラメータ** | **説明** |
| --- | --- |
| アカウントリスト | リストに連絡先を追加するか、リストから連絡先を削除します。指定可能な値：true、false。 |
| 文字列パラメータ | 属性タイプが文字列に構成されている場合、文字列の属性値を追加します。 |
| 数値パラメータ | 属性タイプが数値に構成されている場合、数値の属性値を追加します。 |
| 日付パラメータ | 属性タイプが日付に構成されている場合、日付の属性値を追加します。 |
| 地理パラメータ | 属性タイプが地理情報に構成されている場合、地理属性値を追加します。地理属性には、次のキー名で構成される固定スキーマが含まれます。<ul><li>住所</li><li>住所2</li><li>市区町村</li><li>州</li><li>郵便番号</li><li>国ISOコード</li><li>タイムゾーン</li><li>場所</li><ul><li>緯度</li><li>経度</li></ul></ul> |
| 配列パラメータ | 属性タイプが配列に構成されている場合、配列の属性値を追加します。デフォルトの動作では、配列値を指定された値に置き換えます。追加または削除の動作を指定するオブジェクトを使用して、デフォルトの動作を上書きできます。最大項目数の制限（デフォルトは25）を超えた場合、新しい値が最も古い値を置き換えます。 |

### 連絡先のアクティビティを記録（イベント）

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |

| バッチの有効期間 | 有効期間（TTL）を構成して、バッチアクションを送信する頻度を指定します。1～60分の値を入力します。デフォルト値は10分です。 |
