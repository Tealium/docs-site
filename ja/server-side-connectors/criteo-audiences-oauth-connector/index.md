## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Criteo API
* APIバージョン：2026-01
* APIエンドポイント：`https://api.criteo.com/2025-07/marketing-solutions`
* ドキュメント：[Criteo Audiences API](https://developers.criteo.com/marketing-solutions/docs/audiences)

## バッチ制限

このコネクタは、ベンダーへの大容量データ転送に対応するため、リクエストをバッチ処理します。次の3つのしきい値のいずれかに達するまで、リクエストはキューに格納されます。

* リクエストの最大数：50,000
* 最も古いリクエストからの最大経過時間：120分
* リクエストの最大サイズ：10 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の項目を構成します。
* **広告主ID**
  * Criteoアカウントの連携に関連付けられている広告主IDを入力します。

コネクタを構成したら、**完了**をクリックします。

**接続を確立**をクリックし、画面の指示に従ってCriteoに接続します。接続をテストするには、**接続をテスト**をクリックします。

### Criteoでオーディエンスを作成する

Criteoで新しいオーディエンスを作成するには、次の手順に従います。

1. **オーディエンスを作成**をクリックします。
1. **新しいオーディエンス名**を入力します。
1. **新しいオーディエンスの説明**を入力します。
1. **作成**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| ユーザーをオーディエンスに追加 | ✓ | ✓ |
| ユーザーをオーディエンスから削除 | ✓ | ✓ |

アクションの名前を入力し、**アクションタイプ**を選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### ユーザーをオーディエンスに追加

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| オーディエンス | ユーザーを追加するオーディエンスを選択するか、オーディエンスIDを指定します。 |

#### 識別子

ユーザー識別子の値をマッピングします。

| **パラメータ** | **説明** |
| --- | --- |
| メールアドレス | 組み込みのハッシュ処理を適用せずにメールアドレスの値を送信します。値をハッシュ化する必要がない場合、または値がすでにハッシュ化されている場合は、このオプションを選択します。 |
| メールアドレス（MD5ハッシュを適用） | プレーンテキストのメールアドレスを指定すると、コネクタによって前後の空白が削除され、小文字に変換された後、MD5でハッシュ化されます。 |
| メールアドレス（MD5 SHA256ハッシュを適用） | プレーンテキストのメールアドレスを指定すると、コネクタによって前後の空白が削除され、小文字に変換された後、MD5、続いてSHA256でハッシュ化されます。 |
| モバイルID | Appleの場合はIDFAモバイルID、Androidの場合はADIDモバイルIDです。 |
| Identity Link | Identity Linkです。 |
| Gum ID | Cookie Matchingによって取得された識別子です。対応するGum Caller IDがリクエストに自動的に追加されます。 |
| Gum Caller ID | CriteoがGUMのソルティングに使用する値です。Criteo Cookie Matching Serviceタグを使用する場合は、マッピングしないでください。 |

#### バッチ構成

| **パラメータ** | **説明** |
| --- | --- |
| バッチの有効期間 | バッチアクションの送信頻度を指定するため、有効期間（TTL）を構成します。5～120の値を入力します。デフォルト値は30分です。 |
| バッチレコード数 | バッチレコード数は1,000～50,000の範囲で指定する必要があります。デフォルト値は50,000です。 |
