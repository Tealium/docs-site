## バッチ制限

このコネクタは、ベンダーへの大容量データ転送に対応するため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。以下のいずれかのしきい値に達するか、プロファイルが公開されるまで、リクエストはキューに格納されます。

* リクエストの最大数：10,000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：2 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の構成を行います。
* **APIベースURL**  
  * APIベースURLを選択します。
* **Amazon AdsマネージャーアカウントID**  
  * ADMマネージャーアカウントIDです。確認するには、ADM UIの右上にあるメニューで［マネージャーアカウント］をクリックします。マネージャーアカウントがある場合に使用します。
* **Amazon AdsアカウントID**  
  * ADMアカウントIDです。マネージャーアカウントがない場合に使用します。非マネージャーアカウントではデータセットを作成できません。

コネクタを構成したら、**［完了］**をクリックします。


<blockquote>
Amazon AdsマネージャーアカウントIDとAmazon AdsアカウントIDの両方を構成しないでください。
</blockquote>


## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| 訪問をオーディエンスに追加 | ✓ | ✓ |
| 訪問をオーディエンスから削除 | ✓ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

以下のセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。
