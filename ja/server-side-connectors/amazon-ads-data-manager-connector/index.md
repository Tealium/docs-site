## バッチ制限

このコネクタは、ベンダーへの大量データ転送をサポートするためにバッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかの閾値に達するか、プロファイルが公開されるまでキューに入れられます：

* リクエストの最大数：10,000
* 最古のリクエストからの最大時間：60分
* リクエストの最大サイズ：2 MB

## 構成

コネクタマーケットプレイスにアクセスし、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の構成を構成します：
* **APIベースURL**  
  * APIベースURLを選択します。
* **Amazon Ads Data Manager ID**  
  * あなたのAdsデータマネージャー（ADM）マネージャーID。見つけるには、ADM UIの右上メニューでマネージャーアカウントをクリックします。

## アクション

| アクション名 | AudienceStream | EventStream |
| --- | :---: | :---: |
| オーディエンスに訪問を追加 | ✓ | ✓ |
| オーディエンスから訪問を削除 | ✓ | ✓ |

アクション名を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションの構成方法について説明します。

### オーディエンスに訪問を追加

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| オーディエンスデータセット | ADMオーディエンスデータセットを選択します。ADMオーディエンスデータセットを作成するには、**オーディエンスデータセットを作成**をクリックします。 |

#### 外部ユーザーID

| **パラメータ** | **説明** |
| --- | --- |
| 外部ID | データプロバイダーによって定義された外部ユーザー識別子です。 |
| 外部ID（SHA256ハッシュを適用） | コネクタがAmazonに送信する前に外部ID値をハッシュ化する場合は、このパラメータを使用します。 |

| 名（既にSHA256ハッシュ化済み） | すでに空白トリム、小文字化、SHA256ハッシュ化された名を提供します。 |
| 名（SHA256ハッシュを適用） | プレーンテキストの名を提供し、コネクタがこの値を空白トリム、小文字化、SHA256ハッシュ化します。 |

| 住所（既にSHA256ハッシュ化済み） | すでに空白トリム、小文字化、SHA256ハッシュ化された住所を提供します。 |
| 住所（SHA256ハッシュを適用） | プレーンテキストの住所を提供し、コネクタがこの値を空白トリム、小文字化、SHA256ハッシュ化します。 |
| 市区町村（既にSHA256ハッシュ化済み） | すでに空白トリム、小文字化、SHA256ハッシュ化された市区町村を提供します。 |

| LiveRamp ID | LiveRamp IDです。 |

#### 国コード

| **パラメータ** | **説明** |
| --- | --- |
| 国コード | ISO 3166形式の2文字の文字列で、データが収集された国を示します。レコードレベルで追加された国コードは、オーディエンスレベルで追加された国コードを上書きします。 |
| IPアドレス | このオーディエンスに追加されたメンバーの国を決定するために使用されるIPアドレスです。 |
