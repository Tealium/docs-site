## バッチ処理の上限

このコネクタは、ベンダーへの大量のデータ転送に対応するため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに追加されます。

* リクエストの最大数：10,000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：2 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を行います。
* **APIベースURL**  
  * APIベースURLを選択します。
* **Amazon AdsマネージャーアカウントID**  
  * ADMマネージャーアカウントIDです。確認するには、ADM UIの右上にあるメニューで「Manager Account」をクリックします。マネージャーアカウントを所有している場合に使用します。
* **Amazon AdsアカウントID**  
  * ADMアカウントIDです。マネージャーアカウントを所有していない場合に使用します。非マネージャーアカウントではデータセットを作成できません。


<blockquote>
Amazon AdsマネージャーアカウントIDとAmazon AdsアカウントIDの両方を構成しないでください。
</blockquote>


## アクション

| アクション名 | AudienceStream | EventStream |
| --- | :---: | :---: |
| オーディエンスに訪問を追加 | ✓ | ✓ |
| オーディエンスから訪問を削除 | ✓ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| オーディエンスデータセット | マネージャーアカウント：ドロップダウンからADMオーディエンスデータセットを選択するか、**オーディエンスデータセットを作成**をクリックして新しいデータセットを作成します。非マネージャーアカウント：ADMオーディエンスデータセットIDを手動で入力します。非マネージャーアカウントでは、データセットの作成および一覧表示は利用できません。 |

#### 外部ユーザーID

| **パラメータ** | **説明** |

| 外部ID | データプロバイダーによって定義された外部ユーザー識別子です。 |
| 外部ID（SHA256ハッシュを適用） | Amazonに送信する前に、コネクタで外部IDの値をハッシュ化する場合は、このパラメータを使用します。 |

#### 国コード

| **パラメータ** | **説明** |
| --- | --- |
| 国コード | 国コードは、データが収集された国を示すISO 3166形式の2文字の文字列です。レコードレベルで追加された国コードは、オーディエンスレベルで追加された国コードより優先されます。 |
