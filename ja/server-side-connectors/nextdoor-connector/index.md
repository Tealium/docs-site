## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名: Nextdoor API
* APIバージョン: v2
* APIエンドポイント: `https://ads.nextdoor.com/v2/api`
* ドキュメント: [Nextdoor API](https://developer.nextdoor.com/reference/conversion-api)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **APIトークン**:（必須）Nextdoor Ads Managerのアカウントページで、ログイン中のユーザーとそのユーザーに関連付けられたアカウントに固有の認証トークンを取得します。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| コンバージョンを送信 | ✗ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### コンバージョンを送信

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| イベント名 | コンバージョントラッキングイベントのタイプ。リストから値を選択するか、カスタム文字列値を入力します。次の値を使用できます：`Add to Cart`、`Initiate Checkout`、`Search`、`Add to Wishlist`、`Subscribe`、`View Content`。|
| アクションソース | コンバージョンが発生するチャネル。ドロップダウンリストから値を選択します。 |

#### コンバージョンイベント

| **パラメータ** | **説明** |
| --- | --- |
| クライアントID | Nextdoor Ads Managerの広告主ID。**データソースID**または**クライアントID**が必要です。 |
| データソースID | Nextdoor Ads ManagerのデータソースID。**データソースID**または**クライアントID**が必要です。これにより、Conversions APIとピクセルの両方を介してイベントを送信する広告主について、Nextdoorがイベントの重複を排除できます。 |
| パートナーID | 単一のパートナーに関連付けられた、Nextdoorによって生成されたID。この値は、すべてのConversion API呼び出しで必須です。 |
| アクションソースURL | イベントが発生したブラウザーのURL。URLは`http://`または`https://`で始まり、検証済みドメインと一致する必要があります。この値は、Webサイトイベントでは必須です。 |
| イベントID | 一意のイベントを識別できる文字列またはハッシュ化されたID。CAPIとピクセルトラッキングからのイベントの重複を排除するために必要です。**イベントID**または**自動重複排除**が必要です。 |
| イベント時刻 | [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601)形式のイベントのタイムスタンプ。**イベント時刻（エポック）**または**イベント時刻**が必要です。 |
| イベント時刻（エポック） | `1970-01-01`からの経過秒数。ミリ秒は使用できません。**イベント時刻（エポック）**または**イベント時刻**が必要です。 |
| テストイベント | このイベントがテストイベントかどうかを示します。デフォルト値は`False`です。 |
| イベントのタイムゾーン | コンバージョンイベントが発生した場所を示すタイムゾーン。 |
#### 顧客データ

この連携には、**メールアドレス**、**電話番号**、**クリック ID**のうち、少なくとも1つ、または複数のパラメータの組み合わせが必要です。

| **パラメータ** | **説明** |
| --- | --- |
| メールアドレス（SHA256 でハッシュ化済み） | SHA256 でハッシュ化済みのメールアドレスを指定します。 |
| メールアドレス（SHA256 ハッシュを適用） | プレーンテキストのメールアドレスを指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256 でハッシュ化します。 |
| 外部 ID | ロイヤルティプログラムの会員 ID、ユーザー ID、外部 Cookie ID など、広告主が使用する一意の ID。特定のイベントに対して、1つ以上の外部 ID を送信できます。他のチャネルを介して外部 ID を送信する場合は、Conversions API と同じ形式を使用してください。 | 
| 電話番号（SHA256 でハッシュ化済み） | SHA256 でハッシュ化済みの電話番号を指定します。 |
| 電話番号（SHA256 ハッシュを適用） | プレーンテキストの電話番号を指定します。コネクタは、この値の前後の空白を削除してから、SHA256 でハッシュ化します。 |
| 名（SHA256 でハッシュ化済み） | SHA256 でハッシュ化済みの名を指定します。 |
| 名（SHA256 ハッシュを適用） | プレーンテキストの名を指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256 でハッシュ化します。 |
| 姓（SHA256 でハッシュ化済み） | SHA256 でハッシュ化済みの姓を指定します。 |
| 姓（SHA256 ハッシュを適用） | プレーンテキストの姓を指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256 でハッシュ化します。 |
| 生年月日（SHA256 でハッシュ化済み） | SHA256 でハッシュ化済みで、`YYYYMMDD` 形式の生年月日を指定します。 |
| 生年月日（SHA256 ハッシュを適用） | プレーンテキストの生年月日を `YYYYMMDD` 形式で指定します。コネクタは、この値の前後の空白を削除してから、SHA256 でハッシュ化します。 |
| 番地（SHA256 でハッシュ化済み） | SHA256 でハッシュ化済みの番地を指定します。 |
| 番地（SHA256 ハッシュを適用） | プレーンテキストの番地を指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256 でハッシュ化します。 |
| 市区町村（SHA256 でハッシュ化済み） | SHA256 でハッシュ化済みの市区町村を指定します。 |
| 市区町村（SHA256 ハッシュを適用） | プレーンテキストの市区町村を指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256 でハッシュ化します。 |
| 州（SHA256 でハッシュ化済み） | 小文字に変換済みの2文字の [ANSI 略称コード](https://en.wikipedia.org/wiki/Federal_Information_Processing_Standard_state_code)で州の略称を指定します。 |
| 州（SHA256 ハッシュを適用） | 州の略称を2文字の [ANSI 略称コード](https://en.wikipedia.org/wiki/Federal_Information_Processing_Standard_state_code)で指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256 でハッシュ化します。 |
| 郵便番号（SHA256 でハッシュ化済み） | SHA256 でハッシュ化済みの郵便番号を指定します。 |
| 郵便番号（SHA256 ハッシュを適用） | プレーンテキストの郵便番号を指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256 でハッシュ化します。 |
| 国（SHA256 でハッシュ化済み） | 前後の空白を削除し、SHA256 でハッシュ化済みの2文字の国コードを [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) 形式で指定します。 |
| 国（SHA256 ハッシュを適用） | プレーンテキストの国コードを [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) 形式で指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256 でハッシュ化します。 |
| 性別（SHA256 でハッシュ化済み） | SHA256 でハッシュ化済みの性別を指定します。小文字の頭文字を使用してください。女性は f、男性は m、ノンバイナリーは n を使用します。回答しない場合は空のままにします。 |
| 性別（SHA256 ハッシュを適用） | プレーンテキストの性別を指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256 でハッシュ化します。小文字の頭文字を使用してください。女性は f、男性は m、ノンバイナリーは n を使用します。回答しない場合は空のままにします。 |
| ピクセル ID | Nextdoor ピクセル ID。Conversions API とピクセルの両方を介してイベントを送信する広告主について、Nextdoor がイベントの重複を排除できるようにします。 |
| クリック ID | クリックスルー URL にエンリッチメントされる `ndclid` パラメータと同じ値です。 |
| クライアント IP アドレス | <ul><li>イベントに対応するブラウザの IP アドレスは、有効な IPV4 または IPV6 アドレスである必要があります。IPV6 対応ユーザーには、IPV4 よりも IPV6 の使用が推奨されます。</li><li>イベントを正確にレポートできるように、常に実際の IP アドレスを指定してください。</li><li>この値をハッシュ化しないでください。</li><li>すべてのイベントで**クライアント IP アドレス**と**ユーザーエージェント**の両方のパラメータを送信すると、イベントのマッチングとキャンペーンの広告配信が向上する可能性があります。</li><li>ブラウザから送信されるイベントにはこの情報が自動的に追加されますが、サーバーから送信されるイベントについては手動で構成する必要があります。</li></ul>|
| クライアントユーザーエージェント | イベントに対応する、ハッシュ化されていないブラウザのユーザーエージェント。[Conversions API](https://developers.facebook.com/docs/marketing-api/conversions-api) を使用して共有されるウェブサイトイベントには、このパラメータが必要です。すべてのイベントで**クライアント IP アドレス**と**ユーザーエージェント**の両方のパラメータを送信すると、イベントのマッチングとキャンペーンの広告配信が向上する可能性があります。この情報はブラウザから送信されるイベントには自動的に追加されますが、サーバーから送信されるイベントについては手動で構成する必要があります。 |
| データソース ID | Nextdoor Ads Manager のデータソース ID。**データソース ID**または**クライアント ID**が必要です。Conversions API とピクセルの両方を介してイベントを送信する広告主について、Nextdoor がイベントの重複を排除できるようにします。 |
| 配信最適化 | <ul><li>`True`：データを最適化に使用できることを示します。</li><li>`False`：データがアトリビューションのみに使用されることを示します。</li></ul> |

#### カスタムイベントとアプリイベント

| **パラメータ** | **説明** |
| --- | --- |
| 注文金額 | 購入イベントでは必須です。[ISO 4217](https://en.wikipedia.org/wiki/ISO_4217) 形式の通貨コードに続けて、イベントに関連付けられた数値の合計金額（小数点以下2桁まで）を指定します。 |
| 注文 ID | 取引の注文 ID。オフラインイベントでは、この値が必要です。 |
| アプリ ID | 広告主の一意の ID に対応します。App Store および Google Play ストアのモバイルアプリ ID を使用します。 |
| プラットフォーム | ユーザーのプラットフォーム。値には `iOS` または `Android` を指定できます。 |
| アプリバージョン | モバイルアプリのバージョン。 |
| 配送カテゴリ | <ul><li>`In Store`：購入した商品を受け取るために、顧客が店舗内に入る必要があります。</li><li>`Curbside`：顧客が車で店舗まで行き、車内で待機して注文品を受け取ります。</li><li>`Home Delivery`：購入品が顧客の自宅に配送されます。</li></ul> |

#### 商品コンテキスト

| **パラメータ** | **説明** |
| --- | --- |
| ID | （必須）商品 ID。 |
| コンテンツ名 | 商品名。 |
| 数量 | 商品の数量。 |
| 商品価格 | 商品単価。 |
| アプリトラッキングの有効化 | ATT に関するユーザーのオプトアウト構成。アプリイベントをトラッキングし、Conversions API を介して Nextdoor に送信するかどうかを指定します。<ul><li>`False`：アプリイベントのトラッキングを無効にします。アプリイベントは Nextdoor に送信されません。</li><li>`True`：アプリイベントのトラッキングを有効にします。アトリビューションと測定のために、アプリイベントが Nextdoor に送信されます。</li></ul>  |
