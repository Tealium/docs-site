## 要件

このコネクタを使用するには、以下が必要です。

* 使用予定のアクションタイプに合わせて構成された Google Ads コンバージョンアクション：
  * **オフラインコンバージョンを送信**：コンバージョンアクションのタイプは `UPLOAD_CLICKS` である必要があります。
  * **オンラインコンバージョンを送信**：コンバージョンアクションのタイプは `WEBPAGE` である必要があります。
* Google Ads アカウントで、Tealium が接続済みのプロダクトとしてリンクされていること。手順については、[Tealium を Google Ads にリンクする](#link-tealium-to-google-ads)を参照してください。

## 仕組み

Google Ads Data Manager コンバージョンコネクタは、Google Data Manager API を介して、オフラインおよびオンラインのコンバージョンイベントを Google Ads に送信します。このコネクタは、[Google Ads コンバージョンコネクタ](https://docs.tealium.com/google-ads-conversions-connector/)よりも広範なイベントスキーマをサポートしており、ユーザー識別子、広告識別子、デバイス情報、コンバージョンデータ、カートデータ、ユーザープロパティ、カスタム変数、同意情報を含めることができます。

Tealium は、Google に承認された独自のデータパートナー認証情報を使用して認証します。コネクタ構成で Google OAuth 認証情報を入力する必要はありません。

## Tealium を Google Ads にリンクする

コネクタを構成する前に、コンバージョンイベントを受信する Google Ads アカウントに Tealium をリンクします。

1. Google Ads にログインします。
1. **ツール > データマネージャー > 接続済みのプロダクト**に移動します。
1. **+ プロダクトを接続**をクリックし、Tealium を選択します。
1. プロダクトのリンクを完了します。
1. Tealium に戻り、コネクタ構成で**プロダクトリンクのステータスを確認**をクリックして接続を確認します。

リンクを作成するアカウントによって、コネクタに入力するアカウント ID が決まります。

* **クライアントアカウント**：コンバージョンアクションを所有するクライアントアカウントに Tealium を直接リンクする場合は、そのアカウント ID を**顧客 ID**に入力します。
* **マネージャーアカウント**：マネージャーアカウントを介して Tealium をリンクする場合は、クライアントアカウント ID を**顧客 ID**に、マネージャーアカウント ID を**顧客マネージャー ID**に入力します。

## API 情報

このコネクタは、次のベンダー API を使用します。

* **API 名**：Google Data Manager API。
* **API バージョン**：v1。
* **API エンドポイント**：`POST https://datamanager.googleapis.com/v1/events:ingest`。
* **ドキュメント**：[Google：Data Manager API のイベント取り込み](https://developers.google.com/data-manager/api/reference/rest/v1/events/ingest)。

## バッチ処理の制限

このコネクタは、ベンダーへの大量のデータ転送をサポートするために、リクエストをバッチ処理します。並列処理により、イベントが順不同でベンダーに到達する可能性があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。以下のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに保持されます。

* リクエストの最大数：2,000
* 最も古いリクエストからの最大経過時間：60 分
* リクエストの最大サイズ：2 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下を構成します。

* **顧客 ID**：コンバージョンアクションを所有する Google Ads の顧客 ID。指定した場合、この値は、顧客 ID の上書き値が含まれていないイベントのフォールバックとして使用されます。すべてのイベントで顧客 ID の上書き値を指定する場合に限り、このフィールドを空白のままにしてください。
* **顧客マネージャー ID**：マネージャーアカウントを介して Tealium を Google Ads にリンクした場合の、Google Ads マネージャー顧客 ID。Tealium をクライアントアカウントに直接リンクしている場合は、このフィールドを空白のままにしてください。
* **プロダクトリンクのステータスを確認**：クリックすると、構成された Google Ads アカウントに Tealium が接続済みのプロダクトとしてリンクされていることを確認できます。**顧客マネージャー ID**が指定されている場合はその値を使用し、それ以外の場合は**顧客 ID**を使用して確認します。どちらのフィールドも構成されていない場合、このボタンは無効になります。

コネクタを構成した後、**完了**をクリックします。

### オフラインコンバージョンを送信

#### コンバージョンアクション

| **パラメータ** | **説明** |
| --- | --- |
| コンバージョンアクション ID | （必須）このイベントを受信する Google Ads コンバージョンアクション ID を選択または入力します。コンバージョンアクションのタイプは `UPLOAD_CLICKS` である必要があります。コンバージョンアクション ID を確認するには、Google Ads でコンバージョンアクションを開き、**コンバージョンタイプ ID**の横にある数値を確認します。 |

#### ユーザー識別子

コンバージョンに関連付けるユーザー識別子をマッピングします。メールアドレス、電話番号、および住所の氏名フィールドは、Google に送信される前に正規化され、SHA-256 でハッシュ化されます。コネクタは、ハッシュ化された値を小文字の 16 進数文字列として送信します。

住所情報を指定する場合は、名、姓、国コード、郵便番号の 4 つの住所フィールドをすべて指定する必要があります。不完全な住所データは送信されません。

| **パラメータ** | **説明** |
| --- | --- |
| メールアドレス（SHA256 ハッシュ化済み） | SHA-256 でハッシュ化されたメールアドレス。ハッシュ化する前に、すべての空白を削除し、小文字に変換します。`gmail.com` および `googlemail.com` のアドレスでは、`@` 記号より前にあるピリオドも削除し、ローカル部のプラス記号とそれ以降のすべての文字を削除します。ハッシュは、64 文字の小文字の 16 進数文字列として指定します。 |
| メールアドレス（SHA256 ハッシュを適用） | プレーンテキストのメールアドレス。コネクタは、Google に送信する前に値を正規化してハッシュ化します。 |
| 電話番号（SHA256 ハッシュ化済み） | SHA-256 でハッシュ化された電話番号。ハッシュ化する前に、先頭にプラス記号と国コードを付け、プラス記号以降には数字のみが含まれる E.164 形式に電話番号を正規化します。ハッシュは、64 文字の小文字の 16 進数文字列として指定します。 |
| 電話番号（SHA256 ハッシュを適用） | 国コードを含むプレーンテキストの電話番号。コネクタは、Google に送信する前に値を E.164 形式に整形してハッシュ化します。 |
| 住所情報：名（SHA256 ハッシュ化済み） | SHA-256 でハッシュ化された名。ハッシュ化する前に、小文字に変換し、空白を削除して、句読点および「Mrs.」などの敬称を削除します。ハッシュは、64 文字の小文字の 16 進数文字列として指定します。 |
| 住所情報：名（SHA256 ハッシュを適用） | 敬称や接頭辞を含まないプレーンテキストの名。コネクタは、Google に送信する前に値を正規化してハッシュ化します。 |
| 住所情報：姓（SHA256 ハッシュ化済み） | SHA-256 でハッシュ化された姓。ハッシュ化する前に、小文字に変換し、空白を削除して、句読点および「Jr.」などの接尾辞を削除します。ハッシュは、64 文字の小文字の 16 進数文字列として指定します。 |
| 住所情報：姓（SHA256 ハッシュを適用） | 接尾辞を含まないプレーンテキストの姓。コネクタは、Google に送信する前に値を正規化してハッシュ化します。 |
| 住所情報：国コード | 住所に関連付けられた 2 文字の ISO 3166-1 alpha-2 国または地域コード。この値はハッシュ化しないでください。 |
| 住所情報：郵便番号 | 住所に関連付けられた郵便番号または ZIP コード。先頭と末尾の空白を削除します。米国の住所の場合は、5 桁の数字、または 5 桁の数字に 4 桁の拡張番号をエンリッチメントした形式で指定します。この値はハッシュ化しないでください。 |

#### カート内商品

複数の商品を送信するには、商品フィールドに配列型の属性を使用します。各配列には同じ数の値を含め、同じ位置にある値が同一の商品を表すようにする必要があります。

| **パラメーター** | **説明** |
| --- | --- |
| 商品 ID | （必須）カート内商品の識別子。この値は、Merchant Center で使用されている商品識別子と一致する必要があります。 |
| マーチャント商品 ID | Merchant Center フィード内の商品に関連付けられた商品識別子。 |
| 数量 | （必須）販売された単位数。 |
| 単価 | （必須）税金、送料、およびトランザクションレベルの割引を除く、1 単位あたりの価格。 |
| 商品コンバージョン値 | 商品に関連付けられたコンバージョン値。 |

#### 同意

同意値はイベントレベルでマッピングします。コネクターは、これらの値を変更せずに Google に渡します。同意が拒否された場合でも、マッピングされたすべてのイベントフィールドがリクエストに含まれます。Google 側で制限が適用されます。

| **パラメーター** | **説明** |
| --- | --- |
| 広告ユーザーデータに関する同意 | 広告ユーザーデータに関する同意ステータス。有効な値は `CONSENT_GRANTED`、`CONSENT_DENIED`、および `CONSENT_STATUS_UNSPECIFIED` です。省略形の値 `GRANTED` と `DENIED` も使用できます。このフィールドをマッピングしない場合、同意フィールドはイベントから省略されます。 |
| 広告のパーソナライズに関する同意 | 広告のパーソナライズに関する同意ステータス。有効な値は `CONSENT_GRANTED`、`CONSENT_DENIED`、および `CONSENT_STATUS_UNSPECIFIED` です。省略形の値 `GRANTED` と `DENIED` も使用できます。このフィールドをマッピングしない場合、同意フィールドはイベントから省略されます。 |

| メールアドレス（SHA256 でハッシュ化済み） | SHA-256 でハッシュ化されたメールアドレス。ハッシュ化する前に、すべての空白を取り除き、小文字に変換します。`gmail.com` および `googlemail.com` のアドレスでは、`@` 記号より前にあるピリオドも削除し、ローカル部のプラス記号とそれに続くすべての文字を削除します。ハッシュは、64文字の小文字の16進数文字列として指定します。 |
| メールアドレス（SHA256 ハッシュを適用） | プレーンテキストのメールアドレス。コネクタは、Google に送信する前に値を正規化してハッシュ化します。 |

| 電話番号（SHA256 ハッシュを適用） | 国コードを含むプレーンテキストの電話番号。コネクタは、値を E.164 形式に整形し、Google に送信する前にハッシュ化します。 |
| 住所情報：名（SHA256 でハッシュ化済み） | SHA-256 でハッシュ化された名。ハッシュ化する前に、小文字に変換して空白を取り除き、句読点および「Mrs.」などの敬称を削除します。ハッシュは、64文字の小文字の16進数文字列として指定します。 |
| 住所情報：名（SHA256 ハッシュを適用） | 敬称や接頭辞を含まないプレーンテキストの名。コネクタは、Google に送信する前に値を正規化してハッシュ化します。 |
| 住所情報：姓（SHA256 でハッシュ化済み） | SHA-256 でハッシュ化された姓。ハッシュ化する前に、小文字に変換して空白を取り除き、句読点および「Jr.」などの接尾辞を削除します。ハッシュは、64文字の小文字の16進数文字列として指定します。 |
| 住所情報：姓（SHA256 ハッシュを適用） | 接尾辞を含まないプレーンテキストの姓。コネクタは、Google に送信する前に値を正規化してハッシュ化します。 |
| 住所情報：国コード | 住所に関連付けられた2文字の ISO 3166-1 alpha-2 国または地域コード。この値はハッシュ化しないでください。 |
| 住所情報：郵便番号 | 住所に関連付けられた郵便番号または ZIP コード。先頭と末尾の空白を取り除きます。米国の住所では、5桁、または5桁の後に4桁の拡張番号が続く形式で指定します。この値はハッシュ化しないでください。 |

#### カート内商品

複数の商品を送信するには、商品フィールドに配列型属性を使用します。各配列には同じ数の値を含め、同じ位置の値が同じ商品を表すようにする必要があります。

複雑な商品データやネストされた商品データを送信するには、`{{my_template}}` などのテンプレート参照を **カート内商品** にマッピングします。テンプレートでは、各商品の商品 ID、数量、単価を含む、完全なカート内商品配列を構築する必要があります。テンプレートがマッピングされている場合、個別の商品フィールドのマッピングは無視されます。

| **パラメーター** | **説明** |
| --- | --- |
| 商品 ID | （必須）カート内商品の識別子。この値は、Merchant Center で使用されている商品識別子と一致する必要があります。 |
| 販売者商品 ID | Merchant Center フィード内の商品に関連付けられた商品識別子。 |
| 数量 | （必須）販売された個数。 |
| 単価 | （必須）税、送料、トランザクション単位の割引を除いた、1個あたりの価格。 |
| 商品コンバージョン値 | 商品に関連付けられたコンバージョン値。 |

#### 同意

イベントレベルで同意値をマッピングします。コネクタはこれらの値を変更せずに Google に渡します。同意が拒否された場合でも、マッピングされたすべてのイベントフィールドがリクエストに含まれます。Google 側で制限が適用されます。

| **パラメーター** | **説明** |
| --- | --- |
| 広告ユーザーデータへの同意 | 広告ユーザーデータに対する同意ステータス。有効な値は `CONSENT_GRANTED`、`CONSENT_DENIED`、`CONSENT_STATUS_UNSPECIFIED` です。省略形の値 `GRANTED` と `DENIED` も使用できます。このフィールドがマッピングされていない場合、同意フィールドはイベントから省略されます。 |
| 広告のパーソナライズへの同意 | 広告のパーソナライズに対する同意ステータス。有効な値は `CONSENT_GRANTED`、`CONSENT_DENIED`、`CONSENT_STATUS_UNSPECIFIED` です。省略形の値 `GRANTED` と `DENIED` も使用できます。このフィールドがマッピングされていない場合、同意フィールドはイベントから省略されます。 |
