## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：TikTok HTTP API
* APIバージョン：v1.3
* APIエンドポイント：`https://business-api.tiktok.com/open_api/v1.3`
* ドキュメント：[TikTokオーディエンスセグメント](https://ads.tiktok.com/marketing_api/docs?id=1736874036878337)

## バッチ制限

このコネクタは、ベンダーへの大量データ転送をサポートするため、リクエストをバッチ処理します。次のいずれかのしきい値に達するまで、リクエストはキューに格納されます。

* リクエストの最大数：1000
* 最も古いリクエストからの最大経過時間：30分
* リクエストの最大サイズ：1 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **広告主ID**：（必須）TikTok Ads Managerの広告アカウントID。詳細については、[TikTok：広告アカウントIDを確認する方法](https://ads.tiktok.com/help/article/find-your-ad-account-id?lang=en)を参照してください。

**接続を確立**をクリックして、TikTokへの接続をテストします。

このコネクタ用のオーディエンスを作成するには、次の手順を実行します。

1. **オーディエンスを作成**をクリックします。
1. **カスタムオーディエンス名**に、このコネクタで使用するオーディエンス名を入力します。
1. **暗号化タイプ**ドロップダウンリストから、オーディエンスへのデータ追加時に使用する暗号化タイプを選択します。
1. **作成**をクリックし、次に**完了**をクリックします。

オーディエンスを削除するには、次の手順を実行します。

1. **オーディエンスを削除**をクリックします。
1. **オーディエンスID**ドロップダウンリストから、削除するオーディエンスを選択します。
1. **削除**をクリックし、次に**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| 訪問をオーディエンスに追加 | ✓ | ✗ |
| 訪問をオーディエンスから削除 | ✓ | ✗ |

**続行**をクリックして、コネクタのアクションを構成します。アクションの名前を入力し、**アクションタイプ**を選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### 訪問をオーディエンスに追加

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|オーディエンスID| オーディエンスを選択するか、オーディエンスIDを入力します。|
|IDFA（MD5ハッシュを適用）| プレーンテキストのiOS IDFAを指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、MD5でハッシュ化します。|
|IDFA（MD5ハッシュ化済み）| MD5でハッシュ化済みのiOS IDFAを指定します。|
|AAID（MD5ハッシュを適用）| Androidデバイスのプレーンテキストの広告識別子を指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、MD5でハッシュ化します。|
|AAID（MD5ハッシュ化済み）| MD5でハッシュ化済みのAndroidデバイスの広告識別子を指定します。|
|IDFA（SHA256ハッシュを適用）| プレーンテキストのiOS IDFAを指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、SHA256でハッシュ化します。|
|IDFA（SHA256ハッシュ化済み）| SHA256でハッシュ化済みのiOS IDFAを指定します。|
|AAID（SHA256ハッシュを適用）| Androidデバイスのプレーンテキストの広告識別子を指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、SHA256でハッシュ化します。|
|AAID（SHA256ハッシュ化済み）| SHA256でハッシュ化済みのAndroidデバイスの広告識別子を指定します。|
|メールアドレス（SHA256ハッシュを適用）| プレーンテキストのメールアドレス（`@`を含める必要があります）を指定します。コネクタは、この値の前後の空白を削除して小文字に変換し、SHA256でハッシュ化します。 |
|メールアドレス（SHA256ハッシュ化済み）| SHA256でハッシュ化済みのメールアドレスを指定します。 |
|電話番号（SHA256ハッシュを適用）| プレーンテキストの電話番号を指定します。コネクタは、この値の前後の空白を削除し、SHA256でハッシュ化します。|
|電話番号（SHA256ハッシュ化済み）| SHA256でハッシュ化済みの電話番号を指定します。|

1つのアクションに複数の識別子をマッピングできます。識別子を追加するには、**マッピングを追加**をクリックします。少なくとも1つの識別子をマッピングしてください。コネクタは、1つのレコードに複数の訪問を含めるのではなく、同じ訪問の複数の識別子を1つのリクエストで送信します。識別子のマッピングには、次の制約が適用されます。

* 識別子タイプごとに許可されるソース属性は1つのみです。
* 同じ識別子とハッシュ方式の組み合わせを重複してマッピングすることはできません。
* 同じ識別子タイプについて、プレーンテキスト値とハッシュ化済みの値の両方をマッピングすることはできません。
