## API 情報

このコネクタでは、次のベンダー API を使用します。

* API 名：TikTok HTTP API
* API バージョン：v1.3
* API エンドポイント：`https://business-api.tiktok.com/open_api/v1.3`
* ドキュメント：[TikTok オーディエンスセグメント](https://ads.tiktok.com/marketing_api/docs?id=1736874036878337)

## バッチ制限

このコネクタでは、ベンダーへの大量のデータ転送に対応するため、リクエストをバッチ処理します。次のいずれかのしきい値に達するまで、リクエストはキューに格納されます。

* リクエストの最大数：1000
* 最も古いリクエストからの最大経過時間：30 分
* リクエストの最大サイズ：1 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を行います。

* **広告主 ID**：（必須）TikTok Ads Manager の広告アカウント ID。詳細については、[TikTok：広告アカウント ID を確認する方法](https://ads.tiktok.com/help/article/find-your-ad-account-id?lang=en)を参照してください。

**接続を確立**をクリックして、TikTok への接続をテストします。

このコネクタ用のオーディエンスを作成するには、次の手順に従います。

1. **オーディエンスを作成**をクリックします。
1. **カスタムオーディエンス名**に、このコネクタで使用するオーディエンス名を入力します。
1. **暗号化タイプ**ドロップダウンリストから、オーディエンスへのデータ追加時に使用する暗号化タイプを選択します。
1. **作成**をクリックし、次に**完了**をクリックします。

オーディエンスを削除するには、次の手順に従います。

1. **オーディエンスを削除**をクリックします。
1. **オーディエンス ID**ドロップダウンリストから、削除するオーディエンスを選択します。
1. **削除**をクリックし、次に**完了**をクリックします。

## アクション

| アクション名 | AudienceStream | EventStream |
| --- | :---: | :---: |
| 訪問をオーディエンスに追加 | ✓ | ✗ |
| オーディエンスから訪問を削除 | ✓ | ✗ |

**続行**をクリックして、コネクタのアクションを構成します。アクションの名前を入力し、**アクションタイプ**を選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### 訪問をオーディエンスに追加

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|オーディエンス ID| オーディエンスを選択するか、オーディエンス ID を入力します。|
|IDFA（MD5 ハッシュを適用）| プレーンテキストの iOS IDFA を指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、MD5 でハッシュ化します。|
|IDFA（MD5 でハッシュ化済み）| MD5 でハッシュ化済みの iOS IDFA を指定します。|
|AAID（MD5 ハッシュを適用）| Android デバイス用のプレーンテキストの広告 ID を指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、MD5 でハッシュ化します。|
|AAID（MD5 でハッシュ化済み）| MD5 でハッシュ化済みの Android デバイス用広告 ID を指定します。|
|IDFA（SHA256 ハッシュを適用）| プレーンテキストの iOS IDFA を指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256 でハッシュ化します。|
|IDFA（SHA256 でハッシュ化済み）| SHA256 でハッシュ化済みの iOS IDFA を指定します。|
|AAID（SHA256 ハッシュを適用）| Android デバイス用のプレーンテキストの広告 ID を指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256 でハッシュ化します。|
|AAID（SHA256 でハッシュ化済み）| SHA256 でハッシュ化済みの Android デバイス用広告 ID を指定します。|
|メールアドレス（SHA256 ハッシュを適用）| プレーンテキストのメールアドレス（`@`を含める必要があります）を指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256 でハッシュ化します。 |
|メールアドレス（SHA256 でハッシュ化済み）| SHA256 でハッシュ化済みのメールアドレスを指定します。 |
|電話番号（SHA256 ハッシュを適用）| プレーンテキストの電話番号を指定します。コネクタは、この値の前後の空白を削除してから、SHA256 でハッシュ化します。|
|電話番号（SHA256 でハッシュ化済み）| SHA256 でハッシュ化済みの電話番号を指定します。|

1 つのアクションに複数の識別子をマッピングできます。識別子を追加するには、**マッピングを追加**をクリックします。少なくとも 1 つの識別子をマッピングしてください。コネクタは、1 つのレコードに複数の訪問を含めるのではなく、同じ訪問の複数の識別子を 1 回のリクエストで送信します。識別子のマッピングには、次の制約が適用されます。

* 識別子タイプごとに許可されるソース属性は 1 つだけです。
* 同じ識別子とハッシュの組み合わせを重複してマッピングすることはできません。
* 同じ識別子タイプについて、プレーンテキスト値とハッシュ化済みの値の両方をマッピングすることはできません。
