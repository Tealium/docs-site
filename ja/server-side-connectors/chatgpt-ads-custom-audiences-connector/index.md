ChatGPT Ads カスタムオーディエンスコネクタは、OpenAI カスタムオーディエンスに訪問を追加、またはそこから削除します。そのオーディエンスを ChatGPT Ads キャンペーンでターゲットに構成し、対象への追加、除外、または入札単価の調整に使用できます。

このコネクタは、送信前に識別子を検証し、SHA-256 でハッシュ化します。サポートされる識別子の種類は、メールアドレス、電話番号、Google Advertising ID（GAID）です。

## 要件

このコネクタには、次のものが必要です。

* OpenAI Ads Manager アカウント。
* OpenAI Ads Manager の **Settings** で作成した Ads API キー。キーは、そのキーが属する広告アカウント内のカスタムオーディエンスにのみアクセスできます。
* カスタムオーディエンス。OpenAI Ads Manager で作成するか、コネクタの **Create Custom Audience** 管理タスクを使用して作成します。

## API 情報

このコネクタは、次のベンダー API を使用します。

* **API 名**：OpenAI Ads API。
* **API バージョン**：v1。
* **API エンドポイント**：`https://api.ads.openai.com`。
* **ドキュメント**：[OpenAI Ads：カスタムオーディエンス](https://developers.openai.com/ads/custom-audiences)および [OpenAI Ads API OpenAPI 仕様](https://developers.openai.com/ads/openapi.json)。

## バッチ制限

このコネクタは、ベンダーへの大量のデータ転送をサポートするためにバッチリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに入れられます。

* リクエストの最大数：2000
* 最も古いリクエストからの最大経過時間：60 分
* リクエストの最大サイズ：4 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **Ads API Key**：（必須）OpenAI Ads Manager の **Settings** で作成した Ads API キー。キーは、そのキーが属する広告アカウント内のカスタムオーディエンスにのみアクセスできます。

コネクタを構成した後、**Done** をクリックします。

## カスタムオーディエンスの作成

**Create Custom Audience** 管理タスクを使用すると、コネクタから直接 OpenAI に空のカスタムオーディエンスを作成できます。コネクタは、そのコネクタの **Ads API Key** を使用し、キーが属する広告アカウントにオーディエンスを作成します。

カスタムオーディエンスを作成するには、次の手順を実行します。

1. コネクタで **Create Custom Audience** をクリックします。
1. 次のフィールドを構成します。

    | フィールド | 説明 |
    | --- | --- |
    | **Audience Name** | （必須）新しいカスタムオーディエンスの名前。3～1,000 文字で指定します。 |
    | **Description** | （任意）OpenAI に保存されるオーディエンスの説明。個人データを含めないでください。 |

1. **Create Custom Audience** をクリックします。

オーディエンスは空の状態で作成されます。**Add to Custom Audience** アクションを使用してメンバーを追加します。


<blockquote>
クリックするたびに個別のオーディエンスが作成されます。OpenAI から応答が返されない場合、オーディエンスがすでに存在している可能性があるため、再試行する前に **Custom Audience** リストを更新してください。
</blockquote>


広告アカウントで小規模または空のオーディエンスが許可されていない場合、OpenAI はリクエストを拒否します。代わりに OpenAI Ads Manager でオーディエンスを作成してください。

カスタムオーディエンスの名前を変更したり、アーカイブしたりするには、OpenAI Ads Manager を使用します。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| カスタムオーディエンスに追加 | ✓ | ✓ |
| カスタムオーディエンスから削除 | ✓ | ✓ |

**Continue** をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### カスタムオーディエンスに追加

OpenAI カスタムオーディエンスに訪問を追加します。すでにメンバーである訪問を追加しても影響はありません。

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| **API Key Override** | <ul><li>（任意）コネクタの **Ads API Key** の代わりに、このアクションで使用する Ads API キー。キーを保持する属性をマッピングするか、キーをカスタム値として入力します。</li><li>カスタム値はアクションに保存され、平文で表示されます。キーをアクションに含めないようにするには、属性からマッピングしてください。</li><li>**Custom Audience** リストでは、常にコネクタのキーが使用されます。このキーが別の広告アカウントに属している場合は、リストから選択するのではなく、カスタムオーディエンス ID を入力します。</li></ul> |
| **Custom Audience** | <ul><li>（必須）カスタムオーディエンスを選択するか、`caud_123` などの ID を入力します。</li><li>新しいオーディエンスを作成するには、**Create Custom Audience** をクリックするか、OpenAI Ads Manager で作成します。</li><li>リストにはアーカイブ済みのオーディエンスは含まれず、最大 5,000 件のオーディエンスが表示されます。オーディエンスがリストにない場合は、その ID を入力します。</li><li>オーディエンスを対象への追加または入札単価の調整に使用するには、約 25,000 人の一致ユーザーが必要です。除外オーディエンスには最小人数の要件はありません。送信した識別子の数よりも、一致するユーザー数は少なくなることが見込まれます。</li></ul> |

#### 識別子

少なくとも 1 つの属性をマッピングします。有効な識別子を持たない訪問は送信されず、アクションで検証エラーが報告されます。

| 識別子 | 説明 |
| --- | --- |
| **Email Address (apply SHA256 hash)** | 平文のメールアドレスをマッピングします。コネクタは値の前後の空白を削除して小文字に変換し、ドットとプラスタグを保持したままハッシュ化します。`@` がちょうど 1 つではない値や、スペースを含む値はスキップされます。 |
| **Email Address (already SHA256 hashed)** | 前後の空白を削除して小文字に変換してからハッシュ化された、メールアドレスの 64 文字の 16 進数 SHA-256 ハッシュをマッピングします。 |
| **Phone Number (apply SHA256 hash)** | `+1 (415) 555-2671` のように、国番号を含む電話番号をマッピングします。コネクタはスペース、ハイフン、丸かっこ、ピリオドを削除してから、`+14155552671` などの E.164 形式の番号をハッシュ化します。先頭の `+` と国番号がない番号はスキップされます。 |
| **Phone Number (already SHA256 hashed)** | `+14155552671` などの E.164 形式の電話番号をハッシュ化した、64 文字の 16 進数 SHA-256 ハッシュをマッピングします。 |
| **Google Advertising ID (GAID)** | ハイフンを含む GAID をマッピングします。ハッシュ化しないでください。コネクタは小文字で送信し、OpenAI がハッシュ化します。すべてゼロの ID はスキップされます。 |

マッピングルール：

* 無効な値はスキップされますが、訪問のその他の識別子は引き続き送信されます。
* 各オプションは一度だけマッピングしてください。両方のメールアドレスオプション、または両方の電話番号オプションをマッピングした場合、ハッシュ化済みの値が送信されます。有効なハッシュ化済みの値が訪問にない場合にのみ、平文の値がハッシュ化されて送信されます。
* 1 つの種類について複数の値を送信するには、リスト属性をマッピングします。

### カスタムオーディエンスから削除

OpenAI カスタムオーディエンスから訪問を削除します。メンバーではない訪問を削除しても影響はありません。削除によって、このオーディエンスを使用しているキャンペーンが最小人数を下回る場合、OpenAI は削除を拒否することがあります。

このアクションでは、**Add to Custom Audience** と同じパラメータを使用します。詳細については、[カスタムオーディエンスに追加](#add-to-custom-audience)を参照してください。

## 既知の制限事項

* オーディエンスを対象への追加または入札単価の調整に使用するには、約 25,000 人の一致ユーザーが必要です。OpenAI は 100,000 人を推奨しています。除外オーディエンスには最小人数の要件はありません。
* 一致ユーザー数は、正確な値ではなく範囲として OpenAI Ads Manager に表示されます。
* OpenAI はバックグラウンドでオーディエンスの変更を適用します。送信が成功しても、メンバーシップには即座に反映されません。通常、処理には 20～30 分かかります。
* 同じ訪問に対する **Add to Custom Audience** と **Remove from Custom Audience** が、順番どおりに適用されることは保証されません。追加後すぐに削除すると、一時的に誤った状態になることがあります。
* カスタムオーディエンスでは、EEA またはスイスのユーザーをターゲットに構成できません。
