## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **Snowflake アカウント識別子**：Snowflake アカウント識別子は、`{account_identifier}.snowflakecomputing.com` という形式でアカウント URL を構成するために使用されます。
* **ユーザー名**：Snowflake アカウントのユーザー名です。Snowflake サービスユーザーの使用をお勧めします。
* **秘密鍵**：ユーザーの秘密鍵です。
* **秘密鍵のパスフレーズ**：（任意）秘密鍵が暗号化されている場合は、暗号化された秘密鍵のパスフレーズを指定します。秘密鍵が暗号化されていない場合は、値を割り当てないでください。
* **ユーザーロール**：（任意）認証およびモデルエンドポイントへのアクセスに使用する Snowflake ロールを指定します。空白のままにすると、ユーザーのデフォルトロールが使用されます。選択したロールは、構成済みのユーザーに付与されており、Snowflake Cortex API およびデプロイ済みの各モデルエンドポイントへアクセスする権限を持っている必要があります。

コネクタを構成した後、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| Snowflake Cortex にプロンプトを送信 | ✓ | ✓ |
| モデルエンドポイントを呼び出す | ✓ | ✓ |

### Snowflake Cortex にプロンプトを送信

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| モデル | このリクエストで使用する Snowflake Cortex モデルを入力します。<br>正確なモデル名（例：`llama3.1-8b`）を指定してください。利用可能なモデルは Snowflake のリージョンと構成によって異なり、無効なモデル名を指定するとエラーが発生します。<br>Snowflake で構成されている場合は、完全修飾されたファインチューニング済みモデル名（`DATABASE.SCHEMA.MODEL`）も入力できます。<br>利用可能なモデルについては、[Snowflake：利用可能なモデル](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-rest-api#model-availability)を参照してください。 |

#### Tealium コンテキスト

コネクタは、現在のイベントから `tealium_account`、`tealium_profile`、`tealium_visitor_id` を自動的に渡します。必要に応じて、マッピングした値でこれらを上書きしてください。

| パラメータ | 説明 |
| --- | --- |
| Tealium イベント | （必須）AI レスポンスに含める `tealium_event` の値を入力します。 |
| Tealium データソース | Cortex データソースの作成後に提供されたデータソースキーを入力します。 |
| プロンプトパラメータ | Tealium 属性を、プロンプトテンプレートで使用するプレースホルダー名（例：`product_id`、`event_value`）にマッピングします。 |
| 訪問プロファイルを含める | （オーディエンスアクションで利用可能）有効にすると、訪問プロファイル全体をプロンプト内で `{{visitor_profile}}` として使用できます。 |
| 現在の訪問を含める | （オーディエンスアクションで利用可能）有効にすると、現在の訪問属性が `{{visitor_profile}}` オブジェクトに追加されます（属性名をキーとして使用）。 |
| イベントペイロードを含める | （イベントアクションで利用可能）有効にすると、現在のイベントデータをプロンプト内で `{{event_payload}}` として使用できます。 |
| プロンプト | 選択した Snowflake Cortex モデルに送信するプロンプトを入力します。<br>マッピングしたパラメータには二重波括弧を使用します。例：`{{product_id}}`、`{{event_value}}`。<br>対応するオプションを有効にした後、`{{visitor_profile}}`（オーディエンスアクション）または `{{event_payload}}`（イベントアクション）を参照します。<br>モデルが各出力フィールドをどのように決定して構成するかを記述します。<br>JSON の書式構成に関する指示は含めないでください。コネクタは、構造化出力のマッピングを通じて JSON 構造を自動的に適用します。 |

#### モデルの詳細構成

| パラメータ | 説明 |
| --- | --- |
| `temperature` | ランダム性と創造性を制御します。値が低いほど、モデルの出力はより決定論的になります。 |
| `max_completion_tokens` | モデルが生成できるトークンの最大数です。デフォルトは 512 です。 |
| `top_p` | 確率質量が上位 p の候補のみからサンプリングすることで、多様性を制御します。 |

#### 構造化出力

| パラメータ | 説明 |
| --- | --- |
| 属性名 | 返されるフィールドの名前です。 |
| データ型 | フィールドのデータ型（文字列、整数、数値、ブール値）です。 |
| デバッグモード | 有効にすると、コネクタはレスポンスを Tealium Collect に送信しません。完全な処理を有効にする前に、Trace を使用して Snowflake の生レスポンスを確認し、有効な JSON であることを検証してください。 |

### モデルエンドポイントを呼び出す

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| エンドポイント URL | Snowflake Model Registry／Snowpark Container Services によって生成された、デプロイ済みの公開エンドポイントの URL を入力します。例：`https://<service-id>.snowflakecomputing.app/predict`。<br>この URL は、モデルの呼び出しと、認証に必要な OAuth スコープの生成に使用されます。<br>エンドポイントは公開アクセス可能で、リアルタイム推論用に構成されている必要があります。<br>Snowflake のユーザーまたはロールには、エンドポイントを呼び出す権限が必要です。 |
| 入力データ | Tealium のイベント属性または訪問属性を、デプロイ済みモデルが要求する入力フィールドにマッピングします。<br>入力フィールド名は、モデルが要求する特徴量名と完全に一致する必要があります。<br>少なくとも 1 つのマッピングが必要です。 |
| レスポンスパス | モデルレスポンス内で、属性として Tealium Collect に送信するフィールドを含む JSON オブジェクトへの任意のパスです。<br>ドット表記と配列インデックスを使用します。例：`data[0][1].PREDICTION` または `predictions[0]`。パスにある値が JSON 文字列の場合は、自動的に解析されます。<br>空白のままにすると、レスポンスのルートが JSON オブジェクトとして使用されます。<br>ネストされたオブジェクトと配列は JSON 文字列としてシリアライズされます。 |
| デバッグモード | 有効にすると、コネクタはレスポンスを Tealium Collect に送信しません。完全な処理を有効にする前に、Trace を使用して Snowflake の生レスポンスを確認し、有効な JSON であることを検証してください。 |
