## 構成

コネクターマーケットプレイスに移動し、新しいコネクターを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクターを追加した後、次の構成を構成します。

* **テナント ID**  
  * 組織を表す Azure Active Directory インスタンスの一意の識別子。
* **クライアント ID**  
  * Azure Active Directory に登録されたアプリケーションに割り当てられた一意の識別子。
* **クライアントシークレット**  
  * パスワードのように機能し、アプリケーションが Azure Active Directory で認証するために使用する文字列。
* **ワークスペース**  
  * 接続先のワークスペースを指定します。
* **Eventhouse**  
  * 接続先の Eventhouse インスタンスを指定します。
* **データベース**  
  * 接続先のデータベースを選択します。

コネクターを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| カスタムレコードを送信 | ✓ | ✓ |
| カスタムレコードを送信（バッチ） | ✓ | ✓ |
| イベントデータ全体を送信 | ✗ | ✓ |
| イベントデータ全体を送信（バッチ） | ✗ | ✓ |
| 訪問データ全体を送信 | ✓ | ✗ |
| 訪問データ全体を送信（バッチ） | ✓ | ✗ |
| ログイベントを送信 | ✗ | ✓ |
| ログイベント全体を送信 | ✗ | ✓ |

アクションの名前を入力し、アクションタイプを選択します。

以下のセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。

### カスタムレコードを送信

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| テーブル | 接続するテーブルの名前を指定します。 |

#### イベントパラメーター

パラメーターをテーブルの列にマッピングします。少なくとも 1 つのパラメーターをマッピングする必要があります。

### カスタムレコードを送信（バッチ）

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| テーブル | 接続するテーブルの名前を指定します。 |

#### イベントパラメーター

パラメーターをテーブルの列にマッピングします。少なくとも 1 つのパラメーターをマッピングする必要があります。

| **パラメーター** | **説明** |
| --- | --- |
| バッチの有効期間 | バッチアクションを送信する頻度を指定するため、有効期間（TTL）を構成します。`1`～`60` 分の値を入力します。デフォルト値は `10` 分です。 |

### イベントデータ全体を送信

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| テーブル | 接続するテーブルの名前を指定します。 |
| タイムスタンプ | タイムスタンプを記録する列を選択します。 |
| ペイロード | JSON ペイロードを記録する動的列を選択します。 |
| タイムスタンプ属性 | タイムスタンプを別の形式で送信する場合は、タイムスタンプとして割り当てる属性を選択します。属性が割り当てられていて、その値が空の場合、コネクターは現在のタイムスタンプを送信します。 |
| 属性名を出力 | デフォルトでは、属性キーが使用されます。代わりに属性名をキーとして使用する場合は、このチェックボックスをオンにします。属性名が更新されると、その変更がペイロード名にも反映されることに注意してください。 |
