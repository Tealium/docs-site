## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を構成します。

* **認証タイプ**：
  * **OAuth**：クライアント認証情報を使用してEmarsys v3 APIで認証します。詳細については、[Emarsys：v3 APIでの認証](https://dev.emarsys.com/docs/emarsys-core-api-guides/b3c3a1eba8515-authentication-in-v3-api)を参照してください。
  * **WSSE**：ユーザー名とパスワードを使用してEmarsys v2 APIで認証します。詳細については、[Emarsys：v2 WSSE認証](https://dev.emarsys.com/docs/emarsys-core-api-guides/branches/main/b3c3a1eba8515-authentication)を参照してください。
* **クライアントID**：  
OAuth認証タイプでは必須です。Emarsys v3 APIでの認証に使用するクライアントIDです。
* **クライアントシークレット**：  
OAuth認証タイプでは必須です。Emarsys v3 APIでの認証に使用するクライアントシークレットです。
* **ユーザー名**：  
WSSE認証タイプでは必須です。Emarsys APIDへのアクセス権限を持つユーザー名です。Emarsys APIDのユーザー名について詳しくは、[Emarsys：アカウントの構成](https://dev.emarsys.com/docs/core-api-reference/branches/main/a12e08c686f0f-2-set-up-your-account)を参照してください。
* **パスワード**：  
WSSE認証タイプでは必須です。指定したユーザー名のパスワードです。
* **環境**：  

コネクタを構成したら、**完了**をクリックします。
API呼び出しの対象となる環境です。

#### バッチ処理の上限

このコネクタは、ベンダーへの大量データ転送に対応するため、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに保持されます。

* リクエストの最大数：1000
* 最も古いリクエストからの最大経過時間：4分45秒
* リクエストの最大サイズ：10 MB
