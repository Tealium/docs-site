## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、以下の項目を構成します。

* **URL**
  * （必須）リクエストの送信先となる収集サーバーの完全なヒットURLを指定します。
  * 例：`https://logs.xiti.com/hit.xiti`
  * 詳細については、[ヒットの作成](https://developers.atinternet-solutions.com/general-en/craft-your-hit/)を参照してください。

* **サイト番号**
  * （必須）データの集計対象となるサイトです。

## アクション構成 - パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### アクション - カスタムページヒットを送信

#### パラメータ

| **パラメータ** | **説明**  |

| テンプレート変数  | <ul><li>（任意）テンプレートのデータ入力としてテンプレート変数を指定します</li><li>詳細については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。</li><li>ネストされたテンプレート変数には、ドット記法で名前を付けます。</li><li>例：`items.name`</li><li>ネストされたテンプレート変数は通常、データレイヤーのリスト属性から構築されます</li></ul> |
| テンプレート | <ul><li>（任意）メッセージデータ内で参照するテンプレートを指定します</li><li>>詳細については、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。</li><li>テンプレートは、サポートされているフィールドに二重中括弧を使用して名前で挿入します。例：`{{SomeTemplateName}}`。</li></ul>  |

### アクション - メディア再生ヒットを送信

#### パラメータ

| **パラメータ** | **説明**  |
|:------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 一意の訪問ID | <ul><li>（必須）訪問ごとに一意である必要があります</li><li>[XiTi by AT Internetのドキュメント](https://developers.atinternet-solutions.com/general-en/craft-your-hit/)を参照してください</li></ul> |
| コンテンツラベル | <ul><li>1～3個のラベル</li><li>配列属性タイプを使用して構成します。また、単一のラベルはスカラー値として指定できます</li></ul>  |
| メディアタイプ  | <ul><li>（必須）メディアタイプを選択します</li><li>オプションは`Video`、`Audio`、` Pre-roll video`、`Mid-roll video`、`Post-roll video`です</li></ul> |
| 配信タイプ  | <ul><li>（必須）配信タイプを選択します</li><li>オプションは`Clip`または`Live`です</li></ul>  |
| コンテンツの長さ  | <ul><li>配信タイプが`Clip`の場合、コンテンツの長さを秒単位で指定する必要があります</li><li>ライブ配信には適用されません</li></ul>  |
| 配信場所  | <ul><li>（必須）配信タイプを選択します</li><li>オプションは`internal`または`external`です</li></ul>  |
| コンテンツレベル | <ul><li>（任意）対応するIDを取得するには、XiTi Webサイトであらかじめ構成しておく必要があります</li></ul> |
| コンテンツのバッファリング | <ul><li>（任意）バッファリング中は`1`に構成し、バッファリング終了時に解除します</li></ul> |
| ページラベル  | <ul><li>（任意）コンテンツが再生されるページのラベル（任意でツリー構造を含む）</li></ul>  |
| ページレベル2  | <ul><li>（任意）コンテンツが再生されるページのレベル2</li></ul> |
| プレーヤー識別子 | <ul><li>（任意）同じページに複数のプレーヤーがある場合に便利です</li></ul> |
| 関連コンテンツのラベル | <ul><li>（任意）ツリー構造がある場合はそれを含みます。プリロール、ミッドロール、またはポストロールコンテンツの場合に使用します</li></ul> |
| 配信ドメイン  | <ul><li>任意</li></ul> <ul><li>外部配信の場合の配信ドメイン</li></ul>  |
| テンプレート変数  | <ul><li>（任意）テンプレートのデータ入力としてテンプレート変数を指定します</li><li>詳細については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。</li><li>ネストされたテンプレート変数には、ドット記法で名前を付けます</li><li>例：`items.name`</li><li>ネストされたテンプレート変数は通常、データレイヤーのリスト属性から構築されます</li></ul> |
| テンプレート | <ul><li>（任意）メッセージデータ内で参照するテンプレートを指定します</li><li>詳細については、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。</li><li>テンプレートは、サポートされているフィールドに二重中括弧を使用して名前で挿入します。例：`{{SomeTemplateName}}`。</li></ul>  |
