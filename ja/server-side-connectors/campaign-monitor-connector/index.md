## コネクターアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| スマートメールを送信 | ✓ | ✗ |
| 購読者を追加または更新 | ✓ | ✗ |

| 購読者の購読を解除 | ✓ | ✗ |
| 購読者を更新 | ✓ | ✗ |

## 構成

コネクターマーケットプレイスに移動し、新しいコネクターを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクターを追加したら、次の項目を構成します。

* **APIキー**  
 <br>Campaign Monitorアカウントを操作するには、APIキーが必要です。詳細については、<a href="http://help.campaignmonitor.com/topic.aspx?t=206" target="_blank">APIキーはどこで確認できますか？</a>を参照してください。
* **クライアント名**  
 <br>クライアントアカウントを管理するには、名前が必要です。

## アクション

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。

### スマートメールを送信

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| スマートメール | 送信するスマートトランザクションメールを選択します。 |

### 購読者を追加または更新

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| 購読者リスト | 購読者を追加するリストを選択します。 |
| 購読者のメールアドレス | （必須） |
| 購読者名 | （必須） |
| 購読者を再購読させる |  |
| 購読者の自動返信を再開 |  |

### 購読者を削除

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| 購読者リスト | 購読者を削除するリストを選択します。 |
| 購読者のメールアドレス | 選択したリストから削除するメールアドレスを指定します（<a href="http://help.campaignmonitor.com/topic.aspx?t=140#remove-options" target="_blank">削除と購読解除の違い</a>を参照）。削除されたメールアドレスはサプレッションリストに追加されません。<br>推奨事項：対象者から削除を依頼された場合は購読解除アクションを使用し、その他の理由で削除することを決定した場合は削除アクションを使用してください。 |

### 購読者の購読を解除

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| 購読者リスト | 購読者の購読を解除するリストを選択します。 |
| 購読者のメールアドレス | 選択したリストから購読解除するメールアドレスを指定し、サプレッションリストに追加します。また、購読解除構成が変更されているリストを除き、そのクライアントの他のすべてのリストでも、このメールアドレスの購読が解除されます。 |

### 購読者を更新

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| 購読者リスト | 購読者を更新するリストを選択します。 |
| 購読者のメールアドレス | （必須） |
| 購読者名 | （必須） |
| 購読者の携帯電話番号 |  |
| 購読者のカスタムフィールド | Clearを選択した場合、**Clear**を選択して値フィールドに値を入力するか、**Clear**を選択して値フィールドに`Clear`と入力し、値をクリアする属性名を入力することで、属性値を削除できます。カスタムフィールドの値をクリアするには、カスタムフィールドの名前と値に加えて、値がtrueのClearパラメーターを渡します。複数値の「複数選択」フィールドから特定のオプションを削除するには、値フィールドにオプション名を指定し、Clear: trueパラメーターを渡します。複数値の「複数選択」フィールドのすべての値をクリアするには、値を空にしてClear: trueパラメーターを渡します。また、日付タイプのカスタムフィールドは、値として「0000-00-00」を渡すことでもクリアできます。使用可能なフィールドは、選択した購読者リストによって決まります（<a href="http://help.campaignmonitor.com/topic.aspx?t=154" target="_blank">カスタムフィールドを作成して使用する方法</a>を参照）。<br>日付属性は自動的にYYYY-MM-DD形式に変換されます。 |
| トラッキングへの同意 | 購読者がメールの開封とクリックのトラッキングを許可しているかどうかを示します。この値は、同じクライアント内で同じメールアドレスを持つすべての購読者に適用されます。メールアドレスに対してunchangedの値を渡した場合、そのアドレスが現在クライアントに存在しない、またはConsentToTrackの既存値がない場合は、購読者が同意したものとみなされます。 |
| SMS送信への同意 | 購読者がSMSの受信に同意したかどうかを示す任意のパラメーターです。購読者のSMS送信への同意は、携帯電話番号が指定されている場合にのみ記録されます。同意していないことを示すためにも使用できます。このパラメーターを省略すると、既存の同意構成は変更されません。 |
| 再購読 | 購読者が非アクティブな状態である、以前に購読を解除している、またはサプレッションリストに追加されている場合に、Resubscribeの入力値としてtrueを指定すると、その購読者はリストに再追加されます。そのため、この方法は慎重に、適切な場合にのみ使用してください。Resubscribeにfalseを指定した場合、購読者はアクティブリストに再追加されません。 |
| 購読ベースの自動返信を再開 | RestartSubscriptionBasedAutorespondersの入力値としてtrueを指定すると、すべてのシーケンスが再開されます。RestartSubscriptionBasedAutorespondersは、再購読する購読者にのみ影響します。省略した場合のデフォルト値はfalseです。 |
