## 要件

このコネクタを構成する前に、Google Display & Video 360 アカウントで Tealium をリンク済みアカウントとして追加してください。

詳細については、[Google Display & Video 360：外部データ管理プラットフォームまたはカスタマーマッチのアップロードパートナーからオーディエンスリストを共有する](https://support.google.com/displayvideo/answer/9649053?hl=en)を参照してください。

## API 情報

このコネクタは、次のベンダー API を使用します。

* **API 名**：Google Data Manager API
* **API バージョン**：v1
* **API エンドポイント**：`https://datamanager.googleapis.com`
* **ドキュメント**：[Google Data Manager API](https://developers.google.com/data-manager/api/reference/rest)

非推奨のアクションでは Google Ads API を使用します。詳細については、[カスタマーマッチリストに追加（非推奨）](#add-to-customer-match-list-deprecated)を参照してください。

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/manage-connectors/)を参照してください。


<blockquote>
このコネクタを追加すると、ベンダーのデータプラットフォームポリシーへの同意を求められます。
</blockquote>


コネクタを追加した後、次の構成を構成します。

* **顧客 ID**：（必須）Tealium にリンクされている Google DV360 パートナー ID。パートナー ID を確認するには、Google DV360 ダッシュボードで **パートナー構成 > 基本情報** に移動します。
* **対象プロダクト**：（必須）リンク済みアカウントの対象プロダクト。

**完了**をクリックします。

### カスタマーマッチリストの作成

カスタマーマッチリストを作成するには、**カスタマーマッチリストを作成**をクリックし、次の情報を入力します。

| **パラメータ** | **説明** |
| --- | --- |
| リスト名 | （必須）カスタマーマッチリストの名前。 |
| リストタイプ | （必須）リストのタイプ。この構成は、このリストで使用するユーザー識別情報のタイプに影響します。<ul><li>連絡先情報 - メールアドレス、電話番号、住所などの顧客情報に基づいてメンバーを照合します。</li><li>モバイル広告 - モバイル広告 ID に基づいてメンバーを照合します。</li></ul> |
| アプリ ID | モバイル広告リストタイプでは必須です。データの収集元であるモバイルアプリケーションを一意に識別する文字列です。 |
| リストメンバーシップの有効期間 | （任意）ユーザーが最後にリストへ追加されてから、そのリストに留まる日数。`0`～`540`の数値を指定する必要があります。デフォルトの有効期間は 540 日です。 |
| リストの説明 | （任意）リストの説明。 |

### ユーザー識別子

各アクションにはユーザー識別子が必要です。これらの値を正規化して SHA-256 でハッシュ化するか、コネクタによる処理を選択します。各値は、次の要件を満たす必要があります。

* 小文字
* テキストの先頭と末尾から空白を削除
* SHA-256 でハッシュ化

選択した`User List`タイプによって、ユーザー識別子のタイプが決まります。`User List`タイプは、次のいずれかです。

* `CONTACT_INFO`
* `MOBILE_ADVERTISING_ID`

次のユーザー識別子フィールドがサポートされています。

|ユーザー識別子フィールド| 説明|
|---| ---|
| `CONTACT_INFO` | <ul><li>ハッシュ化されたメールアドレス、ハッシュ化された電話番号、または住所情報を指定します。</li><li>住所情報を指定する場合は、国コード、名、姓、郵便番号の 4 つのフィールドがすべて必須です。いずれかの**住所情報**フィールドが欠落している場合、コネクタはリクエストから住所オブジェクト全体を削除します。削除後にユーザーデータが残っていない場合、アクションは検証エラーで失敗し、再試行されません。</li><li>**住所情報：国コード**：ユーザーの住所の 2 文字の国コードを ISO 3166-1 alpha-2 形式で指定します。</li><li>**住所情報：名（SHA256 でハッシュ化済み）**：先頭と末尾の空白を削除し、小文字に変換して SHA-256 でハッシュ化した名を指定します。</li><li>**住所情報：名（SHA256 ハッシュを適用）**：名をプレーンテキストで指定します。コネクタが値を SHA-256 でハッシュ化します。</li><li>**住所情報：姓（SHA256 でハッシュ化済み）**：先頭と末尾の空白を削除し、小文字に変換して SHA-256 でハッシュ化した姓を指定します。</li><li>**住所情報：姓（SHA256 ハッシュを適用）**：姓をプレーンテキストで指定します。コネクタが値を SHA-256 でハッシュ化します。</li><li>**住所情報：郵便番号**：ユーザーの住所の郵便番号を指定します。</li><li>**メールアドレス（SHA256 でハッシュ化済み）**：先頭と末尾の空白を削除し、小文字に変換して SHA-256 でハッシュ化したメールアドレスを指定します。値は、64 個の16進文字で構成される有効な SHA-256 16進文字列である必要があります。無効な値は、送信前にリクエストから削除されます。</li><li>**メールアドレス（SHA256 ハッシュを適用）**：メールアドレスをプレーンテキストで指定します。コネクタが値を SHA-256 でハッシュ化します。</li><li>**電話番号（SHA256 でハッシュ化済み）**：先頭と末尾の空白を削除し、SHA-256 でハッシュ化した電話番号を指定します。値は、64 個の16進文字で構成される有効な SHA-256 16進文字列である必要があります。無効な値は、送信前にリクエストから削除されます。有効なユーザー識別子が残っていない場合、アクションは検証エラーで失敗し、再試行されません。</li><li>**電話番号（SHA256 ハッシュを適用）**：電話番号をプレーンテキストで指定します。コネクタが値を SHA-256 でハッシュ化します。</li></ul> |

### カスタマーマッチリストに追加（Data Manager API）

#### API 情報

このコネクタは、次のベンダー API を使用します。

* API 名：Google Data Manager API
* API バージョン：v1
* API エンドポイント：`https://datamanager.googleapis.com`
* ドキュメント：[Google Data Manager API](https://developers.google.com/data-manager/api/reference/rest)

#### バッチ制限

このアクションは、ベンダーへの大量データ転送に対応するため、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに保持されます。

* リクエストの最大数：66,000
* 最も古いリクエストからの最大経過時間：1440 分
* リクエストの最大サイズ：50 MB

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| カスタマーマッチリスト | カスタマーマッチリストを選択します。Tealium コネクタを使用して作成されたリストのみ選択できます。カスタマーマッチリストを作成するには、[カスタマーマッチリストの作成](#create-customer-match-list)を参照してください。 |
| ユーザー識別子 | 照合するユーザー識別子。サポートされているフィールドについては、[ユーザー識別子](#user-identifiers)を参照してください。 |

##### 同意

デフォルトでは、コネクタは`adUserData`および`adPersonalization`の同意について`GRANTED`を送信します。同意していない訪問がリストに追加されないようにするには、オーディエンスロジックを使用します。同意していない訪問をリストから削除するには、**カスタマーマッチリストから削除**アクションを使用します。

### カスタマーマッチリストに追加（非推奨）


<blockquote>
このアクションは非推奨です。[カスタマーマッチリストに追加（Data Manager API）](#add-to-customer-match-list-data-manager-api)に移行してください。
</blockquote>


Tealium は Google DV 360 からリストの統計情報を直接取得します。そのため、このコネクタおよび [Google DV 360 カスタマーマッチコネクタインサイト](https://docs.tealium.com/connector-insights-google-dv360-customer-match/)では、マッチ数とコネクタリクエストの総量に差異が生じる場合があります。

このコネクタは、以下のベンダーAPIを使用します。

* API名：Google Ads API
* APIバージョン：v18
* APIエンドポイント：`https://googleads.googleapis.com/`
* ドキュメント：[Google Ads API](https://developers.google.com/google-ads/api/docs/start)

#### バッチ制限

このアクションは、ベンダーへの大量のデータ転送をサポートするために、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、以下のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに格納されます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：1440分
* リクエストの最大サイズ：50 MB

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| カスタマーマッチリスト | カスタマーマッチリストを選択します。Tealiumコネクタを使用して作成されたリストのみ利用できます。カスタマーマッチリストを作成するには、[カスタマーマッチリストの作成](#create-customer-match-list)を参照してください。 |

##### 同意

同意の動作については、[カスタマーマッチリストへの追加（Data Manager API）](#add-to-customer-match-list-data-manager-api)を参照してください。
