## API情報

このコネクタは以下のベンダーAPIを使用します：

* API名：楽天広告主取引API
* APIバージョン：v1
* APIエンドポイント：`https://api.linksynergy.com`
* ドキュメント：[楽天広告開発者ポータル](https://developers.rakutenadvertising.com/)

## 構成

コネクタマーケットプレイスにアクセスし、新しいコネクタを追加します。コネクタの追加方法については、[コネクタについて](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の構成を構成します：

* **楽天広告主ID**：あなたの楽天広告主ID。
* **クライアントID**：楽天から提供されるOAuthクライアントID。
* **クライアントシークレット**：楽天から提供されるOAuthクライアントシークレットキー。

このコネクタはOAuth 2.0クライアント資格情報認証を使用します。クライアントIDとクライアントシークレットを`https://api.linksynergy.com/token`でベアラートークンと交換します。ベアラートークンは4時間後に期限切れになります。

### 取引送信

#### 注文データ

| パラメータ | 説明 |
| --- | --- |
| 取引タイムスタンプ | (必須) ユーザーがオンラインで手数料対象アクションを完了したUTC時間。 |
| 注文ID | (必須) ユニークな注文ID、取引問い合わせへの返答には消費者向けが望ましい。 |
| 通貨 | (必須) 注文通貨コード。 |
| クリックID | リンクレス報告でない場合に必要。楽天からリダイレクトまたは最終着地ページで送信された34文字のID。 |
| 着地タイムスタンプ | リンクレス報告でない場合に必要。ユーザーがあなたのサイトに着地したUTC時間。このタイムスタンプは取引タイムスタンプよりも前でなければなりません。 |

#### 商品価格計算を無効にする

楽天は商品価格を価格 × 数量として送信することを要求します。コネクタはこの計算を自動的に行います。マップされた価格値を変更せずに送信するには、このチェックボックスを有効にします。

## 業種別オプションデータ
