## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：The Trade Desk CRM API
* APIバージョン：v3
* APIエンドポイント：`https://api.thetradedesk.com/v3/crmdata/`
* ドキュメント：[The Trade Desk CRM API](https://partner.thetradedesk.com/v3/portal/data/doc/DataIntegrateCRMData)

## バッチ制限

このコネクタは、ベンダーへの大量のデータ転送に対応するため、リクエストをバッチ処理します。次の3つのしきい値のいずれかに達するまで、リクエストはキューに格納されます。

* リクエストの最大数：10,000
* 最も古いリクエストからの最大経過時間：720分
* リクエストの最大サイズ：100 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を行います。
* **広告主ID**
  * （必須）The Trade Deskの広告主ID。
* **APIトークン**
  * （必須）有効期間の長いAPIトークン。
  * トークンを生成するには、The Trade Desk Partner Portalの**User Profile**メニューにある**Manage API Tokens**セクションに移動します。
  * 詳細については、[The Trade Desk：APIトークン認証](https://partner.thetradedesk.com/v3/portal/api/doc/Authentication)を参照してください。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| ターゲティングデータをアップロード | ✓ | ✓ |
| コンバージョンデータをアップロード | ✓ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### ターゲティングデータをアップロード

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| ターゲティングセグメント | リストからThe Trade Deskのターゲティングセグメントを選択します。ターゲティングセグメントを作成するには、**ターゲティングセグメントを作成**をクリックします。 |

#### ユーザー識別子

任意のパラメータ：

| **パラメータ** | **説明** |
| --- | --- |
| メールアドレス | プレーンテキストのメールアドレスを指定します。 |
| メールアドレス（SHA256でハッシュ化済み） | 前後の空白を削除し、小文字に変換して、SHA256でハッシュ化したメールアドレスを指定します。コネクタは、The Trade Deskに送信する前に、未加工のバイトをBase64でエンコードします。 |
| 電話番号 | プレーンテキストの電話番号を指定します。EUセグメントには電話番号をアップロードできないことに注意してください。 |
| 電話番号（SHA256でハッシュ化済み） | 前後の空白を削除し、SHA256でハッシュ化した電話番号を指定します。コネクタは、The Trade Deskに送信する前に、未加工のバイトをBase64でエンコードします。EUセグメントには電話番号をアップロードできないことに注意してください。 |

### コンバージョンデータをアップロード

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| コンバージョンセグメント | The Trade Desk UIでTracking Tag IDとして表示されるコンバージョンセグメントIDを入力します。<ul><li>新しいコンバージョンセグメントを作成するには、**コンバージョンセグメントを作成**をクリックします。</li><li>作成後、セグメントIDが**コンバージョンセグメント**フィールドに表示されます。</li><li>アップロードする前に、The Trade Desk UIでコンバージョンセグメントをキャンペーンに関連付ける必要があります。この手順が完了するまで、アップロードしたデータをキャンペーンに関連付けることはできません。</li></ul> |

#### ユーザー識別子

任意のパラメータ：

| **パラメータ** | **説明** |
| --- | --- |
| メールアドレス | プレーンテキストのメールアドレスを指定します。 |
| メールアドレス（SHA256でハッシュ化済み） | 前後の空白を削除し、小文字に変換して、SHA256でハッシュ化したメールアドレスを指定します。コネクタは、The Trade Deskに送信する前に、未加工のバイトをBase64でエンコードします。 |
| 電話番号 | プレーンテキストの電話番号を指定します。EUセグメントには電話番号をアップロードできないことに注意してください。 |
| 電話番号（SHA256でハッシュ化済み） | 前後の空白を削除し、SHA256でハッシュ化した電話番号を指定します。コネクタは、The Trade Deskに送信する前に、未加工のバイトをBase64でエンコードします。EUセグメントには電話番号をアップロードできないことに注意してください。 |

#### コンバージョンデータ

任意のパラメータ：

| **パラメータ** | **説明** |
| --- | --- |
| タイムスタンプ | コンバージョンのタイムスタンプ。エポックタイムスタンプを含むTealiumの日付属性をマッピングします。コネクタは値をUTCに変換し、`yyyy-MM-dd'T'HH:mm:ss.SSS'Z'`形式で送信します。マッピングされていない場合、コネクタは現在のタイムスタンプを送信します。 |
| 値 | 小数点以下2桁までのコンバージョン値。 |
| 通貨 | 値の金額に使用する通貨。例：`USD`。 |
| 国 | コンバージョンが発生した国の正式名称。 |
| 地域 | **国**フィールドがUnited Statesに構成されている場合は必須です。コンバージョンが発生した地域の正式名称またはコード。例：`NY`または`New York`。 |
| 都市圏 | コンバージョンが発生した大都市圏の数値ジオターゲティングコード。 |
| 市区町村 | コンバージョンが発生した市区町村。 |
| 注文ID | トランザクションまたはコンバージョンイベントの一意の識別子。最大長は64文字です。 |
| プライバシータイプ | ユーザーの地理的位置に基づいて、適用されるプライバシー規制（`GDPR`、`GPP`）を指定します。 |
| 適用対象 | プライバシータイププロパティで指定された値が適用対象かどうかを示します。 |
| 同意文字列 | プライバシー規制が適用される場合のユーザーの同意（`TCF`文字列、`GPP`文字列）。 |
