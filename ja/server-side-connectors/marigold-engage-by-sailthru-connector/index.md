## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の構成を構成します。

* **APIキー**
  * Sailthruアカウントの機能にアクセスするためのAPIキー。

* **共有シークレット**
  * Sailthruアカウントの共有シークレット。

## アクション構成 - パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### アクション - ユーザーをリストに追加（バッチジョブ）

##### バッチ制限

このアクションでは、ベンダーへの大量データ転送に対応するため、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。以下のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数：10000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：10 MB

#### パラメータ

| **パラメータ**             | **説明**                                                                     |
| ------------------------- | ----------------------------------------------------------------------------------- |
| Sailthruリスト             | <ul><li>ユーザーを追加する1つ以上のリストを選択します。</li></ul>                          |
| ユーザーのFacebook ID          | <ul><li>ユーザーのFacebook IDにマッピングします</li></ul>                                           |
| Sailthru Horizon Cookie   | <ul><li>Sailthru Horizon Cookieにマッピングします</li></ul>                                    |
| ユーザーのSMS                  | <ul><li>ユーザーのSMSにマッピングします</li></ul>                                                   |
| ユーザー指定識別子 | <ul><li>ユーザー指定識別子にマッピングします</li></ul>                                  |
| ユーザーのメールアドレス                | <ul><li>ユーザーのメールアドレスにマッピングします</li></ul>                                                 |
| ユーザーのTwitter名         | <ul><li>ユーザーのX名にマッピングします</li></ul>                                          |
| Sailthru識別子       | <ul><li>Sailthru識別子にマッピングします</li></ul>                                        |
| ユーザーのカスタム変数     | <ul><li>ユーザーにカスタム変数を構成します。</li></ul>                                 |
| オプトアウト                   | <ul><li>次のいずれかである必要があります：`all`、`basic`、`blast`、`none`</li></ul> |
| 登録日               | <ul><li>ユーザーの登録日。</li></ul>                                                 |
