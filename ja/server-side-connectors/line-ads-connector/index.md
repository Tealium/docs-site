## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：LINE Ads
* APIバージョン：v3
* APIエンドポイント：`https://ads.line.me/api/v3/adaccounts`
* ドキュメント：[LINE API](https://ads.line.me/public-docs/v3/3.11.1/data-general-partner)

## バッチ処理の制限

このコネクタは、ベンダーへの大量データ転送をサポートするため、リクエストをバッチ処理します。次のいずれかのしきい値に達するまで、リクエストはキューに保持されます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：10 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。

* **アクセスキー**
  * （必須）LINE広告マネージャーUIのグループ構成ページからアクセスキーを取得します。
* **シークレットキー**
  * （必須）LINE広告マネージャーUIのグループ構成ページからシークレットキーを取得します。
* **広告アカウントID**
  * （必須）LINE AdsのアカウントIDです。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| カスタムオーディエンスへの訪問の追加 | ✓ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### カスタムオーディエンスへの訪問の追加

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| LINEオーディエンス | LINEオーディエンスを選択します。ドロップダウンにオーディエンスが表示されない場合は、オーディエンスIDを手動で入力し、**LINEオーディエンスタイプ**を構成します。 |

#### ユーザー識別子

| **パラメータ** | **説明** |
| --- | --- |
| メールアドレス（SHA256ハッシュを適用） | プレーンテキストのメールアドレスまたはアドレスの配列を指定します。コネクタは空白を削除し、小文字に変換してから、SHA256ハッシュを使用してこの値をハッシュ化します。 |
| メールアドレス（SHA256でハッシュ化済み） | 空白の削除、小文字への変換、およびSHA256によるハッシュ化がすでに行われたメールアドレスまたはアドレスの配列を指定します。 |
| 電話番号（SHA256ハッシュを適用） | プレーンテキストの電話番号または電話番号の配列を指定します。コネクタは空白を削除し、SHA256ハッシュを使用してこの値をハッシュ化します。 |
| 電話番号（SHA256でハッシュ化済み） | 空白の削除とSHA256によるハッシュ化がすでに行われた電話番号または電話番号の配列を指定します。 |
| LINEオーディエンスタイプ | LINEオーディエンスタイプを選択します。**LINEオーディエンス**フィールドにオーディエンスIDを手動で入力した場合にのみ必須です。指定できる値は`HASHED_EMAIL`と`HASHED_PHONE_NUMBER`です。 |
