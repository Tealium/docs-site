## 必要条件

* コンバージョンイベントを送信する権限を持つ Pinterest 広告アカウント。
* `user_data` で以下の有効なユーザーIDのいずれかを送信する能力:
    * Email（既に SHA256 ハッシュ化済み）(`em`)。
    * Appleの広告識別子（既に SHA256 ハッシュ化済み）または Google 広告ID（既に SHA256 ハッシュ化済み）(`hashed_maids`)。
    * クライアントIPアドレスとクライアントユーザーエージェント（`client_ip_address` と `client_user_agent`）。
    * アプリID（該当する場合）。 
<blockquote>
Pinterestは少なくとも1つの有効なユーザーIDが必要です。PII制限がある組織は、この統合を構成する前に承認を得る必要があります。
</blockquote>

* オフラインイベントの場合:
    * コネクタ構成で **イベントアクションソース** を `Offline` に構成する必要があります。
    * オフラインイベントには、必要なすべてのイベントパラメータを含める必要があります。詳細については、[Pinterest: サーバーイベントパラメータの形式](https://developers.pinterest.com/docs/track-conversions/track-conversions-in-the-api/#format-server-event-parameters)を参照してください。

## API情報

このコネクタは以下のベンダーAPIを使用します:

* API名: Pinterest API
* APIバージョン: v5
* APIエンドポイント: `https://api.pinterest.com/`
* ベンダー文書: [Pinterest: コンバージョンガイド](https://developers.pinterest.com/docs/conversions/conversion-management/)

## バッチ制限

このコネクタは、ベンダーへの大量データ転送をサポートするためにバッチリクエストを使用します。詳細については、[Batched Actions](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかの閾値に達するか、プロファイルが公開されるまでキューに入れられます:

* 最大リクエスト数: 1000
* 最古のリクエストからの最大時間: 10分
* リクエストの最大サイズ: 2 MB

## 動作方法

Pinterest API for Conversionsを使用すると、広告主はPinterestタグを使用せずにPinterestにコンバージョンイベントを送信できます。コンバージョンをPinterestキャンペーンにマッピングすることで、キャンペーンの効果とコンバージョンを推進するアクションの正確なビューが得られます。このアプローチは、ターゲティングの最適化、透明性の向上、およびレポートと分析の改善を促進します。

Pinterest API for Conversionsは、ウェブ、アプリ内、またはオフラインのコンバージョンを受け取ることができます。イベント発生から1時間以内に受信したイベントは、ウェブまたはアプリイベントとして報告されます。その時間枠の外で受信したイベントは、オフラインイベントとして分類されます。

Pinterest ConversionsコネクタとPinterestタグを併用することで、可視性を最大化し、コンバージョンを追跡することをお勧めします。Pinterest Conversionsコネクタは単独で利用可能ですが、両方を併用することで最良の結果が得られます。

追跡可能なイベントには以下が含まれます:

* **カートに追加**: アイテムがショッピングカートに追加されます。
* **チェックアウト**: トランザクションが完了します。
* **カスタム**: カスタムイベントを追跡します。このイベント名を使用して、コンバージョンレポートに含めたい特別なイベントを追跡します。
* **リード**: 製品またはサービスへの関心。
* **ページ訪問**: 製品ページや記事ページなどの主要ページの閲覧。
* **検索**: あなたのウェブサイトでの検索。
* **サインアップ**: あなたの製品やサービスへのサインアップ。
* **カテゴリ表示**: カテゴリページの閲覧。
* **ビデオ視聴**: ビデオの視聴。
* **ユーザー定義イベント**: オーディエンスターゲティングのために定義した追加のイベント。変換レポートで利用可能なユニークなイベントはありません。

## 重複排除

冗長な実装が存在する場合（例: Pinterest API for Conversionsと[Pinterest tag](https://docs.tealium.com/pinterest-tag/)）、重複排除が必要です。重複排除を使用することで、コネクタまたはタグソリューションを独立して使用する場合よりも多くのコンバージョンが帰属されることが期待されます。

[Pinterest tag](https://docs.tealium.com/pinterest-tag/)とPinterest API for Conversionsは、重複排除のためにイベントIDを使用します。複数のソースを使用してコンバージョンデータを追跡する場合、この値を含めることを確認してください。イベントIDを見つけるには、次の手順を完了してください:

1. [Pinterestビジネスアカウント](http://pinterest.com/business/create/)にログインします。
1. **広告 > レポート**に移動します。
1. テーブルの右上にあるメニューアイコンをクリックし、**パフォーマンス**を選択します。

サイトに追加したイベントコードに応じて、選択した期間中に発生した回数とともにテーブル全体にリストされます。

次の命名規則を使用してイベント属性を探します:

```none
pinterest_event_id_{PINTEREST_EVENT}_{TAG_UID}
```

例: `pinterest_event_id_Checkout_32`

各タイプのイベントIDに対して別のアクションを使用します。イベント固有のイベントID属性をイベントIDにマッピングし、一致するイベント名をイベント名にマッピングします。例:

| **Tealium 属性/値** | Pinterest パラメータ |
|---|---|
| `pinterest_event_id_Checkout_32` | イベントID |
| `Checkout` (ドロップダウン選択) | イベント名 |

詳細については、[Pinterest タグ構成ガイド](https://docs.tealium.com/pinterest-tag/)を参照してください。

### 重複排除の確認

Pinterestは重複排除されたコンバージョン指標を表示しません。代わりに、以下の項目を検証することで重複排除を確認します:

* `event_id`がウェブとAPIのペイロードの両方に存在します。
* 両バージョンをトリガーした後、レポートでコンバージョンが1回だけ表示されます。

Pinterest広告マネージャーで`event_id`を表示するには、次の手順を使用します:

1. **広告マネージャー > コンバージョン > イベント**に移動します。
1. 広告アカウントを選択します。
1. イベント（例: チェックアウト）を選択します。
1. **イベント診断**を開きます。
1. イベントペイロードを展開するためにクリックします。
1. 次のことを確認します:
    * `event_source` = `web` または `api`
    * `event_id`が一致します
    * **ユーザーデータステータス** = `accepted`

## 検証

コネクタアクションを検証するには、次のようにテストイベントコードを使用します:

1. **Send Conversion Event** アクションで **Testing Mode** を選択します。
1. テストイベントを送信します。
1. Pinterestで次の手順を使用します:
    * **Conversions > Events > Test Events**に移動します。
    * 受領とペイロードの整合性を確認します。

## 構成

コネクタマーケットプレースに移動して新しいコネクタを追加します。コネクタを追加する一般的な手順については、[About Connectors](https://docs.tealium.com/about-connectors/)の記事を参照してください。


<blockquote>
このコネクタを追加すると、ベンダーのデータプラットフォームポリシーを受け入れるように求められます。
</blockquote>


コネクタを追加した後、次の構成を構成します:

* **EULA Agreement**: (必須) Pinterestのデータプラットフォームポリシーを受け入れるためのチェックボックスを選択します。
* **Access Token**: (必須) Pinterest広告マネージャーを通じて生成されたアクセストークン。詳細については、[Pinterest: コンバージョンガイド](https://developers.pinterest.com/docs/conversions/conversion-management/#Authenticating%20for%20the%20Conversion%20Tracking%20endpoint)を参照してください。
* **Ad Account ID**: (必須) 広告アカウントの一意の識別子。Pinterestアカウントにログインし、広告主アカウントを所有するPinterestアカウントに移動して **Ads > Overview** にアクセスします。**Ad Account ID** はURLパスに表示されます。例: `ads.pinterest.com/advertiser/{ad_account_id}/...` .

構成が完了したら **Done** をクリックします。

### オフラインコンバージョン

オフラインイベントを通じて、ウェブサイトやアプリの外で発生する広告の影響を測定できます。これには、物理的な小売店での購入、相互作用、およびコンバージョンが含まれます。オフラインイベントとコンバージョンを処理するために、必要なパラメータを含めるようにPinterest Conversionsコネクタを構成します。
#### 構成手順

Pinterest Conversionsコネクターを使用してオフラインイベントを送信するには：

1. **アクション**タブで、新しい**送信コンバージョンイベント**アクションを追加します。
1. **イベントアクションソース**パラメータを`Offline`にマッピングします。
1. 必要なパラメータをマッピングし、イベントタイプに必要に応じてオプションのパラメータを含めます。
    * Pinterestは、オフラインイベントの必須イベントIDパラメータにトランザクションID、注文ID、またはTealium Randomをマッピングすることを推奨しています。
1. Pinterest広告マネージャーで確認します。

#### ユーザーデータ

データマッピングは以下の要件を満たす必要があります：

* 配列型属性をマップして複数の値を追加します。
* 単一値属性をマップして単一の値を追加します。単一値属性は**クライアントIPアドレス**および**クライアントユーザーエージェント**フィールドにのみマップする必要があります。

以下のパラメータが必要です：

| **パラメータ** | **説明** |
| --- | --- |
| Email（既にSHA256ハッシュ化済み） | 空白トリム、小文字化、SHA256ハッシュ化が既に行われたメールアドレスを提供してください。 |
| Email（SHA256ハッシュを適用） | プレーンテキストのメールアドレスを提供し、コネクタがこの値を空白トリム、小文字化し、SHA256ハッシュを使用してハッシュ化します。 |
| Appleの広告識別子（既にSHA256ハッシュ化済み） | 空白トリムおよびSHA256ハッシュ化が既に行われたAppleの広告識別子を提供してください。 |
| Appleの広告識別子（SHA256ハッシュを適用） | プレーンテキストのAppleの広告識別子を提供し、コネクタがこの値を空白トリムし、SHA256ハッシュを使用してハッシュ化します。 |
| Google広告ID（既にSHA256ハッシュ化済み） | 空白トリムおよびSHA256ハッシュ化が既に行われたGoogle広告IDを提供してください。 |

| クライアントIPアドレス | ユーザーのIPアドレスで、IPv4またはIPv6形式のいずれかです。 |
| クライアントユーザーエージェント | ユーザーのウェブブラウザのユーザーエージェント文字列です。 |
| 電話番号（既にSHA256ハッシュ化済み） | 数字のみを含む電話番号で、空白トリムおよびSHA256ハッシュ化が既に行われています。ハッシュ化する前に先頭のゼロを削除してください。 |
| 電話番号（SHA256ハッシュを適用） | プレーンテキストの電話番号を提供し、コネクタがすべての非数字文字と先頭のゼロを削除し、空白トリムし、SHA256ハッシュを使用してこの値をハッシュ化します。 |
| 性別（既にSHA256ハッシュ化済み） | 空白トリム、小文字化、SHA256ハッシュ化が既に行われた性別を提供してください。 |
| 性別（SHA256ハッシュを適用） | プレーンテキストの性別を提供し、コネクタがこの値を空白トリム、小文字化し、SHA256ハッシュを使用してハッシュ化します。 |
| 生年月日（既にSHA256ハッシュ化済み） | 空白トリム、小文字化、SHA256ハッシュ化が既に行われた生年月日を提供してください。 |
| 生年月日（SHA256ハッシュを適用） | プレーンテキストの生年月日を提供し、コネクタがこの値を空白トリム、小文字化し、SHA256ハッシュを使用してハッシュ化します。 |
| 名（既にSHA256ハッシュ化済み） | 空白トリム、小文字化、SHA256ハッシュ化が既に行われた名前を提供してください。 |
| 名（SHA256ハッシュを適用） | プレーンテキストの名前を提供し、コネクタがこの値を空白トリム、小文字化し、SHA256ハッシュを使用してハッシュ化します。 |
| 姓（既にSHA256ハッシュ化済み） | 空白トリム、小文字化、SHA256ハッシュ化が既に行われた姓を提供してください。 |
| 姓（SHA256ハッシュを適用） | プレーンテキストの姓を提供し、コネクタがこの値を空白トリム、小文字化し、SHA256ハッシュを使用してハッシュ化します。 |

| 郵便番号（SHA256ハッシュを適用） | プレーンテキストの郵便番号を提供し、コネクタがすべての非数字文字を削除し、空白トリムし、SHA256ハッシュを使用してこの値をハッシュ化します。 |
| 国コード（既にSHA256ハッシュ化済み） | 空白トリム、小文字化、SHA256ハッシュ化が既に行われた国コードを提供してください。 |
| 国コード（SHA256ハッシュを適用） | プレーンテキストの国コードを提供し、コネクタがこの値を空白トリム、小文字化し、SHA256ハッシュを使用してハッシュ化します。 |
| 外部ID（既にSHA256ハッシュ化済み） | 空白トリムおよびSHA256ハッシュ化が既に行われた1つ以上の外部IDを提供してください。複数の外部IDがある場合は、配列としてフォーマットしてください。詳細については、[Pinterest: 外部IDとは何ですか？](https://developers.pinterest.com/docs/api-features/conversion-best-practices/#what-is-an-external-id)を参照してください。 |

| **パラメータ** | **説明** |

| 通貨 | ISO 4217通貨コード。提供されない場合、Pinterestはアカウント作成時に構成された広告主の通貨を使用します。 |
| 価値 | イベントの総価値。コネクタは文字列値を受け取り、それを[倍精度数](https://en.wikipedia.org/wiki/Double-precision_floating-point_format)に解析します。複数のアイテムがあるチェックアウトイベントの場合、すべてのアイテムの合計価格を使用します。 |
| コンテンツID | 製品IDのリスト。 |
| アイテム数 | イベントの製品の総数。たとえば、チェックアウトイベントで購入されたアイテムの総数。 |
| 注文ID | 注文ID。 |
| 検索文字列 | ユーザーのコンバージョンイベントに関連する検索文字列。 |
| オプトアウトタイプ | 個人情報の共有をオプトアウトするさまざまなプライバシー権法のフラグ。値はコンマで区切られる必要があります。配列型属性はマップされ、コンマ区切りの文字列に変換されます。 |

#### コンテンツデータ

* コンバージョンに複数のアイテムを追加するために配列型属性を提供します。配列型属性は同じ長さでなければなりません。
* 単一値属性をパラメータにマップする場合、その値はコンバージョンの配列内のすべてのアイテムに適用されます。

| **パラメータ** | **説明** |
| --- | --- |
| アイテム価格 | コンバージョン内の個々のアイテムの価格。コネクタは文字列値を受け取り、それを[倍精度数](https://en.wikipedia.org/wiki/Double-precision_floating-point_format)に解析します。複数のアイテムがあるチェックアウトイベントの場合、各アイテムの価格を提供します。 |
| 数量 | 製品の数量。 |
| ID | 製品のID。**AddToCart**および**Checkout**イベントに推奨されます。 |
| アイテム名 | 製品の名前。 |
| アイテムカテゴリ | 製品のカテゴリ。 |
| アイテムブランド | 製品のブランド。 |

## コネクタのインサイト

Pinterest コンバージョンコネクタは、Tealiumで直接 Pinterest コンバージョンイベント品質スコア（EQS）データを表示するコネクタインサイトをサポートしています。詳細については、[コネクタインサイト: Pinterest コンバージョン](https://docs.tealium.com/connector-insights-pinterest-conversions/)を参照してください。
