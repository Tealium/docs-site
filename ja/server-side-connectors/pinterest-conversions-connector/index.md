## 要件

* コンバージョンイベントを送信する権限を持つPinterest広告アカウント。
* `user_data`で、次のいずれかの有効なユーザーIDを送信できること。
    * メールアドレス（SHA256でハッシュ化済み）（`em`）。
    * Appleの広告主向け識別子（SHA256でハッシュ化済み）またはGoogle広告ID（SHA256でハッシュ化済み）（`hashed_maids`）。
    * クライアントIPアドレスおよびクライアントユーザーエージェント（`client_ip_address`および`client_user_agent`）。
    * アプリID（該当する場合）。
<blockquote>
Pinterestでは、照合のために少なくとも1つの有効なユーザーIDが必要です。PIIに関する制限がある組織では、この統合を構成する前に承認を得る必要があります。
</blockquote>

* すべてのオフラインイベントについて：
    * コネクタ構成で、**Event Action Source**を`Offline`に構成する必要があります。
    * オフラインイベントには、必須のイベントパラメータをすべて含める必要があります。詳細については、[Pinterest：サーバーイベントパラメータの形式](https://developers.pinterest.com/docs/track-conversions/track-conversions-in-the-api/#format-server-event-parameters)を参照してください。

## API情報

このコネクタでは、次のベンダーAPIを使用します。

* API名：Pinterest API
* APIバージョン：v5
* APIエンドポイント：`https://api.pinterest.com/`
* ベンダーのドキュメント：[Pinterest：コンバージョンガイド](https://developers.pinterest.com/docs/conversions/conversion-management/)

## バッチ制限

このコネクタでは、ベンダーへの大量データ転送をサポートするために、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに保持されます。

* リクエストの最大数：1000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：2 MB

## 仕組み

Pinterest API for Conversionsを使用すると、広告主はPinterestタグを使用せずにコンバージョンイベントをPinterestへ送信できます。コンバージョンをPinterestキャンペーンにマッピングすることで、コンバージョンの可視性が向上し、キャンペーンの効果とコンバージョンにつながるアクションをより正確に把握できます。この方法により、ターゲティングが最適化され、透明性が高まり、レポートと分析が改善されます。

Pinterest API for Conversionsは、Web、アプリ内、またはオフラインのコンバージョンを受信できます。イベント発生から1時間以内に受信したイベントは、Webイベントまたはアプリイベントとしてレポートされます。この時間枠を過ぎて受信したイベントは、オフラインイベントとして分類されます。

可視性を最大限に高めてコンバージョンを追跡するために、Pinterest ConversionsコネクタとPinterestタグを併用することをお勧めします。Pinterest Conversionsコネクタは単独のソリューションとして利用できますが、Pinterest ConversionsコネクタとPinterestタグを併用することで最良の結果が得られます。

追跡できるイベントは次のとおりです。

* **カートに追加**：商品がショッピングカートに追加された。
* **チェックアウト**：取引が完了した。
* **カスタム**：カスタムイベントを追跡します。コンバージョンレポートに含める特別なイベントを追跡するには、このイベント名を使用します。
* **リード**：製品またはサービスへの関心。
* **ページ訪問**：製品ページや記事ページなど、主要ページの閲覧。
* **検索**：Webサイト上での検索。
* **サインアップ**：製品またはサービスへのサインアップ。
* **カテゴリ表示**：カテゴリページの閲覧。
* **動画視聴**：動画の視聴。
* **ユーザー定義イベント**：オーディエンスターゲティングを目的として定義した追加イベントを登録します。固有のイベントはコンバージョンレポートには使用できません。

## 重複排除

重複する実装が存在する場合（たとえば、Pinterest API for Conversionsと[Pinterestタグ](https://docs.tealium.com/pinterest-tag/)）、1つのイベントが両方のソリューションから送信された際に二重にカウントされるのを防ぐため、重複排除が必要です。重複排除を使用すると、コネクタまたはタグのソリューションを単独で使用する場合よりも多くのコンバージョンがアトリビューションされることが期待できます。

[Pinterestタグ](https://docs.tealium.com/pinterest-tag/)とPinterest API for Conversionsでは、重複排除にイベントIDを使用します。複数のソースを使用してコンバージョンデータを追跡する場合は、この値が含まれていることを確認してください。イベントIDを確認するには、次の手順を実行します。

1. [Pinterestビジネスアカウント](http://pinterest.com/business/create/)にログインします。
1. **Ads > Reporting**に移動します。
1. テーブル上部の右上にあるメニューアイコンをクリックし、**Performance**を選択します。

サイトに追加したイベントコードに応じて、選択した期間内の発生回数とともにテーブル全体に表示されます。

次の命名規則に従うイベント属性を探します。

```none
pinterest_event_id_{PINTEREST_EVENT}_{TAG_UID}
```

例：`pinterest_event_id_Checkout_32`

イベントIDのタイプごとに個別のアクションを使用します。イベント固有のイベントID属性をEvent IDにマッピングし、それに対応するイベント名をEvent Nameにマッピングします。例：

| **Tealiumの属性／値** | Pinterestパラメータ |
|---|---|
| `pinterest_event_id_Checkout_32` | Event ID |
| `Checkout`（ドロップダウンで選択） | Event Name |

詳細については、[Pinterestタグ構成ガイド](https://docs.tealium.com/pinterest-tag/)を参照してください。

### 重複排除の確認

Pinterestには、重複排除済みコンバージョンの指標は表示されません。代わりに、次の項目を検証して重複排除を確認します。

* `event_id`がWebとAPIの両方のペイロードに存在する。
* 両方のバージョンをトリガーした後、レポートにコンバージョンが1回だけ表示される。

Pinterest Ads Managerで`event_id`を表示するには、次の手順を実行します。

1. **Ads Manager > Conversions > Events**に移動します。
1. 広告アカウントを選択します。
1. イベント（たとえば、Checkout）を選択します。
1. **Event Diagnostics**を開きます。
1. イベントペイロードをクリックして展開します。
1. 次の項目を確認します。
    * `event_source` = `web`または`api`
    * `event_id`が一致している
    * **User data status** = `accepted`

## 検証

コネクタアクションを検証するには、次のようにテストイベントコードを使用します。

1. **Send Conversion Event**アクションで、**Testing Mode**を選択します。
1. テストイベントを送信します。
1. Pinterestで、次の手順を実行します。
    * **Conversions > Events > Test Events**に移動します。
    * イベントが受信され、ペイロードが完全であることを確認します。

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。


<blockquote>
このコネクタを追加すると、ベンダーのデータプラットフォームポリシーへの同意を求められます。
</blockquote>


コネクタを追加した後、次の構成を構成します。

* **EULA Agreement**：（必須）チェックボックスをオンにして、Pinterestのデータプラットフォームポリシーに同意します。
* **Access Token**：（必須）Pinterest Ads Managerを通じて生成されたアクセストークン。詳細については、[Pinterest：コンバージョンガイド](https://developers.pinterest.com/docs/conversions/conversion-management/#Authenticating%20for%20the%20Conversion%20Tracking%20endpoint)を参照してください。
* **Ad Account ID**：（必須）広告アカウントの一意の識別子。Pinterestで**Ad Account ID**を確認するには、広告主アカウントを所有するPinterestアカウントにログインし、**Ads > Overview**に移動します。**Ad Account ID**はURLパスに表示されます。例：`ads.pinterest.com/advertiser/{ad_account_id}/...`

コネクタの構成が完了したら、**Done**をクリックします。

### オフラインコンバージョン

オフラインイベントを使用すると、実店舗など、Webサイトやアプリの外部で発生した購入、インタラクション、コンバージョンに広告が与えた影響を測定できます。Pinterest Conversionsコネクタを通じてオフラインイベントとコンバージョンを処理するには、必須パラメータを含めるようにコネクタを構成します。
#### 構成手順

オフラインイベントを送信するように Pinterest Conversions コネクタを構成するには、次の手順を実行します。

1. **Actions** タブで、新しい **Send Conversion Event** アクションを追加します。
1. **Event Action Source** パラメータを `Offline` にマッピングします。
1. 必須パラメータをマッピングし、イベントタイプに応じて必要なオプションパラメータを含めます。
    * Pinterest では、オフラインイベントの必須の Event ID パラメータに、トランザクション ID、注文 ID、または Tealium Random をマッピングすることを推奨しています。
1. Pinterest Ads Manager で確認します。

## アクション

| **アクション名** | **訪問プロファイル** | **イベントデータ** |
| --- | --- | --- |
| コンバージョンイベントを送信 | ✓ | ✓ |

**Continue** をクリックして、コネクタアクションを構成します。アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

以下のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### コンバージョンイベントを送信

| **パラメータ** | **説明** |
| --- | --- |
| Event Name | （必須）記録するユーザーイベントのタイプ。<br>注：カスタムイベントタイプのイベントは、レポートでは使用できません。<br>**Add to Cart** - 商品がショッピングカートに追加されます。<br>**Add to Wishlist** - 商品がウィッシュリストに追加されます。<br>**Checkout** - 完了したトランザクション。<br>**Custom** - コンバージョンレポートに含める特別なイベントを追跡するには、このイベント名を使用します。<br>**Initiate Checkout** - チェックアウトプロセスが開始されます。たとえば、ユーザーがチェックアウトボタンをクリックした場合です。<br>**Lead** - 製品またはサービスへの関心。<br>**Page Visit** - 製品ページや記事ページなど、主要ページの閲覧。<br>**Search** - Web サイト上での検索。<br>**Signup** - 製品またはサービスへの登録。<br>**Subscribe** - コンテンツストリーミングや月次メールなどのサービス、または毎月の配送などの製品提供をユーザーが定期購読します。<br>**View Category** - カテゴリページの閲覧。<br>**View Content** - 製品ページやランディングページなど、ビジネスに関連する Web ページにユーザーがアクセスします。<br>**Watch Video** - 動画の視聴。 |
| Event Action Source | （必須）コンバージョンイベントが発生した場所を示すソース。<br>**App Android** - Android デバイスのモバイルアプリ内イベントを通じて発生。<br>**App iOS** - iOS デバイスのモバイルアプリ内イベントを通じて発生。<br>**Offline** - オフラインで発生したイベント。<br>**Web** - デスクトップおよびモバイルの Web ブラウザを通じて発生。 |

#### コンバージョンイベントのパラメータ

| **パラメータ** | **説明** |
| --- | --- |
| Event ID | （必須）イベントの一意の ID を含む文字列値。この ID は、Pinterest API for Conversions と Pinterest Tag から取り込まれたイベントの重複排除に使用できます。 |
| Ad Account ID Override | この構成は、コネクタ構成セクションで使用される Pinterest の **Ad Account ID** を上書きします。**Ad Account ID Override** またはコネクタ構成セクションの **Ad Account ID** のいずれかを指定する必要があります。 |
| Event Time | ユーザーのコンバージョンイベントが発生した時刻を示す、秒単位の Unix タイムスタンプ（UTC）。イベント時刻を、Pinterest がリクエストを受信した時刻より後にすることはできません。このフィールドがマッピングされていない場合、現在のタイムスタンプで初期化されます。 |
| Event Source URL | Web コンバージョンイベントの URL。 |
| Opt Out | **Event Action Source** が **Web** または **Offline** の場合、このパラメータは、ユーザーが Web コンバージョンイベントのトラッキングをオプトアウトしているかどうかを定義します。**Event Action Source** が **App Android** または **App iOS** の場合、ユーザーが iOS デバイスで広告トラッキング制限を有効にしているか、Android デバイスで広告のパーソナライズをオプトアウトしているかどうかを定義します。 |
| Event Name Override | **Event Name** が **Custom** に構成されている場合、このフィールドにカスタムイベントの名前を指定します。 |
#### ユーザーデータ

データマッピングは、次の要件を満たす必要があります。

* 複数の値を追加するには、配列型属性をマッピングします。
* 単一の値を追加するには、単一値属性をマッピングします。**クライアントIPアドレス**および**クライアントユーザーエージェント**フィールドには、単一値属性のみをマッピングしてください。

次のパラメータが必要です。

| **パラメータ** | **説明** |
| --- | --- |
| メールアドレス（SHA256でハッシュ化済み） | 空白の除去、小文字への変換、およびSHA256によるハッシュ化がすでに行われたメールアドレスを指定します。 |
| メールアドレス（SHA256ハッシュを適用） | プレーンテキストのメールアドレスを指定します。コネクタによって空白が除去され、小文字に変換された後、SHA256でハッシュ化されます。 |
| Appleの広告識別子（SHA256でハッシュ化済み） | 空白の除去およびSHA256によるハッシュ化がすでに行われたAppleの広告識別子を指定します。 |
| Appleの広告識別子（SHA256ハッシュを適用） | プレーンテキストのAppleの広告識別子を指定します。コネクタによって空白が除去された後、SHA256でハッシュ化されます。 |
| Google広告ID（SHA256でハッシュ化済み） | 空白の除去およびSHA256によるハッシュ化がすでに行われたGoogle広告IDを指定します。 |
| Google広告ID（SHA256ハッシュを適用） | プレーンテキストのGoogle広告IDを指定します。コネクタによって空白が除去された後、SHA256でハッシュ化されます。 |
| クライアントIPアドレス | ユーザーのIPアドレス。IPv4またはIPv6形式で指定できます。 |
| クライアントユーザーエージェント | ユーザーのWebブラウザのユーザーエージェント文字列。 |
| 電話番号（SHA256でハッシュ化済み） | 数字のみで構成され、空白の除去およびSHA256によるハッシュ化がすでに行われた電話番号を指定します。ハッシュ化する前に先頭のゼロを削除してください。 |
| 電話番号（SHA256ハッシュを適用） | プレーンテキストの電話番号を指定します。コネクタによって数字以外のすべての文字と先頭のゼロが削除され、空白が除去された後、SHA256でハッシュ化されます。 |
| 性別（SHA256でハッシュ化済み） | 空白の除去、小文字への変換、およびSHA256によるハッシュ化がすでに行われた性別を指定します。 |
| 性別（SHA256ハッシュを適用） | プレーンテキストの性別を指定します。コネクタによって空白が除去され、小文字に変換された後、SHA256でハッシュ化されます。 |
| 生年月日（SHA256でハッシュ化済み） | 空白の除去、小文字への変換、およびSHA256によるハッシュ化がすでに行われた生年月日を指定します。 |
| 生年月日（SHA256ハッシュを適用） | プレーンテキストの生年月日を指定します。コネクタによって空白が除去され、小文字に変換された後、SHA256でハッシュ化されます。 |
| 名（SHA256でハッシュ化済み） | 空白の除去、小文字への変換、およびSHA256によるハッシュ化がすでに行われた名を指定します。 |
| 名（SHA256ハッシュを適用） | プレーンテキストの名を指定します。コネクタによって空白が除去され、小文字に変換された後、SHA256でハッシュ化されます。 |
| 姓（SHA256でハッシュ化済み） | 空白の除去、小文字への変換、およびSHA256によるハッシュ化がすでに行われた姓を指定します。 |
| 姓（SHA256ハッシュを適用） | プレーンテキストの姓を指定します。コネクタによって空白が除去され、小文字に変換された後、SHA256でハッシュ化されます。 |
| 市区町村（SHA256でハッシュ化済み） | 空白の除去、小文字への変換、およびSHA256によるハッシュ化がすでに行われた市区町村を指定します。ハッシュ化する前にスペースと句読点を削除してください。 |
| 市区町村（SHA256ハッシュを適用） | プレーンテキストの市区町村を指定します。コネクタによってスペースと句読点が削除され、空白が除去され、小文字に変換された後、SHA256でハッシュ化されます。 |
| 州（SHA256でハッシュ化済み） | 空白の除去、小文字への変換、およびSHA256によるハッシュ化がすでに行われた州を指定します。 |
| 州（SHA256ハッシュを適用） | プレーンテキストの州を指定します。コネクタによって空白が除去され、小文字に変換された後、SHA256でハッシュ化されます。 |
| 郵便番号（SHA256でハッシュ化済み） | 数字のみで構成され、空白の除去およびSHA256によるハッシュ化がすでに行われた郵便番号を指定します。 |
| 郵便番号（SHA256ハッシュを適用） | プレーンテキストの郵便番号を指定します。コネクタによって数字以外のすべての文字が削除され、空白が除去された後、SHA256でハッシュ化されます。 |
| 国コード（SHA256でハッシュ化済み） | 空白の除去、小文字への変換、およびSHA256によるハッシュ化がすでに行われた国コードを指定します。 |
| 国コード（SHA256ハッシュを適用） | プレーンテキストの国コードを指定します。コネクタによって空白が除去され、小文字に変換された後、SHA256でハッシュ化されます。 |
| 外部ID（SHA256でハッシュ化済み） | 空白の除去およびSHA256によるハッシュ化がすでに行われた1つ以上の外部IDを指定します。複数の外部IDがある場合は、配列として指定します。詳細については、[Pinterest：外部IDとは](https://developers.pinterest.com/docs/api-features/conversion-best-practices/#what-is-an-external-id)を参照してください。|
| 外部ID（SHA256ハッシュを適用） | 1つ以上のプレーンテキストの外部IDを指定します。コネクタによって空白が除去された後、SHA256でハッシュ化されます。複数の外部IDを指定する場合は、配列として指定します。 |
| クリックID | ドメイン上の`_epik` Cookie、またはURL内の`&epik=`クエリパラメータに保存される一意の識別子。ROASやCPAなどのレポートパフォーマンスを向上させることができます。 |

#### カスタムデータ

| **パラメータ** | **説明** |
| --- | --- |
| 通貨 | ISO 4217通貨コード。指定しない場合、Pinterestではアカウント作成時に構成された広告主の通貨が使用されます。 |
| 値 | イベントの合計値。コネクタは文字列値を受け取り、それを[倍精度浮動小数点数](https://en.wikipedia.org/wiki/Double-precision_floating-point_format)として解析します。複数の商品を含むチェックアウトイベントの場合は、すべての商品の合計価格を使用します。 |
| コンテンツID | 商品IDのリスト。 |
| 商品数 | イベントに含まれる商品の合計数。たとえば、チェックアウトイベントで購入された商品の合計数です。 |
| 注文ID | 注文ID。 |
| 検索文字列 | ユーザーのコンバージョンイベントに関連する検索文字列。 |
| オプトアウトタイプ | 個人情報の共有からユーザーをオプトアウトさせるための、各種プライバシー権法に対応するフラグ。値はカンマ区切りで指定してください。配列型属性をマッピングすると、カンマ区切りの文字列に変換されます。 |

#### コンテンツデータ

* コンバージョンに複数の商品を追加するには、配列型属性を指定します。配列型属性の長さはすべて同じである必要があります。
* 単一値属性をパラメータにマッピングした場合、その値はコンバージョンの配列内にあるすべての商品に適用されます。

| **パラメータ** | **説明** |
| --- | --- |
| 商品価格 | コンバージョン内の個々の商品の価格。コネクタは文字列値を受け取り、それを[倍精度浮動小数点数](https://en.wikipedia.org/wiki/Double-precision_floating-point_format)として解析します。複数の商品を含むチェックアウトイベントの場合は、各商品の価格を指定します。 |
| 数量 | 商品の数量。 |
| ID | 商品のID。**AddToCart**イベントおよび**Checkout**イベントでの使用を推奨します。 |
| 商品名 | 商品の名前。 |
| 商品カテゴリ | 商品のカテゴリ。 |
| 商品ブランド | 商品のブランド。 |
