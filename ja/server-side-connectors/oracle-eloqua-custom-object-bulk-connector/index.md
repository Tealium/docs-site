---## 要件

* Oracle Eloqua アカウント
* Oracle Eloqua アカウントの会社名
* Oracle Eloqua アカウントのユーザー名
* Oracle Eloqua アカウントのパスワード

## バッチ制限

このコネクタは、ベンダーへの大量のデータ転送に対応するため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。以下のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数：10000
* 最も古いリクエストからの最大経過時間：15 分
* リクエストの最大サイズ：30 MB

## コネクタアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
|カスタムオブジェクトをインポート| ✓| ✗|

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の必須構成を構成します。

* 会社
* ユーザー名
* パスワード

## アクション構成 - パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### アクション - カスタムオブジェクトをインポート

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|アクション名|  <ul><li>この特定のアクションの名前</li></ul> |
|アクションカテゴリー|  <ul><li>例：メール</li><li>これらのカテゴリーは、同意プロンプトおよび同意構成機能を通じてユーザーに表示されます。</li><li>ユーザーは、これらのカテゴリーに基づいてトラッキングをオプトインまたはオプトアウトできます</li></ul> |
|ソース|  <ul><li>データソースを選択</li></ul> |
|カスタムオブジェクト|  <ul><li>（必須）カスタムオブジェクトを選択します。</li></ul> |
