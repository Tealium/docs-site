## API 情報

このコネクタでは、次のベンダー API を使用します。

* API 名：StackAdapt API
* API エンドポイント：`https://api.stackadapt.com/graphql`
* ドキュメント：[StackAdapt GraphQL API](https://docs.stackadapt.com/graphql)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を構成します。

* **API キー**：StackAdapt API キーを指定します。API キーをお持ちでない場合は、StackAdapt の担当チームにお問い合わせください。
* **環境**：StackAdapt 環境を選択します。
* **広告主 ID**：デフォルトの広告主 ID です。動的に構成するには、コネクタのアクションマッピングでこの値を上書きします。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| プロファイルのアップサート（バッチ） | ✓ | ✗ |
| プロファイルリストへのプロファイルの追加 | ✓ | ✗ |
| プロファイルリストへのプロファイルの追加（バッチ） | ✓ | ✗ |
| プロファイルリストからのプロファイルの削除 | ✓ | ✗ |
| プロファイルリストからのプロファイルの削除（バッチ） | ✓ | ✗ |

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### プロファイルのアップサート（バッチ）

StackAdapt でプロファイルを作成または更新し、既存のプロファイルリストに追加します。

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| 未加工のメールアドレス | 顧客のメールアドレス。 |
| 広告主 ID | 構成で構成したデフォルトの広告主 ID を上書きします。 |
| プロファイル所有ステータス | オプション。アップロードしたプロファイルがユーザー所有か、サードパーティ所有かを指定します。有効な値は `INDETERMINATE`、`OPTED_IN`、`PROSPECT` です。 |
| プロファイルリスト ID | アップロードしたプロファイルに関連付けられているプロファイルリストの ID。 |

#### スキーマ

| **パラメータ** | **説明** |
| --- | --- |
| PII かどうか | 個人を特定できる情報（PII）を表すパラメータを追加します。 |
| プロファイル | スキーマ属性を Tealium 属性にマッピングします。スキーマセクションで定義したものと同じパラメータを使用してください。 |
| バッチの有効期間 | バッチアクションの送信頻度を指定するため、有効期間（TTL）を構成します。`1`～`60` 分の値を入力します。デフォルト値は `10` 分です。 |
