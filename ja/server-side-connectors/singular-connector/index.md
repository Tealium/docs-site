## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Singular API
* APIバージョン：v1
* APIエンドポイント：`https://s2s.singular.net/api/v1`
* ドキュメント：[Singular API](https://support.singular.net/hc/en-us/articles/31394799175963-Server-to-Server-SESSION-Endpoint-API-Reference#Session_API_Endpoint)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **SDK APIキー**
    * （必須）SDKキーは、APIリクエストで`a`パラメータとして渡されます。
    * SDKキーは、Singular UIのメインメニューにある[開発者ツール](https://app.singular.net/?#/react/sdk_integration)から取得します。
    * レポートAPIキーを使用しないでください。使用すると、データが拒否されます。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| セッションデータを送信 | ✗ | ✓ |
| イベントデータを送信 | ✗ | ✓ |

アクションの名前を入力し、**アクションタイプ**を選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### セッションデータを送信

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| プラットフォーム | アプリのプラットフォーム。使用可能な値は、`Android`、`iOS`、`PC`、`Xbox`、`Playstation`、`Nintendo`、`MetaQuest`、`CTV`です。 |

#### セッションデータパラメータ

すべてのパラメータはURLエンコードされません。

| パラメータ | 説明 |
| --- | --- |
| IPv4アドレス | （必須）デバイスのパブリックIPv4アドレス。 |
| OSバージョン | （必須）セッション時のデバイスのOSバージョン。 |
| アプリ識別子 | （必須）アプリ識別子。 |
| アプリケーションバージョン | （必須）アプリケーションのバージョン。 |
| インストール | （必須）このパラメータは、このセッションがインストールまたは再インストール後の最初のセッションかどうかを示します。 |
| クライアント定義識別子 | 他のすべての識別子を使用できない特殊なケースで使用する、クライアント定義の識別子。 |
| タイムスタンプ | UNIX時間（秒）で表したセッションの時刻。 |
| タイムスタンプ（ミリ秒） | 13桁のUNIX時間（ミリ秒）で表したセッションの時刻。 |
| グローバルプロパティ | 最大5つのキーと値のペアを含むJSONオブジェクト。 |
| IPを使用 | このパラメータは、IPv4アドレスパラメータではなくHTTPリクエストからIPアドレスを抽出するようSingularに指示します。 |
| 国 | セッション時点におけるユーザーのISO 3166-1 alpha-2形式の2文字の国コード。 |
| ユーザーエージェント | デバイスのユーザーエージェント。 |
| データ共有オプション | 情報共有に対するエンドユーザーの同意。 |
| 内部ユーザーID | 内部ユーザーID。 |

#### プラットフォーム固有のデータパラメータ

ベンダー側のプラットフォーム固有パラメータにマッピングするイベント属性を選択します。
