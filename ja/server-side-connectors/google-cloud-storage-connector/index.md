## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Google Cloud Storage API
* APIバージョン：v1
* APIエンドポイント：`https://storage.googleapis.com/`
* ドキュメント：[Google Cloud Storage API](https://cloud.google.com/storage/docs/json_api)

## バッチ処理の上限

このコネクタは、ベンダーへの大容量データ転送に対応するため、リクエストをバッチ処理します。詳細については、「バッチアクション」を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに追加されます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：100 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を行います。

* **プロジェクトID**：接続するプロジェクトIDを選択します。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | ビジタープロファイル | イベントデータ |
| --- | :---: | :---: |
| イベントデータ全体を送信 | ✗ | ✓ |
| カスタムイベントデータを送信 | ✗ | ✓ |
| ビジターデータ全体を送信 | ✓ | ✗ |
| カスタムビジターデータを送信 | ✓ | ✗ |
| ログイベントを送信 | ✗ | ✓ |
| ログイベント全体を送信 | ✗ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

以降のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### イベントデータ全体を送信

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| バケット | オブジェクトを作成するバケットを選択します。 |
| オブジェクトパス | データを追加するオブジェクトへのパスを指定します。 |
| オブジェクトパスのサフィックス | ファイルパスに動的なサフィックス（タイムスタンプなど）として追加する属性を選択します。複数のサフィックス値を指定した場合は、アンダースコア文字で区切られます。 |
| レコードのサフィックス | <ul><li>区切り文字として各レコードの末尾に追加するサフィックスです。</li><li>デフォルトは`Newline`です。</li><li>使用可能なオプションは`Newline`と`No Delimiter`です。</li></ul> |
| 既存のオブジェクトを上書き | オブジェクトがすでに存在する場合、現在のデータで上書きします。選択しない場合は、代わりにデータが追加されます。データを追加する場合、各ブロックは、Tealiumから転送されるデータを含むペイロードを格納した単一オブジェクトの配列で構成されます。 |
| 属性名を出力 | デフォルトでは、属性キーが使用されます。代わりに属性名をキーとして使用する場合は、このチェックボックスをオンにします。属性名が更新されると、ペイロード名にもその更新が反映される点に注意してください。 |
| バッチの有効期間 | バッチアクションを送信する頻度を指定するため、有効期間（TTL）を構成します。`1`～`60`分の値を入力します。デフォルト値は`10`分です。 |
