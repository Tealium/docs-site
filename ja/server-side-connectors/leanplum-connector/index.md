## API情報

このコネクタでは、次のベンダーAPIを使用します。

* API名：Leanplum API
* APIバージョン：v1.0
* APIエンドポイント：`https://api.leanplum.com/api`
* ドキュメント：[Leanplum API](https://docs.leanplum.com/reference/overview#introduction)

## コネクタアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
|複数リクエストを送信（バッチ処理）| ✓| ✓|
|ユーザー属性を構成| ✓| ✓|
|メッセージを送信| ✓| ✓|
|イベントをトラッキング| ✓| ✓|

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を構成します。

* **App ID**：アプリケーションID。確認するには、ナビゲーション列でアプリを選択し、**Manage Apps**をクリックします。次に、**Keys & Settings**をクリックします。
* **API Version**：使用するLeanplum APIのバージョン。
* **Client Key**：Leanplumアプリの本番環境用キー。

## アクション

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

### 複数リクエストを送信（バッチ処理）

#### バッチ制限

このアクションでは、ベンダーへの大量データ転送に対応するため、バッチリクエストを使用します。次のいずれかのしきい値に達するまで、リクエストはキューに格納されます。

* リクエストの最大数：50
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：1 MB

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| Action | APIアクション |
| Time | リクエストが発行された時刻（UNIX時間）。イベント時刻を計算する際に、LeanplumとAPI呼び出し元との時刻の差を解消するために使用されます。 |
| User ID | 現在のユーザーID。会社で使用している任意のユーザーIDを構成できます。デバイスIDを使用する場合は空白のままにします。詳細については、<a href="https://docs.leanplum.com/reference/selecting-a-user" target="_blank">ユーザーの選択</a>を参照してください。 |
| Device ID | デバイスの一意のID。 |
| App ID | アプリケーションID。確認するには、ナビゲーション列でアプリを選択し、**Manage Apps**をクリックします。次に、**Keys & Settings**をクリックします。 |
| API Version | 使用するLeanplum APIのバージョン。 |
| Create Disposition | APIによってユーザーを作成するかどうかを決定するポリシー。このメソッドのデフォルト値は**CreateIfNeeded**です。<br><br>指定可能な値：<ul><li>**CreateIfNeeded** 指定されたIDを持つユーザーがまだ存在しない場合、そのユーザーを作成します。</li><li>**CreateNever** ユーザーがすでに存在している必要があります。存在しない場合、API呼び出しはスキップされ、警告が返されます。</ul></li> |
| Dev Mode | ユーザーが開発モードであるかどうか（リクエストに関連付けられたユーザーが一般ユーザーではなく開発者であるかどうか）。これはレポート作成上重要です。デフォルト値：`false`。 |
| Event | イベントの名前。収益化イベントを識別するには「Purchase」を使用し、イベント値に収益を指定します。 |
| Message ID | このイベントに関連付けられたメッセージID。ユーザーによるメッセージへの反応をトラッキングするには、この値を構成します。メッセージの送信または表示をトラッキングするには、イベント引数を空文字列に構成します。 |
| Disposition | トラッキング対象イベントがセッションとユーザーアクティビティに与える影響を決定します。<br><br>指定する場合、Dispositionには次のいずれかの値を構成する必要があります。<ul><li>`active` <ul><li>デフォルト値です。</li><li>ユーザーアクティビティを反映するイベントに使用します。</li><li>アクティブイベントでは、ユーザーをアクティブとしてマークし、セッション内でトラッキングする必要があります。</li><li>非推奨のオプション`allowOffline: false`に代わるものです。</li></ul> </li><li>`passive` <ul><li>ユーザーアクティビティに対応しないイベントに使用します。</li><li>これらのイベントはセッション内で発生する必要がなく、ユーザーをアクティブとしてマークしません。</li><li>例：ユーザーへのメッセージ送信はユーザーに影響を与えますが、ユーザーアクティビティを表すものではないため、パッシブとしてトラッキングされます。</li><li>非推奨のオプション`allowOffline: true`に代わるものです。</li></ul> </li><li>`requireActive` <ul><li>セッション内でのみトラッキングする必要があるイベントに使用します。</li><li>ユーザーにアクティブなセッションがない場合、これらのイベントは拒否され、`ignored: true`を含む警告レスポンスが返されます。</li><li>警告メッセージは変更される可能性があるため、クライアントはignoredフィールドを使用して警告を検出する必要があります。</li></ul> </li></ul> </li> |
| Force | ユーザーがターゲティング条件を満たしているかどうかにかかわらず、メッセージを送信するかどうか。デフォルト：`false`。 |
| Created | ユーザーが作成された時刻。1970年1月1日午前0時（UTC）からの経過秒数で指定します。 |
| Last Active | ユーザーが最後にアクティブだった時刻。1970年1月1日午前0時（UTC）からの経過秒数で指定します。 |
| Total Sessions | ユーザーがこれまでに行ったセッションの合計数。 |
| Time Spent In App | ユーザーがこれまでにアプリ内で費やした合計秒数。 |
| Locale | ユーザーの現在のロケール。例：en_US。 |
| Country | ユーザーが所在する国。<a href="http://en.wikipedia.org/wiki/ISO_3166-1_alpha-2" target="_blank"><u>ISO 2文字コード</u></a>で指定します。例：米国の場合はUS。ユーザーのIPアドレスに基づいて国を検出するには、(detect)に構成します。 |
| Region | ユーザーが所在する地域（州）。例：カリフォルニア州の場合はca。ユーザーのIPアドレスに基づいて地域を検出するには、(detect)に構成します。 |
| City | ユーザーが所在する都市。例：San Francisco。ユーザーのIPアドレスに基づいて都市を検出するには、(detect)に構成します。 |
| Location | ユーザーの位置（緯度／経度）。例：37.775,-122.4183。ユーザーのIPアドレスに基づいて位置を検出するには、(detect)に構成します。 |
| Location Accuracy Type | 提供される位置情報のタイプ（IP、CELL、またはGPS）。デフォルト：IP。 |
| Timezone | ユーザーのタイムゾーンの略称。タイムゾーン略称の一覧を参照してください。 |
| Timezone Offset Seconds | GMTからのタイムゾーンオフセット（秒）。 |
| User Attributes | キーと値のペアで構成されるユーザー属性のマップ。各キーは文字列である必要があります。属性はセッションをまたいで保存されます。指定した属性のみが更新されます（たとえば、既存の属性を省略した場合、その属性は保持されます）。 |
| User Attribute Values To Add | 既存のユーザー属性セットに追加する値のマップ。たとえば、既存のInterestsセットにSportsを追加するには、{"Interests":"Sports"}を指定します。 |
| Value | イベント値。たとえば、購入イベントの場合は購入価格になります。 |
| Currency Code | 値に関連付けられたISO 4217通貨コード。Leanplumは、元の価格と通貨コードをイベントパラメータlocalCurrencyおよびlocalPriceとして保持しながら、値を優先通貨に自動変換します。通貨換算レートは1時間ごとに更新されます。 |
| Time | イベントが発生した時点のUNIXタイムスタンプを指定するオプション。現在時刻とは異なる場合があります。 |
| Info | イベントにエンリッチメントする任意の情報。 |
| Parameters | キーと値のペアで構成されるフラットなパラメータオブジェクト。各キーは文字列である必要があり、最大50個のパラメータを構成できます。 |
| Values | メッセージで使用されるテンプレート変数を上書きする、キーと値のペアで構成されたJSONオブジェクト。 |
