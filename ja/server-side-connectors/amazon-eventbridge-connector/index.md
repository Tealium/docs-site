## コネクタアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
|イベントデータをイベントソースに送信| ✗| ✓|
|訪問データをイベントソースに送信| ✓| ✗|
|カスタマイズしたデータをイベントソースに送信（詳細構成）| ✓| ✓|

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。

* **アカウント ID**  
アカウント ID を入力します。
* **リージョン**  
（必須）リージョンを選択します。

コネクタの構成が完了したら、**完了**をクリックします。

## アクション構成 — パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### アクション — イベントデータをイベントソースに送信

#### パラメータ

| **パラメータ**         | **説明**                                                                                                                                                                                                                                                           |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| イベントソース          | データの送信先となるパートナーイベントソースを選択します。                                                                                                                                                                                                                              |
| 詳細タイプ           | イベントの詳細に含まれるフィールドを決定するために使用する自由形式の文字列です。詳細タイプについて詳しくは、[Amazon EventBridge API PutPartnerEvents のドキュメント](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_PutPartnerEvents.html)を参照してください。 |
| リソース             | イベントが主に関連する AWS リソースです。Amazon リソースネーム（ARN）で識別されます。<br> 0 個を含め、任意の数を指定できます。                                                                                                                              |
| 属性名を出力 | 属性名が更新された場合、ペイロード内の名前にもその更新が反映されます。                                                                                                                                                                                         |
|                       |                                                                                                                                                                                                                                                                           |

### アクション — 訪問データをイベントソースに送信

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|イベントソース| データの送信先となるパートナーイベントソースを選択します。|
|詳細タイプ| イベントの詳細に含まれるフィールドを決定するために使用する自由形式の文字列です。|
|リソース| イベントが主に関連する AWS リソースです。Amazon リソースネーム（ARN）で識別されます。<br> 0 個を含め、任意の数を指定できます。|
| 現在の訪問データを訪問データに含める | 現在の訪問データをペイロードに追加します。「現在の訪問のイベントデータを除外」が選択されていない場合、これには訪問のイベントデータが含まれます。 |
| 現在の訪問のイベントデータを除外 | 現在の訪問データからイベントデータを除外します。 |
|属性名を出力| 属性名が更新された場合、ペイロード内の名前にもその更新が反映されます。|

### アクション — カスタマイズしたデータをイベントソースに送信（詳細構成）

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|イベントソース| データの送信先となるパートナーイベントソースを選択します。|
|詳細タイプ| イベントの詳細に含まれるフィールドを決定するために使用する自由形式の文字列です。|
|リソース| イベントが主に関連する AWS リソースです。Amazon リソースネーム（ARN）で識別されます。<br> 0 個を含め、任意の数を指定できます。|
|カスタムメッセージ定義|
|メッセージテンプレート変数| （任意）テンプレートへのデータ入力として使用するテンプレート変数を指定します。詳細については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。<br> ネストされたテンプレート変数には、ドット表記で名前を付けます（例：`items.name`）。<br> ネストされたテンプレート変数は、通常、データレイヤーのリスト属性から作成されます。|
|メッセージテンプレート| （任意）URL、URL パラメータ、ヘッダー、または本文データで参照するテンプレートを指定します。詳細については、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。<br> テンプレートは、サポートされているフィールドに二重波括弧で囲んだ名前を指定することで挿入されます。例：`{{SomeTemplateName}}`。|
