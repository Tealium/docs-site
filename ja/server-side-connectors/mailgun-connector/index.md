## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Mailgun API
* APIバージョン：v3
* APIエンドポイント：`https://api.mailgun.net`
* ドキュメント：[Mailgun API](https://documentation.mailgun.com/en/latest/)

## コネクタアクション

| アクション名 | ビジタープロファイル | イベントデータ |
| --- | :---: | :---: |
| メールを送信 | ✓ | ✓ |
| リスト内のメンバーをアップサート | ✓ | ✓ |

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を構成します。

* **Mailgunドメイン**：（必須）適切なリージョンベースのドメインを選択します。
* **APIキー**：（必須）プライベートAPIキーは、Mailgunダッシュボードで確認できます。

## アクション構成 - パラメーターとオプション

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。

### アクション - メールを送信

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| 送信ドメイン | （必須）Mailgunアカウントのドメイン。 |
| From | （必須）送信者のメールアドレス。 |
| To | （必須）受信者のメールアドレス。 |
| 件名 | メールの件名。 |
| テキスト | メッセージの本文。 |
| CC | CC（カーボンコピー）の送信先メールアドレス。 |
| BCC | BCC（ブラインドカーボンコピー）の送信先メールアドレス。 |
| テンプレート名 | Mailgunのメール送信テンプレート名。 |
| テンプレートテキスト | テンプレートを使用してメッセージのテキストをレンダリングする場合は、このパラメーターを**yes**に構成します。 |
| テンプレートバージョン | 特定のバージョンのテンプレートを使用してメールを送信します。 |
| テンプレート変数 | テンプレート変数の展開時に入力として使用する、JSONエンコードされた辞書に属性をマッピングします。詳細については、[Mailgun APIリファレンス](https://documentation.mailgun.com/en/latest/api-sending.html#sending)を参照してください。 |

### アクション - リスト内のメンバーをアップサート

#### バッチ制限

このアクションは、ベンダーへの大容量データ転送に対応するため、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数：1000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：1 MB

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| アドレス | （必須）リストのメールアドレス。 |
| メンバーアドレス | （必須）リストに追加するメールアドレス。 |
| メンバー名 | 追加するメールアドレスの名前。 |
| 購読 | <ul><li>**yes**：新しいメンバーを購読登録します。</li><li>**no**：新しいメンバーを購読登録しません。</li></ul> |
| アップサート | <ul><li>**yes**：リストにメンバーが存在する場合、そのメンバーを更新します。</li><li>**no**：重複している場合でも、リストにメンバーを追加します。</li></ul> |
| 変数 | 追加のメンバーパラメーターを渡すために属性をマッピングします。詳細については、[Mailgun APIリファレンス](https://documentation.mailgun.com/en/latest/api-sending.html#sending)を参照してください。 |
