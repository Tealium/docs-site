## API情報

このコネクタでは、以下のベンダーAPIを使用します。

* API名：ROKT API
* APIエンドポイント：
  * APIエンドポイント：`https://api.rokt.com`
  * V1：`https://api.rokt.com/v1/events`
  * V2：`https://api.rokt.com/v2/events`
  * カスタムオーディエンスのインポート：`https://data.rokt.com/v3/import/suppression`
* ドキュメント：
  * [カスタムオーディエンスインポートAPI](https://docs.rokt.com/developers/api-reference/custom-audience-import/)
  * [イベントAPI](https://docs.rokt.com/developers/api-reference/event-api/)


<blockquote>
イベント送信アクションでは、v1とv2の両方の認証方式がサポートされています。使用するAPIはアクションレベルで指定できます。ただし、カスタムオーディエンス更新アクションでは、v2認証方式のみがサポートされています。詳細については、[Rokt：イベントAPI v1](https://docs.rokt.com/developers/api-reference/event-api#generating-app-id-and-app-secret)または[Rokt：イベントAPI v2](https://docs.rokt.com/developers/api-reference/event-api/#authentication-v2)のドキュメントを参照してください。
</blockquote>


## バッチ制限

このコネクタでは、ベンダーへの大量データ転送に対応するため、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。以下のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに追加されます。

* リクエストの最大数：100
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：1 MB

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/ja/server-side/connectors/manage/)を参照してください。

コネクタを追加したら、以下の構成を構成します。

* **クライアントID**  
  * （必須）App IDまたは公開キーを指定します。
* **クライアントシークレット**  
  * （必須）App Secretまたは秘密キーを指定します。
* **アカウントID**  
  * （必須）アカウントIDを指定します。

コネクタの構成が完了したら、**完了**をクリックします。

## アクション

| アクション名 | ビジタープロファイル | イベントデータ |
| --- | :---: | :---: |
| イベントを送信 | ✓ | ✓ |
| イベントを送信（バッチ） | ✓ | ✓ |
| カスタムオーディエンスを更新 | ✓ | ✗|
| カスタムオーディエンスを更新（バッチ） | ✓ | ✗ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

以下のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### イベントを送信

#### コンバージョンデータ

| **パラメータ** | **説明** |
| --- | --- |
| イベントID | マッピングされていない場合、Tealiumによってこの値のUUIDが生成されます。 |
| イベント時刻 | マッピングされていない場合、RFC 3339形式の現在のタイムスタンプに構成されます。 |
| メタデータ | イベントに関するビジネスクリティカルではない情報です。 |
| バージョン | デフォルトは`V2`です。**App ID**キーと**App Secret**キーを使用してV1エンドポイントにイベントを送信するには、`V1`に構成します。`rpub`キーと`rsec`キーを使用してV2エンドポイントにイベントを送信するには、`V2`に構成します。 |

### イベントを送信（バッチ）

#### コンバージョンデータ

| **パラメータ** | **説明** |
| --- | --- |
| イベントID | マッピングされていない場合、Tealiumによってこの値のUUIDが生成されます。 |
| イベント時刻 | マッピングされていない場合、RFC b3339形式の現在のタイムスタンプに構成されます。 |
| メタデータ | イベントに関するビジネスクリティカルではない情報です。 |
| バージョン | デフォルトは`V1`です。**App ID**キーと**App Secret**キーを使用してV1エンドポイントにイベントを送信するには、`V1`に構成します。`rpub`キーと`rsec`キーを使用してV2エンドポイントにイベントを送信するには、`V2`に構成します。|

### カスタムオーディエンスを更新

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| アクション | ビジターを指定したリストに追加するには、`include`に構成します。このリストは、ターゲティングまたは除外に使用できます。指定したリストからビジターを削除するには、`exclude`に構成します。|
| メール | メールアドレスです。 |
| リスト | 使用するカスタムオーディエンスリストの名前です。リストの値を指定しない場合、デフォルトでメールアドレスがAdvertiserDatabaseリストにインポートされます。 |
| SHA-256ハッシュ化 | メールフィールドに指定された未加工のメールアドレスをTealiumでSHA-256ハッシュ化する場合は、このチェックボックスをオンにします。 |
