## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Adform API
* APIバージョン：v1
* APIエンドポイント：`https://api.adform.com/v1/dmp`
* ドキュメント：[Adform：DMP APIリファレンス](https://api.adform.com/v1/help/dmp)

## 構成

**コネクタマーケットプレイス**に移動し、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタの概要](https://docs.tealium.com/about-connectors/)の記事を参照してください。

コネクタを追加した後、次の項目を構成します。

* **クライアントID**：（必須）クライアントIDを指定します。
* **クライアントシークレット**：（必須）クライアントシークレットを指定します。
* **認証タイプ**：Adformアカウントの認証モードを選択します。
  * **パートナーレベル**（デフォルト）：AdformパートナーIDを使用します。従来のAdform DMPアカウントでは、このオプションを選択します。
  * **広告主レベル**：Adform広告主IDとともにAdform Audience Managerを使用します。
* **AdformパートナーID**：（パートナーレベルでは必須）AdformパートナーIDを入力します。
* **Adform広告主ID**：（広告主レベルでは必須）リストからAdform広告主IDを選択するか、手動で入力します。リストには、アクティブな広告主のみが表示されます。

## オーディエンスセグメントの管理

セグメントを作成および削除し、オーディエンスセグメントにユーザーを追加したり、そこから削除したりします。このコネクタは、APIエンドポイントを使用して、顧客データプラットフォーム内のセグメントを取得、作成、削除します。

使用できる管理タスクは、構成時に選択した**認証タイプ**によって異なります。

| 認証タイプ | 使用可能なタスク |
|---|---|
| パートナーレベル | 新しいオーディエンスセグメント、オーディエンスセグメントの削除 |
| 広告主レベル | 新しいオーディエンス（Audience Manager） |

動的オーディエンス生成を有効にしてデフォルト構成を調整できるのは、アカウント管理者のみです。管理者は、価格、日単位の有効期間（TTL）、およびデータタイプを構成できます。

セグメントを削除するには、**オーディエンスセグメントの削除**をクリックし、削除するオーディエンスセグメントを選択します。このタスクは、パートナーレベルでのみ使用できます。


<blockquote>
デフォルトでは、オーディエンスを動的に作成する機能は使用できません。この機能を使用するには、Adform管理者に機能を有効にするよう依頼してください。
</blockquote>


### パートナーレベル

パートナーレベルのセグメントを作成するには、**新しいオーディエンスセグメント**をクリックし、次の項目を構成します。

|**構成**| **説明**|
|---| ---|
| 名前 | （必須）Adformに表示するオーディエンスの名前。 |
| AdformパートナーID | （必須）アカウントのAdformパートナーID。 |
| カテゴリID | （必須）オーディエンスのカテゴリID。 |
| 所有者ID | （必須）オーディエンス所有者IDの値。 |
| 価格 | （必須）オーディエンスごとに構成する価格。 |
| データタイプ | データ共有計画に応じてデータタイプを構成します。<ul><li>**ファーストパーティ**：自社のみがデータを使用します。</li><li>**セカンドパーティ**：1社以上のパートナーとデータを共有します。</li><li>**サードパーティ**：ブランドデータプロバイダーとして、すべての利用者とこのデータを共有します。</li></ul> |
| 有効期間（TTL） | （必須）オーディエンスセグメント内のデータの有効期間。 |
| 頻度 | （必須）ユーザーがオーディエンスに割り当てられるために、カテゴリに該当する必要がある回数。 |

セグメントのステータスは、オーディエンスセグメント名の横に括弧で表示されます。例：`Cart Abandoners (active)`

### 広告主レベル

Audience Managerのグローバルアカウント用に広告主レベルのオーディエンスを作成するには、**新しいオーディエンス（Audience Manager）**をクリックし、次の項目を構成します。

|**構成**| **説明**|
|---| ---|
| 名前 | （必須）Adformに表示するオーディエンスの名前。 |
| サードパーティオーディエンスID | （必須）このオーディエンスを一意に識別する外部識別子。ユーザー追加／削除呼び出しでセグメントIDとして使用されます。 |
| カテゴリID | （必須）オーディエンスのカテゴリID。 |
| 有効期間（TTL） | （必須）オーディエンスセグメント内のデータの有効期間。 |
| 頻度 | （必須）ユーザーがオーディエンスに割り当てられるために、カテゴリに該当する必要がある回数。 |
| ID Fusion | クロスデバイスのID解決にID Fusionを有効にします。デフォルト：`Yes`。 |
| 類似オーディエンス | 類似オーディエンスモデリングを有効にします。デフォルト：`No`。 |

## アクション

| アクション名 | AudienceStream | EventStream | 認証タイプ |
| --- | :---: | :---: | --- |
|ユーザーをオーディエンスセグメントに追加| ✓| ✓| パートナーレベル |
|ユーザーをオーディエンスセグメントから削除| ✓| ✓| パートナーレベル |
|ユーザーをオーディエンスセグメントに追加（Audience Manager）| ✓| ✓| 広告主レベル |
|ユーザーをオーディエンスセグメントから削除（Audience Manager）| ✓| ✓| 広告主レベル |


<blockquote>
Adform Segmentsコネクタは、`UID`パラメータの送信をサポートしていません。`UID`パラメータが必要な場合、Adformでは[Adformタグ](https://docs.tealium.com/adform-tag/)の使用を推奨しています。
</blockquote>


### ユーザーをオーディエンスセグメントに追加

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|オーディエンスセグメント（`sg`）| 更新するオーディエンスセグメント。リストから選択するか、所有者IDを直接入力します。|
|AdformパートナーID| （必須）アカウントのAdformパートナーID。|
|GAID（`gaid`）| Google広告主訪問ID属性。|
|IDFA（`idfa`）| Appleの広告主向け識別子。|
|ファーストパーティデータソース| 含まれるIDを管理するソースまたはテクノロジープロバイダーを表すテキスト。`netid.de`などのトップレベルドメインを使用します。|
|ファーストパーティエージェントタイプ| ユーザー識別子の取得元であるユーザーエージェントのタイプを識別する整数。指定可能なエージェントタイプの値：<ul><li>1 - デスクトップデバイスのブラウザーから収集。</li><li>2 - モバイルデバイス上のアプリ（アプリ内）から収集（IDFAやAAIDなど）。</li><li>3 - 複数のデバイスおよびアプリケーションで共通するユーザーベースのID。</li><li>500+ - ベンダー固有のコンテキストおよびID、ベンダー固有のコード。</li></ul> |
|ファーストパーティID| ソースプロバイダーのファーストパーティIDを表す識別子。長い文字列またはGUIDの場合があります。|

### ユーザーをオーディエンスセグメントに追加（Audience Manager）

[ユーザーをオーディエンスセグメントに追加](#add-user-to-audience-segment)と同じパラメータを使用します。`sg`パラメータには、Audience Managerセグメントの**サードパーティオーディエンスID**を使用します。

### ユーザーをオーディエンスセグメントから削除（Audience Manager）

[ユーザーをオーディエンスセグメントから削除](#remove-user-from-audience-segment)と同じパラメータを使用します。`sg`パラメータには、Audience Managerセグメントの**サードパーティオーディエンスID**を使用します。
## ファーストパーティ ID

Adform は、現在利用可能なすべてのファーストパーティ ID ソリューションに対応しています。コネクタは、呼び出し内のオーディエンスにファーストパーティ ID を割り当てます。

コネクタは、以下のファーストパーティ ID をサポートしています。

|**プロバイダー名**| **ソース名**|
|---| ---|
|NetID| `netid.de`|
|Britepool| `britepool.com`|
|Liveramp (IdentityLink)| `liveramp.com`|
|PubCommonID| `id5-sync.com`|
|Lotame (Panorama ID)| `crwdcntrl.net`|
|Unified ID 2.0| `uidapi.com`|
|Prebid Shared ID| `sharedid.org`|
|独自 ID| `your-top-level-domain.com` この値を使用すると、訪問の統合のために Tealium 訪問 ID を Adform にマッピングできます。|
