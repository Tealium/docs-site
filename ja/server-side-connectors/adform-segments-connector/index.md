## API 情報

このコネクタは、次のベンダー API を使用します。

* API 名: Adform API
* API バージョン: v1
* API エンドポイント: `https://api.adform.com/v1/dmp`
* ドキュメント: [Adform: DMP API リファレンス](https://api.adform.com/v1/help/dmp)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を行います。

* **クライアント ID**: （必須）クライアント ID を指定します。
* **クライアントシークレット**: （必須）クライアントシークレットを指定します。
* **認証タイプ**: Adform アカウントの認証モードを選択します。
  * **パートナーレベル**（デフォルト）: Adform パートナー ID を使用します。従来の Adform DMP アカウントの場合は、これを選択します。
  * **広告主レベル**: Adform 広告主 ID とともに Adform Audience Manager を使用します。
* **Adform パートナー ID**: （パートナーレベルでは必須）Adform パートナー ID を入力します。
* **Adform 広告主 ID**: （広告主レベルでは必須）リストから Adform 広告主 ID を選択するか、手動で入力します。リストには、有効な広告主のみが表示されます。

コネクタを構成したら、**完了**をクリックします。

## オーディエンスセグメントの管理

セグメントの作成と削除、およびオーディエンスセグメントへのユーザーの追加と削除を行います。このコネクタは API エンドポイントを使用して、顧客データプラットフォーム内のセグメントを取得、作成、削除します。

使用できる管理タスクは、構成時に選択した**認証タイプ**によって異なります。

| 認証タイプ | 使用可能なタスク |
|---|---|
| パートナーレベル | 新規オーディエンスセグメント、オーディエンスセグメントを削除 |
| 広告主レベル | 新規オーディエンス（Audience Manager） |

動的オーディエンス生成を有効にしてデフォルト構成を調整できるのは、アカウント管理者のみです。管理者は、価格、日単位の有効期間（TTL）、およびデータタイプを構成できます。

セグメントを削除するには、**オーディエンスセグメントを削除**をクリックし、削除するオーディエンスセグメントを選択します。このタスクは、パートナーレベルでのみ使用できます。


<blockquote>
デフォルトでは、オーディエンスを動的に作成する機能は使用できません。この機能を使用するには、Adform 管理者に機能を有効にするよう依頼してください。
</blockquote>


### パートナーレベル

パートナーレベルのセグメントを作成するには、**新規オーディエンスセグメント**をクリックし、次の構成を行います。

|**構成**| **説明**|
|---| ---|
| 名前 | （必須）Adform に表示するオーディエンスの名前。 |
| Adform パートナー ID | （必須）アカウントの Adform パートナー ID。 |
| カテゴリ ID | （必須）オーディエンスのカテゴリ ID。 |
| 所有者 ID | （必須）オーディエンス所有者 ID の値。 |
| 価格 | （必須）オーディエンスごとに構成する価格。 |
| データタイプ | データ共有プランに従ってデータタイプを構成します。<ul><li>**ファーストパーティ**: データを使用するのは自社のみです。</li><li>**セカンドパーティ**: パートナーとデータを共有します。</li><li>**サードパーティ**: ブランドデータプロバイダーとして、すべての相手とこのデータを共有します。</li></ul> |
| 有効期間（TTL） | （必須）オーディエンスセグメント内のデータの有効期間。 |
| 頻度 | （必須）ユーザーがオーディエンスに割り当てられるために、カテゴリに該当する必要がある回数。 |

セグメントのステータスは、オーディエンスセグメント名の横に括弧で表示されます。例: `Cart Abandoners (active)`

### 広告主レベル

Audience Manager のグローバルアカウント用に広告主レベルのオーディエンスを作成するには、**新規オーディエンス（Audience Manager）**をクリックし、次の構成を行います。

|**構成**| **説明**|
|---| ---|
| 名前 | （必須）Adform に表示するオーディエンスの名前。 |
| サードパーティオーディエンス ID | （必須）このオーディエンスの一意の外部識別子。ユーザーの追加／削除呼び出しでセグメント ID として使用されます。 |
| カテゴリ ID | （必須）オーディエンスのカテゴリ ID。 |
| 有効期間（TTL） | （必須）オーディエンスセグメント内のデータの有効期間。 |
| 頻度 | （必須）ユーザーがオーディエンスに割り当てられるために、カテゴリに該当する必要がある回数。 |
| ID Fusion | クロスデバイスの ID 解決に ID Fusion を有効にします。デフォルト: `Yes`。 |
| 類似オーディエンス | 類似オーディエンスモデリングを有効にします。デフォルト: `No`。 |

## アクション

| アクション名 | 訪問プロファイル | イベントデータ | 認証タイプ |
| --- | :---: | :---: | --- |
|オーディエンスセグメントにユーザーを追加| ✓| ✓| パートナーレベル |
|オーディエンスセグメントからユーザーを削除| ✓| ✓| パートナーレベル |
|オーディエンスセグメントにユーザーを追加（Audience Manager）| ✓| ✓| 広告主レベル |
|オーディエンスセグメントからユーザーを削除（Audience Manager）| ✓| ✓| 広告主レベル |


<blockquote>
Adform Segments コネクタは、`UID` パラメータの送信をサポートしていません。`UID` パラメータが必要な場合、Adform では [Adform タグ](https://docs.tealium.com/adform-tag/)の使用を推奨しています。
</blockquote>


### オーディエンスセグメントにユーザーを追加

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|オーディエンスセグメント（`sg`）| 更新するオーディエンスセグメント。リストから選択するか、所有者 ID を直接入力します。|
|Adform パートナー ID| （必須）アカウントの Adform パートナー ID。|
|GAID（`gaid`）| Google 広告主訪問 ID 属性。|
|IDFA（`idfa`）| Apple の広告主向け識別子。|
|ファーストパーティデータソース| 含まれる ID を管理するソースまたはテクノロジープロバイダーを表すテキスト。トップレベルドメイン（例: `netid.de`）を使用します。|
|ファーストパーティエージェントタイプ| ユーザー識別子の取得元となるユーザーエージェントのタイプを識別する整数。使用可能なエージェントタイプの値: <ul><li>1 - ブラウザーを使用するデスクトップデバイスから収集。</li><li>2 - モバイルデバイス上のアプリ（アプリ内）から収集（IDFA や AAID など）。</li><li>3 - 複数のデバイスおよびアプリケーションで同一となるユーザーベースの ID。</li><li>500+ - ベンダー固有のコンテキストおよび ID、ベンダー固有のコード。</li></ul> |
|ファーストパーティ ID| ソースプロバイダーから取得したファーストパーティ ID の識別子。長い文字列または GUID の場合があります。|

### オーディエンスセグメントにユーザーを追加（Audience Manager）

[オーディエンスセグメントにユーザーを追加](#add-user-to-audience-segment)と同じパラメータを使用します。`sg` パラメータには、Audience Manager セグメントの**サードパーティオーディエンス ID**を使用します。

### オーディエンスセグメントからユーザーを削除（Audience Manager）

[オーディエンスセグメントからユーザーを削除](#remove-user-from-audience-segment)と同じパラメータを使用します。`sg` パラメータには、Audience Manager セグメントの**サードパーティオーディエンス ID**を使用します。
## ファーストパーティ ID

Adform は、現在利用可能なすべてのファーストパーティ ID ソリューションに対応しています。コネクタは、呼び出し内のオーディエンスにファーストパーティ ID を割り当てます。

コネクタは、以下のファーストパーティ ID をサポートしています。

|**プロバイダー名**| **ソース名**|
|---| ---|
|NetID| `netid.de`|
|Britepool| `britepool.com`|
|Liveramp (IdentityLink)| `liveramp.com`|
|PubCommonID| `id5-sync.com`|
|Lotame (Panorama ID)| `crwdcntrl.net`|
|Unified ID 2.0| `uidapi.com`|
|Prebid Shared ID| `sharedid.org`|
|独自 ID| `your-top-level-domain.com` この値を使用すると、訪問を関連付けるために Tealium 訪問 ID を Adform にマッピングできます。|
