## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Viant API
* APIバージョン：v1
* APIエンドポイント：`https://vdp-connect-api.viantinc.com`
* ドキュメント：[Viant API](https://docs.api.viantinc.com/reference/how-to-get-started)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **クライアントID**：必須。Viant VDP API認証用のクライアントID。
* **クライアントシークレット**：必須。Viant VDP API認証用のクライアントシークレット。
* **アカウントID**：必須。ViantアカウントID。
* **広告主ID**：必須。Viant広告主ID。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| コンバージョンイベントを送信 | ✓ | ✓ |
| ヘルスケアコンバージョンイベントを送信 | ✓ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

以下のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### コンバージョンイベントを送信

#### バッチ制限

このアクションでは、ベンダーへの大容量データ転送に対応するため、バッチリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに保持されます。

* リクエストの最大数：1,000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：10 MB

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| コンバージョンイベントタイプ | **PageView** - ページビューイベント<br>**LandingPage** - ランディングページイベント<br>**ItemView** - アイテムビューイベント<br>**AddToCart** - カート追加イベント<br>**InitiateCheckout** - チェックアウト開始イベント<br>**AddPaymentInfo** - 支払い情報追加イベント<br>**Purchase** - 購入イベント<br>**Lead** - リードイベント |

#### 売上データ

| **パラメータ** | **説明** |
| --- | --- |
| トランザクションID | トランザクションの一意の識別子。自動マッピングが適用されます。上書きするには属性をマッピングします。 |
| コンバージョンタイムスタンプ | コンバージョンのISO 8601タイムスタンプ。例：`2025-07-28T15:32:00Z`。自動マッピングが適用されます。上書きするには属性をマッピングします。 |
| ストアID | 店舗またはロケーションの一意の識別子。 |
| 金額 | コンバージョンまたはトランザクションの合計金額。自動マッピングが適用されます。上書きするには属性をマッピングします。 |
| 通貨 | 通貨コード。例：`USD`、`EUR`。自動マッピングが適用されます。上書きするには属性をマッピングします。 |
| 販売チャネル | 販売チャネル。例：`Online`、`In-store`。 |

#### 識別子

| **パラメータ** | **説明** |
| --- | --- |
| メールアドレスにSHA256を適用 | 顧客のプレーンテキストのメールアドレス。コネクタによって正規化され、SHA256ハッシュ化が適用されます。 |
| SHA256適用済みメールアドレス | SHA256でハッシュ化された顧客のメールアドレス。 |
| 住所にSHA256を適用 | 顧客のプレーンテキストの住所。コネクタによって正規化され、SHA256ハッシュ化が適用されます。 |
| SHA256適用済み住所 | SHA256でハッシュ化された顧客の住所。 |
| IPアドレス | 顧客の`IP`アドレス。 |
| モバイルID | 顧客のモバイル`ID`。 |
| Cookie | イベントCookie。 |

#### 購入アイテム

| **パラメータ** | **説明** |
| --- | --- |
| アイテムID | （アイテムが存在する場合は必須）製品SKUの一意の識別子。 |
| 製品名 | 人が判読できる製品名。 |
| 製品カテゴリ | 製品のカテゴリ。 |
| 価格 | （アイテムが存在する場合は必須）単価。 |
| 数量 | （アイテムが存在する場合は必須）購入数量。 |
| カスタムデータ | 追加のコンテキストとして、最大10個のカスタムキーと値のメタデータペア。例：`campaign IDs`、`user segments`。 |

#### コンバージョンの場所

| **パラメータ** | **説明** |
| --- | --- |
| コンバージョンの国 | コンバージョンが発生した場所の国。 |
| コンバージョンの州 | コンバージョンが発生した場所の州。 |
| コンバージョンの市区町村 | コンバージョンが発生した場所の市区町村。 |
| 自動マッピングを無効化 | コネクタの自動マッピングを無効にします。 |

### ヘルスケアコンバージョンイベントを送信

#### バッチ制限

このアクションでは、ベンダーへの大容量データ転送に対応するため、バッチリクエストを使用します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに保持されます。

* リクエストの最大数：1,000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：10 MB

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| ヘルスケアイベント名 | （必須）Viantに送信する匿名化されたイベントコード。例：`Page View`、`Event 1`、`Event 2`。HIPAA要件に準拠するため、説明的なイベント名ではなく、短く意味を推測できないコードを使用してください。 |

#### 売上データ

| パラメータ | 説明 |
| --- | --- |
| トランザクションID | （必須）トランザクションの一意の識別子。インプレッションIDとクリックIDをグループ化するために使用されます。 |
| コンバージョンタイムスタンプ | コンバージョンのISO 8601タイムスタンプ。例：`2025-07-28T15:32:00Z`。指定されていない場合は現在時刻が使用されます。 |
| ストアID | 店舗またはロケーションの一意の識別子。 |
| 販売チャネル | 販売チャネル。例：`Online`、`In-store`。 |

#### ヘルスケア識別子

| パラメータ | 説明 |
| --- | --- |
| ViantインプレッションID | クリエイティブマクロ`${ADELPHIC_IMPRESSIONID}`から取得される、Viantの仮名化されたインプレッショントラッキングID。ビュースルーコンバージョンのアトリビューションに使用されます。 |
| ViantクリックID | クリエイティブマクロ`${ADELPHIC_CLICKID}`から取得される、Viantの仮名化されたクリックトラッキングID。クリックスルーコンバージョンのアトリビューションに使用されます。 |
| カスタム識別子 | （任意）顧客が定義した仮名化キー。例：社内の診療イベントIDまたはファネルID。 |
| カスタムデータ | （任意）追加のコンテキストを提供するキーと値のメタデータペア。`healthcare_capi`フラグは自動的に含まれます。 |

#### コンバージョンの場所

| パラメータ | 説明 |
| --- | --- |
| コンバージョンの国 | コンバージョンが発生した場所の国。 |
| コンバージョンの州 | コンバージョンが発生した場所の州。 |
| コンバージョンの市区町村 | コンバージョンが発生した場所の市区町村。 |
