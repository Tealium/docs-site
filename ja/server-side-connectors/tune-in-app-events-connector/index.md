## コネクタアクション

| **アクション名** | **訪問プロファイル** | **イベントデータ** |
|:----------------------|:-------------------|:----------------|
| 定義済みイベントを送信 | ✓                  | ✓               |
| カスタムイベントを送信 | ✓                  | ✓               |

## 要件

* TUNE アカウント
* メールアドレスとパスワード
* プライベート/API キー
* パブリック/コンシューマーキー

上記のキーを取得するには、TUNE アカウントに関連付けられているメールアドレスから TUNE サポートにリクエストを送信する必要があります。TUNE サポートがキーを作成します。

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の構成を構成します。

* **プライベート API キー**
  * 必須
  * プライベート API キーを指定します。
  * 詳細については、[プライベート API キーの取得](https://tune.docs.branch.io/measurement-docs/obtaining-your-private-api-key/)を参照してください。

* **パブリックコンシューマーキー**
  * 必須
  * パブリックコンシューマーキーを指定します。

## アクション構成 - パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。
