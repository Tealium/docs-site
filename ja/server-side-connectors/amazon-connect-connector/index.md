## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Amazon Connect
* APIバージョン：v1.0
* APIエンドポイント：`https://connect.{REGION}.amazonaws.com`
* ドキュメント：[Amazon Connect：StartOutboundVoiceContact](https://docs.aws.amazon.com/connect/latest/APIReference/API_StartOutboundVoiceContact.html)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を行います。

* **認証タイプ**：（必須）使用する認証のタイプ。
    * **アクセスキー**
        * **アクセスキー**：（必須）IAMユーザーのアクセスキーを指定します。関連付けられたIAMポリシー（IAMユーザーまたは引き受けるロールのいずれの場合も）では、データの送信先となるストリームに対する`kinesis:PutRecord`権限を付与する必要があります。
        * **シークレットキー**：（必須）IAMユーザーのシークレットキーを指定します。
        * **リージョン**：（必須）使用しているAWS Connectリージョンを選択します。
    * **STS**
        * **STS - 引き受けるロール：ARN**：（必須）引き受けるロールに割り当てられたAmazonリソースネーム。詳細については、[IAMロールへの切り替え](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles_use_switch-role-api.html)を参照してください。
        * **STS - 引き受けるロール：セッション名**：（必須）引き受けるロールセッションの一意の識別子。
        * **STS - 引き受けるロール：外部ID**：（任意）第三者が顧客のアカウントでロールを引き受ける際に使用する一意の識別子。詳細については、[AWS：第三者が所有するAWSアカウントへのアクセス](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles_common-scenarios_third-party.html)を参照してください。
        * **リージョン**：（必須）使用しているAWS Connectリージョンを選択します。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| アウトバウンド音声コンタクトを開始 | ✓ | ✓ |
| プロファイル属性を更新 | ✓ | ✓ |
| プロファイル属性を更新（バッチ） | ✓ | ✓ |

アクションの名前を入力し、アクションタイプを選択します。

次のセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。

### アウトバウンド音声コンタクトを開始

#### パラメーター

| パラメーター | 説明 |
| --- | --- |
| インスタンスID | （必須）Amazon Connectインスタンスの識別子。 |
| キューID | 通話に使用するキュー。キューを指定すると、発信者IDとして表示される電話番号には、そのキューで指定されている電話番号が使用されます。キューを指定しない場合は、フローで定義されているキューが使用されます。**キューID**または**発信元電話番号**のいずれかが必要です。 |
| 発信元電話番号 | Amazon Connectインスタンスに関連付けられた、E.164形式の電話番号。**キューID**または**発信元電話番号**のいずれかが必要です。 |
| コンタクトフローID | （必須）アウトバウンド通話に使用するフローの識別子。 |

#### ベンダーパラメーター

| パラメーター | 説明 |
| --- | --- |
| 宛先電話番号 | （必須）E.164形式の顧客の電話番号。 |
| キャンペーンID | アウトバウンド通信のキャンペーン識別子。値の長さは1～100文字である必要があります。 |
| クライアントトークン | 重複リクエストを防止するための、大文字と小文字を区別する一意の識別子。指定しない場合、AWS SDKによってこのフィールドに値が構成されます。最大長は500文字です。 |
| 説明 | エージェントのパネルに表示される音声コンタクトの説明。値の長さは0～4096文字である必要があります。 |
| 名前 | （必須）CCPに表示される音声コンタクト名。値の長さは0～1024文字である必要があります。 |
| 関連コンタクトID | タスクやチャットをリンクするための関連`contactId`。値の長さは1～256文字である必要があります。 |
| トラフィックタイプ | トラフィッククラス。指定可能な値：`GENERAL`または`CAMPAIGN`。 |

#### 留守番電話検出構成

| パラメーター | 説明 |
| --- | --- |
| 留守番電話のプロンプトを待機 | 留守番電話のプロンプトを待機するかどうかを示すブール値。 |
| 留守番電話検出を有効化 | 留守番電話の検出が必要かどうかを示すブール値。`true`の場合、**トラフィックタイプ**は`CAMPAIGN`である必要があります。 |
| 属性 | 属性マップを使用するカスタムのキーと値のペア。これらは標準のAmazon Connect属性であり、他のコンタクト属性と同様にフローからアクセスできます。コンタクトごとに、すべてのキーと値のペアを合わせて最大32,768 UTF-8バイトまで指定できます。属性キーには、英数字、ハイフン、およびアンダースコアのみを使用できます。 |

#### 参照

| パラメーター | 説明 |
| --- | --- |
| タイプ | 参照のタイプ。指定可能な値：`URL`、`NUMBER`、`STRING`、`DATE`、`EMAIL`。 |
| 値 | 参照に使用する有効な値。たとえば、Contact Control Panel（CCP）でエージェントに表示される、書式構成済みのURLです。タイプが`DATE`の場合、値はUnix Epoch時刻形式である必要があります。 |

### プロファイル属性を更新（標準およびバッチ）

#### バッチ制限

このアクションでは、バッチリクエストを使用して、ベンダーへの大容量データ転送をサポートできます。次のいずれかのしきい値に達するまで、リクエストはキューに格納されます。

* リクエストの最大数：500
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：5 MB

#### パラメーター

| パラメーター | 説明 |
| --- | --- |
| ストリーム名 | （必須）データの送信先となるストリームを選択します。IAMポリシーで`kinesis:ListStreams`権限が付与されていない場合は、カスタム値を手動で入力します。 |
| リージョンのオーバーライド | KinesisリージョンとConnectリージョンが異なる場合は、使用しているAWS Kinesisリージョンを選択します。 |

#### メッセージオプション

| パラメーター | 説明 |
| --- | --- |
| パーティションキー | （必須）データレコードをストリーム内のどのシャードに割り当てるかを決定します。 |
| 明示的ハッシュキー | （必須）データレコードを割り当てるシャードを明示的に決定するために使用します。 |
| 順序付け用シーケンス番号 | （必須）同じクライアントから同じパーティションキーに送信されるメッセージについて、シーケンス番号が厳密に増加することを保証します。 |

#### メッセージデータ

| パラメーター | 説明 |
| --- | --- |
| テンプレート変数 | （必須）テンプレートのデータ入力として使用するテンプレート変数を指定します。ネストされたテンプレート変数にはドット表記で名前を付けます。たとえば、`items.name`です。ネストされたテンプレート変数は通常、データレイヤーのリスト属性から構築されます。詳細および使用例については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。|
| テンプレート | （必須）データセクションで参照するテンプレートを指定します。テンプレートは、サポートされているフィールドに二重波括弧を使用して名前で挿入されます。たとえば、`{{SomeTemplateName}}`です。詳細および使用例については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。|
