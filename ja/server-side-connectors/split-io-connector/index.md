## API情報

このコネクターは、次のベンダーAPIを使用します。

* API名：Split API
* APIバージョン：v2
* APIエンドポイント：`https://api.split.io`
* ドキュメント：[Split API](https://docs.split.io/reference/introduction)

## 構成

コネクターマーケットプレイスに移動し、新しいコネクターを追加します。詳しくは、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクターを追加した後、次の項目を構成します。

* **管理者APIキー**  
  * セグメントへのユーザーの追加およびセグメントからのユーザーの削除に必要な管理者APIキーです。詳しくは、[Split.io：APIキー](https://help.split.io/hc/en-us/articles/360019916211-API-keys)を参照してください。
* **SDK APIキー**  
  * 「イベントを送信」アクションに必要なSDK APIキーです。詳しくは、[Split.io：APIキー](https://help.split.io/hc/en-us/articles/360019916211-API-keys)を参照してください。
* **ワークスペースID**  
  * （必須）環境のプロジェクトまたはワークスペースのID（`wsId`）です。
* **環境ID**  
  * この接続で使用する環境です。

### セグメントの作成

セグメントを作成するには、次の手順を実行します。

1. **セグメントを作成**をクリックします。
1. セグメントの**名前**を入力します。
1. セグメントの**説明**を入力します。
1. **トラフィックタイプID**を選択します。
1. **作成**をクリックします。
1. **完了**をクリックします。

### トラフィックタイプの作成

トラフィックタイプを作成するには、次の手順を実行します。

1. **トラフィックタイプを作成**をクリックします。
1. トラフィックタイプの**名前**を入力します。
1. **作成**をクリックします。
1. **完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| セグメントにユーザーを追加 | ✓ | ✗ |
| セグメントにユーザーを追加（バッチ） | ✓ | ✗ |
| セグメントからユーザーを削除 | ✓ | ✗ |
| セグメントからユーザーを削除（バッチ） | ✓ | ✗ |
| イベントを送信 | ✗ | ✓ |
| イベントを送信（バッチ） | ✗ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメーターとオプションの構成方法について説明します。

### バッチの上限

このアクションでは、ベンダーへの大量データ転送に対応するため、リクエストをバッチ処理します。詳しくは、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルが公開されるまで、リクエストはキューに保持されます。

* リクエストの最大数：10,000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：1 MB
