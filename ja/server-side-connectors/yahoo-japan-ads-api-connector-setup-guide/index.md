## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Yahoo! JAPAN API
* APIバージョン：v20
* APIエンドポイント：`https://ads-display.yahooapis.jp`
* ドキュメント：[Yahoo! JAPAN API](https://ads-developers.yahoo.co.jp/developercenter/en/)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタの追加方法に関する一般的な手順については、[コネクタについて](https://docs.tealium.com/ja/server-side/connectors/manage/)の記事を参照してください。

コネクタを追加した後、次の項目を構成します。

* **クライアントID**：（必須）アプリケーションのクライアントID。
* **クライアントシークレット**：（必須）アプリケーションのクライアントシークレット。

コネクタの構成が完了したら、**完了**をクリックします。

## バッチ処理の上限

このコネクタでは、ベンダーへの大量のデータ転送をサポートするため、リクエストをバッチ処理します。並列処理により、イベントが送信順とは異なる順序でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに保持されます。

* リクエストの最大数：200
* 最も古いリクエストからの最大経過時間：360分
* リクエストの最大サイズ：10 MB

## アクション

|アクション名|訪問プロファイル|イベントデータ|
|---|---|---|
|ユーザーリストを追加|✓|✗|

**続行**をクリックして、コネクタのアクションを構成します。アクションの名前を入力し、アクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### ユーザーリストを追加

#### 標準パラメータ

|**パラメータ**|**説明**|
|---|---|
|アカウントID|（必須）アカウントID。|
|オーディエンスリストID|（必須）オーディエンスリストID。|
|ベースアカウントID|（必須）アカウントIDがMCCアカウントの場合のベースアカウントID。|

#### ユーザーID

|**パラメータ**|**説明**|
|---|---|
|メールアドレス（SHA256でハッシュ化済み）|前後の空白を削除し、小文字に変換してからSHA256でハッシュ化したメールアドレスを指定します。|
|メールアドレス（SHA256ハッシュを適用）|プレーンテキストのメールアドレスを指定します。コネクタによって前後の空白が削除され、小文字に変換された後、SHA256でハッシュ化されます。|
|IDFA|iOSデバイス用の広告識別子。|
|AAID|Androidデバイス用の広告識別子。|
|不明|不明な値。|
