## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **スクリプトID** &ndash; （必須）トラッキング対象アプリケーションの識別子。
* **パートナーID** &ndash; （必須）トラッキングシステムの識別子。
* **パートナーシステム** &ndash; （必須）トラッキングシステムの分かりやすい名前。
* **エンジンベースURL** &ndash; （必須）エンジンベースURLを選択するか、トラッキングAPIのURLをカスタムテキストとして指定します。

## アクション

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

以下のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### イベントをトラッキング

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| イベント名 | （必須）イベント名。 |
| ページ名 | （必須）ページ名。 |
| 訪問ID | 訪問の一意の識別子。このフィールドがマッピングされていない場合、**tealium_visitor_id**に自動的にマッピングされます。 |
| ページURL | 現在のページのURL。このフィールドがマッピングされていない場合、**Current URL**に自動的にマッピングされます。 |
| 参照元URL | ユーザーが直前にアクセスしたURL。このフィールドがマッピングされていない場合、**Referring URL**に自動的にマッピングされます。 |
| ユーザーエージェント | クライアントのユーザーエージェント。このフィールドがマッピングされていない場合、**User Agent**に自動的にマッピングされます。 |
| テンプレート変数 | **テンプレート**のデータ入力としてテンプレート変数を指定します。詳細については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。ネストされたテンプレート変数には、ドット表記で名前を付けます。例：**items.name**。ネストされたテンプレート変数は通常、データレイヤーのリスト属性から作成されます。 |
| テンプレート | トラッキングデータパラメータで参照するテンプレートを指定します。詳細については、[Trimouテンプレートエンジンガイド]()を参照してください。テンプレートは、二重波括弧で囲んだ名前を使用して、サポートされているフィールドに挿入されます。例：**&#123;&#123;TemplateName&#125;&#125;**。 |
