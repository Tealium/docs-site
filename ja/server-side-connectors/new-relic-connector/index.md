## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を行います。
* **APIキー**
  * New Relicのライセンスキー。ブラウザキー、モバイルキー、ユーザーキーはサポートされていません。
* **アカウントID**
  * New RelicのアカウントID。
* **リージョン**
  * アカウントが属するリージョン：**EU**または**US**。

コネクタを構成したら、**完了**をクリックします。

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| イベントタイプ | イベントの名前。 |
| タイムスタンプ | Unixエポックからの経過秒数またはミリ秒数で表したイベントの時刻。指定しない場合、デフォルト値は送信時刻です。 |
| 整形表示 | デフォルトでは、属性キーが使用されます。代わりに属性名をキーとして使用するには、このチェックボックスを有効にします。属性名を更新すると、ペイロード内の名前にも変更が反映されることに注意してください。 |

### イベントデータ全体を送信（バッチ）

#### バッチの制限

このアクションは、ベンダーへの大量データ転送に対応するため、バッチリクエストを使用します。次のいずれかのしきい値に達するまで、リクエストはキューに格納されます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：60分

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| イベントタイプ | イベントの名前。 |
| タイムスタンプ | Unixエポックからの経過秒数またはミリ秒数で表したイベントの時刻。指定しない場合、デフォルト値は送信時刻です。 |
| 整形表示 | デフォルトでは、属性キーが使用されます。代わりに属性名をキーとして使用するには、このチェックボックスを有効にします。属性名を更新すると、ペイロード内の名前にも変更が反映されることに注意してください。 |
| バッチの有効期間 | バッチアクションを送信する頻度を指定するには、有効期間（TTL）を構成します。`1`～`60`分の値を入力します。デフォルトは`10`分です。 |

### セキュリティデータイベントを送信

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| リポジトリ | 統合対象のアプリのリポジトリURL。 |

#### セキュリティメタデータ

| **パラメータ** | **説明** |
| --- | --- |
| `source` | このイベントを生成したセキュリティツールのわかりやすい名前（例：Snyk、Dependabot）。 |
| `title` | 問題の短い要約（50～100文字）。 |
| `message` | 説明および修正ガイダンスを含む、問題の詳細な説明。Markdown形式を含めることができます。 |

#### 問題の分類

| **パラメータ** | **説明** |
| --- | --- |
| `issueType` | サポートされる問題タイプ：`Library Vulnerability`、`Container Vulnerability`、`Host Vulnerability`。 |
| `issueId` | 問題の標準識別子（例：`CVE`、`CWE`、`CIS`ベンチマークルール）。 |
| `severity` | 定義済みの重大度レベル：`CRITICAL`、`HIGH`、`MEDIUM`、`LOW`、`INFO`。 |

#### エンティティの関連付け

| **パラメータ** | **説明** |
| --- | --- |
| `entityType` | 報告された問題をNew Relic内の既知のエンティティ（例：ホスト、リポジトリ、AWS）に関連付けるために使用します。 |
| `entityLookupValue` | 指定されたタイプに該当する適切なエンティティを検索するために使用します。 |
| `entityGuid` | New Relic内の特定のエンティティを示す一意の識別子。 |
#### CVSSv3

| **パラメーター** | **説明** |
| --- | --- |
| `cvssScore` | CVE に割り当てられた CVSSv3 スコア。 |
| `cvssVector` | CVE を記述する CVSSv3 ベクトル。 |

#### 課題追跡

| **パラメーター** | **説明** |
| --- | --- |
| `issueInstanceKey` | この課題の特定の発生を識別する一意の識別子。 |
| `issueVendorID` | `issueId` と異なる場合の、課題に対するベンダー固有の識別子。 |
| `disclosureURL` | 課題に関する追加情報の URL（ベンダーの Web サイト、公開情報源など）。 |

#### 修復ガイダンス

| **パラメーター** | **説明** |
| --- | --- |
| `remediationExists` | この課題に対する既知の修正が存在するかどうかを示します（`true` または `false`）。 |
| `remediationRecommendation` | 課題を解決するための簡潔なガイダンス（例：`Upgrade PACKAGE_NAME to X.Y.Z`）。 |
| イベントメタデータ | 課題が検出された時刻のタイムスタンプ（エポックからのミリ秒数）。デフォルトは、データが New Relic に送信された時点です。 |
| カスタムフィールド | ログに含める追加のカスタムフィールドをマッピングします。 |

### ログイベント全体を送信する

#### バッチ制限

このアクションでは、ベンダーへの大量データ転送に対応するため、リクエストをバッチ処理します。リクエストは、次のいずれかのしきい値に達するまでキューに保持されます。

* リクエストの最大数：10,000
* 最も古いリクエストからの最大経過時間：60 分
* リクエストの最大サイズ：1 MB

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| タイムスタンプ | エポックからのミリ秒数または秒数（整数）、あるいは ISO 8601 形式のタイムスタンプ（文字列）。指定しない場合は取り込み時刻がデフォルトになります。 |
| ログタイプ | ログを識別し、解析ルールと照合するための主要フィールド。 |
| カスタムフィールド | ログメッセージの属性になります。 |
