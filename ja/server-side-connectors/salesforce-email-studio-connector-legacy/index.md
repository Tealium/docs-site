## 前提条件

Salesforce Email Studio（ExactTarget）コネクタを構成するには、以下の項目が必要です。

* **ユーザー名**
  * ExactTarget Marketing Cloud のユーザー名を入力します。
  * 詳細については、次の ExactTarget 開発者向けドキュメントを参照してください：[SOAP Web Services API の概要](https://developer.salesforce.com/docs/atlas.en-us.noversion.mc-apis.meta/mc-apis/getting_started_developers_and_the_exacttarget_api.htm)。

* **パスワード**
  * ExactTarget Marketing Cloud のパスワード。

* **サーバーホスト名**
  * （必須）ExactTarget Marketing Cloud のサーバーホスト名を入力します。
  * サーバーホスト名が不明な場合は、ExactTarget Marketing Cloud の担当者にお問い合わせください。
  * サーバーホストを入力する際は、プロトコルとパスを含めないでください。たとえば、`webservice.exacttarget.com` のみを入力します。

* **IP ホワイトリスト**
  * （任意）ExactTarget Marketing Cloud でホワイトリストが有効になっている場合は、該当する IP アドレスをホワイトリストに登録するようシステムを構成します。
  * 通常、これはデフォルト構成です。

## コネクタ構成の要件

ExactTarget Marketing Cloud API には、Simple Object Access Protocol（SOAP）と Representational State Transfer（REST）という 2 つの Web サービス通信プロトコルがあります。Tealium Salesforce Email Studio（ExactTarget）コネクタは SOAP を使用します。SOAP 呼び出しは、アクセストークンまたはユーザー名とパスワードを使用して認証できます。Tealium コネクタでは、ユーザー名とパスワードによる認証方式を使用します。

詳細については、[SOAP Web Services API の概要](https://developer.salesforce.com/docs/atlas.en-us.mc-apis.meta/mc-apis/getting_started_developers_and_the_exacttarget_api.htm)の「Authenticate with Username Token」を参照してください。

コネクタを構成するには、次の認証情報が必要です。

* ExactTarget Marketing Cloud アカウントへのアクセスに使用するユーザー名とパスワード
* `http://webservice.s10.exacttarget.com/` などのサーバーホスト名

## 構成の構成

コネクタマーケットプレイスに移動し、新しい Salesforce Email Studio（ExactTarget）コネクタを追加します。コネクタを追加する一般的な手順については、[コネクタの概要](https://docs.tealium.com/ja/server-side/connectors/manage/)を参照してください。

ベンダーを構成するには、次の手順を実行します。

1. **Configure** タブで、内容が分かるタイトルを入力します。
1. ExactTarget Marketing Cloud アカウントのユーザー名、パスワード、およびホスト名を入力します。  

<blockquote>
ホスト名に `http` または `https` プロトコルを含めないでください。
</blockquote>


1. （任意）Salesforce Email Studio（ExactTarget）コネクタの構成に関する説明メモを入力します。

| 非同期処理 | <ul><li>非同期処理をサポートします。デフォルトでは無効になっています。</li><li>大量のデータを処理する場合は、このオプションを有効にします。</li><li>非同期処理を有効にするには、このオプションを選択します。</li><li>API呼び出しは、受信時に直接処理されるのではなく、処理前にキューに登録されます。</li><li>非同期API呼び出しは通常、より迅速に完了します。また、キューに登録された基盤処理が後で失敗した場合でも、常に成功レスポンスを返します。</li><li>詳細については、[非同期処理](https://developer.salesforce.com/docs/atlas.en-us.noversion.mc-apis.meta/mc-apis/asynchronous_processing.htm)を参照してください。</li></ul> |

このアクションでは、ベンダーへの大量のデータ転送をサポートするため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルが公開されるまで、リクエストはキューに格納されます。

* リクエストの最大数：1000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：1 MB
