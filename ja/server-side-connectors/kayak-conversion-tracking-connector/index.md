## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の構成を構成します。

## アクション構成 — パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### アクション — コンバージョンを送信
#### パラメータ

| **パラメータ**          | **説明**                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:-----------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| KAYAKクリックID         | <ul><li>（必須）お客様のサイトに送信されたクリック／リードを識別するKAYAK固有の識別子。</li><li>この値では大文字と小文字が区別されます。</li></ul>                                                                                                                                                                                                                                                                                                  |
| 予約ID             | <ul><li>（必須）予約を識別するお客様固有の識別子。</li><li>予約ごとに一意である必要があり、以降のすべてのレポートで使用してください。</li></ul>                                                                                                                                                                                                                                                                  |
| KAYAKコミッション       | <ul><li>（必須）予約によってKAYAKが獲得したコミッション。コミッション通貨パラメータで指定された通貨を使用します。</li><li>`$`などの通貨記号を含めないでください。</li><li>小数点以下6桁までに制限してください。</li></ul>                                                                                                                                                                                                           |
| コミッション通貨    | <ul><li>（必須）KAYAKコミッションの通貨。</li><li>可能であれば、KAYAKへのコミッションの支払いに使用する通貨を指定してください。</li><li>[ISO 4217](https://en.wikipedia.org/wiki/ISO_4217)コードを使用してください。</li></ul>                                                                                                                                                                                                           |
| コンバージョン日時        | <ul><li>（任意）予約が最初に行われた日時。レポートのタイムゾーンを使用します。</li><li>[W3Cによって簡略化されたISO 8601形式](https://www.w3.org/TR/NOTE-datetime)である`YYYY-MM-DDThh:mm:ssTZD`形式を使用してください。</li><li>指定しない場合は、現在のタイムスタンプが使用されます。</li></ul>                                                                                                                                     |
| 価格                  | <ul><li>予約の総額。通貨パラメータで指定された通貨を使用します。</li><li>`$`などの通貨記号を含めないでください。</li><li>小数点以下6桁までに制限してください。</li></ul>                                                                                                                                                                                                                                            |
| 通貨               | <ul><li>価格の通貨。</li><li>[ISO 4217](https://en.wikipedia.org/wiki/ISO_4217)コードを使用してください。</li><li>価格パラメータを使用する場合、このパラメータは必須です。</li></ul>                                                                                                                                                                                                                                                         |
| 予約タイプ           | <ul><li>予約のタイプ。</li><li>`flight`、`hotel`、`car`、`package`、`cruise`、`train`、`restaurant`、`activity`のいずれかである必要があります。</li></ul>                                                                                                                                                                                                                                                                                              |
| コミッション率  | <ul><li>コミッションの計算時にこの予約へ適用されるコミッション率。</li><li>`0`から`1`までの小数で指定し、小数点以下6桁までに制限してください。</li></ul>                                                                                                                                                                                                                                                          |
| タグ1                  | <ul><li>追加データ用のカスタムフィールド。</li></ul>                                                                                                                                                                                                                                                                                                                                                                                         |
| タグ2                  | <ul><li>追加データ用のカスタムフィールド。</li></ul>                                                                                                                                                                                                                                                                                                                                                                                         |
| チェックイン日          | <ul><li>予約のチェックイン日。</li><li>`yyyy-mm-dd`形式を使用してください。</li><li>施設の現地タイムゾーンを使用してください。</li></ul>                                                                                                                                                                                                                                                                                                  |
| チェックアウト日         | <ul><li>予約のチェックアウト日。</li><li>`yyyy-mm-dd`形式を使用してください。</li><li>施設の現地タイムゾーンを使用してください。</li></ul>                                                                                                                                                                                                                                                                                                       |
| HID                    | <ul><li>予約された施設を識別するお客様固有の識別子。これは、当社に提供されるデータフィード内およびAPIで使用される識別子と同じものです。</li></ul>                                                                                                                                                                                                                                                                                                 |
| 旅行者数    | <ul><li>旅行者の合計人数（全年齢）。</li></ul>
| 客室数 | <ul><li>予約された客室の数。</li></ul> |
| 出発空港 | <ul><li>予約された旅程の最初の出発空港の[IATAコード](https://en.wikipedia.org/wiki/IATA_airport_code)。</li></ul> |
| 到着空港 | <ul><li>予約された旅程の最初の区間における到着空港の[IATAコード](https://en.wikipedia.org/wiki/IATA_airport_code)。</li></ul> |
| 運賃クラス | <ul><li>予約内の各セグメントの運賃基準コードをカンマで区切ったリスト。</li><li>出発日順に並べる必要があります。</li><li>すべてのフライトセグメントで同じ運賃基準コードを共有する場合は、単一の値を使用できます。</li><li>複数の運賃クラスを追加するには、配列型属性をマッピングします。</li><li>単一の運賃クラスを追加するには、単一値属性をマッピングします。</li></ul> |
| キャビンクラス | <ul><li>予約内の各セグメントで予約されたキャビンクラスをカンマで区切ったリスト。</li><li>指定可能な値は、`First`、`Business`、`Premium Economy`、または`Economy`です。</li><li>出発日順に並べる必要があります。</li><li>すべてのフライトセグメントで同じキャビンクラスを共有する場合は、単一の値を使用できます。</li><li>複数のキャビンクラスを追加するには、配列型属性をマッピングします。</li><li>単一のキャビンクラスを追加するには、単一値属性をマッピングします。</li></ul> |
| 区間インデックス | <ul><li>0から始まる区間番号。</li></ul> |
| セグメントインデックス | <ul><li>0から始まるセグメント番号。</li></ul> |
| 出発空港コード | <ul><li>出発空港コード</li></ul> |
| 到着空港コード | <ul><li>到着空港コード</li></ul> |
| 出発日時 | <ul><li>`yyyy-mm-dd`形式を使用します。</li></ul> |
| 到着日時 | <ul><li>`yyyy-mm-dd`形式を使用します。</li></ul> |
| 航空会社コード | <ul><li>[IATAコード](https://en.wikipedia.org/wiki/IATA_airport_code)</li></ul> |
| フライト番号 | <ul><li>フライト番号。</li><li>複数のフライト旅程を追加するには、配列型属性をマッピングします。</li><li>配列型属性の長さはすべて同じである必要があります。</li><li>単一のフライト旅程を追加するには、単一値属性をマッピングします。</li></ul> |
| レンタカー貸出日 | <ul><li>貸出場所の現地タイムゾーンにおけるレンタカーの貸出日。</li><li>`yyyy-mm-dd`形式を使用します。</li></ul> |
| レンタカー返却日 | <ul><li>返却場所の現地タイムゾーンにおけるレンタカーの返却日。</li><li>`yyyy-mm-dd`形式を使用します。</li></ul> |
| レンタカー貸出場所ID | <ul><li>この予約の貸出場所を示すお客様固有の識別子。これは当社へのデータフィードで提供され、APIで使用されるものと同じです。</li></ul> |
| レンタカー返却場所ID | <ul><li>この予約の返却場所を示すお客様固有の識別子。これは当社へのデータフィードで提供され、APIで使用されるものと同じです。</li></ul> |
| レンタカー会社 | <ul><li>この予約におけるレンタカー会社の一意の識別子。弊社に提供されたデータフィード内の識別子と同一であり、API でも使用されます。</li></ul> |
