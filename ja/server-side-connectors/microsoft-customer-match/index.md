## 要件

* Microsoft Ads アカウント
* Microsoft Ads テナント内でスーパー管理者権限または書き込みアクセス権を持つ Microsoft ユーザー。
    * 認証に使用するユーザーは、個人用 Microsoft アカウント（MSA）である必要があります。
    * 勤務先のメールアドレスを使用できますが、SSO 経由でアクセスするのではなく、個人用アカウントとして登録する必要があります。組織で Microsoft へのログインに SSO または MFA を使用している場合でも、勤務先のメールアドレスを個人用アカウントとして登録すれば使用できます。登録時に、**個人用アカウントを使用する**を選択してください。
* アカウントの地域でカスタマーマッチが有効化および承認されていること。詳細については、[Microsoft：カスタマーマッチ - 独自のデータを使用して顧客を見つける](https://help.ads.microsoft.com/#apex/ads/en/56921/1)を参照してください。

### Microsoft の利用規約への同意

Tealium への認証に使用する Microsoft ユーザーがビジネスアカウントに新しく追加されたユーザーである場合、最初に以下を実行する必要があります。

1. そのユーザーで Microsoft Ads にサインインします。
1. オーディエンスを一度手動で作成し、Microsoft Customer Match の利用規約への同意を行います。

これらの規約に同意するまでは、アクション構成で **Customer Match の規約に同意する**チェックボックスが有効になっていない場合、API によってオーディエンス作成またはメンバーシップ更新リクエストが拒否されることがあります。

## API 情報

このコネクタでは、次のベンダー API を使用します。

* API 名：Campaign Management API
* API バージョン：v13
* API エンドポイント：`https://campaign.api.bingads.microsoft.com/CampaignManagement/v13/`
* ドキュメント：[Microsoft：Campaign Management API](https://learn.microsoft.com/en-us/advertising/campaign-management-service/campaign-management-service-reference?view=bingads-13)

## バッチ制限

このコネクタでは、ベンダーへの大量データ転送をサポートするため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数：1,000
* 最も古いリクエストからの最大経過時間：60 分
* リクエストの最大サイズ：5 MB

Microsoft の Campaign Management REST API は、1 回のリクエストにつき最大 1,000 件の `CustomerListItems` を受け付けます。この上限に基づいて、これらのバッチしきい値が決まります。

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。

* **アカウント ID**：（必須）リクエスト内のエンティティを所有している、またはそれらに関連付けられている広告アカウントの識別子。広告主が Microsoft Ads UI にログインした際の URL（例：`AID=`）で確認できます。
* **顧客 ID**：（必須）ユーザーがアクセスしている、または操作元として使用しているマネージャーアカウント（顧客）の識別子。広告主が Microsoft Ads UI にログインした際の URL（例：`CID=`）で確認できます。

コネクタを構成したら、**完了**をクリックします。

**アカウント ID** と **顧客 ID** を構成した後、**接続を確立**をクリックして Microsoft のサーバーに接続します。

### カスタマーマッチリストの作成

このオプションを使用してカスタマーマッチリストを作成し、広告のターゲットとする登録者を追加します。このタスクは Campaign Management REST の `Audiences` エンドポイントを呼び出し、新しいリストの **オーディエンス ID** を同期的に返します。

**作成**をクリックした後、確認メッセージが表示されるまで待ちます。顧客リストが正常に作成されると、インターフェイスに **オーディエンス ID** が表示されます。**オーディエンス ID** をコピーし、アクション構成の **カスタマーマッチリスト ID** フィールドに貼り付けます。

| フィールド | 説明 |
| --- | --- |
| 名前 | （必須）顧客リストの名前。このフィールドには最大 128 文字まで入力できます。 |
| 説明 | （任意）顧客リストの説明。この顧客リストでターゲットにしているオーディエンスを把握しやすくするために説明を使用します。このフィールドには最大 1,024 文字まで入力できます。 |
| スコープ | （任意）顧客リストを作成するレベル。<ul><li>**アカウント**：コネクタ構成のアカウント ID の下にリストが作成され、このアカウント内の広告グループにのみ関連付けることができます。</li><li>**顧客**：コネクタ構成の顧客 ID の下にリストが作成され、その顧客のすべてのアカウントにわたって広告グループに関連付けることができます。</li><li>スコープが選択されていない場合は、**顧客**が使用されます。</li></ul> |
| メンバーシップ期間 | （任意）顧客リストを作成する際に、顧客リストの定義に一致するアクションを検索してユーザーをリストに追加するために、Microsoft Advertising がどの時点まで遡るかを指定できます。<ul><li>最短期間は `1` 日で、許可される最長期間は `390` 日です。</li><li>メンバーシップ期間が `-1` の場合、有効期限はありません。</li><li>メンバーシップ期間が null の場合、デフォルトの期間（30 日）が使用されます。</li></ul> |

### カスタマーマッチリストの確認

このオプションを使用してカスタマーマッチリストを検索し、そのメタデータを表示します。このタスクは Campaign Management REST の `Audiences/QueryByIds` エンドポイントを呼び出し、リストの名前、ID、スコープ、サイズを表示します。


<blockquote>
リストの作成後またはオーディエンスメンバーの追加後、最大 48 時間にわたり、サイズの値が「構築中」と表示されることがあります。
</blockquote>


| フィールド | 説明 |
| --- | --- |
| カスタマーマッチリスト ID | （必須）確認するカスタマーマッチリストの識別子。 |

## ユースケース

#### Microsoft の各種サービスを横断した高価値リマーケティング

Tealium からリアルタイムのオーディエンスリストを同期することで、Bing、MSN、Outlook、Edge 全体で高価値ユーザーセグメントをより高い精度でアクティベートします。ファーストパーティ識別子を活用した行動ベースのリマーケティングにより、マッチ率が向上し、ブラウザベースのトラッキングへの依存度が低下して、ROAS が向上します。

例：

* 商品を閲覧したもののコンバージョンに至らなかったカート放棄ユーザーに再アプローチします。
* 過去にブランドと接点を持ったユーザーに対してプロモーションをエンリッチメントします。
* CRM オーディエンスのリーチを Microsoft のネイティブ広告環境に拡大します。

#### 予算効率を高める除外リスト

コンバージョン済みユーザーを、見込み顧客獲得キャンペーンや部分一致キャンペーンから除外します。広告主は無駄な予算を削減し、コンバージョンの可能性がより高い新規ユーザーに広告費を振り向けることで、入札効率を高めることができます。

例：

* 最近購入したユーザーを新規顧客獲得キャンペーンから除外します。
* カスタマーサービスへの問い合わせや返金を申請したユーザーを除外します。
* 離脱したユーザーや登録解除したユーザーを削除します。

#### ライフサイクルおよび CRM から広告へのアクティベーション

ロイヤルティ階層、サブスクリプションのステータス、顧客ライフサイクルの段階を CDP から Microsoft Ads に直接同期します。これにより、顧客生涯価値と顧客ステージに基づいてユーザーごとに異なるターゲティングを行うという、強力な入札戦略が可能になります。

例：

* VIP 限定アップセルキャンペーン向けのロイヤルティ階層。
* サブスクリプション更新のリマインダー。
* 既知の店舗顧客をデジタルリマーケティングキャンペーンの対象にします。

#### オムニチャネルのパーソナライゼーション

ハッシュ化されたファーストパーティ識別子を同期し、オフラインとオンラインのインタラクションを連携させます。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| ユーザーをオーディエンスに追加 | ✓ | ✗ |

### ユーザーをオーディエンスに追加
#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |

| カスタマーマッチ規約に同意 | （任意）このリクエストで広告主に代わって [Microsoft カスタマーマッチ規約](https://go.microsoft.com/fwlink/?linkid=2106709) にプログラムによって同意するには、このチェックボックスを選択します。このチェックボックスをオフにした場合は、顧客リストデータをアップロードする前に、Microsoft Ads UI で規約に手動で同意する必要があります。詳細については、[Microsoft のサービス利用規約への同意](#accept-microsoft-terms-of-service)を参照してください。 |
