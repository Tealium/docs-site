## 要件

LINEコネクタには、以下が必要です。

* LINE：チャネルアクセストークン。詳細については、[Messaging APIの概要](https://developers.line.biz/en/docs/messaging-api/overview/)を参照してください。

## API情報

このコネクタでは、以下のベンダーAPIを使用します。

* API名：LINE Messaging API
* APIバージョン：v2
* APIエンドポイント：`https://api.line.me/v2`
* ドキュメント：[LINE：オーディエンスAPI](https://developers.line.biz/en/docs/messaging-api/)

## バッチ処理の制限

このアクションでは、ベンダーへの大量データ転送をサポートするため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。以下のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数：10,000
* 最も古いリクエストからの最大経過時間：30分
* リクエストの最大サイズ：1 MB

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

ベンダーを構成するには、以下の手順に従います。

1. **Configure**タブで、コネクタインスタンスのタイトルを指定します。
1. アカウント用にLINEで構成したチャネルアクセストークンを入力します。
1. 実装に関する追加のメモを入力します。

### プッシュメッセージ - テンプレートメッセージ（ボタンテンプレート）

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| コンタクト ID | （必須）LINE Business Center の **Channel Console** で構成された Webhook から受信した ID。この ID は、ユーザーがアカウントの追加やメッセージの送信などの操作を行った際に、Webhook URL へ送信される HTTPS POST リクエストに含まれます。 |
| 代替テキスト | （必須）メッセージの代替テキスト。テキストは 400 文字以内である必要があります。このテキストは、通知やチャットリストに表示されます。 |
| テンプレート - テキスト | （必須）メッセージのテキスト。画像もタイトルもない場合は 400 文字以内、画像またはタイトルがある場合は 60 文字以内である必要があります。 |
| テンプレート - サムネイル画像 URL | （必須）画像のサムネイルの URL。URL は 2,000 文字以内で、HTTPS プロトコルを使用する必要があります。 |
| テンプレート - 画像のアスペクト比 | （必須）画像のアスペクト比。指定できる値は `rectangle` または `square` です。デフォルト値は `rectangle` です。 |
| テンプレート - 画像サイズ | （必須）画像のサイズ。指定できる値は `cover` または `contain` です。デフォルト値は `cover` です。 |
| テンプレート - 画像の背景色 | （必須）16 進数形式で指定する画像の背景色。デフォルト値は `#FFFFFF`（白）です。 |
| テンプレート - タイトル | （必須）メッセージのタイトル。タイトルは 40 文字以内である必要があります。 |
