## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を構成します。

* **収集ドメイン**：（必須）組織の収集エンドポイント。
* **収集パス**：（必須）収集パス。
* **サイトID**：（必須）データソースのサイトID。

コネクタの構成が完了したら、**完了**をクリックします。

## アクション

|アクション名|訪問プロファイル|イベントデータ|
|---|---|---|
|イベントを送信|✓|✓|

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。Piano Analyticsコネクタのパラメータの詳細については、[Piano Analytics：Collection API](https://developers.atinternet-solutions.com/piano-analytics/data-collection/how-to-send-events/collection-api#marketing-campaigns)のドキュメントを参照してください。

### バッチ制限

このコネクタでは、ベンダーへの大容量データ転送をサポートするために、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数：100
* 最も古いリクエストからの最大経過時間：5分
* リクエストの最大サイズ：1 MB

### イベントを送信

#### パラメータ

|パラメータ|説明|
|---|---|
|イベントタイプ|すべての[標準イベント](https://developers.atinternet-solutions.com/piano-analytics/data-collection/how-to-send-events/standard-events)がサポートされています。標準以外のカスタムイベントを送信するには、**カスタム**オプションを選択し、**イベントプロパティ**セクションで**カスタムイベントタイプ**の値を指定します。|

#### イベントプロパティ

|パラメータ|説明|
|---|---|
|日付形式|イベントプロパティを構成するときに使用する[日付形式](https://developers.atinternet-solutions.com/piano-analytics/data-collection/how-to-send-events/collection-api#date)を指定します。<br>UTCエポックからの経過ミリ秒（またはCDH日付属性）のみ書式構成できます。それ以外の場合、アクションは失敗します。<br>有効な日付形式は、`YYYYMMDD`、`YYYY-MM-DD`、`YYYY-MM-DDTHH:mm:ssZ`、`UNIX`です。|

#### 標準パラメータ

|パラメータ|説明|
|---|---|
|IPアドレス|クライアントのIPアドレス。|
|リファラー|データを送信するページのアドレス。|
|サイトID|データが属するサイトのID。このパラメータの値が空でない場合、**構成**タブで定義されている値を上書きします。|
|ユーザーエージェント|クライアントのユーザーエージェント。このフィールドがマッピングされていない場合、Event Streaming API HubではUser Agent属性に、Customer Data Platform（CDP）では訪問の最新のUser Agent属性に自動的にマッピングされます。|
|訪問ID|訪問の一意の識別子。このフィールドがマッピングされていない場合、Tealium Visitor IDに自動的にマッピングされます。|

#### 共通コンテキストプロパティ

Piano Analyticsでは、分析をエンリッチメントするために追加のプロパティを使用することを推奨しています。

|パラメータ|説明|
|---|---|
|前のURL|前のページのURL。このフィールドがマッピングされていない場合、Event StreamingではCurrent URL属性に、Customer Data Platform（CDP）ではEntry URL属性に自動的にマッピングされます。|
|デバイスのUTCタイムスタンプ|デバイスのUTCタイムスタンプ（秒単位）。日付属性はUNIXタイムスタンプに変換されます。|
|イベント収集プラットフォーム|使用された収集プラットフォーム。|
|イベント収集バージョン|収集プラットフォームのバージョン。|
|デバイスメーカー|デバイスのメーカー。|
|デバイスモデル|デバイスのモデル。|
|デバイス表示領域の高さ|ビューポートの高さ。|
|デバイス表示領域の幅|ビューポートの幅。|
|デバイス画面の高さ|デバイス画面の高さ。|
|デバイス画面の幅|デバイス画面の幅。|

#### マーケティングキャンペーンプロパティ

マーケティングキャンペーンを追跡するには、このセクションのフィールドをマッピングします。

|パラメータ|説明|
|---|---|
|キャンペーンメディア|マーケティングキャンペーンの追跡に必要なプロパティ。|
|キャンペーン名|マーケティングキャンペーンの追跡に必要なプロパティ。|
|キャンペーン作成|キャンペーンの作成情報。使用例については、[Piano Analytics Collection API](https://developers.atinternet-solutions.com/piano-analytics/data-collection/how-to-send-events/collection-api#marketing-campaigns)のドキュメントを参照してください。|
|キャンペーンバリアント|キャンペーンのバリアント。|
|キャンペーン形式|キャンペーンの形式。|
|キャンペーンタイプ|キャンペーンのタイプ。|

#### ユーザープロパティ

|パラメータ|説明|
|---|---|
|ユーザーID|認証済みユーザーを追跡するには、このフィールドをマッピングします。|
|ユーザーカテゴリ|認証済みユーザーを追跡するには、このフィールドをマッピングします。|

#### 目標プロパティ

|パラメータ|説明|
|---|---|
|目標タイプ|コンバージョンを追跡するには、目標タイプを構成します。|

#### 拡張マーケティングソース検出

|パラメータ|説明|
|---|---|
|ソースコンテンツ|マーケティングキャンペーンのコンテンツの詳細（広告コピーやクリエイティブラベルなど）を取得します。|
|クリエイティブ形式|キャンペーンで使用されたクリエイティブ形式を識別します。|
|ソースID|特定のキャンペーンを追跡するための一意の識別子。|
|マーケティング施策|使用されたマーケティング施策を記録します。|
|ソース|主要なトラフィックソースを示します。|
|ソースプラットフォーム|ソースの発生元となったプラットフォームを指定します。|
|ソースキーワード|検索語句またはキーワードを取得します。|
|イベント自動収集|イベント収集が自動的にトリガーされたかどうかを追跡します。|
|国|（Alpha-`2`）地域別レポート用のISO 3166 Alpha-2国コードを提供します。|
