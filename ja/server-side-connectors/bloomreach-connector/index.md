## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Bloomreach API
* APIバージョン：v2.0
* APIエンドポイント：`https://api-engagement.bloomreach.com`
* ドキュメント：[Bloomreach API](https://documentation.bloomreach.com/engagement/reference/about)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。
* **APIキー**  
APIキー。
* **APIシークレット**  
APIシークレット。
* **プロジェクトトークン**  
プロジェクトトークン。Engagement Webアプリの**プロジェクト構成 > アクセス管理 > API**で確認できます。
* **APIドメイン**  

コネクタを構成したら、**完了**をクリックします。
Bloomreach APIドメイン。デフォルト値は`https://api-engagement.bloomreach.com`です。

## バッチ制限

このアクションでは、ベンダーへの大容量データ転送に対応するため、リクエストをバッチ処理します。詳細については、「バッチアクション」を参照してください。次のいずれかのしきい値に達するか、プロファイルが公開されるまで、リクエストはキューに格納されます。

* リクエストの最大数：50
* 最も古いリクエストからの最大経過時間：5分
* リクエストの最大サイズ：30 MB

#### メールコンテンツ

| **パラメータ** | **説明** |
| --- | --- |
| テンプレートID | 送信するメールテンプレートのID。選択した定義済みテンプレートのURLで確認できます。 |
| 件名 | メールの件名を定義します。このフィールドではJinjaは評価されません。 |
| 送信者アドレス | 送信者のメールアドレス。 |
| 送信者名 | 通常は送信者の名です。 |
| 添付ファイル名 | 添付ファイルの名前。 |
| 添付ファイルのコンテンツ | Base64でエンコードされたファイルのコンテンツ。 |
| 添付ファイルのコンテンツタイプ | 添付ファイルの形式。 |
| HTML | `<html>`タグと`</html>`タグの間に配置するメールコンテンツを定義します。CSSコンテンツを含めることもできます。このフィールドではJinjaは評価されません。 |
| メールコンテンツパラメータ | テンプレートで使用するメールのパーソナライズに必要なすべてのデータを指定します。形式：`param_name`:"value"。例：`first_name`:"Marian" |
| キャンペーン名 | メールキャンペーンの名前。 |

| **パラメータ** | **説明** |
| --- | --- |

| 言語 | テンプレートの言語バージョン。テンプレートに複数の言語バージョンが作成されている場合は、このメールで使用するバージョンを選択できます。 |

#### 受信者の顧客ID

| **パラメータ** | **説明** |
| --- | --- |
| ID転送 | リンクによるID転送機能を有効にするかどうか。指定可能な値：<ul><li>`Enabled` - デフォルト値。すべてのクリックでユーザーを識別する`iitt`パラメータを追加します。</li><li>`Disabled` - リンクに何も追加せず、IDを転送しません。</li><li>`First Click` - 最初のクリック時にのみユーザーを識別する`xnpe_tifc`を追加します。</li></ul> |

#### メールテンプレート構成

| **パラメータ** | **説明** |
| --- | --- |
| ユーザーIDを転送 | リンクによるID転送機能を有効にするかどうか。指定可能な値：<ul><li>`enabled`（デフォルト値）</li><li>`disabled`</li><li>`iitt` - リンクにIDを転送しません。</li></ul> この構成は、リクエスト本文に直接指定する`transferidentity`パラメータと同じです。指定できるのはいずれか一方のみであることに注意してください。構成内と単独の両方でID転送を指定すると、エラーになります。 |
| 同意カテゴリー | Engagementプラットフォームの同意構成を尊重するには、顧客の同意カテゴリーを指定します。 |
| トラッキング同意カテゴリー | Engagementプラットフォームのトラッキング同意構成を尊重するには、顧客のトラッキング同意カテゴリーを指定します。 |
| メールテンプレートのカスタムイベントプロパティ | カスタム属性。 |
