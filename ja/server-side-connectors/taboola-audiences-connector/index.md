## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Taboola API
* APIバージョン：v1.0
* APIエンドポイント：`https://backstage.taboola.com/backstage/api/1.0`
* ドキュメント：[Taboola API](https://developers.taboola.com/backstage-api/reference/add-or-remove-users)

## バッチ制限

このコネクタは、ベンダーへの大容量データ転送に対応するため、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに保持されます。

* リクエストの最大数：10000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：10 MB

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| ユーザーをオーディエンスに追加（バッチ） | ✓ | ✓ |
| ユーザーをオーディエンスから削除（バッチ） | ✓ | ✓ |

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。


<blockquote>
このコネクタを追加する際は、ベンダーのデータプラットフォームポリシーに同意する必要があります。
</blockquote>


コネクタを追加した後、次の構成を構成します。

* **アカウントID**：割り当てられたTaboolaアカウントID。

## アクションパラメータ

**続行**をクリックして、コネクタのアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### ユーザーをオーディエンスに追加（バッチ）

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| オーディエンスID | ユーザーの追加先となるオーディエンスのID。**オーディエンスIDを確認**をクリックして、入力した**オーディエンスID**を確認します。新しいオーディエンスを作成するには、次の手順に従います。<ol><li>**オーディエンスを作成**をクリックします。</li><li>**オーディエンス名**フィールドに一意のオーディエンス名を入力します。</li><li>**TTL（時間）**フィールドに、ユーザーをオーディエンスに保持する時間を入力します。デフォルト値は`8670`（1年）です。</li><li>新規および既存のキャンペーンからオーディエンスを除外するには、**キャンペーンから除外**フィールドに`True`を入力します。デフォルト値は`False`です。</li><li>**完了**をクリックします。</li></ol> |
| ユーザーID | SHA256でハッシュ化されたメールアドレスまたはMAIDデバイスIDとして指定するユーザーID。 |
| タイプ | ユーザーIDのタイプ（`DEVICE_ID`または`EMAIL_ID`）。 |
