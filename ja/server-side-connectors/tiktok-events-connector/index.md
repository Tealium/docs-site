## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：TikTok HTTP API
* APIバージョン：v1.3（Events 2.0）
* APIエンドポイント：`https://business-api.tiktok.com/open_api/v1.3/event/track/`
* ドキュメント：[TikTok Events 2.0](https://business-api.tiktok.com/portal/docs?id=1771101303285761)

## バッチ制限

このコネクタは、ベンダーへの大量のデータ転送に対応するため、リクエストをバッチ処理します。並列処理によって、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数：50
* 最も古いリクエストからの最大経過時間：5分
* リクエストの最大サイズ：1 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **アクセストークン**：TikTokのアクセストークン。
* **ピクセルID**：WebサイトにTikTokピクセルをすでに統合している場合は、既存のピクセルコードを使用します。TikTok広告マネージャーアカウントにログインして、`pixel_code`を確認します。Webサイトごとに1つのピクセルを作成してください。

## 重複排除
 
Tealium iQタグ管理アカウント内のTikTok PixelタグからイベントIDを受信するようにこのコネクタを構成するには、次の命名規則に従うイベント属性を探します。

```nohl
tiktok_event_id_<TIKTOK_EVENT>_<TAG_UID>
```

たとえば、UIDが`174`のタグからのイベントでは、次の属性が送信されます。

```nohl
tiktok_event_id_Checkout_174
```

タグUIDは、Tealium iQの**タグ**テーブルまたはタグの詳細画面で確認できます。

![](https://docs.tealium.com/images/server-side-connectors/tiktok-pixel-uid.png)

このイベントID形式に一致するイベントIDごとに、個別のアクションを構成します。イベント固有のイベントID属性を`Event ID`にマッピングし、対応するイベント名を`Event Name`にマッピングします。

例：

| Tealiumの属性／値 | TikTokパラメータ |
|-------|------|
| `tiktok_event_id_Checkout_174` | イベントID |
| `Checkout`（カスタムテキスト） | イベント名 |

詳細については、[TikTok Pixelタグ構成ガイド](https://docs.tealium.com/tiktok-pixel-tag/)を参照してください。

### 自動重複排除

同じイベントソースID（`event_source_id`）、イベントタイプ（例：`AddToCart`）、およびイベントID（`event_id`）を持つ複数のイベントを受信した場合、TikTokは最初のイベントを使用し、最初のイベントから48時間以内に受信した後続のイベントを破棄します。

後続のイベントを最初のイベントから5分以内に受信した場合、TikTokはそのデータを最初のイベントにマージします。たとえば、最初のイベントにユーザーのメールアドレス（`user.email`）が含まれていなくても、後続の重複イベント（5分以内に受信）にこの情報が含まれている場合、TikTokはメールアドレスのデータを最初のイベントにマージします。

#### 自動重複排除

| パラメータ | 説明 |
| --- | --- |
| 自動マッピングを無効化 | 自動マッピングが無効になっている場合、自動的にマッピングされたパラメータは、デフォルトではベンダーに送信されません。 |

コネクタは、デフォルトで次のパラメータを自動的にマッピングします。

* **TikTokクリックID（`ttclid`）：** まず`ttclid` Cookieから読み取り、存在しない場合は`ttclid`クエリパラメータを使用して、`data[].user.ttclid`としてシリアル化します。
* **ユーザーエージェント：** 訪問のユーザーエージェントから読み取ります。

自動マッピングを無効にするには、**自動マッピングを無効化**を`true`に構成します。自動的にマッピングされたパラメータは、ベンダーに送信されません。

#### カスタムイベント

このコネクタのカスタムイベントを選択するには、次の手順に従います。

1. **イベントタイプ**カテゴリで、**コンバージョンイベント名**として`Custom`を選択します。
1. **カスタムイベント名**フィールドにカスタムイベント名を入力し、**+ マッピングを追加**をクリックします。
