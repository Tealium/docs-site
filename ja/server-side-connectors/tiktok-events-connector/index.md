## API 情報

このコネクタは、次のベンダー API を使用します。

* API 名：TikTok HTTP API
* API バージョン：v1.3（Events 2.0）
* API エンドポイント：`https://business-api.tiktok.com/open_api/v1.3/event/track/`
* ドキュメント：[TikTok Events 2.0](https://business-api.tiktok.com/portal/docs?id=1771101303285761)

## バッチ処理の上限

このコネクタは、ベンダーへの大量のデータ転送をサポートするため、リクエストをバッチ処理します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに格納されます。

* リクエストの最大数：50
* 最も古いリクエストからの最大経過時間：5 分
* リクエストの最大サイズ：1 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **アクセストークン**：TikTok のアクセストークン。
* **ピクセル ID**：Web サイトに TikTok ピクセルをすでに統合している場合は、既存のピクセルコードを使用します。TikTok Ads Manager アカウントにログインして、`pixel_code`を確認してください。Web サイトごとに 1 つのピクセルを作成します。

コネクタを構成したら、**完了**をクリックします。

## 重複排除
 
Tag Management アカウントの TikTok Pixel タグからイベント ID を受信するようにこのコネクタを構成するには、次の命名規則を使用するイベント属性を探します。

```nohl
tiktok_event_id_<TIKTOK_EVENT>_<TAG_UID>
```

たとえば、UID が`174`のタグからのイベントは、次の属性を送信します。

```nohl
tiktok_event_id_Checkout_174
```

タグ UID は、Tag Management の**タグ**テーブルまたはタグの詳細画面で確認できます。

![](https://docs.tealium.com/images/server-side-connectors/tiktok-pixel-uid.png)

このイベント ID 形式に一致するイベント ID ごとに、個別のアクションを構成します。イベント固有のイベント ID 属性を`Event ID`にマッピングし、対応するイベント名を`Event Name`にマッピングします。

例：

| Tealium の属性／値 | TikTok パラメータ |
|-------|------|
| `tiktok_event_id_Checkout_174` | イベント ID |
| `Checkout`（カスタムテキスト） | イベント名 |

詳細については、[TikTok Pixel タグ構成ガイド](https://docs.tealium.com/tiktok-pixel-tag/)を参照してください。

### 自動重複排除

同じイベントソース ID（`event_source_id`）、イベントタイプ（例：`AddToCart`）、イベント ID（`event_id`）を持つ複数のイベントを受信した場合、TikTok は最初のイベントを使用し、そのイベントから 48 時間以内に受信した後続のイベントを破棄します。

最初のイベントから 5 分以内に後続のイベントを受信した場合、TikTok はそのデータを最初のイベントにマージします。たとえば、最初のイベントにユーザーのメールアドレス（`user.email`）が含まれていないものの、後で受信した重複イベント（5 分以内に受信）にこの情報が含まれている場合、TikTok はメールアドレスのデータを最初のイベントにマージします。

#### 自動重複排除

| パラメータ | 説明 |
| --- | --- |
| 自動マッピングを無効化 | 自動マッピングを無効にすると、自動的にマッピングされたパラメータはデフォルトではベンダーに送信されません。 |

コネクターは、デフォルトで次のパラメータを自動的にマッピングします。

* **TikTokクリックID（`ttclid`）：** 最初に `ttclid` Cookieから読み取り、見つからない場合は `ttclid` クエリパラメータを使用し、`data[].user.ttclid` としてシリアル化します。
* **ユーザーエージェント：** 訪問のユーザーエージェントから読み取ります。

自動マッピングを無効にするには、**自動マッピングを無効化**を `true` に構成します。自動的にマッピングされたパラメータはベンダーに送信されません。

#### カスタムイベント

このコネクターのカスタムイベントを選択するには、次の手順を実行します。

1. **イベントタイプ**カテゴリで、**コンバージョンイベント名**に `Custom` を選択します。
1. **カスタムイベント名**フィールドにカスタムイベント名を入力し、**+ マッピングを追加**をクリックします。
