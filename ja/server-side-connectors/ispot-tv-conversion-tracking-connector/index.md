## 仕組み

iSpot TV Conversion Analyticsは、トラッキングコードを使用して、1,700万台を超えるテレビにおけるテレビ広告への接触を、お客様のWebサイトおよびアプリのファーストパーティデータと関連付けます。各テレビはホームネットワークに接続されているため、iSpotはホーム庭のIPアドレスにアクセスできます。これにより、iSpotはテレビ広告への接触を、IPアドレスに関連付けられたお客様のデータセットと結び付けることができます。その結果、テレビ広告のクリエイティブ、メディア、配信頻度が、売上やその他の重要なKPIにどのように影響するかについて、強力なクローズドループ分析が可能になります。プロセス全体は、個人を特定できる情報（PII）に関する要件に準拠した方法で実行されます。

## コネクタに関するヒント

タグとコネクタの両方を使用するハイブリッド構成を推奨します。この構成により、データの耐障害性が最大限に高まり、サーバーサイドのシグナルを使用したイベント照合が改善され、リアルタイムのクライアントサイドシグナルを維持しながらデータフローの継続性を確保できます。

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **サイトID**
  * トラッキングコードには、一意のWebサイトまたはアプリごとに固有のサイトIDが必要です。このIDはiSpotから提供されます。
  * サイトIDの形式は`TC-1234-1`です。各要素の意味は次のとおりです。
    * `TC`はトラッキングコードを表します。
    * `1234`はクライアントのアカウントIDです。
    * `-1`はサイト識別子で、サイトごとに増加します。

## アクション構成 - パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### アクション - ピクセルを送信

#### パラメータ

| **パラメータ** | **説明** |
|:--------------|:-----------------------|
| IPアドレス | <ul><li>IPアドレスはIPv4のみを使用してください。</li><li>例：`192.168.0.1`</li><li>Tealiumは、`X-Forwarded-For`リクエストヘッダーで値を渡します。</li></ul> |
| ユーザーエージェント | <ul><li>元のクライアントデバイスのユーザーエージェントです。</li><li>Tealiumは、リクエストヘッダーで`User-Agent`を渡します。</li></ul> |
| ユーザーエージェント | <ul><li>ユーザーエージェントを、元のクライアントデバイスのユーザーエージェントに構成します。</li><li>Tealiumは、リクエストヘッダーで`User-Agent`を渡します。</li></ul> |
| Cookie | <ul><li>iSpot Cookieは、Cookieリクエストヘッダーの一部として送信されます。</li><li>このCookieの値は、サービスからのJSONレスポンスを通じて、元のクライアントサイドブラウザから取得できます。</li><li>例：`https://ps.ispot.tv/v2/your-site-id.gif`</li></ul> |
| リファラー | <ul><li>元の訪問のリファラーです。リファラーリクエストヘッダーで送信されます。</li></ul> |
| イベント時刻 | <ul><li>クライアントの訪問とサーバーサイドリクエストの時間差が数分を超える場合は、イベント時刻をクライアント訪問時の元のUTC時刻に構成します。形式は`yyyy-MM-dd hh:mm:ss`です。</li><li>イベント時刻を指定しない場合、コネクタは実行時に生成します。</li></ul> |
| カスタムデータ | <ul><li>iSpot Tracking Codeでは、ビジネス目標に応じたカスタムデータを渡すことができます。</li><li>このセクションで個々の属性を渡すと、コネクタによってURLエンコードされたJSONオブジェクトにまとめられます。</li></ul> |
