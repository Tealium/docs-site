## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Awin API
* APIエンドポイント：`https://www.awin1.com`
* ドキュメント：[Awin：Awin API](https://developer.awin.com/apidocs/conversion-api)
* 認証タイプ：OAuth2.0
* タグのドキュメント：[Awinタグ](https://docs.tealium.com/awin-tag/)

## 仕組み

タグとコネクタの両方を使用するハイブリッド構成を推奨します。この構成により、データの耐障害性を最大限に高め、サーバーサイドデータによるイベントマッチングを改善し、リアルタイムのクライアントサイドデータを維持しながらデータフローの継続性を確保できます。このコネクタはAwinタグを使用し、トラフィックの流入元を識別する`awc`クエリ文字列パラメータを含む参照リンクから発生したコンバージョンをアトリビューションします。Tealium拡張機能を使用するか、`awc`パラメータを保持してサーバーサイドコネクタから送信することで、購入が正しいコミッショングループに割り当てられます。


<blockquote>
さまざまなブラウザのアップデートにより、Awinはピクセルのみの実装をサポートしなくなりました。このコネクタでは、フォールバックとして[Awin S2S API](https://developer.awin.com/docs/direct-s2s)実装を使用できます。
</blockquote>


## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。

* **トークン**  
（必須）このトークンは、個人ユーザーアカウントにリンクされています。トークンの作成方法について詳しくは、[AWIN：認証と認可](https://developer.awin.com/apidocs/api-authentication)を参照してください。
* **マーチャント（広告主ID）**  
該当するAwin広告主ID。サポートが必要な場合は、Awinアカウントマネージャーにお問い合わせください。

コネクタの構成が完了したら、**完了**をクリックします。

### 重複排除

複数のマーケティングチャネルやネットワークを使用している場合、同一のコンバージョンに対して複数のトラフィックソースへコミッションが支払われないよう、重複排除を実行する必要があります。詳細については、以下のチャネルパラメータに関する説明と[AWIN：重複排除](https://advertiser-success.awin.com/s/article/What-is-De-Duplication)を参照してください。

### チャネルパラメータ

Awinでは、トラフィックの流入元に基づいて各コンバージョンを処理する方法をシステムに指示するために、すべてのお客様が**チャネルパラメータ**を使用することを強く推奨しています。

このパラメータに成果対象となったチャネルコードを構成すると、Tealiumはリクエストを次の4つの方法で処理できます。

* 処理しない。
* Awin Cookieが存在する場合に処理する。
* AwinクリックCookieが存在する場合のみ処理する。
* AwinポストビューCookieが存在する場合のみ処理する。

### コンバージョンを送信

サーバー間トラッキングは、トラッキングに必須の要素です。コンバージョンデータは、Tealiumコネクタを介したHTTPSリクエストにより、Tealium Customer Data HubからAwinのサーバーへ直接送信する必要があります。

#### パラメータ

| **パラメータ**| **説明**|
|:---|:--- |
| 合計金額 | （必須）関連する割引を適用した後、税金、配送料、関連するサービス料などの追加料金を加算する前の注文小計金額。値は浮動小数点数データ型にする必要があります。桁区切り記号は使用できず、小数点には標準のドット（`.`）文字を使用する必要があります。 |
| 注文参照番号 | （必須）一意の予約IDまたは注文ID。|
| マーチャント（広告主ID） | 広告主プログラムID。この値は、構成画面で指定した値を上書きします。|
| コミッショングループコード | 推奨。トランザクションのアトリビューション先とするコミッショングループのコード。単一グループの場合、このパラメータには文字列を指定でき、複数グループの場合は配列を指定できます。使用できる文字は、大文字の英数字、アンダースコア、ハイフンです。このパラメータが構成されていない場合、Awinはデフォルトのコミッショングループを使用します。 |
| コミッショングループ金額 | 各コミッショングループに割り当てるコミッション金額。単一グループの場合、このパラメータには文字列を指定でき、複数グループの場合は配列を指定できます。配列の値は、コミッショングループ配列と同じ順序で指定する必要があります。マッピングされていない場合、マッピングされた合計金額がデフォルト値になります。 |
| チャネル | ラストクリック参照元のチャネル名。Awinには、デフォルト値である**aw**を常に使用してください。この値は20文字以内の英数字で指定する必要があります。トラフィックの流入元に基づいて各コンバージョンを処理する方法をAwinシステムが判断できるよう、このパラメータを含めることを強く推奨します。値の例としては、`aw`（Awinには常にこの値を使用）、`display`、`ppc`などがあります。詳細については、[Awin：チャネルパラメータ](https://developer.awin.com/docs/channel-parameter)を参照してください。 |
| AWCパラメータ | この値は、クリックの流入元を識別するためにAwinによってランディングページURLに追加されます。**AWCパラメータ**または**バウチャーコード**のいずれかに値を指定する必要があります。`awc`値は、クリックの流入元を識別するためにAwinによってランディングページURLに追加されるパラメータです。エンドユーザーがサイトに到達したときに、サーバーサイドのスクリプト言語を使用して`awc`値を記録するようにサイトを構成する必要があります。この値は、コンバージョン時に`cks`パラメータへ入力するために使用されます。この関数は、すべてのページで呼び出す必要があります。Cookieを使用してawc値を取得する場合は、次のガイドラインに従ってください。<ul><li>Cookieは、クライアントサイドスクリプトではなく、HTTPレスポンスヘッダーで構成する必要があります。たとえば、PHPで構成されたCookieは使用できます。</li><li>CookieにはHTTP Onlyフラグを構成する必要があります。</li><li>CookieにはSecureフラグを構成する必要があります。</li></ul> |
| バウチャーコード | トランザクションのURLエンコードされたバウチャーコード。**AWCパラメータ**または**バウチャーコード**のいずれかに値を指定する必要があります。|
| 通貨コード| <ul><li>推奨。トランザクションで使用された通貨のISO通貨コード（例：`GBP`または`USD`）。</li><li>正確なトラッキングを維持するために、このパラメータを指定することを強く推奨します。</li></ul> |
| カスタムパラメータ | 1つまたは複数のカスタムトラッキングパラメータに使用する入力データ。 |
| テストモード| 受信したトラッキングリクエストは、テスト目的のため処理されません。 |

### 商品レベルコンバージョン

商品レベルトラッキングを使用すると、広告主は個々の商品のパフォーマンスを測定できる、より詳細なレポートを作成できます。
#### パラメータ

| パラメータ | 説明 |
|:---|:---|
| 合計金額 | （必須）関連する割引を適用した後、税金、配送料、関連するサービス料などの追加料金を加算する前の注文小計金額。値は浮動小数点型でなければなりません。桁区切り文字は使用できず、小数点には標準のドット（`.`）文字を使用する必要があります。 |
| 注文参照番号 | （必須）一意の予約IDまたは注文ID。|
| マーチャント（広告主ID） | 広告主プログラムID。この値は、構成画面の値を上書きします。 |
| コミッショングループコード | 推奨。トランザクションの割り当て先となるコミッショングループのコード。単一グループの場合、このパラメータには文字列を指定し、複数グループの場合は配列を指定できます。使用できる文字は、英大文字、数字、アンダースコア、ハイフンです。このパラメータが指定されていない場合、Awinはデフォルトのコミッショングループを使用します。コミッショングループのコードはpartsパラメータにマッピングされ、商品レベルでもマッピングされます。</li></ul> |
| コミッショングループ金額 | 各コミッショングループに割り当てるコミッション金額。単一グループの場合、このパラメータには文字列を指定し、複数グループの場合は配列を指定できます。配列の値は、コミッショングループの配列と同じ順序で指定する必要があります。マッピングされていない場合、デフォルト値はマッピングされた合計金額になります。 |
| チャネル | ラストクリックの参照元のチャネル名。Awinの場合は、常にデフォルト値の`aw`を使用してください。この値は20文字以内の英数字で指定する必要があります。トラフィックの流入元に基づいて各コンバージョンを処理する方法をAwinシステムが判断できるよう、このパラメータを含めることを強く推奨します。値の例としては、`aw`（Awinでは常にこの値を使用）、`display`、`ppc`などがあります。 |
| AWCパラメータ | クリック元を識別するために、AwinによってランディングページのURLに追加される値。**AWCパラメータ**または**バウチャーコード**のいずれかの値を指定する必要があります。Cookieを使用してawc値を取得する場合は、次のガイドラインに従ってください。<ul><li>Cookieは、クライアント側スクリプトではなく、HTTPレスポンスヘッダーで構成する必要があります。たとえば、PHPで構成されたCookieは問題ありません。CookieにはHTTP Onlyフラグを構成する必要があります。</li><li>CookieにはSecureフラグを構成する必要があります。</li></ul> |
| バウチャーコード | トランザクションに使用するURLエンコードされたバウチャーコード。**AWCパラメータ**または**バウチャーコード**のいずれかの値を指定する必要があります。|
| 通貨コード | 推奨。トランザクションで使用された通貨のISO通貨コード（例：`GBP`、`USD`）。|
| 商品名 | （必須）トランザクション内の商品名の配列。|
| カスタムパラメータ | 1つまたは複数のカスタムトラッキングパラメータに対する入力データ。 |
| テストモード | 受信したトラッキングリクエストは、テスト目的のため処理されません。 |
