## API情報

このコネクタでは、次のベンダーAPIを使用します。

* API名：Nine API
* APIバージョン：v1
* APIエンドポイント：`https://pubsub.googleapis.com/`
* ドキュメント：[Nine API](https://cloud.google.com/pubsub/docs/overview)

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| ユーザーをセグメントに追加 | ✓ | ✗ |
| ユーザーをセグメントから削除 | ✓ | ✗ |
| ユーザーをすべてのセグメントから削除 | ✓ | ✗ |

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。

* **秘密鍵**  

コネクタを構成した後、**完了**をクリックします。
 
Google Pub/Sub接続用の秘密鍵を入力してください。

## アクション：パラメーターとオプション

以下のセクションでは、各アクションでサポートされているパラメーターを示します。

### アクション：ユーザーをセグメントに追加

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| セグメント名 | （必須）オーディエンスセグメントの名前を入力します。 |
| クライアント名 | （必須）NineのアカウントID。 |
| メールアドレス（SHA256でハッシュ化済み） | SHA256でハッシュ化済みのメールアドレスを指定します。 |
| メールアドレス（SHA256ハッシュを適用） | プレーンテキストのメールアドレスを指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256でハッシュ化します。 |
