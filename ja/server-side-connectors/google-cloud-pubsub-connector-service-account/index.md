## 前提条件

### Google Cloud Pub/Sub コネクタ

このコネクタは、認証に 3-legged OAuth フローを使用します。このフローでは、ユーザーがクライアント ID とクライアントシークレットを入力する必要があります。このコネクタを構成する前に、次の手順を実行してください。

1. Google Cloud プロジェクトで、アプリケーションの種類をウェブアプリケーションに構成した OAuth クライアント ID 認証情報を作成します。
1. Google Cloud のウェブアプリケーション構成を更新し、Tealium サーバーを許可リストに追加して、接続成功時に必要なコールバックを指定します。Google Cloud コンソールで、**認証情報**に移動し、OAuth クライアント ID の構成を次の値で編集します。各項目には、Tealium インスタンスの URL で使用されているサブドメインに応じて、いずれかの値を追加します。
    * 承認済みの JavaScript 生成元：
      * `https://my.tealiumiq.com`
      * `https://my.tealiumiq.com`
      * `https://[privatecloud subdomain].tealiumiq.com`
    * 承認済みのリダイレクト URI：
      * `https://my.tealiumiq.com/oauth/google/callback.html`
      * `https://my.tealiumiq.com/oauth/google/callback.html`
      * `https://[private cloud subdomain].tealiumiq.com/oauth/google/callback.html`
1. コネクタの構成で使用する次の構成情報を控えておきます。
    * プロジェクト ID
    * クライアント ID
    * クライアントシークレット

### Google Cloud Pub/Sub（サービスアカウント）コネクタ

このコネクタは、アクセスに Google Cloud サービスアカウントを使用する 2-legged OAuth フローを使用します。コネクタを構成する前に、Google Cloud プロジェクトで Pub/Sub パブリッシャーのロールを持つサービスアカウントを作成してください。サービスアカウントの作成方法について詳しくは、Google Cloud ドキュメントの「[IAM によるアクセス制御](https://cloud.google.com/pubsub/docs/access-control)」を参照してください。サービスアカウントを作成したら、コネクタの構成で使用する次の構成情報を控えておきます。

* プロジェクト ID
* サービスアカウントのメールアドレス
* サービスアカウントキー

## 構成

コネクタマーケットプレイスに移動して、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、追加したコネクタに応じて次の項目を構成します。

### Google Cloud Pub/Sub コネクタ

* **Google Cloud Platform プロジェクト ID**  
（必須）Google Cloud Platform のプロジェクト ID。
* **クライアント ID**  
（必須）Google Cloud プロジェクト内で、アプリケーションの種類がウェブアプリケーションに構成されている OAuth クライアント ID。
* **クライアントシークレット**  
（必須）Google Cloud プロジェクトで割り当てられたクライアントシークレットを入力します。

### Google Cloud Pub/Sub（サービスアカウント）コネクタ

* **Google Cloud Platform プロジェクト ID**  
（必須）Google Cloud Platform のプロジェクト ID。
* **クライアントメールアドレス**  
（必須）Google Cloud プロジェクトで使用するサービスアカウントのメールアドレス。
* **秘密鍵**  

コネクタを構成したら、**完了**をクリックします。
（必須）Google Cloud プロジェクトのサービスアカウント用に生成された秘密鍵。

### イベントデータをトピックに送信

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|プロジェクトトピック|（必須）メッセージのパブリッシュ先となる Pub/Sub プロジェクト内のトピックを選択します。|
|メッセージ属性|属性値をカスタム Pub/Sub メッセージ属性にマッピングします。**宛先**ドロップダウンリストにメッセージ属性キーを入力します。|
|属性名を出力|属性名が更新されると、パブリッシュされるメッセージのペイロード内の名前に更新後の名前が自動的に反映されます。|
|順序指定キー|Pub/Sub トピックのサブスクライバーが、パブリッシュされた順序でメッセージを受信できるようにするには、順序指定キーの値をマッピングまたは入力します。詳細については、「[Google：メッセージの順序指定](https://cloud.google.com/pubsub/docs/ordering)」を参照してください。|

### 訪問データをトピックに送信

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|プロジェクトトピック|（必須）メッセージのパブリッシュ先となる Pub/Sub プロジェクト内のトピックを選択します。|
|メッセージ属性|属性値をカスタム Pub/Sub メッセージ属性にマッピングします。**宛先**ドロップダウンリストにメッセージ属性キーを入力します。|
|現在の訪問データを含める|パブリッシュされるメッセージに訪問データと現在の訪問データの両方を含めるには、このチェックボックスをオンにします。|
|属性名を出力|属性名が更新されると、パブリッシュされるメッセージのペイロード内の名前に更新後の名前が自動的に反映されます。|
|順序指定キー|Pub/Sub トピックのサブスクライバーが、パブリッシュされた順序でメッセージを受信できるようにするには、順序指定キーの値をマッピングまたは入力します。詳細については、「[Google：メッセージの順序指定](https://cloud.google.com/pubsub/docs/ordering)」を参照してください。|

### カスタマイズしたデータをトピックに送信（詳細）

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|プロジェクトトピック|（必須）メッセージのパブリッシュ先となる Pub/Sub プロジェクト内のトピックを選択します。|
|メッセージデータ|（必須）メッセージデータを構成するための値を指定します。テンプレートを使用する場合は、テンプレートからメッセージデータを生成するためにテンプレート名を参照します。単純な 1 階層の JSON 形式の場合は値を名前にマッピングします。それ以外の場合は、テンプレート名を参照し、**カスタムメッセージ定義**オプションのみを選択します。|
|メッセージ属性|属性値をカスタム Pub/Sub メッセージ属性にマッピングします。**宛先**ドロップダウンリストにメッセージ属性キーを入力します。|
|テンプレート変数|テンプレートのデータ入力としてテンプレート変数を指定します。詳細については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。ネストされたテンプレート変数にはドット記法で名前を付けます。例：`items.name`。ネストされたテンプレート変数は通常、データレイヤーのリスト属性から構成されます。|
|テンプレート|メッセージ属性またはデータで参照するテンプレートを指定します。詳細については、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。テンプレートは、サポートされているフィールドに二重波括弧で名前を指定することで挿入されます。例：`{{SomeTemplateName}}`。|
|順序指定キー|Pub/Sub トピックのサブスクライバーが、パブリッシュされた順序でメッセージを受信できるようにするには、順序指定キーの値をマッピングまたは入力します。詳細については、「[Google：メッセージの順序指定](https://cloud.google.com/pubsub/docs/ordering)」を参照してください。|

### ログイベントをトピックに送信

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| プロジェクトトピック |（必須）ログイベントの送信先となるトピックを選択します。|
| メッセージ属性 |（任意）値をメッセージ属性にマッピングします。|

### カスタム URL を使用してイベントデータを送信

| **パラメータ** | **説明** |
| --- | --- |
| URL の上書き |（必須）データの送信先となるカスタム `URL` を入力します。|
| メッセージ属性 | 値をメッセージ属性にマッピングします。|
| 属性名を出力 | 属性名が更新されると、ペイロード内の名前に更新内容が反映されます。|
|順序指定キー|Pub/Sub トピックのサブスクライバーが、パブリッシュされた順序でメッセージを受信できるようにするには、順序指定キーの値をマッピングまたは入力します。詳細については、「[Google：メッセージの順序指定](https://cloud.google.com/pubsub/docs/ordering)」を参照してください。|
