## バッチ制限

このコネクタは、ベンダーへの大量データ転送をサポートするために、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに入れられます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：10 分
* リクエストの最大サイズ：100 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **認証タイプ**  
  * 認証タイプを選択します。使用可能なオプションは、**STS** と **アクセスキー**です。
    * **STS**：**ロールの引き受け：ARN** フィールドと **ロールの引き受け：セッション名**フィールドが必要です。
    * **アクセスキー**：**AWS アクセスキー**フィールドと AWS シークレットアクセスキーフィールドが必要です。
* **リージョン**  
  * （必須）リージョンを選択します。
* **STS - ロールの引き受け：ARN**  
  * STS 認証では必須です。引き受けるロールの Amazon リソースネーム（ARN）を指定します。
  * 例：`arn:aws:iam:222222222222:role/myrole`
  * 詳細については、[AWS Identity and Access Management：IAM ロールへの切り替え（AWS API）](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles_use_switch-role-api.html)を参照してください。
* **STS - ロールの引き受け：セッション名**  
  * 引き受けるロールのセッション名です。
  * 2～64 文字で指定する必要があります。
* **STS - ロールの引き受け：外部 ID**  
  * サードパーティの外部識別子を指定します。
  * 詳細については、[AWS Identity and Access Management：サードパーティが所有する AWS アカウントへのアクセス](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles_common-scenarios_third-party.html)を参照してください。
* **アクセスキー - AWS アクセスキー**  
  * **アクセスキー**認証では必須です。AWS アクセスキーを指定します。
* **アクセスキー - AWS シークレットアクセスキー**  
  * **アクセスキー**認証では必須です。AWS シークレットアクセスキーを指定します。

### AWS S3 への接続を作成する

Tealium がバケットの一覧を表示し、イベントおよびオーディエンスデータを S3 オブジェクトにアップロードするには、AWS S3 インスタンスへの接続が必要です。認証には次の 2 つのオプションがあります。

* アクセスキーとアクセスシークレットを指定します。
* STS（Security Token Service）認証情報を指定します。

コネクタを構成した後、**完了**をクリックします。


<blockquote>
S3 オブジェクトが暗号化されている場合は、IAM ユーザーと KMS キーポリシーに復号権限を追加する必要があります。
</blockquote>


#### アクセスキーとシークレット認証情報

AWS アクセスキーとシークレットを確認するには、次の手順を実行します。

1. AWS Management Console にログインし、**IAM**（Identity and Access Management）サービスに移動します。
1. **ユーザー**をクリックし、**ユーザーを追加**をクリックします。
1. ユーザー名を入力します。例：`TealiumS3User`
1. 作成したユーザーにポリシーをアタッチします。
    1. **アクセス許可**タブで、**既存のポリシーを直接アタッチ**をクリックします。
    1. フルアクセスを許可するには、`AmazonS3FullAccess` ポリシーを検索してアタッチします。特定のバケットへのアクセスを制限するには、次の例のようなポリシーを作成します。この例では、`YOUR_BUCKET_NAME` は、Tealium がイベントおよびオーディエンスデータを S3 オブジェクトにアップロードする際に使用するバケットです。
    ```json
    {
      "Version": "2012-10-17",
      "Statement": [
          {
                "Effect": "Allow",
                "Action": [
                   "s3:ListBucket",
                    "s3:PutObject",
                    "s3:GetObject",
                    "s3:ListBucketMultipartUploads",
                    "s3:ListMultipartUploadParts"
                ],
                "Resource": [
                    "arn:aws:s3:::YOUR_BUCKET_NAME",
                    "arn:aws:s3:::YOUR_BUCKET_NAME/*"
                ]
            },
            // Add the following section if you are running on a private cloud
            // and require decryption
            {
                "Effect": "Allow",
                "Action": [
                     "kms:Decrypt",
                     "kms:GenerateDataKey"
                ],
                 "Resource": "arn:aws:kms:YOUR_REGION:111879511226:key/YOUR_KEY_ID"
           }
        ]
    }
    ```
1. キーを作成します。
    1. **セキュリティ認証情報**タブに移動し、**アクセスキーを作成**をクリックします。
    1. **アクセスキー ID** と **シークレットアクセスキー**をコピーし、安全に保存します。
    1. プライベートクラウド環境を使用している場合は、次のようなステートメントをキーポリシーに追加します。
    ```
    {
        "Sid": "AllowDecryptFromIAMUser",
        "Effect": "Allow",
        "Principal": {
            "AWS": "arn:aws:iam::<<account-id>>:user/<<user-name>>"
        },
        "Action": [
            "kms:Decrypt",
            "kms:GenerateDataKey"
        ],
        "Resource": "*"
    }
    ```
#### STS 認証情報

STS 認証情報を確認するには、次の手順を実行します。

1. **AWS Management Console** にログインし、**IAM**（Identity and Access Management）サービスに移動します。
1. **Roles** をクリックし、**Create role** をクリックします。
1. **Trusted entity** のタイプとして、AWS アカウントを選択します。
1. **Another AWS account** を選択し、Tealium のアカウント ID を入力します。
    * プライベートクラウドのお客様の場合、ID は `111879511226` です。
    * その他すべてのお客様の場合、ID は `757913464184` です。
1. （任意）**Require external ID** チェックボックスを選択し、使用する外部 ID を指定します。外部 ID は最大 256 文字で、英数字（`A-Z`、`a-z`、`0-9`）およびハイフン（`-`）、アンダースコア（`_`）、ピリオド（`.`）などの記号を使用できます。
1. ロールの名前を入力します。ロール名は TealiumS3 で始まる必要があります。例：`TealiumS3-test.`
1. ロールにポリシーをアタッチします。
    1. **Permissions** タブで、**Attach existing policies directly** をクリックします。
    1. フルアクセスを許可するには、`AmazonS3FullAccess` ポリシーを検索してアタッチします。アクセスを特定のバケットに制限するには、次の例のようなポリシーを作成します。この例で、`YOUR_BUCKET_NAME` は、Tealium がイベントおよびオーディエンスデータを S3 オブジェクトにアップロードするために使用するバケットです。
    ```json
    {
        "Version": "2012-10-17",
        "Statement": [
            {
                "Effect": "Allow",
                "Action": [
                    "s3:ListBucket",
                    "s3:PutObject",
                    "s3:GetObject",
                    "s3:ListBucketMultipartUploads",
                    "s3:ListMultipartUploadParts"
                ],
                "Resource": [
                    "arn:aws:s3:::YOUR_BUCKET_NAME",
                    "arn:aws:s3:::YOUR_BUCKET_NAME/*"
                ]
            },
            // Add the following section if you are running on a private cloud
            // and require decryption
            {
                "Effect": "Allow",
                "Principal": {
                "AWS": "arn:aws:iam::111879511226:user/YOUR_USER_NAME"
             },
                "Action": "s3:GetObject",
                "Resource": "arn:aws:s3:::YOUR_BUCKET_NAME/*"
            }
        ]
    }
    ```
1. 信頼ポリシーを作成します。
    1. **Trust relationships** タブに移動し、**Edit trust** relationship をクリックします。
    1. 信頼ポリシーで、指定した外部 ID に作成したロールの使用が許可されていることを確認します。また、プライベートクラウドのお客様の場合は ID が `111879511226`、その他すべてのお客様の場合は ID が `757913464184` であることを確認します。
    1. Tealium への接続用に `EXTERNAL_ID` の値を構成します。ID は最大 256 文字で、英数字（`A-Z`、`a-z`、`0-9`）およびハイフン（`-`）、アンダースコア（`_`）、ピリオド（`.`）などの記号を使用できます。
    ```json
        {
            "Version": "2012-10-17",
            "Statement": [
                {
                    "Effect": "Allow",
                    "Principal": {
                        "AWS": "arn:aws:iam::757913464184:root"
                    },
                    "Action": "sts:AssumeRole",
                    "Condition": {
                        "StringEquals": {
                            "sts:ExternalId": "EXTERNAL_ID"
                        }
                    }
                }
            ]
        }
    ```

### バケットの作成

S3 バケットは、データの保存と整理に使用される AWS S3 内の保存コンテナです。コネクタ構成ウィンドウでは、構成手順で **Create Bucket** をクリックして新しいバケットを作成できます。

1. コネクタ構成画面で、**Create Bucket** をクリックします。
1. バケット名を入力します。
1. **Create** をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| イベントデータ全体を送信 | ✗ | ✓ |
| カスタムイベントデータを送信 | ✗ | ✓ |
| 訪問データ全体を送信 | ✓ | ✗ |
| カスタム訪問データを送信 | ✓ | ✗ |
| ログイベントを送信 | ✗ | ✓ |
| ログイベント全体を送信 | ✗ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

以下のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### イベントデータ全体を送信

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| バケット | Amazon S3 バケットを選択するか、カスタム値を指定します。 |
| ファイルパス | データを追加する S3 オブジェクトへのパスを指定します。 |
| ファイルパスのサフィックス | 現在のタイムスタンプを持つ属性など、ファイルパスにサフィックスを動的に追加する場合は、ここで選択します。これにより、イベントごとに一意のファイルが作成され、既存のファイルが上書きされるのを防止できます。区切り文字は、ファイルパスとサフィックスの間、および複数のサフィックス値の間に配置されます。区切り文字は、**ファイルパスの区切り文字**で構成します。 |
| ファイルパスの区切り文字 | ファイルパスとファイルパスのサフィックスの間、および複数のサフィックス値の間に配置される文字です。オプションは、**アンダースコア**（デフォルト）、**ハイフン**、**ピリオド**、**スラッシュ**、または**なし**です。既存の構成では、アンダースコアの動作が維持されます。 |
| レコードのサフィックス | <ul><li>区切り文字として各レコードの末尾に追加するサフィックスです。</li><li>デフォルトは `Newline` です。</li><li>使用可能なオプションは `Newline` と `No Delimiter` です。</li></ul> |
| 属性名を出力 | デフォルトでは、属性キーが使用されます。代わりに属性名をキーとして使用する場合は、このチェックボックスを有効にします。属性名が更新されると、ペイロードの名前にも更新が反映される点に注意してください。 |
| バッチの有効期間 | バッチアクションを送信する頻度を指定するため、有効期間（TTL）を構成します。`1`～`60` 分の値を入力します。デフォルト値は `10` 分です。 |

| バッチの有効期間 | バッチアクションを送信する頻度を指定するため、有効期間（TTL）を構成します。`1`～`60` 分の値を入力します。デフォルト値は `10` 分です。 |
| テンプレート変数 | <ul><li>**テンプレート**のデータ入力としてテンプレート変数を指定します。詳細と使用例については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。</li><li>ネストされたテンプレート変数にはドット表記で名前を付けます。例：`items.name.`</li><li>ネストされたテンプレート変数は、通常、データレイヤーのリスト属性から作成されます。</li></ul> |
| テンプレート | <ul><li>イベントパラメータで参照するテンプレートを指定します。詳細については、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。</li><li>テンプレートは、サポートされているフィールドに二重中括弧を使用して名前で挿入します。例：`{{SomeTemplateName}}`</li></ul>|
