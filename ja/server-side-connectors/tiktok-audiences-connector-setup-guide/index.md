## API情報

このコネクタでは、次のベンダーAPIを使用します。

* API名：TikTok HTTP API
* APIバージョン：v1.3
* APIエンドポイント：`https://business-api.tiktok.com/open_api/v1.3`
* ドキュメント：[TikTokオーディエンスセグメント](https://ads.tiktok.com/marketing_api/docs?id=1736874036878337)

## バッチ処理の上限

このコネクタは、ベンダーへの大量データ転送に対応するため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに格納されます。

* リクエストの最大数：1000
* 最も古いリクエストからの最大経過時間：30分
* リクエストの最大サイズ：1 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/about-connectors/)の記事を参照してください。

コネクタを追加した後、次の構成を構成します。

* **広告主ID**：（必須）TikTok Ads Managerの広告アカウントIDです。詳細については、[TikTok：広告アカウントIDを確認する方法](https://ads.tiktok.com/help/article/find-your-ad-account-id?lang=en)を参照してください。TikTokへの接続をテストするには、**接続を確立**をクリックします。

このコネクタ用のオーディエンスを作成するには、次の手順に従います。

1. **オーディエンスを作成**をクリックします。
1. **カスタムオーディエンス名**に、このコネクタで使用するオーディエンス名を入力します。
1. **暗号化タイプ**ドロップダウンリストから、オーディエンスへのデータ追加時に使用する暗号化タイプを選択します。
1. **作成**をクリックしてから、**完了**をクリックします。

オーディエンスを削除するには、次の手順に従います。

1. **オーディエンスを削除**をクリックします。
1. **オーディエンスID**ドロップダウンリストから、削除するオーディエンスを選択します。
1. **削除**をクリックしてから、**完了**をクリックします。

コネクタの構成が完了したら、**完了**をクリックします。

## アクション

| アクション名 | AudienceStream | EventStream |
| --- | :---: | :---: |
| オーディエンスに訪問を追加 | ✓ | ✗ |
| オーディエンスから訪問を削除 | ✓ | ✗ |

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、**アクションタイプ**を選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### オーディエンスに訪問を追加

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| オーディエンスID | オーディエンスを選択するか、オーディエンスIDを入力します。 |
| IDFA（MD5ハッシュを適用） | プレーンテキストのiOS IDFAを指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、MD5でハッシュ化します。 |
| IDFA（MD5でハッシュ化済み） | MD5でハッシュ化済みのiOS IDFAを指定します。 |
| AAID（MD5ハッシュを適用） | Androidデバイス用のプレーンテキストの広告IDを指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、MD5でハッシュ化します。 |
| AAID（MD5でハッシュ化済み） | MD5でハッシュ化済みのAndroidデバイス用広告IDを指定します。 |
| IDFA（SHA256ハッシュを適用） | プレーンテキストのiOS IDFAを指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256でハッシュ化します。 |
| IDFA（SHA256でハッシュ化済み） | SHA256でハッシュ化済みのiOS IDFAを指定します。 |
| AAID（SHA256ハッシュを適用） | Androidデバイス用のプレーンテキストの広告IDを指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256でハッシュ化します。 |
| AAID（SHA256でハッシュ化済み） | SHA256でハッシュ化済みのAndroidデバイス用広告IDを指定します。 |
| メールアドレス（SHA256ハッシュを適用） | プレーンテキストのメールアドレス（`@`を含める必要があります）を指定します。コネクタは、この値の前後の空白を削除し、小文字に変換してから、SHA256でハッシュ化します。 |
| メールアドレス（SHA256でハッシュ化済み） | SHA256でハッシュ化済みのメールアドレスを指定します。 |
| 電話番号（SHA256ハッシュを適用） | プレーンテキストの電話番号を指定します。コネクタは、この値の前後の空白を削除してから、SHA256でハッシュ化します。 |
| 電話番号（SHA256でハッシュ化済み） | SHA256でハッシュ化済みの電話番号を指定します。 |

1つのアクションに複数の識別子をマッピングできます。識別子を追加するには、**マッピングを追加**をクリックします。少なくとも1つの識別子をマッピングしてください。コネクタは、1つのレコードに複数の訪問を含めるのではなく、同じ訪問の複数の識別子を1つのリクエストで送信します。識別子のマッピングには、次の制約が適用されます。

* 識別子タイプごとに許可されるソース属性は1つのみです。
* 同じ識別子とハッシュ方式の組み合わせを重複してマッピングすることはできません。
* 同じ識別子タイプについて、プレーンテキスト値とハッシュ化済みの値の両方をマッピングすることはできません。
