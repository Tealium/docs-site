## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Yahoo API
* APIバージョン：v1
* APIエンドポイント：`https://datax.yahooapis.com`
* ドキュメント：[Yahoo API](https://help.yahooinc.com/datax/docs/yahoo-ad-tech-datax-api-specifications)

## バッチ制限

このコネクタは、ベンダーへの大量データ転送に対応するため、リクエストをバッチ処理します。並列処理により、イベントが順不同でベンダーに到達する場合があります。順序が重要な場合は、イベントにシーケンス値を追加してください。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに保持されます。

* リクエストの最大数：10,000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：100 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。


<blockquote>
このコネクタを追加すると、ベンダーのデータプラットフォームポリシーへの同意を求められます。
</blockquote>


コネクタを追加したら、次の構成を行います。

* **GDPRモード**（必須）GDPRモード。サポートされる値：
    * **oath_is_controller**：Yahooはデータ管理者として機能します。識別された各データ主体は、IAB-EUの透明性と同意に関する標準に従い、指定された目的でYahooが自身のデータを処理することに明示的に同意しています。
    * **oath_is_processor**：Yahooは、第三者のデータ管理者との契約に基づき、一般データ保護規則（GDPR）におけるデータ処理者として機能します。

コネクタを構成したら、**完了**をクリックします。

このコネクタを初めて実装する場合は、次の手順を実行します。

1. **新しいタクソノミーセグメント**をクリックします。
1. **新しいタクソノミーセグメントの作成**画面で、Yahoo MDM番号を入力してタクソノミーブランチに追加します。
    * 複数のユーザーを追加する場合は、各エントリをカンマで区切ります。
1. オーディエンスデータの送信先となるセグメントの**名前**を入力します。このセグメント名をTealiumのオーディエンス名と一致させることをお勧めします。
1. （任意）**説明**を入力します。
1. **アカウント（プロファイル）セグメントを作成**をクリックします。

これにより、タクソノミーファイルにTealiumアカウント名、Tealiumプロファイル名、データを受信するオーディエンスセグメントという3つのノードが追加されます。

（Tealiumプロファイルで別のYahooXコネクタを構成することにより）タクソノミーファイルのアカウントおよびプロファイルセグメントをすでに作成している場合は、次の手順を実行します。

1. **オーディエンスをタクソノミーに追加**をクリックします。
1. オーディエンスの**名前**を入力します。
1. （任意）**説明**を入力します。
1. **オーディエンスを追加**をクリックします。
<blockquote>
Yahooによるタクソノミーセグメントの構成処理には、最長45分かかる場合があります。この時間内にデータ送信を開始すると、Yahoo内にセグメントがまだ存在しないため、データは受け入れられず、エラーが発生します。
</blockquote>


## アクション

| アクション名 | ビジタープロファイル | イベントデータ |
| --- | :---: | :---: |
| ユーザーをセグメントに追加 | ✓ | ✗ |
| オプトアウト | ✓ | ✗ |

アクションの名前を入力し、アクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### ユーザーをセグメントに追加

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| URNタイプ | （必須）ユーザー識別子（URN）のタイプ。<ul><li>DXID</li><li>ZIP4</li><li>IXID</li><li>IDFA（iOS広告主向けID）</li><li>GPADVID（Google Play広告ID）</li><li>メール（SHA256ハッシュを適用）</li><li>メール（SHA256でハッシュ化済み）</li></ul> 新しいタクソノミーセグメントを作成するには、**新しいタクソノミーセグメントを作成**をクリックし、画面の指示に従います。 |
| URN値 | （必須）ユーザー識別子（URN）の値。 |
| タクソノミーID | （必須）タクソノミーのID。 |

#### セグメント

| **パラメータ** | **説明** |
| --- | --- |
| タイムスタンプ | この適格判定に関連付けられた、秒単位のUNIXエポック時刻によるタイムスタンプ。例：`1376244670`。この値は過去の時刻である必要があります。 |
| 有効期限タイムスタンプ | 適格判定が期限切れになる時刻を示す、秒単位のUNIXエポック時刻によるタイムスタンプ。例：`1379234569`。 |
| GDPR | サポートされる値：<ul><li>**true**：欧州のオーディエンスデータ。データプロバイダーは、データがGDPR規制の対象であることを示します。</li><li>**false**：その他の地域。データプロバイダーは、データがGDPR規制の対象ではないことを示します。</li></ul> |

### オプトアウト

このアクションでは、**ユーザーをセグメントに追加**アクションと同じパラメータおよびマッピングオプションを使用します。詳細については、[ユーザーをセグメントに追加](#add-user-to-segment)を参照してください。
