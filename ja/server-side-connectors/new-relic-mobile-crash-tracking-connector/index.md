## 仕組み

システムクラッシュが発生すると、ライブイベントから受信したデータが取得されます。UDH のクラッシュトラッキングコネクタは、クラウド配信方式を使用してクラッシュデータをベンダーに転送し、ライブイベントに関連データが表示される方法をカスタマイズできます。

### 要件

* New Relic アカウント
* API キー

#### 推奨 SDK モジュール：

* [Tealium Android 用 Crash Reporter モジュール](https://docs.tealium.com/ja/platforms/android-java/module-list/crash-reporter/)

### サポートされているアクション

| **アクション名** | **オーディエンスによるトリガー** | **イベントによるトリガー** |
|:-------------------------|:-------------------------|:----------------------|
| Android クラッシュイベントを送信 | ✗ | ✓ |

## 構成

コネクタマーケットプレイスに移動して、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

ベンダーを構成するには、次の手順に従います。

1. **Configure**タブで、コネクタインスタンスのタイトルを入力します。

1. New Relic からアカウント用に受け取った API キーを入力します。

1. 実装に関する追加のメモを入力します。

## アクション構成：パラメータとオプション

**Continue**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### アクション：Android クラッシュイベントを送信


<blockquote>
コネクタは、New Relic に送信する前に、イベント属性を必須フィールドへ自動的にマッピングします。
</blockquote>


#### パラメータ
