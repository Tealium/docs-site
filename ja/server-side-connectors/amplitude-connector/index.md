## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Amplitude HTTP API
* APIバージョン：v2
* APIエンドポイント：`https://api2.amplitude.com/2/httpapi`
* ドキュメント：[Amplitude HTTP API](https://developers.amplitude.com/docs/http-api-v2)

## コネクタアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
|イベントを送信| ✓| ✓|
|イベントを送信（非バッチ）| ✓| ✓|

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **APIキー**  
**Settings &rarr; Projects**にあります。
* **サーバーエンドポイント**  
使用するAmplitudeエンドポイントを入力します。  
    * 標準サーバー：`https://api2.amplitude.com/2/httpapi`  
    * EUデータレジデンシーサーバー：`https://api.eu.amplitude.com/2/httpapi`  
値を入力しない場合、コネクタはデフォルトで**標準サーバー**のエンドポイントを使用します。

コネクタの構成が完了したら、**Done**をクリックします。

## アクション構成 — パラメーターとオプション

**Continue**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。

### アクション — イベントを送信（バッチ）


<blockquote>
リアルタイム処理が必要な場合は、「イベントを送信（バッチ）」アクションを使用しないでください。
</blockquote>


#### バッチの制限

このアクションは、ベンダーへの大量データ転送に対応するため、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに格納されます。

* リクエストの最大数：2000
* 最も古いリクエストからの最大経過時間：10分
* リクエストの最大サイズ：1 MB

#### パラメーター

|**パラメーター**| **説明**|
|---| ---|
|イベントタイプ| （必須）イベントの一意の識別子。Amplitudeでは、内部使用のために次のイベント名が予約されています：`[Amplitude] Start Session`、`[Amplitude] End Session`、`[Amplitude] Revenue`、`[Amplitude] Revenue (Verified)`、`[Amplitude] Revenue (Unverified)`、`[Amplitude] Merged User`。|
|APIキーのオーバーライド| **APIキー**の構成構成を上書きします。|
|サーバーエンドポイントのオーバーライド| **サーバーエンドポイント**の構成構成を上書きします。|
|Android ID| AndroidデバイスのAndroid ID（広告IDではありません）。|
|アプリバージョン| アプリケーションの現在のバージョン。|
|通信事業者| ユーザーが利用している通信事業者。|
|市区町村| ユーザーがいる市区町村。|
|国| ユーザーがいる国。|
|指定マーケットエリア| ユーザーの現在の指定マーケットエリア（DMA）。|
|デバイスブランド| ユーザーが使用しているデバイスのブランド。|
|デバイスID| iOSのIdentifier for Vendorなど、デバイス固有の識別子。デバイスIDがイベントとともに送信されない場合、デフォルト値はユーザーIDのハッシュ化されたバージョンになります。|
|デバイスのIPアドレス| ユーザーのIPアドレス。AmplitudeはIPアドレスを使用して、ユーザーの所在地（市区町村、国、地域、DMA）を逆引きします。|
|デバイスメーカー| ユーザーが使用しているデバイスのメーカー。|
|デバイスモデル| ユーザーが使用しているデバイスのモデル。|
|イベントID| 同じユーザーIDとタイムスタンプを持つイベントを互いに区別するための増分カウンター。特にイベントが同時に発生することが予想される場合、時間の経過とともに増加するイベントIDを送信することをAmplitudeは推奨しています。|
|Google Play開発者サービスの広告ID| Androidデバイス用のGoogle Play開発者サービス広告ID。|
|iOS Identifier for Advertiser| iOSデバイス用のIdentifier for Advertiser。|
|iOS Identifier for Vendor| iOSデバイス用のIdentifier for Vendor。|
|挿入ID| イベントの一意の識別子。Amplitudeは、過去7日以内に同じデバイスIDおよび挿入IDで送信された後続のイベントを重複排除します。UUIDを生成するか、デバイスID、ユーザーID、イベントタイプ、イベントID、時刻を組み合わせて使用することをAmplitudeは推奨しています。|
|言語| ユーザーが構成した言語。Amplitudeは、ISO 639言語コードを読みやすい言語名に自動変換します（例：`en-US`から`English`）。|
|位置情報の緯度| ユーザーの現在の緯度。|
|位置情報の経度| ユーザーの現在の経度。|
|OS名| ユーザーが使用しているモバイルオペレーティングシステムまたはブラウザーの名前。|
|OSバージョン| ユーザーが使用しているモバイルオペレーティングシステムまたはブラウザーのバージョン。|
|プラットフォーム| データを送信するデバイスプラットフォーム。|
|価格| 商品の購入価格。revenueフィールドが送信されない場合、収益データには必須です。返金には負の値を使用します。|
|製品ID| 購入した商品の識別子。このフィールドには、priceとquantityの両方、またはrevenueを含める必要があります。|
|数量| 購入した商品の数量。指定しない場合、デフォルト値は`1`です。|
|地域| ユーザーの現在の地域。|
|収益| トランザクションによる収益。priceとquantityを乗算した値です。price、quantity、revenueの3つのフィールドをすべて送信した場合、revenue値はpriceとquantityを乗算した値になります。返金には負の値を使用します。|
|収益タイプ| 購入した商品の収益タイプ。このフィールドには、priceとquantityの値、またはrevenueの値を送信する必要があります。|
|セッションID| エポックからの経過時間をミリ秒単位で表したセッションの開始時刻。イベントを特定のシステムに関連付ける場合、このパラメーターが必要です。値`-1`は、値が指定されていないことを表します。|
|時刻| エポックからの経過時間をミリ秒単位で表したイベントのタイムスタンプ。時刻がイベントとともに送信されない場合、デフォルト値はリクエストのアップロード時刻になります。|
|ユーザーID| ユーザーのID。|
|イベントプロパティ| イベントとともに送信する追加データを表すキーと値のペアのディクショナリ。<br>空の値はスキップされ、含まれません。|
|ユーザープロパティ| ユーザーに関連付けられた追加データを表すキーと値のペアのディクショナリ。個別の値はそれぞれ、Amplitudeダッシュボードにユーザーセグメントとして表示されます。<br>空の値はスキップされ、含まれません。|
|グループ| Enterprise限定。<br>ユーザーグループを表すキーと値のペアのディクショナリ。グループの詳細については、[JavaScript SDKの抜粋](https://github.com/amplitude/Amplitude-Javascript#setting-groups)を参照してください。<br>空の値はスキップされ、含まれません。|
|テンプレート変数| データ入力としてテンプレート変数を指定します。詳細については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。<br>ネストされたテンプレート変数には、ドット表記で名前を付けます（例：`items.name`）。<br>ネストされたテンプレート変数は通常、データレイヤーのリスト属性から作成されます。|
|テンプレート| 本文データで参照するテンプレートを指定します。詳細については、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。<br>テンプレートは、サポートされているフィールドに二重波括弧で囲んだ名前を使用して挿入されます。例：`{{SomeTemplateName}}`。|
