## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の構成を構成します。

* **クライアントアカウントID**  
（必須）Criteoの**クライアントID**です。

## アクション構成 — パラメータとオプション

**続行**をクリックしてコネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### 自動重複排除

自動重複排除アクションを使用すると、[Criteo OneTagタグ](https://docs.tealium.com/criteo-onetag-tag/)から生成された一意の識別子をイベントデータセットとともに送信できます。Criteo OneTagタグの構成で**ページビューIDを生成**が有効になっていることを確認してください。イベント属性には、以下の命名規則が使用されます。

`criteo_page_view_id_<TAG_UID>`

たとえば、UIDが`171`のタグから発生したページビューイベントでは、以下の属性値が送信されます。

```nohl
criteo_page_view_id_171
```

タグのUIDは、タグ管理の**タグ**テーブルまたはタグの詳細画面で確認できます。

![](https://docs.tealium.com/images/server-side-connectors/criteo-onetag-uid.png)

自動重複排除を構成するには、**自動重複排除**セクションで**マッピングを追加**を選択します。マッピングでCriteo OneTagタグIDを指定し、**Tealium iQタグID**にマッピングします。

自動重複排除を構成すると、Tealiumはタグ管理から送信されるCriteoページビューIDを自動的に検索し、重複排除のためにイベントペイロードへ追加します。

### アクション — イベントを送信

#### イベントタイプ

| **パラメータ** | **説明** |
| --- | --- |
| イベントタイプ | 送信する標準のWeb、旅行、またはストアイベントです。詳細については、[Criteo Server to Server - Event Payloads](https://guides.criteotilt.com/onetag/s2s/#event-payloads)を参照してください。 |

#### 標準パラメータ

最も正確なデータ収集を行うため、CriteoではIPアドレス、完全なURL、およびユーザーエージェントをマッピングすることを強く推奨しています。

| **パラメータ** | **説明** |
| --- | --- |
| アカウント | データの送信先となるアカウントのパートナーIDです。コネクタ構成画面またはアクション画面で入力できます。アクション画面の値は、コネクタ構成画面の値より優先されます。 |
| サイトタイプ | 閲覧に使用されたデバイスタイプ（またはサイトバージョン）です。使用できる値は、`d`（デスクトップ）、`t`（タブレット）、`m`（モバイル）です。デフォルト値は`d`です。 |
| 完全なURL | イベントがトリガーされたページの完全なURLです。 |
| 直前のURL | イベントがトリガーされたページの直前のURLです。 |
| IP | ユーザーのIPアドレスです。 |
| ユーザーエージェント | ユーザーのブラウザーから取得したユーザーエージェント文字列です。 |
| リテーラー訪問ID | 未認証ユーザーについて、複数のセッション間で一貫して使用される一意のIDです。例：ファーストパーティCookie ID。 |

#### ユーザー識別子

可能な場合、Criteoではマッピング済みユーザーIDとメールアドレスの両方をマッピングすることを推奨しています。メールアドレスを指定すると、利用可能な場合にクロスデバイスアトリビューションが可能になり、マッピング済みユーザーIDがないイベントにも対応できる場合があります。

| **パラメータ** | **説明** |
| --- | --- |
| GUM ID | GUM呼び出しによって返される、ソルト処理済みのCriteoユーザーID（GUM ID）です。詳細については、[Criteo Server to Server - Criteo GUM Call](https://guides.criteotilt.com/onetag/s2s/#criteo-gum-call)を参照してください。 |
| GAID | Googleの広告識別子です。 |
| IDFA | Appleの広告主向け一意識別子です。 |
| 未加工メールアドレス | ユーザーの未加工メールアドレスです。空でない最初のメールパラメータが使用されます。 |
| メールMD5（MD5ハッシュを適用） | ユーザーのハッシュ化されていないメールアドレスです。 |
| メールMD5（MD5でハッシュ化済み） | MD5でハッシュ化されたユーザーのメールアドレスです。 |
| メールSHA256（SHA256ハッシュを適用） | ユーザーのハッシュ化されていないメールアドレスです。 |
| メールSHA256（SHA256でハッシュ化済み） | SHA256でハッシュ化されたユーザーのメールアドレスです。 |
| メールSHA256 MD5（SHA256 MD5ハッシュを適用） | ユーザーのハッシュ化されていないメールアドレスです。 |
| メールSHA256 MD5（SHA256 MD5でハッシュ化済み） | MD5およびSHA256でハッシュ化されたユーザーのメールアドレスです。 |

#### イベントパラメータ

| **パラメータ** | **説明** |
| --- | --- |
| ID | 特定の注文を識別するために使用される注文IDです。 |
| アイテム（上位3製品） | ユーザーが訪問したリストページに表示された上位3製品の配列です。 |
| アイテム（製品ID） | ユーザーが閲覧した製品の製品IDです。 |
| アイテムID（文字列または配列） | カート内の製品の製品ID、単価、数量です。値には、カンマ（`","`）区切りの文字列または配列を使用できます。 |
| アイテム価格（文字列または配列） | カート内の製品の単価です。値には、カンマ区切りの文字列または配列を使用できます。 |
| アイテム数量（文字列または配列） | カート内の製品の数量です。値には、カンマ区切りの文字列または配列を使用できます。 |
| アイテム価格（Tally） | アイテムIDから数値への有効なJSONマップを含むTally属性または文字列属性です。例：`{"PID1":1.99,"PID2":3.99}`。構成する各Tallyについて、アイテムIDをTallyのキーとして、プロパティ値をTallyの値として使用してください。 |
| アイテム数量（Tally） | アイテムIDから数値への有効なJSONマップを含むTally属性または文字列属性です。例：`{"PID1":1.99,"PID2":3.99}`。構成する各Tallyについて、アイテムIDをTallyのキーとして、プロパティ値をTallyの値として使用してください。 |
| 通貨 | タグに渡される通貨のISOコードです。 |
| タイムスタンプ | ユーザーに対してイベントが発生した時刻を、ISO 8601 UTC形式`YYYY-MM-DDThh:mm:ssZ`で指定します。タイムスタンプを指定しない場合は、現在のタイムスタンプが使用されます。 |
| チェックイン日 | ユーザーが送信したチェックイン日を`YYYY-MM-DD`形式で指定します。 |
| チェックアウト日 | ユーザーが送信したチェックアウト日を`YYYY-MM-DD`形式で指定します。 |
| NBRA | 検索に含まれる大人の人数です。 |
| NBRC | 検索に含まれる子供の人数です。 |
| NBRI | 検索に含まれる乳児の人数です。 |
| NBRR | 検索に含まれる客室数です。 |
| ストアID | フィードで渡されたストアIDです。 |
| ストアID一覧 | フィードで渡されたストアIDです。製品を取り扱うストアの配列です。 |
| DD | 売上をCriteoにアトリビューションする場合は**1**、しない場合は**0**を構成します。通常のアトリビューションによって注文がCriteoに帰属すると判断された場合にのみ、その売上がCriteoにアトリビューションされます。 |
| カテゴリ | リストページのカテゴリです。 |
| キーワード | 検索結果リストページで検索されたキーワードです。 |

#### 自動重複排除

タグ管理のタグUIDを指定すると、タグ管理から送信されたイベントID値が自動的に検索されます。
