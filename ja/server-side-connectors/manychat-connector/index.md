## API情報

このコネクターは、次のベンダーAPIを使用します。

* API名：Manychat API
* APIエンドポイント：`https://api.manychat.com`
* ドキュメント：[Manychat API](https://api.manychat.com/swagger#/)

## 構成

コネクターマーケットプレイスに移動し、新しいコネクターを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクターを追加したら、次の項目を構成します。

* **APIキー**  
  *   Manychatでは、Account Public APIで使用するAPIキーが提供されます。

コネクターを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| 名前でタグを追加 | ✓ | ✗ |
| 名前でタグを削除 | ✓ | ✗ |
| 名前でカスタムフィールドを構成 | ✓ | ✗ |
| 購読者をアップサート | ✓ | ✗ |
| メッセージを送信 | ✓ | ✗ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメーターとオプションの構成方法について説明します。

### 名前でタグを追加

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| 購読者ID | 購読者の一意の識別子。 |
| タグ名 | 購読者に付けるタグのラベル。 |

### 名前でタグを削除

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| 購読者ID | 購読者の一意の識別子。 |
| タグ名 | 購読者から削除するタグ。 |

### 名前でカスタムフィールドを構成

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| 購読者ID | 購読者の一意の識別子。 |
| フィールド名 | 値を構成するフィールドの名前。 |
| フィールド値 | フィールドの値。 |
| 日時フィールド | （任意）カスタムフィールドで日時形式（`YYY-MM-DDTHH:MM:SS+00:00`）が必要な場合は、チェックボックスを選択します。それ以外の場合は、`YYYY-MM-DD`形式が使用されます。 |

### 購読者をアップサート

#### 購読者パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| 購読者ID | 購読者の一意の識別子。 |
| 名 | 購読者の名。 |
| 姓 | 購読者の姓。 |
| 電話番号 | 購読者の電話番号。 |
| メールアドレス | 購読者のメールアドレス。 |
| WhatsApp電話番号 | 購読者のWhatsApp電話番号。 |
| 性別 | 購読者の性別。 |
| SMSオプトイン済み | 真偽値。電話番号プロパティが空でない場合は必須です。 |
| メールオプトイン済み | 真偽値。メールプロパティが空でない場合は必須です。 |
| 同意文言 | SMSオプトイン済みプロパティが`true`の場合は必須です。 |

### メッセージを送信

#### メッセージパラメーター

| **パラメーター** | **説明** |
| --- | --- |
| 購読者ID | 購読者の一意の識別子。 |
| データ | メッセージデータ。このオブジェクトの作成にはテンプレート変数を使用する必要があります。[詳細情報](https://manychat.github.io/dynamic_block_docs/)。 |
| メッセージタグ | メッセージを表すタグ。例：`ACCOUNT_UPDATE`。 |
| OTNトピック名 | One-Time Notificationのトピック名。例：チャンネルニュース。 |
| テンプレート変数 | **テンプレート**のデータ入力としてテンプレート変数を指定します。<br>詳細および使用例については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。<br>ネストされたテンプレート変数には、ドット表記で名前を付けます。例：items.name。<br>ネストされたテンプレート変数は通常、データレイヤーのリスト属性から作成されます。 |
| テンプレート | データフィールドで参照するテンプレートを指定します。詳細については、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。<br>テンプレートは、サポートされているフィールドに二重波括弧で囲んだ名前を使用して挿入されます。例：`{{SomeTemplateName}}`。 |
