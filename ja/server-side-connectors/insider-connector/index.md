## API情報

このコネクタは、次のベンダーAPIを使用します。

*   API名：Insider API
*   APIバージョン：v1
*   APIエンドポイント：`https://unification.useinsider.com/api/user/v1`
*   ドキュメント：[Insider API](https://academy.useinsider.com/docs/api-reference-insider-apis)

## コネクタアクション

| **アクション名** | **訪問プロファイル** | **イベントデータ** |
| --- | --- | --- |
| アップサートおよび購読（バッチ） | ✓ | ✓ |
| アップサートおよび購読（リアルタイム） | ✓ | ✓ |
| アトリビューションの削除（バッチ） | ✓ | ✓ |
| アトリビューションの削除（リアルタイム） | ✓ | ✓ |
| ユーザーの削除 | ✓ | ✓ |

### バッチ制限

このコネクタは、ベンダーへの大容量データ転送をサポートするためにバッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルが公開されるまで、リクエストはキューに入れられます。

*   リクエストの最大数：1000
*   最も古いリクエストからの最大経過時間：10分
*   リクエストの最大サイズ：5 MB

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。

*   **パートナー名**<br>**Inone > Inone Settings > [Account Preferences](https://academy.useinsider.com/docs/account-preferences)**に移動し、パートナー名をコピーして貼り付けます。
*   **APIキー**<br>リクエストを認証するにはAPIキーが必要です。トークンの生成方法については、[API認証トークン](https://academy.useinsider.com/docs/api-authentication-tokens)を参照してください。

コネクタの構成が完了したら、**完了**をクリックします。

## アクション構成 — パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、アクションタイプを選択します。

### アクション — アトリビューションの削除（バッチまたはリアルタイム）

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| | **ユーザー識別子** |
| メールアドレス | ユーザーのメールアドレス。 |
| 電話番号 | E.164形式のユーザーの電話番号。例：+6598765432。 |
| UUID | ユーザーのUUIDパラメータ。 |
| ユーザーカスタム識別子 | ユーザーのカスタム識別子情報を指定します。デフォルトまたはカスタムのユーザー識別子を少なくとも1つ指定する必要があります。 |
| | **ユーザー属性** |
| デフォルトユーザー属性の完全削除 | 対応するユーザーから完全に削除するデフォルトユーザー属性を選択します。 |
| カスタムユーザー属性の完全削除 | 対応するユーザーから完全に削除するカスタムユーザー属性を選択します。 |
| デフォルトユーザー属性の部分削除 | 部分的に削除するデフォルトユーザー属性を選択します。たとえば、配列属性から値の1つを削除します。部分削除できるのは配列型属性のみです。複数の値を削除するには、配列型属性を使用します。単一値属性は、単一の値を含む配列に変換されます。 |
| カスタムユーザー属性の部分削除 | 部分的に削除するカスタムユーザー属性を選択します。たとえば、配列属性から値の1つを削除します。部分削除できるのは配列型属性のみです。複数の値を削除するには、配列型属性をマッピングします。単一値属性は、単一の値を含む配列に変換されます。 |
| リストID | （任意）部分削除の場合のみ。ニュースレターの連絡先リストID（ユーザーは直接追加されます）。 |
