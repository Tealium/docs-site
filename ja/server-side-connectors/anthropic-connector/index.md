## 仕組み

このコネクタは、カスタムプロンプトおよびマッピングされたTealiumデータを使用してAnthropicモデルを呼び出し、その応答をJSONイベントとしてTealium Collectに送り返して、リアルタイムエンリッチメントを実行します。


<blockquote>
このコネクタは、大量のイベントではなく、対象を絞った価値の高いインタラクションに使用してください。過度に使用すると、ベンダーアカウントでレート制限が適用されたり、APIコストが増加したりする可能性があります。また、Tealiumへの受信イベント量も増加します。
</blockquote>


## 使用量とコストに関する考慮事項

このコネクタを有効化する前に、アカウントの制限、使用量ティア、料金モデルを確認してください。このコネクタは、イベントおよびオーディエンスのトリガーによっては大量のリクエストを生成し、予期しない使用料金や超過料金が発生する可能性があります。

詳細については、[Claude APIドキュメント：レート制限](https://platform.claude.com/docs/en/api/rate-limits)を参照してください。

## API情報

このコネクタでは、次のベンダーAPIを使用します。

* API名：Anthropic API
* APIバージョン：v1
* APIエンドポイント：`https://api.anthropic.com/v1`
* ドキュメント：[Anthropic API](https://platform.claude.com/docs/en/home)

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **Anthropic APIキー**：このコネクタからAnthropic APIへのリクエストを認証するためのAnthropic APIキーです。Anthropicアカウント構成でAPIキーを作成および管理します。

コネクタを構成した後、**完了**をクリックします。

### Anthropicにプロンプトを送信


<blockquote>
AIコネクタの仕組みとプロンプトの構成方法の概要については、[AIコネクタ](https://docs.tealium.com/ai-connectors-and-functions/)のガイドを参照してください。
</blockquote>


#### マッピング

| **パラメータ** | **説明** |
| --- | --- |
| モデル | このプロンプトに使用するAnthropicモデルを選択します。パフォーマンスとコストの要件に合ったモデルを選択してください。 |

#### Tealiumコンテキスト

このコネクタは、AIモデルの呼び出し時、および構造化された応答を返す際に、重要なTealium属性を自動的に含めます。

次の属性はAIリクエストに自動的に追加され、構造化出力JSONにも含まれます：`tealium_account`、`tealium_profile`、`tealium_visitor_id`。

これらの値は現在のイベントから取得されるため、プロンプト内で参照する必要はありません。マッピングを使用してこれらの値を上書きできます。

| **パラメータ** | **説明** |
| --- | --- |
| `tealium_event` | （必須）Tealiumに返されるAI応答に含める`tealium_event`値を入力します。 |
| `tealium_datasource` | （任意）このコネクタからの応答イベントに関連付けるデータソースキーです。 |
| プロンプトパラメータ | Tealium属性を、プロンプトテンプレートで使用するプレースホルダー名にマッピングします。たとえば、`Lifetime Value`を`lifetime_val`にマッピングし、プロンプトテンプレート内で`{{lifetime_val}}`を参照します。 |
| イベントペイロードを含める | （イベントアクションで使用可能）このチェックボックスをオンにすると、イベントペイロードを変数`{{event_payload}}`としてプロンプトテンプレートで使用できます。 |
| 訪問プロファイルを含める | （オーディエンスアクションで使用可能）有効にすると、訪問プロファイル全体を`{{visitor_profile}}`としてプロンプトで使用できます。 |
| 現在の訪問を含める | （オーディエンスアクションで使用可能）有効にすると、現在の訪問属性が`{{visitor_profile}}`オブジェクトに追加されます（属性名をキーとして使用）。 |
| プロンプト | 選択したAnthropicモデルに送信するプロンプトを入力します。一貫性があり、機械可読な出力を得るために、次のガイドラインに従ってください：<br>マッピングされたパラメータには二重波括弧を使用します。例：`{{product_id}}`、`{{event_value}}`。<br>オーディエンスコネクタのアクションでは、`Include visitor profile`を有効にしてから`{{visitor_profile}}`を参照します。<br>イベントコネクタのアクションでは、`Include current event payload`を有効にしてから`{{event_payload}}`を参照します。<br>JSON形式を指示する文（例：`Return only JSON`）を含めないでください。コネクタがJSON構造を自動的に適用します。 |

#### モデルの詳細構成

| **パラメータ** | **説明** |
| --- | --- |
| `temperature` | ランダム性と創造性を制御します（値が低いほど決定論的になります）。 |
| `max_tokens` | モデルが生成できるトークンの最大数です。値を指定しない場合、コネクタによってデフォルト値の512が構成されます。 |
| `top_p` | 上位pの確率質量のみからサンプリングすることで、多様性を制御します。 |

#### 構造化出力（JSONスキーマ）

AI応答に含める属性を定義します。これらのマッピングによって、`output_config`を使用してAnthropicに送信されるスキーマが決まり、応答JSONがそのスキーマに一致することが保証されます。


<blockquote>
プロンプトにJSON形式を指示する文を追加しないでください。これらのマッピングから派生したスキーマによって、構造が自動的に適用されます。
</blockquote>


| **パラメータ** | **説明** |
| --- | --- |
| 属性名 | AI応答イベントに含める属性名です。エンリッチメント用に、一致するイベント属性を作成する必要があります。 |
| 必須／任意 | 応答イベントで属性を必須とするか任意とするかを指定します。 |
| データ型 | フィールドのデータ型です（文字列、数値、整数、またはブール値）。 |
| デバッグモード | 有効にすると、コネクタはTealium Collectに応答を送信しません。完全な処理を有効にする前に、Traceを使用してAnthropicの未加工の応答を調査し、有効なJSONであることを検証してください。 |
