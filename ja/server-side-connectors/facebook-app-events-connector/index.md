## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Facebook Graph API - Marketing API
* APIバージョン：v25.0
* APIエンドポイント：`https://graph.facebook.com`

## 仕組み

このAPIを使用してアプリのインストールとアプリ内コンバージョンを報告し、Facebook Analyticsにデータを送信します。Facebook SDKを使用せずにモバイルデバイスで利用できます。詳細については、[Facebook App Events API](https://developers.facebook.com/docs/marketing-api/app-event-api#install_parameters)のドキュメントを参照してください。

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。

* **アプリケーションID**：Facebook for Developersのアプリダッシュボードに表示されているアプリID。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 顧客データプラットフォーム（CDP） | イベントストリーミング |
|:----------------|:-------------------|:----------------|
| イベントを送信 | ✓ | ✓ |

**続行**をクリックして、コネクタのアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。
