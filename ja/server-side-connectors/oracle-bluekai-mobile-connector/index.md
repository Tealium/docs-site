## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を構成します。

* **サイトID**：BlueKaiコンテナから提供され、BlueKaiプラットフォーム上のデスクトップサイトとモバイルサイトを関連付けます。

## アクション構成 — パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### アクション — ピクセルを送信

#### パラメータ

| **パラメータ**   | **説明**                                                                                                                                                                                                                                                                 |
|:----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ユーザーエージェント      | <ul><li>指定した場合、その値が`User-Agent`ヘッダーで使用されます</li><li>指定しない場合、デフォルトは`Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/69.0.3497.100 Safari/537.36`です</li></ul>                                        |
| ユーザーIDタイプ    | <ul><li>ユーザー識別子のタイプ</li><li>BlueKai Webサイトの[IDスワッピング](https://docs.oracle.com/en/cloud/saas/data-cloud/dsmkt/integrating-oracle-bluekai-platform.html#GUID-A8856438-EF6A-4BCE-A2E4-B4CE725B0E61)ガイドラインを参照してください</li></ul>                                    |
| ユーザーID値   | <ul><li>ユーザー識別子の値</li></ul>                                                                                                                                                                                                                                      |
| IDハッシュ化      | <ul><li>ユーザーIDをハッシュ化する場合はオンにします</li><li>メールアドレスと電話番号はハッシュ化する必要があります</li></ul>                                                                                                                                                                                       |
| ハッシュタイプ       | <ul><li>ハッシュアルゴリズムを選択します</li><li>メールアドレスと電話番号は、MD5またはSHA256でハッシュ化する必要があります</li><li>ANDROIDIDは、MD5またはSHA1でハッシュ化する必要があります</li><li>ADIDとIDFAは、MD5またはSHA1でハッシュ化するか、ハッシュ化せずに使用する必要があります</li></ul> |
| Phints          | <ul><li>Phintsをキーと値のペアとして指定します</li><li>左側の値が右側のキーに割り当てられます</li></ul>                                                                                                                                                        |
| 追加データ | <ul><li>追加データをキーと値のペアとして指定します</li><li>このデータに追加処理は行われません</li></ul>                                                                                                                                                        |
