## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。

* **APIユーザー名**
* **APIパスワード**
* **サーバーホスト**  
適切なサーバーホストについては、Oracle Responsysの担当者にお問い合わせください。  

<blockquote>
サーバーホストを入力する際は、プロトコルやパスを含めないでください。
</blockquote>


## アクション構成 - パラメーターとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、リストからアクションタイプを選択します。

### アクション - 訪問をプロファイル拡張テーブルにマージ

|**パラメーター**| **説明**|
|---| ---|
|テーブルフォルダー名| 必須|
|テーブルオブジェクト名| 必須|
|更新方法| <ul><li>（必須）既存のレコードをどのように更新するかを制御します。</li><li>NO_UPDATE — このオプションを選択した場合、既存のレコードが一致しても更新されません。そのため、INSERTのみを実行するには、このオプションを使用します。</li><li>REPLACE_ALL — このオプションを選択した場合、既存のレコードが一致すると、構成されているすべてのプロパティが更新されます。</li></ul> |
|RIID|
|CUSTOMER_ID|
|EMAIL_ADDRESS|
|構成するデータ列に空の値を渡す| 任意|
|構成するデータ列| 必須。マージするレコードデータを指定してください。|

### アクション - 訪問を補足テーブルにマージ

|**パラメーター**| **説明**|
|---| ---|
|テーブルフォルダー名| 必須|
|テーブルオブジェクト名| 必須|
|更新方法| <ul><li>必須。既存のレコードをどのように更新するかを制御します。</li><li>NO_UPDATE — このオプションを選択した場合、既存のレコードが一致しても更新されません。そのため、INSERTのみを実行するには、このオプションを使用して、**一致しない場合に挿入**チェックボックスをオンにします。</li><li>REPLACE_ALL — このオプションを選択した場合、既存のレコードが一致すると、構成されているすべてのプロパティが更新されます。</li></ul> |
|一致しない場合に挿入| 任意|
|構成するデータ列に空の値を渡す| 任意|
|構成するデータ列| <ul><li>（必須）主キー列が含まれていることを確認してください。</li><li>リストを渡すにはリスト属性を使用し、すべてのリストのインデックス長が同じであることを確認してください。</li></ul> |
