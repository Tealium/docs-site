## バッチ処理の制限
このコネクタは、ベンダーへの大量のデータ転送をサポートするために、バッチリクエストを使用します。詳細については、「バッチアクション」を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに保持されます。

* リクエストの最大数：100,000
* 最も古いリクエストからの最大経過時間：60分
* リクエストの最大サイズ：100 MB

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **テナントID**：組織を表すAzure Active Directoryインスタンスの一意の識別子。
* **認証タイプ**：認証タイプを選択します。使用可能なオプションは、クライアント資格情報、認可コードフロー（SSO）、共有アクセス署名（SAS）です。
* **クライアントID**：Azure Active Directoryに登録されたアプリケーションに割り当てられた一意の識別子。
* **クライアントシークレット**：パスワードとして機能し、アプリケーションがAzure Active Directoryで認証するために使用する文字列。
* **共有アクセス署名**：Tealiumがリソースにアクセスする方法を指定する、特別なクエリパラメータのセットを指定します。
* **保存アカウント名**：Azure Storageアカウントの一意の名前。Blob、File、Queue、Table保存などの保存サービスへのアクセスに使用されます。
* **APIバージョン**：Azure Storageインスタンスと互換性のあるAPIバージョン。デフォルト：2025-01-05。

コネクタを構成したら、**完了**をクリックします。

### イベントデータ全体を送信

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| コンテナ | オブジェクトを作成するコンテナを選択します。このコンテナは、ファイルシステムのフォルダと同様に、Blobのセットを整理するアカウント内の最上位保存単位です。 |
| Blobパス | データを追加するBlobオブジェクトのパスを指定します。 |
| ファイルBlobサフィックス | 現在のタイムスタンプを持つ属性など、ファイル名にサフィックスを動的に追加する場合は、ここで選択します。複数のサフィックス値を指定した場合は、アンダースコア文字で区切られます。 |
| レコードサフィックス | <ul><li>区切り文字として各レコードの末尾に追加するサフィックス。</li><li>デフォルトは`Newline`です。</li><li>使用可能なオプションは`Newline`と`No Delimiter`です。</li></ul> |
| 既存のBlobを上書き | Blobオブジェクトがすでに存在する場合、現在のデータで上書きします。選択しない場合、データは代わりに追加されます。データを追加する場合、各ブロックは、Tealiumから転送されるデータのペイロードを含む`JSON`オブジェクトのグループで構成されます。 |
| 属性名を出力 | デフォルトでは、属性キーが使用されます。代わりに属性名をキーとして使用する場合は、このチェックボックスをオンにします。ペイロードの名前には、属性名に対するすべての更新が反映されることに注意してください。 |
| バッチの有効期間 | バッチアクションを送信する頻度を指定するため、有効期間（TTL）を構成します。`1`～`60`分の値を入力します。デフォルト値は`10`分です。 |

### カスタムビジターデータを送信
#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| Container | オブジェクトを作成するコンテナーを選択します。このコンテナーは、ファイルシステムのフォルダーと同様に、一連の Blob を整理するアカウント内の最上位保存単位です。 |
| Blob Path | データを追加する Blob オブジェクトのパスを指定します。 |
| File Blob Suffix | 現在のタイムスタンプを持つ属性など、ファイル名にサフィックスを動的に追加する場合は、ここで選択します。複数のサフィックス値を指定した場合は、アンダースコア文字で区切られます。 |
| Record Suffix | <ul><li>区切り文字として各レコードの末尾に追加するサフィックス。</li><li>デフォルトは `Newline` です。</li><li>使用可能なオプションは `Newline` と `No Delimiter` です。</li></ul> |
| Overwrite Existing Blob | Blob オブジェクトがすでに存在する場合、現在のデータで上書きします。選択しない場合は、データが追加されます。データを追加する場合、各ブロックは、Tealium から転送されたデータをペイロードに含む `JSON` オブジェクトのグループで構成されます。 |
| Message Data | <ul><li>メッセージデータを構成するための値を指定します。</li><li>テンプレートのサポート：テンプレートからメッセージデータを生成するには、テンプレート名を参照します。テンプレートを使用する場合は、Custom Message Definition にマッピングします。テンプレートを使用すると、その他のキーと値のペアは無視されます。</li></ul> |
| Template Variables | <ul><li>**Templates** のデータ入力としてテンプレート変数を指定します。詳細および使用例については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。</li><li>ネストされたテンプレート変数には、ドット表記で名前を付けます。例：`items.name.`</li><li>ネストされたテンプレート変数は、通常、データレイヤーのリスト属性から構築されます。</li></ul> |
| Templates | <ul><li>Message Data で参照するテンプレートを指定します。詳細については、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。</li><li>テンプレートは、サポートされているフィールドに二重波括弧を使用して名前で挿入されます。例：`{{SomeTemplateName}}`</li></ul>|
| Batch Time To Live | バッチアクションを送信する頻度を指定するために、有効期間（TTL）を構成します。`1`～`60`分の値を入力します。デフォルト値は`10`分です。 |

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| Container | オブジェクトを作成するコンテナーを選択します。このコンテナーは、ファイルシステムのフォルダーと同様に、一連の Blob を整理するアカウント内の最上位保存単位です。 |
