## API情報

このコネクタは、以下のベンダーAPIを使用します。

* API名：Movable Ink API
* APIバージョン：v1.0
* APIエンドポイント：`https://collector.movableink-dmz.com/behavioral/`
* ドキュメント：[Movable Ink API](https://support.movableink.com/hc/en-us/articles/10252591570071)

## コネクタのアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| イベントを送信 | ✓ | ✓ |

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の構成を構成します。

* **アクセストークンID**：（必須）アクセストークンID。
* **アクセストークンシークレット**：（必須）アクセストークンシークレット。
* **行動エンドポイント**：（必須）行動エンドポイントのURL。

## アクション

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

以下のセクションでは、各アクションのパラメーターとオプションを構成する方法について説明します。

### イベントを送信

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| イベントタイプ | イベントのタイプ。 |
| イベントサブタイプ | イベントのサブタイプを指定します。 |
| タイムスタンプ | イベントが発生した時刻（Unix時間）。値が指定されていない場合、コネクタはイベント時刻を使用します。 |
| タイムゾーン | イベントが発生した場所のタイムゾーン（IANAタイムゾーンデータベース内のTZデータベース名）。 |
| ユーザーID | このイベントをトリガーしたプロファイルの一意の識別子。 |
| 匿名ID | このイベントをトリガーした匿名プロファイルの一意の識別子。 |
| プロパティのメタ情報 | イベントに関する追加のコンテキストを提供するメタデータのマップ。 |
