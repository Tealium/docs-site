Google Analytics 4 Measurement Protocol は、gtag、GTM、または Firebase を使用して収集される既存のイベントを補完することを目的としています。一部のイベント名とパラメータ名は自動収集用に予約されているため、Measurement Protocol では送信できません。Google Analytics 4 Measurement Protocol コネクタを使用すると、gtag、GTM、または Firebase を使用せずにイベントを Google Analytics に送信できますが、利用できるレポート機能が一部に限られる場合があります。

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **API Secret（必須）**  
Google Analytics UI で生成された API Secret。シークレットを作成するには、**管理 > データストリーム > ストリームを選択 > Measurement Protocol > 作成**に移動します。
* **Measurement ID（任意）**  
ストリームに関連付けられた Measurement ID。Google Analytics UI の **管理 > データストリーム > ストリームを選択 > Measurement ID** にあります。
* **Firebase App ID（任意）**  
Firebase App ID。Firebase アプリの識別子です。Firebase コンソールの **プロジェクトの構成 > 全般 > マイアプリ > アプリ ID** にあります。

### クライアント ID のマッピング

クライアント ID は、Web クライアントのユーザーインスタンスを一意に識別する、Web ベースのイベントに必須のパラメータです。

Google Analytics は、クライアント ID を `_ga` という名前の Cookie に保存します。この Cookie の形式は `GA1.2.12349876.1500644855` で、クライアント ID は `12349876.150064485` です。`clientId` の値は Google Analytics トラッカーから直接取得できます。

* 正しい形式のクライアント ID 値を指定すると、コネクタはその値を使用します。
* イベントの `client_id` マッピングに完全な `_ga` Cookie 値が含まれている場合、コネクタは自動的に解析し、クライアント ID の部分のみを抽出します。
* イベントデータに `cp.utag_main__ga` があり、正しい形式のクライアント ID が含まれている場合、コネクタはその値を `client_id` に自動的にマッピングします。

### 同意

デフォルトでは、コネクタは同意シグナルを送信しません。同意を指定しない場合、Google Analytics は、そのクライアントインスタンスに対応するオンラインインタラクションの同意構成を使用します。`ad_user_data` と `ad_personalization` の同意を構成する際、同意の状態は許可または拒否のいずれかになります。

#### デバイス情報

リクエスト内のイベントにデバイス情報を含めるには、ユーザーエージェントまたはデバイスレベルの属性を使用します。
デバイス属性をマッピングした場合、ユーザーエージェントは無視されます。

リクエストにデバイス情報もユーザーエージェントも指定されていない場合、Google Analytics はクライアント ID を使用して、タグ付けイベントからデバイス情報を取得します。

Google は、最低限必要なカテゴリを含め、できるだけ多くのデバイス属性を指定することを推奨しています。

| **パラメーター** | **説明** |
| --- | --- |
| カテゴリ | デバイスのカテゴリ。例：`desktop`、`tablet`、`mobile`、`smart TV`。 |
| 言語 | ISO 639-1 形式の言語。例：`en` または `en-US`。 |
| 画面解像度 | `WIDTHxHEIGHT` 形式のデバイス解像度。例：`1280x2856`。 |
| オペレーティングシステム | オペレーティングシステムまたはプラットフォーム。例：`MacOS`。 |
| オペレーティングシステムのバージョン | オペレーティングシステムまたはプラットフォームのバージョン。例：`13.5`。 |
| モデル | デバイスのモデル。例：`Pixel 9 Pro` または `Samsung Galaxy S24`。 |
| ブランド | デバイスのブランド。例：`Google` または `Samsung`。 |
| ブラウザー | ブラウザーのブランドまたは種類。例：`Chrome` または `Firefox`。 |
| ブラウザーのバージョン | ブラウザーのバージョン。例：`136.0.7103.60` または `5.0`。 |

#### 地理情報

位置情報属性をマッピングした場合、IP オーバーライドのマッピングは無視されます。

Google は、最低限必要な国 ID と地域 ID を含め、できるだけ多くの属性を指定することを推奨しています。

詳細については、[Google Analytics Measurement Protocol：地理情報](https://developers.google.com/analytics/devguides/collection/protocol/ga4/reference?client_type=gtag#payload_geo_info)を参照してください。

| **パラメーター** | **説明** |
| --- | --- |
| 市区町村 | 訪問の市区町村名。 |
| 地域 ID | 訪問の国および行政区画を表す ISO 3166 コード。例：`US-CA`、`US-AR`、`CA-BC`、`GB-LND`、`CN-HK`。 |
| 国 ID | ISO 3166-1 alpha-2 形式で表した訪問の国。例：`US`、`AU`、`ES`、`FR`。 |
| 亜大陸 ID | UN M49 形式で表した訪問の亜大陸。例：`011`、`021`、`030`、`039`。 |
| 大陸 ID | UN M49 形式で表した訪問の大陸。例：`002`、`019`、`142`、`150`。 |

| **パラメーター** | **説明** |
| --- | --- |
| メールアドレス（SHA256 でハッシュ済み） | 空白の除去、小文字への変換、SHA256 によるハッシュ化がすでに行われたメールアドレスを指定します。`gmail.com` および `googlemail.com` のメールアドレスについては、ハッシュ化する前にドメイン名より前にあるすべてのピリオド（`.`）を削除してください。 |
| メールアドレス（SHA256 ハッシュを適用） | プレーンテキストのメールアドレスを指定します。コネクターは、`gmail.com` および `googlemail.com` のメールアドレスについて、ドメイン名より前にあるすべてのピリオド（`.`）を削除した後、空白の除去、小文字への変換、SHA256 によるハッシュ化を行います。 |

## デバッグ

Google Analytics 4 Measurement Protocol には、イベントを検証するための次のエンドポイントが用意されています。

```none
https://google-analytics.com/debug/mp/collect?
```

Tealium Google Analytics 4 Measurement Protocol コネクタは、[Trace](https://docs.tealium.com/about-trace/) 中にこのエンドポイントを使用し、イベントデータの検証に関する情報を提供します。Trace 内の API 呼び出しの HTTP レスポンスコンテンツで、Google Analytics 4 Measurement Protocol の検証メッセージを確認できます。
