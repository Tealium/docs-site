Epsilon はマーケティングサービスプロバイダーです。Epsilon Event API を使用すると、顧客がウェブサイト上で閲覧した商品や購入した商品に関する情報を Epsilon に送信できます。

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、以下の構成を構成します。

* **会社 ID**：呼び出しを識別するための会社 ID（`dtm_cid`）。
* **セカンダリ会社 ID**：会社 ID を確認するための別の識別子（`dtm_cmagic`）。

## アクション

| **アクション名** | **訪問プロファイル** | **イベントデータ** |
| --- | --- | --- |
| 閲覧イベントを送信 | ✗ | ✓ |
| トランザクションイベントを送信 | ✗ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

以下のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### 閲覧イベントを送信

#### イベントデータ

| **パラメータ** | **説明** |
| --- | --- |
| フォーム ID（`dtm_fid`） | （必須）閲覧イベントのフォーム ID。 |
| URL（`dtmc_loc`） | （必須）ユーザーが閲覧しているページの URL。 |
| IP アドレス（`dtm_user_ip`） | （必須）ユーザーの IP アドレス。 |
| Cookie ID（`dtm_cookie_id`） | （必須）ユーザーの一意の ID。 |
| プロモーション ID（`dtm_promo_id`） | ページタイプまたはプロモーションのコンテキストを識別する値。 |
| ブランド（`dtmc_brand`） | 閲覧された商品またはコンテンツに関連付けられたブランド。 |
| 正規 URL（`dtmc_canonical_url`） | 閲覧されているページの正規 URL。 |
| カテゴリ（`dtmc_category`） | 商品またはコンテンツの主要カテゴリ。 |
| 顧客 ID（`dtm_user_id`） | 既知の顧客を表す一意の識別子（CRM ID やロイヤルティ ID など）。 |
| 部門（`dtmc_department`） | 商品に関連付けられた部門または事業分野（`Electronics`、`Home` など）。 |
| メールアドレス（SHA256 ハッシュを適用） | Epsilon に送信する前に SHA256 でハッシュ化するプレーンテキストのメールアドレス。 |
| メールアドレス（SHA256 でハッシュ化済み） | SHA256 ですでにハッシュ化されているメールアドレス。指定された状態のまま Epsilon に送信されます。 |
| GDPR 同意（`dtmc_tcf_string`） | 訪問の GDPR 同意状態を表す IAB TCF 同意文字列。 |
| メーカーのモデル／部品番号（`dtmc_mpn`） | 商品に対するメーカーのモデル番号または部品番号。 |
| メーカー UPC（`dtmc_upc`） | 商品に対するメーカーの UPC。 |
| 商品 ID（`dtmc_product_id`） | 閲覧されている商品を表す一意の識別子。 |
| 参照元 URL（`dtm_referrer`） | 訪問を現在のページに誘導したページの URL。 |
| サブカテゴリ（`dtmc_sub_category`） | 商品またはコンテンツのサブカテゴリ（`Apparel` 内の `Shoes` など）。 |
| ユーザーエージェント（`dtm_user_agent`） | 訪問のデバイスから取得したブラウザのユーザーエージェント文字列。 |
| キャッシュバスター | レスポンスのキャッシュを防ぐために使用するランダム値またはタイムスタンプ値。 |
| GPP 文字列 | （必須）Global Privacy Platform（GPP）の同意文字列。 |
| カスタムクエリパラメータ | ベース URL にクエリ文字列パラメータとして追加するカスタム値。 |

#### イベントデータ

| **パラメータ** | **説明** |
| --- | --- |
| フォーム ID（`dtm_fid`） | （必須）トランザクションイベントのフォーム ID。 |
| URL（`dtmc_loc`） | （必須）トランザクションが発生するページの URL（確認ページなど）。 |
| IP アドレス（`dtm_user_ip`） | （必須）ユーザーの IP アドレス。 |
| Cookie ID（`dtm_cookie_id`） | （必須）ユーザーを識別するために広告主が指定する Cookie ID。 |
| プロモーション ID（`dtm_promo_id`） | トランザクションに関連付けられたページタイプまたはプロモーションを識別する値。 |
| ブランド（`dtmc_brand`） | 購入された商品に関連付けられたブランド。 |
| 正規 URL（`dtmc_canonical_url`） | トランザクションページの正規 URL。 |
| カテゴリ（`dtmc_category`） | 商品またはコンテンツの主要カテゴリ。 |
| 顧客 ID（`dtm_user_id`） | 既知の顧客を表す一意の識別子（CRM ID やロイヤルティ ID など）。 |
| 部門（`dtmc_department`） | 商品に関連付けられた部門または事業分野。 |
| メールアドレス（SHA256 ハッシュを適用） | Epsilon に送信する前に SHA256 でハッシュ化するプレーンテキストのメールアドレス。 |
| メールアドレス（SHA256 でハッシュ化済み） | SHA256 ですでにハッシュ化されているメールアドレス。指定された状態のまま Epsilon に送信されます。 |
| GDPR 同意（`dtmc_tcf_string`） | 訪問の GDPR 同意状態を表す IAB TCF 同意文字列。 |
| メーカーのモデル／部品番号（`dtmc_mpn`） | 商品に対するメーカーのモデル番号または部品番号。 |
| メーカー UPC（`dtmc_upc`） | 商品に対するメーカーの UPC。 |
| 商品 ID（`dtmc_product_id`） | 購入された商品を表す一意の識別子。 |
| 参照元 URL（`dtm_referrer`） | 訪問をトランザクションページに誘導した URL。 |
| サブカテゴリ（`dtmc_sub_category`） | 商品またはコンテンツのサブカテゴリ。 |
| ユーザーエージェント（`dtm_user_agent`） | 訪問のデバイスから取得したブラウザのユーザーエージェント文字列。 |
| キャッシュバスター | レスポンスのキャッシュを防ぐために使用するランダム値またはタイムスタンプ値。 |
| GPP 文字列 | （必須）Global Privacy Platform（GPP）の同意文字列。 |

#### トランザクションデータ

| **パラメータ** | **説明** |
| --- | --- |
| トランザクション ID（`dtmc_transaction_id`） | 各コンバージョンに対する広告主固有の識別子。 |
| 注文小計（`dtm_conv_val`） | 購入されたすべての商品の合計価格。税金や送料は含めないでください。 |
| コンバージョンタイプ（`dtmc_conv_type`） | 配送や店舗受け取りなど、オンライン購入のタイプを区別するために使用します。 |
| 通貨コード（`dtm_conv_curr`） | ISO 4217 通貨コード（EUR や USD など）。 |
| 店舗所在地（`dtmc_conv_store_location`） | 店舗受け取りタイプのコンバージョンに対応する店舗所在地。 |

#### 商品データ

| **パラメータ** | **説明** |
| --- | --- |
| 商品 ID | トランザクション内の商品 ID の配列。 |
| 商品価格 | トランザクション内の商品価格の配列。 |
| 商品数量 | トランザクション内の商品数量の配列。 |
| 商品割引額 | トランザクション内の商品割引額の配列。 |
| カスタムクエリパラメータ | ベース URL にクエリ文字列パラメータとして追加するカスタム値。 |
