## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加したら、次の構成を構成します。

* **エージェンシーシークレットキー**：The Trade Deskから提供されたシークレットキー。

コネクタを構成したら、**完了**をクリックします。

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| ファーストパーティ広告主データを送信 | ✓ | ✓ |

アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションの構成方法について説明します。

### ファーストパーティ広告主データを送信


<blockquote>
`TDID`パラメータまたは`UID2`パラメータのいずれか一方のみを使用してください。`TDID`と`UID2`の両方に値を構成すると、コネクタエラーが発生する可能性があります。
</blockquote>


#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| データセンターのリージョン | （必須）ユーザーデータの発生元に地理的に最も近いデータセンターを選択します。 |

#### 広告主列

| **パラメータ** | **説明** |
| --- | --- |
| 広告主ID | （必須）広告主ID。使用可能なタイプは、`DAID`、`TDID`、`UID2`、`EUID`、`IDL`（`RampID`）、`ID5`、`netID`です。必要なIDは1つだけです。 |
| デバイス広告ID（DAID） | デバイス広告ID（`DAID`） |
| Trade Desk ID（TDID） | Trade Desk ID（`TDID`） |
| Unified ID（ハッシュ化済みUID2） | Unified ID（`UID2`）。すでにハッシュ化されている場合は、**SHA256ハッシュ化済み**オプションを使用し、前後の空白を削除して小文字に変換した後、SHA256でハッシュ化した値を指定します。詳細については、[関数を使用してUID2を生成する](https://docs.tealium.com/use-visitor-function-uid20/)を参照してください。 |
| UID2トークン（暗号化された広告トークン） | 暗号化されたUID2広告トークン。このトークンでは大文字と小文字が区別されます。 |
| Identity Link（IDL） | Identity Link（`IDL`） |

#### データ列

| **パラメータ** | **説明** |
| --- | --- |
| TTLのオーバーライド（分） | 有効期間（`ttl`）を分単位でオーバーライドします。`ttl`の最大値は259200分（180日）です。 |
| タイムスタンプのオーバーライド | タイムスタンプをオーバーライドします。 |
| データ名 | （必須）データ名 |
