## API情報

このコネクタは、次のベンダーAPIを使用します。

* API名：Adobe Journey Optimizer API
* APIエンドポイント：`https://platform.adobe.io`
* ドキュメント：[Adobe Journey Optimizer API](https://developer.adobe.com/journey-optimizer-apis/)

## アクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
| 単一メッセージ実行（リアルタイム） | ✓ | ✓ |
| 単一メッセージ実行（バッチ） | ✓ | ✓ |

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の項目を構成します。

* **クライアントID**  
（必須）クライアントID（APIキー）は、Adobeアカウントの[Adobe Developer Console](https://www.adobe.com/go/devs_console_ui)で確認できます。
* **クライアントシークレット**  
（必須）クライアントシークレットは、AdobeアカウントのAdobe Developer Consoleで確認できます。
* **組織ID**  
（必須）組織IDは、AdobeアカウントのAdobe Developer Consoleで確認できます。
* **サンドボックス**  

コネクタを構成したら、**完了**をクリックします。
API呼び出しで、デフォルト環境（本番環境）とは異なる環境を参照するかどうかを指定します。

## アクション

以下のセクションでは、各アクションでサポートされるパラメータを示します。

### 単一メッセージ実行（バッチ）

このアクションは、ベンダーへの大容量データ転送に対応するために、バッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまでキューに追加されます。

* リクエストの最大数：20
* 最も古いリクエストからの最大経過時間：5分
* リクエストの最大サイズ：1 MB

#### パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| キャンペーンID | （必須）キャンペーン識別子。 |
| リクエストID | 一意のリクエスト識別子。 |
| 名前空間 | AEPプロファイルの名前空間。 |

#### 受信者パラメータ

| **パラメータ** | **説明** |
| --- | --- |
| タイプ | （必須）受信者のタイプ。例：`aep`。 |
| ユーザーID | （必須）AEPプロファイル識別子。 |
| コンテキスト | メッセージコンテンツ内の動的変数の置換に使用されるコンテキストデータ。 |
| メールアドレス | 受信者のメールアドレス。外部ユーザーIDとしても使用されます。 |
| 携帯電話番号 | SMSテキストメッセージの受信者の携帯電話番号。 |
| プロファイル | メッセージコンテンツ内の動的変数の置換に使用されるプロファイルデータ。 |
| テンプレート変数 | **テンプレート**のデータ入力としてテンプレート変数を指定します。詳細および使用例については、[connector-template-variables](https://docs.tealium.com/connector-template-variables/)を参照してください。<br>ネストされたテンプレート変数には、ドット表記で名前を付けます。例：`items.name`。<br>ネストされたテンプレート変数は通常、データレイヤーのリスト属性から構築されます。|
| テンプレート | 本文パラメータで参照するテンプレートを指定します。詳細については、[about-connector-templates](https://docs.tealium.com/about-connector-templates/)を参照してください。<br>テンプレートは、サポートされているフィールドに二重波括弧で名前を指定して挿入されます。例：`{{SomeTemplateName}}`。|
