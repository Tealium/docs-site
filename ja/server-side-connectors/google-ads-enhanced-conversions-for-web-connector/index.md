Google 広告のウェブ向け拡張コンバージョンコネクタを使用すると、トランザクション ID とハッシュ化されたユーザー識別子を含むコンバージョン調整をアップロードし、ウェブコンバージョン測定の精度を向上できます。

## 要件

* 拡張コンバージョンが有効なコンバージョンを構成した Google 広告アカウント。
* 拡張コンバージョンが有効なコンバージョンアカウントに対する読み取りおよび書き込み権限。
* [Google 広告コンバージョントラッキングおよびリマーケティング（gtag.js）タグ](https://docs.tealium.com/google-ads-conversion-tracking-and-remarketing-gtagjs-tag/)
* Google 広告アカウントの顧客 ID。詳細については、[Google：Google 広告のお客様 ID を確認する](https://support.google.com/google-ads/answer/1704344?hl=en)を参照してください。
  * クライアントに代わってアカウントにアクセスする場合は、マネージャー顧客 ID（MCC ID）を構成する必要があります。顧客 ID を確認するには、Google 広告にログインし、**構成 > アクセスとセキュリティ > マネージャー**に移動します。

## コネクタアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
|コンバージョンを送信| ✓| ✓|

## API 情報

このコネクタは、次のベンダー API を使用します。

* API 名：Google Ads API
* API バージョン：v24
* API エンドポイント：`https://googleads.googleapis.com/`
* ドキュメント：[Google Ads API：拡張コンバージョン](https://developers.google.com/google-ads/api/docs/conversions/enhance-conversions)

## バッチ処理の制限

このコネクタでは、ベンダーへの大量のデータ転送に対応するため、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルがパブリッシュされるまで、リクエストはキューに保持されます。

* リクエストの最大数：2,000
* 最も古いリクエストからの最大経過時間：10 分
* リクエストの最大サイズ：2 MB

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。詳細については、[about-connectors](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、次の構成を構成します。

* **顧客 ID**  
（必須）管理する Google 広告アカウントの顧客 ID を指定します。
* **マネージャー顧客 ID**  
（任意）クライアントに代わってアカウントにアクセスする場合は、マネージャー顧客 ID を構成する必要があります。顧客 ID を確認するには、Google 広告にログインし、**構成 > アクセスとセキュリティ > マネージャー**に移動します。

### Google アカウントと規約

コンバージョンが構成されているアカウントに対して、少なくとも読み取りおよび書き込み権限を持つ Google アカウントとの接続を確立する必要があります。**Google でログイン**をクリックし、画面の指示に従います。

Google アカウントを接続した後、Google のポリシーおよび Google 広告データ処理規約に準拠していることを確認する必要があります。詳細については、[Google 広告：ウェブ向け拡張コンバージョンを有効にする](https://support.google.com/google-ads/answer/15093619?)を参照してください。

コネクタの構成が完了したら、**完了**をクリックします。

## 重複排除

Google は、トランザクション ID を使用して、クライアント側とサーバー側のコンバージョン間で重複を排除します。この ID は各コンバージョンイベントに固有であり、サーバー側イベントとクライアント側イベントで一致している必要があります。購入には `order_id`、その他のイベントには `tealium_random` を使用することをお勧めします。

タグで **サーバー側拡張コンバージョンのイベントマッチングを有効化**がオンになっており、コネクタで **自動トランザクション ID** が構成されている場合、コネクタでのマッピングは必要ありません。

**自動トランザクション ID** を構成するには、コネクタアクションの構成で、Google 広告コンバージョントラッキングおよびリマーケティングタグのクライアント側タグ UID を `Tealium iQ Tag ID` にマッピングします。`Tealium iQ Tag ID` が指定されている場合、タグ管理から送信されたトランザクション ID の値が自動的に検索されます。この機能を利用するには、タグテンプレートが 2023 年 4 月より後のバージョンであり、`transaction_id` または `order_id` がマッピングされている必要があります。

## アクション構成 — パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### アクション — コンバージョンを送信
#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|コンバージョン アクション|既存のコンバージョン アクションを選択します。コンバージョン アクションは、Google 広告の UI でタイプを **WEBPAGE**、拡張コンバージョンを有効、拡張コンバージョンの実装方法を **API** に構成する必要があります。拡張コンバージョンについて詳しくは、[Google 広告：拡張コンバージョン トラッキング](https://support.google.com/google-ads/answer/9888656)を参照してください。|
|トランザクション ID|コンバージョン イベントを一意に識別する、広告主が生成した ID。この ID の値は、クライアント側のイベントと一致している必要があります。購入には `order_id`、その他のイベントには `tealium_random` を使用します。自動トランザクション ID が指定されている場合、このパラメータは必須ではありません。|
|コンバージョン値|コンバージョンの金額。|
|コンバージョン通貨|コンバージョンの通貨コード。|
|コンバージョン日時|元のコンバージョンが発生した日付と時刻。タイムゾーンを **yyyy-mm-dd hh:mm:ss+｜-hh:mm** 形式で含めます。例：`2022-01-01 12:32:45-08:00`。このフィールドがマッピングされておらず、GCLID が存在する場合、コネクタは現在の日付と時刻を使用します。GCLID が存在しない場合、`conversionDateTime` は省略されます。|
|Gclid|利用可能な場合、コンバージョンにつながった広告クリックの Google クリック識別子。GCLID が存在しない場合、**コンバージョン日時**がマッピングされていても、`conversionDateTime` は省略されます。|
|ユーザー エージェント|広告主が該当データを保持している場合、**コンバージョンしたユーザー**のユーザー エージェント。|
|メールアドレス（SHA256 ハッシュ化済み）|空白を除去し、小文字に変換してから SHA256 でハッシュ化したメールアドレスを指定します。`gmail.com` および `googlemail.com` のアドレスについては、ハッシュ化する前にローカル部（ドメインより前の部分）からすべてのピリオド（.）を削除します。|
|メールアドレス（SHA256 ハッシュを適用）|プレーンテキストのメールアドレスを指定すると、コネクタは `gmail.com` および `googlemail.com` のメールアドレスについて、ドメイン名より前にあるすべてのピリオド（.）を削除し、空白を除去して小文字に変換した後、この値を SHA256 でハッシュ化します。|
|電話番号（SHA256 ハッシュ化済み）|[E164 標準](https://en.wikipedia.org/wiki/E.164)に従い、空白を除去して SHA256 でハッシュ化した電話番号を指定します。|
|電話番号（SHA256 ハッシュを適用）|プレーンテキストの電話番号を指定すると、コネクタは数字だけが残るように数字以外の文字をすべて削除し、番号の先頭にプラス記号（`+`）をエンリッチメントして空白を除去した後、この値を SHA256 でハッシュ化します。|
|住所情報：名（SHA256 ハッシュ化済み）|空白を除去し、小文字に変換してから SHA256 でハッシュ化した名を指定します。|
|住所情報：名（SHA256 ハッシュを適用）|プレーンテキストの名を指定すると、コネクタは空白を除去し、小文字に変換してから、この値を SHA256 でハッシュ化します。|
|住所情報：姓（SHA256 ハッシュ化済み）|空白を除去し、小文字に変換してから SHA256 でハッシュ化した姓を指定します。|
|住所情報：姓（SHA256 ハッシュを適用）|プレーンテキストの姓を指定すると、コネクタは空白を除去し、小文字に変換してから、この値を SHA256 でハッシュ化します。|
|住所情報：番地（SHA256 ハッシュ化済み）|空白を除去し、小文字に変換してから SHA256 でハッシュ化した番地を指定します。|
|住所情報：番地（SHA256 ハッシュを適用）|プレーンテキストの番地を指定すると、コネクタは空白を除去し、小文字に変換してから、この値を SHA256 でハッシュ化します。|
|住所情報：市区町村|ユーザーの住所の市区町村。|
|住所情報：州|ユーザーの住所の州コード。|
|住所情報：郵便番号|ユーザーの住所の郵便番号。|
|住所情報：国コード|ユーザーの住所の ISO 3166-1 alpha-2 形式の2文字の国コード。|
|自動トランザクション ID|（任意）Tealium iQ タグ ID に構成すると、Tealium はタグ管理から送信されたトランザクション ID の値を自動的に検索します。この機能を使用するには、タグテンプレートが2023年4月より後のバージョンである必要があります。トランザクション ID または自動トランザクション ID のいずれかを指定する必要があります。|
|コンバージョン アクションの上書き|（任意）コンバージョン アクション ID を指定して、**必須**セクションのコンバージョン アクションを上書きします。イベントストリーミング変数を使用して、コンバージョン アクション ID を構成できます。コンバージョン アクション ID を確認するには、Google 広告ダッシュボードに移動してコンバージョンをクリックします。コンバージョン アクション ID は、ウェブサイト URL に含まれる `ctId` クエリパラメータの値です。たとえば、URL が `https://ads.google.com/aw/conversions/detail?ctId=987654321` の場合、コンバージョン アクション ID は `987654321` です。|

## エラーのトラブルシューティング

一般的なエラーコードと解決方法を以下に示します。

* **CUSTOMER_NOT_ACCEPTED_CUSTOMER_DATA_TERMS**：Google のポリシーと規約に同意していません。この問題を解決するには、ポリシーと規約に同意してください。詳しくは、[Google 広告：ウェブ向け拡張コンバージョンを有効にする](https://support.google.com/google-ads/answer/15093619?)を参照してください。
* **EC_MODE_MISMATCH**：Google 広告プラットフォームで、コンバージョン アクションに誤ったコンバージョン タイプが構成されています。Google 広告プラットフォームの **ツール > コンバージョン > コンバージョン イベント** で、コンバージョン タイプを API に変更してください。
* **INVALID_USER_CUSTOMER_AUTHORIZATION**：コネクタの構成時に Google 広告プラットフォームへの認証に使用するログインには、オーディエンス リストを所有するアカウントに対する読み取り専用以上のアクセス権が必要です。
* **無効なパラメータ - アクションのパラメータ値が無効であるか、必須パラメータがありません**：これは、必須フィールドが欠落している場合にコネクタから発生する内部検証エラーです。次のいずれかのアクション エラーが返されます。
  * **トランザクション ID を空にすることはできません**：コンバージョンに注文 ID がない場合は、クライアント側タグおよびコネクタのアクション構成で `tealium_random` をマッピングできます。
  * **メールアドレス、電話番号、またはすべての住所情報を指定する必要があります**：拡張コンバージョンに必要な PII は、次のいずれかの組み合わせです。  
a) 顧客のメールアドレス  
b) 顧客の名、姓、番地、市区町村、州、国、郵便番号  
必須フィールドの値がイベントデータに含まれていることを確認してください。

詳しくは、[Google 広告：API エラー](https://developers.google.com/google-ads/api/reference/rpc/v14/AccessInvitationErrorEnum.AccessInvitationError)を参照してください。
