## コネクタアクション

| アクション名 | 訪問プロファイル | イベントデータ |
| --- | :---: | :---: |
|コンバージョンを送信| ✓| ✓|

## API 情報

このコネクタでは、次のベンダー API を使用します。

* API 名：Google Ads API
* API バージョン：v24
* API エンドポイント：`https://googleads.googleapis.com/`
* ドキュメント：[Google Ads API：リード向け拡張コンバージョンをアップロードする](https://developers.google.com/google-ads/api/docs/conversions/upload-identifiers)

## バッチ処理の上限

このコネクタでは、ベンダーへの大量のデータ転送をサポートするために、リクエストをバッチ処理します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。次のいずれかのしきい値に達するか、プロファイルが公開されるまで、リクエストはキューに保持されます。

* リクエストの最大数：2,000
* 最も古いリクエストからの最大経過時間：10 分
* リクエストの最大サイズ：2 MB

### 同意

デフォルトでは、コネクタは `adUserData` に `GRANTED` の値を送信します。このデフォルト構成を上書きするには、関連する Event Streaming 属性を、値が `DENIED` の `Ad User Data Consent` にマッピングします。

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/ja/server-side/connectors/manage/)の記事を参照してください。

コネクタを追加した後、次の構成を構成します。

* **顧客 ID**  
（必須）管理する Google 広告アカウントの顧客 ID を指定します。
* **マネージャー顧客 ID**  
（任意）クライアントに代わってアカウントにアクセスする場合は、マネージャー顧客 ID を構成する必要があります。顧客 ID を確認するには、Google 広告にログインし、**構成 > アクセスとセキュリティ > マネージャー**に移動します。

コネクタの構成が完了したら、**完了**をクリックします。

## アクション構成 — パラメータとオプション

**続行**をクリックして、コネクタアクションを構成します。アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションを構成する方法について説明します。

### アクション — コンバージョンを送信

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|コンバージョンアクション| タイプが **UPLOAD_CLICKS** で、拡張コンバージョンが有効になっている既存のコンバージョンアクションを選択します。詳細については、[Google 広告の拡張コンバージョントラッキング](https://support.google.com/google-ads/answer/9888656)を参照してください。|

#### ユーザーデータ

|**パラメータ**| **説明**|
|---| ---|
|メールアドレス（SHA256 ハッシュ化済み）| 前後の空白を削除し、小文字に変換して、SHA256 でハッシュ化済みのメールアドレスを指定します。`gmail.com` および `googlemail.com` のメールアドレスについては、ハッシュ化する前にドメイン名より前にあるすべてのピリオド（`.`）を削除してください。|
|メールアドレス（SHA256 ハッシュを適用）| プレーンテキストのメールアドレスを指定します。コネクタは、`gmail.com` および `googlemail.com` のメールアドレスについて、ドメイン名より前にあるすべてのピリオド（`.`）を削除し、前後の空白を削除して小文字に変換した後、この値を SHA256 でハッシュ化します。|
|電話番号（SHA256 ハッシュ化済み）| [E164 規格](https://en.wikipedia.org/wiki/E.164)に準拠し、前後の空白を削除して SHA256 でハッシュ化済みの電話番号を指定します。|
|電話番号（SHA256 ハッシュを適用）| プレーンテキストの電話番号を指定します。コネクタは、数字以外のすべての記号を削除し、番号の先頭にプラス記号（`+`）を付け、前後の空白を削除した後、この値を SHA256 でハッシュ化します。|
| gclid | コンバージョンに関連付けられた Google クリック ID（GCLID）。`gclid` と `user_identifiers`（メールアドレスまたは電話番号）の両方を指定した場合、Google 広告は `user_identifiers` を無視します。GCLID が存在しない場合、**コンバージョン時刻**がマッピングされていても、`conversionDateTime` は省略されます。 |
| 住所情報：名（SHA256 ハッシュ化済み） | 前後の空白を削除し、小文字に変換して、SHA256 でハッシュ化済みの名を指定します。 |
| 住所情報：名（SHA256 ハッシュを適用） | プレーンテキストの名を指定します。コネクタは小文字に変換し、前後の空白を削除した後、この値を SHA256 でハッシュ化します。 |
| 住所情報：姓（SHA256 ハッシュ化済み） | 前後の空白を削除し、小文字に変換して、SHA256 でハッシュ化済みの姓を指定します。 |
| 住所情報：姓（SHA256 ハッシュを適用） | プレーンテキストの姓を指定します。コネクタは小文字に変換し、前後の空白を削除した後、この値を SHA256 でハッシュ化します。 |
| 住所情報：番地（SHA256 ハッシュ化済み） | 前後の空白を削除し、小文字に変換して、SHA256 でハッシュ化済みの番地を指定します。 |
| 住所情報：番地（SHA256 ハッシュを適用） | プレーンテキストの番地を指定します。コネクタは小文字に変換し、前後の空白を削除した後、この値を SHA256 でハッシュ化します。 |
| 住所情報：市区町村 | プレーンテキストの市区町村を指定します。 |
| 住所情報：州 | プレーンテキストの州を指定します。 |
| 住所情報：郵便番号 | プレーンテキストの郵便番号を指定します。 |
| 住所情報：国 | プレーンテキストの国を指定します。 |

#### コンバージョンデータ

|**パラメータ**| **説明**|
|---| ---|
|コンバージョン値| コンバージョンの金額。|
|コンバージョン通貨| コンバージョンの通貨コード。|
|コンバージョン時刻| 最初のコンバージョンが発生した日時。タイムゾーンを指定する必要があります。形式は <code>yyyy-mm-dd hh:mm:ss+&#124;-hh:mm</code> です。例：`2022-01-01 12:32:45-08:00` または `2022-01-01 12:32:45+08:00`。値がマッピングされていない場合、現在時刻が値として構成されます。このデフォルト値は、GCLID も存在する場合にのみ適用されます。GCLID が存在しない場合、コンバージョン時刻がマッピングされていても、`conversionDateTime` は省略されます。|
|注文 ID| コンバージョンに関連付けられた注文 ID。注文 ID は、コンバージョンアクションごとに 1 つのコンバージョンにのみ使用できます。|
|カスタム変数| このコンバージョンに関連付けられたカスタム変数。値をカスタム変数 ID にマッピングします。コネクタは `conversion_custom_variable` フィールドを次の形式で送信します：`customers/{customer_id}/conversionCustomVariables/{custom_variable_id}`。|
#### カートデータ

| **パラメータ** | **説明** |
| --- | --- |
|マーチャント ID|商品がアップロードされる Merchant Center の ID。|
|フィードの国コード|商品がアップロードされるフィードに関連付けられた国コード。|
|フィードの言語コード|商品がアップロードされるフィードに関連付けられた言語コード。|
|ローカルトランザクション費用|カート全体に適用される送料無料やクーポン割引など、トランザクションレベルのすべての割引の合計。|
|商品 ID|商品のショッピング ID。Merchant Center の商品 ID と一致する必要があります。複数の商品を追加するには、配列型属性を指定します。配列型属性の長さはすべて同じである必要があります。単一値属性も使用でき、その場合は各商品に適用されます。|
|数量|販売された商品の数量。複数の商品を追加するには、配列型属性を指定します。配列型属性の長さはすべて同じである必要があります。単一値属性も使用でき、その場合は各商品に適用されます。|
|単価|税金、送料、およびトランザクションレベルの割引を除いた単価。複数の商品を追加するには、配列型属性を指定します。配列型属性の長さはすべて同じである必要があります。単一値属性も使用でき、その場合は各商品に適用されます。|
|顧客 ID の上書き|（任意）コネクタ構成内の顧客 `ID` を上書きする顧客 ID を指定します。このオプションを使用する場合は、コンバージョン アクション ID の上書きも使用する必要があります。|
|マネージャー顧客 ID の上書き|（任意）顧客 ID の上書きを使用してクライアント顧客にアクセスする場合は、マネージャー顧客 ID を指定します。|
|コンバージョン アクションの上書き|（任意）**必須**セクションのコンバージョン アクションを上書きするコンバージョン アクション ID を指定します。このパラメータを使用すると、イベントストリーミング変数によってコンバージョン アクション ID を構成できます。コンバージョン アクション ID を確認するには、Google 広告ダッシュボードに移動してコンバージョンをクリックします。コンバージョン アクション ID は、ウェブサイト URL の `ctId` クエリパラメータの値です。たとえば、URL が `https://ads.google.com/aw/conversions/detail?ctId=987654321` の場合、コンバージョン アクション ID は `987654321` です。|
|広告ユーザーデータへの同意|（任意）広告ユーザーデータに対する同意。デフォルト値は `GRANTED` です。有効な値は `GRANTED` または `DENIED` です。|
