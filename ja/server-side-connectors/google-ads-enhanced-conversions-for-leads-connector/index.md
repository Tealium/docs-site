## コネクタのアクション

| アクション名 | AudienceStream | EventStream |
| --- | :---: | :---: |
|コンバージョン送信| ✓| ✓|

## API情報

このコネクタは以下のベンダーAPIを使用します：

* API名：Google Ads API
* APIバージョン：v24
* APIエンドポイント：`https://googleads.googleapis.com/`
* ドキュメント：[Google Ads API: リード向けエンリッチメントコンバージョンのアップロード](https://developers.google.com/google-ads/api/docs/conversions/upload-identifiers)

## バッチ制限

このコネクタは、ベンダーへの大量データ転送をサポートするためにバッチリクエストを使用します。詳細については、[バッチアクション](https://docs.tealium.com/batched-actions/)を参照してください。リクエストは、次のいずれかの閾値に達するか、プロファイルが公開されるまでキューに入れられます：

* 最大リクエスト数：2,000
* 最古のリクエストからの最大時間：10分
* リクエストの最大サイズ：2 MB

### 同意

コネクタはデフォルトで `adUserData` の値として `GRANTED` を送信します。デフォルトを上書きするには、関連するEventStream属性を `Ad User Data Consent` にマッピングし、値を `DENIED` に構成します。

## 構成の構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/ja/server-side/connectors/manage/)の記事を参照してください。

コネクタを追加した後、以下の構成を構成します：

* **顧客ID**  
(必須) 管理する広告アカウントの顧客IDを提供してください。
* **マネージャー顧客ID**  
(オプション) クライアントを代表してアカウントにアクセスする場合、マネージャー顧客IDを構成する必要があります。顧客IDは、Google Adsにログインし、**構成 > アクセスとセキュリティ > マネージャー**に移動することで見つけることができます。

コネクタの構成が完了したら、**完了**をクリックします。

## アクション構成 — パラメータとオプション

コネクタアクションの構成を続行するには、**続行**をクリックします。アクションの名前を入力し、ドロップダウンメニューからアクションタイプを選択します。

次のセクションでは、各アクションのパラメータとオプションの構成方法について説明します。

### アクション — コンバージョン送信

#### パラメータ

|**パラメータ**| **説明**|
|---| ---|
|コンバージョンアクション| **UPLOAD_CLICKS**タイプでエンリッチメントコンバージョンが有効になっている既存のコンバージョンアクションを選択します。詳細については、[Google Ads エンリッチメントコンバージョントラッキング](https://support.google.com/google-ads/answer/9888656)を参照してください。|

#### ユーザーデータ

|**パラメータ**| **説明**|
|---| ---|
|メールアドレス（既にSHA256ハッシュ化済み）| すでに空白をトリミングし、小文字に変換し、SHA256でハッシュ化されたメールアドレスを提供してください。`gmail.com`および`googlemail.com`のメールアドレスのドメイン名の前にあるすべてのピリオド(`.`)をハッシュ化する前に削除してください。|
|メールアドレス（SHA256ハッシュを適用）| プレーンテキストのメールアドレスを提供し、コネクタが`gmail.com`および`googlemail.com`のメールアドレスのドメイン名の前にあるすべてのピリオドを削除し、空白をトリミングし、小文字に変換し、この値をSHA256ハッシュでハッシュ化します。|
|電話番号（既にSHA256ハッシュ化済み）| [E164標準](https://en.wikipedia.org/wiki/E.164)に従って、すでに空白をトリミングし、SHA256でハッシュ化された電話番号を提供してください。|
|電話番号（SHA256ハッシュを適用）| プレーンテキストの電話番号を提供し、コネクタがすべての非数字記号を削除し、プラス記号(`+`)で番号をプレフィックスし、空白をトリミングし、この値をSHA256ハッシュでハッシュ化します。|
| gclid | コンバージョンに関連付けられたGoogleクリックID（GCLID）です。`gclid`と`user_identifiers`（メールまたは電話）の両方を提供する場合、Google Adsは`user_identifiers`を無視します。GCLIDが存在しない場合、**Conversion Time**がマッピングされている場合でも`conversionDateTime`は省略されます。 |
| 住所情報：名（既にSHA256ハッシュ化済み） | すでに空白をトリミングし、小文字に変換し、SHA256でハッシュ化された名前を提供してください。 |
| 住所情報：名（SHA256ハッシュを適用） | プレーンテキストの名前を提供し、コネクタが小文字に変換し、空白をトリミングし、この値をSHA256ハッシュでハッシュ化します。 |
| 住所情報：姓（既にSHA256ハッシュ化済み） | すでに空白をトリミングし、小文字に変換し、SHA256でハッシュ化された姓を提供してください。 |
| 住所情報：姓（SHA256ハッシュを適用） | プレーンテキストの姓を提供し、コネクタが小文字に変換し、空白をトリミングし、この値をSHA256ハッシュでハッシュ化します。 |
| 住所情報：住所（既にSHA256ハッシュ化済み） | すでに空白をトリミングし、小文字に変換し、SHA256でハッシュ化された住所を提供してください。 |
| 住所情報：住所（SHA256ハッシュを適用） | プレーンテキストの住所を提供し、コネクタが小文字に変換し、空白をトリミングし、この値をSHA256ハッシュでハッシュ化します。 |
| 住所情報：市区町村 | プレーンテキストの市区町村を提供してください。 |
| 住所情報：州 | プレーンテキストの州を提供してください。 |
| 住所情報：郵便番号 | プレーンテキストの郵便番号を提供してください。 |
| 住所情報：国 | プレーンテキストの国を提供してください。 |

#### コンバージョンデータ

|**パラメータ**| **説明**|
|---| ---|
|コンバージョン値| コンバージョンの金銭的価値。|
|コンバージョン通貨| コンバージョンの通貨コード。|
|コンバージョン時間| 元のコンバージョンが発生した日時。タイムゾーンを指定する必要があります。形式は <code>yyyy-mm-dd hh:mm:ss+&#124;-hh:mm</code> です。たとえば、`2022-01-01 12:32:45-08:00`または`2022-01-01 12:32:45+08:00`です。値がマッピングされていない場合、値は現在の時間に構成されます。このデフォルトはGCLIDが存在する場合のみ適用されます。GCLIDが存在しない場合、**Conversion Time**がマッピングされていても`conversionDateTime`は省略されます。|
|注文ID| コンバージョンに関連付けられた注文IDです。注文IDは、コンバージョンアクションごとに1つのコンバージョンにのみ使用できます。|
|カスタム変数| このコンバージョンに関連付けられたカスタム変数です。値をカスタム変数IDにマッピングします。コネクタは次の形式で`conversion_custom_variable`フィールドを送信します：`customers/{customer_id}/conversionCustomVariables/{custom_variable_id}`。|

#### カートデータ

| **パラメータ** | **説明** |
| --- | --- |
|マーチャントID| アイテムがアップロードされるマーチャントセンターのIDです。|
|フィード国コード| アイテムがアップロードされるフィードに関連付けられた国コードです。|
|フィード言語コード| アイテムがアップロードされるフィードに関連付けられた言語コードです。|
|ローカルトランザクションコスト| カート全体に対する送料無料やクーポン割引など、すべてのトランザクションレベルの割引の合計です。|
|商品ID| 商品のショッピングIDです。マーチャントセンターの商品識別子と同じでなければなりません。複数のアイテムを追加するために配列型属性を提供します。配列型属性は長さが等しくなければなりません。単一値属性を使用することもでき、各アイテムに適用されます。|
|数量| 販売されたアイテムの数です。複数のアイテムを追加するために配列型属性を提供します。配列型属性は長さが等しくなければなりません。単一値属性を使用することもでき、各アイテムに適用されます。|
|単価| 税金、送料、およびトランザクションレベルの割引を除いた単価です。複数のアイテムを追加するために配列型属性を提供します。配列型属性は長さが等しくなければなりません。単一値属性を使用することもでき、各アイテムに適用されます。|
| カスタマーIDオーバーライド | (オプション) コネクタ構成のカスタマー`ID`をオーバーライドするためのカスタマーIDを提供します。このオプションを使用する場合は、変換アクションIDのオーバーライドも使用する必要があります。 |
| マネージャーカスタマーIDオーバーライド | (オプション) カスタマーIDオーバーライドを使用してクライアントカスタマーにアクセスする場合は、マネージャーカスタマーIDを提供します。 |
|変換アクションオーバーライド | (オプション) **必須**セクションの変換アクションをオーバーライドするための変換アクションIDを提供します。このパラメーターでは、EventStream変数を使用して変換アクションIDを入力できます。変換アクションIDを見つけるには、Google Adsダッシュボードにアクセスし、変換をクリックします。変換アクションIDは、ウェブサイトURLの`ctId`クエリパラメーターの値です。例えば、URLが`https://ads.google.com/aw/conversions/detail?ctId=987654321`の場合、変換アクションIDは`987654321`です。 |
| 広告ユーザーデータの同意 | (オプション) 広告ユーザーデータの同意です。デフォルト値は`GRANTED`です。有効な値は`GRANTED`または`DENIED`です。 |
