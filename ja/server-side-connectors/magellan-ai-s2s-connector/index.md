## API情報

このコネクタは以下のベンダーAPIを使用します：

* API名：Magellan AI S2S API
* APIエンドポイント：`https://mgln.ai`

## 構成

コネクタマーケットプレイスに移動し、新しいコネクタを追加します。コネクタの追加方法については、[コネクタについて](https://docs.tealium.com/about-connectors/)を参照してください。

コネクタを追加した後、以下の構成を構成します：

* **Magellan Pixel Token**：あなたのMagellan AIピクセルトークン。すべてのイベントをあなたのMagellanアカウントにリンクします。この値はMagellan AIダッシュボードで見つけることができます。

## アクション

| アクション名 | AudienceStream | EventStream |
| ----------- | :------------: | :---------: |
| イベント送信 | ✓ | ✓ |

### イベント送信

#### パラメータ

| パラメータ | 説明 |
| --- | --- |
| イベントタイプ | (必須) Magellanイベントタイプを選択します。エンドポイントパスを決定し、そのイベントに関連するフィールドを制御します。<br>ページビュー<br>リード<br>製品<br>カートに追加<br>チェックアウト<br>購入<br>識別<br>コード |
| カテゴリ | (オプション) リードを送信するために使用されるアクションのタイプ（例：`formFill`または`ButtonClick`）。 |
| コード | (コードイベントに必須) 追跡されるクーポンまたは紹介コード。紹介者があるアカウント作成で紹介コードがコードとして渡され、`type`が`referrer`に構成される場合に使用されます。購入イベントで割引コードを使用する場合は不要です。 |
| 通貨 | (リード、製品、カートに追加、チェックアウト、購入イベントに必須) イベント通貨。リード、製品、カートに追加、チェックアウト、購入イベントで`_ccurrency`に自動マッピングされます。 |
| 割引コード | (オプション) チェックアウトおよび購入イベントの割引またはプロモーションコード。チェックアウトおよび購入イベントで`_cpromo`に自動マッピングされます。 |
| ID | イベントごとに異なる方法で使用される一意のID：<ul><li><code>identify</code> — ユーザーID（必須）。</li><li><code>view</code> — ユーザーID（オプション）。</li><li><code>lead</code> — ユーザーID（オプション）。</li><li><code>checkout</code> — 注文ID（オプション）。</li><li><code>purchase</code> — 注文ID（必須）。</li></ul>チェックアウトおよび購入イベントで`_corder`に自動マッピングされます。 |
| IPアドレス | (必須) クライアントのIPアドレス。クライアントIP属性に自動マッピングされます。 |
| 新規顧客か | (オプション) 顧客がリピーターでない場合に`true`に構成します。文字列値はブール値に変換されます。 |
| 商品ID | (オプション) 商品IDの並列配列。チェックアウトおよび購入イベントで`_cprod`に自動マッピングされます。 |
| 商品名 | (オプション) 商品名の並列配列。チェックアウトおよび購入イベントで`_cprodname`に自動マッピングされます。 |
| 商品タイプ | (オプション) 商品タイプ/カテゴリの並列配列。チェックアウトおよび購入イベントで`_ccat`に自動マッピングされます。 |
| 商品ベンダー | (オプション) 商品ベンダーの並列配列。チェックアウトおよび購入イベントで`_cbrand`に自動マッピングされます。 |
| 商品数量 | (オプション) 商品数量の並列配列。チェックアウトおよび購入イベントで`_cquan`に自動マッピングされます。 |
| 商品バリアントID | (オプション) バリアントIDの並列配列。チェックアウトおよび購入イベントで`_csku`に自動マッピングされます。 |
| 商品バリアント名 | (オプション) バリアント名の並列配列。 |
| 商品ID | (オプション) 商品ID。リード、製品、カートに追加イベントで`_cprod`に自動マッピングされます（文字列に変換）。 |
| 商品名 | (オプション) 商品名。 |
| 商品タイプ | (オプション) 商品のタイプ（例：`Women's Shoes`）。 |
| 商品ベンダー | (オプション) 商品のベンダー。 |
| 数量 | (オプション) イベントの数量。リード、カートに追加、チェックアウト、購入イベントで`_cquan`に自動マッピングされます（数値に変換）。 |
| 紹介URL | (オプション) 紹介URLアドレス。ページビューイベントで`dom.referrer`から自動マッピングされます。 |
| タイプ | (オプション) イベントのカテゴリラベル。リードイベントの場合、リードアクションのタイプを指定するために使用します。例えば`Sales Demo`、`Account Creation`、または`Newsletter signup`。コードイベントの場合、コードのタイプを指定するために使用します。例えば`referrer`。 |
| URL | (ページビューイベントに必須) イベントのURL。ビューイベントで現在のURL属性に自動マッピングされます。 |
| 価値 | (リード、製品、カートに追加、チェックアウト、購入イベントに必須) イベントごとに異なる方法で使用される値：<ul><li><code>lead</code> — リードに割り当てられた総価値。リードイベントではデフォルトで<code>0</code>です。</li><li><code>product</code> — アイテムごとの価値。</li><li><code>add_to_cart</code> — カートに追加された総価値。</li><li><code>checkout</code> — カートの総価値。</li><li><code>purchase</code> — 注文の総価値。</li></ul>チェックアウトおよび購入イベントで`_ctotal`に、カートに追加および製品イベントで`_cprice`の合計に自動マッピングされます。 |
| バリアントID | (オプション) 商品バリアントID。 |
| バリアント名 | (オプション) 商品バリアント名。 |
| Pixel Token Override | (オプション) このアクションのコネクタレベルのMagellan Pixel Tokenを上書きします。異なるイベントが異なるMagellanピクセルに属する場合に使用します。 |
| E-Commerce自動マッピング無効 | E-Commerce自動マッピングが無効の場合、標準の商業属性（**通貨**、**注文ID**、**価値**、**数量**、**商品ID**、**割引コード**、および**ラインアイテム**）はTealium UDO属性から自動マッピングされません。イベントデータおよびラインアイテムセクションでこれらのフィールドを手動でマッピングします。 |
| 識別子自動マッピング無効 | 識別子自動マッピングが無効の場合、**IPアドレス**はクライアントIP属性から自動マッピングされません。イベントデータセクションでIPアドレスフィールドを手動でマッピングします。 |
