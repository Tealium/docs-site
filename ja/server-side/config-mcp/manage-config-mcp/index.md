Tealium構成MCPを使用する前に、[Tealium構成MCPに接続する](https://docs.tealium.com/connect-config-mcp/)のセットアップ手順を完了してください。

## セッションを開始する

Claude Desktop、claude.ai、またはClaude Code CLIでの新しいチャットは、それぞれのプロファイルドラフトを持つ新しいTealium構成MCPセッションを開始します。

1. **Tealium構成MCP**コネクタが有効なClaudeで新しいチャットを開始します。
1. エージェントがどのプロファイルバージョンで作業するか尋ねます。以下から選択してください：
   * **最新の公開バージョン：** 最も最近に公開されたプロファイルバージョン。
   * **最新の保存バージョン：** 最も最近に保存されたバージョンで、未公開のドラフトを含む。
   * 名前または番号で特定のリビジョン。
1. Tealium構成MCPは選択されたバージョンに基づいて一時的なドラフトを作成します。セッション中のすべての変更はそのドラフトに適用されます。プロンプトが表示されたときにドラフトバージョンに名前を付けることもできます。
1. エージェントは選択されたバージョンでメッセージボックスを事前に入力します。メッセージを送信してセッションを開始します。

## 探索して変更を加える

プロファイルについて質問するか、変更を加えたい内容を説明します。質問に対しては、エージェントが直接応答します。変更の場合、Tealium構成MCPは計画を作成し、エージェントがそれを提示し、何かが適用される前に確認します。


<blockquote>
既存のオーディエンスを編集する前に、現在のAudiences UIで公開されていることを確認してください。Tealium構成MCPがオーディエンスを読み取ることはできますが、条件変更を適用できない場合は、**Activate > Audiences**でオーディエンスを開き、変更を加えずに保存して公開し、新しいMCPセッションを開始して操作を再試行してください。
</blockquote>


```wrap
「High Value Customers」オーディエンスに条件を追加して、過去30日間に購入した訪問のみが含まれるようにします。
```

確認後、Tealium構成MCPはドラフトに変更を順次適用し、各パッチ後にプロファイルの整合性を検証します。Tealium構成MCPが競合を検出した場合、自動的に解決を試み、エージェントが行ったことを説明します。

特定のタスクや例示的なプロンプトについては、[ユースケース](https://docs.tealium.com/about-config-mcp/#use-cases)を参照してください。

## コミットとレビュー

変更が完了したら、エージェントにコミットを依頼するか、`commit`と入力します。

エージェントはセッション中に行われたすべての変更の要約を提供します。要約を確認し、次に進むことを確認します。

コミット後：

1. Tealium UIでプロファイルに移動します。
1. **バージョン履歴**に移動し、新しい保存バージョンを探します。
1. 変更を確認します。
1. 組織の承認プロセスを完了した後に手動で公開します。


<blockquote>
コミットは新しい保存バージョンを作成しますが、変更を公開しません。新しいバージョンを手動で公開するまで、プロファイルは以前の公開バージョンで動作を続けます。
</blockquote>


長いセッションを終了する前に変更をコミットしてください。セッションは4日間の非活動後に期限切れになり、コミットされていない変更は失われます。セッションが期限切れになった後、新しいチャットを開始し、**最新の保存バージョン**としてコミットされたバージョンを選択して続行します。

## ベストプラクティス

* **必要最小限の努力レベルを使用します。** 推奨される努力レベルより低い努力レベルを使用すると、結果が悪くなり、より多くの誤出力が発生します。必要最小限の努力レベルは、Sonnet（4.6、5）で**High**、Opus（4.6、4.7、4.8、5）で**Medium**です。
* **正確で明確であること。** 明確な指示はより正確な結果をもたらします。一般的な用語で説明するのではなく、エンティティ名、条件、値を直接指定してください。
* **確認する前にレビューします。** 各ステップを承認する前に、エージェントの計画を注意深く読んでください。提案された変更が意図したものでない場合は、計画を調整するか、リクエストを明確にしてください。
* **新しいタスクごとに新しいチャットを開始します。** 新しいユースケースや異なるプロファイルバージョンに切り替える場合は、セッションコンテキストをリセットするために新しいチャットを開始します。

一般的な問題を解決するためのヘルプについては、[トラブルシューティング](https://docs.tealium.com/troubleshoot-config-mcp/)を参照してください。
