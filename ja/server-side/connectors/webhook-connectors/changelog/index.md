### 2026-10-27

テンプレートを使用できるすべての Webhook コネクタアクションで利用可能な、2 つの予約済みテンプレート変数を追加しました。
  * **`tealium_event_payload`**：UDO、DOM、Cookie データを含む、現在のイベント全体。属性のマッピングは不要です。
  * **`tealium_visitor_payload`**：属性および現在の訪問データを含む、訪問プロファイル全体。属性のマッピングは不要です。

詳細については、[予約済み変数](https://docs.tealium.com/connector-template-variables/#reserved-variables)を参照してください。

### 2024-07-10

HTTP ベースのすべての Webhook コネクタに、次のアクションを追加しました。
  * **HTTP リクエストによるイベントデータの送信**
  * **HTTP リクエストによる訪問データの送信**
  * **HTTP リクエストによる訪問データの一括送信**

### 2021-11-30

* 構成時に 302 レスポンスをサポートするための構成オプションを Webhook コネクタに追加しました。

### 2021-07-20

* コネクタアクションの表に、各アクションへのリンクを追加しました。

### 2021-06-07

* 「HTTP リクエストによるカスタマイズデータの一括送信（詳細）」アクションと「バッチの制限事項」セクションを追加しました。

### 2020-11-05

* Webhook 2-Legged OAuth2 コネクタおよび 3-Legged OAuth2 コネクタに、バッチ処理のサポートを追加しました。

### 2018-12-18

* ドメインレベルの Cookie が共有されないようにするため、Webhook コネクタの Apache Cookie 管理を無効にしました。

### 2017-08-24

* 「HTTP リクエストによるイベントデータの送信」と「HTTP リクエストによる訪問データの送信」という 2 つの新しいアクションを追加しました。
* POST-visitor と PUT-visitor の 2 つのアクションを削除しました。これらのアクションは［アクション］ドロップダウンリストに表示されなくなりましたが、現在プロファイルにインストールされている場合は、引き続き Tealium でサポートされます。

### 2017-03-02

* OAuth サービスをサポートするため、新しい Webhook OAuth2 コネクタを追加しました。このサービスは Webhook（BasicAuth）コネクタとは別のものです。

### 2016-11-13

* 複雑な JSON および XML ペイロードをサポートする、新しい「カスタムリクエストの送信」アクションを追加しました。ネストされた JSON を変換するための組み込みテンプレートユーティリティをサポートします。
* GET、POST、PUT メソッドを新しいアクションの下に移動しました。これらは個別のアクションとして扱われなくなりました。

### 2016-06-14

* AudienceDirect コネクタは廃止され、Webhook に置き換えられました。
* POST-visitor および PUT-Visitor アクションは、新しい Webhook（BasicAuth）コネクタに統合されました。
* プロファイルに非推奨または機能しない AudienceDirect アクションが含まれている場合は、新しい Webhook インスタンスで再構成する必要があります。
