## 除外条件における未割り当て属性

**除外**条件で使用される属性が未割り当ての場合、結果は演算子によって異なります。

| 演算子 | 結果 | 訪問に対する処理 |
| --- | --- | --- |
| 配列に含まれない | `true` | 維持 |
| 含まない | `true` | 維持 |
| 含まない（大文字と小文字を区別しない） | `true` | 維持 |
| 等しくない | `true` | 維持 |
| 等しくない（大文字と小文字を区別しない） | `true` | 維持 |
| 未割り当て | `true` | 維持 |
| ステップ未完了 | `true` | 維持 |
| 含む | `false` | 除外 |
| 含む（大文字と小文字を区別しない） | `false` | 除外 |
| 配列に含まれる | `false` | 除外 |
| 等しい | `false` | 除外 |
| 等しい（大文字と小文字を区別しない） | `false` | 除外 |
| 割り当て済み | `false` | 除外 |
| ステップ完了 | `false` | 除外 |
| 完了済み | `false` | 除外 |

### 数値属性

数値属性では、未割り当て値の処理方法が異なります。比較の第1オペランドが未割り当ての数値属性である場合、Tealiumはその値を`0.0`として評価します。

例：

* `equals 0`は`true`と評価されます。
* その他の数値比較では、属性が`0.0`と比較されます。
* `does not equal <value>`は、未割り当ての数値属性に対して`true`と評価されます。

`0.0`というデフォルト値が適用されるのは、未割り当ての数値属性が第1オペランドである場合のみです。第2オペランドが未割り当ての数値属性である場合、その条件に一致する訪問はいません。

## 集計属性での拡張ルール条件の使用

[集計]()属性では、`contains`演算子を使用して特定のキーを確認し、そのキーに関連付けられた値を評価できます。


<blockquote>
この拡張ルール条件は、`contains`演算子でのみ使用できます。
</blockquote>


集計属性の拡張条件を作成するには、次の手順を実行します。

1. **変換 > ルール**に移動します。
1. ルールを追加するか、既存のルールを選択して編集します。
1. **条件**で、評価する集計属性を選択します。
1. **含む**演算子を選択します。
1. **カスタム値**を選択します。
1. 評価する集計キーを入力します。  
   ![](https://docs.tealium.com/images/server-side/tally-rule.png)
1. **値に対してルールを実行**をクリックし、キーに関連付けられた値の評価に使用する演算子を選択します。
1. 比較する値を指定します。属性を選択するか、カスタム値を入力できます。
1. **保存**をクリックします。
## 正規表現

`matches regex` 演算子は、文字列属性でのみ使用できます。この条件は、属性値の一部が正規表現に一致すると `true` を返します。


<blockquote>
正規表現はスラッシュ（`/`）で囲まずに入力してください。たとえば、値 `abc1234567890` 全体に一致させるには、`^[a-z0-9]{13}$` と入力します。
</blockquote>


![](https://docs.tealium.com/images/server-side/audiences/regex_example_ui.png)

`matches regex` 演算子には、次のオプションがあります。

* **複数行モード**：文字列全体の先頭と末尾だけでなく、各行の先頭と末尾で `^` と `$` を一致させます。
* **大文字と小文字を区別しない**：正規表現を属性値と照合するときに、大文字と小文字の違いを無視します。

次の例は、値 `abc1234567890` に対する一般的な正規表現の結果を示しています。

| 正規表現 | 戻り値 | 説明 |
| ---------------- | ------------ | -------------------------------------------------------- |
| `\d{3}`          | `true`       | 文字列内の任意の位置にある、連続する3桁の数字に一致します。 |
| `^abc`           | `true`       | `^` は文字列の先頭に一致します。 |
| `\d{3}$`         | `true`       | `$` は文字列の末尾に一致します。 |
| `^[a-z0-9]{13}$` | `true`       | `^` と `$` により、13文字の文字列全体に一致します。 |
| `^[a-zA-Z]{4}`   | `false`      | 文字列の先頭が、連続する4文字の英字ではありません。 |
| `[a-zA-Z]{4}$`   | `false`      | 文字列の末尾が、連続する4文字の英字ではありません。 |
| `^[a-z0-9]{15}$` | `false`      | 文字列の長さが15文字ではありません。 |
