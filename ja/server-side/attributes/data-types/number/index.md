数値属性には、訪問数、ページビュー数、イベント数などの指標を参照するための数値を格納します。一般的な例として、顧客生涯価値、注文取引合計、最終購入からの経過日数などがあります。

## 仕組み

数値は小数または整数として格納されます。要件に合う型を選択してください。

* **小数（デフォルト）**
    * 小数値には、0桁以上の小数部を指定できます。
    * 例：`12`、`12.0`、`12.345`
    * 小数値にはJavaのDoubleクラスが使用されます。詳細については、[Class Double](https://docs.oracle.com/javase/8/docs/api/java/lang/Double.html)を参照してください。
    * 金額を表す属性に推奨されます。
* **整数**  
    * 整数値のみが格納されます。
    * 例：`12`、`-4`、`3214`
    * 数量、カウンター、スコアを表す数値属性に適しています。

数値属性は、イベント、訪問、訪問の各スコープで使用できます。

![](https://docs.tealium.com/images/server-side/scope-3checks.png)

### サイズ制限

数値属性の小数値は、`-1.7976931348623157×10^308`から`1.7976931348623157×10^308`までの範囲内である必要があります。数値属性の整数値は、`-2147483647`から`2147483647`までの範囲内である必要があります。

また、数値属性は、暗号化および圧縮後のプロファイルの最大サイズ（400 KB）によっても制限されます。

## エンリッチメント

### 数値を増加または減少させるエンリッチメント

このエンリッチメントは、正の値で数値を増加させるか、負の値で数値を減少させます。変更に使用する値には、別の数値属性または定数値を指定できます。

たとえば、訪問の注文における顧客生涯価値（LTV）を計算するには、`purchase`イベントが発生するたびに、このエンリッチメントを使用して`order_total`属性の値を属性に加算します。

**属性名**：顧客生涯価値合計

* **初期値**：`121.78` 
* **エンリッチメントに使用する値**：order_total `220.00`
* **結果**：`341.78`

### 比率を構成

2つの数値の商を新しい比率の数値として構成します。

たとえば、注文あたりの平均カート商品数を計算するには、このエンリッチメントを使用して、購入済みカート商品総数属性と完了済み注文総数属性の比率を構成します。

**属性名**：注文あたりの平均カート商品数

* **初期値**：---
* **エンリッチメントに使用する値**：  
購入済みカート商品総数：`48.00`  
完了済み注文総数：`3.00` 
* **結果**：`16.00`

### 積を構成

2つの数値の積を新しい数値として構成します。

たとえば、`coupon_discount_amount`を計算するには、このエンリッチメントを使用して`order_subtotal`に`coupon_discount_percent`を乗算します。

**属性名**：`coupon_discount_amount`

* **初期値**：---
* **エンリッチメントに使用する値**：  
order_subtotal：`42.00`  
coupon_discount_percent：`0.05`
* **結果**：`2.10`

### 差を構成

2つの数値の差を新しい数値として構成します。

**属性名**：`order_subtotal`

* **初期値**：`42.00 `
* **エンリッチメントに使用する値**：  
order_subtotal：`42.00`  
coupon_discount_amount：`2.10`
* **結果**：`39.90`

### 合計を構成

2つの数値の合計を構成します。

たとえば、`order_total`を`order_subtotal`と`order_tax_amount`の合計に構成します。

**属性名**：`order_total`

* **初期値**：---
* **エンリッチメントに使用する値**：  
order_subtotal：`39.90`  
order_tax_amount：`3.29`
* **結果**：`43.19`

### 数値を構成

数値を特定の値に構成します。

たとえば、`purchase`イベントが発生するたびに、最終購入金額を`order_total`の値に構成します。

**属性名**：最終購入金額

* **初期値**：---
* **エンリッチメントに使用する値**：order_total：`43.19`
* **結果**：`43.19`

### 2つの日付間の差を構成
（Customer Data Platform（CDP）のみ）

2つのイベント間の経過時間を計算します。経過時間は、次のいずれかの単位で表すことができます。

* 分
* 時間
* 日
* 週
* 月

差は常に正の値として格納されるため、日付はどちらの順序でも構成できます。

たとえば、最終購入日と現在の訪問日の差を日数で求め、最終購入からの経過日数を計算します。


<blockquote>
日付属性はUnixタイムスタンプとして格納されますが、これらの例では読みやすくするために書式構成された日付を使用しています。
</blockquote>


**属性名**：最終購入からの経過日数

* **初期値**：---
* **エンリッチメントに使用する値**：  
最終購入日：`"2018/10/30"`  
現在の訪問日：`"2019/11/01"`
* **結果**：`367`

### タイムラインに基づく移動平均を構成
（CDPのみ）

移動平均は、一定期間に取得された数値の算術平均です。これらの値は、[タイムライン]()のエントリとして収集された数値属性および[集計]()属性から取得されます。最終的な平均の計算に含めることができるエントリは、タイムラインの有効期限によって決まります。有効期限がない場合は、単純平均として計算されます。

**属性名**：平均注文金額

* **初期値**：---
* **エンリッチメントに使用する値**：`[20.00, 30.00, 40.00, 50.00]`
* **結果**：`35.00`

### タイムラインに基づく移動合計を構成
（CDPのみ）

移動合計は、[タイムライン](https://docs.tealium.com/timeline-attribute/)のエントリとして取得された、数値属性または[集計](https://docs.tealium.com/tally-attribute/)属性内の数値の合計です。集計時に含めることができるエントリは、タイムラインの有効期限によって決まります。

**属性名**：注文金額合計

* **初期値**：---
* **エンリッチメントに使用する値**：`[10.00, 20.00, 30.00, 40.00, 50.00]`
* **結果**：`150.00`

### 数値をタイムラインのエントリ数に構成

数値をタイムライン内のエントリ数に構成します。

**属性名**：注文総数

* **初期値**：---
* **エンリッチメントに使用する値**：`[10.00, 20.00, 30.00, 40.00, 50.00]`
* **結果**：`5.00`

### 数値を集計値に構成
（CDPのみ）

数値を集計内の特定の値に構成します。集計属性と、集計内のエントリ名を指定します。たとえば、「サイトカテゴリ閲覧数」という集計には、「Shoes」のエントリが含まれている場合があります。

**属性名**：靴カテゴリの閲覧数

* **初期値**：---
* **エンリッチメントに使用する値**：サイトカテゴリ閲覧数：`{"Shoes": 42}`
* **結果**：`42`

### 数値を集計内の項目数に構成
（CDPのみ）

属性を集計内のエントリ数に構成します。たとえば、「サイトカテゴリ閲覧数」という集計には、3つのエントリが含まれている場合があります。

**属性名**：閲覧したカテゴリ数

* **初期値**：---
* **エンリッチメントに使用する値**：  
``` 
{  
  "Shoes": 42,  
  "Shirts": 11,  
  "Pants": 8
} 
``` 
* **結果**：`3.00`

### 数値を文字列セット内の項目数に構成
（CDPのみ）

数値を文字列セット内の項目数に構成します。たとえば、「アクティブなブラウザータイプ」という文字列セットには、3つのエントリが含まれている場合があります。

**属性名**：アクティブなブラウザータイプの数

* **初期値**：---
* **エンリッチメントに使用する値**：`["Firefox", "Safari", "Chrome"]`
* **結果**：`3.00`

### 数値をタイムラインに基づく集計の移動最大値に構成
（CDPのみ）

数値を、タイムライン内で取得された集計内の別の数値の移動最大値に構成します。

**属性名**：最高注文金額

* **初期値**：---
* **エンリッチメントに使用する値**：`[10.00, 20.00, 30.00, 40.00, 50.00]`
* **結果**：`50.00`

### 数値を数値の変化量に構成
（CDPのみ）

この属性を、前回のイベント以降における、この属性と別の属性との差に構成します。たとえば、このエンリッチメントを使用して、前回の注文金額と現在の注文金額の差を取得します。「注文金額の変化」という名前の属性を構成するには、その値を前回の注文以降の`order_subtotal`の変化量に構成します。

**属性名**：注文金額の変化

* **初期値**：`30.00 `
* **エンリッチメントに使用する値**：order_subtotal：`42.00`
* **結果**：`12.00`
### 日付の変化量に数値を構成
（CDP のみ）

この属性を、選択した値について、今回のイベントと前回のイベント間での変化量に構成します。たとえば、購入が発生するたびに、「最終購入日」日付属性の月数の変化を取得するには、このエンリッチメントを使用します。

日付の変化量は、次のいずれかの単位で表せます。

* 分
* 時間
* 日
* 週
* 月

**属性名**：最終購入日からの月数

* **初期値**：
* **エンリッチする値**：  
最終購入日（前回のイベント）：`"10/31/2019"`  
最終購入日（今回のイベント）：`"12/31/2019"` 
* **結果**：2（月）

## スティッチングのマージルール

スティッチングのマージルール（有効な場合）は、2 つの訪問プロファイルをスティッチングするときに属性の最終値を決定する、属性ごとの任意のルールです。

数値属性では、次のスティッチングのマージルールがサポートされています。

| ルール | 説明 |
| ---- | ----------- |
| 最大値 | 大きい方の値を保持します。 |
| 最小値 | 小さい方の値を保持します。 |
| 新しい値 | より最近更新された値（削除された値を含む）を保持します。 |
| 古い値 | より以前に更新された値（削除された値を含む）を保持します。 |
| 再計算 | 以前の値を破棄し、最終的にマージされたプロファイルに対してエンリッチメントを実行します。 |
| 再計算（強制） | 以前の値を破棄し、最終的にマージされたプロファイルに対してエンリッチメントを実行し、一部の条件を強制的に `true` にします。 |
| 合計 | 両方の訪問の値を加算します。 |

詳細については、[stitching-merge-rules](https://docs.tealium.com/stitching-merge-rules/)を参照してください。
