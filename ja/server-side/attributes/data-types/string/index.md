## 仕組み

文字列は、名や郵便番号などの顧客情報、注文 ID や配送方法などの注文情報、またはサイトセクションやサイト言語などのサイト情報に使用されます。

文字列属性は、イベント、訪問、訪問の各スコープで使用できます。

![](https://docs.tealium.com/images/server-side/attribute-scopes-table-all.png)

### サイズ制限

Event Streaming の文字列属性の最大長は 1,500 文字です。この制限を超える文字列は、1,500 文字に切り詰められます。

Customer Data Platform（CDP）の文字列属性値の最大長は 1,000 文字です。エンリッチメントの結果、文字列が 1,000 文字を超えた場合、その値は保存されません。

文字列属性には、暗号化および圧縮後のプロファイルの最大サイズ（400 KB）による制限も適用されます。

## エンリッチメント

文字列属性では、次のエンリッチメントを使用できます。

### 文字列を構成

このエンリッチメントは、指定した定数値または別の文字列属性の値を使用して、文字列属性の値を構成します。ソース値として使用できるのは、文字列、iQ 変数、または Omnichannel 属性のみです。

**属性名**：`customer_type`

* **開始値**：`""`
* **エンリッチに使用する値**：`"unknown"`
* **結果の値**：`"unknown"`

### 文字列を分割

このエンリッチメントでは、分配率に基づいて複数の値を構成できます。構成する各値には、それぞれ割合も指定します。値と割合の組み合わせは複数構成できますが、分配率の合計は 100% である必要があります。分配は乱数ジェネレーターに基づくため、サンプル数が少ない場合は指定した分配率と一致しないことがあります。ただし、割り当てられる値が増えるにつれて、分配率はより正確になります。ソース値として使用できるのは、文字列、iQ 変数、または Omnichannel 属性のみです。

この例では、`test_group` という属性を使用して、ユーザーを 2 つの均等なグループ（50 対 50）にセグメント化します。一方のグループ名は「GroupA」、もう一方は「GroupB」です。この属性を使用して、各グループに関連するアクティビティを識別できます。

**属性名**：`test_group`

* **開始値**：`""`
* **結果の値**：文字列母集団の `50%` に文字列値 `"GroupA"` を構成<br> 文字列母集団の `50%` に文字列値 `"GroupB"` を構成

関連項目：[エンリッチメントの例：文字列の分割](https://support.tealiumiq.com/en/support/solutions/articles/36000363487-enrichment-example-split-string)

### 文字列を削除

このエンリッチメントは、属性から値全体を削除します。

* **開始値**：`"Jane Smith"`
* **結果の値**：（削除）

### 文字列を小文字に変換

このエンリッチメントは、文字列属性の現在の値を小文字に変換します。

**属性名**：`email_address`

* **開始値**：`"First.Last@Example.com"`
* **結果の値**：`"first.last@example.com"`

### 属性を結合

このエンリッチメントは、複数の値を区切り文字で結合して、単一のテキスト値を作成します。区切り文字には、1 文字以上の文字列を使用できます。たとえば、`site_section`、`page_category`、およびその他のページレベル属性を組み合わせて、ページ階層の値を作成できます。

**属性名**：`page_path`

* **開始値**：`""`
* **エンリッチに使用する値**：  
属性 1：`site_region="en-us"`  
属性 2：`site_section="Electronics"`  
属性 3：`category_name="Tablets"`  
区切り文字：`":"`
* **結果の値**：`"en-us:Electronics:Tablets"`

### 文字列を日付に構成

このエンリッチメントは、日付値を文字列に変換し、カスタム書式を適用できるようにします。ソース値には、日付、文字列、iQ 変数、またはファイルインポート属性を使用できます。日付フォーマッターの詳細については、[日付属性](https://docs.tealium.com/date-attribute/#date-formatter)を参照してください。

**属性名**：`last_purchase_date`

* **開始値**：`""`
* **エンリッチに使用する値**：書式 `"yyy-MM-dd"` の最終ログイン日
* **結果の値**：`"2019-12-31"`

## スティッチングのマージルール

スティッチングのマージルールが有効な場合、2 つの訪問プロファイルをスティッチングするときに属性の最終値を決定する、属性ごとの任意のルールとして機能します。

文字列属性では、次のスティッチングのマージルールがサポートされています。

| ルール | 説明 |
| ---- | ----------- |
| 新しい値 | より新しく更新された値を保持します（削除された値を含む）。 |
| 古い値 | より前に更新された値を保持します（削除された値を含む）。 |
| 再計算 | 以前の値を破棄し、最終的にマージされたプロファイルに対してエンリッチメントを実行します。 |
| 再計算（強制） | 以前の値を破棄し、最終的にマージされたプロファイルに対してエンリッチメントを実行し、一部の条件を強制的に `true` にします。 |

詳細については、[stitching-merge-rules](https://docs.tealium.com/stitching-merge-rules/)を参照してください。
