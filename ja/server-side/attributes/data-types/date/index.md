## 仕組み

日付属性を使用して、`First Purchase Date`、`Last Checkout Date`、`Last Visit Date` などの重要なタイムスタンプを保存します。

日付属性は、イベント、訪問、訪問の各スコープで使用できます。

![](https://docs.tealium.com/images/server-side/attribute-scopes-table-all.png)

## 日付フォーマッター

文字列属性を日付に変換するには、日付フォーマッターを使用します。日付形式パネルから、文字列値に対応するタイムスタンプ構成要素を選択します。たとえば、`01/31/2020` のような文字列値は、`MM/dd/yyyy` 形式を使用して日付に変換できます。

日付と時刻の文字列パターン：

| 記号 | 説明 | 値の例 |
|--------|-----------------------------------|------------------------|
| G | 紀元の指定子 | BC, AD |
| y | 年（2桁または4桁） | 12, 2012（`yy` または `yyyy` を使用） |
| M | 月（Mの数によって長さが異なる） | MM, MMM, MMMMM |
| d | 日（dの数によって長さが異なる） | d, dd |
| h | 時（1～12、AM/PM） | hh |
| H | 時（0～23） | HH |
| m | 分（0～59） | mm |
| s | 秒（0～59） | ss |
| S | ミリ秒（0～999） | SSS |
| a | AM/PMマーカー | AM, PM |
| z | タイムゾーン | PST, EST |
| Z | RFC 822タイムゾーン | -0800, +0530 |
| ' | テキスト区切り文字のエスケープ | |
| ' | 単一引用符 | |

詳細については、[Oracle：SimpleDateFormat Javaクラス](https://docs.oracle.com/javase/6/docs/api/java/text/SimpleDateFormat.html)を参照してください。


<blockquote>
文字列に `T` が含まれる場合は、式内の `T` の前後に単一引用符を付けます。たとえば、`2024-08-22T10:24:58.905` という文字列には、式 `yyyy-MM-dd'T'HH:mm:ss.SSS` を使用します。`yyyy-MM-ddTHH:mm:ss.SSS` のように引用符を省略すると、解析エラーが発生します。
</blockquote>


### 日付値を文字列属性として収集する

日付値は文字列のイベント属性として収集し、エンリッチメントを使用して日付の訪問属性に変換することをお勧めします。この方法により、不正な形式によるエラーのリスクを最小限に抑え、下流のデータベースシステムにおけるデータ収集や処理の中断を防ぐことができます。文字列としてインポートすることで、特に多様な日付形式を扱う場合に、柔軟性とデータ整合性が向上します。

#### 例

登録日を文字列として取得し、日付属性をエンリッチするには、次の手順を実行します。

1. `Signup Date` イベント属性を、`"2023-10-15"` のような文字列として作成します。
1. `Signup Date` 訪問属性を日付として作成します。  
1. 訪問属性に対して[日付を構成エンリッチメント](#set-date)を使用し、`yyyy-MM-dd` 形式で文字列を日付属性に変換します。  

### サイズ制限

各日付属性の値は、次の範囲に制限されます。

* 最小値：`-292275055-05-16T16:47:04.192Z`
* 最大値：`+292278994-08-17T07:12:55.807Z`

これらの属性は、暗号化および圧縮後のプロファイルの最大サイズ（400 KB）によっても制限されます。

## エンリッチメント

### 日付を取得

**日付を取得**エンリッチメントは、イベント条件が発生した時点の現在のタイムスタンプを属性に構成します。このエンリッチメントは、イベント、訪問、訪問の各属性で使用できます。

たとえば、最終購入日を取得するには、購入イベントを識別するルールとともにこのエンリッチメントを使用します。

**属性名：** 最終購入日

* **開始値**：`""`
* **エンリッチ方法**：
* **結果値**：`1491233145706`

### 日付を構成

**日付を構成**エンリッチメントは、属性を別の属性の値に構成します。別の属性が文字列の場合は、[日付フォーマッター](#date-formatter)を使用して日付に変換します。このエンリッチメントは、イベント、訪問、訪問の各属性で使用できます。

**属性名**：最終購入日

* **開始値**：`""`
* **エンリッチに使用する文字列**：`01/04/2019`
* **使用する形式**：`dd/MM/yyyy`（この形式では、文字列を解析する際の日、月、年の順序を指定します。）

**日付を構成**エンリッチメントを使用して、別の日付属性（Event StreamingまたはCustomer Data Platform（CDP））からEvent Streamingの日付を構成する場合、形式文字列にプレースホルダーを使用できます。たとえば、**日付を構成**エンリッチメントで、次のように構成します。

* **構成する日付**：値を構成する日付属性。この例では、`date_of_birth`。
* **日付形式**：任意のプレースホルダー（例：`x`）を入力します。

![](https://docs.tealium.com/images/server-side/attributes/set_date_enrichment_example.png)

### 日付を削除

**日付を削除**エンリッチメントは、日付属性の値を消去します。このエンリッチメントは、イベント、訪問、訪問の各属性で使用できます。

**属性名**：最終訪問日

* **開始値**：`1491233145706`
* **結果値**：（削除済み）

### 日付形式から変換

**日付形式から変換**エンリッチメントは、受信値に想定される日付形式に基づいて値を構成します。このエンリッチメントは、CollectタグまたはHTTP APIから送信された文字列値を変換するために使用します。[日付フォーマッター](#date-formatter)を使用して、文字列値を日付に変換します。このエンリッチメントは、イベント属性で使用できます。

## スティッチングのマージルール

スティッチングのマージルール（有効な場合）は、2つの訪問プロファイルがスティッチングされたときに属性の最終値を決定する、属性ごとの任意のルールです。

日付属性では、次のスティッチングのマージルールがサポートされています。

| ルール | 説明 |
| ---- | ----------- |
| Max | より新しい日付を保持します。 |
| Min | より古い日付を保持します。 |
| Newer | より最近更新された値（削除された値を含む）を保持します。 |
| Older | より以前に更新された値（削除された値を含む）を保持します。 |
| Recalculate | 以前の値を破棄し、最終的にマージされたプロファイルに対してエンリッチメントを実行します。 |
| Recalculate (Force) | 以前の値を破棄し、最終的にマージされたプロファイルに対してエンリッチメントを実行し、一部の条件を強制的に `true` にします。 |

詳細については、[stitching-merge-rules](https://docs.tealium.com/stitching-merge-rules/)を参照してください。
