## 仕組み

配列は、値のリストを格納するために使用します。文字列または数値の属性には、`"Home Page"` や `12.95` のような単一の値しか格納できませんが、配列には `["Pants", "Shirts"]` や `[5.99, 12.95]` のように複数の値を格納できます。配列は、[数値]()、[文字列]()、および[ブール値]()の各属性データ型で使用できます。

すべての例で、配列は JSON 形式で表されています。

```json
["Pants", "Shirts", "Shoes"]
[2, 4, 6]
[true, false, false]
[]
```


<blockquote>
配列には重複する値を含めることができます。
</blockquote>


### サイズ制限

配列の要素数は 30,000 個に制限されています。各ブール値および数値の要素にはサイズ制限がありませんが、文字列の要素には次の制限があります。

* Event Streaming の文字列属性の最大長は 1,500 文字です。この制限を超える文字列は、1,500 文字に切り詰められます。
* Customer Data Platform（CDP）の文字列属性値の最大長は 1,000 文字です。エンリッチメントによって文字列が 1,000 文字を超えた場合、その値は保存されません。

これらの属性は、暗号化および圧縮後のプロファイルの最大サイズ（400 KB）によって制限されます。
