属性は実装の基盤であり、顧客の行動やブランドとのやり取りを定義するために使用されます。属性は、訪問、訪問のセッション、収集されたイベントのプロパティを定義します。属性の一般的な例には、メールアドレス、メンバーID、製品カテゴリ、最終訪問日、使用中のブラウザーなどがあります。

各プロファイルには、訪問属性と訪問属性を合計で最大500個含めることができます。現在の属性総数は、**訪問／訪問属性**画面で確認できます。

![](https://docs.tealium.com/images/server-side/attributes/count-of-attributes.png)


<blockquote>
プロファイルに500個を超える属性が必要な場合は、[サポートにお問い合わせください](https://docs.tealium.com/support/)。
</blockquote>

|---|---|---|
| イベント | 個々のイベントに関連付けられ、ページ、コンテンツ、および顧客がリアルタイムで実行しているアクションを表す属性です。例：ページ名、製品価格、イベント名、注文合計など。 | **属性ソース**<br>イベント属性は、次のソースから取得されます。<br><ul><li>**ユニバーサル変数** [ユニバーサルデータオブジェクト](https://docs.tealium.com/universal-data-object/)</li><li>**JavaScriptページ変数** グローバルJavaScript変数（ブラウザー）</li><li>**HTMLメタデータ** メタデータタグ（ブラウザー）</li><li>**ファーストパーティCookie** ブラウザーCookie</li><li>**クエリ文字列パラメータ** 現在のページのURLクエリ文字列（ブラウザー）</li></ul> |
| 訪問 | 特定の訪問（またはセッション）に関する属性です。データは訪問中保持されます。例：訪問時間、使用ブラウザー、参照元URL、カートに追加された製品。 | これらの属性は、現在のセッションにおける訪問のアクティビティを表します。訪問属性はセッション中保持されます。詳細については、[セッションの長さ](https://docs.tealium.com/server-side-session-length/)を参照してください。 |
| 訪問 | すべての訪問を通じた、特定の訪問に関する属性です。例：メールアドレス、メンバーID、全期間の注文合計、カテゴリの表示回数。 | このデータは、セッション間および異なるデバイス間で訪問に引き継がれます。訪問データは、現在の訪問が終了した後も保持されます。 |
| オムニチャネル | オムニチャネルサービスを通じてオフラインデータをインポートするために使用します。このスコープにはデータ型は必要ありません。 | オムニチャネル属性は、ファイルインポートを定義するときに定義します。オムニチャネルはレガシースコープであり、[ファイルインポート](https://docs.tealium.com/about-file-import/)に置き換えられました。 |

### セッションの長さ

セッションの長さによって、訪問が非アクティブになってから終了するまでの時間が決まります。新しいイベントが発生しないままセッションの長さに達すると、訪問が終了し、訪問終了時の処理が実行されます。その訪問から次のイベントが発生すると、新しい訪問が開始されます。イベントのアクティビティにかかわらず、訪問時間は最大24時間です。

詳細については、[サーバーサイドのセッションの長さ](https://docs.tealium.com/server-side-session-length/)を参照してください。

## データ型

属性には、基本的な数値から、より高度な集計やバッジまで、さまざまな型があります。データ型によって、属性値が保存される形式が決まります。

次のデータ型がサポートされています。

|データ型|説明|
|---|---|
|[数値]()|注文合計、全期間のイベント数、最終訪問からの経過日数などの数値を保存します。|
|[文字列]()|姓名、住所、お気に入りの製品、ページ名などのテキスト値を保存します。|
|[ブール値]()|`true`と`false`の2つの値のいずれか一方のみを保存します。ブール値は、訪問のアクションや訪問のステータスを示すために使用できます。|
|[数値の配列]()|複数の数値を配列として保存します。配列には、一意または重複した数値を含めることができます。|
|[文字列の配列]()|複数の文字列値を配列として保存します。配列には、一意または重複した文字列値を含めることができます。|
|[ブール値の配列]()|複数のブール値を配列として保存します。配列には、一意または重複したブール値を含めることができます。|
|[集計]()|1つ以上のキーと値のペアを保存します。|
|[文字列のセット]()|一意の文字列値のコレクションをセットとして保存します。|
|[日付]()|イベント、訪問イベント、または特定の訪問の日付を保存します。|
|[ファネル]()|決済ファネルや登録など、複数ステップからなるイベントの各ステップのステータスを追跡します。|
|[タイムライン]()|指定した期間内に発生した訪問アクションをすべて記録します。|
|[バッジ]()|特定の条件または閲覧行動を満たす訪問に、視覚的なマークやシンボルを割り当てます。|
|[訪問ID](https://docs.tealium.com/visitor-id-attribute/)|訪問固有の特性をセカンダリ識別子として保存します。|

## 属性ID

すべてのイベント属性、訪問属性、訪問属性には、一意の属性識別子があります。このIDの値は、エンリッチメントが実行される順序に影響する場合があり、より複雑なデータソース構成や訪問スティッチング構成で必要になることがあります。

## サイズ制限

Event StreamingおよびCustomer Data Platform（CDP）のほとんどの属性には、保存容量の制限と、その制限を超えた場合の固有の動作があります。訪問プロファイル全体には、圧縮および暗号化された状態で400 KBの上限があることに注意してください。

## イベント制限

Tealiumプラットフォームと個々の顧客アカウントの両方を保護するため、CDPでは1回の訪問につきイベント数が10,000件に制限されています。

訪問が1回の訪問で10,000件のイベントに達すると、その訪問は永久に禁止されます。訪問が禁止されると、訪問プロファイルが削除され、その訪問ID、およびそれにスティッチされるすべてのIDから今後送信されるイベントは、CDPとEvent Streamingの両方で無視されます。さらに、アカウント、プロファイル、訪問ID、および禁止が発生したことを示す情報を含むログメッセージが記録されます。

禁止措置は永久的です。ただし、Tealium Operationsチームがメンテナンスを実施し、禁止された訪問のコレクションを消去するまでとなります。訪問が誤って禁止されたと思われる場合、または禁止リストから削除する必要がある訪問がいる場合は、Tealiumサポートにお問い合わせください。


<blockquote>
訪問に対する永久禁止が解除された後、その訪問が1回の訪問で再び10,000件のイベント制限を超えると、再度禁止されます。
</blockquote>


## イベント属性

|属性|保存容量の制限|制限超過時の動作|
|---|---|---|
|**文字列**|1,500文字|文字列が制限を超える場合、1,500文字に切り詰められます。|
|**任意の型の配列**|30,000エントリ|属性を構成または更新した結果、制限を超える場合、その属性は30,000エントリに切り詰められて構成されます。|
|**日付**|最小：`"-292275055-05-16T16:47:04.192Z"`、最大：`"+292278994-08-17T07:12:55.807Z"`|
|**数値**|動的な精度を持つ`java.lang.Number`で表されます。|
## 訪問／訪問属性

|属性|保存容量の上限|上限超過時の動作|
|---|---|---|
|**文字列**|1,000文字|エンリッチメントの結果、文字列が1,000文字を超えた場合、その値は保存されません。|
|**タイムライン**|100エントリ|上限に達すると、古いエントリから破棄されます（先入れ先出し）。たとえば、タイムラインに100件のエントリがあり、新しいエントリが追加されると、最初のエントリが削除されます。|
|**集計**|30,000エントリ|属性の構成または更新によって上限を超えた場合、属性は30,000エントリに切り詰められたうえで構成されます。|
|**任意の型の配列**|30,000エントリ|属性の構成または更新によって上限を超えた場合、属性は30,000エントリに切り詰められたうえで構成されます。|
|**文字列のセット**|30,000エントリ|属性の構成または更新によって上限を超えた場合、属性は30,000エントリに切り詰められたうえで構成されます。|
|**日付**|最小値：「-292275055-05-16T16:47:04.192Z」 最大値：「+292278994-08-17T07:12:55.807Z」|
|**数値**|動的な精度を持つ`java.lang.Number`で表現されます。||
|**訪問ID**|2 KB|訪問IDが2 KBを超える場合、レコードは保存されません。|
|**ファネル**|上限なし\*||

\*上限はありませんが、暗号化および圧縮後のプロファイルの最大サイズ（400 KB）による制限は引き続き適用されます。

## クライアントサイドとサーバーサイドの接続

### タグ管理から属性をインポートする

インポートされた属性とは、対応するタグ管理プロファイルで最初に作成された変数です。タグ管理変数は、同名のサーバーサイドプロファイルにイベントスコープ属性として自動的にエクスポートされます。これらの属性では、**Any**データ型が使用されます。タグ管理で変数を変更して（**prod**にパブリッシュすると）、その変更はEvent Streaming内の対応する属性に即座に適用されます。


<blockquote>
Imported attributes are not editable. You must use Tag Management to manage them.
</blockquote>


![](https://docs.tealium.com/images/server-side/imported-tealium-iq-variables1.png)  
![](https://docs.tealium.com/images/server-side/imported-tealium-iq-variables2.png)  

インポートされた属性にデータが格納されるのは、[Tealium Collectタグ](https://docs.tealium.com/tealium-collect-tag/)を使用してそのデータを収集した場合のみです。

インポートされた属性を直接エンリッチすることはできません。ただし、インポートされた属性を複製し、その値を使用して複製した属性をエンリッチした後、必要に応じてさらにエンリッチできます。

#### トラブルシューティング

タグ管理の変数がEvent Streamingに表示されない場合は、タグ管理変数がサーバーサイドプロファイルに対応するタグ管理プロファイルに存在し、保存およびパブリッシュされていることを確認してください。変数の変更をパブリッシュした後、ブラウザーでEvent Streamingページを更新してください。タグ管理変数をサーバーサイドで使用できるようにするためのサポートが必要な場合は、Tealiumサポートにお問い合わせください。

### 属性をタグ管理にエクスポートする

サーバーサイド属性をタグ管理変数として使用できるようにするには、データレイヤーエンリッチメントを使用します。

詳細については、[about-data-layer-enrichment](https://docs.tealium.com/about-data-layer-enrichment/)を参照してください。

* 定義済みのルールを適用するには、ドロップダウンリストから選択して、**ルールを追加**をクリックします。  
      
<blockquote>
Creating a new rule through the enrichments dialog box automatically applies it to the enrichment.
</blockquote>


* 新しいルールを適用するには、**ルールを作成**をクリックします。

![](https://docs.tealium.com/images/server-side/attributes/preloaded-attribute-filter.png)

## 依存関係

依存関係とは、この属性に依存するすべてのオブジェクトです。たとえば、次のものがあります。

* 属性
* オーディエンス
* セグメント
* コネクタ
* ルール
* Predict
* データソース

依存関係にその属性が含まれている場合、その属性を削除することはできません。

属性の依存関係を表示するには、**属性**テーブルで属性をクリックし、**依存関係**タブをクリックします。依存関係の詳細を表示するには、**移動**をクリックします。

![](https://docs.tealium.com/images/server-side/ea-visitor-dependencies.png)
