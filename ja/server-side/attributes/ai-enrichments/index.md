<blockquote>
AIエンリッチメントは選ばれた顧客のみが利用可能です。この機能を試してみたい場合は、[サポートに連絡してください](https://docs.tealium.com/support/)。
</blockquote>


AIエンリッチメントは、Tealiumの顧客データパイプライン内でリアルタイムの顧客データにLLMベースの処理を適用します。AIエンリッチメントを構成するには、AIの指示を書き、トリガーを選択し、評価および出力イベント属性を選択します。AIエンリッチメントはそのデータを評価し、出力データを含む新しいイベントを生成し、それをTealiumデータパイプラインに送り返し、オーディエンス、コネクター、およびダウンストリームのアクティベーションで利用可能にします。

## 仕組み

各AIエンリッチメントは以下のフローに従います：

**トリガー → 評価する属性 → AI指示 → イベント生成（出力イベント属性）**

トリガーが発火すると、AIエンリッチメントはAI指示に従って評価する属性を評価し、出力値を生成します。AIエンリッチメントは新しいAIエンリッチメントイベントを生成し、出力イベント属性を持つそれをTealiumデータ収集パイプラインに送り返します。エンリッチメントを完了するには、そのイベントに対して行動する属性、オーディエンス、およびコネクターを構成します。

各トリガーの実行は新しいイベントを生成します。


<blockquote>
AIエンリッチメントはトリガーイベントを変更せず、訪問プロファイルに直接書き込みません。
</blockquote>


### トリガー

トリガーはAIエンリッチメントが実行されるタイミングを決定します。各トリガーの実行は新しいAIエンリッチメントイベントを生成します。

トリガータイプは以下の通りです：

* **処理された訪問**  
訪問が選択したオーディエンスに参加または離脱するときにAIエンリッチメントが実行されます。このトリガーを使用して、オーディエンスメンバーシップの変更に基づいてエンリッチメントを評価します。
* **処理されたイベント**  
イベントフィードがイベントを処理した後にAIエンリッチメントが実行されます。このトリガーは、即時評価が必要な高信号のインタラクションに使用します。

### 評価する属性

_評価する属性_ は、AIエンリッチメントが評価する訪問、訪問、およびイベント属性です。エンリッチメントを最適化するために、AIエンリッチメントが検出する条件を意味深く反映する属性を使用します。たとえば、エンゲージメントのトレンド、サブスクリプションの変更、サポートのインタラクション、または財務信号などです。

### 出力イベント属性

_出力イベント属性_ は、生成されたAIエンリッチメントイベントに表示されるイベント属性です。出力属性を訪問プロファイルに永続化するには、生成されたイベントから属性を構成するエンリッチメントルールを構成します。

### AI指示

AI指示はAIエンリッチメントのタスク指示です。それらはビジネスの成果、評価するべき行動、決定基準、および評価する属性の解釈方法を説明します。

Tealiumは、モデルに送信する前に構成された評価する属性をAI指示に自動的に追加します。

AIエンリッチメントは以下を受け取ります：

* システムメッセージ：安全性、範囲、および出力形式をカバーするTealium制御のガードレール。
* カスタムメッセージ：入力データと組み合わせたあなたのAI指示。

最良の結果を得るために、AI指示に以下を含めてください：

* ビジネス目標または決定すること。
* 検出する行動または信号。
* 明確な基準、閾値、または許可された出力カテゴリ。
* 選択した入力データの解釈に関するガイダンス。
* データが欠落している場合やあいまいなシナリオに関する指示。

AI指示に以下を含めないでください：

* "JSONのみを返す"などのJSON形式の指示。
* 手動で書かれた出力スキーマ、フィールドリスト、またはデータタイプ。
* 評価する属性として選択していないTealium識別子やフィールド。
* 存在しないデータに関する仮定。
* 長文コンテンツやメディア生成の要求。

### AIエンリッチメントイベント

AI指示に対して属性を評価した後、AIエンリッチメントは新しいエンリッチメントイベントを生成します。このイベントには`tealium_event`とあなたの出力イベント属性が含まれ、データ収集パイプラインに戻ります。`tealium_event`の値は`async_processed_AI_ENRICHMENT_ID`の形式で、`AI_ENRICHMENT_ID`はあなたが構成する各エンリッチメントに固有です。この値を使用して、エンリッチメントルールやイベントフィードなどのダウンストリームコンポーネントを構成します。

例 AIエンリッチメントイベント：
```json
{
  "tealium_event": "async_processed_00070f98-9134-4901-adeb-2d343a0f4ac",
  "your_output_attribute": "VALUE"
}
```

### 例

**例：製品レビューの感情を分類する**

* **トリガー**: 製品レビューイベント
* **評価する属性**: 製品レビューテキスト (`product_review_text`)
* **AI指示**:  
    ```wrap
    製品レビューに基づいて、顧客の感情を「不満足」、「中立」、または「満足」として分類します。
    ```
* **出力イベント属性**: `ai_review_sentiment`

生成されたAIエンリッチメントイベント：
```json
{
  "tealium_event": "async_processed_00070f98-9134-4901-adeb-2d343a0f4ac",
  "ai_review_sentiment": "satisfied"
}
```

**例：ショッピングの意図を推測する**

* **トリガー**: 「放置されたカート」オーディエンスに参加
* **評価する属性**: `cart_product_names`, `cart_total_value`, `visit_count_7d`
* **AI指示**:  
    ```wrap
    ショッピングのミッションを推測します。"mission"を6語以下の要約で構成し、"urgency"を「high」、「med」、または「low」で構成し、ミッションが健康、妊娠、未成年者、または財政的困難を示唆している場合は"sensitive"を「true」に構成します。
    ```
* **出力イベント属性**: `shopping_mission` (文字列), `shopping_urgency` (文字列), `shopping_sensitive` (ブール値)

生成されたAIエンリッチメントイベント：
```json
{
  "tealium_event": "async_processed_20470d98-2171-4901-dacf-6a513a0f4bd",
  "shopping_mission": "back to school, high cart value",
  "shopping_urgency": "medium",
  "shopping_sensitive": false
}
```

## AIエンリッチメントを作成する

AIエンリッチメントを作成するには、**AIエンリッチメント**に移動し、**新しいAIエンリッチメント**をクリックします。

### ステップ1: トリガーを選択

オーディエンス内の訪問のステータスに基づいてAIエンリッチメントを実行するには、**処理された訪問**を選択します。このオプションを選択した後、オーディエンスと特定の[オーディエンストリガー](https://docs.tealium.com/about-connectors/#terminology)を選択します。

イベントフィードがイベントを処理した後にAIエンリッチメントを実行するには、**処理されたイベント**を選択します。このオプションを選択した後、リストからイベントフィードを選択します。

### ステップ2: 評価する属性と出力イベント属性を選択

**評価する属性**  
AIエンリッチメントが評価する属性を選択します。AI指示で説明されている行動や条件を反映する属性を選択します。トリガーが処理されたイベントの場合は、イベント属性のみを選択できます。トリガーが処理された訪問の場合は、訪問または訪問属性のみを選択できます。

**出力イベント属性**  
AIエンリッチメントが出力するイベント属性を選択します。**属性を追加**をクリックし、属性名とタイプを定義します。これらの属性は生成されたAIエンリッチメントイベントに表示されます。

### ステップ3: AI指示を書く

ビジネスの成果、評価する行動、およびAIエンリッチメントが生成すべき出力値を説明します。効果的なAI指示の書き方については、[AI指示](#ai-instructions)を参照してください。
### ステップ4: レビューと作成

AIエンリッチメント構成を確認してください：

* **AIエンリッチメント指示**: 書いたAI指示を確認してください。
* **AIエンリッチメント名**: AIエンリッチメントの名前を入力してください。
* **ステータス**: 新しいAIエンリッチメントはデフォルトで非アクティブです。作成後にAIエンリッチメントをアクティブにしてください。
* **トリガー**: AIエンリッチメントをトリガーするオーディエンスまたはイベントフィード。
* **評価する属性**: AIエンリッチメントによって評価される属性。
* **結果**: 生成されたAIエンリッチメントイベントに構成された出力イベント属性。

**作成**をクリックしてAIエンリッチメントを保存してください。

生成されたイベント名に注意してください。形式は `async_processed_AI_ENRICHMENT_ID` となります。例えば `async_processed_00070f98-9134-4901-adeb-2d343a0f4ac` です。この値を使用して下流コンポーネントを構成してください。

## 下流コンポーネントの構成

AIエンリッチメントを作成しても構成は完了しません。AIエンリッチメントは出力データを含む新しいAIエンリッチメントイベントを生成しますが、下流コンポーネントを構成するまでそのイベントに対して何も行われません。

### エンリッチメントルールの作成

生成されたイベントから訪問属性に出力属性値を書き込むエンリッチメントルールを作成してください。

エンリッチメント条件をイベント名 (`async_processed_AI_ENRICHMENT_ID`) に合わせて、生成されたAIエンリッチメントイベントのみがルールをトリガーするようにします。

この例では、エンリッチメントルールはイベントがAIエンリッチメントから来ていること、および訪問のレビュー感情がまだ構成されていないことを要求します：


[
  [
    {
      "input": "tealium_event",
      "operator": "equals",
      "filter": "async_processed_00070f98-9134-4901-adeb-2d343a0f4ac"
    },
    {
      "input": "ai_review_sentiment (visitor)",
      "operator": "not populated"
    }
  ]
]


### オーディエンスの構築

新しいAIエンリッチメント属性に基づいて訪問をセグメント化するオーディエンスルールを作成してください。

### コネクタまたはイベントフィードの構成

生成されたイベントに直接対応するために、AIエンリッチメントイベント名に基づいたイベントフィードを作成し、そのフィードに基づいてコネクタアクションを構成してください。

エンリッチされた訪問属性に対応するために、新しいオーディエンスに基づいてコネクタアクションを構成してください。

Traceを使用してAIエンリッチメントが実行され、期待される出力を生成していることを確認してください。AIエンリッチメントが実行されると、Traceは以下を表示します：
