## はじめに


![](https://docs.tealium.com/images/icons/icon-forward.svg)

#### 概要

仕組みを理解し、利用を開始するには、ここから始めてください。



![](https://docs.tealium.com/images/icons/icon-forward.svg)

#### 処理順序

サーバーサイドのデータ収集における処理順序について説明します。



![](https://docs.tealium.com/images/icons/icon-forward.svg)

#### Tealium Collectのインストール

Webサイト、モバイルアプリ、サーバーアプリケーションからデータ収集を開始するために、Tealium Collectをインストールする方法について説明します。


## 収集


![](https://docs.tealium.com/images/icons/icon-arrow-right-into.svg)

#### データソース

Webサイト、モバイルアプリ、またはカスタムアプリケーションからTealiumにデータを送信します。



![](https://docs.tealium.com/images/icons/icon-product-data-connect.svg)

#### Data Connect

社内システムのデータをTealiumに統合し、イベントと訪問のデータをエンリッチします。



![](https://docs.tealium.com/images/icons/icon-cloud-down.svg)

#### Data Cloud Activation

Tealiumにデータを保存または読み込むことなく、データクラウドから顧客データを直接アクティベートします。


## 変換


![](https://docs.tealium.com/images/icons/icon-cubes.svg)

#### 属性

イベントと訪問に関連付けられるデータ要素を定義し、エンリッチします。



![](https://docs.tealium.com/images/icons/icon-id.svg)

#### ID解決

訪問スティッチングを使用して、デバイスやチャネルをまたいで訪問のIDを統合します。



![](https://docs.tealium.com/images/icons/icon-bolt.svg)

#### 関数

JavaScript関数を記述して、受信データを変更したり、イベントやオーディエンスをリアルタイムで処理したりします。


## アクティベート


![](https://docs.tealium.com/images/icons/icon-audience.svg)

#### オーディエンス

オーディエンスセグメントを作成して、最も価値の高い顧客を特定し、アクションを実行します。



![](https://docs.tealium.com/images/icons/icon-chart-line.svg)

#### Audience Discovery

属性データをグラフィカルに可視化して、訪問セグメントを調査および検証します。



![](https://docs.tealium.com/images/icons/icon-moments-api.svg)

#### Context API

コンポーザブルAPIを使用して、リアルタイムのパーソナライゼーション向けに高パフォーマンスな訪問データを取得します。


## 分析


![](https://docs.tealium.com/images/icons/icon-product-audiencestream.svg)

#### オーディエンスダッシュボード

顧客セグメント全体のオーディエンスメンバーシップとパフォーマンスを監視します。



![](https://docs.tealium.com/images/icons/icon-timer.svg)

#### 使用状況レポート

アカウント全体のイベント量と訪問の処理状況を追跡します。



![](https://docs.tealium.com/images/icons/prod_icon_din.svg)

#### Tealium Insights

EventDBとAudienceDBのデータを可視化したダッシュボードを表示します。


## ガバナンス


![](https://docs.tealium.com/images/icons/icon-user-solid.svg)

#### 訪問検索

訪問ID属性を使用して、個々の訪問レコードを検索します。



![](https://docs.tealium.com/images/icons/icon-shield.svg)

#### サーバーサイドの同意

サーバーサイドのイベントデータ全体に同意構成を適用します。



![](https://docs.tealium.com/images/icons/icon-circles-overlap.svg)

#### 同意のオーケストレーション

目的に基づくポリシーを使用して、イベントレベルのアクティベーションに対する同意を一元的に適用します。
