## はじめに

* 解決する問題と、解決によって達成する目標を定義します。

## データの操作

* Customer Data Platform（CDP）プロファイルに、バッジやブール値など、ターゲットとなる行動を示す高品質な属性が含まれていることを確認します。該当する属性がない場合は、データを蓄積する期間をできるだけ長く確保するため、速やかに属性を作成します。
* 作業を開始する前に、データの収集とクレンジングに関するベストプラクティスを確立します。モデル作成前のデータ準備について詳しくは、[データを準備する]()を参照してください。
* データ準備の段階で、サイロ化されたデータセットを結合し、組織のデータについて改善可能なその他の特性も検討します。

## モデルのトレーニングとデプロイ

* 可能な場合は、トレーニングにより長い日付範囲を使用します。
* モデルを本番環境または実際のアプリケーションにデプロイします。
* 本番環境でモデルがどの程度適切に機能しているかを評価し、改善が必要な場合は「トレーニングとテスト」の段階に戻ります。

## オーディエンスの作成

* Tealium Predictを使用して既存のオーディエンスを改善またはエンリッチメントし、効率を高める方法を検討します。
