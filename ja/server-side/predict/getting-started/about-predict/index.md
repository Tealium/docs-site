Tealium Predict は、CDP 製品とともに使用する組み込み型の機械学習テクノロジー製品です。複雑な分野である機械学習を、完全に管理された機能へと集約します。Tealium Predict は Customer Data Platform（CDP）と連携し、よりインテリジェントなオーディエンスを構築および作成して、信頼できる機械学習インサイトをアクティベートします。

![](https://docs.tealium.com/images/predict/high-level-predict-flow.png)

Tealium Predict を使用すると、訪問の行動について有意義な予測を行うデータモデルを作成、最適化、デプロイし、以下の事項を特定できます。

* 主要業績評価指標（KPI）に影響を与える要因。たとえば、オンラインで商品を購入する可能性が高い顧客のタイプ。
* Web サイト内で購入を促進するマーケティングチャネル。
* 効果的な顧客パーソナライゼーションに適用する、オンライン訪問のセグメンテーションカテゴリー。

デプロイされたモデルは、モデルのトレーニングとデプロイ後に利用可能になる予測出力属性を使用して、Tealium によってリアルタイムで管理されます。わずか数回のクリックで、モデルスコアに基づいて訪問を分類してオーディエンスを作成し、パーソナライズされた体験を提供することで ROI を向上させることができます。

## 主なメリット

Tealium Predict の主なメリットは次のとおりです。

* **実装環境全体で機械学習インテリジェンスを活用**  
Tealium が提供する 1,200 を超える任意の統合で、予測インサイトを自動的にアクティベートできます。
* **簡素化**  
Tealium Predict テクノロジーにより、データサイエンティストや専任チームを必要とせずに機械学習を実装できます。コードを一行も記述することなく、モデルを作成してデプロイし、その価値を CDP ですぐにアクティベートできます。
* **顧客の行動を予測**  
顧客が将来取る可能性の高い行動について自動的に結論を導き出し、顧客のニーズに直接対応するカスタマイズされたプログラムを設計できます。
* **パーソナライゼーション**  
Tealium Customer Data Hub を使用すると、有意義な訪問パーソナライゼーションデータを正確に特定できます。
* **ユーザーデータを扱う機械学習プロジェクトの所要時間を短縮**  
データの収集と分析が機械学習インテリジェンスとネイティブに統合されているため、データの準備とアクティベーションにかかる時間が大幅に短縮されます。
* **予測可能性に基づいて顧客をスコアリング**  
モデルに組み込まれたテクノロジーにより、訪問が再訪問したり、特定の行動を完了したりする可能性を示すスコアが生成されます。その後、スコアを活用してオーディエンスを生成し、再エンゲージメントキャンペーンなど、さらに先を見越したアクションを実施できます。

## 顧客ユースケース

機械学習と顧客データを活用し、顧客体験の向上を通じて収益を促進する実際の方法について詳しくは、[Tealium Predict ML：顧客データを活用した注目の機械学習ユースケース トップ 5](https://tealium.com/blog/data-driven-marketing/tealium-predict-ml-top-5-emerging-machine-learning-use-cases-with-customer-data/)を参照してください。これらの顧客ユースケースでは、マーケティング、顧客体験ストラテジスト、データサイエンティストの視点から、以下の内容を取り上げています。

* プロアクティブマーケティング：機械学習を活用したセグメンテーション
* マーケティング効率：購入率またはコンバージョン率の向上
* 顧客維持：チャーンの削減
* 顧客体験：ファネルの最適化
* 予測分析：顧客インサイトの獲得と仮説の検証
