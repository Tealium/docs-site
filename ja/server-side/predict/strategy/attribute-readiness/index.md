Tealium Predictを使用してモデルを作成する際、顧客データプラットフォーム（CDP）のデータセットに含まれる、ターゲット属性として使用可能な属性のリストから選択できます。各属性には、その属性がトレーニングに使用できる状態かどうかを示す「**準備完了**」または「**準備未完了**」の評価が付けられます。属性の準備状況は、**+ New Model**をクリックしたときに表示される、使用可能な属性のドロップダウンリスト内で各属性の横に表示されます。この機能を使用すると、次の例に示すように、ターゲット出力属性の候補が「**準備完了**」または「**準備未完了**」のどちらであるかを事前に確認できます。

![](https://docs.tealium.com/images/predict/predict-v2-target-attr-ready.png)

機械学習テクノロジーで成果を得るには大量のデータが必要であり、機械学習モデルは大量のデータでトレーニングするほど、より良い結果をもたらします。

ターゲット属性が「**準備完了**」または「**準備未完了**」のどちらであるかは、次の2つの要素によって決まります。

* 属性のデータ量
* True値とFalse値の間でのデータ量の分布

TrueグループとFalseグループの両方が、最小しきい値を上回っている必要があります。たとえば、トレーニング期間内の各日について、TrueおよびFalseの訪問数の日次中央値が200以上である必要があります。このしきい値は、ターゲット属性の選択肢をできる限り多く提供するため、意図的に可能な限り低く構成されています。「**準備未完了**」と表示されたターゲット属性を使用するモデルは、通常、モデルに必要なデータが不足しているため、トレーニングプロセス中に失敗します。

「**準備未完了**」という評価は、その属性がほかの用途でも問題になるという意味ではありません。現時点では、Tealium Predictモデルのトレーニングを正常に行うには不十分であると判断されていることを意味します。

使用するターゲット属性に「**準備未完了**」と表示されている場合は、次のいずれかの解決策を試してください。

* データがさらに蓄積されるまで待ちます。多くの場合、時間が経過して対象期間が長くなると問題は自然に解消されます。
* CDPデータソースへのトラフィックを増やす方法を検討します。
* CDPプロファイルにデータソースを追加し、このターゲットの日次データ量を増やします。
