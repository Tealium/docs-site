## 動作原理

Moments APIの**インサイト**タブは、Moments APIエンジンの書き込みと読み取りに関するビジュアライゼーションとデータを表示します。エンジンの書き込みは、エンジンで使用される訪問データが更新されたときに発生します。エンジンの読み取りは、エンドポイントに対して`GET`リクエストが行われたときに発生します。

Moments API インサイト機能をオフにすると、ダッシュボードとそのデータはこの変更を公開してから30日後に削除されます。データを保持するには、この期間内に機能を再度有効にしてください。

Moments APIの**インサイト**タブには、以下のビジュアライゼーションとデータが表示されます：

* エンジンの読み取り
* エンジンの書き込み
* エンジンの読み取りと書き込み
* データ制限を超えたエンジン書き込みリクエストで書き込まれなかったもの
* データ制限を超えたエンジン書き込みの平均サイズ
* 時間経過による総読み取り数
* 時間経過による総書き込み数
* エンジン別の総読み取り数
* エンジン別の総書き込み数
* 時間経過による書き込まれなかった総データ量（バイト単位）

### データ制限を超える書き込みリクエスト

エンジンに多数のオーディエンス、バッジ、および属性が指定されている場合、エンジンの書き込みサイズは、訪問ごとのエンジンごとに保存できる最大データ量を超えることがあります。オーディエンス、バッジ、および属性の名前を使用すると、書き込みサイズが増加することもあります。詳細については、[制限](https://docs.tealium.com/about-moments-api/#limits)を参照してください。

エンジンの書き込みが訪問ごとのエンジンごとの最大データ量を超えている場合、以下のいずれかの方法で書き込みサイズを減らすことができます：

* オーディエンス、バッジ、および属性の名前の代わりに属性IDを使用する。
* データを2つ以上のエンジンに分割する。

## 日付範囲を選択

データとビジュアライゼーションのデフォルトの**日付範囲**は**過去30日間**です。新しい**日付範囲**を選択するには、次の手順を使用します：

1. **コントロール**バーをクリックします。  
![](https://docs.tealium.com/images/server-side/moments-api-insights-tab-control-bar.png)
1. 現在の**日付範囲**をクリックします。
1. 次のいずれかを行います：  
    * 週、月、四半期、または年ごとにデータを表示するには、**Relative by**をクリックしてオプションを選択します。  
    * 絶対的な日付範囲のデータを表示するには、**Absolute date range**をクリックし、開始日と終了日を選択します。    
    ディスプレイは新しいデータで更新されます。
1. リストを閉じるには、**コントロール**バーをクリックします。

## エンジンを選択

データとビジュアライゼーションのデフォルトの**エンジン**は**すべて**です。特定のエンジンを選択するには、次の手順を使用します：

1. **コントロール**バーをクリックします。  
![](https://docs.tealium.com/images/server-side/moments-api-insights-tab-control-bar.png)
1. 現在の**エンジン**をクリックして新しいエンジンを選択します。  
ディスプレイは新しいデータで更新されます。
1. リストを閉じるには、**コントロール**バーをクリックします。

## Moments API インサイトタブの更新

Moments APIの**インサイト**タブに表示されるビジュアルは、Tealium InsightsのMoments APIダッシュボードでも利用可能です。Moments APIの**インサイト**タブには、データセットの構造または容量に注意が必要な場合にメッセージが表示されます。

### Moments API インサイトデータセットの更新

Moments API インサイトのデータセット構造が更新された場合、データセット構造が古くなっていることを示すメッセージがMoments API インサイトタブに表示され、更新が必要です。

データセットを更新するには、次の手順を使用します：

1. メッセージで**更新**をクリックします。
1. 確認メッセージで**送信**をクリックします。  
データセットの更新が完了すると、成功メッセージが表示されます。

### Moments API インサイトデータセットのリフレッシュ

Moments API **インサイト**タブのデータセットが最大容量に達した場合、データセットが容量制限に達し、リフレッシュが必要であることを示すメッセージが表示されます。

データセットのデータをリフレッシュするには、次の手順を使用します：

1. メッセージで**リフレッシュ実行**をクリックします。
1. 確認メッセージで**送信**をクリックします。  
データセットのリフレッシュはバックグラウンドで実行されます。リフレッシュが完了すると、データセットには最新の800百万行のみが含まれます。
