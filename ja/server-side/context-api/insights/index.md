## 仕組み

Context API の **インサイト** タブには、Context API のエンジン書き込みとエンジン読み取りに関するビジュアライゼーションおよびデータが表示されます。エンジンで使用される訪問データが更新されると、エンジン書き込みが発生します。エンドポイントに `GET` リクエストが行われると、エンジン読み取りが発生します。

Context API インサイト機能を無効にした場合、この変更をパブリッシュしてから30日後にダッシュボードとそのデータが削除されます。データを保持するには、この期間内に機能を再度有効にしてください。

Context API の **インサイト** タブには、以下のビジュアライゼーションとデータが表示されます。

* エンジン読み取り
* エンジン書き込み
* エンジン読み取りと書き込み
* データ上限を超えたため書き込まれなかったエンジン書き込みリクエスト
* データ上限を超えたエンジン書き込みの平均サイズ
* 経時的な読み取り総数
* 経時的な書き込み総数
* エンジン別の読み取り総数
* エンジン別の書き込み総数
* 経時的な未書き込みデータの合計バイト数（データ上限を超えた書き込みリクエストによるもの）

### データ上限を超える書き込みリクエスト

1つのエンジンに多数のオーディエンス、バッジ、属性を指定すると、エンジン書き込みのサイズが、エンジンごとに訪問1人当たり保存可能なデータの最大量を超える場合があります。オーディエンス、バッジ、属性に名前を使用することでも、書き込みサイズが増加する可能性があります。詳細については、[制限](https://docs.tealium.com/about-context-api/#limits)を参照してください。

エンジン書き込みが、エンジンごとに訪問1人当たりのデータの最大量を超えている場合は、次のいずれかの方法で書き込みサイズを削減できます。

* オーディエンス、バッジ、属性には、名前ではなく属性IDを使用します。
* データを2つ以上のエンジンに分割します。

## 日付範囲の選択

データとビジュアライゼーションのデフォルトの **日付範囲** は **過去30日間** です。新しい **日付範囲** を選択するには、次の手順を実行します。

1. **コントロール** バーをクリックします。  
![](https://docs.tealium.com/images/server-side/moments-api-insights-tab-control-bar.png)

<blockquote>
このスクリーンショットには、以前の製品名「Context API」が表示されています。製品UIの更新時に更新される予定です。
</blockquote>

1. 現在の **日付範囲** をクリックします。
1. 次のいずれかを実行します。  
    * 週、月、四半期、または年単位でデータを表示するには、**相対期間** をクリックしてオプションを選択します。  
    * 絶対日付範囲のデータを表示するには、**絶対日付範囲** をクリックし、開始日と終了日を選択します。    
    新しいデータで表示が更新されます。
1. リストを閉じるには、**コントロール** バーをクリックします。

## エンジンの選択

データとビジュアライゼーションのデフォルトの **エンジン** は **すべて** です。特定のエンジンを選択するには、次の手順を実行します。

1. **コントロール** バーをクリックします。  
![](https://docs.tealium.com/images/server-side/moments-api-insights-tab-control-bar.png)
1. 現在の **エンジン** をクリックして、新しいエンジンを選択します。  
新しいデータで表示が更新されます。
1. リストを閉じるには、**コントロール** バーをクリックします。

## Context API インサイトタブの更新

Context API の **インサイト** タブに表示されるビジュアルは、Tealium Insights でも Context API ダッシュボードとして利用できます。データセットの構造または容量に対応が必要な場合、Context API の **インサイト** タブにメッセージが表示されます。

### Context API インサイトデータセットの更新

Context API インサイトのデータセット構造が更新されると、データセット構造が古くなっており、更新が必要であることを示すメッセージが Context API インサイトタブに表示されます。

データセットを更新するには、次の手順を実行します。

1. メッセージ内の **更新** をクリックします。
1. 確認メッセージで **送信** をクリックします。  
データセットの更新が完了すると、成功メッセージが表示されます。

### Context API インサイトデータセットのリフレッシュ

Context API の **インサイト** タブのデータセットが最大容量に達すると、データセットが容量上限に達しており、リフレッシュが必要であることを示すメッセージが表示されます。

データセット内のデータをリフレッシュするには、次の手順を実行します。

1. メッセージ内の **リフレッシュを実行** をクリックします。
1. 確認メッセージで **送信** をクリックします。  
データセットのリフレッシュはバックグラウンドで実行されます。リフレッシュが完了すると、データセットには最新の8億行のみが含まれます。
