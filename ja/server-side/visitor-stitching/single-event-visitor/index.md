## 仕組み

シングルイベント訪問とは、Webサイトまたはモバイルアプリへの新規訪問から、Tealiumがリアルタイムイベントを1件受信し、その訪問中に追加のアクティビティが発生しなかった場合を指します。

以下のすべての条件を満たす訪問は、シングルイベント訪問と見なされます。

* **受信したイベントが1件のみ**  
  訪問中に受信したイベントが1件だけである。
* **訪問スティッチングなし**  
  イベントによって訪問スティッチングがトリガーされない。
* **バッジの割り当てなし**  
  訪問中にバッジが割り当てられない。
* **ファイルインポート由来ではない**  
  イベントがファイルインポートから生成されたものではない。

## 顧客データプラットフォーム（CDP）

シングルイベント訪問はCDPに永続化され、AudienceStoreに渡されてAudienceDBに保存されます。

訪問が新しいセッションで再訪すると、再訪問として認識されます。


<blockquote>
2026年4月29日より前は、CDPではシングルイベント訪問のレコードは永続化されていませんでした。
</blockquote>


## EventStoreとEventDB

シングルイベント訪問のイベントはEventStoreとEventDBに保存され、対応するレコードがAudienceStoreとAudienceDBに保存されます。

## 訪問時間

デフォルトのセッション時間は30分です。ただし、追加のイベントが発生しない場合、シングルイベント訪問は10分後に終了します。

これは、訪問の初回訪問にも適用されます。
