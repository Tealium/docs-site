## AudienceStore コネクタの構成

Connector Marketplace に移動し、新しいコネクタを追加します。コネクタを追加する一般的な手順については、[コネクタについて](https://docs.tealium.com/about-connectors/)を参照してください。


<blockquote>
オーディエンス名は 128 文字未満にする必要があります。それ以上の場合、DataAccess によってオーディエンス名が切り詰められ、エラーが発生する可能性があります。
</blockquote>


## アクション

| アクション名 | 顧客データプラットフォーム（CDP） | イベントストリーミング |
| --- | --- | --- |
| バケットに訪問データを送信（すべての属性） | ✓ | ✗ |
| バケットに訪問データを送信（選択した属性） | ✓ | ✗ |

### バケットに訪問データを送信（すべての属性）

#### パラメーター

| **パラメーター** | **説明** |
| --- | --- |
| 現在の訪問データを含める | 現在の訪問に関するすべてのイベントデータを含めるには、このチェックボックスをオンにします。 |
| 属性 ID で送信 | デフォルトでは、訪問データの JSON プロパティキーは CDP の属性名に基づきます。CDP の属性 ID をキーとしてデータを送信するには、このチェックボックスをオンにします。 |

#### バッチ処理オプション

| **パラメーター** | **説明** |
| --- | --- |
| 最大レコード数 | コネクタがオーディエンスフォルダーにバッチを送信する前に収集するレコード数です。1,000～100,000 レコードの値を入力します。 |
| 有効期間 | コネクタがオーディエンスフォルダーにバッチを送信するまでの待機時間です。20～180 分の値を入力します。 |
| 最大ペイロードサイズ | コネクタがオーディエンスフォルダーにバッチを送信する前に収集するペイロードのサイズです。1 MB～100 MB の値を入力します。 |

### バケットに訪問データを送信（選択した属性）

#### パラメーター

| パラメーター | 説明 |
| --- | --- |
| 保存する訪問属性 | 訪問属性を列ヘッダー名にマッピングします。 |
| データを CSV 形式にする（オフの場合は JSON） | デフォルトの JSON ファイルではなく CSV ファイルとしてデータを保存するには、このチェックボックスをオンにします。 |

#### バッチ処理オプション

| **パラメーター** | **説明** |
| --- | --- |
| 最大レコード数 | コネクタがオーディエンスフォルダーにバッチを送信する前に収集するレコード数です。1,000～100,000 レコードの値を入力します。 |
| 有効期間 | コネクタがオーディエンスフォルダーにバッチを送信するまでの待機時間です。20～180 分の値を入力します。 |
| 最大ペイロードサイズ | コネクタがオーディエンスフォルダーにバッチを送信する前に収集するペイロードのサイズです。1 MB～100 MB の値を入力します。 |

詳細については、[AudienceStore コネクタ構成ガイド]()を参照してください。

AudienceStore コネクタを構成すると、コネクタの詳細ページにアクション、各アクションがトリガーされた回数、およびステータスが表示されます。


<blockquote>
後で AudienceStore を無効にすると、AudienceStore コネクタも無効になります。AudienceStore を再度有効にした場合は、AudienceStore コネクタを手動で有効にする必要があります。
</blockquote>


Audience コネクタを構成した後、**Store > AudienceStore** に移動すると、JSON または CSV ファイルを表示およびダウンロードできます。各ファイルには、訪問のプロファイルデータ（訪問属性および訪問属性）が含まれています。サードパーティ製ツールを使用してファイルを表示することもできます。詳細については、[ファイルの表示]()を参照してください。
