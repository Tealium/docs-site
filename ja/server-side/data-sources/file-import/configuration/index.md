<blockquote>
開始する前に、構成プロセス中にアップロードするサンプルCSVファイル（1,000列未満）を作成してください。このサンプルファイルは、列のマッピングを自動検出するために使用されます。
</blockquote>



<blockquote>
正常にインポートするには、CSVファイルが正しくフォーマットされている必要があります。ファイル形式については、[インポート用CSVファイルの準備](https://docs.tealium.com/prepare-a-csv-file-for-import/)を参照してください。
</blockquote>


## 1. ファイルインポートデータソースを追加する

  1. **Connect > Data Sources**に移動します。
  1. **+ Add Data Source**をクリックします。
  1. **Categories**で**File Import**をクリックし、**File Import**プラットフォームを選択します。
  1. **Name**フィールドに、ファイルタイプに関連する一意の名前を入力します。
  1. **Continue**をクリックします。

## 2. サンプルファイルをアップロードする（任意）

ファイルインポートの構成でサンプルCSVファイルを使用する場合は、**Upload Sample File**画面でアップロードします。サンプルファイルの1行目にある列名が自動的に検出され、**Column Mappings**画面のエントリを事前構成するために使用されます。

この手順を省略してファイル内の列を手動で指定するには、**Continue**をクリックして**Map Columns**画面に直接進みます。

サンプルファイルをアップロードするには、次の手順を実行します。

1. **Upload File**をクリックし、アップロードするサンプルCSVファイルを選択します。  
**Sample File**プレビュー画面に、ファイルの内容が表形式で表示されます。
1. サンプルファイルをスクロールし、列とデータが正しく表示されていることを確認します。検出された列名は表の下にCSV形式で一覧表示され、**Map Columns**画面に事前入力されます。
1. サンプルファイルに問題がある場合は、**Remove**をクリックしてエラーを修正するか、別のファイルを試します。
1. サンプルファイルの内容を確認し終えたら、**Continue**をクリックします。

## 3. 列のマッピングを構成する

**Map Columns**テーブルを使用して、事前構成された列ラベルをイベント属性にマッピングするか、マッピングするファイルの列ラベルを手動で入力します。CSVファイルの各行はイベントとして処理されます。

イベント属性にマッピングされていない列は無視されます。CSVファイルに存在しないマッピング済みの列も無視されます。

ファイルの列ラベルをイベント属性にマッピングするには、次の手順を実行します。

1. **Event Specification**ドロップダウンリストを使用して、ファイル内のデータに一致する仕様を選択します。カスタムのイベント属性セットを使用するには、**Custom**を選択します。  
この選択により、インポートプロセス中の`tealium_event`属性の値が決まります。**Custom**を選択した場合、`tealium_event`は**imported**に構成されます。それ以外の場合は、**purchase**など、対応する仕様名に構成されます。
<blockquote>
選択した仕様を変更すると、列マッピングテーブルがリセットされます。
</blockquote>

1. サンプルファイルをアップロードしていない場合は、ファイルの列ラベルを**Map Columns**テーブルに入力します。各CSV列ラベルは一意である必要があります。
1. ドロップダウンリストから、対応するイベント属性を選択します。  
列に日付／時刻の値が含まれている場合は、対応する属性を選択して**Set Format**をクリックします。**Date/Time Format**スライドアウトで、適切な日付／時刻形式を選択するか、カスタム形式を入力して**Done**をクリックします。
1. 対応するすべてのイベント属性のマッピングが完了したら、**Continue**をクリックします。

## 4. 訪問ID属性をマッピングする

ファイルデータをCustomer Data Platform（CDP）で使用するには、データを訪問ID属性にマッピングします。訪問IDを表すマッピング済みイベント属性を選択し、対応する訪問ID属性にマッピングします。


<blockquote>
AudienceStreamのVisitor ID Mappingはデフォルトで有効になっています。訪問IDのマッピングを無効にすると、訪問のスティッチングでエラーが発生する可能性があります。AudienceStreamのVisitor ID Mappingについて詳しくは、[Tealiumデータソースを使用した訪問の識別](https://docs.tealium.com/visitor-identification-data-sources/)を参照してください。
</blockquote>


## 5. ファイル転送サービスを構成する


<blockquote>
独自のファイル転送サービスを使用する場合は、続行する前に接続情報を用意してください。
</blockquote>


既存のファイルサービス構成を選択するか、新しい構成を作成します。
* ファイルサービス構成をすでに作成している場合は、[既存のファイルサービス構成を完了する](#complete-an-existing-file-service-configuration)セクションを参照してください。
* ファイルサービス情報を変更するには、構成名の横にある編集アイコンをクリックします。
* 新しい構成を追加するには、[新しいファイルサービス構成を追加する](#add-a-new-file-service-configuration)セクションを参照してください。

### 既存のファイルサービス構成を完了する

ファイルサービス構成を完了または編集するには、次の手順を実行します。

1. **Choose File Service Configuration**ドロップダウンリストから既存の構成を選択します。
1. `customers`などの**File Name Prefix**を入力します。ファイル名のプレフィックスは、ファイル内のデータをインポートするときに使用するファイルインポートデータソースを識別するために使用されます。この例では、`customers`というプレフィックスを使用して、`customers_VERSION.csv`という名前のCSVファイルを作成します。プレフィックスにはアンダースコアを含めることができますが、末尾にアンダースコアを含めないでください。
<blockquote>
ファイル名のプレフィックスは、複数のファイルインポートデータソース間で一意である必要があります。たとえば、`customers`と`customers-orders`というプレフィックスは、先頭のプレフィックス`customers`が共通しているため、予期しない結果が発生します。
</blockquote>

1. （任意）ファイル処理の効率を向上させるには、GZIP形式を使用してファイルを圧縮します。ファイルが圧縮されている場合は、**Compression**形式として**GZIP**を選択します。
1. （任意）ファイルを安全に処理するために、PGP暗号化を使用してファイルを暗号化します。ファイルが暗号化されている場合は、**Encryption**形式として**PGP**を選択します。
<blockquote>
圧縮と暗号化の両方が行われたファイルを処理する場合は、最初にファイルを圧縮し、その後で暗号化する必要があります。以前にマッピングしたファイルの新しいバージョンでは、元のファイルと同じ暗号化および圧縮方式を使用する必要があります。  
File Importでの圧縮について詳しくは、[ファイルインポートデータソースでの暗号化と圧縮](https://docs.tealium.com/encryption-and-compression-file-import/)を参照してください。
</blockquote>

1. **Enable File Service Processing**セクションで、トグルを使用してFile Importのサービス処理を有効または無効にします。
    * **ON**に構成すると、ファイルサービスが確認され、ファイルが10分ごとに処理されます。
    * ファイルの処理を開始する準備ができていない場合は、**OFF**に構成します。サービスは後で有効にできます。
1. **Continue**をクリックして、**Summary**タブに移動します。

### 新しいファイルサービス構成を追加する

新しいファイル転送サービス構成を追加するには、次の手順を実行します。

1. **+**アイコンをクリックして、新しいファイルサービス構成を追加します。
1. **Service Configuration**画面で構成の名前を入力し、使用するファイルサービスのタイプを選択します。
1. 選択したサービスへのアクセスに必要な認証情報を入力します。  
    * **Tealium S3 Bucket** - 必要な認証情報は自動的に生成されます。
    * **My SFTP Connection** - **Authentication Method**を選択します。サポートされている認証方法は、**Password**、**Upload Private Key File**、および**Generate Key Pair**です。
      * **Password**を選択した場合は、パスワードを入力して**Test File Source Connection**をクリックします。
      * **Upload Private Key File**を選択した場合は、リストからファイルを選択して**Test File Source Connection**をクリックします。
      * **Generate Key Pair**を選択した場合は、**Generate**をクリックしてから**Test File Source Connection**をクリックします。
1. （任意）ファイルサービス接続をテストするには、**Test Connection**をクリックします。
1. **Save**をクリックします。
## 6. 概要
最後の手順では、概要を確認し、必要に応じて修正してから、プロファイルを保存して公開します。


1. **イベント属性**と**訪問 ID のマッピング**を確認します。
1. 構成を編集するには、**前へ**をクリックして、変更する手順に戻ります。
1. **完了**をクリックして構成画面を終了します。新しいデータソースが**データソースダッシュボード**に表示されます。
1. **保存／公開**をクリックして、変更を保存して公開します。


<blockquote>
インポート処理のステータスを確認するには、データソースを展開して**ステータス**タブをクリックし、**データソースダッシュボード**に移動します。詳細については、[インポートステータスの表示](https://docs.tealium.com/view-import-status/)を参照してください。
</blockquote>



## ファイルインポートデータソース構成の編集

ファイルインポートデータソースの構成を変更するには、**データソースダッシュボード**に移動し、変更する構成の横にある編集アイコンをクリックします。**データソース構成**画面では、列のマッピング、訪問 ID のマッピング、およびファイルサービスの構成を編集できます。
