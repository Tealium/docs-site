## トレースイベントを再生する

トレース画面では、トレースの概要にあるいずれかのアイコンをクリックして、イベントの再生、一時停止、または再開を行うことができます。

![](https://docs.tealium.com/images/server-side/trace-icons.png)

次の表では、各トレースアイコンについて詳しく説明します。

| アイコン | 説明 |
| ---- | ----------- |
| ![](https://docs.tealium.com/images/server-side/trace-icon-play-normal.png) | 通常の速度で再生します。イベントの再生には、デフォルトで通常速度が使用されます。|
| ![](https://docs.tealium.com/images/server-side/trace-icon-play-2x.png) | 通常の2倍の速度で再生します。|
| ![](https://docs.tealium.com/images/server-side/trace-icon-pause.png) | 進行中のトレースを一時停止します。一時停止中もバックグラウンドでは新しいイベントの処理が継続されますが、再度一時停止アイコンをクリックして再開するまで、新しいログエントリは表示されません。|
| ![](https://docs.tealium.com/images/server-side/trace-icon-view-profile.png) | 最新の訪問プロファイルを表示します。最新の訪問のプロファイルのスナップショットがJSON形式で表示されます。このウィンドウを閉じるには、**OK**をクリックします。|
| ![](https://docs.tealium.com/images/server-side/trace-icon-get-code-replay.png) | イベントを再生するためのコードを取得すると、イベントごとにcurlコマンドが生成されます。Webページ上で構成手順を再現することなくトレース内のイベントを再生するには、ターミナルウィンドウで`curl`コマンドを実行します。<ul><li>単一のイベントを再生するには、対応するcurlコマンドをコピーしてターミナルウィンドウに貼り付け、**Enter**キーを押してコマンドを実行します。</li><li>複数のイベントを再生するには、**Download Bash Script**をクリックして.shファイルをダウンロードします。ターミナルウィンドウで.shスクリプトを実行します。</li></ul> |
| ![](https://docs.tealium.com/images/server-side/trace-icon-exit-race.png) | 現在のトレースを終了します。Webページ上でトレースがまだアクティブな場合は、トレースIDを使用してトレースに再度参加できます。|

## イベントの詳細を表示する

次の画像は、トレースインターフェイスの各部分を示しています。**Trace Log**は、アクション、イベント、オーディエンスをリアルタイムでスクロール表示する概要です。**Overview Panel**には、詳細なアクティビティのスナップショットが表示されます。**Search**を使用すると、訪問属性および訪問スコープ属性のリストから特定の属性を検索できます。リスト内の属性は、データ型（数値、日付など）ごとにグループ化されます。**Filters**を使用すると、これらの属性を絞り込むことができます。

![](https://docs.tealium.com/images/server-side/trace-log-sections.png)

### フィルター

フィルタリングを使用すると、属性とそれに関連付けられた構成が正常に機能しているかどうかを確認できます。フィルターを使用して、属性とその値の表示方法を選択できます。ラベル（属性にラベルを追加している場合）またはタイプで属性を絞り込みます。タイプには次のいずれかを指定します。

* **All**  
Customer Data Platform（CDP）プロファイルに構成されているすべての属性タイプと値を表示します。
* **Existing**  
CDPの処理後に値を取得した属性のみを表示します。
* **Modified**  
変更またはエンリッチされた属性のみを表示します。

## トレースログ

トレースログでは、クリック可能なテキストは青色で、それ以外のテキストは灰色です。ログエントリの横にあるタイムスタンプには、そのログエントリの時刻が表示されます。イベントの詳細を表示するには、青色のイベントテキストをクリックして、イベントの詳細ビューをスライド表示します。


<blockquote>
UIの他の機能に移動しても処理を継続できるように、トレースウィンドウを最小化できます。
</blockquote>

## 1つのトレース内の複数の訪問プロファイル

次の場合、1つのトレースIDで複数の訪問プロファイルが取得されることがあります。

* 複数のテストセッションで、セッション間にトレースを停止せず、同じトレースIDを再利用した場合。
* 複数のドメインにまたがってテストを行い、訪問がスティッチされていない場合（たとえば、ドメイン間でTAPID値が一致しない場合）。

トレースに複数の訪問プロファイルが含まれている場合、トレースログで選択したイベントにかかわらず、概要パネルには常に最新の訪問プロファイルのスナップショットが表示されます。以前の訪問プロファイルのイベントも、引き続きトレースログに表示されます。

1つのトレースに複数の訪問プロファイルが混在しないようにするには、テストセッションごとに新しいトレースIDを生成してください。
