## 必要条件

トレースを使用するには、次の項目が必要です。

* Event StreamingまたはCustomer Data Platform（CDP）  
* [Tealium Toolsブラウザー拡張機能](https://chrome.google.com/webstore/detail/tealium-tools/gidnphnamcemailggkemcgclnjeeokaa)  


<blockquote>
一括イベントにトレースIDを追加しないでください。<br>本番データを監視するための永続的なパラメータとして、トレースIDを追加しないでください。
</blockquote>


## 仕組み

トレースを使用すると、Event StreamingとCDPの内部動作を詳しく確認できます。トレースツールは、構成をテストするうえで不可欠です。トレースを使用してワークフローの詳細を確認し、属性が正しく更新されていること、ルールが正しく適用されていること、アクションが想定どおりにトリガーされることを確認します。

トレースインターフェイスでは、次の操作を実行できます。

* トレースを開始または停止する
* 実行中のトレースに参加する
* 事前定義されたワークフローとイベントログの詳細をリアルタイムで表示する
* ルールを構成して結果を表示する
* イベントを再実行、一時停止、または再開するためのリプレイコードを取得する
* アクション、イベント、オーディエンスの概要をスクロール表示する
* イベントまたは処理ステップの詳細を表示する
* 訪問プロファイルのスナップショットを表示する


<blockquote>
無効なトレースIDはイベントデータから削除されます。
</blockquote>


## 制限

* **時間制限**：アクティビティの有無にかかわらず、トレースは12時間後にタイムアウトして削除されます。
* **イベント数の制限**：1つのトレースでサポートされるイベントは最大250件です。上限に達すると、トレースは新しいイベントの受け入れを停止します。
* **Functions**：トレースを使用してFunctionsをテストする場合、関数呼び出しは1分あたり15回に制限されます。
