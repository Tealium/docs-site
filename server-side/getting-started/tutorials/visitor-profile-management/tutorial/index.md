This tutorial shows you how to set up Customer Data Platform (CDP) using visit and visitor attributes, a dynamic audience, and a vendor connector. Then test your configuration using live data from your website or application.

## Requirements

To complete this tutorial, you need:

* Tealium server-side login credentials
* An existing Tealium server-side account
* An activated visitor profile management account
* A vendor that provides a server-side API (optional)

## What is visitor profile management?

![](https://docs.tealium.com/images/tutorials/audiencestream-customer-evolution.jpg)

Tealium visitor profile management is a CDP that provides identity resolution, data enrichment, and audience management. It creates visitor profiles based on visitor behavior and attributes. You can group these profiles into audiences and use connectors to trigger real-time actions.

Visitor profile management provides the following capabilities:

* **Visitor stitching:** Combines visitor data to create a unified customer profile.
* **Vendor integrations:** Server-side API integrations trigger actions based on real-time customer data signals.

This tutorial covers attributes, audiences, connectors, and testing.
