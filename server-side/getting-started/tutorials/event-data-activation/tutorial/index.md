This tutorial shows you how to set up a server-side profile with a data source, event specifications, and a vendor connector. Then test your configuration using live data from your website or application.

## Requirements

To complete this tutorial, you need:

* Tealium server-side login credentials
* Access to modify the code of a website or mobile app
* A vendor that provides a server-side API (optional)

## What is event data activation?

![](https://docs.tealium.com/images/tutorials/eventstream-icon.jpg)

Tealium event data activation is a server-side data collection and delivery platform. It uses server-side vendor integrations to reduce mobile app size, minimize client-side network requests, and deploy new vendors without code releases.

You can use event data activation to collect and manage incoming data, define event specifications, monitor data quality, and route data to vendors.
