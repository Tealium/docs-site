The Tealium Developer Portal is where you discover, subscribe to, and make authenticated requests to Tealium APIs. From the Developer Portal you can browse available APIs, create applications, manage OAuth2 credentials, and monitor API usage.

New to the Developer Portal? Start with [About the Tealium Developer Portal](https://docs.tealium.com/dev-portal-about/) to understand how applications, subscriptions, scopes, and tokens work together. Then follow the [getting started tutorial](https://docs.tealium.com/dev-portal-getting-started/) for a step-by-step walkthrough of your first API call.
