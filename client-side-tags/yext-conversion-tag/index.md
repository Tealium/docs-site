---## Tag tips

* Use mapping to override the standard configuration values.
* Conversions will fire if the ID mapping is populated.

## Tag configuration

Go to the tag marketplace to add a new tag. For more information, see [About tags](https://docs.tealium.com/about-tags/).

## Data mappings

Data mappings send values from data layer variables to the corresponding variables in the vendor tag. For more information, see [About data mappings](https://docs.tealium.com/about-data-mappings/).

The available categories are:

### Standard

|Variable| Description|
|---| ---|
|`optin`|  <ul><li>Optin</li></ul> |
|`cid`|  <ul><li>Customer Identification Number (CID)</li></ul> |
|`value`|  <ul><li>Value</li></ul> |
